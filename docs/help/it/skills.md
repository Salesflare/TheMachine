Una skill insegna alla tua Machine come svolgere un certo tipo di compito, per esempio «rispondere a domande sui prezzi». Contiene solo istruzioni: non cambia mai ciò che la tua Machine può fare.

## Scrivi una skill

In **Impostazioni**, **Skill**, premi **Nuova skill** o **Parti da un esempio**. Inserisci **Nome**, **Quando usarla** e **Istruzioni**, poi premi **Salva**.

## Quando viene usata

Ogni attività che la tua Machine prepara riceve la skill più adatta, senza che tu debba chiederlo: una che ha lo stesso nome completo della bacheca, del progetto o del titolo. Vengono considerate anche le altre skill, quindi viene seguita anche quella dedicata a quel tipo di lavoro, per esempio una risposta in un tipo di conversazione già noto o un aggiornamento del CRM.

## Importa

Premi **Importa**:

- **Da Claude** o **Da ChatGPT**, poi **Trova le mie skill**. Cerca le skill in quell’account, nel browser della tua Machine.
- Oppure importa una skill dal tuo dispositivo: **Carica .skill o .zip**, **Carica una cartella** o **Incolla un SKILL.md**.

Seleziona le skill che vuoi e premi **Importa selezionate**. Vengono importate solo le istruzioni, mai gli script.

## Cerca su ClawHub

Trova le skill pubblicate da altre persone. Leggine una prima di installarla: sono create da altri, non da The Machine.

## Dalle tue note

Quando molte delle tue note riguardano lo stesso tipo di compito, un’attività suggerisce una skill. Prima controlla le skill che hai già:

- Una svolge già quel compito: **Aggiorna <skill>** mostra la skill con ciò che le note insegnano e le modifiche evidenziate. Solo **Aggiorna skill** la modifica.
- Una è collegata, ma distinta: l’attività spiega in una riga in cosa consiste e propone comunque **Crea skill**.

**Non ora** lascia le note come sono. Anche le skill che la tua Machine propone in Impostazioni > Skill vengono controllate allo stesso modo.

## Da un’attività

Chiedi di creare una skill in un’attività e la tua Machine la scriverà lì. Apri **Leggi la skill**, poi premi **Crea skill** (o **Aggiorna skill** se ne hai già una). Non viene installato nulla finché non lo fai. Se invece l’hai scartata in Impostazioni > Skill, l’attività mostra **Skill scartata** e resta aperta finché non la chiudi.

## Condividi una skill

Condividi una skill con un amico o una persona del tuo team. Potrà leggerla e scegliere se installarla. Le modifiche successive le arriveranno solo se la condividi di nuovo.
