## Da dove arrivano

- Su una Machine ospitata, i dettagli delle organizzazioni vengono cercati per te, senza costi.
- Sul tuo computer, la funzione è disattivata finché non aggiungi una chiave per un servizio di ricerca, come Apollo, People Data Labs o Hunter. Consulta la [guida alla configurazione](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md).

Viene inviato solo l’indirizzo web dell’organizzazione, mai i tuoi messaggi né le persone che conosci lì. Una Machine ospitata o collegata a The Machine Network effettua fino a 1.000 ricerche al giorno; altrimenti, fino a 50. I dettagli vengono aggiornati ogni 90 giorni. I siti condivisi e i servizi di posta, come gmail.com, non vengono mai cercati. Per le persone viene effettuata una ricerca a parte: consulta [Ruolo e foto](people.md#job-title-and-photo).

Se la ricerca non trova un logo, The Machine usa l’icona del sito web dell’organizzazione, salvata sulla tua Machine. Nessun servizio di loghi può sapere con chi hai a che fare. Se sono disponibili sia un logo sia un’icona, nei punti in cui c’è poco spazio, come la riga di un’attività, viene mostrata l’icona quadrata.

Se disponibili, sotto la descrizione dell’organizzazione vengono mostrate fino a 5 specializzazioni. Puoi anche filtrare l’elenco delle organizzazioni per specializzazione: **Filtra**, poi **Specializzazione**. Se la ricerca di una persona include i dettagli dell’azienda per cui lavora, questi vengono aggiunti anche all’organizzazione, senza bisogno di cercarli a parte. I dettagli cercati negli ultimi 90 giorni restano invariati.

## Correggere un risultato errato

Nella pagina dell’organizzazione:

- **Modifica** per cambiare il nome, il settore, le dimensioni, la posizione, l’anno di fondazione, la descrizione, il sito web, LinkedIn, le note e il tuo rapporto con l’organizzazione. Le modifiche vengono mantenute. Svuota un campo per ripristinare il valore trovato dalla ricerca.
- Se è stata scelta l’azienda sbagliata, seleziona **Azienda sbagliata, cancella i dettagli** in **Modifica**.
- Dopo aver cancellato i dettagli, seleziona **Cercalo di nuovo** per recuperare informazioni aggiornate.
