サイドバー下部の **ヘルプ** をタップして、自分の言葉で質問します。「ToDoをスヌーズするには？」のように入力してください。Enterで送信し、Shift+Enterで改行します。回答はアプリの言語、または入力した言語で表示されます。ヘルプページへのリンクを開くと、パネル内にその言語で表示されます。

## 回答の参照元

質問に合ったヘルプページを読み、説明がない内容についてはアプリのコードを参照します。内容が合わない場合は、別の言葉でもう一度検索します。回答には、参照したページへのリンクが付きます。

回答はMachine上のモデルを使って、短い独立したチャットとして生成されます。入力欄の下で、このヘルプチャットに使うモデルや思考レベルを変更できます（[モデル](model.md)を参照）。モデルに渡るのは質問と該当するページだけです。ほかのメッセージ、人物、設定は含まれません。

質問の内容に合わせて、一般的な質問にはわかりやすく、技術的な質問には詳しく回答します。セットアップや役割、質問の仕方から知識レベルを推測し、モデルに渡るのはその推測だけです。

まずThe Machineに備わっている機能を案内し、それで対応できない場合にのみスキルを提案します。[自分らしく使う](personalize.md)をご覧ください。

## チームに共有される情報

ヘルプの改善のため、Machineでは各質問の内容を表す短い語句をいくつか集計します。たとえば「ToDoをスヌーズする」などです。質問や回答そのもの、名前、住所、数字は含まれません。集計されるのは、これらのヘルプページにある語句だけです。集計結果は1日1回、アカウント情報を含めずにThe Machineチームへ送信されます。

送信を停止するには、**設定** の **セキュリティ** にある **The Machineチーム** の **ヘルプへの質問内容を共有** をオフにするか、[セキュリティレベル](security-levels.md)を **慎重** に設定してください。この機能には [The Machine Network](/network) が必要です。まだ送信されていない集計結果は削除されます。

## できないこと

ヘルプは質問に回答します。データを確認したり、何かを変更したりすることはできません。代わりに、どこをタップすればよいかを案内します。

操作方法ではなく、不具合についての説明だと思われる場合は、回答の最後に **このバグを報告** が表示されます。タップすると **バグを報告** が開き、行った操作、期待した結果、実際に起きたことを簡潔にまとめた内容と、サポートへの報告にチェックが入った状態で表示されます。内容は自由に変更できます。**送信** を押すまで、何も送信されません。

**バグを報告** は、同じパネルにある独立したタブからも開けます。[サポートを受ける](get-support.md#report-a-bug)をご覧ください。
