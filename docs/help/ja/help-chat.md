サイドバー下部の **ヘルプ** をタップします。**設定** の上にあります。たとえば「ToDoをスヌーズするには？」のように、自分の言葉で質問してください。Enterで送信し、Shift+Enterで改行できます。ヘルプはアプリの言語、または入力した言語で回答します。ヘルプページへのリンクは、その言語でパネル内に直接開きます。

## 回答の情報源

ヘルプは、質問に関連するヘルプページを読み、ページに書かれていないことについてはアプリのコードを参照します。回答には、参照したページへのリンクが付きます。

Machine自体のモデルを使い、短いやり取りを独立したチャットとして行います。メッセージボックスの下で、このヘルプチャットに別のモデルや思考レベルを選べます（[モデル](model.md)をご覧ください）。使われるのは質問と関連するページだけです。メッセージ、人物、設定は使われません。

理解度に合わせて回答します。多くの場合はわかりやすい言葉で、技術的な質問にはより詳しく答えます。設定、役割、質問の仕方から理解度を推測します。使われるのは推測した理解度だけです。

まずThe Machineに備わっている機能を案内し、それで対応できない場合にのみスキルを提案します。[自分らしく使う](personalize.md)をご覧ください。

## チームに共有される情報

ヘルプの改善のため、Machineは質問ごとに、その内容を示すいくつかの単語を数えます。たとえば「ToDoをスヌーズする」などです。質問や回答そのもの、名前、アドレス、数字は含まれません。ヘルプページにある単語だけが対象です。1日1回、集計結果がアカウント情報なしでThe Machineチームに送信されます。

送信を停止するには、**設定** の **セキュリティ** にある **The Machineチーム** の **ヘルプへの質問内容を共有** をオフにするか、[セキュリティレベル](security-levels.md)で **慎重** を選びます。この機能には[The Machine Network](/network)が必要です。まだ送信されていないデータは削除されます。

## できないこと

ヘルプは質問に回答します。データを見ることはできず、何かを変更することもありません。代わりに、どこをタップすればよいか案内します。

説明された内容が使い方の質問ではなく不具合のように思われる場合、回答の最後に **このバグを報告** が表示されます。タップすると **バグを報告** が開き、行ったこと、期待していたこと、実際に起きたことを簡潔にまとめた内容と、サポートへの報告にチェックが入った状態で表示されます。内容は自由に変更できます。**送信** を押すまでは、何も送信されません。

同じパネルには、**バグを報告** 専用のタブもあります。[サポートを受ける](get-support.md#report-a-bug)をご覧ください。
