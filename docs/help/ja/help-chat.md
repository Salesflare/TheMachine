上部の **ヘルプ** をタップしてください。**設定** の隣にあります。「ToDoをスヌーズするには？」のように、自分の言葉で質問できます。Enterで質問を送信し、Shift+Enterで改行できます。ヘルプはアプリの言語、または入力した言語で回答します。ヘルプページへのリンクをタップすると、その言語のページがパネル内で開きます。

## 回答の情報源

ヘルプは、質問に関連するヘルプページを読み、ページに説明がない場合はアプリのコードも参照します。回答には、参照したページへのリンクが表示されます。

Machine独自のモデルを使い、通常のチャットとは別の短いチャットとして動作します。メッセージボックスの下で、このヘルプチャットに別のモデルや思考レベルを選べます（[モデル](model.md)をご覧ください）。送信されるのは質問と関連するページだけです。メッセージ、連絡先、設定は送信されません。

質問する人の知識に合わせて回答します。多くの場合はわかりやすい言葉で説明し、技術的な質問には詳しく答えます。設定、役割、質問の仕方から知識のレベルを推測します。送信されるのは推測したレベルだけです。

まずThe Machineに標準で備わっている機能を案内し、標準機能で対応できない場合にのみスキルを提案します。[自分好みに設定する](personalize.md)をご覧ください。

## チームに共有される情報

ヘルプの改善のため、質問の内容を示す「ToDoをスヌーズする」のような単語を、Machineがいくつか数えます。質問や回答そのもの、名前、住所、数字は送信されず、ヘルプページにある単語だけが対象です。1日1回、アカウント情報を含めずに集計数がThe Machineチームに送信されます。

送信を停止するには、**設定** の **セキュリティ** にある **The Machineチーム** の **ヘルプで依頼された内容を共有** をオフにするか、[セキュリティレベル](security-levels.md)を **慎重** に設定してください。この機能には[The Machine Network](/network)が必要です。まだ送信されていない情報は削除されます。

## できないこと

ヘルプは質問に答えます。データを見ることはできず、何かを変更することもありません。代わりに、どこをタップすればよいかを案内します。

説明された内容が使い方の質問ではなく、不具合のように思われる場合、回答の最後に **このバグを報告** が表示されます。タップすると **バグを報告** が開き、行ったこと、想定していたこと、実際に起きたことを簡潔にまとめた内容が入力され、サポートへの報告にもチェックが入ります。内容は自由に変更できます。**送信** を押すまでは、何も送信されません。

**バグを報告** は、同じパネル内に独立したタブとしても表示されます。[サポートを受ける](get-support.md#report-a-bug)をご覧ください。
