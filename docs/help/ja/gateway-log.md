## 読み取る内容

Machine 自身のログです。失敗した実行、拒否された引き継ぎ、送信されなかったTelegramのメッセージ、The Machine 自身のエラーを確認します。修正が必要になると、ToDoでお知らせします。

## 更新時に保留された修正

The Machine の更新後、新しいバージョンに合わなくなった修正があると、その修正を保留して更新を続行します。Machine が古いバージョンのままになることはありません。ToDo **更新時に保留された修正をやり直す**に、該当する修正が表示されます。

**やり直す**を選ぶと、新しいバージョンに合わせて修正を作り直します。ほかの修正と同様、変更内容を確認して**修正をマージ**をタップします。マージすると、古い修正は削除されます。ToDoを閉じることもできます。

## 更新時に保持された自分のファイル

新しいバージョンに、自分で追加したファイルと同じ名前のファイルが含まれている場合、更新時に上書きせず、自分のファイルの名前を変更して続行します。ToDoには保持されたファイルの数と、変更前後の名前が表示されます。確認したらToDoを閉じてください。

## できること

ありません。Machine 自身のログを読み取るだけです。

## 接続する

- ホスト型のMachineでは、設定ページの**その他のソース**に「Machine の状態」として表示されます。Machineごとに1つです。
- 自分のコンピューターでは、`assistant connect gateway`を実行します。

## 削除する

- ダッシュボードで**接続**を開き、**詳細**から**接続を解除**します。
- ホスト型のMachineでは、設定ページで横にある**削除**を押すこともできます。

ほかの場所でアンインストールする必要はありません。
