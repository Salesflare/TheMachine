## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今後1週間の予定、期限のToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜日のまとめなど、決まった周期でMachineが行う作業を確認できます。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人物、組織、プロジェクトを確認できます。それぞれのページはサイドバーに表示されます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkに参加しているチーム、家族、友達を確認できます。参加後に表示されます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの進み具合や、学習した内容を確認できます。
- **接続**：接続元とその状況を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の **検索または質問** から、ToDo、人物、メッセージなどを検索できます。そのすぐ下には **新しいToDo** があります。サイドバー下部には **ブラウザー**、**ヘルプ**、**設定** があります。スマートフォンでは、上部バーのメニューボタンを押すとサイドバーが開きます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も **確認待ち** に表示されるため、件数は上部の数字と一致します。タップすると開きます。

ToDoのメニューを開くには、カーソルを合わせて **⋯** をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選択して `Shift F10` を押します。メニューには **名前を変更** と **開く** のほか、ToDoごとの **完了にする**、**スヌーズ**、**不要** があります。それぞれ **元に戻す** こともできます。

**ブラウザー** では、MachineがLinkedInなどのサイトで使うブラウザーを確認できます。パソコンではサイドバーの横に開きます。ToDoの **ブラウザーで表示** や、サイトへのログインが必要なときの **ブラウザーを開く** も同じです。スマートフォンのブラウザーでは新しいタブで開きます。スマートフォンアプリ、またはホーム画面に追加したダッシュボードでは、画面いっぱいに表示されます。Xを押すと戻ります。

**原寸大** を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと元に戻ります。

ToDoがブラウザーを使っている間は、上部に **停止** が表示されます。押すと、その実行をすぐに終了します。それ以降クリック、入力、送信は行われず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

複数の実行がある場合は、現在表示中の実行が停止します。続けるには、ToDoのチャットに入力するか、**再試行** を押します。

ToDoが多くて画面に収まらない場合、サイドバー全体が1つの列としてスクロールします。

スマートフォンでは、**このメールを送信しますか？** などのダイアログが画面いっぱいに表示されます。入力中もボタンは常に押せる位置にあります。

## もっと活用する

ToDoの上部には、Machineをもっと便利にするための小さなToDoが表示されます。スマートフォンアプリやデスクトップアプリ、通知、WhatsApp、別のアカウント、その他の接続などが対象です。各項目には、その手順に進むボタンが1つあります。完了した項目は一覧から消えるため、残っている手順だけが表示されます。一度に表示されるのは最大5項目です。未完了の手順が先に表示されるため、メールで提案されたGitHubなどのツールは、先の手順が完了すると一覧に加わります。

項目は、利用できる場合にだけ表示されます。Chromebookのようにデスクトップアプリを使えないパソコンでは、代わりにブラウザーからダッシュボードをインストールする案内が表示されます。項目の横にある×を押すと、どのデバイスでもその項目が閉じます。最上部の×を押すと、ToDo全体が閉じます。

初日を過ぎると、**確認待ち** の上に「残り2件・続ける」のような控えめな1行で表示されます。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

最初の2週間は、新しいToDoが1件以下の日に、理由付きの提案が1つToDoの先頭に表示されることがあります。たとえば「WhatsAppを接続しますか？メール5件で言及されています。」や「WhatsAppをもう一度試しますか？コードの有効期限が切れました。」のように表示されます。折りたたむと、ボタンと×が付いた提案だけが表示されます。提案は、その手順に通常表示される項目に置き換わります。最初の確認を終えるときに次の手順が表示される場合は、その間、提案は待機します。

提案は、Machineがすでに持っている情報だけをもとに表示されます。WhatsAppへのリンクや、知り合いからのメールでの言及、接続済みのメールボックスには取り込まれていない自分のメールアドレス、SlackやTeamsの会議からのメール、接続が完了しなかった場合などです。表示するのは最大で件数だけで、メッセージの内容や送信者は表示しません。一度に表示されるのは1件までで、新しい提案は1日1件までです。メールや通知で送られることはありません。×を押すと、その提案は完全に閉じます。

**元に戻す** または **非表示の1件を表示** を押すと、項目が再表示されます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo** の順に開きます。**設定** の **一般** にある **このデバイス** でも同じ設定ができます。**設定** の **アプリ** には、常にスマートフォンアプリが表示され、パソコンではデスクトップアプリも表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンが、使用中に再読み込みされることはありません。アプリを開いたとき、またはウィンドウを数分間バックグラウンドにしたり、操作せずにいたりすると読み込まれます。未保存のテキストがあるときや、ダイアログを開いているときに中断することはありません。上部に **更新の準備完了** が表示されたら、押してすぐに読み込めます。

大きな機能や改善が追加されると、**新機能** の短いお知らせが表示されます。表示は1日1回までです。**戻る** と **次へ** を押すか、スワイプして確認できます。お知らせ内のボタンを押すと、その機能が開きます。**完了** または **×** を押すと閉じます。操作中の画面に重なって表示されることはなく、一度閉じるとすべてのデバイスで表示されなくなります。使い始めてから公開された内容だけが表示されます。

## メッセージ

Macでは `⌘K`、WindowsまたはLinuxでは `Ctrl K` を押すと検索が開きます。スマートフォンでは検索アイコンを押します。2文字以上入力すると、Machineが読んだすべての内容から、意味や単語がよく一致するメッセージが **メッセージ** に表示されます。過去の[履歴](history.md)は単語で検索されます。

検索欄では質問もできます。検索欄が空のときに表示される質問例のように尋ねると、自分のメッセージから短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を見る** を押すと、すべてのアカウントまたは選択した1つのアカウントの結果が一覧で開きます。結果を開くと、内容を読める画面が表示され、元の場所へのリンクもあります。検索欄が空の場合は、最新のメッセージが表示されます。

検索では最も一致する結果が先に表示されます。メッセージ全体がある場合、スマートフォンのプレビューはそのメッセージとして一度だけ表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、回答の元になったメッセージが表示されます。メッセージに答えがない場合は、回答を表示しません。

## 学び

学びでは、Machineが学習した内容と、ToDoがどれだけ役立っているかを確認できます。内容がないタブは表示されません。

- **学習した内容**：メッセージから作成したプロフィール（役割、文体、言語、大切にしていること）、文章の書き方、事実、メモから学習した好みを確認できます。自分の言葉で **編集** したり、不要になった内容を **削除** したりできます。プロフィールは `USER.md` に保存されています。編集すると、その行だけが変更されます。ここで自分で変更した行が、後から上書きされることはありません。チャットで何かを忘れるよう頼むこともできます（「引っ越したことを忘れて」など）。事実が1つだけ一致する場合は削除され、設定の **アクティビティ** と **変更内容** から **元に戻す** ことができます。複数の事実が一致する場合は、どれを削除するかチャットで確認されます。メモから事実やルールを学習すると、ToDoのチャットに **学習した内容に保存しました** と表示され、**編集** と **元に戻す** ができます。
- 事実には **一時的**、**約束**、**設定** の種類があり、いつまで有効かを **まで** で指定できます。一時的な事実は数週間で、好みや約束は数か月で、その他の事実は1年で薄れていきます。有効期限が過ぎるか、新しいメッセージで無効になったことがわかると、事実は **終了済み** に移動します。**再表示** すると元に戻ります。
- **事実** には、全般的な情報、つまり自分や仕事の進め方に関する情報が保存されます。人物、組織、プロジェクトに関する事実は、Graph内の各ページにある **把握している情報** に保存され、そこで編集できます。人物などのフルネームが記載された事実は、保存時にそのページに移動します。ToDoのチャットには、その人物などの名前とともに **追加先**、**Graph内** と表示されます。Graphのページに保存されている事実の数は、**事実** の下に控えめな1行で表示されます。開くと各ページに移動できます。自分のメッセージから得た事実には、元になった言葉が引用符付きで表示されます。
- 誰かの電話番号やメールアドレスを入力すると、事実ではなくGraphのその人物のページに保存されます。電話番号がすでに1つの記録にあり、別の記録に同じ名前が登録されている場合は、2つの記録がマージされます。ToDoのチャットには、名前とともに **追加先** と表示され、**元に戻す** ことができます。誰の情報かはっきりしない場合は、事実として保存されます。
- 使われていないからといって、情報が削除されることはありません。各ToDoには関連性の高い事実が表示され、新しい事実ほど重視されます。そのため、あまり必要にならない事実も、ほかの情報を圧迫せずに残ります。終了した事実も、関連するToDoやチャットでは履歴として役立ちますが、現在の状況として扱われることはありません。
- メモの内容が、すでに学習した内容を別の言い方で表している場合は、置き換えられるため、同じ情報が重複して表示されません。**マージを元に戻す** と、以前の表現に戻ります。自分で編集した内容が置き換えられることはありません。
- **これらを取り込む**：以前OpenClawを使っていた場合、メモ（`MEMORY.md`、`USER.md`）から残しておく価値のある行が、元のファイル名とともに上部に表示されます。残す項目にチェックを入れて、**チェックを入れたままにする** を押すと、ほかの情報と同じように事実やルールになります。Graph内の人物などに関する事実はそのページに移動します（誕生日は「誕生日」ルーティンにも追加されます）。自分に関する事実は「事実」に残ります。**残りを却下** すると、却下した項目は再表示されません。ファイルが変更されることはなく、残す価値のある内容がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが知っている情報を取り込みます。アシスタントを選んで **プロンプトをコピー** し、そのアシスタントに送信して、回答を貼り付けます。**確認** 画面で各行を残すか、編集するか、チェックを外すか選べます。すでに伝えた行は除外されます。事実と食い違う行は、その事実の横に表示されるため、どちらを残すか選べます。パスワード、コード、キー、カード番号、アカウント番号は、表示前に除外されます。許可を与えようとする行も除外されます。インポートした事実は参考情報であり、許可として扱われることはありません。各行には情報の取得元と取得時期が表示され、編集するまでは **編集するまでは参考情報のみです** と示されます。初期設定のToDoや、最初の確認中にも表示されます。
- **変更内容**：編集、却下、チャットを通じて学習した内容を確認できます。それぞれ **元に戻す** ことができます。[文章](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに対して行った選択のタイムラインです。
- **共有済み**：Machineチームと共有する学習内容や、投票がある場合は投票を確認できます。[学びを共有する](share-learnings.md)をご覧ください。
- **進み具合**：過去30日間の4つの数値を確認できます。数値が高いほど良好です。決定したToDoが3件に達すると表示が始まります。決定とは、実行するか却下したToDoのことです。それまでは、決定した件数が表示されます。
  - **効果**：決定したToDoのうち、却下せずに実行したもの（**実行**、送信、または完了）の割合です。
  - **完了**：**実行** で開始し、終了したToDoのうち、完了したものの割合です。手順が完了した、完了としてマークした、または自動的に完了した場合が含まれます。却下または期限切れになったものは未完了として数えます。まだ開いているものはまだ集計されず、**進行中** と表示されます。
  - **一度で成功**：完了したToDoのうち、**実行** 後に修正が必要なかったものの割合です。
  - **完了** と **一度で成功** は、ToDoが3件に達してから数値が表示されます。
  - **そのまま送信**：送信した下書きのうち、編集や **修正を依頼** をせずに送信したものの割合です。
  - 各数値は、その前の30日間と比較されます。グラフには最初の2週間は日ごと、その後は週ごとに、最大8週間分の棒が表示されます。
  - **ソース別の効果**：ソースごとに実行した件数を確認できます。たとえば **メール**、**追加しました**（**新しいToDo** から追加）、**Androidの通知**、**The Machine自身**（エラーなどの問題）です。
  - **見逃したToDo**：週に1回、ToDoが作成されなかったメッセージをサンプル調査し、ToDoが必要だった可能性のある件数を推定します。該当するメッセージが一覧表示されます。**開く**、またはメッセージの行を押すと内容を確認できます。**実際の見落とし** または **見落としではありません** を選び、判定が正しかったかを伝えます。**実際の見落とし** を選ぶとToDoも追加され、**元に戻す** ことができます（**ToDoを開く** を押すとそのToDoが開きます）。Machineはその内容を学習し、以降は似たメッセージを見つけやすくなります。回答すると数値がすぐに調整され、その内容はMachineに保存されます。残りがわずかになると、割合の代わりに **少数** と表示されます。最初の週次チェック後に表示されます。
