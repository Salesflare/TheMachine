## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今後1週間の予定、期限を迎えるToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜のまとめなど、決まった周期でMachineが行う作業です。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人、組織、プロジェクトを確認できます。それぞれのページはサイドバーに表示されます。[Graph](graph.md)をご覧ください。
- **Fleet**：Fleetを利用している場合、The Machine Network上のチーム、家族、友人を確認できます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの状況や、学習した内容を確認できます。
- **接続**：接続元とその状況を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の **検索または質問** から、ToDo、人、メッセージなどを検索できます。そのすぐ下には **新しいToDo** があります。下部には **ブラウザー**、**ヘルプ**、**設定** があります。スマートフォンでは、上部バーのメニューボタンからサイドバーを開けます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も **確認待ち** に表示されるため、件数は上部の表示と一致します。タップすると内容を確認できます。

ToDoのメニューを開くには、カーソルを合わせて **⋯** をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoにフォーカスして `Shift F10` を押します。メニューには **名前を変更** と **開く** のほか、ToDoごとの **完了にする**、**スヌーズ**、**不要** があり、それぞれ **元に戻す** こともできます。

**ブラウザー** では、LinkedInなどのサイトでMachineが使うブラウザーを表示します。パソコンではサイドバーの横に開きます。ToDoの **ブラウザーで表示** や、サイトへのサインインが必要なときの **ブラウザを開く** も同じ場所に開きます。スマートフォンのブラウザーでは新しいタブに開きます。スマートフォンアプリや、ホーム画面に追加したダッシュボードでは全画面で開きます。Xを押すと戻ります。

**原寸大** を選ぶと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと戻ります。

ToDoがブラウザーを使っている間は、上部に **停止** が表示されます。1回押すと、その処理がすぐに終了します。それ以上クリック、入力、送信は行われず、ToDoのチャットに「ブラウザーから停止しました」と表示されます。

複数の処理が実行中の場合は、手前に表示されている処理が停止します。続けるには、ToDoのチャットにメッセージを入力するか、**再試行** を押します。

ToDoが多くて表示しきれない場合は、サイドバー全体が1つの列としてスクロールします。

スマートフォンでは、**このメールを送信しますか？** のようなダイアログが全画面に表示されます。入力中もボタンをすぐに押せます。

## 活用する

ToDoの上部には、Machineをもっと便利にするための項目をまとめた小さなToDoがあります。スマートフォンアプリ、通知、WhatsApp、このパソコンのアプリ、別のアカウント、その他の接続などが表示されます。各行には、その設定に進むボタンが1つあります。設定が終わると行はリストから消え、残りの項目だけが表示されます。行は最大5つまで表示され、未完了の項目が先に並びます。そのため、メールからわかったGitHubなどのツールは、前の項目を設定してから表示されます。

行は必要な場所にだけ表示されます。行の横にある×を押すと、すべてのデバイスでその行が閉じます。上部の×を押すと、ToDo全体が閉じます。

初日が終わると、**確認待ち** の上に「残り2ステップ・続ける」のような控えめな1行にまとまります。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

**元に戻す** または **非表示の項目を1件表示** を押すと、行を再表示できます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo** の順に開きます。**設定** の **一般** にある **このデバイス** にも同じ設定があります。**設定** の **アプリ** には、スマートフォンアプリが常に表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンが公開されても、使用中に再読み込みされることはありません。アプリを開いたとき、またはウィンドウを数分間バックグラウンドにしたり、操作せずにいたりすると読み込まれます。未保存のテキストや開いているダイアログを中断することはありません。上部の **更新の準備完了** を押すと、すぐに読み込めます。

大きな機能や改善が公開されると、**新機能** のお知らせが表示されます。表示は1日に1回までです。**戻る** と **次へ** で進むか、スワイプしてください。お知らせ内のボタンを押すと、その機能が開きます。**完了** または **×** で閉じます。操作中の画面に重ねて表示されることはなく、閉じるとすべてのデバイスで表示されなくなります。使い始めてから公開された内容だけが表示されます。

## メッセージ

Macでは `⌘K`、WindowsとLinuxでは `Ctrl K` を押すか、スマートフォンで検索アイコンをタップして検索を開きます。2文字以上入力すると、Machineが読んだすべての内容から、意味や語句がよく一致するものが **メッセージ** に表示されます。古い[履歴](history.md)は語句で検索されます。

検索画面で質問することもできます。空の検索欄に表示される質問例のように入力すると、自分のメッセージをもとに短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示** を押すと、すべてのアカウント、または選択したアカウントの結果一覧が開きます。各結果を開くと閲覧画面が表示され、元の場所へのリンクも確認できます。検索欄が空の場合は、最新のメッセージが表示されます。

検索では最も一致度の高い結果が最初に表示されます。スマートフォンでメッセージの一部をプレビューした場合、そのメッセージは全体を表示したときに一度だけ表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、その回答の元になったメッセージが表示されます。メッセージに答えがない場合、回答は表示されません。

## 学び

「学び」では、Machineが学習した内容と、ToDoの効果を確認できます。内容のないタブは非表示になります。

- **学んだこと**：メモから学んだ、文章の書き方、事実、好みの進め方を確認できます。内容は自分の言葉で **編集** でき、事実ではなくなったものは **削除** できます。チャットで何かを忘れるよう頼むこともできます（「引っ越したことを忘れて」など）。事実が1つだけ一致する場合は削除され、**設定** の **アクティビティ** と **変更内容** から **元に戻す** ことができます。複数一致する場合は、どれを忘れるかチャットで確認されます。メモから事実やルールを学習すると、ToDoのチャットに **学習した内容に保存しました** と表示され、**編集** と **元に戻す** を選べます。
- 事実には **一時的**、**約束**、**設定** の種類があり、いつまで有効かを **まで** で設定できます。一時的な事実は数週間で、設定と約束は数か月で、その他の事実は1年で薄れていきます。期限を過ぎた場合や、新しいメッセージで有効でないとわかった場合は、事実が **終了済み** に移動します。**再表示** すると元に戻せます。
- **事実** には、自分自身や仕事の進め方に関する一般的な内容が保存されます。人、組織、プロジェクトについての事実は、Graphの各ページにある **把握していること** に保存され、そこで編集できます。誰かのフルネームが含まれる事実は、保存時にその人のページへ移動し、ToDoのチャットにその人の名前とともに **Graphに保存しました** と表示されます。**事実** の下には、Graphのページに保存されている事実の数が控えめに表示されます。開くと各ページに移動できます。自分のメッセージから得た事実には、元になった言葉が引用符付きで表示されます。
- 人の電話番号やメールアドレスを入力すると、事実ではなくGraphのその人のページに保存されます。すでに1つのレコードに登録されていて、同じ名前の別のレコードが1つだけある場合は、2つのレコードが統合されます。ToDoのチャットには **追加先** とその人の名前が表示され、**元に戻す** こともできます。誰の情報か特定できない場合は、事実として保存されます。
- リストがいっぱいになることはありません。項目が増えると、3週間使われていない事実やルールは **保留** に移動します。**再表示** すると元に戻せます。編集または再表示した項目は、そのまま残ります。保留中の事実も、関連するToDoやチャットでは参考にされます。終了済みの事実は履歴としてのみ使われ、現在の状態としては扱われません。
- メモに、すでに学習した内容が別の言葉で書かれている場合は、既存の内容と置き換わり、重複して表示されません。**マージを元に戻す** と、以前の表現に戻ります。自分で編集した内容が置き換わることはありません。
- **これらを取り込む**：以前OpenClawを使っていましたか？メモ（`MEMORY.md`、`USER.md`）から残す価値のある行が、元のファイル名とともに上部に表示されます。残す項目にチェックを入れて **チェックを入れたままにする** を押すと、通常の事実やルールとして保存されます。Graph上の人物に関する事実はその人のページに移動し、誕生日は「誕生日」ルーティンにも反映されます。自分に関する事実は「事実」に残ります。**残りを却下** すると、再表示されません。ファイルは変更されず、残す価値のある内容がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが自分について知っている内容を取り込めます。アシスタントを選び、**プロンプトをコピー** して相手に送信し、返答を貼り付けます。**確認** では、残す行や編集する行を選び、不要な行のチェックを外せます。すでに伝えた内容はスキップされ、事実と食い違う行は事実の横に表示されるため、どちらを残すか選べます。パスワード、コード、キー、カード番号、口座番号は表示前に除外され、権限を与えようとする行も除外されます。インポートした事実は参考情報であり、権限を与えるものではありません。それぞれに取得元と日付が表示され、編集するまでは **編集するまでは参考情報のみです** と示されます。初期設定のToDoでも、初回の読み込み中にも利用できます。
- **変更内容**：編集、却下、チャットから学習した内容を確認できます。それぞれ **元に戻す** ことができます。[文章の作成](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに対する選択の履歴を確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、確認待ちの投票がある場合はその内容を確認できます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **利用状況**：過去30日間の4つの数値を確認できます。数値が高いほど良好です。判断済みのToDoが3件（実行または却下）になると表示されます。それまでは、判断したToDoの件数が表示されます。
  - **効果**：判断したToDoのうち、却下せずに実行した（**実行**、送信、または完了した）割合です。
  - **一度で成功**：**実行** で始めたToDoのうち、その後に修正が不要だった割合です。
  - **完了**：**実行** で始めたToDoのうち、続行や再試行を依頼せずに完了した割合です。
  - **そのまま送信**：送信した下書きのうち、編集や **修正を依頼** をせずに送信した割合です。
  - 各数値は、その前の30日間と比較されます。グラフは最初の2週間は日ごと、その後は週ごとに、最大8週間分の棒グラフを表示します。
  - **ソース別の効果**：**メール**、**追加しました**（**新しいToDo** から）、**電話への通知**、**The Machine自身**（エラーなどの問題）といったソースごとに、実行した件数を確認できます。
  - **見逃したToDo**：週に1回、ToDoが作成されなかったメッセージをサンプルで確認し、ToDoが必要だった可能性のある件数を推定します。見つかったメッセージが一覧に表示されます。**開く** またはメッセージの行を押すと内容を確認でき、**本当の見落とし** または **見落としではありません** を選ぶと、判定が正しかったかを伝えられます。**本当の見落とし** を選ぶとToDoも追加され、**元に戻す** ことができます（**ToDoを開く** からそのToDoに移動できます）。その内容からMachineが学習し、以降は似たメッセージを見つけられるようになります。回答は数値の精度向上に使われ、Machineに保存されます。最初の週次チェック後に表示されます。
