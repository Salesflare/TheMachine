## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今週の予定、期限を迎えるToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜日のまとめなど、Machineが定期的に行う作業を確認できます。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人物、組織、プロジェクトを確認できます。サイドバーから、それぞれのページを開けます。[Graph](graph.md)をご覧ください。
- **Fleet**：利用を始めると、The Machine Network上のチーム、家族、友達を確認できます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの進み具合や、学習した内容を確認できます。
- **接続**：接続先とその状態を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の**検索または質問**から、ToDo、人物、メッセージなどを検索できます。そのすぐ下には**新しいToDo**があります。下部には**ブラウザー**、**ヘルプ**、**設定**があります。スマートフォンでは、上部のメニューボタンからサイドバーを開けます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も**確認待ち**に表示されるため、件数は上部の表示と一致します。タップすると開きます。

ToDoのメニューを開くには、ToDoにカーソルを合わせて**⋯**をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDo上で`Shift F10`を押します。メニューには**名前を変更**と**開く**のほか、**完了にする**、**スヌーズ**、**不要**があります。それぞれ**元に戻す**こともできます。

**ブラウザー**では、LinkedInなどのサイトで使う、Machine専用のブラウザーを表示します。パソコンではサイドバーの横に開きます。ToDoの**ブラウザーで表示**や、サイトへのログインが必要なときの**ブラウザーを開く**も同じ場所に表示されます。スマートフォンのブラウザーでは新しいタブに開きます。スマートフォンアプリ、またはホーム画面に追加したダッシュボードでは全画面で開きます。Xを押すと戻ります。

**原寸大**を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと戻ります。

ToDoがブラウザーを使用中は、上部に**停止**が表示されます。一度押すと、その処理はすぐに終了します。それ以上クリック、入力、送信は行われず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

複数の処理が実行中の場合は、手前に表示されている処理が停止します。続けるには、ToDoのチャットに入力するか、**再試行**を押します。

ToDoが多くて表示しきれない場合、サイドバー全体が1列のままスクロールします。

スマートフォンでは、**このメールを送信しますか？**のようなダイアログが全画面に表示されます。入力中もボタンを押せる位置に表示されます。

## さらに活用する

ToDoの上部には、スマートフォンアプリ、デスクトップアプリ、通知、WhatsApp、別のアカウント、追加の接続先など、The Machineをもっと便利にするための小さなToDoが表示されます。各行にはその手順用のボタンが1つあり、完了すると一覧から消えます。そのため、残っている手順だけが表示されます。表示される行は最大5件で、未完了の手順が先に並びます。たとえば、メールで提案されたGitHubなどのツールは、前の手順が完了すると行に追加されます。

行は、表示に適したデバイスにだけ表示されます。Chromebookのようにデスクトップアプリを使えないパソコンでは、代わりにブラウザーからダッシュボードをインストールする案内が表示されます。行の×を押すと、どのデバイスでもその行を閉じられます。上部の×を押すと、ToDo全体が閉じます。

初日を過ぎると、**確認待ち**の上に「残り2件 · 続ける」のような控えめな1行に折りたたまれます。タップするとToDoが開き、矢印をタップすると再び折りたためます。

最初の2週間は、新しいToDoが1件以下の日に、理由付きの提案が1つ、ToDoの先頭に表示されることがあります。たとえば、「WhatsAppを接続しますか？メールで5件言及されています。」や「WhatsAppをもう一度試しますか？コードの有効期限が切れました。」のように表示されます。折りたたむと、提案とそのボタン、×だけが表示されます。この提案は、その手順の通常の行の代わりに表示されます。最初の確認の最後に次の手順が表示される間は、提案は表示されません。

提案には、The Machineがすでに持っている情報だけを使います。WhatsAppへのリンクや、人物から届いたメールでのWhatsAppへの言及、接続済みのメールボックスに含まれていない自分のメールアドレス、SlackやTeamsの会議からのメール、完了しなかった接続などです。表示されるのは最大で件数のみで、メッセージの内容や送信者は表示されません。同時に表示されるのは1件までで、新しい提案は1日に最大1件です。メールや通知で届くことはありません。×を押すと、提案は完全に閉じます。

**元に戻す**または**非表示の1件を表示**を押すと、行を再表示できます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo**の順に選びます。**設定**の**一般**にある**このデバイス**にも同じ操作があります。**設定**の**アプリ**には、スマートフォンアプリが常に表示され、パソコンではデスクトップアプリも表示されます。

## 新しいバージョン

新しいダッシュボードのバージョンが公開されても、使用中にページが再読み込みされることはありません。アプリを開いたとき、またはウィンドウが数分間バックグラウンドにあるか、操作されていないときに読み込まれます。保存していないテキストや開いているダイアログを中断することはありません。画面上部の**更新の準備完了**を押すと、すぐに読み込めます。

大きな機能や改善が公開されると、1日に最大1回、小さな**新機能**のお知らせが表示されます。**戻る**と**次へ**で進むか、スワイプして確認できます。お知らせのボタンを押すと、その機能が開きます。**完了**または**×**を押すと閉じます。操作中の画面に重なって表示されることはなく、一度閉じるとどのデバイスでも再表示されません。利用を始めてから公開された内容だけが表示されます。

## メッセージ

Macでは`⌘K`、WindowsとLinuxでは`Ctrl K`を押すか、スマートフォンでは検索アイコンを押すと検索が開きます。2文字以上入力すると、Machineが読んだすべての内容から、意味や単語が一致する関連度の高い結果が**メッセージ**に表示されます。古い[履歴](history.md)は単語で検索されます。

ここで質問することもできます。空の検索欄に表示される質問の例を使うと、自分のメッセージから短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示**を押すと、すべてのアカウント、または1つのアカウントの結果を一覧で確認できます。各結果を開くと、閲覧画面に元の場所へのリンクが表示されます。検索欄が空のときは、最新のメッセージが表示されます。

検索結果は関連度の高いものから表示されます。スマートフォンで、全文を読めるメッセージのプレビューがある場合は、そのメッセージとして1回だけ表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、その元になったメッセージが表示されます。メッセージに答えが書かれていない場合、回答は表示されません。

## 学び

「学び」では、The Machineが学習した内容と、ToDoがどれくらい役立っているかを確認できます。項目が空の場合は、タブが非表示になります。

- **学習した内容**：メモから学んだ文章の書き方、事実、好みを確認できます。内容は自分の言葉で**編集**でき、当てはまらなくなったものは**削除**できます。チャットに忘れるよう頼むこともできます（「引っ越したことを忘れて」など）。明らかに一致する事実が1つの場合は削除され、**設定**の**アクティビティ**と**変更内容**から**元に戻す**ことができます。一致する事実が複数ある場合は、チャットでどれかを確認されます。メモから事実やルールを学習すると、ToDoのチャットに**学習した内容に保存しました**と表示され、**編集**と**元に戻す**ができます。
- 事実には**一時的**、**約束**、**設定**の種類があり、いつまで有効かを**まで**で指定できます。一時的な事実は数週間で、設定や約束は数か月で薄れていきます。その他の事実は1年で薄れていきます。期限を過ぎたときや、新しいメッセージから事実が当てはまらなくなったとわかったときは、**終了済み**に移動します。**再表示**を押すと元に戻せます。
- **事実**には、全般的な事実、自分についての事実、仕事の進め方が表示されます。人物、組織、プロジェクトについての事実は、Graph内のそれぞれのページにある**把握している情報**に保存され、そこで編集できます。フルネームが含まれる事実は保存時に該当するページへ移動し、ToDoのチャットには「**追加先**：名前、**Graph**」と表示されます。**事実**の下には、Graphのページに保存されている事実の件数が控えめに表示されます。開くと各ページを確認できます。自分のメッセージから得た事実には、元になった言葉が引用符付きで表示されます。
- 人物の電話番号やメールアドレスを入力すると、事実ではなくGraph内のその人物のページに追加されます。すでに1つのレコードに電話番号があり、同じ名前の別のレコードが1つある場合は、2つのレコードが統合されます。ToDoのチャットには**追加先**と名前が表示され、**元に戻す**ことができます。誰の情報か明確でない場合は、事実として残ります。
- 使われていないことを理由に削除されるものはありません。各ToDoには関連性の高い事実が使われ、新しい事実ほど重視されます。そのため、あまり必要とされない事実も、ほかの情報の邪魔をせずに残ります。終了した事実も、ToDoやチャットで関連する話題が出たときは履歴として役立ちます。ただし、現在の状況として扱われることはありません。
- すでに学習した内容を別の言葉で説明するメモは、その内容に置き換わるため、同じ情報が二重に表示されることはありません。**マージを元に戻す**と、以前の表現が戻ります。自分で編集した内容が置き換えられることはありません。
- **これらを取り込む**：OpenClawを使っていた場合、残しておく価値のあるメモ（`MEMORY.md`、`USER.md`）が、元のファイル名とともに上部に表示されます。残す項目にチェックを入れて**チェックを入れたままにする**を押すと、ほかの情報と同じように事実やルールとして追加されます。Graph内の人物についての事実はその人物のページに移動します（誕生日は「誕生日」ルーティンにも追加されます）。自分についての事実は「事実」に残ります。**残りを却下**すると、却下した項目は再表示されません。ファイルが変更されることはありません。残す価値のある内容がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが知っている自分についての情報を取り込めます。アシスタントを選び、**プロンプトをコピー**して、そのアシスタントに送信し、回答を貼り付けます。**確認**では、各行を残すか、編集するか、チェックを外すか選べます。すでに伝えてある行はスキップされます。事実と食い違う行はその事実の横に表示されるので、どちらを残すか選べます。パスワード、コード、キー、カード番号、アカウント番号は表示前に除外されます。権限を与えようとする行も除外されます。インポートした事実は参考情報であり、権限を与えるものではありません。それぞれに情報元と日付が表示され、**編集するまでは参考情報のみです**という状態が維持されます。初期設定のToDoにも表示され、最初の確認中にも表示されます。
- **変更内容**：編集、却下、チャットから学習した内容が表示され、それぞれ**元に戻す**ことができます。[文章](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに対する選択の履歴を確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、投票がある場合は未回答の投票が表示されます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **利用状況**：過去30日間の4つの数値を確認できます。数値が高いほど良い状態です。ToDoを3件以上決定する（実行するか却下する）と表示が始まります。それまでは、決定した件数が表示されます。
  - **効果**：決定したToDoのうち、却下せずに**実行**した、送信した、または完了したものの割合です。
  - **一度で成功**：**実行**を始めたToDoのうち、あとから修正せずに済んだものの割合です。
  - **完了**：**実行**を始めたToDoのうち、続行や再試行を頼まずに完了したものの割合です。
  - **そのまま送信**：送信した下書きのうち、編集や**修正を依頼**をせずに送信したものの割合です。
  - 各数値は、その前の30日間と比較されます。グラフには、最初の2週間は日ごとの棒が表示され、その後は週ごとに最大8週間分が表示されます。
  - **ソース別の効果**：**メール**、**追加しました**（**新しいToDo**から追加）、**Androidの通知**、**The Machine自身**（エラーなどの問題）といったソースごとに、実行した件数を確認できます。
  - **見逃したToDo**：週に1回、ToDoにならなかったメッセージの一部をThe Machineが確認し、ToDoが必要だった可能性のある件数を推定します。見つかったメッセージが一覧に表示されます。**開く**、または行そのものを押すとメッセージを確認できます。**実際の見落とし**または**見落としではありません**を選んで、判定が正しいかを知らせます。**実際の見落とし**を選ぶとToDoも追加され、**元に戻す**ことができます（**ToDoを開く**を押すと追加したToDoが開きます）。The Machineは回答から学習し、次から同様のメッセージを見つけられるようになります。回答はすぐに件数へ反映され、Machineに保存されます。残りがわずかになると、パーセントではなく**少数**と表示されます。最初の週次確認後に表示されます。
