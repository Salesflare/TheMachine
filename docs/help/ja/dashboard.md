## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今週の予定、期限があるToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **Graph**：メッセージに登場する人、組織、プロジェクトを確認できます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkにチーム、家族、友人がいる場合、そのメンバーを確認できます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの状況と、学習した内容を確認できます。
- **接続**：接続しているソースと、その状況を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の**検索**では、ToDo、人、メッセージなどを検索できます。**ブラウザー**、**ヘルプ**、**設定**は下部にあります。スマートフォンでは、上部のメニューボタンからサイドバーを開けます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も**おすすめ**に表示されるため、件数は上部の表示と一致します。タップすると開きます。

ToDoのメニューを開くには、ToDoにカーソルを合わせて**⋯**をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選択して`Shift F10`を押します。メニューには**名前を変更**と**開く**のほか、ToDoごとの**完了にする**、**スヌーズ**、**不要**があり、それぞれに**元に戻す**があります。

**ブラウザー**には、The MachineがLinkedInなどのサイトで使う専用ブラウザーが表示されます。パソコンではサイドバーの横に開きます。ToDoの**ブラウザーで表示**や、サイトへのサインインが必要なときの**ブラウザを開く**も同様です。スマートフォンのブラウザーでは新しいタブに開きます。スマートフォンのアプリ、またはホーム画面に追加したダッシュボードでは画面全体に表示され、Xを押すと戻ります。

**原寸大**を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと元に戻ります。

ToDoがブラウザーを使っている間は、上部に**停止**が表示されます。1回押すと、その実行がすぐに終了します。それ以上クリック、入力、送信は行われず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

実行中の処理が複数ある場合は、手前に表示されている処理が停止します。続けるには、ToDoのチャットに入力するか、**再試行**を押します。

ToDoが多くて表示しきれない場合、サイドバー全体が1列でスクロールします。

スマートフォンでは、**このメールを送信しますか？**のようなダイアログが画面全体に表示されます。入力中もボタンが常に押せる位置にあります。

## さらに活用する

ToDoの上部にある小さなToDoには、The Machineをさらに便利にする方法が表示されます。スマートフォンアプリ、通知、WhatsApp、このパソコン用アプリ、別のアカウント、接続の追加などが対象です。各項目には、その手順に進むボタンが1つあります。完了した項目は一覧から消えるため、残っている項目だけが表示されます。一覧には最大5項目が表示され、未完了の手順が先に表示されます。そのため、メールで勧められたGitHubなどのツールも、先に必要な手順を終えると項目に表示されます。

項目は、利用できる場面でのみ表示されます。項目の横にある×を押すと、すべてのデバイスでその項目が閉じます。上部の×を押すと、ToDo全体が閉じます。

最初の日が過ぎると、**おすすめ**の上に「残り2件 · 続ける」のような控えめな1行に折りたたまれます。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

**元に戻す**または**非表示の項目を1件表示**を押すと、項目を再表示できます。ToDo全体を再表示するには、**設定**の**一般**から**初期設定のToDo**を選びます。**設定**の**一般**にある**このデバイス**にも同じ設定があり、**設定**の**アプリ**には常にスマートフォンアプリが表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンが、使用中に再読み込みされることはありません。アプリを開いたとき、またはウィンドウが数分間バックグラウンドにあるか、操作されていないときに読み込まれます。未保存のテキストや開いているダイアログの操作が中断されることはありません。上部に表示される**更新の準備完了**を押すと、すぐに読み込まれます。

大きな機能や改善がリリースされると、小さな**新機能**のお知らせが表示されます。表示は1日に1回までです。**戻る**と**次へ**で読み進めるか、スワイプしてください。お知らせ内のボタンを押すと、その機能が開きます。**完了**または**×**を押すと閉じます。操作中に表示されることはなく、閉じるとすべてのデバイスで表示されなくなります。使い始めた後にリリースされた内容だけが表示されます。

## メッセージ

Macでは`⌘K`、WindowsとLinuxでは`Ctrl K`を押すと検索が開きます。スマートフォンでは検索アイコンを押します。2文字以上入力すると、**メッセージ**に、The Machineが読んだすべての内容から、意味または単語が最もよく一致する結果が表示されます。古い[履歴](history.md)は単語で一致するものが表示されます。

検索画面では質問することもできます。空の検索欄に表示される質問例のように入力すると、自分のメッセージから短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を見る**を押すと、すべてのアカウント、または選択したアカウントの結果一覧が開きます。各結果を開くと、元の場所へのリンクが付いたリーダーで表示されます。検索欄が空の場合は、最新のメッセージが表示されます。

検索結果には最も一致するものが最初に表示されます。スマートフォンで、全文があるメッセージのプレビューが表示される場合、そのメッセージは1件の結果として表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、その回答の元になったメッセージが表示されます。メッセージに答えが書かれていない場合、回答は表示されません。

## 学び

学びでは、The Machineが学習した内容と、ToDoがどれだけ役立っているかを確認できます。内容のないタブは非表示になります。

- **学習した内容**：メモから学習した、文章の書き方、事実、好みの進め方を確認できます。内容は自分の言葉で**編集**でき、事実ではなくなったものは**削除**できます。チャットで何かを忘れるよう頼むこともできます（「引っ越したことを忘れて」）。事実が1つだけ明確に一致する場合は、その事実が削除され、設定の**アクティビティ**と**変更内容**に**元に戻す**が表示されます。一致するものが複数ある場合は、チャットでどれを削除するか確認されます。メモから事実やルールを学習すると、ToDoのチャットに**学習した内容に保存しました**と表示され、**編集**と**元に戻す**が選べます。
- 事実には、**一時的**なもの、**約束**、**設定**があります。適用期間を**まで**で指定できます。一時的な事実は数週間で、設定と約束は数か月で、それ以外の事実は1年で表示されなくなります。指定した日付を過ぎた場合や、新しいメッセージで内容が変わったとわかった場合、事実は**終了済み**に移動します。**再表示**を押すと元に戻ります。
- **事実**には、本人や仕事の進め方に関する一般的な事実が保存されます。人、組織、プロジェクトに関する事実は、Graphの各ページにある**把握していること**に保存され、そこで編集できます。フルネームが記載された事実は、保存時にその人、組織、プロジェクトのページに移動します。ToDoのチャットには、その名前とともに**Graphに追加しました**と表示されます。**事実**の下には、Graphのページに保存されている事実の数が控えめに表示されます。開くと、それぞれのページに移動できます。
- 人の電話番号やメールアドレスを入力すると、事実ではなくGraphのその人のページに保存されます。すでに1件の記録にその番号があり、別の記録にも同じ名前がある場合は、2件が統合されます。ToDoのチャットには、相手の名前と**追加先**、**元に戻す**が表示されます。誰の情報かわからない場合は、事実として保存されます。
- 一覧に保存件数の上限はありません。長くなると、3週間使われていない事実やルールは**保留**に移動し、**再表示**で元に戻せます。編集したものや再表示したものは、そのまま残ります。保留中の事実も、関連するToDoやチャットでは役立ちます。終了した事実は過去の情報としてのみ使われ、現在の情報として使われることはありません。
- すでに学習した内容を別の言葉で書いたメモは、既存の内容に置き換わり、同じ内容が重複して表示されることはありません。**マージを元に戻す**と以前の表現に戻せます。自分で編集した内容が置き換わることはありません。
- **これらを取り込む**：以前OpenClawを使っていましたか？OpenClawのメモ（`MEMORY.md`、`USER.md`）から保存する価値のある行が、元のファイル名とともに上部に表示されます。残すものにチェックを入れてから**チェックを入れたままにする**を押すと、ほかの内容と同じように事実やルールとして保存されます。Graphにいる人についての事実は、その人のページに移動します（誕生日は誕生日のルーティンにも登録されます）。本人についての事実は**事実**に残ります。**残りを却下**すると、却下した内容が再び表示されることはありません。ファイルが変更されることはなく、保存する価値のある内容がない場合は何も表示されません。
- **変更内容**：編集、却下、チャットから学習した内容を確認できます。それぞれに**元に戻す**があります。[文章の書き方](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに関する選択を時系列で確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、投票がある場合は未回答の投票を確認できます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **状況**：過去30日間の数値を4つ確認できます。数値は高いほど良好です。決定したToDo（実行または却下）が3件に達すると表示されます。それまでは、これまでに決定した件数が表示されます。
  - **効果**：決定したToDoのうち、却下せずに実行したもの（**実行**、送信、または完了）の割合です。
  - **一度で成功**：**実行**を選んだToDoのうち、その後修正が必要なかったものの割合です。
  - **完了**：**実行**を選んだToDoのうち、続行や再試行を依頼せずに完了したものの割合です。
  - **そのまま送信**：送信した下書きのうち、編集や**修正を依頼**をせずに送信したものの割合です。
  - 各数値は、その前の30日間と比較されます。グラフは最初の2週間は1日ごと、その後は1週間ごとの棒グラフで、最大8週間分が表示されます。
  - **ソース別の効果**：ソースごとに実行したToDoの数を確認できます。**メール**、**追加しました**（**新しいToDo**から追加）、**電話への通知**、**The Machine自身**（エラーなどの問題）が対象です。
  - **見逃したToDo**：The Machineは週に1回、ToDoが作成されなかったメッセージの一部を確認し、ToDoが必要だった可能性のある件数を推定します。見つかったメッセージが一覧に表示されます。**開く**またはメッセージの行を押すと内容を確認でき、**本当の見落とし**または**見落としではありません**を選んで判定を伝えられます。**本当の見落とし**を選ぶとToDoも追加され、**元に戻す**を選べます（**ToDoを開く**を押すとそのToDoが開きます）。The Machineはその結果から学習し、以後は同じようなメッセージを見つけられるようになります。回答によって数値の精度が上がり、回答はThe Machineに保存されます。最初の週次チェック後に表示されます。
