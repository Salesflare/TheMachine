## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今週の予定、期限があるToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜日のまとめのように、Machineが定期的に行う作業を確認できます。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人、組織、プロジェクトを確認できます。それぞれのページはサイドバーに表示されます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkにチーム、家族、友人がいる場合に確認できます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの進み具合と、学習した内容を確認できます。
- **接続**：接続元とその状態を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の **検索または質問** では、ToDo、人、メッセージなどを検索できます。そのすぐ下には **新しいToDo** があります。下部には **ブラウザー**、**ヘルプ**、**設定** があります。スマートフォンでは、上部のメニューボタンをタップするとサイドバーが開きます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も **確認待ち** に表示され、件数は上部の件数と一致します。タップすると開きます。

ToDoのメニューを開くには、カーソルを合わせて **⋯** をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選択して `Shift F10` を押します。メニューには **名前を変更** と **開く** のほか、ToDoごとの **完了にする**、**スヌーズ**、**不要** があり、それぞれ **元に戻す** こともできます。

**ブラウザー** では、Machine専用のブラウザーを表示します。LinkedInなどのサイトで使うブラウザーです。パソコンではサイドバーの横に開きます。ToDoの **ブラウザーで表示** や、サイトへのサインインが必要なときの **ブラウザを開く** も同じ場所に開きます。スマートフォンのブラウザーでは新しいタブに開きます。スマートフォンアプリや、ホーム画面に追加したダッシュボードでは画面全体に表示されます。×をタップすると戻ります。

**原寸大** を選ぶと、ブラウザーがウィンドウ全体に表示されます。もう一度選ぶと元に戻ります。

ToDoがブラウザーを使っている間は、上部に **停止** が表示されます。押すと、その実行をすぐに終了します。それ以上クリック、入力、送信は行われず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

実行中の処理が複数ある場合は、手前に表示されている処理が停止します。続けるには、ToDoのチャットに入力するか、**再試行** を押します。

ToDoが多くて画面に収まらない場合は、サイドバー全体が1つの列としてスクロールします。

スマートフォンでは、**このメールを送信しますか？** のようなダイアログが画面全体に表示されます。入力中も、ボタンは常に押せる位置にあります。

## さらに便利に使う

ToDoの上部には小さなToDoがあり、Machineをもっと便利に使うための項目が並びます。スマートフォンアプリ、通知、WhatsApp、このパソコンのアプリ、別のアカウント、接続の追加などです。各行には、その手順に進むボタンが1つあります。完了すると行が一覧から消えるため、残っている項目だけを確認できます。表示される行は最大5つで、未完了の項目が先に並びます。そのため、メールで提案されたGitHubのようなツールは、先に必要な手順を終えると行に表示されます。

行は、該当する場合にのみ表示されます。行の **×** を押すと、すべてのデバイスでその行が閉じます。上部の **×** を押すと、ToDo全体が閉じます。

初日が過ぎると、**確認待ち** の上に「残り2ステップ・続ける」のような控えめな1行で表示されます。タップするとToDoが開き、矢印をタップすると折りたたまれます。

**元に戻す** または **非表示を1件表示** を選ぶと、行が再表示されます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo** の順に開きます。**設定** の **一般** にある **このデバイス** にも同じ操作項目があります。また、**設定** の **アプリ** には、いつでもスマートフォンアプリが表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンが公開されても、使用中に再読み込みされることはありません。アプリを開いたとき、またはウィンドウが数分間バックグラウンドにあるか、操作されていないときに読み込まれます。未保存のテキストや開いているダイアログの操作を妨げることはありません。上部の **更新の準備完了** を押すと、すぐに読み込めます。

大きな新機能や改善が公開されると、**新機能** の短い案内が表示されます。表示は1日に最大1回です。**戻る** と **次へ** で読み進めるか、スワイプしてください。案内にあるボタンを押すと、その機能が開きます。**完了** または **×** で閉じます。操作中の画面に重ねて表示されることはなく、閉じるとすべてのデバイスで表示されなくなります。使い始めた後に公開された内容だけが表示されます。

## メッセージ

Macでは `⌘K`、WindowsとLinuxでは `Ctrl K` を押すと検索が開きます。スマートフォンでは検索アイコンをタップしてください。2文字以上入力すると、Machineが読んだすべての内容から、意味やキーワードが一致する結果が **メッセージ** に表示されます。以前の[履歴](history.md)はキーワードで検索できます。

ここで質問することもできます。検索欄が空のときに表示される質問例のように入力すると、自分のメッセージから短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示** を選ぶと、全アカウントまたは1つのアカウントの結果一覧が開きます。結果を選ぶと閲覧画面が開き、元の場所へのリンクが表示されます。検索欄が空の場合は、最新のメッセージが表示されます。

検索結果は最も一致するものが先に表示されます。スマートフォンでメッセージのプレビューが全文表示される場合、そのメッセージは1件の結果として表示されます。全アカウントを対象に質問すると、上部に短い回答が表示され、その下に回答の元になったメッセージが表示されます。メッセージに答えが含まれていない場合は、回答が表示されません。

## 学び

「学び」では、Machineが学習した内容と、ToDoがどれくらいうまく機能しているかを確認できます。内容がないタブは非表示になります。

- **学んだこと**：メモから学習した、文章の書き方、事実、好みの進め方を確認できます。内容を自分の言葉で **編集** したり、事実ではなくなった内容を **削除** したりできます。チャットで「引っ越したことを忘れて」のように頼んで、内容を忘れさせることもできます。該当する事実が1つだけの場合は削除され、設定の **アクティビティ** と **変更内容** に **元に戻す** が表示されます。該当する事実が複数ある場合は、チャットでどれを削除するか確認されます。メモから事実やルールを学習すると、ToDoのチャットに **学習した内容に保存しました** と表示され、**編集** と **元に戻す** を選べます。
- 事実には **一時的**、**約束**、**設定** の種類があり、いつまで有効かを **まで** で指定できます。一時的な事実は数週間、好みや約束は数か月、その他の事実は1年で薄れていきます。有効期限を過ぎたときや、新しいメッセージによって無効になったと分かったときは、事実が **終了済み** に移動します。**再表示** を選ぶと元に戻せます。
- **事実** には、本人や仕事の進め方に関する全般的な事実が保存されます。人、組織、プロジェクトに関する事実はGraph内の各ページにある **把握していること** に保存され、そこで編集できます。名前がフルネームで書かれた事実は、保存時に該当するページへ移動し、ToDoのチャットには「**追加先**：Graphの［名前］」と表示されます。Graphのページに保存されている事実の数は、**事実** の下に控えめな1行で表示されます。開くと、それぞれのページに移動できます。自分のメッセージから得た事実には、元になった言葉が引用符付きで表示されます。
- 人の電話番号やメールアドレスを入力すると、事実ではなくGraph内のその人のページに保存されます。番号がすでに1つのレコードに登録されていて、同じ名前の別のレコードがある場合は、2つのレコードがマージされます。ToDoのチャットには「**追加先**：［名前］」と **元に戻す** が表示されます。誰の情報か判断できない場合は、事実として保存されます。
- 使われていないという理由で削除されることはありません。各ToDoには関連性の高い事実が優先して使われ、新しい事実ほど重視されます。そのため、あまり必要にならない事実が残っていても、ほかの内容を圧迫しません。終了した事実も、関連するToDoやチャットでは過去の情報として参照されます。現在の状況として扱われることはありません。
- メモに、すでに学習した内容が別の言葉で書かれている場合は、既存の内容が置き換わるため、同じ内容が重複して表示されません。**マージを元に戻す** と以前の表現に戻ります。自分で編集した内容が置き換わることはありません。
- **これらを取り込む**：以前OpenClawを使っていましたか？残しておく価値のあるメモ（`MEMORY.md`、`USER.md`）の行が、元のファイル名とともに上部に表示されます。残す項目にチェックを入れて **チェックを入れたままにする** を選ぶと、ほかの内容と同じように事実やルールとして保存されます。Graph内の人に関する事実はその人のページに移動します（誕生日は「誕生日」ルーティンにも反映されます）。自分に関する事実は「事実」に残ります。**残りを却下** すると、再び表示されることはありません。ファイルが変更されることはなく、残す価値のある情報がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが知っている自分の情報を取り込めます。アシスタントを選び、**プロンプトをコピー** してそのアシスタントに送信し、回答をここに貼り付けます。**確認** では、残す、編集する、チェックを外す項目を1行ずつ確認できます。すでに伝えてある内容は省かれます。事実と食い違う内容は、どちらを残すか選べるように並べて表示されます。パスワード、コード、キー、カード番号、アカウント番号は表示前に除外され、権限を与えようとする行も除外されます。インポートした事実は参考情報であり、権限にはなりません。それぞれに情報元と日付が表示され、**編集するまでは参考情報のみです** と示されます。初期設定のToDoや、初回確認中にも利用できます。
- **変更内容**：編集、却下、チャットを通じて学習した内容を確認できます。それぞれ **元に戻す** を選べます。[文章の書き方](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに対して行った選択を時系列で確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、投票できる項目があれば表示されます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **利用状況**：過去30日間の4つの数値を確認できます。数値は高いほど良好です。判断済みのToDoが3件（実行または却下）に達すると表示されます。それまでは、これまでに判断した件数が表示されます。
  - **効果**：判断したToDoのうち、却下ではなく、実行した（**実行**、送信、または完了した）割合です。
  - **一度で成功**：**実行** したToDoのうち、その後修正が不要だった割合です。
  - **完了**：**実行** したToDoのうち、続行や再試行を依頼せずに完了した割合です。
  - **そのまま送信**：送信した下書きのうち、編集や **修正を依頼** をせずに送信した割合です。
  - 各数値は、その前の30日間と比較されます。グラフは最初の2週間は日ごとに、その後は週ごとに、最大8週間分の棒で表示されます。
  - **ソース別の効果**：ソースごとに実行した件数を確認できます。ソースには **メール**、**追加しました**（**新しいToDo** から追加）、**電話への通知**、**The Machine自身**（エラーなどの問題）があります。
  - **見逃したToDo**：週に1回、ToDoが作成されなかったメッセージの一部をThe Machineが確認し、ToDoが必要だった可能性のある件数を推定します。見つかったメッセージが一覧に表示されます。**開く**、またはメッセージの行自体を選ぶとメッセージが表示されます。**本当の見落とし** または **見落としではありません** を選ぶと、判定が正しかったかを伝えられます。**本当の見落とし** を選ぶとToDoも追加され、**元に戻す** を選べます（**ToDoを開く** でそのToDoに移動します）。この結果からThe Machineが学習し、以降は似たメッセージを見つけられるようになります。回答はすぐに数値へ反映され、Machineに保存されます。残りが数件だけになると、割合ではなく **少数** と表示されます。最初の週次確認が終わると表示されます。
