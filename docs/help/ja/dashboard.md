## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今後1週間の予定、期限が来るToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜日のサマリーなど、決まったタイミングでMachineが行う作業です。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人、組織、プロジェクトを確認できます。それぞれのページはサイドバーに表示されます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkに参加しているチーム、家族、友達を確認できます。参加後に表示されます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの状況と、Machineが学んだ内容を確認できます。
- **接続**：接続元とその状況を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の **検索または質問** では、ToDo、人、メッセージなどを検索できます。そのすぐ下に **新しいToDo** があります。下部には **ブラウザー**、**ヘルプ**、**設定** があります。スマートフォンでは、上部バーのメニューボタンからサイドバーを開けます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからの依頼も **確認待ち** に表示されるため、件数は上部の表示と一致します。タップすると開きます。

ToDoのメニューを開くには、カーソルを合わせて **⋯** をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選んで `Shift F10` を押します。メニューには **名前を変更** と **開く** のほか、ToDoごとの **完了にする**、**スヌーズ**、**不要** があり、それぞれ **元に戻す** こともできます。

**ブラウザー** では、Machineがサイトの閲覧に使うブラウザーを確認できます。たとえばLinkedInの閲覧に使います。パソコンではサイドバーの横に開きます。ToDoの **ブラウザーで表示** や、サイトへのログインが必要なときの **ブラウザーを開く** も同様です。スマートフォンのブラウザーでは新しいタブに開きます。スマートフォンアプリ、またはホーム画面に追加したダッシュボードでは画面全体に表示され、Xを押すと戻ります。

**原寸大** を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと元に戻ります。

ToDoがブラウザーを使っている間は、上部に **停止** が表示されます。1回押すと、その実行はすぐに終了します。それ以上クリック、入力、送信は行われず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

複数の実行がある場合、停止するのは現在表示中の実行です。続けるには、ToDoのチャットに入力するか、**再試行** を押します。

ToDoが多くて収まらない場合は、サイドバー全体が1列でスクロールします。

スマートフォンでは、**このメールを送信しますか？** のようなダイアログが画面全体に表示されます。入力中も、ボタンはいつでも押せる位置にあります。

## もっと活用する

「ToDo」の上部に表示される小さなToDoには、Machineをもっと便利にする方法が表示されます。スマートフォンアプリ、通知、WhatsApp、このコンピューターのアプリ、別のアカウント、接続の追加などです。各項目には、その手順に進むボタンが1つあります。完了すると一覧から消えるため、残っている項目だけが表示されます。一覧には最大5項目が表示され、未完了の手順が先に並びます。そのため、メールで使うことを提案されたGitHubなどのツールは、前の手順が終わると表示されます。

項目は、表示する意味がある場合にだけ表示されます。項目の横にある×を押すと、すべてのデバイスでその項目が閉じます。上部の×を押すと、ToDo全体が閉じます。

初日を過ぎると、**確認待ち** の上に「残り2ステップ・続ける」のような控えめな1行で表示されます。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

最初の2週間は、新しいToDoが1件以下の日に、理由付きの提案が1つ、ToDoの先頭に表示されることがあります。たとえば「WhatsAppを接続しますか？メール5件で言及されています。」や「もう一度WhatsAppを試しますか？コードの期限が切れました。」のように表示されます。折りたたむと、提案とそのボタン、×だけが表示されます。その手順の通常の項目に代わって表示されます。最初の確認を終えたときに次の手順が表示される場合は、提案はその間待機します。

提案は、Machineがすでに持っている情報だけをもとに表示されます。WhatsAppへのリンクや、知人からのメールでの言及、自分のアドレスが記載されているものの接続済みのメールボックスに含まれていない情報、SlackやTeamsの会議からのメール、完了しなかった接続などです。表示するのは最大でも件数だけで、メッセージの内容や送信者は表示しません。一度に表示される提案は1つまでで、新しい提案は1日に最大1つです。メールや通知で届くことはありません。×を押すと完全に閉じます。

**元に戻す** または **非表示の項目を1件表示** を押すと、項目が再表示されます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo** の順に開きます。**設定** の **一般** にある **このデバイス** にも同じ操作があります。スマートフォンアプリは、いつでも **設定** の **アプリ** から確認できます。

## 新しいバージョン

ダッシュボードを使用中に、新しいバージョンが勝手に再読み込みされることはありません。アプリを開いたとき、またはウィンドウを数分間バックグラウンドにしたり、操作せずにいたりすると読み込まれます。未保存のテキストや開いているダイアログの操作を中断することはありません。上部の **更新の準備完了** を押すと、すぐに読み込まれます。

大きな機能や改善がリリースされると、**新機能** の小さな案内が表示されます。表示は1日最大1回です。**戻る** と **次へ** で進むか、スワイプしてください。案内のボタンを押すと、その機能が開きます。**完了** または **×** を押すと閉じます。操作中に表示されることはなく、閉じるとすべてのデバイスで表示されなくなります。利用を始めてからリリースされた内容だけが表示されます。

## メッセージ

Macでは `⌘K`、WindowsとLinuxでは `Ctrl K` を押すか、スマートフォンで検索アイコンを押すと検索が開きます。2文字以上入力すると、Machineが読んだすべての内容から、意味や単語が最もよく一致するものが **メッセージ** に表示されます。以前の[履歴](history.md)は単語で検索できます。

検索欄では質問もできます。検索欄が空のときに表示される質問例のように入力すると、自分のメッセージをもとに短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示** を押すと、すべてのアカウントまたは1つのアカウントの結果を一覧で開きます。各結果は、元の場所へのリンクが付いたリーダーで開きます。検索欄が空の場合は、最新のメッセージが表示されます。

検索結果は最もよく一致するものが先に表示されます。メッセージの全文がある場合、スマートフォンのプレビューはそのメッセージとして1回だけ表示されます。すべてのアカウントを対象に質問すると、回答が上部に短く表示され、その下に回答の元になったメッセージが表示されます。メッセージに答えが書かれていない場合、回答は表示されません。

## 学び

「学び」には、Machineが学んだ内容と、ToDoがどの程度役に立っているかが表示されます。中身のないタブは非表示になります。

- **学んだ内容**：メモから学んだ、文章の書き方、事実、好みの進め方です。内容は自分の言葉で **編集** したり、事実でなくなったものを **削除** したりできます。チャットで何かを忘れるように頼むこともできます（「引っ越したことを忘れて」）。一致する事実が1つだけの場合は削除され、**設定** の **アクティビティ** と **変更内容** から **元に戻す** ことができます。一致する事実が複数ある場合は、チャットでどれを削除するか確認します。メモから事実やルールを学んだときは、ToDoのチャットに **学習した内容に保存しました** と表示され、**編集** と **元に戻す** ができます。
- 事実には **一時的**、**約束**、**設定** の種類があり、有効な期間を **まで** で指定できます。一時的な事実は数週間で、設定と約束は数か月で、その他の事実は1年で古くなります。期限を過ぎた事実や、新しいメッセージで無効になったことがわかった事実は **終了済み** に移動します。**再表示** を押すと元に戻せます。
- **事実** には、自分自身や仕事の進め方についての一般的な情報が保存されます。人、組織、プロジェクトに関する事実は、Graph内の各ページにある **既知の情報** に保存され、そこで編集できます。人物のフルネームが記載された事実は、保存時にその人のページに移動します。ToDoのチャットには、その人の名前とともに **追加先** と **Graph** 内が表示されます。**事実** の下に、Graphのページに保存された事実の数が控えめに表示されます。開くと各ページに移動できます。自分のメッセージから得た事実には、引用符付きで元になった言葉が表示されます。
- 誰かの電話番号やメールアドレスを伝えると、事実ではなくGraphのその人のページに追加されます。番号がすでに1つのレコードに登録されていて、同じ名前の別のレコードがある場合は、2つのレコードが統合されます。ToDoのチャットには、相手の名前と **追加先** が表示され、**元に戻す** ことができます。誰の情報か判断できない場合は、事実として保存されます。
- 使わないからといって情報が削除されることはありません。各ToDoには関連性の高い事実が表示され、新しい事実ほど重視されます。そのため、あまり必要にならない事実が、ほかの情報を圧迫せずに残ります。終了した事実も、関連するToDoやチャットでは履歴として役立ちますが、現在の情報として扱われることはありません。
- メモに、すでに学んだ内容が別の言葉で書かれている場合は、古い内容を置き換えます。同じ内容が重複して表示されることはありません。**マージを元に戻す** と、以前の表現に戻せます。自分で編集した内容が置き換えられることはありません。
- **これらを取り込む**：OpenClawを使っていたことがありますか？残しておく価値のあるメモの行（`MEMORY.md`、`USER.md`）が、元のファイル名とともに上部に表示されます。残す項目にチェックを入れてから **チェックを入れたままにする** を押すと、ほかの情報と同じように事実やルールとして保存されます。Graphに登録済みの人に関する事実は、その人のページに移動します（誕生日は「誕生日」ルーティンにも追加されます）。自分に関する事実は「事実」に残ります。**残りを却下** すると、残りの項目は再表示されません。ファイルが変更されることはなく、残す価値のある情報がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが自分について知っている内容を取り込みます。アシスタントを選び、**プロンプトをコピー** して相手に送り、返答を貼り付けてください。**確認** では、残す行の編集やチェック解除ができます。すでに伝えた行はスキップされ、事実と異なる行はその事実の横に表示されるため、どちらを残すか選べます。パスワード、コード、キー、カード番号、口座番号は表示前に除外され、権限を与えようとする行も除外されます。インポートした事実は参考情報であり、権限を与えるものではありません。それぞれに情報元と日時が表示され、編集するまでは **編集するまでは参考情報のみです** と表示されます。初期設定のToDoや、最初の確認中にも表示されます。
- **変更内容**：編集、却下、チャットから学んだ内容が表示され、それぞれ **元に戻す** ことができます。[文章](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoについて選んだ内容のタイムラインです。
- **共有済み**：Machineチームと共有する学習内容や、投票できる項目がある場合に表示されます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **状況**：過去30日間の4つの数値を確認できます。数値が高いほど良い状態です。決定したToDoが3件（実行または却下）に達すると表示されます。それまでは、これまでに決定したToDoの件数が表示されます。
  - **効果**：決定したToDoのうち、却下せずに実行したもの（**実行**、送信、完了）の割合です。
  - **一度で成功**：**実行** を選んだToDoのうち、後から修正せずに済んだものの割合です。
  - **完了**：**実行** を選んだToDoのうち、続行や再試行を頼まずに完了したものの割合です。
  - **そのまま送信**：送信した下書きのうち、編集や **修正を依頼** をせずに送ったものの割合です。
  - 各数値は、その前の30日間と比較されます。グラフは最初の2週間は日ごと、それ以降は週ごとに棒グラフで表示され、最大8週間分を確認できます。
  - **ソース別の効果**：ソースごとに、実行したToDoの数を確認できます。たとえば **メール**、**追加しました**（**新しいToDo** から）、**スマートフォンへの通知**、**The Machine自身**（エラーなどの問題）です。
  - **見逃したToDo**：Machineは週に1回、ToDoが作成されなかったメッセージの一部を確認し、ToDoが必要だった可能性のある件数を推定します。該当したメッセージが一覧に表示されます。**開く**、またはメッセージの行を押すと内容を確認できます。**実際の見落とし** または **見落としではありません** を選ぶと、判定が正しかったかをMachineに伝えられます。**実際の見落とし** を選ぶとToDoも追加され、**元に戻す** ことができます（**ToDoを開く** で追加したToDoに移動します）。Machineはその内容から学び、以降は同じようなメッセージを検出します。回答はすぐに数値に反映され、自分のMachineに保存されます。残りが少なくなると、割合の代わりに **少数** と表示されます。最初の週次確認後に表示されます。
