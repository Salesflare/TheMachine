## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今後1週間の予定、期限が来るToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：毎週月曜日のまとめなど、一定のペースでMachineが行う作業を確認できます。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人、組織、プロジェクトを確認できます。サイドバーから、それぞれのページを開けます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkにチーム、家族、友達がいる場合に表示されます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの状況や、Machineが学習した内容を確認できます。
- **接続**：接続元とその状況を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の**検索または質問**では、ToDo、人、メッセージなどを検索できます。そのすぐ下には**新しいToDo**があります。下部には**ブラウザー**、**ヘルプ**、**設定**があります。スマートフォンでは、上部バーのメニューボタンを押すとサイドバーが開きます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからのリクエストも**確認待ち**に表示されるため、件数は上部の数字と同じです。タップすると開きます。

ToDoのメニューを開くには、カーソルを合わせて**⋯**をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選択して`Shift F10`を押します。メニューには**名前を変更**と**開く**のほか、ToDoごとの**完了にする**、**スヌーズ**、**不要**があり、それぞれ**元に戻す**ことができます。

**ブラウザー**では、LinkedInなどのサイトでMachineが使うブラウザーを表示します。パソコンではサイドバーの横に開きます。ToDoの**ブラウザーで表示**や、サイトへのログインが必要なときの**ブラウザーを開く**も同様です。スマートフォンのブラウザーでは新しいタブで開きます。スマートフォンアプリ、またはホーム画面に追加したダッシュボードでは全画面で開きます。Xを押すと戻ります。

**原寸大**を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと元に戻ります。

ToDoでブラウザーを使っている間は、上部に**停止**が表示されます。押すと実行がすぐに終了し、それ以上クリック、入力、送信は行われません。ToDoのチャットには「ブラウザーから停止しました」と表示されます。

複数の実行がある場合は、前面に表示されているものが停止します。続けるには、ToDoのチャットに入力するか、**再試行**を押します。

ToDoが表示しきれない場合、サイドバー全体が1列のままスクロールします。

スマートフォンでは、**このメールを送信しますか？**のようなダイアログが全画面で表示されます。入力中もボタンがいつでも押せる位置にあります。

## もっと活用する

ToDoの上部には小さなToDoがあり、Machineをもっと便利にする項目が表示されます。スマートフォンアプリ、デスクトップアプリ、通知、WhatsApp、別のアカウント、接続の追加などです。各行には、その手順を進めるボタンが1つあります。完了すると一覧から消えるので、残っている項目だけが表示されます。表示されるのは最大5行で、未完了の項目が先に表示されます。そのため、メールで提案されたGitHubなどのツールは、前の手順が終わると行に表示されます。

各行は、表示に適した場合のみ表示されます。Chromebookのようにデスクトップアプリを使っていないパソコンでは、代わりにブラウザーからダッシュボードをインストールするよう案内されます。行の×を押すと、どのデバイスでもその行が閉じます。上部の×を押すと、ToDo全体が閉じます。

初日が過ぎると、**確認待ち**の上に「残り2ステップ・続ける」のような控えめな1行に折りたたまれます。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

最初の2週間は、その日に新しいToDoが1件以下の場合、理由付きの提案が1つ、ToDoの先頭に表示されることがあります。「WhatsAppに接続しますか？メール5件で言及されています。」や「WhatsAppをもう一度試しますか？コードの有効期限が切れました。」のような内容です。折りたたまれているときは、提案とボタン、×だけが表示されます。そのステップの通常の行に代わって表示されます。初回確認の最後に専用の次の手順が表示される場合は、そちらが終わるまで待ちます。

提案は、Machineがすでに持っている情報だけをもとに表示されます。WhatsAppへのリンクやメールでの言及、接続済みのメールボックスに取り込まれていない自分のアドレス、SlackやTeamsの会議からのメール、完了しなかった接続です。表示されるのは最大で件数のみで、メッセージの内容や送信者は表示されません。一度に表示される提案は1つまでで、新しい提案は1日に1つまでです。メールや通知で届くことはありません。×を押すと完全に閉じます。

**元に戻す**または**非表示を1件表示**を押すと、行が再表示されます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo**の順に開きます。**設定**の**一般**にある**このデバイス**にも同じ操作があります。**設定**の**アプリ**には、スマートフォンアプリが常に表示され、パソコンではデスクトップアプリも表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンが、使用中に再読み込みされることはありません。アプリを開いたとき、またはウィンドウが数分間バックグラウンドにあるか、操作されていないときに読み込まれます。未保存のテキストや開いているダイアログを中断することはありません。上部の**更新の準備完了**を押すと、すぐに読み込まれます。

大きな機能や改善が追加されると、1日に最大1回、小さな**新機能**のお知らせが表示されます。**戻る**と**次へ**で進むか、スワイプしてください。お知らせ内のボタンを押すと、その機能が開きます。**完了**または**×**を押すと閉じます。操作中に表示されることはなく、一度閉じるとどのデバイスでも再表示されません。利用を始めた後に公開された内容だけが表示されます。

## メッセージ

Macでは`⌘K`、WindowsとLinuxでは`Ctrl K`を押すと検索が開きます。スマートフォンでは検索アイコンを押します。2文字以上入力すると、Machineが読んだ内容から、意味または単語がよく一致するものが**メッセージ**に表示されます。以前の[履歴](history.md)は単語で検索できます。

そこから質問することもできます。検索欄が空のときに表示される質問の例などを入力すると、自分のメッセージから短い回答が得られます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示**を押すと、すべてのアカウント、または選択した1つのアカウントの結果が表示されます。各結果を開くと、閲覧画面と元の場所へのリンクが表示されます。検索欄が空の場合は、最新のメッセージが表示されます。

検索では、最も一致する結果が最初に表示されます。スマートフォンで、全文があるメッセージのプレビューを表示する場合、同じメッセージは一度だけ表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、その元になったメッセージが表示されます。メッセージに答えがない場合は、回答を表示しません。

## 学び

「学び」には、Machineが学習した内容と、ToDoがどれだけ役立っているかが表示されます。内容のないタブは非表示になります。

- **学習した内容**：メモから学んだ、文章の書き方、事実、好みの進め方を確認できます。自分の言葉で**編集**したり、もう正しくない内容を**削除**したりできます。チャットで何かを忘れるよう頼むこともできます（「引っ越したことを忘れて」）。該当する事実が1つに絞れる場合は削除され、**設定**の**アクティビティ**と**変更内容**から**元に戻す**ことができます。複数の事実が該当する場合は、チャットでどれを指すか確認されます。メモから事実やルールを学習すると、ToDoのチャットに**学習した内容に保存しました**と表示され、**編集**と**元に戻す**を選べます。
- 事実には**一時的**、**約束**、**設定**の種類があり、該当する期間を**まで**で指定できます。一時的な事実は数週間で、設定や約束は数か月で薄れていきます。それ以外の事実は1年で薄れていきます。設定した日を過ぎるか、新しいメッセージで事実が当てはまらなくなったとわかると、事実は**終了済み**に移動します。**再表示**を押すと元に戻ります。
- **事実**には、自分自身や仕事の進め方に関する一般的な事実が表示されます。人、組織、プロジェクトに関する事実はGraphの各ページの**把握していること**に保存され、そこで編集できます。氏名をフルネームで示した事実は、保存時に該当するページに移動し、ToDoのチャットには、その人の名前と**Graphに追加しました**が表示されます。Graphのページに保存されている事実の件数は、**事実**の下に控えめな1行で表示されます。そこを開くと各ページに移動できます。自分のメッセージから得た事実には、元になった言葉が引用符付きで表示されます。
- 誰かの電話番号やメールアドレスを入力すると、事実ではなくGraphのその人のページに保存されます。すでに1つのレコードに電話番号があり、別のレコードの名前が同じ場合は、2つのレコードが統合されます。ToDoのチャットには名前と**追加先**が表示され、**元に戻す**ことができます。誰の情報かはっきりしない場合は、事実として残ります。
- 使われていないという理由で削除されることはありません。各ToDoには、関連性の高い事実が表示され、新しい事実ほど重視されます。そのため、あまり必要としない事実も、ほかの情報を押しのけずに残ります。終了した事実も、ToDoやチャットで関連する話題が出たときに限り、過去の情報として役立ちます。現在の状態として扱われることはありません。
- すでに学習した内容を別の言い方で書いたメモは、既存の内容に置き換わるため、重複して表示されません。**マージを元に戻す**を押すと、以前の表現に戻ります。自分で編集した内容が置き換えられることはありません。
- **これらを取り込む**：OpenClawを使っていましたか？メモ（`MEMORY.md`、`USER.md`）から、残しておく価値のある行が元のファイル名とともに上部に表示されます。残す項目にチェックを入れてから**チェックを入れたままにする**を押すと、通常の事実やルールとして保存されます。Graphにいる人についての事実はその人のページに移動します（誕生日は「誕生日」ルーティンにも追加されます）。自分についての事実は「事実」に残ります。**残りを却下**すると、それらは再表示されません。ファイルが変更されることはなく、残す価値のある内容がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが知っている自分の情報を取り込みます。アシスタントを選び、**プロンプトをコピー**して送信し、回答を貼り付けてください。**確認**画面で、残す行を選んだり、編集したり、チェックを外したりできます。すでに伝えた行は除外されます。事実と食い違う行は並べて表示されるため、どちらを残すか選べます。パスワード、コード、キー、カード番号、口座番号は、表示前に除外されます。権限を与えようとする行も除外されます。インポートした事実は参考情報であり、権限を与えるものではありません。それぞれに情報元と日付が表示され、編集するまでは**編集するまでは参考情報のみです**と記されます。初期設定のToDoと、初回確認中にも表示されます。
- **変更内容**：編集、却下、チャットを通じて学習した内容が、**元に戻す**とともに表示されます。[文章](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoについての選択を時系列で確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、投票がある場合は投票が表示されます。[学習内容の共有](share-learnings.md)をご覧ください。
- **進捗**：過去30日間の4つの数値が表示されます。数値が高いほど良好です。判断したToDoが3件に達すると表示が始まります。それまでは、判断したToDoの件数が表示されます。
  - **効果**：判断したToDoのうち、却下するのではなく、実行した（**実行**、送信、または完了した）件数の割合です。
  - **完了**：**実行**を始めた後に終了したToDoのうち、完了になった件数の割合です。ステップが終わった、自分で完了にした、または自動的に完了した場合が該当します。却下または期限切れになったものは未完了として数えます。まだ開いているToDoはまだ集計されず、**まだ進行中**と表示されます。
  - **一度で成功**：完了したToDoのうち、**実行**の後に修正が必要なかった件数の割合です。
  - **完了**と**一度で成功**は、ToDoが3件に達すると数値が表示されます。
  - **そのまま送信**：送信した下書きのうち、編集も**修正を依頼**もせずに送信した件数の割合です。
  - 各数値は、その前の30日間と比較されます。グラフは最初の2週間は日ごとに、その後は週ごとに、最大8週間分の棒を表示します。
  - **ソース別の効果**：**メール**、**追加しました**（**新しいToDo**から）、**Androidの通知**、**The Machine自身**（エラーなどの問題）といったソースごとに、実行した件数を表示します。
  - **見逃したToDo**：週に1回、The MachineはToDoにならなかったメッセージの一部を確認し、ToDoが必要だった可能性のある件数を推定します。見つかったメッセージが一覧に表示されます。**開く**またはメッセージ自体を押すと内容を確認でき、**実際の見落とし**または**見落としではありません**を選ぶと、判定が正しかったかを伝えられます。**実際の見落とし**を選ぶとToDoも追加され、**元に戻す**ことができます（**ToDoを開く**を押すとそのToDoに移動します）。The Machineはこの内容から学習し、以降は同じようなメッセージを見つけやすくなります。回答はすぐに数値に反映され、Machineに保存されます。残りが数件になると、割合ではなく**少数**と表示されます。最初の週次チェックの後に表示されます。
