## タブ

- **ToDo**：ToDoと約束を確認できます。[ToDo](cards.md)をご覧ください。
- **カレンダー**：今週の予定、期限が来るToDo、約束を確認できます。[カレンダー](calendar.md)をご覧ください。
- **ルーティン**：月曜日のまとめなど、決まったタイミングでMachineが行う作業を確認できます。[ルーティン](routines.md)をご覧ください。
- **Graph**：メッセージに登場する人物、組織、プロジェクトを確認できます。それぞれのページはサイドバーに表示されます。[Graph](graph.md)をご覧ください。
- **Fleet**：The Machine Networkに参加すると、チーム、家族、友達を確認できます。[Fleet](fleet.md)をご覧ください。
- **学び**：ToDoの進み具合や、学習した内容を確認できます。
- **接続**：接続元とその状態を確認できます。[接続](connections.md)をご覧ください。

サイドバー上部の **検索または質問** では、ToDo、人物、メッセージなどを検索できます。そのすぐ下には **ToDoを新規作成** があります。サイドバー下部には **ブラウザー**、**ヘルプ**、**設定** があります。スマートフォンでは、上部バーのメニューボタンを押すとサイドバーが開きます。

サイドバーには、ページと同じようにToDoが表示されます。Fleetからのリクエストも **確認待ち** に表示されるため、件数は上部の件数と同じです。タップすると開きます。

ToDoのメニューを開くには、カーソルを合わせて **⋯** をクリックするか、右クリックします。スマートフォンでは長押しします。キーボードの場合は、ToDoを選択して `Shift F10` を押します。メニューには **名前を変更** と **開く** のほか、ToDo専用の **完了にする**、**スヌーズ**、**不要** があり、それぞれ **元に戻す** ことができます。

**ブラウザー** では、MachineがLinkedInなどのサイトで使うブラウザーを表示します。パソコンではサイドバーの横に開きます。ToDoの **ブラウザーで表示** や、サイトへのログインが必要なときの **ブラウザーを開く** も同じです。スマートフォンのブラウザーでは新しいタブで開きます。スマートフォンアプリや、ホーム画面に追加したダッシュボードでは画面全体に表示され、Xを押すと戻ります。

**原寸大** を押すと、ブラウザーがウィンドウ全体に表示されます。もう一度押すと戻ります。

ToDoがブラウザーを使用している間は、上部に **停止** が表示されます。押すと、その実行はすぐに終了します。それ以降はクリック、入力、送信を行わず、ToDoのチャットには「ブラウザーから停止しました」と表示されます。

複数の実行がある場合は、現在表示中の実行が停止します。続けるには、ToDoのチャットに入力するか、**再試行** を押します。

ToDoが表示しきれないときは、サイドバー全体が1列のままスクロールします。

スマートフォンでは、**このメールを送信しますか？** などのダイアログが画面全体に表示されます。入力中もボタンは常に押せる位置にあります。

## もっと活用する

ToDoの上部にある小さなToDoには、Machineをもっと便利にする項目が表示されます。スマートフォンアプリ、通知、WhatsApp、このコンピューターのアプリ、別のアカウント、その他の接続などです。各項目にはその設定用のボタンが1つあり、完了するとリストから消えるため、残っている項目だけが表示されます。表示されるのは最大5件で、未完了の項目が先です。そのため、メールでおすすめされたGitHubなどのツールは、先に必要な設定を済ませると表示されます。

項目は、利用できる場所にだけ表示されます。項目の横の×を押すと、すべてのデバイスでその項目が閉じます。上部の×を押すと、ToDo全体が閉じます。

初日を過ぎると、**確認待ち** の上に「残り2件・続ける」のような控えめな1行で表示されます。タップするとToDoが開き、矢印をタップすると再び折りたたまれます。

最初の2週間は、その日に新しいToDoが1件以下の場合、理由付きのおすすめがToDoの先頭に表示されることがあります。たとえば「WhatsAppに接続しますか？メール5件で言及されています。」や「WhatsAppをもう一度試しますか？コードの有効期限が切れました。」のような内容です。折りたたむと、おすすめとそのボタン、×だけが表示されます。通常その設定項目が表示される場所におすすめが入ります。最初の確認が終わるときに次のステップが表示される場合は、おすすめは表示されません。

おすすめは、Machineがすでに把握している情報だけをもとに表示されます。WhatsAppへのリンクや、誰かからのメールでの言及、接続済みのメールボックスに含まれていない自分のメールアドレス、SlackやTeamsの会議からのメール、接続が完了しなかった場合などです。表示されるのは多くても件数だけで、メッセージの内容や送信者は表示されません。一度に表示されるのは1件までで、新しいおすすめは1日に最大1件です。メールや通知では送られません。×を押すと、そのおすすめは完全に閉じます。

**元に戻す** または **非表示の項目を1件表示** を押すと、項目が再表示されます。ToDo全体を再表示するには、**設定**、**一般**、**初期設定のToDo** の順に開きます。**設定** の **一般** にある **このデバイス** にも同じ設定があります。また、**設定** の **アプリ** にはいつでもスマートフォンアプリが表示されます。

## 新しいバージョン

ダッシュボードの新しいバージョンは、使用中に再読み込みされません。アプリを開いたとき、またはウィンドウが数分間バックグラウンドにあるか、操作されていないときに読み込まれます。未保存のテキストがあるときや、ダイアログが開いているときに中断することはありません。上部の **更新の準備完了** を押すと、すぐに読み込まれます。

大きな機能や改善が公開されると、1日に最大1回、小さな **新機能** のお知らせが表示されます。**戻る** と **次へ** で進めるか、スワイプしてください。お知らせにボタンがある場合は、機能が開きます。**完了** または **×** で閉じます。作業中の画面には表示されず、一度閉じるとすべてのデバイスで表示されなくなります。使い始めてから公開された内容だけが表示されます。

## メッセージ

Macでは `⌘K`、WindowsとLinuxでは `Ctrl K`、スマートフォンでは検索アイコンを使って検索を開きます。2文字以上入力すると、**メッセージ** にMachineが読んだ内容から、意味や単語がよく一致するものが表示されます。古い[履歴](history.md)は単語で検索されます。

検索欄では質問もできます。空の検索欄に表示される質問例などを入力すると、自分のメッセージに基づいた短い回答が表示されます（[キーボードとコマンドパレット](keyboard.md)）。

**すべての結果を表示** を押すと、すべてのアカウントまたは選択したアカウントの結果が一覧で開きます。各結果を開くと閲覧画面が表示され、元の場所へのリンクも確認できます。検索欄が空の場合は、新しいメッセージが表示されます。

検索結果では、一致度の高いものが先に表示されます。スマートフォンでプレビューできるメッセージは、全体が表示される場合、そのメッセージとして1回だけ表示されます。すべてのアカウントを対象に質問すると、上部に短い回答と、その回答のもとになったメッセージが表示されます。メッセージに答えがない場合、回答は表示されません。

## 学び

学びでは、Machineが学習した内容と、ToDoの成果を確認できます。内容のないタブは表示されません。

- **学習した内容**：メモから学習した文章の書き方、事実、好みの進め方を確認できます。自分の言葉で **編集** したり、事実でなくなったものを **削除** したりできます。チャットで「引っ越したことを忘れて」のように頼んで、情報を忘れさせることもできます。明らかに一致する事実が1件なら削除され、**設定** の **アクティビティ** と **変更内容** から **元に戻す** ことができます。一致する事実が複数ある場合は、チャットでどれを削除するか確認されます。メモから事実やルールを学習すると、ToDoのチャットに **学習した内容に保存しました** と表示され、**編集** と **元に戻す** ができます。
- 事実には **一時的**、**約束**、**設定** の種類があり、いつまで有効かを **まで** で指定できます。一時的な事実は数週間で、好みや約束は数か月で、それ以外の事実は1年で薄れていきます。指定した日付を過ぎた場合や、新しいメッセージで有効でなくなったとわかった場合、事実は **終了済み** に移動します。**再表示** すると元に戻ります。
- **事実** には、一般的な事実、自分についての事実、仕事の進め方が保存されます。人物、組織、プロジェクトに関する事実は、Graphの各ページの **把握していること** に保存され、そこで編集できます。人物、組織、プロジェクトのフルネームが含まれる事実は、保存時にそのページへ移動し、ToDoのチャットには、その名前とともに **Graphに追加しました** と表示されます。Graphのページにある事実の件数は、**事実** の下に控えめな1行で表示されます。開くと各ページに移動できます。自分のメッセージから学習した事実には、元になった言葉が引用符付きで表示されます。
- 誰かの電話番号やメールアドレスを入力すると、事実ではなくGraphのその人のページに保存されます。すでに1つの記録にある電話番号が、同じ名前の別の記録にもある場合は、2つの記録が統合されます。ToDoのチャットには、その人の名前とともに **追加先** と **元に戻す** が表示されます。誰の情報かはっきりしない場合は、事実として保存されます。
- 使われていないからといって、情報が削除されることはありません。各ToDoには関連性の高い事実が優先して使われ、新しい事実ほど重視されます。そのため、めったに必要にならない事実も、ほかの情報を邪魔せずに残ります。終了した事実も、関連するToDoやチャットでは履歴として役立ちますが、現在の状況として扱われることはありません。
- すでに学習した内容を別の言葉で書いたメモは、元の内容を置き換えるため、重複して表示されません。**マージを元に戻す** と、以前の表現に戻ります。自分で編集した内容が置き換えられることはありません。
- **これらを取り込む**：以前OpenClawを使っていた場合、残しておく価値のあるメモの行（`MEMORY.md`、`USER.md`）が、元のファイル名とともに上部に表示されます。残すものにチェックを入れて **チェックを入れたままにする** を押すと、ほかの情報と同じように事実やルールになります。Graphにいる人物についての事実はその人のページに移動し（誕生日は「誕生日」ルーティンにも追加されます）、自分についての事実は「事実」に残ります。**残りを却下** すると、その内容は再表示されません。ファイルが変更されることはなく、残す価値のある内容がない場合は何も表示されません。
- **別のAIからインポート**：ChatGPT、Claude、Geminiが自分について学習した内容を取り込めます。アシスタントを選び、**プロンプトをコピー** してアシスタントに送り、返答を貼り付けてください。**確認** では、残す、編集する、チェックを外す項目を1行ずつ確認できます。すでに伝えた内容はスキップされます。事実と異なる内容はその事実の横に表示されるため、どちらを残すか選べます。パスワード、コード、キー、カード番号、口座番号は表示前に除外され、アクセス権を与えようとする行も除外されます。インポートした事実は参考情報であり、許可として扱われません。それぞれに情報元と日付が表示され、編集するまでは **編集するまでは参考情報のみです** と表示されます。初期設定のToDoと、最初の確認中にも表示されます。
- **変更内容**：編集、却下、チャットから学習した内容を、**元に戻す** とともに確認できます。[文章](writing.md#it-keeps-learning)をご覧ください。
- **決定**：ToDoに対する選択の履歴を時系列で確認できます。
- **共有済み**：The Machineチームと共有する学習内容や、確認を待っている投票があれば表示されます。[学習内容を共有する](share-learnings.md)をご覧ください。
- **利用状況**：過去30日間の数値を4つ確認できます。数値が高いほど良い状態です。判断したToDoが3件に達するまでは表示されず、それまでは判断した件数が表示されます。判断したToDoとは、実行したもの、または却下したものです。
  - **効果**：判断したToDoのうち、却下せずに実行した（**実行**、送信、または完了した）割合です。
  - **一度で成功**：**実行** を選んだToDoのうち、その後に修正が必要なかった割合です。
  - **完了**：**実行** を選んだToDoのうち、続けるように頼んだり、もう一度試したりせずに完了した割合です。
  - **そのまま送信**：送信した下書きのうち、編集や **修正を依頼** をせずに送信した割合です。
  - 各数値は、その前の30日間との比較です。グラフは最初の2週間は日ごと、それ以降は週ごとに最大8週間分を表示します。
  - **ソース別の効果**：ソースごとに実行した件数を確認できます。たとえば **メール**、**追加しました**（**ToDoを新規作成** から追加）、**Androidの通知**、**The Machine自身**（エラーなどの問題）です。
  - **見逃したToDo**：週に1回、The MachineはToDoが作られなかったメッセージを一部確認し、ToDoが必要だった可能性を推定します。見つかったメッセージは一覧に表示されます。**開く** またはメッセージの行を押すと内容を確認でき、**実際の見落とし** または **見落としではありません** を選ぶと、判定が正しかったかを伝えられます。**実際の見落とし** を選ぶとToDoも追加され、**元に戻す**（**ToDoを開く** でそのToDoを開く）が表示されます。Machineはその内容から学習し、以降は同じようなメッセージを見つけやすくなります。回答は件数にすぐ反映され、Machineに保存されます。残りが数件だけになると、割合ではなく **少数** と表示されます。最初の週次確認の後に表示されます。
