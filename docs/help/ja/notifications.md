通知を減らしたり、種類を変えたりできますか？ **設定** の **通知** で、通知の種類ごとに届く場所を選べます。

- **新しいToDo**：今日が期限のものや緊急のものなど、すぐに対応が必要なものだけ通知します。
- **結果と質問**：送信できる状態の返信、タスクで必要なログイン、Fleetからの質問を通知します。
- **リマインダー**：スヌーズしたToDoや、返信待ちの内容を再度通知します。
- **朝のダイジェスト**：その日の予定を短くまとめてお知らせします。詳しくは下記をご覧ください。
- **夜のダイジェスト**：今日完了したことと、明日の予定をお知らせします。詳しくは下記をご覧ください。

通知の種類ごとに、**プッシュ通知**（スマートフォンやコンピューターのアプリ）、設定済みの場合は **Telegram**、ホスティング版 Machine または The Machine Network 上の Machine では **メール** のオン／オフを設定できます。ダイジェストのTelegram通知を除き、すべてオンになっています。

**勤務時間** も同じタブで設定できます。勤務日、通知を送信できる時間帯、スヌーズの通知時刻、ダイジェストの時刻、タイムゾーンを設定します。[勤務時間](work-hours.md)をご覧ください。

## すぐに対応が必要なものだけ

プッシュ通知、Telegramの通知音、メールが届くのは、次の場合だけです。

- 今日が期限、または緊急に設定されたToDo
- 誰かが返信を待っていて、返信の下書きができており、送信できる状態
- ログインが必要なタスク
- 設定した時刻にスヌーズが解除されたとき

それ以外はダッシュボードに通知なしで表示され（Telegramでも通知音は鳴りません）、朝のダイジェストにまとめられます。休日は、緊急のものか今日が期限のものだけ通知されます。プッシュ通知は1日最大8件です。ダッシュボードを3日間開かなかった場合は、戻ってくるまで朝のダイジェストだけが届きます。

## 通知されるタイミング

ダッシュボードが開いているかどうかだけでなく、実際に使っているかどうかを確認します。

- 使用中（画面を表示していて、過去10分以内にクリック、入力、スクロールのいずれかをした場合）：通知音は鳴りません。Telegramには通知音なしで届きます。開いたり再読み込みしたりするだけでは使用中とみなされません。
- 離席中（バックグラウンドにある、閉じている、または10分間操作がない場合）：戻って通知を見るまでに、離席から1分後にプッシュ通知が届きます。
- その後15分たっても未確認で、すぐに対応が必要な場合：その件についてメールを1通送ります。メールは1時間に最大1通です。すでに対応した内容は除外され、各ToDoは現在の状態で1回だけ記載されます。ほとんどの日は、朝のダイジェストだけがメールで届きます。
- チームメンバーからToDoを割り当てられ、Machineに通知先の電話番号もTelegramも設定されていない場合：未確認のままなら15分後に、タイトルとリンクを記載したメールを1通送ります。**結果と質問** の **メール** をオフにすると、このメールは届きません。
- 勤務時間外：通知は届きません。朝のダイジェストに記載されます。
- 休日に新しい仕事用ToDoが追加された場合は、次の勤務日のダイジェスト時刻まで保留されます。ToDoには「通知：11月2日（月）・08:30」のように、通知される時刻が表示されます。

進捗や編集では通知されません。まだ確認していないToDoに新しい結果が届いても、新しい通知は送らず、既存の通知が更新されます。短時間に複数の通知が発生しても、通知音は1回だけ鳴ります。アプリのアイコンには、対応が必要なToDoの数が表示されます。

## 通知のボタン

通知には次の操作に使うボタンがあります。スマートフォンアプリの場合：

- 新しいToDo：「実行」「スヌーズ」「完了にする」
- 下書きの準備完了：「下書きを開く」「スヌーズ」「完了にする」
- 結果の準備完了：「開く」「完了にする」「スヌーズ」
- 質問、行き詰まり、ログイン：「回答」「開く」または「ログイン」、続けて「スヌーズ」と「完了にする」
- リマインダー：「完了にする」「スヌーズ」「開く」
- 朝のダイジェスト：タップして開きます。

ブラウザーとTelegramでは、ボタンが2つ表示されます。Fleetの質問では「一度だけ回答」と「辞退」が表示されます。

通知から送信、支払い、送信手続きが行われることはありません。下書きは必ず最初に開くため、送信前に内容を確認できます。「下書きを開く」を選ぶと、ToDoがリストに表示され、下書きの全文を確認できます。「実行」は、新しいToDoの作業を開始する場合にのみ使います。

スマートフォンアプリでは、「スヌーズ」と「完了にする」を使う前にロック解除が必要です。ブラウザーではダッシュボードが開き、操作が行われたあと、「元に戻す」が表示されます。スヌーズすると、ToDoは2時間後に再度表示されます。リマインダーの場合は、翌朝に再度表示されます。

メールには「開く」リンク（返信待ちの内容には「スヌーズ」も）があります。リンクを開くと、ダッシュボードだけが表示されます。

通知をタップするか、メールまたはTelegramの「開く」を選ぶと、ToDoが現在の場所で強調表示されます。表示先は **たった今完了**、**完了**、**後で戻ります** などです。チャットは開きません。ページに最新の状態がまだ反映されていない場合は、反映後にToDoが表示されます。

## 朝のダイジェスト

勤務日の **朝のダイジェスト** の時刻に届きます。お知らせがない場合は届きません。その時刻が **スヌーズの通知時刻** より早い場合は、朝に再表示されるToDoを含めるため、スヌーズの通知時刻から5分後まで送信を待ちます。**プレビュー** では、送信せずに内容を確認できます。既定ではプッシュ通知とメールで届き、ひと目で読める短さにまとめられています。

- 「おはようございます、Samさん。返信が2件、送信できる状態です」のように、今日の重要事項を添えた挨拶。ToDoが1件の場合は「おはようございます、Samさん。確認をお願いします：注文書を送信」のように表示されます。準備完了として数えられるのは、承認できる下書きまたは結果があるToDoだけです。先に回答が必要なものは含まれません。
- 挨拶で数えたToDo。それぞれに「開く」リンクが付き、今日が期限の内容も表示されます。それ以外の場合は、実行することを最大3件まで表示します。
- 自分で追加した、対応待ちのToDoを最大5件まで表示します。挨拶で数えた内容に含まれるかどうかは問いません。
- さらに保留できるToDoの件数と、自分のペースで対応した場合にかかる時間を、たとえば「あと12件を保留できます。対応には約5分かかります」のように表示します。回答待ちのToDoは所要時間に含まれません。今日が期限でも後の時間までスヌーズされているToDoや、The Machineがまだ作業中のToDoは、自分の対応待ちになるまで件数に含まれません。件数はリストで対応を待っているToDoと一致します。
- 会議を1行で表示します。

「開く」を選ぶと、ToDoがリストで強調表示されます。完了済みやスヌーズ中のToDoも表示されます。約束を開くと、該当するToDoがある場合はそのToDoが、ない場合は約束のページが開きます。

プッシュ通知にはリンクなしで同じ内容が表示されます。通知をタップするか、メール末尾のリンクを選ぶと、**ToDo** でもう一度ダイジェストを確認できます。

## 夜のダイジェスト

勤務日の **勤務時間** で設定した時刻に1回届きます。既定では **まで** の15分前で、上記の行で選んだ方法で届きます。その日にダッシュボードを使ったか、ダッシュボード、Telegram、チャット、音声のいずれかでToDoに対応した場合だけ届きます。完了したToDoも開催した会議もない日は届きません。

「こんばんは、Samさん。今日はToDoを4件完了しました」のように、件数で1日を振り返ったあと、**仕事** と **個人** の項目が表示されます。内容がない項目は表示されません。それぞれ次の内容が含まれます。

- **今日完了**：自分またはMachineが完了したToDoを最大3件表示し、その後に「ほか12件」と当日の会議を表示します。たとえば「会議3件：料金に関する電話会議、ほか2件」のように表示されます。
- **明日の予定**（金曜日は次の勤務日）：最初の会議と期限が近い内容を表示します。

最後に、対応が必要なToDoの数が表示されます。プッシュ通知をタップするか、メール末尾のリンクを選ぶと、**仕事用をコピー** と **個人用をコピー** があるダイジェストをもう一度確認できます。停止するには、その行をオフにします。

## プライバシー

プッシュ通知はMachineからデバイスに直接送信され、デバイス用に暗号化されます。メールはThe Machineのメールサーバーとメールプロバイダーを経由します。[慎重](security-levels.md)に設定すると通知にToDoのテキストが表示されず、メールには件数だけが記載されます。特定の種類の通知をメールで受け取りたくない場合は、その種類の **メール** をオフにしてください。

**このデバイス** でデバイスのプッシュ通知をオンにするか、[アプリをインストール](phone-app.md)をご覧ください。[モバイルアプリ](mobile-app.md)では、AppleまたはGoogleを通じて簡単な通知を受け取り、その後Machineからタイトルと次の操作を取得します。
