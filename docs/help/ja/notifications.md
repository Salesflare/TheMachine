通知を減らしたい、または別の方法で受け取りたい場合は、**設定**の**通知**で種類ごとに受け取り方を選べます。

- **新しいToDo**：今日が期限のものや緊急のものなど、すぐに対応が必要なものだけ通知します。
- **結果と質問**：送信できる状態の返信、タスクで必要なログイン、Fleetからの質問を通知します。
- **リマインダー**：スヌーズしたToDoや、返事を待っているものを再通知します。
- **朝のダイジェスト**：その日の予定を短くまとめてお知らせします。詳しくは下記をご覧ください。
- **夜のダイジェスト**：今日完了したことと、明日の予定をお知らせします。詳しくは下記をご覧ください。

種類ごとに、**プッシュ通知**（スマートフォンまたはコンピューターのアプリ）、設定済みの**Telegram**、ホスティング版 Machine または The Machine Network 上の Machine で使える**メール**を切り替えられます。ダイジェストのTelegram通知を除き、すべてオンになっています。

同じタブで**勤務時間**も設定できます。勤務日、通知を送信できる時間帯、スヌーズの通知時刻、ダイジェストの時刻、タイムゾーンを指定します。[勤務時間](work-hours.md)をご覧ください。

## すぐに対応が必要なものだけ

プッシュ通知、Telegramの通知音、メールが届くのは、次の場合だけです。

- 期限が今日、または緊急に設定されたToDo
- 誰かが待っている返信の下書きができ、送信できる状態になったとき
- ログインが必要なタスク
- 設定した時刻にスヌーズから戻ったとき

それ以外はダッシュボードに静かに表示され（Telegramでは通知音なしで届き）、朝のダイジェストを待ちます。休みの日は、緊急のものか今日が期限のものだけ通知します。プッシュ通知は1日最大8件です。ダッシュボードを3日間開いていない場合は、戻ってくるまで朝のダイジェストだけが届きます。

## 通知が届くタイミング

ダッシュボードが開いているかどうかだけでなく、実際に使っているかを確認します。

- 使用中（画面を表示していて、過去10分以内にクリック、入力、スクロールをした場合）：通知音は鳴りません。Telegramは通知音なしで届きます。開いたり再読み込みしたりするだけでは使用中とみなされません。
- 離席中（バックグラウンドにある、閉じている、または10分間操作がない場合）：戻って通知を見る前に限り、離れてから1分後にプッシュ通知が届きます。
- 15分たっても通知が届かず、すぐに対応が必要な場合：その内容をメールで1時間に最大1回送ります。確認済みまたは対応済みのものは除外され、各ToDoはその時点の内容で1回だけ記載されます。ほとんどの日は朝のダイジェストだけがメールで届きます。
- 通知が届いたとみなされるのは、スマートフォンまたはブラウザーに通知が表示されたとき、またはTelegramがメッセージを受け取ったときです。スマートフォンの電源がオフ、オフライン、または通知がオフの場合は届いたことになりません。ダッシュボードの使用中に届いたTelegramも同様です。コンピューターにだけ表示された場合は、外出している可能性があるため、緊急のものや今日が期限のものはメールでも送ります。
- スマートフォンアプリ、ブラウザー通知、Telegramを使っていない場合：上記すべてがメールで届きます。
- Telegramに届かない場合：プッシュ通知は1回送信され、Telegramにも自動で再送されます。
- チームメンバーからToDoを渡されたとき、Machineから通知できるスマートフォンやTelegramがない場合：まだ確認されていなければ、15分後にタイトルとリンクを記載したメールが1通届きます。**結果と質問**の**メール**をオフにすると、メールは届きません。
- 勤務時間外：通知は届きません。朝のダイジェストに記載されます。
- 休みの日に新しい仕事のToDoが追加された場合は、次の勤務日のダイジェスト時刻まで保留されます。ToDoには通知予定時刻が表示されます。例：通知 月 11月2日・08:30。

進捗や編集では通知されません。まだ確認していないToDoに新しい結果が追加された場合は、新しい通知を送らずに内容を更新します。通知が続けて発生した場合も、通知音は1回だけ鳴ります。アプリのアイコンには、対応が必要なToDoの数が表示されます。

## 通知のボタン

通知には次の操作に使うボタンがあります。スマートフォンアプリでは、次のとおりです。

- 新しいToDo：**実行**、**スヌーズ**、**完了**。
- 下書きの準備完了：**下書きを開く**、**スヌーズ**、**完了**。
- 結果の準備完了：**開く**、**完了**、**スヌーズ**。
- 回答が必要なもの、進行できないもの、ログインが必要なもの：**回答**、**開く**、または**ログイン**。その後、**スヌーズ**と**完了**を選べます。
- リマインダー：**完了**、**スヌーズ**、**開く**。
- 朝のダイジェスト：タップすると開きます。

ブラウザーとTelegramでは、このうち2つのボタンが表示されます。Fleetからの質問には、**回答**と**辞退**のボタンが表示されます。

通知から送信、支払い、申し込みが行われることはありません。下書きは必ず最初に開くため、送信前に内容を確認できます。**下書きを開く**を選ぶと、ToDoリストに下書き全文が表示されます。**実行**を選ぶと、新しいToDoの作業だけが始まります。

スマートフォンアプリでは、**スヌーズ**または**完了**を選ぶと、まずロックを解除するよう求められます。ブラウザーではダッシュボードが開き、操作が実行されてから「元に戻す」が表示されます。スヌーズしたToDoは2時間後に戻ります。リマインダーの場合は翌朝に戻ります。

メールには**開く**リンクがあり、返事を待っているものには**スヌーズ**リンクもあります。リンクを開くと、ダッシュボードだけが表示されます。

通知をタップするか、メールまたはTelegramで**開く**を選ぶと、ToDoリストの該当するToDoが強調表示されます。表示場所は現在の状態に応じて変わり、**たった今完了**、**完了**、**後で戻ります**、または別のビューに表示されます。チャットが開くことはありません。ページがまだ更新されていない場合は、更新後にToDoが表示されます。

## 朝のダイジェスト

勤務日の**朝のダイジェスト**時刻に届きます。お知らせがない場合は届きません。この時刻が**スヌーズの通知時刻**より早い場合は、朝に戻ってくるToDoを含めるため、スヌーズの通知時刻の5分後まで待ってから届きます。**プレビュー**を選ぶと、送信せずに内容を確認できます。初期設定ではプッシュ通知とメールで届き、ひと目で読める短さです。

- 「おはようございます、Samさん。送信できる返信が2件あります」など、今日の大切なことを含む挨拶が表示されます。ToDoが1件の場合は、「おはようございます、Samさん。確認をお願いします：注文書を送信」のように表示されます。承認待ちの下書きまたは結果があるToDoだけが準備完了として数えられます。先に回答が必要なToDoは含まれません。
- 挨拶に含まれるToDoがそれぞれ「開く」リンク付きで表示され、今日が期限のものも記載されます。該当するものがない場合は、ToDoが最大3件表示されます。
- 自分で追加し、自分の対応を待っているToDoが最大5件表示されます。挨拶に含まれる件数に関係なく表示されます。
- ほかに保留できるToDoの数と、自分のペースで対応した場合にかかる時間が表示されます。例：「ほかに12件保留できます。対応に約5分かかります」。回答待ちのToDoは所要時間に含まれません。今日が期限でも後の時刻までスヌーズしているToDoや、The Machineが作業中のToDoは、自分の対応待ちになるまで数えられません。件数は、リストで対応を待っているToDoの数と一致します。
- ミーティングが1行で表示されます。

**開く**を選ぶと、そのToDoがリスト内で強調表示されます。完了済みやスヌーズ中の場合も同様です。約束を開くと、そのToDoが表示されます。まだToDoがない場合は、約束のページが開きます。

プッシュ通知にはリンクなしで同じ内容が表示されます。通知をタップするか、メール末尾のリンクを選ぶと、**ToDo**でダイジェストをもう一度確認できます。

## 夜のダイジェスト

勤務日に1回、**勤務時間**で設定した時刻に届きます。初期設定では**まで**の15分前です。受け取り方法は、上の行で選んだものになります。その日にダッシュボードを使ったか、ダッシュボード、Telegram、チャット、音声のいずれかでToDoの選択をした場合にだけ届きます。完了したToDoも開催したミーティングもない日は届きません。

「こんばんは、Samさん。今日完了したToDoは4件です」のように、その日の件数から始まり、次に**仕事**と**個人**のセクションが表示されます。内容がないセクションは表示されません。Machine自体に関するアラートは、どちらにも表示されません。各セクションには次の内容が含まれます。

- **今日完了**：自分またはMachineが完了したToDoが最大3件表示され、その後に「ほかに12件」と、その日のミーティングが表示されます。例：「ミーティングがほかに3件：料金についての通話とほか2件」
- **明日の予定**（金曜日の場合は次の勤務日）：最初のミーティングと、期限が来るものが表示されます。

最後に、対応が必要なToDoの数が表示されます。プッシュ通知をタップするか、メール末尾のリンクを選ぶと、**仕事用をコピー**と**個人用をコピー**を含めて、もう一度確認できます。停止するには、この行をオフにします。

## プライバシー

プッシュ通知は、Machineからデバイスに直接、デバイス向けに暗号化して送られます。メールはThe Machineのメールサーバーとメールプロバイダーを経由します。[慎重](security-levels.md)の設定で通知内のToDoのテキストを非表示にすると、メールには件数だけが記載されます。メールに表示したくない種類は、**メール**をオフにしてください。

**このデバイス**でデバイスのプッシュ通知をオンにするか、[アプリをインストールする](phone-app.md)をご覧ください。[モバイルアプリ](mobile-app.md)では、AppleまたはGoogleを通じて簡単な通知が届き、その後Machineにタイトルと次の操作を確認します。
