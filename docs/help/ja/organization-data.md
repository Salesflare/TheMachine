## 情報の取得元

- ホスティング版Machineでは、組織の詳細が無料で検索されます。
- 自分のコンピューターでは、Apollo、People Data Labs、Hunterなどの検索サービスのキーを追加するまで無効です。[設定ガイド](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md)をご覧ください。

送信されるのは組織のWebアドレスだけで、メッセージや、そこで知り合った人の情報は送信されません。ホスティング版Machine、またはThe Machine Network上のMachineでは1日最大1,000件、それ以外では最大50件を検索します。検索結果は90日ごとに更新されます。gmail.comなどの共有サイトやメールプロバイダーは検索されません。人物情報は別に検索されます。[役職と写真](people.md#job-title-and-photo)をご覧ください。

検索でロゴが見つからない場合は、組織のWebサイトで指定されているアイコンをMachineに保存して使用します。ロゴサービスに、取引先の情報が伝わることはありません。両方のロゴがある場合、ToDoの行など小さな表示には正方形のアイコンを使います。

検索結果に含まれている場合は、組織の専門分野を最大5つ、説明の下に表示します。組織リストは、**絞り込む**、**専門分野**の順に選ぶと、専門分野で絞り込めます。人物の情報を検索したときに勤務先の詳細も見つかった場合、その情報を組織にも反映するため、組織の情報を別途検索する必要はありません。過去90日以内に検索した詳細はそのまま保持されます。

## 間違った組織を修正する

組織のページで、次の操作ができます。

- **編集**すると、名前、業種、規模、所在地、設立年、説明、Webサイト、LinkedIn、メモ、自分にとっての位置づけを変更できます。編集内容は保持されます。フィールドを空欄にすると、検索結果の値が再び使われます。
- 間違った組織が選ばれた場合は、**編集**内の**会社が違う場合は、詳細を消去**を選びます。
- 詳細を消去すると表示される**もう一度検索する**を選ぶと、最新の詳細を取得できます。
