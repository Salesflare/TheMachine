## 情報の取得元

- ホスティング版のMachineでは、組織情報を無料で調べます。
- 自分のコンピューターで使う場合は、Apollo、People Data Labs、Hunterなどの検索サービスのキーを追加するまで無効です。[設定ガイド](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md)をご覧ください。

送信されるのは組織のWebアドレスだけで、メッセージや、その組織の誰と知り合いかといった情報は送信されません。ホスティング版のMachine、またはThe Machine Network上のMachineでは、1日に最大1,000件、それ以外では最大50件を検索します。それぞれ90日ごとに更新されます。gmail.comのような共有サイトやメールプロバイダーは検索しません。人物情報は別途検索されます。詳しくは[役職と写真](people.md#job-title-and-photo)をご覧ください。

検索結果にロゴがない場合は、組織のウェブサイトにあるアイコンを使い、Machineに保存します。ロゴサービスに、やり取りしている相手が知られることはありません。ロゴとアイコンの両方がある場合、ToDoの行など小さな表示箇所には正方形のアイコンを表示します。

検索結果にある場合は、組織の専門分野を最大5つ、説明の下に表示します。組織一覧は専門分野で絞り込めます。**絞り込む**、次に**専門分野**を選んでください。人物情報の検索で勤務先の組織情報も取得できた場合、その情報を組織にも反映するため、組織自体の検索は不要です。過去90日以内に検索した情報は、そのまま保持されます。

## 間違った情報を修正する

組織のページで、次の操作ができます。

- **編集**を選ぶと、名前、業種、規模、所在地、設立年、説明、ウェブサイト、LinkedIn、メモ、自分にとっての位置づけを変更できます。変更内容は保存されます。検索結果を再び使うには、項目を空にしてください。
- 別の会社が選ばれている場合は、**編集**内の**会社が違う場合は、詳細を消去**を選んでください。
- 詳細を消去すると表示される**もう一度検索する**を選ぶと、最新情報を取得します。
