## 情報の取得元

- ホスト型のMachineでは、組織の詳細を無料で検索します。
- 自分のコンピューターでは、Apollo、People Data Labs、Hunterなどの検索サービスのキーを追加するまでオフになっています。[設定ガイド](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md)をご覧ください。

送信されるのは組織のWebアドレスだけです。メッセージや、そこで誰とつながっているかは送信されません。1日に検索する組織は最大50件で、それぞれ90日ごとに更新されます。gmail.comのような共有サイトやメールプロバイダーは検索しません。人物情報は別に検索できます。[役職と写真](people.md#job-title-and-photo)をご覧ください。

検索でロゴが見つからない場合は、組織のWebサイトのアイコンを使い、Machineに保存します。ロゴサービスに取引相手が知られることはありません。ロゴとアイコンの両方がある場合、ToDoの行などの小さな表示には正方形のアイコンを使います。

検索で情報が見つかると、組織の説明の下に専門分野を最大5つ表示します。また、組織リストは専門分野で絞り込めます：**絞り込む**を選び、**専門分野**を選択します。人物情報を検索した際に会社の詳細も取得できた場合、その情報は組織にも反映されるため、組織の情報を個別に検索する必要はありません。過去90日以内に検索した詳細はそのまま表示されます。

## 間違った情報を修正する

組織のページで操作します。

- **編集**を選ぶと、名前、業種、規模、所在地、設立年、説明、Webサイト、LinkedIn、その組織との関係を変更できます。変更内容は保持されます。検索結果に戻すには、項目を空にします。
- 会社が違う場合は、**会社が違う場合は、詳細を消去**を選びます。
- 最新の詳細を取得するには、**もう一度検索する**を選びます。
