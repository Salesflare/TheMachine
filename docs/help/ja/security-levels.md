## 2つのレベル

**設定**を開き、**セキュリティ**を選びます。

- **標準**：現在のデフォルト設定です。変更はありません。
- **慎重**：スマートフォンに表示する情報や保存する情報を減らしたいときに使う、より厳しい設定です。

レベルは設定の出発点です。その後に設定を変更すると、レベルは**カスタム**と表示されます。レベルを選び直すと、設定がリセットされます。

## 「慎重」にすると変わること

- **通知内のテキスト**がオフになります。通知には「新しいToDo」や「準備完了」と表示され、ToDoの内容は表示されません。
- **ログイン情報の保存を提案**がオフになります。保存したログイン情報は、**保存済みのログインをすべて忘れる**をタップするまで残ります。
- **仕事関係の連絡先を検索する**、**学びの共有を提案**、**ヘルプで依頼された内容を共有**がオフになります。
- **連絡先のうち、Machineを持っている人を確認**と**メールアドレスを知っている人に見つけてもらう**がオフになります。
- **実行の詳細を90日間保持**がオフになり、詳細は30日間保持されます。
- **他のMachineから自分のMachineに尋ねられること**が**オフ**になります。他のMachineとの予定調整はできません。[友達とNetwork](friends.md#scheduling-with-other-machines)をご覧ください。
- 家族との空き時間の共有では、先に確認を求められます。友達とのミーティングでは、コンテキストの共有を拒否します。

## Work Fleetのレベル

Fleetのオーナーまたは管理者がFleetの設定でレベルを選びます。**設定** › **アカウント**を開き、**Fleet**をタップします。Fleetの全員にレベルが表示されます。「慎重」の場合：

- チームメンバーへの回答は、名前を含めず、仕事用アカウントの相手についてのみ、確認を待ってから送信されます。
- 紹介と引き継ぎも、確認を待ってから行われます。
- チームのGraphでは、クライアントとのメールを共有しますが、添付ファイルは共有しません。
- 仕事のToDoに関する通知には、テキストが表示されません。
- 仕事関係の連絡先は検索されません。
- 自分で有効にしていない限り、MachineはNetwork上の連絡先を確認せず、メールアドレスで見つけられるようにもしません。
- 全員が7日ごとに再ログインします。
- 招待リンクは、送信先のメールアドレスでのみ使えます。

メンバーはFleetより厳しい設定にできますが、緩くはできません。メンバー自身が選んだ設定は保持され、Fleetが「標準」に戻ると再び適用されます。

## どちらのレベルでも同じこと

確認なしに情報が送信されることはありません。下書きを確認してから、**送信**を押します。実行とコーディングエージェントの動作は変わりません。ログインには常に認証アプリのコードまたはパスキーが必要です。
