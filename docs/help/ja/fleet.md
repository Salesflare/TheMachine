Fleet を使うと、The Machine Network を通じて、Machine がチーム、家族、友達のMachineと連携できます。Machine 同士のやり取りはエンドツーエンドで暗号化され、Machine は設定したルールに従ってのみ応答します。

## Fleet の種類

- **Work Fleet**：チーム向けです。仕事を引き継いだり、誰かを知っている人を尋ねたり、紹介やチームブリーフを受け取ったりできます。
- **ファミリー Fleet**：最大6人で利用できます。全員の予定が空いているときに、共有 ToDo や予定を確認できます。無料です。[ファミリー](family.md)をご覧ください。
- **友達**：The Machine を使う人なら、1人ずつ追加できます。無料です。[友達](friends.md)をご覧ください。

## Fleet タブ

Fleet に参加すると表示されます。Fleet、Family、Friends、Network、共有、アクティビティごとのペインがあります。

## 料金、Fleet からの退出、新しい Fleet の開始

各Fleet名の下にある**料金**には、利用枠、Machine の支払い担当者、オーナー向けには Fleet のカードと請求書が表示されます。**このFleetから退出**を選ぶと退出できます。オーナーは、先に別の人へ引き継ぐ必要があります。**別のFleetを始める**を選ぶと、新しい Fleet を開始できます。

それぞれを選ぶと、アカウントの該当ページが開きます。料金が変わる場合は、先に確認する金額が表示されます。セルフホストのMachineでは、新しいタブでアカウントが開き、サインインが必要です。

## Fleet に質問する

Fleet タブから「Acmeに知り合いがいる人は？」と尋ねるか、[Graph](graph.md)の組織ページで**Fleet に聞く**を選びます。チームメイトのMachineは、それぞれの共有ルールに従って回答し、ルールで定められている場合は先に本人に確認します。

## Work Fleet で自動回答される内容

Standard Work Fleet では、Machine がチームメイトからの次の3種類の質問に自動で回答します：**誰かを知っている人**、**会議のコンテキスト**（「このゲストは誰？」）、**共有メールを担当する人**。回答には、[Team Graph](team-graph.md)ですでにチームと共有されている情報だけを使います。非公開、個人的、機密性の高いやり取りは使いません。回答はそれぞれFleetタブの**アクティビティ**に表示されます。

回答を止めるには、**共有**で**しない**に設定します。**先に確認**に設定したルールは、**常に**と同じように動作します。Team Graph の共有がオフの場合、「誰かを知っている人」と「会議のコンテキスト」については先に確認します。

Careful Work Fleet、Friends、Family では、引き続き先に確認します。温かい紹介、引き継ぎ、無料の質問には、それぞれ独自のルールが適用されます。

## チームの学び

Machine は、Team Graph ですでに共有されている顧客とのやり取りから、チームの仕事の進め方を記録します。記録は1日につき最大1回です。たとえば、「返金リクエストには、サポート用受信トレイから返金テンプレートを使って返信します」といった内容です。Fleet 内の全員に、Work Fleet のペインの**チームの学び**に表示され、それぞれ**アクティビティ**に記録されます。先に確認は行われません。

- チームの誰かが返信したやり取りだけが対象です。非公開、個人的、機密性の高いやり取りは対象外です。
- 複数の顧客に共通する内容だけが対象です。手順、ツール、文体、担当者などです。特定の顧客に関すること、自社製品へのフィードバック、名前、住所、番号、引用は含まれません。
- 確信が持てない内容は記録されません。

Machine は、この会社のWork ToDoを準備するときに、関連する学びを使います。自分の情報、ルール、スキルが優先され、個人のToDoには使われません。学びを使ったToDoには、「チームの学びを使用：返金はサポート用受信トレイから送信」などと表示されます。そこで**削除**をタップすると、Fleet全体から削除できます。

Fleetの誰でも学びを**削除**できます。削除すると全員から消え、再び作成されることはありません。共有を止めるには、設定の「セキュリティ」で**学びの共有を提案**をオフにします。Careful Work Fleet では学びは作成されません。

## チームブリーフ

Fleet タブの**共有**で、**チームブリーフ**を**毎日**または**毎週**に設定します。するとMachineがチームメイトのMachineに件数と日付を尋ねます。対応が必要な内容は、「仕事」のToDoに届きます。たとえば、チームメイトからの返事を待っている顧客、2週間以上連絡がない会社、同じ相手に2人で連絡している状況、共有の会議などです。

- ToDoには、誰からいつから返事を待っているか、相手の依頼内容、進行中のプロジェクトなどの重要事項が表示されます。具体的に伝える内容がない場合は、ToDoではなくブリーフ内の項目として表示されます。
- 会社とチームメイトは、それぞれのページへのリンクになります。**詳細**には、相手が書いた内容（タップすると読めます）、重要事項、連絡を取っているチームメンバー、最新のやり取りが表示されます。[Team Graph](team-graph.md)で共有されている内容のみが対象です。
- 相手が書いた内容がチームメイトのメールにしかない場合、ToDoには誰に尋ねるかが表示されます。
- **チームに聞く**を選ぶと、その内容についての質問が入力済みの状態で送信されます。回答はToDoに表示されます。
- **不要**を選ぶと対応が終了し、ブリーフに反映されます。新しい情報がある場合のみ再び表示されます。
- 誰かが返信するか対応を引き受けると、ToDoは自動で完了します。すでにその会社のToDoがある場合は、そのToDoにまとめられます。

## ブリーフのリクエスト

チームブリーフを有効にしているチームメイトは、毎朝、Machine に件数と日付を尋ねます。Work Fleet では、Machine は[Team Graph](team-graph.md)ですでに共有されている内容だけを使って自動で回答します。Team Graph の共有がオフの場合は何も共有されません。回答はそれぞれFleetタブの**アクティビティ**に表示され、ToDoや通知としては表示されません。

回答を止めるには、Fleet タブの**共有**で**自分の基本情報をチームと共有**をオフにします。チームメイトのブリーフには、未回答として表示されます。

Careful Fleet では、リクエストはFleetタブの**ブリーフのリクエスト**に届きます。**一度だけ共有**、**常に共有**、**拒否**、**しない**から選びます。選択するまで何も共有されず、未回答のリクエストは期限が切れます。

## Team Graph

Work Fleet では、内容を確認した後、顧客との仕事をチームと共有します。[Team Graph](team-graph.md)をご覧ください。

## 共有済みの接続

オーナーまたは管理者は、Fleet タブの**共有済みの接続**からStripeまたはIntercomを一度接続し、チームと共有できます。チームメイトは閲覧できますが、変更はできません。誰が共有したかも確認できます。変更や共有停止ができるのは管理者だけです。[Stripe](stripe.md)と[Intercom](intercom.md)をご覧ください。

## Machine が回答する内容

共有ペインでFleetごとに設定します。[共有ルール](sharing-rules.md)をご覧ください。**設定**には、**Fleet のルール**へのショートカットがあります。

## 会社アカウントでのサインイン

チームメイトが会社のアカウントで参加できるようにします。ホスト型のWork Fleetでは、Google WorkspaceまたはMicrosoft 365でサインインしたオーナーまたは管理者が、アカウントページで**会社アカウントでのサインイン**を有効にできます。

会社のドメインでサインインしたチームメイトには**参加をリクエスト**が表示され、オーナーまたは管理者がそれぞれ**承認**する必要があります。個人用のGmailやOutlook.comアカウントは対象になりません。

Fleetからメンバーを削除すると、すべての場所でサインアウトされます。

Fleetへの参加、新しいFleetの開始、ご自身のコンピューターでのMachineのペアリングについては、[プランと請求](plans-and-billing.md)と[友達とNetwork](friends.md)をご覧ください。

## オーナーと管理者向け

Fleet タブの**管理**には、管理している各Fleet、そのメンバー、役割、招待が表示されます。ホスト型のMachineでは、その場で招待、役割の変更、メンバーの削除、参加リクエストへの回答ができます。料金に影響する変更を行うと、先に確認するためアカウントが開きます。セルフホストのMachineでは、Fleetのメンバーが表示され、アカウント上のFleet設定へのリンクからメンバーと招待を管理できます。

各Fleetのペイン内のFleet名の下と「管理」にある**Fleet の設定**を開くと、アカウント上でそのFleetの設定を変更できます。共有済みの接続、セキュリティ、会社アカウントでのサインイン、回答するMachineの設定に加え、次の2項目があります：

- **最近削除されたメンバー**：削除された人、または退出した人が表示されます。**削除済み、確認済み**は、Machineから仕事のデータが削除され、すべての場所でサインアウト済みであることを示します。それまでは**保留中**と理由が表示されます。
- **アクティビティ**：招待、参加、削除、役割、ホスト型Machine、請求、共有済みの接続、承認など、誰がいつ何をしたかが表示されます。サポートチームがメンバーのMachineレポートやログを閲覧した日時も記録されます。メッセージの内容は記録されません。**CSVをダウンロード**でエクスポートできます。12か月間保存されます。

オーナー向けの**メンバーのMachineを起動する前に確認する**をオンにすると、新しいメンバーのMachineは承認を待ちます。無料のFleetでも同じです。オフにすると、無料のFleetではMachineがすぐに起動し、通知が届きます。料金が発生するMachineは、金額を確認するまで必ず待機します。

**共有を停止**した後、すべてのMachineが接続にアクセスできなくなると、共有済みの接続に**削除済み、確認済み**と表示されます。
