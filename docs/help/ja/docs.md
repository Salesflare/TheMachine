## 読み込む内容

**Microsoft OneDrive**は、ホスティング版Machineと自分のコンピューターで、OneDrive内のWordファイルを読み込みます。Outlookを接続する必要はありません。Google Docsについては、下をご覧ください。読み込む内容は次のとおりです。

- Wordファイルへのコメントと返信、自分へのメンションを含むコメント。
- Wordファイルの変更履歴。

最初の同期では、過去7日分を読み込みます。各項目から、[Graph](graph.md)内の人物やプロジェクトに移動できます。対応が必要なコメントはToDoになります。

## 共有されたファイル

Microsoftは2026年11月に、これらのファイルの一覧表示を終了します。他の人が共有したファイルや、他の人のファイル内でのメンションは、それ以降、MicrosoftからのメールとしてのみMachineに届きます。[Outlook](microsoft.md)も接続し、メールを受信できる状態にしてください。メールから作成されたToDoを開くとメールが表示され、メール内のボタンからファイルを開けます。メールが届かない共有やメンションは確認できません。

## できること

ToDoの処理にドキュメントの内容が必要な場合、MachineはそのToDoを処理している間だけ、該当するドキュメントを読み込みます。Word、PDF、テキストファイルを読み込めます。

自分のOneDrive内にあるファイルも種類を問わず検索し、リンクを表示します。SharePointのサイトや共有されたファイルは検索しません。スキャンしたPDFの文字は読み取れません。

コメントへの返信案を作成できます。Wordでは外部から返信を投稿できないため、返信案をWordにコピーしてください。

許可なしに、提案の承認、コメントの解決、ファイルの共有、ドキュメントの変更を行うことはありません。

操作の実行にのみ使うには、**詳細**で**シグナルを取り込む**をオフにしてください。その場合、ToDoに必要なファイルだけを検索して読み込み、新しいファイルを作成します。

## ドキュメントの作成と編集

Machineは、新しいドキュメントを作成したり、ToDoに関連するドキュメントを変更したりできます。

- ToDoまたはスキルから依頼された新しいドキュメントは、すぐに作成します。自分のOneDriveまたはGoogle Driveに非公開で保存されます。ToDoに**ドキュメントを開く**が表示されます。共有やリンクの送信には、許可が必要です。
- 既存のドキュメントへの変更は、まず準備します。**変更を確認**を押すと、変更前後の段落を確認できます。その後、**保存**を押してください。ToDoのチャットで依頼した変更は、すぐに反映します。
- 確認した時点のドキュメントにのみ書き込みます。その間に誰かが変更していた場合、書き込みは行わず、ToDoでその旨をお知らせします。新しい下書きを依頼してください。
- Talkでは、変更内容をすべて読み上げ、明確な許可を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を拒否した場合、ToDoで理由をお知らせし、再試行用に**確認して作成**を表示します。

テキストの置き換えや追加、段落や見出しの追加ができます。表、画像、変更履歴、フィールドはそのまま残ります。

仕事用ToDoのドキュメントは、その会社のアカウントに保存され、個人用アカウントには保存されません。自分のコンピューターでは、Gmail用に接続したGoogleアカウントにDriveへのアクセス権があれば、新しいGoogle Docsの保存先にもできます。該当するアカウントがない場合、仕事用に接続するアカウントとして、Microsoft OneDrive、またはMachineで利用できる場合はGoogle Docsを案内します。

ドキュメントの作成が最後の手順ではない場合、たとえば返信にリンクを添える場合、ToDoは完了せず、その手順の下書きを作成して許可を待ちます。

接続すると編集機能も使えるようになります。読み取りのみ可能な古い接続では、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 求められる許可

Microsoftから求められる許可は1つだけです。共有されたファイルを含め、ファイルの読み取りと変更を許可します。変更はそれぞれ、引き続きToDoでの許可を待ちます。メールやカレンダーへのアクセス権は変わりません。

後からこの許可を取り消すと、Microsoft OneDriveの**接続**に**ドキュメントを読む許可待ち**と表示されます。

## 接続する

ホスティング版Machine、またはアカウントとペアリングした自分のコンピューターで、次の操作を行います。

- **接続**を開き、**ドキュメントとファイル**を選んで、**Microsoft OneDrive**を選択します。
- **Microsoftでログイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押してもMicrosoftが編集を許可しない場合は、その旨が表示されます。

## Google Docs

ホスティング版Machineで、**接続**を開き、**ドキュメントとファイル**から**Google Docs**を選択します。Googleから、指定したドキュメントの表示と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセス権も変わりません。

接続すると、Machineは次の操作を行います。

- ToDoのメッセージ内にリンクされたGoogle Docs、またはチャットに貼り付けられたGoogle Docsを、そのToDoの処理中にのみ読み込みます。
- そのドキュメントへの変更を準備します。前述のとおり、変更ごとに許可が必要です。
- Google Driveに新しいドキュメントを非公開で作成します。

Driveは検索しません。コメント、共有、提案を確認できるのは、Machineが作成したドキュメントのみです。Drive全体へのアクセスが必要になるため、それ以上のアクセスは求めません。

## Google Sheets と Slides

**接続**のGoogle Docsに**Sheets と Slides を許可する**が表示されている場合は、押して両方を許可してください。Googleから、SheetsとSlidesのファイルをMachineが表示できるように許可するよう求められます。ファイルの変更はできません。

許可すると、MachineはToDoのメッセージ内にリンクされたGoogle SheetsまたはSlidesのファイル、あるいはチャットに貼り付けられたファイルも、そのToDoの処理中にのみ読み込みます。

- スプレッドシートでは、まずリンクされたタブやセルを読み込み、その後、他のタブを最大2,000セルまで読み込みます。数式は計算結果として表示されます。非表示のタブは、リンクされている場合や指定された場合のみ読み込みます。
- スライドでは、テキストとスピーカーノートを順に読み込みます。画像やグラフは読み込みません。

ファイルが大きい場合は、チャットで対象のタブ、セル、スライドを指定してください。ファイルが他の人専用の場合、削除されている場合、またはExcelやPowerPointのファイルの場合は、ToDoでその旨をお知らせします。Google Driveのリンク先がGoogle Docs、Sheets、Slidesのファイルの場合も、同じように扱います。

## 自分のコンピューターで使うGoogle Docs

自分のコンピューターでは、ログイン済みのGmailアカウントにDriveへのアクセス権があれば、そのアカウントに新しいGoogle Docsを作成できます。他のGoogle Docsやそのコメントは読み込みません。**ドキュメントとファイル**には、そのアカウントのGoogle Docsとして表示されます。ToDo用に作成したドキュメントを変更することもできます。

Googleのログイン状態でDrive、Sheets、またはSlidesへのアクセス権がすでにある場合、ToDoにリンクされたGoogle SheetsやSlidesのファイル、またはチャットに貼り付けられたファイルも読み込みます。Googleに追加の許可を求めることはありません。Googleがアクセスを拒否した場合は、そのログインで使っているGoogleプロジェクトでGoogle SheetsまたはSlides APIを有効にしてください。

## 仕事用と個人用

メールと同様に、接続の仕事用または個人用のラベルに従います。仕事用ドキュメントは、[共有ルール](sharing-rules.md)に基づき、チームのGraphに届くことがあります。個人用ドキュメントがGraphに届くことはありません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選んで、**詳細**から**接続を解除**を押してください。以降、読み込みは停止します。すでに取り込んだ内容は残ります。ホスティング版Machineでは、**接続を解除 ↗**を押すと、ログイン情報を管理するセットアップページが開きます。
