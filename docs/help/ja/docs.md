## 読み取る内容

**Microsoft OneDrive** は、ホスト型のMachineと自分のコンピューターで、OneDriveとSharePointにあるWordファイルを読み取ります。Outlookを接続する必要はありません。Google Docsについては下記をご覧ください。取り込む内容は次のとおりです。

- 誰かが共有したドキュメント。
- ドキュメントへのコメントと返信、自分にメンションしたコメント。
- Wordファイルの変更履歴。

最初の同期では過去30日分を取り込みます。各項目は、[Graph](graph.md)内の人物やプロジェクトにリンクされます。対応が必要なコメントはToDoになります。

## できること

ToDoの作業にドキュメントの本文が必要な場合、そのToDoの作業中に限り、該当するドキュメントだけを読み取ります。

コメントへの返信の下書きを作成できます。Wordでは外部から返信を投稿できないため、下書きをWordにコピーしてください。

確認なしに提案を承認したり、コメントを解決したり、ファイルを共有したり、ドキュメントを変更したりすることはありません。

操作の実行だけに使うには、**詳細**で**シグナルを取り込む**をオフにします。その場合、ToDoに必要なドキュメントだけを見つけて読み取り、新しいドキュメントを作成します。

## ドキュメントの作成と編集

ToDoに関係するドキュメントを新しく作成したり、既存のドキュメントを変更したりできます。

- ToDoまたはスキルから依頼があれば、その場で新しいドキュメントを作成します。個人用のOneDriveまたはGoogle Driveに、非公開で保存されます。ToDoに**ドキュメントを開く**が表示されます。共有したり、リンクを送信したりするには、確認が必要です。
- 既存のドキュメントへの変更は、まず準備します。**変更を確認**を押すと、変更前と変更後の段落を確認できます。続けるには**保存**を押してください。ToDoのチャットで依頼した変更は、その場で反映します。
- 表示されていた内容に対してのみ書き込みます。その間に誰かが変更していた場合、書き込みは行わず、ToDoにその旨が表示されます。新しい下書きを依頼してください。
- Talkでは、変更内容全体を読み上げ、明確な「はい」の返事を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を許可しない場合、ToDoに理由が表示され、再試行するための**確認して作成**が表示されます。

テキストの置き換えや追加、段落や見出しの追加ができます。表、画像、変更履歴、フィールドはそのまま残ります。

仕事用のToDoのドキュメントは、その会社のアカウントに保存され、個人用アカウントには保存されません。自分のコンピューターでは、Gmail用に接続したGoogleアカウントにDriveへのアクセス権があれば、新しいGoogle Docsの保存先にもできます。適切なアカウントがない場合、仕事用に接続するサービスとしてMicrosoft OneDrive、またはMachineで利用できる場合はGoogle DocsがToDoに表示されます。

ドキュメントの作成や編集が最終ステップではない場合、たとえばリンク付きの返信が必要な場合、ToDoは未完了のままになり、そのステップの下書きを作成して確認を待ちます。

編集機能は接続時に利用できます。読み取り専用の既存の接続には、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 必要な許可

Microsoftから、共有されたファイルも含め、ファイルの読み取りと変更を許可する確認が1回表示されます。変更のたびに、該当するToDoで確認が必要です。メールやカレンダーへのアクセス権は変わりません。

後から許可を取り消すと、**接続**にMicrosoft OneDriveと**ドキュメントの読み取り許可待ち**が表示されます。

## 接続する

ホスト型のMachine、またはアカウントとペアリングした自分のコンピューターで、次の操作を行います。

- **接続**を開き、**ドキュメントとファイル**から**Microsoft OneDrive**を選びます。
- **Microsoftでサインイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押してもMicrosoftが編集を許可しない場合は、その旨が表示されます。

## Google Docs

ホスト型のMachineで、**接続**を開き、**ドキュメントとファイル**から**Google Docs**を選びます。Googleから、指定したドキュメントの表示と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセス権も変わりません。

接続すると、次のことができます。

- ToDoのメッセージ内にリンクされたGoogle Docを、そのToDoの作業中に限り読み取ります。
- そのドキュメントへの変更を準備します。上記のとおり、変更のたびに確認が必要です。
- Google Driveに非公開の新しいドキュメントを作成します。

Drive内を検索することはありません。作成したドキュメントに限り、コメント、共有、提案を確認できます。それ以上の操作にはDrive全体へのアクセスが必要ですが、その許可は求めません。

自分のコンピューターでは、Driveへのアクセス権があり、Gmailにサインイン済みのアカウントを使って、新しいGoogle Docを作成できます。他のGoogle Docsやコメントは読み取りません。

## 仕事用と個人用

メールと同様に、接続に設定された仕事用または個人用のラベルに従います。仕事用のドキュメントは、[共有ルール](sharing-rules.md)に基づいてチームのGraphに共有される場合があります。個人用のドキュメントが共有されることはありません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選んで、**詳細**から**接続を解除**を押します。以降、読み取りは停止します。すでに取り込んだ内容は残ります。
