## 読み取る内容

**Microsoft OneDrive**は、ホスティング版Machineと自分のコンピューターで、OneDrive内のWordファイルを読み取ります。Outlookを接続する必要はありません。Google Docsについては下記をご覧ください。取り込む内容は次のとおりです。

- Wordファイルのコメントと返信、ファイル内でメンションされているコメント。
- Wordファイルの変更履歴。

初回同期では過去7日分を取り込みます。各項目は、[Graph](graph.md)内の人物やプロジェクトにリンクされます。対応が必要なコメントはToDoになります。

## 共有されたファイル

Microsoftは2026年11月に、こうしたファイルの一覧表示を終了します。それ以降、ファイルの共有や他の人のファイル内でのメンションは、MicrosoftからのメールとしてのみMachineに届きます。[Outlook](microsoft.md)も接続し、メールを有効にしておいてください。メールから作成されたToDoを開くとメールが表示され、メール内のボタンからファイルを開けます。メールが届かない共有やメンションは確認できません。

## できること

ToDoの対応にドキュメントの内容が必要な場合、MachineはそのToDoに対応している間だけ、該当するドキュメントを読み取ります。Word、PDF、テキストファイルを読み取れます。

自分のOneDrive内にあるあらゆる種類のファイルも検索し、リンクを表示します。SharePointのサイトや共有されたファイルは検索しません。スキャンしたPDFのテキストは読み取れません。

コメントへの返信の下書きを作成できます。Wordでは外部から返信を投稿できないため、下書きをWordにコピーしてください。

確認なしに提案を承認したり、コメントを解決したり、ファイルを共有したり、ドキュメントを変更したりすることはありません。

操作だけに使うには、**詳細**の**シグナルを取り込む**をオフにします。すると、ToDoに必要なファイルだけを見つけて読み取り、新しいファイルを作成します。

## ドキュメントの作成と編集

Machineは新しいドキュメントを作成したり、ToDoに関連するドキュメントを変更したりできます。

- ToDoまたはスキルから依頼されると、すぐに新しいドキュメントを作成します。ドキュメントは非公開で、自分のOneDriveまたはGoogle Driveに保存されます。ToDoに**ドキュメントを開く**が表示されます。共有やリンクの送信は、確認を待ってから行います。
- 既存のドキュメントへの変更は、まず準備します。**変更を確認**を押すと、変更前と変更後の段落を確認できます。その後、**保存**を押してください。ToDoのチャットで依頼した変更は、すぐに反映されます。
- 表示された内容のままドキュメントに書き込みます。その間に誰かが変更していた場合は、何も書き込まず、ToDoにそのことを表示します。新しい下書きを依頼してください。
- Talkでは変更内容をすべて読み上げ、明確な同意を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を拒否した場合、ToDoに理由が表示され、再試行するための**確認して作成**が表示されます。

テキストの置き換えや追加、段落や見出しの追加ができます。Google Docsでは、太字、斜体、下線、リンク、見出し、箇条書き、番号付きリスト、改ページの書式設定もできます。**変更を確認**には、変更箇所がそれぞれ表示されます。表は作成できません。画像、変更履歴、フィールドはそのまま残ります。

WorkのToDoのドキュメントは、必ず会社のアカウントに保存され、個人アカウントには保存されません。自分のコンピューターでは、Gmail用に接続済みでDriveへのアクセス権があるGoogleアカウントを、新しいGoogle Docsの保存先にも使えます。Workに使えるアカウントがない場合、ToDoに接続が必要なものが表示されます。Machineで利用できるMicrosoft OneDrive、またはGoogle Docsです。

リンク付きの返信など、ドキュメントの作成が最後の手順ではない場合、ToDoは開いたままになり、その手順の下書きを作成して確認を待ちます。

編集機能は接続時に有効になります。読み取りのみ可能な古い接続には、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 求められる許可

Microsoftから求められる許可は1つです。共有されたファイルも含め、ファイルの読み取りと変更を許可します。変更ごとに、引き続きToDoで確認が必要です。メールやカレンダーへのアクセス権は変わりません。

後から許可を取り消すと、Microsoft OneDriveの**接続**に**ドキュメントを読む許可待ち**と表示されます。

## 接続する

ホスティング版Machine、またはアカウントとペアリングした自分のコンピューターで、次の手順を行います。

- **接続**を開き、**ドキュメントとファイル**を選んで、**Microsoft OneDrive**を選びます。
- **Microsoftでログイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押したときにMicrosoftが編集を許可しない場合は、そのことが表示されます。

## Google Docs

ホスティング版Machineで、**接続**を開き、**ドキュメントとファイル**を選んで、**Google Docs**を選びます。Googleから、指定したドキュメントの表示と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセス権も変わりません。

接続すると、Machineは次のことができます。

- ToDoのメッセージにリンクされたGoogle Doc、またはチャットに貼り付けられたGoogle Docを、そのToDoに対応している間だけ読み取ります。
- そのドキュメントへの変更を準備します。上記のとおり、変更ごとに確認が必要です。
- Google Driveに非公開の新しいドキュメントを作成します。

Driveは検索しません。コメント、共有、提案を確認できるのは、Machineが作成したドキュメントだけです。Drive全体へのアクセスが必要になるため、それ以上のアクセスは求めません。

## Google Sheets と Slides

**接続**でGoogle Docsに**Sheets と Slides を許可する**が表示されたら、押して両方を許可します。Googleから、MachineがSheetsとSlidesのファイルを表示できるよう許可を求められます。ファイルは変更できません。

許可すると、MachineはToDoのメッセージにリンクされたGoogle SheetまたはSlidesファイル、またはチャットに貼り付けられたファイルも、そのToDoに対応している間だけ読み取ります。

- シートでは、まずリンクされたタブまたはセルを読み取り、次に他のタブを読み取ります。最大2,000セルです。数式は計算結果として表示されます。非表示のタブは、リンクされている場合または依頼された場合のみ読み取ります。
- スライドでは、テキストとスピーカーノートを順番に読み取ります。画像とグラフは読み取りません。

### Sheets と Slides の編集

読み取りを許可すると、Google Docsに**Sheets と Slides の編集を許可**が表示される場合があります。押して両方を許可すると、MachineはリンクされたSheetまたはSlidesファイルをドキュメントと同じ方法で変更できます。変更は準備され、**変更を確認**で確認できます。**保存**を押すまで書き込みは行われません。

- シートでは、タブ内のセルへの新しい値の入力、最終行の下への行の追加、または新しいタブの追加ができます。セルごとに変更前と変更後が表示されます。値はテキストとして入力されます。ToDoで指示された場合のみ、数式として入力されます。
- スライドでは、1枚のスライド上のテキストを置き換えるか、タイトルとテキストを含む新しいスライドを作成できます。変更前と変更後が表示されます。
- 表示された内容のままファイルに書き込みます。その間に誰かがセルやスライドを変更していた場合は、何も書き込まず、ToDoにそのことを表示します。

書式、グラフ、画像、Excelファイル、PowerPointファイルは変更されません。

大きなファイルの場合は、チャットで対象のタブ、セル、スライドを指定してください。ファイルが他の人のみに公開されている場合、削除されている場合、またはExcelファイルやPowerPointファイルの場合は、ToDoにそのことが表示されます。Google Driveのリンクも、Google Doc、Sheet、Slidesファイルであれば同じように機能します。

## 自分のコンピューターで使うGoogle Docs

自分のコンピューターでは、Driveへのアクセス権があるGmailアカウントにログインしていれば、Machineはそのアカウントに新しいGoogle Docを作成できます。他のGoogle Docsやそのコメントは読み取りません。**ドキュメントとファイル**には、そのアカウントのGoogle Docsとして表示されます。ToDo用にそこで作成したドキュメントを変更することもできます。

GoogleへのログインにDrive、Sheets、またはSlidesへのアクセス権がすでにある場合は、ToDoにリンクされたGoogle SheetまたはSlidesファイル、またはチャットに貼り付けられたファイルも読み取ります。Googleに追加のアクセス権を求めたり、ファイルを変更したりすることはありません。Googleがアクセスを拒否する場合は、そのログイン用のGoogleプロジェクトでGoogle SheetsまたはSlides APIを有効にしてください。

## 仕事用または個人用

メールと同じように、接続に設定されたWorkまたはPersonalのラベルに従います。Workのドキュメントは、[共有ルール](sharing-rules.md)に基づいてチームのGraphに届く場合があります。PersonalのドキュメントがGraphに届くことはありません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選んで、**詳細**から**接続を解除**します。読み取りは停止します。すでに取り込まれた内容は残ります。ホスティング版Machineでは、**接続を解除 ↗**を押すと、サインイン情報が保存されている設定ページが開きます。
