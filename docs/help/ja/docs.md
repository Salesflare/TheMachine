## 読み取る内容

**Microsoft OneDrive**は、ホスティング版Machineと自分のコンピューターで、OneDrive内のWordファイルを読み取ります。Outlookを接続する必要はありません。Google Docsについては、下記をご覧ください。次の情報を取り込みます。

- Wordファイルのコメントと返信、自分へのメンションを含むコメント。
- Wordファイルの変更履歴。

最初の同期では、過去7日分を取得します。各項目は、[Graph](graph.md)内の人物やプロジェクトにリンクされます。対応が必要なコメントはToDoになります。

## 他の人が共有したファイル

Microsoftは2026年11月に、共有されたファイルを一覧に表示しなくなります。その後、共有や他の人のファイル内でのメンションは、MicrosoftからのメールとしてのみMachineに届きます。[Outlook](microsoft.md)も接続し、メールをオンにしておいてください。メールから作成されたToDoを開くとメールが表示され、メール内のボタンからファイルを開けます。メールが届かない共有やメンションは確認できません。

## できること

ToDoでドキュメントの本文が必要な場合、MachineはそのToDoに対応している間だけ、対象のドキュメントを読み取ります。Word、PDF、テキストファイルを読み取れます。

自分のOneDrive内のあらゆる種類のファイルも探し、リンクを表示します。SharePointのサイトや共有されたファイルは検索しません。スキャンしたPDFの文字は読み取れません。

コメントへの返信の下書きを作成できます。Wordには外部から返信を投稿する方法がないため、下書きをWordにコピーしてください。

許可なく提案を承認したり、コメントを解決したり、ファイルを共有したり、ドキュメントを変更したりすることはありません。

操作だけに使うには、**詳細**の**シグナルを取り込む**をオフにしてください。以降は、ToDoに必要なファイルだけを探して読み取り、新しいファイルを作成します。

## ドキュメントの作成と編集

Machineは新しいドキュメントを作成したり、ToDoに関連するドキュメントを変更したりできます。

- ToDoやスキルから依頼された場合、新しいドキュメントをすぐに作成します。自分のOneDriveまたはGoogle Drive内に、非公開で保存されます。ToDoに**ドキュメントを開く**が表示されます。共有したりリンクを送信したりするには、許可が必要です。
- 既存のドキュメントへの変更は、まず下書きとして準備します。**変更を確認**を押すと、変更前と変更後の各段落を確認できます。確認後、**保存**を押してください。ToDoのチャットで依頼した変更は、すぐに反映されます。
- 確認した時点のドキュメントにのみ書き込みます。その間に誰かが変更していた場合、書き込みは行わず、ToDoにその旨が表示されます。新しい下書きを依頼してください。
- Talkでは、変更内容全体を読み上げ、明確な許可を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を拒否した場合、ToDoに理由が表示され、再試行用の**確認して作成**が表示されます。

テキストの置き換えや追加、段落や見出しの追加ができます。Google Docsでは、太字、斜体、下線、リンク、見出し、箇条書きと番号付きリスト、改ページの書式設定もできます。**変更を確認**には、それぞれの変更が表示されます。表は作成できません。画像、変更履歴、フィールドはそのまま残ります。

WorkのToDoのドキュメントは、その会社のアカウントに保存され、個人アカウントには保存されません。自分のコンピューターでは、Driveへのアクセス権があるGmail用のGoogleアカウントを接続している場合、新しいGoogle Docsも作成できます。利用できるアカウントがない場合、Workで使うために接続するものがToDoに表示されます。Microsoft OneDrive、またはMachineで利用できる場合はGoogle Docsです。

返信とリンクの送信のように、ドキュメントの作成が最後の手順ではない場合、ToDoは開いたままになり、その手順の下書きを作成して許可を待ちます。

接続すると編集機能も使えるようになります。読み取りのみ可能な以前の接続には、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 求められる許可

Microsoftは、共有されたファイルを含むファイルの読み取りと変更について、一度だけ許可を求めます。変更ごとに、引き続きToDoで許可が必要です。メールとカレンダーへのアクセス権は変わりません。

後から許可を取り消すと、Microsoft OneDriveの**接続**に**ドキュメントを読む許可待ち**と表示されます。

## 接続する

ホスティング版Machine、またはアカウントとペアリングした自分のコンピューターで、次の手順を行います。

- **接続**を開き、**ドキュメントとファイル**を選んで、**Microsoft OneDrive**を選択します。
- **Microsoft でログイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押してもMicrosoftが編集を許可しない場合は、その旨が表示されます。

## Google Docs

ホスティング版Machineで、**接続**を開き、**ドキュメントとファイル**を選んで、**Google Docs**を選択します。Googleから、指定したドキュメントの閲覧と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセス権も変わりません。

接続すると、Machineは次の操作を行います。

- ToDoのメッセージにリンクされたGoogle Doc、またはチャットに貼り付けられたGoogle Docを、そのToDoに対応している間だけ読み取ります。
- そのドキュメントへの変更を準備します。上記のとおり、変更ごとに許可が必要です。
- 自分のGoogle Drive内に、非公開の新しいドキュメントを作成します。

ToDoのエリアに複数のGoogle Docs接続がある場合、ファイルを開けて変更できる接続を使って、ファイルを読み取り、変更します。

Driveは検索しません。コメント、共有、提案を確認できるのは、Machineが作成したドキュメントのみです。これらをすべて確認するにはDrive全体へのアクセスが必要ですが、その許可を求めることはありません。

## Google Sheets と Slides

**接続**のGoogle Docsに**Sheets と Slides を許可する**が表示されたら、押して両方を許可してください。Googleから、SheetsとSlidesのファイルをMachineが閲覧する許可を求められます。ファイルの変更はできません。

許可すると、MachineはToDoのメッセージにリンクされた、またはチャットに貼り付けられたGoogle SheetsやSlidesのファイルも、そのToDoに対応している間だけ読み取ります。

- スプレッドシートでは、リンクされたタブやセルを先に読み取り、その後ほかのタブを2,000セルまで読み取ります。数式は計算結果として表示されます。非表示のタブは、リンクされている場合、または指定された場合のみ読み取ります。
- スライドでは、テキストと発表者のメモを順に読み取ります。画像とグラフは読み取りません。

### Sheets と Slides の編集

Machineがこれらを読み取れるようになると、Google Docsに**Sheets と Slides の編集を許可**が表示される場合があります。押して両方を許可すると、ToDoにリンクされた、またはチャットに貼り付けられたSheetsやSlidesのファイルを変更できます。ドキュメントと同じように、変更は準備のみ行います。**変更を確認**で変更内容を確認でき、**保存**を押すまで書き込みは行われません。

- スプレッドシートでは、タブ内のセルへの値の入力、最後の行の下への行の追加、新しいタブの作成ができます。各セルに変更前と変更後が表示されます。値はテキストとして入力されます。ToDoで指示された場合のみ、数式として入力されます。
- スライドでは、1枚のスライドのテキストを置き換えるか、タイトルとテキストを含む新しいスライドを作成できます。変更前と変更後が表示されます。
- 確認した時点のファイルにのみ書き込みます。その間に誰かが対象のセルやスライドを変更していた場合、書き込みは行わず、ToDoにその旨が表示されます。

書式、グラフ、画像、ExcelやPowerPointのファイルはそのまま残ります。

大きなファイルの場合は、チャットで対象のタブ、セル、スライドを指定してください。ファイルが他の人にのみ共有されている場合、削除されている場合、またはExcelやPowerPointのファイルの場合は、ToDoにその旨が表示されます。Google Driveのリンクも、Google Doc、Sheet、Slidesのファイルであれば同じように機能します。

## 自分のコンピューターで使うGoogle Docs

自分のコンピューターでは、Driveへのアクセス権がすでにあるGmailアカウントにログインしている場合、そのアカウントでMachineが新しいGoogle Docを作成できます。他のGoogle Docsやそのコメントは読み取りません。**ドキュメントとファイル**には、そのアカウントのGoogle Docsとして表示されます。ToDoのためにそこで作成したドキュメントを変更することもできます。

GoogleのログインにDrive、Sheets、Slidesへのアクセス権がすでにある場合、ToDoにリンクされた、またはチャットに貼り付けられたGoogle SheetsやSlidesのファイルも読み取ります。Googleに追加の許可を求めることはなく、これらのファイルを変更することもありません。Googleに拒否された場合は、そのログインで使うGoogleプロジェクトのGoogle Sheets APIまたはSlides APIを有効にしてください。

## Work と Personal

メールと同様に、接続に設定されたWorkまたはPersonalのラベルに従います。Workのドキュメントは、[共有ルール](sharing-rules.md)に従ってチームのGraphに表示される場合があります。Personalのドキュメントは表示されません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選び、**詳細**から**接続を解除**を押します。読み取りが停止します。すでに取り込んだ情報は残ります。ホスティング版Machineでは、**接続を解除 ↗**を押すと、ログイン情報を管理するセットアップページが開きます。
