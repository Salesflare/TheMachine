## 読み取る情報

**Microsoft OneDrive**は、ホスティング版Machineと自分のコンピューターで、OneDrive内のWordファイルを読み取ります。Outlookを接続する必要はありません。Google Docsについては下記をご覧ください。次の情報を取り込みます。

- Wordファイルのコメントと返信、自分へのメンションを含むコメント。
- Wordファイルの変更履歴。

初回同期では過去7日分を取り込みます。各項目は、[Graph](graph.md)内の人物やプロジェクトとつながります。対応が必要なコメントはToDoになります。

## 他の人が共有したファイル

Microsoftは2026年11月に、これらのファイルの一覧表示を終了します。他の人が共有したファイルや、他の人のファイル内でのメンションは、MicrosoftからのメールとしてのみMachineに届くようになります。[Outlook](microsoft.md)も接続し、これらのメールを受信できる状態にしてください。そのメールから作られたToDoを開くとメールが表示され、メール内のボタンからファイルを開けます。メールが届かない共有やメンションは確認できません。

## できること

ToDoでドキュメントの内容が必要になると、そのToDoに取り組んでいる間だけ、Machineが該当するドキュメントを読み取ります。Word、PDF、テキストファイルを読み取れます。

自分のOneDrive内にある種類を問わないファイルも検索し、リンクを表示します。SharePointのサイトや共有されたファイルは検索しません。スキャンしたPDFのテキストは読み取れません。

コメントへの返信案を作成できます。Wordでは外部から返信を投稿できないため、返信案をWordにコピーしてください。

許可なく提案を承認したり、コメントを解決したり、ファイルを共有したり、ドキュメントを変更したりすることはありません。

操作だけに使うには、**詳細**の**シグナルを取り込む**をオフにします。すると、ToDoに必要なファイルだけを見つけて読み取り、新しいファイルを作成します。

## ドキュメントの作成と編集

Machineは新しいドキュメントを作成したり、ToDoに関連するドキュメントを変更したりできます。

- ToDoやスキルから依頼された場合、新しいドキュメントをすぐに作成します。自分のOneDriveまたはGoogle Drive内に作成され、非公開になります。ToDoに**ドキュメントを開く**が表示されます。共有したりリンクを送ったりするには、事前に許可が必要です。
- 既存のドキュメントへの変更は、まず準備します。**変更を確認**を押すと、各段落の変更前と変更後を確認できます。その後、**保存**を押してください。ToDoのチャットで依頼した変更は、すぐに反映します。
- 表示されていた内容に対してのみ変更を書き込みます。その間に誰かが変更していた場合、書き込みは行わず、ToDoでその旨を知らせます。新しい下書きを依頼してください。
- Talkでは、変更内容をすべて読み上げ、はっきりとした「はい」の返事を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を拒否した場合、ToDoに理由が表示され、再試行するための**確認して作成**が表示されます。

テキストの置き換えや追加、段落や見出しの追加ができます。表、画像、変更履歴、フィールドはそのまま残ります。

仕事用ToDoのドキュメントは、その会社のアカウントに保存され、個人アカウントには保存されません。自分のコンピューターでは、Gmail用に接続され、Driveへのアクセス権があるGoogleアカウントに、新しいGoogle Docsを作成することもできます。該当するアカウントがない場合、仕事用に接続するものとして、Microsoft OneDriveまたはMachineで利用できるGoogle DocsをToDoが案内します。

ドキュメントが最後の手順ではない場合、たとえばリンク付きの返信を送る場合は、ToDoは開いたままになり、その手順の下書きを作成して許可を待ちます。

編集機能は接続時に利用できます。読み取りのみ可能な古い接続には、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 必要な許可

Microsoftから求められる許可は1つです。共有されたファイルも含め、ファイルの読み取りと変更を許可します。変更ごとに、該当するToDoで許可が必要です。メールとカレンダーへのアクセスには影響しません。

後からこの許可を取り消すと、Microsoft OneDriveの**接続**に**ドキュメントを読む許可待ち**と表示されます。

## 接続する

ホスティング版Machine、またはアカウントとペアリングした自分のコンピューターで、次の操作をします。

- **接続**を開き、**ドキュメントとファイル**から**Microsoft OneDrive**を選びます。
- **Microsoftでサインイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押した後、Microsoftが編集を許可しない場合は、その旨が表示されます。

## Google Docs

ホスティング版Machineで、**接続**を開き、**ドキュメントとファイル**から**Google Docs**を選びます。Googleから、指定したドキュメントの表示と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセスにも影響しません。

接続すると、Machineは次の操作ができます。

- ToDoのメッセージにリンクされたGoogle Docsを、そのToDoに取り組んでいる間だけ読み取ります。
- そのドキュメントへの変更を準備します。上記と同様に、変更ごとに許可が必要です。
- Google Drive内に新しい非公開ドキュメントを作成します。

Driveは検索しません。Machineが作成したドキュメントのコメント、共有、提案のみ確認できます。それ以外の情報にはDrive全体へのアクセスが必要ですが、その許可を求めることはありません。

自分のコンピューターでは、すでにDriveへのアクセス権があるGmailアカウントにサインインしていれば、そのアカウントに新しいGoogle Docsを作成できます。他のGoogle Docsやそのコメントは読み取りません。**ドキュメントとファイル**には、そのアカウントのGoogle Docsとして表示されます。そのアカウントに作成したドキュメントを、ToDoのために変更することもできます。

## 仕事用と個人用

メールと同様に、接続の「仕事用」または「個人用」ラベルに従います。仕事用のドキュメントは、[共有ルール](sharing-rules.md)に基づいてチームのGraphに届くことがあります。個人用のドキュメントがGraphに届くことはありません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選んで、**詳細**から**接続を解除**します。読み取りは停止します。すでに取り込んだ情報は残ります。ホスティング版Machineでは、**接続を解除 ↗**を押すと、サインイン情報が保存されている設定ページが開きます。
