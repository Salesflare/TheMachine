## 読み取る内容

**Microsoft OneDrive** は、ホスティング版Machineと自分のコンピューターで、OneDrive 内の Word ファイルを読み取ります。Outlookを接続する必要はありません。Google Docsについては、下記をご覧ください。取り込む内容は次のとおりです。

- Word ファイルのコメントと返信、自分へのメンションを含むコメント
- Word ファイルの変更履歴

最初の同期では、過去7日分を取り込みます。各項目は、[Graph](graph.md) 内の人物やプロジェクトにリンクされます。対応が必要なコメントはToDoになります。

## 他の人から共有されたファイル

Microsoftは2026年11月に、これらのファイルの一覧表示を終了します。他の人から共有されたファイルや、他の人のファイルでのメンションは、以降MicrosoftからのメールでのみMachineに届きます。[Outlook](microsoft.md)も接続し、メールを受信できる状態にしてください。メールから作成されたToDoを開くとメールが表示され、メール内のボタンからファイルを開けます。メールが届かない共有やメンションは確認できません。

## できること

ToDoでドキュメントの内容が必要になると、MachineはそのToDoに取り組んでいる間だけ、該当するドキュメントを読み取ります。Word、PDF、テキストファイルを読み取れます。

自分のOneDrive内にあるファイルは、種類を問わず検索し、リンクを表示できます。SharePointのサイトや共有されたファイルは検索しません。スキャンしたPDFの文字は読み取れません。

コメントへの返信を下書きできます。Wordでは外部から返信を投稿できないため、下書きをWordにコピーしてください。

確認なしに提案を承認したり、コメントを解決したり、ファイルを共有したり、ドキュメントを変更したりすることはありません。

作業だけに使うには、**詳細**の**シグナルを取り込む**をオフにしてください。その場合、ToDoに必要なファイルだけを見つけて読み取り、新しいファイルを作成します。

## ドキュメントの作成と編集

Machineは新しいドキュメントを作成したり、ToDoに関連するドキュメントを変更したりできます。

- ToDoまたはスキルから依頼されると、新しいドキュメントをすぐに作成します。自分のOneDriveまたはGoogle Driveに保存され、非公開です。ToDoには**ドキュメントを開く**が表示されます。共有したりリンクを送ったりするには、確認が必要です。
- 既存のドキュメントへの変更は、まず準備します。**変更を確認**を押すと、変更前後の段落を確認できます。確認後、**保存**を押してください。ToDoのチャットで依頼した変更は、すぐに反映されます。
- 読み取った時点のドキュメントにだけ書き込みます。その後に誰かが変更していた場合、書き込みは行われず、ToDoにその旨が表示されます。新しい下書きを依頼してください。
- Talkでは、変更内容をすべて読み上げ、明確な「はい」を待ちます。
- MicrosoftまたはGoogleが新しいドキュメントの作成を許可しない場合、理由をToDoに表示し、再試行するための**確認して作成**が表示されます。

テキストの置き換えや追加、段落や見出しの追加ができます。Google Docsでは、太字、斜体、下線、リンク、見出し、箇条書き、番号付きリスト、改ページの書式設定もできます。**変更を確認**には、それぞれの変更が表示されます。表は作成できません。画像、変更履歴、フィールドはそのまま残ります。

WorkのToDoのドキュメントは、その会社のアカウントに保存され、個人用アカウントには保存されません。自分のコンピューターでは、DriveにアクセスできるGmail用のGoogleアカウントを接続している場合、新しいGoogle Docsも作成できます。適切なアカウントがない場合、Workで使うにはMicrosoft OneDrive、またはMachineで利用できるGoogle Docsを接続するようToDoに表示されます。

リンクを添えた返信など、ドキュメントの作成が最後の手順ではない場合、ToDoは開いたままになり、その手順の下書きを作成して確認を待ちます。

接続すると編集機能も使えるようになります。読み取り専用の古い接続には、**接続**に**編集を許可**が表示されます。一度押して、許可してください。

## 必要な許可

Microsoftから求められる許可は1つです。共有されたファイルも含め、ファイルの読み取りと変更を許可します。変更ごとに、引き続きToDoで確認が必要です。メールやカレンダーへのアクセス権は変わりません。

後から許可を取り消すと、Microsoft OneDriveの**接続**に**ドキュメントを読む許可待ち**と表示されます。

## 接続する

ホスティング版Machine、またはアカウントとペアリングした自分のコンピューターで、次の手順を行います。

- **接続**を開き、**ドキュメントとファイル**を選んで、**Microsoft OneDrive**を選択します。
- **Microsoftでログイン**を押し、ファイルの読み取りと編集を許可します。

Microsoftが読み取りを許可しない場合、接続は追加されません。**編集を許可**を押してMicrosoftが編集を許可しない場合は、その旨が表示されます。

## Google Docs

ホスティング版Machineで、**接続**を開き、**ドキュメントとファイル**を選んで、**Google Docs**を選択します。Googleから、指定したドキュメントの表示と編集、新しいドキュメントの作成を許可するよう求められます。Gmailを接続する必要はなく、Gmailへのアクセス権も変わりません。

接続すると、Machineは次のことを行います。

- ToDoのメッセージにリンクされたGoogleドキュメント、またはチャットに貼り付けられたGoogleドキュメントを、そのToDoに取り組んでいる間だけ読み取ります。
- そのドキュメントへの変更を準備します。前述のとおり、変更ごとに確認が必要です。
- Google Driveに新しいドキュメントを非公開で作成します。

Driveは検索しません。自分が作成したドキュメントのコメント、共有、提案のみ確認できます。Drive全体へのアクセスが必要になるため、それ以上のアクセスは求めません。

## Google Sheets と Slides

**接続**のGoogle Docsに**Sheets と Slides を許可する**が表示されたら、それを押して両方を許可してください。Googleから、MachineによるSheetsとSlidesのファイルの表示を許可するよう求められます。変更はできません。

許可すると、MachineはToDoのメッセージにリンクされたGoogle SheetsまたはSlidesのファイル、またはチャットに貼り付けられたファイルも、そのToDoに取り組んでいる間だけ読み取ります。

- スプレッドシートでは、まずリンクされたタブまたはセルを読み取り、その後ほかのタブを読み取ります。読み取れるのは最大2,000セルです。数式は計算結果として表示されます。非表示のタブは、リンクされている場合、または指定された場合にのみ読み取ります。
- スライドでは、テキストとスピーカーノートを順番に読み取ります。画像やグラフは読み取りません。

ファイルが大きい場合は、チャットで対象のタブ、セル、スライドを指定してください。ファイルが他の人だけに公開されている場合、削除されている場合、またはExcelやPowerPointのファイルの場合は、その旨がToDoに表示されます。Google Driveのリンク先がGoogle Docs、Sheets、Slidesのファイルの場合も同じように扱われます。

## 自分のコンピューターで使うGoogle Docs

自分のコンピューターでは、Driveにすでにアクセスできる、ログイン済みのGmailアカウントに新しいGoogleドキュメントを作成できます。他のGoogleドキュメントやそのコメントは読み取りません。**ドキュメントとファイル**には、そのアカウントのGoogle Docsとして表示されます。そこで作成したドキュメントを、ToDoのために変更することもできます。

Googleのログイン済みアカウントがDrive、Sheets、Slidesにすでにアクセスできる場合、ToDoにリンクされたGoogle SheetsまたはSlidesのファイル、またはチャットに貼り付けられたファイルも読み取ります。Googleに追加の許可を求めることはありません。Googleに拒否された場合は、そのログインアカウントのGoogleプロジェクトでGoogle Sheets APIまたはSlides APIを有効にしてください。

## 仕事用または個人用

メールと同様に、接続に設定された仕事用または個人用のラベルに従います。仕事用のドキュメントは、[共有ルール](sharing-rules.md)に基づいてチームのGraphに反映されることがあります。個人用のドキュメントは反映されません。

## 接続を解除する

**接続**を開き、Microsoft OneDriveまたはGoogle Docsを選び、**詳細**から**接続を解除**を押します。読み取りは停止します。すでに取り込まれた内容は残ります。ホスティング版Machineでは、**接続を解除 ↗**を押すと、ログイン情報が保存されているセットアップページが開きます。
