## Configúralas

En la pestaña **Fleet**, abre Compartir. Cada tipo de pregunta tiene una regla:

- Pregúntame antes: ves cada pregunta y decides tú.
- Siempre: tu Machine responde sola.
- Nunca: la rechaza.
- Nombres: solo nombres, sin detalles.

Nunca comparte el contenido de los correos ni de qué tratan tus reuniones. "¿Diferente para alguien? Añade una excepción" fija una regla para una persona.

Las reglas solo cambian en el panel, nunca desde un mensaje.

## La primera vez que alguien pregunta

Una pregunta que te necesita llega como tarea, con **Compartir una vez**, **Compartir siempre**, **Rechazar** o **No compartir nunca**.
