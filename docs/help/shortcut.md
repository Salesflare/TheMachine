## What it reads

Stories in your Shortcut workspace that change state, with their owners and deadlines.

## What it can do

Nothing. It only reads, even though a Shortcut token allows more.

## Connect it

1. On a hosted Machine: open your setup page at app.themachine.computer/setup, go to **More sources** and open Shortcut. On your own computer: **Connections**, **Projects and code**, Shortcut, or `assistant connect shortcut`.
2. Press **Get your token**. Shortcut opens its API Tokens page in a new tab: create a token and copy it.
3. Paste it and press **Connect**. It checks the token right away and shows who it connected as, in which workspace.

In more than one Shortcut workspace? A token belongs to one workspace, so switch to that one in Shortcut first.

## Remove it

- In the dashboard: **Connections**, open Shortcut, **Details**, then **Disconnect**. What it already brought in stays.
- On a hosted Machine you can also press **Remove** next to it on your setup page.

## Revoke it in Shortcut

Delete the token on the same API Tokens page.
