## Open it

On a phone, tap the to-do's title. On a computer, use the to-do's chat link or **See in chat ›**. On a computer, clicking the title renames the to-do.

## What to ask

- About the thread, the people or the background: "What did they ask last time?"
- To change the draft: "Make it shorter" or "Mention the new date".

A question gets an answer and leaves the draft as it is. Approvals stay on the to-do's buttons: chat never sends a draft in the same reply that wrote it.

On a computer, Enter or Ctrl+Enter (Cmd+Enter on a Mac) sends and Shift+Enter starts a new line. On a phone, use the send button.

## Stop a reply

While a reply is being written, the send button turns into **Stop**. Stop ends it right away and keeps what it wrote so far, marked **Stopped**. Write a new message to carry on, or tap **Try again**.

## Add files

Tap the paperclip, paste a screenshot, or drop files on the chat. Each file shows above the message box, and × takes it back. A message can be only files.

- Images (PNG, JPEG, GIF, WebP) up to 5 MB go to the model as images.
- PDFs, text, CSV, JSON and Office files up to 10 MB are files The Machine reads, and can attach to a draft.
- Up to 5 files per message.

Files stay on your Machine, in its data folder, encrypted like your messages. Files you add but never send are removed after a day.
