Une Machine hébergée fonctionne dans le cloud, dans l’UE, rien que pour vous. Nous veillons à ce qu’elle reste opérationnelle et à jour.

## Inscription

1. Sur app.themachine.computer, appuyez sur **Continuer avec Google** ou **Continuer avec Microsoft**. Votre compte est alors créé. Avec Google, le même écran vous demande aussi l’accès à Gmail et à Google Agenda. Autorisez-les pour connecter votre messagerie, sans passer par un deuxième écran Google.
2. Choisissez la taille et l’adresse de votre Machine. Les {trial_days} premiers jours sont gratuits et aucun paiement ne sera prélevé avant la fin de cette période. Si la configuration ne vous demande pas de carte bancaire, ajoutez-en une sur la page de votre compte avant la fin de la période.
3. Appuyez sur **Ajouter une clé d’accès**, puis utilisez votre empreinte digitale, votre visage ou le code PIN de votre appareil. Vous préférez une application d’authentification ? Ouvrez **Utiliser plutôt une application d’authentification**, scannez le code, saisissez les six chiffres et appuyez sur **Activer**. Enregistrez les codes de récupération qui s’affichent ensuite.

## Votre page de configuration

La configuration se fait en une étape par écran : votre forfait, votre clé d’accès, puis **Messagerie et agenda** et **Votre IA**. En haut de l’écran, vous voyez à quelle étape vous êtes. Votre Machine démarre en arrière-plan, vous n’avez donc jamais à attendre.

1. **Messagerie et agenda** : appuyez sur **Connecter Google** ou **Connecter Microsoft**. La configuration commence avec le compte que vous avez utilisé pour vous inscrire. Vous avez autorisé Gmail et Google Agenda lors de votre inscription avec Google ? La configuration ignore cette étape et passe à votre IA. Le type de compte, professionnel ou personnel, dépend de l’adresse. Vous pourrez le modifier plus tard dans votre compte. Consultez [Gmail](gmail.md) et [Microsoft](microsoft.md).
2. **Votre IA** : connectez-vous avec ChatGPT ou Claude, ou collez une clé de votre fournisseur d’IA. Avec Claude, collez le code affiché sur la page de Claude. Vous n’avez pas d’abonnement ? Inscrivez-vous à ChatGPT ou à Claude, ou utilisez une clé : cette étape contient un lien vers la page de clés de chaque fournisseur, qui vous facture selon votre utilisation. Consultez [ChatGPT](chatgpt.md).
**Retour** et le bouton Précédent de votre navigateur vous ramènent à l’étape précédente. Une fois votre messagerie et votre IA opérationnelles, vous arrivez sur votre tableau de bord.

Vos premières tâches s’affichent alors : votre Machine vérifie d’abord vos e-mails les plus récents, puis ceux des 7 derniers jours. Si rien ne requiert votre attention, elle vous indique ce qu’elle a lu et ce qu’il faut connecter ensuite. Si une vérification échoue, elle est relancée dans les minutes qui suivent. Si elle échoue encore, la liste vous le signale.

La configuration ne vous demande rien de facultatif. Ensuite, **Ajouter à tout moment** sur la page de configuration vous donne accès à **Plus de sources**, comme Slack, WhatsApp, GitHub, [Telegram](telegram.md) et [Codex](hand-to-agent.md). Votre tableau de bord vous en suggère aussi une lorsque c’est utile, par exemple GitHub si ses e-mails continuent d’arriver.

Quand votre Machine est prête, **Ouvrir votre tableau de bord** s’affiche en haut de la page. **Ajouter à Claude** vous permet de poser des questions à Claude sur vos e-mails et vos tâches. Pour recevoir des notifications, ajoutez The Machine à l’écran d’accueil de votre téléphone : consultez [Installer l’app et activer les notifications](phone-app.md).

## Demander une source

Il vous manque une source ? Dans **Sources**, sous **Demander une source**, indiquez le service et ce que vous souhaitez lire, puis appuyez sur **Créer**. Votre propre IA la crée et la teste sur votre Machine. Si vous choisissez de la partager, The Machine la propose à tout le monde sur GitHub pour vous. Aucun compte GitHub n’est nécessaire ; [connectez GitHub](github.md) pour que votre contribution vous soit attribuée.

## Revenir plus tard

Votre page de configuration reste accessible à app.themachine.computer/setup. Vous pouvez y ajouter ou supprimer des sources à tout moment. Dans le tableau de bord, **Paramètres** contient **Ouvrir le compte**.
