Une Machine hébergée tourne sur son propre serveur privé dans l’UE. Nous la maintenons en marche et à jour.

## Inscription

1. Sur app.themachine.computer, appuyez sur **Continuer avec Google** ou **Continuer avec Microsoft**. Cela crée votre compte.
2. Scannez le code avec une app d’authentification, tapez les six chiffres et appuyez sur **Activer**. Une clé d’accès peut venir plus tard.
3. Choisissez une taille de serveur et le nom de votre Machine, puis ajoutez votre carte de paiement. Les {trial_days} premiers jours sont gratuits et rien n’est prélevé avant la fin.

## Votre page de configuration

Votre serveur démarre, puis la page de configuration vous guide pour le reste, une étape à la fois :

1. **E-mail et agenda** : connectez Google ou Microsoft. Vous pouvez le faire pendant que votre serveur démarre. Voir [Gmail](gmail.md) et [Microsoft](microsoft.md).
2. **Votre modèle** : connectez-vous avec ChatGPT ou utilisez votre propre clé. Voir [ChatGPT](chatgpt.md).
3. Les vérifications s’activent d’elles-mêmes. Les premières tâches viennent de vos e-mails les plus récents, puis de vos 7 derniers jours.

Sous **Ajoutez-en d’autres à tout moment** se trouvent les options : **Plus de sources** comme Slack, WhatsApp ou GitHub, [Telegram](telegram.md), [Codex](hand-to-agent.md) et la connexion de votre navigateur. Aucune n’est nécessaire pour commencer. Votre tableau de bord les suggère quand elles sont utiles, par exemple GitHub dès que ses e-mails continuent d’arriver.

Quand c’est prêt, appuyez sur **Ouvrir votre tableau de bord**. Ajoutez-le à l’écran d’accueil de votre téléphone pour les notifications : voir [Installer l’app et activer les notifications](phone-app.md).

## Revenir plus tard

Votre page de configuration reste sur app.themachine.computer/setup. Ajoutez ou retirez des sources à tout moment. Dans le tableau de bord, **Paramètres** a **Ouvrir le compte**.
