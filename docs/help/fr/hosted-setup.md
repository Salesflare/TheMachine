Une Machine hébergée fonctionne dans le cloud, dans l’UE, rien que pour vous. Nous la maintenons en fonctionnement et à jour.

## Inscription

1. Sur app.themachine.computer, appuyez sur **Continuer avec Google** ou **Continuer avec Microsoft**. Votre compte sera créé. Avec Google, le même écran vous demande l’accès à Gmail et Calendar. Autorisez-les pour connecter votre messagerie, sans passer par un deuxième écran Google.
2. Choisissez la taille et l’adresse de votre Machine. Les {trial_days} premiers jours sont gratuits et rien ne vous sera facturé avant la fin de cette période. Si la configuration ne vous demande pas de carte bancaire, ajoutez-en une sur la page de votre compte avant la fin de cette période.
3. Appuyez sur **Ajouter une clé d’accès**, puis utilisez votre empreinte digitale, votre visage ou le code PIN de votre appareil. Vous préférez une application d’authentification ? Ouvrez **Utiliser plutôt une application d’authentification**, scannez le code, saisissez les six chiffres et appuyez sur **Activer**. Enregistrez les codes de récupération qui s’affichent ensuite.

## Page de configuration

La configuration se fait en plusieurs étapes, chacune sur un écran : votre forfait, votre clé d’accès, puis **Messagerie et calendrier**, **Votre IA** et **Premières tâches**. En haut, vous voyez à quelle étape vous êtes. Votre Machine démarre en arrière-plan, vous n’avez donc jamais à attendre.

1. **Messagerie et calendrier** : appuyez sur **Connecter Google** ou **Connecter Microsoft**. L’étape commence avec le compte utilisé pour votre inscription. Vous avez autorisé Gmail et Calendar lors de votre inscription avec Google ? La configuration passe alors cette étape et continue avec votre IA. Le type de compte, professionnel ou personnel, est déterminé par l’adresse. Vous pourrez le modifier plus tard dans votre compte. Consultez [Gmail](gmail.md) et [Microsoft](microsoft.md).
2. **Votre IA** : connectez-vous avec ChatGPT ou Claude, ou collez une clé fournie par votre fournisseur d’IA. Avec Claude, collez le code de la page Claude. Vous n’avez pas d’abonnement ? Prenez-en un pour ChatGPT ou Claude, ou utilisez une clé. L’étape contient un lien vers la page des clés de chaque fournisseur, qui vous facture selon votre utilisation. Consultez [ChatGPT](chatgpt.md).
3. **Premières tâches** : votre Machine vérifie d’abord vos e-mails les plus récents, puis ceux des 7 derniers jours. Si rien ne nécessite votre attention, elle indique ce qu’elle a lu et ce que vous pouvez connecter ensuite. En cas d’échec, une vérification est relancée dans les minutes qui suivent. Si elle échoue toujours, la liste vous le signale.

**Retour** et le bouton de retour de votre navigateur vous ramènent à l’étape précédente. Une fois votre messagerie et votre IA opérationnelles, vous arrivez sur votre tableau de bord.

La configuration ne vous demande rien d’autre. Ensuite, **Ajouter d’autres éléments à tout moment** sur la page de configuration vous donne accès à **Autres sources**, comme Slack, WhatsApp, GitHub, [Telegram](telegram.md) et [Codex](hand-to-agent.md). Votre tableau de bord vous suggère aussi des sources lorsque c’est utile, comme GitHub si vous recevez régulièrement des e-mails de ce service.

Quand votre Machine est prête, **Ouvrir votre tableau de bord** s’affiche en haut. **Ajouter à Claude** vous permet de poser des questions sur vos e-mails et vos tâches à Claude. Pour recevoir des notifications, ajoutez The Machine à l’écran d’accueil de votre téléphone : consultez [Installer l’application et activer les notifications](phone-app.md).

## Demander une source

Il vous manque une source ? Dans **Sources**, sous **Demander une source**, indiquez le service et les éléments à lire, puis appuyez sur **Créer**. Votre IA la crée et la teste sur votre Machine. Si vous choisissez de la partager, The Machine la propose à tout le monde sur GitHub pour vous. Vous n’avez pas besoin de compte GitHub. [Connectez GitHub](github.md) pour que votre contribution vous soit attribuée.

## Revenir plus tard

Votre page de configuration reste accessible à l’adresse app.themachine.computer/setup. Vous pouvez y ajouter ou supprimer des sources à tout moment. Dans le tableau de bord, **Paramètres** contient **Ouvrir le compte**.
