## Votre Machine

- Sur votre ordinateur : gratuit. Tout ce que fait The Machine, avec votre propre modèle.
- Hébergée : {price.standard} par mois pour une Machine Standard, ou {price.big} pour une Machine plus grande, hors TVA. Les {trial_days} premiers jours sont gratuits, une seule fois par personne, et aucun prélèvement n’est effectué avant la fin de cette période. Si votre période d’essai a commencé sans carte, ajoutez-en une à votre compte avant la fin.

Votre forfait IA est facturé par votre fournisseur, comme OpenAI. Nous ne vous facturons rien de plus.

## Sur le Network

- Amis et famille : gratuit, avec n’importe quelle Machine. Dans une Fleet famille, les Machines hébergées coûtent {price.family_pair} pour les deux premières ensemble, puis {price.family_seat} par Machine, hors TVA.
- Fleet professionnel : {price.seat} par personne et par mois, ou {price.seat_big} pour une Machine plus grande, hors TVA. Un collègue qui utilise sa propre Machine coûte {price.network} par mois, et celui dont la Machine est déjà hébergée ne paie rien. Chaque Fleet a sa propre carte et ses propres factures, et son propriétaire confirme chaque montant avant le prélèvement.

Tous les prix sont mensuels et hors TVA. Consultez les [tarifs](/pricing).

Vous avez créé un Network pour vos amis avant que le Network devienne gratuit ? Il apparaît dans **Paramètres** › **Compte** jusqu’à ce que vous l’arrêtiez. **Gérer** l’ouvre dans votre compte, où vous pouvez l’arrêter ou changer la carte associée. Votre nom d’utilisateur et vos amis sont conservés.

## Carte et factures

Dans **Paramètres** › **Compte**, appuyez sur **Facturation**, puis sur **Gérer l’abonnement**. Stripe s’ouvre pour vous permettre de changer de carte et de télécharger vos factures. Les informations de votre carte ne nous sont jamais transmises.

Vous pouvez changer la taille de votre Machine à tout moment : dans **Paramètres** › **Compte**, appuyez sur **Changer de forfait**.
