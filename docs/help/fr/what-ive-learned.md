Quand le premier tour d’horizon se termine, **Voici ce que j’ai appris** s’affiche sous vos tâches. Il se remplit pendant que le reste de la configuration se termine, et reste un jour ou jusqu’à ce que vous le fermiez.

## Ce qu’il montre

- **Votre façon d’écrire** : les premières lignes sur votre façon d’écrire vos e-mails.
- **Les personnes avec qui vous travaillez le plus** : jusqu’à 6 personnes avec qui vous échangez sur vos comptes de travail, et ce sur quoi vous travaillez ensemble, d’après un projet ou un fil récent.
- **Vos horaires habituels** : quand vous envoyez vos e-mails de travail.

Uniquement le travail, jamais rien de personnel. Une partie avec trop peu d’éléments ne s’affiche pas.

## Corriger ce qui ne va pas

Touchez **Pas juste** à côté d’un élément, écrivez ce qu’il faut et touchez **Enregistrer**. **Retirer** l’enlève. Chaque correction apparaît dans **Apprentissage**, **Modifications**, avec **Annuler**.

Vos horaires habituels ne changent pas vos [heures de travail](work-hours.md). Votre façon d’écrire se trouve aussi dans [Rédaction](writing.md).
