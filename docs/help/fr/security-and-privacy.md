## En bref

- Votre propre Machine : une Machine hébergée fonctionne dans le cloud de l’UE, rien que pour vous, et n’est jamais partagée. Vous pouvez aussi l’exécuter sur votre propre ordinateur.
- Nous ne lisons pas vos e-mails : les messages sont stockés sous forme chiffrée et nos outils d’assistance ne peuvent pas les ouvrir.
- Rien n’est envoyé sans votre accord : elle lit vos messages et prépare des brouillons, mais c’est vous qui décidez de ce qui est envoyé. Voir [Faire](do-it.md).
- Aucune utilisation pour entraîner l’IA : nous n’avons pas notre propre IA. Votre fournisseur utilise votre compte et applique ses conditions.
- Des apprentissages pour l’équipe, sauf si vous désactivez cette option : de temps en temps, quelques conseils généraux, rien de personnel, vérifiés avant leur envoi. Voir [Partager les apprentissages](share-learnings.md).
- Des rapports d’erreur, sauf si vous désactivez cette option : en cas de problème, le type d’erreur et l’endroit où elle se trouve dans le code. Jamais vos messages, vos noms ou vos adresses. Voir [Rapports d’erreur](error-reports.md).
- Statistiques d’utilisation pour une Machine hébergée : le nombre quotidien de certaines actions (comme les tâches ouvertes ou les e-mails envoyés), jamais leur contenu.
- Emportez vos données ou supprimez-les : exportez tout depuis **Paramètres** › **Général**, ou supprimez votre Machine et ses sauvegardes en un clic. Voir [Résilier ou supprimer](cancel-and-delete.md).
- Nos accès sont consignés : chaque fois que notre équipe consulte le rapport de votre Machine hébergée ou ses journaux. Les propriétaires et administrateurs de Fleet peuvent les consulter sous **Activité**. Voir [Fleets](fleet.md).

## Niveaux de sécurité

**Standard** conserve les réglages par défaut actuels. **Prudent** n’affiche aucun texte dans les notifications, n’enregistre pas les connexions et conserve moins de données. L’administrateur d’une Fleet Travail peut activer le mode **Prudent** pour toute la Fleet. Voir [Niveaux de sécurité](security-levels.md).

## Connexion

Pour accéder au tableau de bord d’une Machine hébergée, vous avez besoin d’une clé d’accès, ou de vous connecter avec Google ou Microsoft et de saisir un code d’authentification.

## Connexions

L’article consacré à chaque connexion indique ce qu’elle lit et ce qu’elle peut envoyer. Vous pouvez déconnecter n’importe laquelle à tout moment : voir [Connexions](connections.md).

## Aide

L’aide fonctionne sur votre propre Machine et ne peut pas voir vos données. Seul le sujet de chaque question est transmis à l’équipe The Machine, jamais vos mots. Voir [Poser une question à l’aide](help-chat.md#what-the-team-sees).
