## En bref

- Votre Machine, rien qu’à vous : si elle est hébergée, elle se trouve dans le cloud européen et n’est jamais partagée. Vous pouvez aussi l’exécuter sur votre propre ordinateur.
- Nous ne lisons pas vos e-mails : les messages sont stockés sous forme chiffrée et nos outils d’assistance ne peuvent pas les ouvrir.
- Rien n’est envoyé sans votre accord : elle lit et rédige des brouillons, mais c’est vous qui décidez de ce qui est envoyé. Voir [Faire](do-it.md).
- Aucune utilisation pour entraîner une IA : nous n’avons pas d’IA à nous. Votre fournisseur fonctionne avec votre compte et selon ses conditions.
- Des apprentissages partagés avec l’équipe, sauf si vous désactivez cette option : de temps en temps, quelques conseils généraux, rien de personnel, vérifiés avant leur envoi. Voir [Partager les apprentissages](share-learnings.md).
- Des rapports d’erreur, sauf si vous désactivez cette option : en cas de problème, le type d’erreur et l’endroit dans le code. Jamais vos messages, vos noms ou vos adresses. Voir [Rapports d’erreur](error-reports.md).
- Statistiques d’utilisation sur une Machine hébergée : décompte quotidien de vos actions (par exemple, les tâches ouvertes ou les e-mails envoyés), jamais leur contenu, et vitesse d’ouverture de votre tableau de bord (temps de chargement uniquement, sur téléphone ou ordinateur, dans l’app ou le navigateur).
- Emportez vos données ou supprimez-les : exportez tout depuis **Paramètres** › **Général**, ou supprimez votre Machine et ses sauvegardes en un seul clic. Voir [Résilier ou supprimer](cancel-and-delete.md).
- Nos accès sont consignés : chaque fois que notre équipe consulte le rapport de votre Machine hébergée ou ses journaux. Les propriétaires et les admins de Fleet peuvent les voir dans **Activité**. Voir [Fleets](fleet.md).

## Niveaux de sécurité

**Standard** conserve les paramètres par défaut actuels. **Prudent** n’affiche aucun texte dans les notifications, n’enregistre pas les connexions et conserve moins de données. L’admin d’une Fleet Travail peut mettre la Fleet en mode **Prudent**. Voir [Niveaux de sécurité](security-levels.md).

## Connexion

Pour accéder à un tableau de bord hébergé, vous devez utiliser une clé d’accès, ou vous connecter avec Google ou Microsoft et saisir un code d’authentification.

## Connexions

L’article de chaque connexion indique ce qu’elle lit et ce qu’elle peut envoyer. Vous pouvez la déconnecter à tout moment : voir [Connexions](connections.md).

## Aide

L’aide fonctionne sur votre propre Machine et ne peut pas voir vos données. Seul le sujet de chaque question est transmis à l’équipe de The Machine, jamais vos mots. Voir [Demander de l’aide](help-chat.md#what-the-team-sees).
