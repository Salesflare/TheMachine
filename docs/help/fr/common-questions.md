## Envoyer un e-mail plus tard, à une heure précise

Appuyez sur **Envoyer plus tard** à côté de **Envoyer maintenant**, puis choisissez une heure. L’e-mail est envoyé exactement comme vous l’avez approuvé. Si la personne vous écrit avant, il attend à nouveau votre feu vert. Consultez [Envoyer plus tard](send-later.md). Les messages LinkedIn et X ne peuvent pas attendre : mettez la tâche **En attente**, puis appuyez sur **Envoyer maintenant** lorsqu’elle revient.

## Annuler l’envoi d’un e-mail ou d’un message

Ce n’est pas possible une fois le message envoyé. Rien ne part sans votre accord : lisez-le d’abord dans **Vérifier et envoyer**. Vous pouvez toutefois encore arrêter certains envois : appuyez sur **Annuler** pour un message qui [doit être envoyé plus tard](send-later.md), ou dans [Parler en direct](talk-live.md). **Annuler** s’affiche pendant quelques secondes après votre accord, et **Arrêter l’envoi** interrompt le reste d’une série de [relances](follow-ups.md).

## Où trouver un brouillon

Un brouillon reste dans la tâche correspondante. S’il n’apparaît plus dans **Pour vous**, cherchez dans **En attente des autres**, **Revient plus tard**, **Plus anciennes** ou **Fait / écarté**, ou retrouvez la tâche avec **Rechercher**. Les versions précédentes se trouvent dans le chat de la tâche, sous **Brouillon précédent**. Un nouvel e-mail que vous n’avez pas envoyé apparaît au-dessus de vos tâches. Consultez [Écrire un nouvel e-mail](email-composer.md).

## Mode clair ou sombre

Le tableau de bord est en mode sombre, sauf si **Mode clair** est activé. Pour passer en mode sombre, désactivez-le. Pour passer en mode clair, activez-le dans **Paramètres** › **Général**, sous **Cet appareil**. Le réglage ne s’applique qu’à ce navigateur ou à ce téléphone. Avec un clavier, saisissez « dark » ou « light » dans **Recherche et commandes**.

## Réduire le nombre de tâches

Appuyez sur **Pas nécessaire** pour les éléments que vous ne voulez pas voir, puis indiquez pourquoi. Votre Machine en tirera des enseignements. Vous pouvez aussi le lui dire dans le chat d’une tâche, par exemple : « Je n’ai jamais besoin de ça ». Pour arrêter une source entière, ouvrez **Connexions**, sélectionnez **Détails**, puis désactivez **Apporte des signaux**. **Tout écarter** efface en une fois tout ce qui se trouve sous **Plus anciennes**.

## Tâches provenant d’une newsletter ou d’un expéditeur

Dites-le dans le chat d’une de ses tâches, par exemple : « Cette liste de diffusion ne doit jamais créer de tâche ». Le message **Ajouté à ce que j’ai appris** s’affiche, et les vérifications suivantes en tiennent compte. Vous pouvez consulter cet apprentissage dans **Apprentissage**, puis le **Modifier** ou le **Retirer**.

Les e-mails continueront d’arriver. Pour les arrêter aussi, désabonnez-vous vous-même ou utilisez [Nettoyage des newsletters](routines.md#templates).

## Qui peut voir vos tâches

Vous seul pouvez les voir. Votre Machine n’appartient qu’à vous, et nos outils d’assistance ne peuvent pas ouvrir vos messages. Une autre personne ne voit une tâche que si vous la partagez avec elle, par exemple avec **Transférer…**. Une Fleet Travail voit le travail client partagé par votre [Graph d’équipe](team-graph.md), jamais vos éléments personnels. Les [Règles de partage](sharing-rules.md) définissent ce à quoi votre Machine peut répondre.

## Partager une tâche

Partagez-la avec un collègue ou un coéquipier : dans la tâche, ouvrez **…**, puis sélectionnez **Transférer…**. Vous devez avoir une [Fleet](fleet.md), et une tâche Travail ne peut être envoyée qu’à votre Fleet Travail.

- **Un coéquipier** : vous lui transmettez la tâche, qui lui appartient dès qu’il l’accepte. Il ne voit que cette tâche. Consultez [Transferts](handoffs.md).
- **Demander une relecture** : il examine la tâche et modifie le brouillon, qui reste le vôtre. Votre Fleet Famille peut relire les tâches personnelles. Consultez [Demander une relecture](ask-to-review.md).
- **Un coéquipier**, puis **Par e-mail** : pour une personne qui n’utilise pas The Machine. Vous pouvez lui fournir une page pour répondre. Consultez [Pages de tâche](task-pages.md).

Pour demander quelque chose à votre Fleet Famille, utilisez son volet dans l’onglet **Fleet**.

## Transférer un e-mail à The Machine

Il n’y a pas d’adresse de transfert, et vous n’en avez pas besoin : The Machine lit les boîtes mail que vous connectez. Pour un élément provenant d’ailleurs, appuyez sur **Nouvelle tâche** et joignez le message ou un fichier, ou partagez-le avec The Machine depuis votre téléphone. Consultez [Application mobile](mobile-app.md#share-to-the-machine).

## Absence du bureau et réponses automatiques

Ce n’est pas possible : The Machine ne configure pas de réponse automatique. Configurez-la directement dans Gmail ou Outlook. The Machine continue de préparer des brouillons pendant votre absence, et ceux-ci vous attendent à votre retour.

## Réserver, commander ou payer quelque chose

[Faire](do-it.md) peut rechercher des informations, choisir et remplir un formulaire dans le navigateur de votre Machine, par exemple pour réserver une table ou prendre un billet. La dernière étape, celle qui confirme la réservation ou le paiement, attend votre accord. Une facture à payer depuis votre banque arrive sous forme de tâche avec les détails du paiement. Vous la réglez vous-même.

## Participer à un appel ou à une réunion

Ce n’est pas possible : The Machine ne participe pas aux appels. Elle vous prépare avant une réunion et lit son résumé ou sa transcription après, depuis [Zoom](zoom.md), [Google Meet](google-meet.md), [Teams](teams.md) ou [Granola](granola.md).

## Imprimer

The Machine n’a pas de bouton d’impression. Utilisez la fonction d’impression de votre navigateur pour imprimer la page affichée.
