## Fonctionnement

- Trouver un créneau : « Quand sommes-nous tous disponibles samedi ? » Seuls les créneaux occupés sont partagés.
- Tâches : demandez à un membre de votre famille de faire quelque chose. Cette personne accepte ou refuse.
- Plans : proposez-en un. Tout le monde répond « Je viens » ou « Je ne peux pas ». La réponse « Je viens » l’ajoute à votre agenda Google, sans inviter personne. « Annuler » le retire. Si vous n’avez pas d’agenda que The Machine peut modifier, vous recevez un lien pour l’ajouter vous-même.

Aucune question professionnelle ne passe par une Fleet Famille.

## Interroger la Machine de quelqu’un

Dans le volet Famille de l’onglet Fleet, choisissez une personne et posez une question : « Des nouvelles du tapis ? »

- Sa Machine rédige une réponse à partir de ses messages personnels. Cette personne voit le brouillon et les messages dont il est tiré, peut le modifier si elle le souhaite, puis l’envoyer. Rien ne vous parvient avant cela.
- La réponse s’affiche dans le volet Famille et sous forme de notification. Après trois jours sans réponse, le statut **Pas de réponse** s’affiche.
- Un brouillon n’est jamais rédigé à partir de messages professionnels, de contenus sensibles ou privés, ni de codes, de liens ou de numéros de compte. Votre Machine fait aussi attention aux cadeaux et aux surprises. En cas de doute, aucun brouillon n’est proposé et vous répondez avec vos propres mots.
- Toutes les questions qui vous sont adressées, ainsi que le contenu exact de vos réponses, figurent dans [Activité](activity.md).
- Vous ne voulez pas recevoir de questions d’une personne ? Choisissez **Jamais** pour cette personne dans le volet Partage. Elle n’en sera pas informée.
- Une Machine qui n’est pas à jour ne peut pas encore répondre. Vous le verrez.

## Suggestions d’invitation

Lorsqu’une tâche porte sur des projets familiaux avec une personne qui ne fait pas encore partie de votre famille, par exemple « Qui va chercher les enfants mercredi ? », une suggestion d’invitation peut s’afficher.

- **Inviter** ouvre le formulaire d’invitation avec son adresse préremplie et affiche l’e-mail qu’elle recevra. Rien n’est envoyé sans votre accord.
- **Pas maintenant** masque la suggestion pendant 90 jours.
- La suggestion concerne uniquement les membres de la famille, selon votre Graph ou vos propres mots. Jamais les contacts professionnels, les personnes qui font déjà partie de votre famille ou celles ayant une invitation en attente. Au maximum une fois par personne.
- Désactivez cette option dans Paramètres, Général, sous Fleet : **Suggérer d’inviter la famille**.

## Déjà fait

Lorsque vous recevez tous les deux le même e-mail, la même facture ou le même formulaire, et que l’un de vous marque sa tâche comme terminée, la tâche de l’autre affiche « Robin l’a fait · sam. 7 nov. ».

- **Fait** clôt votre tâche. **Toujours utile** la conserve et masque la mention.
- Rien n’est clôturé automatiquement.
- Un rappel contenant le même lien vers un formulaire est considéré comme la même tâche.
- Seul un code est partagé, jamais la tâche. Désactivez cette option dans le volet Partage : Tâches déjà effectuées.

## Règles

Par défaut, les disponibilités et les périodes occupées sont partagées, et les tâches, les plans et les questions nécessitent votre accord préalable. Modifiez ces paramètres dans le volet Partage : consultez [Règles de partage](sharing-rules.md).

Une Fleet Famille est gratuite. Les Machines hébergées dans cette Fleet coûtent {price.family_pair} par mois pour les deux premières ensemble, puis {price.family_seat} chacune, hors TVA. Consultez [Forfaits et facturation](plans-and-billing.md).
