## 详情来源

- 使用托管版Machine时，系统会免费为你查询组织详情。
- 在你自己的电脑上，此功能默认关闭。添加 Apollo、People Data Labs 或 Hunter 等查询服务的密钥后即可启用。请参阅[配置指南](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md)。

系统只会发送组织的网址，不会发送你的消息，也不会发送你认识的人。托管版Machine或位于The Machine Network上的Machine每天最多查询1,000个组织，其他情况每天最多查询50个。每项详情每90天更新一次。系统不会查询共享网站和邮件服务商，例如gmail.com。个人信息有单独的查询功能，请参阅[职位和照片](people.md#job-title-and-photo)。

如果查询结果中没有标志，The Machine会使用组织网站指定的图标，并将其保存在你的Machine上。没有任何标志服务会知道你与哪些组织有往来。如果同时有两种图标，在待办的行等较小的位置会显示方形图标。

查询结果包含专长时，组织简介下最多会显示5项专长。你也可以按专长筛选组织列表：点击**筛选**，然后点击**专长**。如果查询某个人时也获取到了其公司的详情，这些信息也会填入组织资料，因此无需单独查询该组织。最近90天内查询的详情会保持不变。

## 更正错误信息

在组织页面上：

- 点击**编辑**，更改名称、行业、规模、所在地、成立年份、简介、网站、LinkedIn、备注，以及它对你来说是什么。你所做的修改会保留。清空某个字段即可重新使用查询结果。
- 如果选错了公司，请在**编辑**中点击**公司选错了，清除详情**。
- 清除详情后会显示**再查一次**，点击即可获取最新详情。
