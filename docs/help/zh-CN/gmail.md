## 读取哪些内容

所有邮件：连接时读取最近 7 天的邮件，之后读取所有新邮件，包括收件和发件邮件。你发送的邮件也会被读取，这样 The Machine 就能了解你的写作方式和你做出的承诺。

促销、简报、动态和论坛邮件会先快速查看：发件人、主题和少量内容，并一次查看多封。遇到重要邮件时，会完整读取，也可能将其变成待办。不会有邮件在未查看的情况下被跳过。

## 可以发送什么

可以发送待办中的邮件，但只有在你批准后才会发送。**执行**会准备一份草稿；**审核并发送**会打开草稿供你编辑。在你点击**立即发送**之前，邮件不会发出。点击**使用 Google 登录**后，Google 也会请求发送权限。如果你在自己的电脑上使用自己的应用，登录权限只能读取邮件，直到你自行添加发送功能。

审核时，**来自**是一个简单的选择器。只有 Gmail 允许此邮箱以你的别名发送邮件时，才会显示该选择器（在设置的[你的地址](settings.md#your-addresses)中标记为**我的**）。回复发到该别名的邮件时，会默认使用这个别名；新邮件则会使用你的邮箱地址。发送前，Gmail 会再次确认：如果 Gmail 没有确认该地址，就不会发送邮件。

回复会进入被回复邮件所在的会话。如果回复使用的邮箱与收到原邮件的邮箱不同，待办会在发送前说明这一点。回复仍会进入原邮件的会话。

回复发出后，其会话会从收件箱移出，并在「稍后处理」标签下停留几天（通常为 3 天，待办另有说明时除外），之后会返回收件箱；如果有人回复，也会提前返回。审核时会在发送前说明这一点。

## 连接

在托管版 The Machine 上：

1. 前往 app.themachine.computer/setup 打开设置页面。
2. 在**邮件和日历**下，点击**连接Google**并登录。Google 页面会显示 The Machine 的开发者 Salesflare。
3. Gmail 和 Google 日历会一起连接。

如果你使用 Google 注册，并在注册页面授权了 Gmail 和日历，它们会自动连接。只有点击「发送」时才会发送邮件。

也可以在控制面板中点击**连接**、**邮件**，选择 Gmail，然后点击**使用 Google 登录**。完成后，你会返回控制面板。

在自己的电脑上，先[将它与你的账号配对](friends.md#a-machine-on-your-own-computer)：

1. 在控制面板中打开**连接**，然后打开**邮件**，并选择 Gmail。
2. 点击**使用 Google 登录**，然后在打开的标签页中登录。Gmail 和 Google 日历会一起连接。

如果尚未配对，或使用自己的 Google OAuth 客户端，请在该页面打开**使用你自己的应用**，或运行 `assistant connect gmail`。点击**打开Google**并登录，然后粘贴 Google 将你重定向到的地址。同一地址对应的 Google 日历也会一并连接。

Google Workspace 管理员可能需要先在管理控制台中允许此应用。

## 移除连接

- 在托管版 The Machine 上：在设置页面中，点击地址旁的**断开连接**。该地址对应的 Gmail 和日历连接会被移除，The Machine 也会忘记登录信息。其他 Machine 会保留各自的连接。在控制面板中点击「连接」旁的**断开连接 ↗**即可前往设置页面。在那里点击**重新连接**，即可重新登录，无需离开控制面板。
- 在自己的电脑上：打开**连接**，选择 Gmail，点击**详情**，然后点击**断开连接**。The Machine 会停止读取邮件，但已读取的内容会保留。如果没有其他功能使用该 Google 登录信息，The Machine 就会忘记它。其他 Machine 会保留各自的连接。

## 在 Google 中卸载

在 Google 账号中，打开「安全性」，然后打开「第三方应用和服务的连接」，移除 Salesflare（通过 Google 登录或托管版）或你自己的应用。
