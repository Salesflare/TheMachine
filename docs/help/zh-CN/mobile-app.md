手机应用会打开你自己的控制面板，登录状态与网页版相同。你可以在iPhone和iPad上从[App Store](https://apps.apple.com/app/id6829875215)下载，或在Android上从[Google Play](https://play.google.com/store/apps/details?id=computer.themachine.app)下载。

待办列表顶部的**充分利用The Machine**待办会推荐你安装应用。在手机浏览器中，点击**获取**会打开应用商店。如果手机设置为显示桌面版网站，会显示两个应用商店的链接。在电脑上会显示二维码，供你用手机扫描，同时也会显示两个应用商店的链接。

在任何手机上打开[themachine.computer/app](https://themachine.computer/app)，都会跳转到对应的应用商店。在电脑上，进入**设置**>**应用**，顶部会显示两个应用商店；在手机上则只显示对应的应用商店。在电脑上，点击**电脑**可以将控制面板安装为应用：请参阅[安装应用](phone-app.md)。

## 连接应用

托管版Machine会使用你的账号登录应用。对于自托管的Machine，请在电脑上进入**设置**>**应用**，应用商店下方的**不在Network上？**会显示一个代码。安装应用后，用手机摄像头扫描代码，或在应用中输入代码下方显示的地址。应用会在连接前征求你的同意，你的Machine仍会要求你使用自己的登录方式。

在**连接**下点击某项服务（Shortcut、Notion、Slack、Zoom等）的**使用以下服务登录**，会打开手机的登录界面。完成登录后会回到应用，新连接会自动显示在**连接**中。

应用无法连接到你的Machine时，会提示你并自动重试。在Mac上，如果应用窗口从睡眠状态恢复后显示空白，应用也会自动重新打开页面。你正在输入的聊天消息也会一并恢复。在Mac或带键盘的iPad上，按Cmd+R可以重新加载页面。

## 通知

应用首次打开时会询问是否允许发送通知。点击通知即可查看相关内容：待办会在列表中高亮显示；早间简报会打开**日历**中的今天；团队简报会打开待办列表；Fleet问题会打开对应的待办。待办文本不会经过Apple、Google或The Machine的服务，它们只会传递一条固定提示，例如“有待办需要你处理”。

接着，应用会向你的Machine请求待办标题和下一步操作，例如“回复Sam”，以及“发送给Sam：周二10:00可以”。早间简报会显示待处理事项和第一场会议的时间，团队简报会显示首批事项，Fleet动态则会显示发生了什么。应用无法连接到你的Machine时，会继续显示固定提示。在Android上，提示会显示待办数量，例如“有2个待办需要你处理”。

通知中有**稍后处理**（推迟到明天）和**标记为已完成**选项；尚未开始的待办还会显示**执行**。解锁手机后即可使用这些操作，无需打开应用。发送和最后一步操作始终会打开应用。每个待办只有一条通知：“正在准备”会变成“已备好”；待办在此处或其他地方完成或推迟后，通知就会消失。

你确认的步骤完成后，通知会显示**已完成**以及操作结果，直到你在待办列表中点击**知道了**。在iPhone上，这条通知可以一直保留到下次打开应用。

在**设置**>**安全**中关闭**通知中的文本**后，通知只会显示固定提示。锁屏设置为隐藏通知内容时也一样。如果没有可显示的内容，通知会显示“点击打开”。如果通知到达时手机无法连接到你的Machine，恢复联网后就会显示详情。

通知遵循与网页版推送相同的规则：根据你在[通知](notifications.md)中为各类通知选择的设置、你的[工作时间](work-hours.md)，以及使用控制面板期间不发送通知。

每部装有应用的手机都会显示在**设置**>**通知**下，名称为**装有应用的手机**。点击**移除**即可停止向该手机发送通知。自托管的Machine需要使用The Machine Network才能发送通知；没有通知时，应用仍可使用。

## 分享到The Machine

在任何应用中点击“分享”，然后选择The Machine。系统会打开**新建待办**，其中包含你分享的文本、链接或文件。检查内容，可以按需添加日期，然后添加待办。在你确认之前，不会添加任何内容。

只分享一个文件也可以，例如发票或信件。你的Machine会读取PDF文本并填写待办内容，包括文件是什么、下一步操作和日期。文件会直接发送到你的Machine并保留在那里。

在Android上，安装为应用的控制面板也可以接收分享内容：在分享菜单中同样选择它即可。

应用中不会显示套餐和账单信息。**设置**中仍会显示**打开账号**，供你删除账号。
