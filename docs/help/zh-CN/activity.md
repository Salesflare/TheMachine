## 显示内容

打开 **设置**，再点 **动态**。列表中的每一行代表 The Machine 做过的一件事，按天从新到旧排列：

- 做了什么，以及结果：已发送、已拒绝、失败或已撤销
- 时间、使用的账号或应用，以及[操作获准的原因](activity.md#what-allowed-it)
- 如果有对应的待办，会附上链接
- 如果是你连接的 AI，例如 ChatGPT 或 Claude：会显示它的名称和 **（已连接的 AI）**，方便你与 The Machine 本身区分

列表包含消息和回复、文档和日历更改、网页操作、已合并的修复、编程智能体、Fleet 问答、发送给 The Machine 团队的心得、技能、Graph 导入、你要求聊天忘记的事实（可点按 **撤销**）、添加或移除的连接，以及团队在[支持访问](get-support.md#support-access)下进行的每次查看，包括被拒绝的访问。

## 操作获准的原因

每条消息、文档或日历更改、网页操作和已合并的修复，都会记录当时允许它执行的原因：

- **已在待办中批准**或**已在 Telegram 中批准**：你点按了**发送**、**确认**或**合并**
- **已通过语音批准**：你在 Talk 中说了“好”
- **已点击“执行”**：你点按了待办上的**执行**
- **已在聊天中询问**：你用文字提出了请求，并显示消息开头的内容。只有当这些文字仍在你自己的消息中时，才会显示引用内容。
- **自动发送的跟进**、**小修复，已自动合并**、**自动创建的私人文档**或**自动提前准备**：由你的一项设置或 The Machine 自己的一条规则触发
- **未记录批准**：没有记录到允许这项操作的依据。它也会被提交到我们的[错误报告](error-reports.md)，以便我们找到遗漏的环节。

网页操作还会列出待办的一次运行记录，显示它在网页上点击或输入的内容，以及允许这次运行的原因。

开始记录这些信息之前的旧条目会保留原来的说法，例如 **等你确认后**。

## 筛选列表

选择顶部列表中的类别，例如 **消息**或**Fleet**。**已拒绝或已拦截**只显示未能执行的操作及其原因。点按**展开**可加载更早的条目。

## 其他位置

待办中的聊天会保留自己的记录，动态里会链接到它。在 Fleet 中，**动态**会显示你的 Fleet 和心得的相同记录；心得旁会有**撤回**选项。在设置中，打开 **安全**里的**在活动中查看每次浏览**，即可查看团队的浏览记录。

动态只显示发生过的事，不会改变 The Machine 可以执行的操作。
