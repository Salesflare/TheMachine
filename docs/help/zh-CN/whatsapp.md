## 读取的内容

你的 Machine 会像电脑上的 WhatsApp 一样，以你手机 WhatsApp 的关联设备身份读取聊天。连接后，WhatsApp 也会发送较早的聊天记录，通常包括几年前的内容。你的 Machine 会保留所有内容，但只有最近 7 天的消息会转成待办。

没有说明文字的照片、语音消息或文件会显示其类型，例如带有图标的“照片”。WhatsApp 自带的通知，例如加密提示或有人加入群组的通知，没有文字内容，因此不会纳入。

## 查看照片

默认关闭，开启后才会读取。在 **连接** 中打开 WhatsApp，然后点按 **详情**，再开启 **查看照片**，The Machine 就会读取工作聊天中的照片，例如收据、屏幕截图、信件照片或表格照片。开启 **也包括私人聊天** 后，也会读取私人聊天中的照片。聊天是工作还是私人，取决于分享时的分类，因此和家人的聊天仍会归为私人聊天。

The Machine 会下载每张照片一次，并像邮件附件一样保存在你的 Machine 上：开启消息保护后会加密，相关消息删除时，照片也会删除。The Machine 自带的模型会读取照片中的图像和文字。这些内容会被视为消息的一部分，绝不会被当作指令。支持最大 5 MB 的 JPEG、PNG 和 WebP 格式。照片中的一次性验证码不会纳入。

待办和消息中都会显示照片。点按照片可查看大图。

## 可以发送的内容

你批准待办后，The Machine 可以向已有聊天发送一段文字，或一个附带可选说明的文件。发送前，待办会显示文件，你可以打开查看。文件最大为 18 MB。如果待办来自 WhatsApp 消息，而你要回复的内容是在该消息之后发送的，或者是在群组中发送的，回复就会引用那条消息；草稿会标记为 **作为回复**。

如果待办来自邮件，但你想在 WhatsApp 上联系对方，可以在待办的聊天中说明。The Machine 会找到你和对方已有的聊天，并将草稿切换到 WhatsApp，供你检查和发送。它不会发起新聊天。

WhatsApp 没有提供官方方式来实现这一功能。读取消息，以及偶尔发送你批准的回复，极不可能造成问题；大量发送或自动发送则可能导致账号被封禁。

## 连接

在托管的 Machine 上：

1. 在控制面板中打开 **连接**，然后点按 **聊天**，再选择 WhatsApp。
2. 点按 **显示二维码**。
3. 在手机上的 WhatsApp 中，打开“设置”“已关联的设备”“关联设备”，然后扫描二维码。
4. 一分钟内，WhatsApp 就会显示为已连接。之后聊天记录会继续同步，连接卡片会显示收到的消息数量。
   如果连接耗时过长，几分钟后会显示提示。点按 **重试**，即可从中断处继续。

如果你正在手机上设置，没有第二个屏幕可供扫描，请打开 **在手机上操作？改用代码关联**，输入号码，然后点按 **获取代码**。WhatsApp 随后会要求你输入该代码。

在自己的电脑上：打开 **连接**，然后点按 **聊天**，选择 WhatsApp，输入带国家/地区代码的手机号码，再点按 **连接**。屏幕上会显示代码。在手机上的 WhatsApp 中，打开“设置”“已关联的设备”“关联设备”，然后点按“改用电话号码关联”，并输入代码。

也可以运行 `assistant connect whatsapp`，然后扫描终端中显示的代码。首次运行时，系统会提示安装 WhatsApp 连接器，这是经过校验和验证的固定版本（[源代码](https://github.com/Salesflare/wacli)）。

在“已关联的设备”中，设备会显示为 The Machine。之前关联的 Machine 会继续显示旧名称，直到你重新关联。

如果 WhatsApp 将你的 Machine 登出，其连接卡片会显示 **WhatsApp 已解除与这台 Machine 的关联**。点按 **重新连接**，然后重新关联。

## 头像

The Machine 会通过保持 WhatsApp 最新状态的同步，向 WhatsApp 请求你 Graph 中尚无头像联系人的头像，每天最多 50 个。不会向这些联系人发送任何内容。如果有人对你隐藏了头像，该联系人仍不会显示头像。

## 移除

- 在托管的 Machine 上：在设置页面中点按它旁边的 **移除**。你的 Machine 会解除关联，并删除保留的 WhatsApp 数据。
- 在自己的电脑上：打开 **连接**，选择 WhatsApp，再点按 **详情**，然后点按 **断开连接**。接着也要在手机上解除关联。

## 在 WhatsApp 中解除关联

在手机上的 WhatsApp 中，打开“设置”“已关联的设备”，点按你的 Machine，然后退出登录。
