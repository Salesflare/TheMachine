## 读取内容

你的 WhatsApp 聊天会像电脑上的 WhatsApp 一样，以你手机 WhatsApp 的关联设备身份同步过来。连接后，WhatsApp 也会发送较早的聊天记录，往往有好几年的内容。你的 Machine 会保留所有内容，只有最近 7 天的消息会转成待办。

没有说明文字的照片、语音消息或文件会显示其类型，例如带图标的“照片”。WhatsApp 自己发出的通知，例如加密提示或有人加入群组的通知，没有文字，因此不会纳入。

## 查看照片

此功能默认关闭。要开启，请在 **连接** 中打开 WhatsApp，再打开 **详情**，并启用 **查看照片**。这样 The Machine 就会读取工作聊天中的照片，例如收据、截图、信件照片或表格照片。启用 **也包括私人聊天** 后，也会读取私人聊天中的照片。聊天是工作还是私人，取决于分享时的分类方式，因此与家人的聊天仍会归为私人聊天。

The Machine 会下载每张照片一次，并像邮件附件一样保存在你的 Machine 上：启用消息保护后会加密；对应消息删除后，照片也会删除。The Machine 自己的模型会读取照片中的内容和文字。这些内容会作为消息的一部分处理，绝不会作为指令。支持最大 5 MB 的 JPEG、PNG 和 WebP 文件。照片中的一次性验证码不会纳入。

待办和消息中都会显示照片。点按照片即可放大查看。

## 可发送的内容

你可以发送文字，或发送一个带可选说明文字的文件到已有聊天，但必须先在待办中批准。发送前，待办会显示文件，你可以打开查看。文件最大为 18 MB。如果待办所对应的 WhatsApp 消息之后还有新内容，或消息来自群组，回复时会引用该消息；草稿会标记为 **作为回复**。

如果待办来自邮件，但你会在 WhatsApp 上联系对方，请在待办的聊天中说明。The Machine 会找到你和对方已有的聊天，并将草稿切换到 WhatsApp，供你检查和发送。它绝不会新建聊天。

WhatsApp 没有提供官方方式来实现这些操作。读取消息并偶尔发送你批准的回复，极不可能引发问题；大量发送或自动发送则可能导致账号被封禁。

## 连接

在托管的 Machine 上：

1. 在控制面板中打开 **连接**，再打开 **聊天**，然后选择 WhatsApp。
2. 点按 **显示二维码**。
3. 在手机上的 WhatsApp 中，打开设置、已关联的设备、关联设备，然后扫描二维码。
4. WhatsApp 会在一分钟内显示为已连接。之后聊天记录会继续同步，连接卡片会显示同步期间收到的消息数量。
   如果连接耗时过长，几分钟后会显示提示。点按 **重试**，即可从中断处继续。

如果你正在手机上设置，又没有第二个屏幕可供扫描，请打开 **在手机上操作？改用代码关联**，输入电话号码并点按 **获取代码**。WhatsApp 随后会要求输入该代码。

在自己的电脑上：打开 **连接**，再打开 **聊天**，选择 WhatsApp，输入带国家区号的电话号码，然后点按 **连接**。页面会显示一个代码。在手机上的 WhatsApp 中，打开设置、已关联的设备、关联设备，然后选择 **改用手机号关联** 并输入代码。

也可以运行 `assistant connect whatsapp`，然后扫描终端中显示的代码。首次运行时，系统会提示安装 WhatsApp 连接器，这是一个固定版本的构建，已通过校验和验证（[来源](https://github.com/Salesflare/wacli)）。

在已关联的设备中，它会显示为 The Machine。之前关联过的 Machine 会继续显示旧名称，直到你重新关联。

## 图片

The Machine 会通过保持 WhatsApp 更新的同步流程，向 WhatsApp 请求 Graph 中尚无头像的联系人的头像，每天最多 50 个。不会向这些联系人发送任何内容。对你隐藏头像的人仍不会显示头像。

## 移除

- 在托管的 Machine 上：在设置页面中点按旁边的 **移除**。你的 Machine 会解除关联，并删除为 WhatsApp 保留的内容。
- 在自己的电脑上：打开 **连接**，选择 WhatsApp，再打开 **详情**，然后点按 **断开连接**。之后也要在手机上解除关联。

## 在 WhatsApp 中解除关联

在手机上的 WhatsApp 中，打开设置、已关联的设备，点按你的 Machine，然后退出登录。
