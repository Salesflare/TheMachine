## 各个标签页

- **待办**：你的待办和承诺。参阅[待办](cards.md)。
- **日历**：查看接下来一周的会议、截止待办和承诺。参阅[日历](calendar.md)。
- **例行程序**：你的Machine按固定节奏执行的工作，例如每周一生成摘要。参阅[例行程序](routines.md)。
- **Graph**：消息中提到的人、组织和项目，每个都有自己的页面，列在侧边栏中。参阅[Graph](graph.md)。
- **Fleet**：你在The Machine Network上的团队、家人和朋友，加入后即可查看。参阅[Fleet](fleet.md)。
- **心得**：查看待办的进展，以及它学到了什么。
- **连接**：查看你的信息来源及其运行情况。参阅[连接](connections.md)。

侧边栏顶部的**搜索或提问**可以查找待办、联系人、消息等，下方是**新建待办**。侧边栏底部有**浏览器**、**帮助**和**设置**。在手机上，点击顶栏中的菜单按钮即可打开侧边栏。

侧边栏会像待办页面一样列出你的待办。Fleet发来的请求也会显示在**待你处理**下，因此这里的数量与顶部的数量一致。点击一项即可打开。

要打开待办菜单，将光标移到待办上并点击**⋯**，右键点击，或在手机上长按。使用键盘时，在待办上按`Shift F10`。除了**重命名**和**打开**，菜单中还有该待办专属的**标记为已完成**、**稍后处理**和**不需要**，每项操作都可以**撤销**。

**浏览器**会显示你的Machine自己的浏览器，它会用这个浏览器访问LinkedIn等网站。在电脑上，浏览器会在侧边栏旁打开；点击待办中的**在浏览器中查看**，或在网站要求登录时点击**打开浏览器**，也会在这里打开。在手机浏览器中，它会在新标签页打开。在手机应用或添加到主屏幕的信息中心中，浏览器会占满屏幕；点击X返回。

点击**原尺寸**即可让浏览器占满整个窗口。再次点击即可返回。

待办正在使用浏览器时，顶部会显示**停止**。点击一次即可立即结束本次运行：不会再点击、输入或发送任何内容，待办的聊天中会显示“已从浏览器停止”。

如果有多个运行任务，会停止当前显示的那个。要继续操作，请在待办的聊天中输入内容，或点击**重试**。

待办太多而无法全部显示时，整个侧边栏会作为一列滚动。

在手机上，像**发送这封邮件？**这样的对话框会占满屏幕，输入时按钮也始终触手可及。

## 充分利用它

“待办”顶部有一项小待办，列出能让The Machine更实用的功能：手机应用、桌面应用、通知、WhatsApp、另一个账号以及更多连接。每一行都有一个按钮，可完成对应步骤；完成后，这一行就会从列表中消失，因此待办只显示尚未完成的步骤。最多显示五行，未完成的步骤排在前面。比如，邮件建议你使用的GitHub，会在前面的步骤完成后显示在列表中。

只有在适用的设备上才会显示对应行。例如，在没有安装桌面应用的电脑上（如Chromebook），这里会建议你从浏览器安装信息中心。点击某一行上的×，即可在所有设备上关闭这一行。点击顶部的×则会关闭整个待办。

第一天结束后，这项待办会折叠成**待你处理**上方的一行提示，例如“还剩2个步骤 · 继续”。点击提示即可打开待办，再点击箭头可重新折叠。

在最初两周内，如果当天新增待办不超过一项，待办开头可能会显示一条建议及原因，例如“连接WhatsApp？有5封邮件提到了它。”或“再试试WhatsApp？设置码已过期。”折叠时，待办只显示这条建议、对应按钮和×。它会替代该步骤通常显示的行。在首次了解流程结束时，会显示专属的后续步骤，在此之前这条建议会暂缓显示。

这些建议只根据The Machine已有的信息生成：邮件中指向WhatsApp的链接或提到WhatsApp的内容、尚未通过任何已连接邮箱导入的你的邮箱地址、Slack邮件或Teams会议邮件，以及未完成的连接。建议最多只会显示数量，不会透露消息内容或发件人。一次只显示一条，每天最多新增一条，也不会通过邮件或通知发送。点击×即可永久关闭。

点击**撤销**或**显示1项已隐藏**即可恢复某一行。要恢复整个待办，请前往“设置”>“常规”>“设置待办”。“设置”>“常规”>“此设备”中也有相同的控制选项；“设置”>“应用”中始终会显示手机应用，在电脑上还会显示桌面应用。

## 新版本

使用信息中心时，不会自动重新加载新版本。打开应用时，或者窗口在后台或闲置几分钟后，新版本才会加载。未保存的文字或打开的对话框不会受到影响。点击顶部的**更新已备好**即可立即加载新版本。

推出重要功能或改进时，会显示一条小小的**新功能**提示，每天最多一次。点击**返回**和**下一步**逐条查看，也可以滑动浏览。提示中的按钮会打开相应功能。点击**已完成**或**×**即可关闭。提示不会遮挡正在进行的操作，关闭后也不会在其他设备上再次显示。你只会看到开始使用后推出的更新。

## 消息

在Mac上按`⌘K`，在Windows和Linux上按`Ctrl K`，或点击手机上的搜索图标，即可打开搜索。输入至少两个字母后，**消息**会根据含义或关键词显示你Machine读过的所有内容中的最佳匹配结果。较早的[历史记录](history.md)仅按关键词匹配。

你也可以直接提问，例如空搜索框中显示的示例问题，系统会根据你自己的消息给出简短回答（[键盘和命令面板](keyboard.md)）。

点击**查看全部结果**可查看所有账号或某一个账号的完整结果列表。每条结果都会在阅读器中打开，并附上来源链接。搜索内容为空时，会显示最新消息。

搜索结果会优先显示最佳匹配项。手机上，如果消息预览对应的完整消息也在结果中，该消息只会显示一次。搜索所有账号并提问时，顶部会显示简短回答及其来源消息。如果消息中没有相关信息，就不会显示回答。

## 心得

“心得”会显示The Machine从你这里学到的内容，以及待办的效果。没有内容的标签页会隐藏。

- **我学到的内容**：根据你的消息生成的个人资料（角色、语气、语言、关注事项）、你的写作方式、事实，以及根据你的笔记总结出的偏好。你可以用自己的话**编辑**任何内容，也可以**移除**不再适用的内容。你的个人资料保存在`USER.md`中：编辑只会修改对应的一行，不会改动你之前在这里亲自修改过的行。你也可以让聊天助手忘记某件事（例如“忘记我搬家了”）：如果有一条事实明确符合，就会将其删除，并可在“设置”>**动态**和**更改**下方点击**撤销**。如果有多条符合，聊天助手会询问你要删除哪一条。笔记教会它一条事实或规则时，待办的聊天中会显示**已保存到“我学到的内容”**，并提供**编辑**和**撤销**选项。
- 一条事实可以标记为**临时**、**承诺**或**偏好**，并用**直到**指定其有效期限。临时事实会在几周后淡出，偏好和承诺会在几个月后淡出，其他事实则会在一年后淡出。超过设定日期，或有更新的消息表明该事实已不再成立时，该事实会移至**已结束**，点击**恢复**即可还原。
- **事实**保存通用信息，例如关于你和你的工作方式。关于某个人、组织或项目的事实会保存在Graph中对应的页面，在**已知信息**下编辑。保存时，如果事实中提到了某人的全名，就会将其移到对应页面，待办的聊天中会显示**已保存到**此人**在Graph中**。**事实**下方会显示一行提示，说明有多少条事实保存在Graph页面中；点击即可打开各个页面。来自你自己消息的事实会附上对应原文，并加上引号。
- 你为某人提供的电话号码或邮箱地址会添加到Graph中的对应页面，而不会放入事实。如果某条记录已有这个号码，且另一条记录的姓名相同，这两条记录就会合并。待办的聊天中会显示**添加到**和对方姓名，并提供**撤销**选项。如果无法确定信息对应谁，就会将其保留为事实。
- 内容不会因为闲置而被移除。每项待办都会使用与其最相关的事实，较新的事实权重更高。因此，即使某条事实很少用到，也会保留下来，不会挤占其他内容。已结束的事实仍会在待办或聊天涉及相关内容时提供帮助，但只作为历史信息，不会被当作当前情况。
- 如果一条笔记换种说法重复了已学到的内容，就会替换原有内容，避免重复列出。点击**撤销合并**可恢复旧表述。你亲自编辑过的内容不会被替换。
- **导入这些**：以前用过OpenClaw吗？其中值得保留的笔记行（`MEMORY.md`、`USER.md`）会显示在顶部，并标明来源文件。勾选要保留的内容，然后点击**保持勾选**：这些内容会像其他内容一样成为事实或规则。关于Graph中某个人的事实会移到对方的页面（生日信息也会加入“生日”例行程序）；关于你的事实会保留在“事实”中。点击**忽略其余内容**后，这些内容就不会再出现。文件不会被修改，如果文件中没有值得保留的内容，也不会显示任何内容。
- **从其他AI导入**：导入ChatGPT、Claude或Gemini对你的了解。选择助手，点击**复制提示词**，将提示词发给它，再把回复粘贴回来。点击**审核**可逐行决定保留、编辑或取消勾选。你之前告诉过它的内容会跳过；如果某一行与已有事实不一致，它会和对应事实一起显示，供你选择保留哪一条。在显示任何内容前，密码、设置码、密钥、银行卡号或账号号码都会被排除，试图授予权限的内容也会被排除。导入的事实仅作上下文参考，不代表授权。每条内容都会注明来源和时间，并标记为**仅作上下文参考，直到你编辑它**。设置待办中也会显示此功能，首次了解流程期间也会显示。
- **更改**：根据你的编辑、忽略操作和聊天内容学到的内容，每项都可以**撤销**。参阅[写作](writing.md#it-keeps-learning)。
- **决策**：按时间顺序查看你对待办做出的选择。
- **已分享**：查看可以分享给The Machine团队的心得，以及待你投票的内容（如果有）。参阅[分享心得](share-learnings.md)。
- **效果如何**：显示过去30天的四项数据，越高越好。至少决定了3项待办（执行或忽略）后才会开始显示；在此之前，会显示你目前决定了多少项。
  - **值得**：在你决定的待办中，有多少项是执行了（点击**执行**、发送或完成），而不是忽略。
  - **已完成**：在通过**执行**开始且已关闭的待办中，有多少项最终完成：对应步骤已结束、你手动标记为已完成，或待办自行以已完成状态关闭。忽略或过期的待办算作未完成。尚未关闭的待办暂不计入，并会标记为**仍在进行**。
  - **一次成功**：在已完成的待办中，有多少项在点击**执行**后不需要修改。
  - **已完成**和**一次成功**从3项待办起显示数据。
  - **原样发送**：在你发送的草稿中，有多少项在发送前未编辑，也未点击**要求修改**。
  - 每项数据都会与前30天进行对比。图表在前两周按天显示柱状图，之后按周显示，最长显示8周。
  - **按来源看价值**：按来源统计你执行的待办数量，例如**邮件**、**由你添加**（通过**新建待办**添加）、**Android通知**或**The Machine本身**（例如错误等问题）。
  - **错过的待办**：The Machine每周会检查一部分未生成待办的消息，并估算其中有多少可能需要生成待办。找到的消息会列在这里：点击**打开**或消息本身即可查看；点击**确实遗漏**或**不算遗漏**可告诉它判断是否正确。点击**确实遗漏**还会添加待办，并提供**撤销**选项（点击**打开待办**即可前往）。The Machine也会从你的反馈中学习，以后就能发现类似消息。你的回答会立即调整数字，并保存在你的Machine上。只剩下少数几项时，会显示**少数**，而不是百分比。首次每周检查后显示。
