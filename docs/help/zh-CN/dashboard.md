## 标签页

- **待办**：查看待办和承诺。参阅[待办](cards.md)。
- **日历**：查看未来一周的会议、截止待办和承诺。参阅[日历](calendar.md)。
- **例行程序**：查看 Machine 按固定节奏完成的工作，例如周一摘要。参阅[例行程序](routines.md)。
- **Graph**：查看消息中提到的人、组织和项目。侧边栏中每个对象都有自己的页面。参阅[Graph](graph.md)。
- **Fleet**：加入 The Machine Network 后，可以在这里查看团队、家人和朋友。参阅[Fleet](fleet.md)。
- **心得**：查看待办的进展，以及 The Machine 学到的内容。
- **连接**：查看你的信息来源及其运行情况。参阅[连接](connections.md)。

侧边栏顶部的**搜索或提问**可以查找待办、联系人、消息等，下方是**新建待办**。侧边栏底部有**浏览器**、**帮助**和**设置**。在手机上，点按顶栏中的菜单按钮即可打开侧边栏。

侧边栏中的待办列表与页面上的列表相同。Fleet 发来的请求也会显示在**给你**下，因此这里的数量与顶部的数量一致。点按一项即可打开。

要打开待办菜单，将鼠标悬停在待办上并点击**⋯**，右键点击，或在手机上长按。使用键盘时，将焦点移到待办上并按 `Shift F10`。除了**重命名**和**打开**，菜单中还有该待办的**标记为已完成**、**稍后处理**和**不需要**，每项操作都可以**撤销**。

**浏览器**会显示你的 Machine 使用的浏览器，例如访问 LinkedIn 时使用的浏览器。在电脑上，它会在侧边栏旁打开；待办中的**在浏览器中查看**，以及网站要求登录时出现的**打开浏览器**也会如此。在手机浏览器中，它会在新标签页打开。在手机应用或添加到主屏幕的控制面板中，它会铺满屏幕；点按 X 即可返回。

点按**原尺寸**即可让浏览器占满整个窗口。再次点按即可返回。

待办正在使用浏览器时，顶部会显示**停止**。点按一次即可立即结束这次操作：不会再点击、输入或发送任何内容，待办聊天中会显示“已从浏览器停止”。

如果同时有多个操作在运行，这会停止当前显示的操作。要继续操作，请在待办聊天中发送消息，或点按**重试**。

待办太多、无法全部显示时，整个侧边栏会作为一列滚动。

在手机上，像**发送这封邮件？**这样的对话框会铺满屏幕，输入时也能随时点按其中的按钮。

## 充分利用它

“待办”顶部会显示一个小待办，列出能让 The Machine 更实用的功能：手机应用、通知、WhatsApp、这台电脑上的应用、另一个账号，以及更多连接。每一行都有一个按钮，用于完成对应步骤。完成后，该行会从列表中消失，因此待办只显示剩余步骤。最多显示五行，未完成的步骤排在前面；例如，邮件中提到的 GitHub 等工具，会在前面的步骤完成后显示。

只有在适用时才会显示相应行。点按某一行上的 ×，可在所有设备上将其关闭。点按顶部的 ×，可关闭整个待办。

使用一天后，它会折叠成**给你**上方的一行简短提示，例如“还剩 2 个步骤 · 继续”。点按提示可打开待办，点按箭头可再次折叠。

点按**撤销**或**显示 1 项隐藏内容**可恢复某一行。要恢复整个待办，请前往**设置**、**常规**、**设置待办**。**设置**、**常规**中的**此设备**也有相同的控制选项，而**设置**、**应用**中始终会显示手机应用。

## 新版本

使用控制面板时，新版本不会自动重新加载。打开应用时，或窗口在后台或闲置几分钟后，新版本才会加载。未保存的文字或打开的对话框不会受到影响。点按顶部的**更新已备好**即可立即加载。

发布重要功能或改进时，会显示一条简短的**新功能**说明，每天最多显示一次。点按**返回**和**下一步**，或滑动屏幕即可浏览。说明中的按钮可打开相应功能。点按**已完成**或**×**即可关闭。它不会遮挡你正在进行的操作，关闭后也会在所有设备上消失。你只会看到开始使用后发布的内容。

## 消息

在 Mac 上按 `⌘K`，在 Windows 或 Linux 上按 `Ctrl K`，或在手机上点按搜索图标，即可打开搜索。输入至少两个字母后，**消息**会按含义或文字，从 The Machine 读过的所有内容中显示最匹配的结果。较早的[历史记录](history.md)只能按文字匹配。

你也可以在这里提问，就像空搜索框中显示的建议问题一样，获取来自你自己消息的简短回答（[键盘和命令面板](keyboard.md)）。

点按**查看全部结果**可打开完整列表，查看所有账号或某个账号的结果。点按某条结果，会在阅读器中打开，并附上来源链接。搜索内容为空时，会显示最新消息。

搜索会先显示最匹配的结果。如果手机上预览的消息已有完整内容，该消息只会显示一次。使用所有账号提问时，顶部会显示简短回答，并附上答案来源消息。如果消息中没有相关信息，则不会显示答案。

## 学习

“学习”会显示 The Machine 从你这里学到的内容，以及待办的效果。没有内容的标签页会隐藏。

- **我学到的内容**：显示你在笔记中体现的写作方式、事实和偏好。你可以用自己的话**编辑**任何内容，也可以**移除**不再正确的内容。你还可以在聊天中要求忘记某件事（例如“忘记我搬家了”）：如果明确匹配到一条事实，该事实就会被删除；你可以在**设置**、**动态**和**更改**中**撤销**。如果匹配到多条事实，聊天会询问你要删除哪一条。笔记中有事实或规则值得记录时，待办聊天会显示**已保存到“我学到的内容”**，并提供**编辑**和**撤销**。
- 事实可以标记为**临时**、**承诺**或**偏好**，并设置其生效时间**直到**何时。临时事实会在几周后淡出，偏好和承诺会在几个月后淡出，其他事实则会在一年后淡出。过了设定日期，或有较新的消息表明事实已不再成立时，该事实会移至**已结束**，点按**恢复**即可还原。
- **事实**会保留一般性内容，例如关于你和你的工作方式的信息。关于某个人、组织或项目的事实，会显示在 Graph 中对应的页面下方**已知信息**中，你可以在那里编辑。保存时，如果事实中提到了某人的全名，就会将其保存到对应页面，待办聊天会显示**已保存到**此人**在 Graph 中的页面**。**事实**下方会显示一行简短提示，说明有多少条事实保存在 Graph 页面中。打开提示即可前往各个页面。来自你自己消息的事实会显示其来源原文，并加上引号。
- 你提供的某人的电话号码或电子邮件地址会保存到 Graph 中对应的页面，而不是事实里。如果号码已存在于一条记录中，且另一条记录有相同姓名，这两条记录会合并。待办聊天会显示**添加到**以及此人的姓名，并提供**撤销**。如果无法确定信息属于谁，就会将其保留为事实。
- 列表不会装满。事实和规则如果三周内都没有用到，就会移至**搁置**；点按**恢复**即可还原。你编辑或恢复过的内容会保留，来自其他 AI 的内容则会排在你自己的内容之前。搁置的事实仍会在待办或聊天涉及相关内容时提供帮助；已结束的事实只会作为历史记录，不会被当作当前情况。
- 如果一条笔记用不同措辞重复了已学到的内容，它会替换原内容，避免重复列出。点按**撤销合并**可恢复旧措辞。你亲自编辑的内容永远不会被替换。
- **导入这些内容**：以前用过 OpenClaw 吗？其笔记（`MEMORY.md`、`USER.md`）中值得保留的内容会显示在顶部，每条都标明来源文件。勾选要保留的内容，然后点按**保持勾选**：这些内容会像其他内容一样成为事实或规则。关于 Graph 中某个人的事实会移至对应页面（生日也会添加到“生日”例行程序）；关于你的事实则会保留在“事实”中。点按**忽略其余内容**后，这些内容不会再出现。文件不会被修改；如果文件中没有值得保留的内容，也不会显示任何内容。
- **从其他 AI 导入**：导入 ChatGPT、Claude 或 Gemini 对你的了解。选择助手，点按**复制提示词**，将提示词发送给它，然后把它的回答粘贴回来。点按**审核**，即可逐条保留、编辑或取消勾选。你已经告诉过它的内容会被跳过；与现有事实不一致的内容会显示在对应事实旁边，供你选择保留哪一条。密码、验证码、密钥、银行卡号或账号会在显示前排除，试图授予权限的内容也会被排除。导入的事实仅作上下文参考，不代表权限。每条事实都会注明来源和时间，并标记为**仅作上下文参考，直到你编辑它**。设置待办中也可以导入，在首次查看内容时也会显示。
- **更改**：显示 The Machine 从你的编辑、忽略操作和聊天中学到的内容，每项都可以**撤销**。参阅[写作](writing.md#it-keeps-learning)。
- **决策**：按时间顺序显示你对待办做出的选择。
- **已分享**：显示要分享给 The Machine 团队的心得，以及等待你投票的内容（如果有）。参阅[分享心得](share-learnings.md)。
- **效果如何**：显示过去 30 天的四项数据，数值越高越好。你做出决定的待办达到 3 项后才会开始显示数据（已执行或已忽略）；在此之前，会显示你已经决定了多少项。
  - **值得**：在你已做出决定的待办中，有多少项被你执行了（点按**执行**、已发送或已完成），而不是被忽略。
  - **一次成功**：在你通过**执行**开始处理的待办中，有多少项之后不需要修正。
  - **已完成**：在你通过**执行**开始处理的待办中，有多少项无需你要求继续或重试就已完成。
  - **原样发送**：在你发送的草稿中，有多少项没有经过编辑或**要求修改**就直接发送。
  - 每项数据都会与之前的 30 天进行比较。图表前两周按天显示柱形，之后按周显示，最长可查看 8 周。
  - **按来源看价值**：显示你按来源执行的待办数量，例如**邮件**、**由你添加**（通过**新建待办**）、**手机通知**或**The Machine本身**（例如错误等问题）。
  - **错过的待办**：The Machine 每周会检查一部分没有生成待办的消息，并估算其中可能需要待办的数量。它会列出找到的消息：点按**打开**或消息本身即可查看；点按**确实遗漏**或**不算遗漏**可告诉 The Machine 判断是否正确。点按**确实遗漏**还会创建待办，并提供**撤销**（点按**打开待办**即可前往）；The Machine 也会从中学习，以后能识别类似消息。你的回答会提高数据准确性，并保留在你的 Machine 上。首次每周检查后才会显示。
