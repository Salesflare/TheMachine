## 标签页

- **待办**：你的待办和承诺。请参阅[待办](cards.md)。
- **日历**：接下来一周的会议、待办截止日期和承诺。请参阅[日历](calendar.md)。
- **例行程序**：Machine 按固定节奏执行的工作，例如每周一生成摘要。请参阅[例行程序](routines.md)。
- **Graph**：消息中提到的人、组织和项目，侧边栏中每个对象都有自己的页面。请参阅[Graph](graph.md)。
- **Fleet**：你在 The Machine Network 上的团队、家人和朋友（加入后即可查看）。请参阅[Fleet](fleet.md)。
- **心得**：待办的进展，以及 The Machine 学到的内容。
- **连接**：你的信息来源及其状态。请参阅[连接](connections.md)。

侧边栏顶部的**搜索或提问**可以查找待办、联系人、消息等，下方就是**新建待办**。底部有**浏览器**、**帮助**和**设置**。在手机上，点按顶部栏中的菜单按钮即可打开侧边栏。

侧边栏中的待办列表与页面上的列表一致。Fleet 发来的请求也会显示在**给你**下方，因此这里的数量与顶部显示的数量一致。点按一项即可打开。

要打开待办的菜单，将鼠标悬停在待办上并点击 **⋯**，右键点击，或在手机上按住待办。使用键盘时，选中待办后按 `Shift F10`。菜单中除了**重命名**和**打开**，还有该待办专属的**标记为已完成**、**稍后处理**和**不需要**选项，每项操作都可以**撤销**。

**浏览器**会显示 Machine 自己的浏览器，也就是它用来访问 LinkedIn 等网站的浏览器。在电脑上，浏览器会在侧边栏旁边打开，待办中的**在浏览器中查看**和网站要求登录时显示的**打开浏览器**也一样。在手机浏览器中，它会在新标签页打开。在手机应用中，或将控制面板添加到手机主屏幕后，它会铺满屏幕；点按 X 即可返回。

点按**原尺寸**可让浏览器占满整个窗口。再次点按即可返回。

待办正在使用浏览器时，顶部会显示**停止**。点按一次即可立即结束这次操作：不会再点击、输入或发送任何内容，待办的聊天中会显示“已从浏览器停止”。

如果同时有多项操作在运行，会停止当前显示的那项。要继续操作，请在待办的聊天中发送消息，或点按**重试**。

待办太多而无法全部显示时，整个侧边栏会作为一列滚动。

在手机上，像**发送这封邮件？**这样的对话框会铺满屏幕，按钮始终触手可及，输入内容时也一样。

## 充分利用 The Machine

待办页面顶部有一条小待办，列出能让 The Machine 更好用的事项：手机应用、通知、WhatsApp、这台电脑上的应用、另一个账户，以及更多连接。每一行都有一个按钮，用于完成相应步骤。完成后，该行就会从列表中消失，因此这里只显示剩余事项。列表最多显示五行，未完成的步骤优先显示。例如，邮件中提到的工具（如 GitHub）会在较早步骤完成后出现在列表中。

只有适用的设备上才会显示相应事项。点按某一行上的 × 会在所有设备上将它关闭。点按待办顶部的 × 会关闭整个待办。

第一天过后，它会收起成一行简短提示，显示在**给你**上方，例如“还剩 2 个步骤 · 继续”。点按提示可打开待办，点按箭头可再次收起。

点按**撤销**或**显示 1 项隐藏内容**可恢复某一行。要恢复整个待办，请前往**设置**、**常规**、**设置待办**。**设置**中的**常规**、**此设备**也有相同的控件，而**设置**中的**应用**始终会显示手机应用。

## 新版本

使用控制面板时，即使有新版本，也不会自动刷新。只有打开应用，或窗口在后台或闲置几分钟后，才会加载新版本。未保存的文字或打开的对话框不会被打断。点按顶部的**更新已备好**可立即加载新版本。

推出重要功能或改进后，会显示一条简短的**新功能介绍**，每天最多显示一次。点按**返回**和**下一步**，或滑动即可浏览。介绍中的按钮可打开相应功能。点按**已完成**或 **×** 即可关闭。介绍不会遮挡正在进行的操作，关闭后会在所有设备上消失。你只会看到开始使用后推出的内容。

## 消息

在 Mac 上按 `⌘K`，在 Windows 和 Linux 上按 `Ctrl K`，或在手机上点按搜索图标，即可打开搜索。输入至少两个字母后，**消息**会根据含义或字词，从 Machine 读过的所有内容中显示最匹配的结果。较早的[历史记录](history.md)只按字词匹配。

你也可以在这里提问，例如输入空搜索框中的建议问题，即可根据自己的消息获得简短回答（[键盘和命令面板](keyboard.md)）。

点按**查看全部结果**可打开完整列表，查看所有账户或某个账户的结果。点按结果可在阅读器中打开，并查看来源链接。搜索框为空时，会显示最新消息。

搜索结果会先显示最匹配的内容。如果手机预览中的消息已有完整内容，只会显示一次，并以该消息的形式呈现。搜索所有账户并提问时，顶部会显示简短回答，并附上相关消息。如果消息中没有答案，就不会显示回答。

## 心得

心得会显示 The Machine 从你这里学到的内容，以及待办的效果。没有内容的标签页会隐藏。

- **我学到的内容**：从你的笔记中了解你的写作方式、事实信息和偏好的做事方式。你可以用自己的话**编辑**其中任何内容，也可以**移除**不再正确的内容。你也可以在聊天中要求 The Machine 忘记某件事（“忘记我搬家了”）：如果明确匹配到一条事实，就会将其删除，并可在**设置**中的**动态**和**更改**下点按**撤销**。如果匹配到多条，聊天会询问你要删除哪一条。当笔记中包含事实或规则时，待办的聊天会显示**已保存到“我学到的内容”**，并提供**编辑**和**撤销**选项。
- 事实可以标记为**临时**、**承诺**或**偏好**，并设置其有效时间**直到**何时。临时事实会在几周后淡出，偏好和承诺会在几个月后淡出，其他事实会在一年后淡出。超过设定日期，或有更新的消息表明事实已不再成立时，该事实会移到**已结束**，点按**恢复**即可还原。
- **事实**保存一般性信息，例如关于你和你的工作方式的事实。关于某个人、组织或项目的事实会保存在 Graph 中对应的页面下，位于**已知信息**中，可在此编辑。保存时，如果事实中提到某个人的全名，就会归到对应页面，待办的聊天会显示**已保存到**对方的**Graph**页面。**事实**下方会显示一条简短提示，说明有多少条事实保存在 Graph 页面中。打开提示即可前往相应页面。来自你自己的消息的事实会用引号显示其来源文字。
- 你提供的某人的电话号码或电子邮件地址会保存到 Graph 中对方的页面，而不会加入事实。如果号码已保存在一条记录中，且另一条记录中的姓名相同，系统会合并这两条记录。待办的聊天会显示**添加到**和对方的姓名，并提供**撤销**选项。如果无法确定信息对应谁，就会将其保留为事实。
- 列表不会塞满内容。列表变长时，三周内未使用的事实和规则会移到**搁置**，点按**恢复**即可还原。你编辑或恢复的内容会保留在原位。搁置的事实仍会在待办或聊天涉及相关内容时发挥作用；已结束的事实只会作为历史记录，不会再被当作当前情况。
- 如果新笔记用不同说法表达了已学到的内容，就会替换原内容，避免重复列出。点按**撤销合并**可恢复原来的说法。你自己编辑的内容不会被替换。
- **导入这些**：以前用过 OpenClaw 吗？其笔记（`MEMORY.md`、`USER.md`）中值得保留的内容会显示在顶部，并注明来源文件。勾选要保留的内容，然后点按**保持勾选**，这些内容就会像其他内容一样成为事实或规则。关于 Graph 中某个人的事实会移到对方的页面（生日也会添加到生日例行程序）；关于你的事实则会保留在“事实”中。点按**忽略其余内容**后，其他内容不会再出现。文件不会被修改，如果文件中没有值得保留的内容，就不会显示任何内容。
- **从其他 AI 导入**：导入 ChatGPT、Claude 或 Gemini 了解到的关于你的信息。选择助手，点按**复制提示词**，将提示词发送给它，然后把回复粘贴回来。点按**审核**可逐条决定保留、编辑或取消勾选。你已经告诉过 The Machine 的内容会被跳过，与现有事实不一致的内容会和该事实并排显示，供你选择保留哪一项。密码、验证码、密钥、银行卡号或账户号码会在显示前排除，试图授予权限的内容也会排除。导入的事实仅作上下文参考，不代表获得授权。每条内容都会注明来源和时间，并标记为**仅作上下文参考，直到你编辑它**。设置待办中以及首次查看读取内容时也可以导入。
- **更改**：The Machine 根据你的编辑、忽略操作和聊天学到的内容，每项都可以**撤销**。请参阅[写作](writing.md#it-keeps-learning)。
- **决策**：记录你对待办所做选择的时间线。
- **已分享**：与 The Machine 团队分享的心得，以及待你投票的内容（如果有）。请参阅[分享心得](share-learnings.md)。
- **效果如何**：显示过去 30 天的四项数据，数值越高越好。决定过 3 项待办（执行或忽略）后才会开始显示数据；在此之前，会显示你已经决定的待办数量。
  - **值得**：在你已经决定的待办中，有多少是你选择执行的（点按**执行**、发送或完成），而不是忽略的。
  - **一次成功**：在你选择**执行**的待办中，有多少之后无需修改。
  - **已完成**：在你选择**执行**的待办中，有多少在你没有要求继续或重试的情况下完成。
  - **原样发送**：在你发送的草稿中，有多少没有经过编辑或点按**要求修改**就直接发送。
  - 每项数据都会与之前 30 天进行比较。图表前两周按天显示柱状图，之后按周显示，最多显示 8 周。
  - **按来源看价值**：按来源查看你执行的待办数量，例如**邮件**、**由你添加**（通过**新建待办**添加）、**手机通知**或**The Machine本身**（例如错误等问题）。
  - **错过的待办**：The Machine 每周会抽查一部分没有生成待办的消息，并估算其中可能需要待办的数量。它会列出找到的消息：点按**打开**或消息所在的行即可查看消息，点按**确实遗漏**或**不算遗漏**可告知 The Machine 判断是否正确。点按**确实遗漏**也会添加待办，并提供**撤销**选项（点按**打开待办**可前往该待办）。The Machine 会从你的反馈中学习，以后就能识别类似消息。你的回答会让统计更准确，并保存在你的 Machine 上。第一次每周检查后才会显示此项。
