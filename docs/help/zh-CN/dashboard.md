## 标签页

- **待办**：你的待办和承诺。请参阅[待办](cards.md)。
- **日历**：接下来一周的会议、截止日期和承诺。请参阅[日历](calendar.md)。
- **例行程序**：The Machine 按固定节奏处理的工作，例如每周一生成摘要。请参阅[例行程序](routines.md)。
- **Graph**：消息中提到的人、组织和项目，它们各自在侧边栏中都有自己的页面。请参阅[Graph](graph.md)。
- **Fleet**：你在 The Machine Network 上的团队、家人和朋友，前提是你已经加入 Fleet。请参阅[Fleet](fleet.md)。
- **心得**：待办的完成情况，以及 The Machine 学到的内容。
- **连接**：你的信息来源及其运行情况。请参阅[连接](connections.md)。

侧边栏顶部的**搜索或提问**可查找待办、人员、消息等内容，下方紧接着是**新建待办**。侧边栏底部有**浏览器**、**帮助**和**设置**。手机上，点按顶栏中的菜单按钮即可打开侧边栏。

侧边栏中的待办列表和页面上的列表相同。Fleet 发来的请求也会显示在**给你**下，因此这里的数量与顶部的数量一致。点按某项即可打开。

如需打开待办菜单，将鼠标悬停在待办上并点击 **⋯**，右键点击，或在手机上长按。使用键盘时，选中待办后按 `Shift F10`。除了**重命名**和**打开**，菜单中还有该待办自己的**标记为已完成**、**稍后处理**和**不需要**选项，每项都可以**撤销**。

**浏览器**会显示 The Machine 自己的浏览器，The Machine 用它浏览 LinkedIn 等网站。在电脑上，浏览器会在侧边栏旁边打开，待办中的**在浏览器中查看**以及网站要求登录时出现的**打开浏览器**也是如此。在手机浏览器中，浏览器会在新标签页中打开。在手机应用中，或将控制面板添加到主屏幕后，浏览器会铺满屏幕；点按 X 可返回。

点按**原尺寸**可让浏览器占满整个窗口。再次点按即可返回。

待办正在使用浏览器时，顶部会显示**停止**。点按一次即可立刻结束这次运行：后续操作会全部停止，不会再点击、输入或发送任何内容，待办的聊天中会显示“已从浏览器停止”。

如果同时有多个运行任务，停止会结束当前显示的那个。要继续操作，请在待办的聊天中输入内容，或点按**重试**。

待办多到无法全部显示时，整个侧边栏会作为一列滚动。

手机上，像**发送这封邮件？**这样的对话框会铺满屏幕，输入时按钮也始终触手可及。

## 充分利用 The Machine

待办页面顶部的小待办会列出能让 The Machine 更实用的项目：手机应用、通知、WhatsApp、这台电脑上的应用、另一个账户以及更多连接。每一行都有一个按钮，用来完成相应步骤。完成后，该行就会从列表中消失，因此待办中只显示尚未完成的项目。最多显示五行，未完成的步骤排在前面；因此，邮件建议使用的工具（例如 GitHub）会在前面的步骤完成后出现。

这些行只会在适用的地方显示。点按某行上的 ×，可在所有设备上关闭该行。点按顶部的 ×，可关闭整个待办。

使用满一天后，这个待办会收起成**给你**上方的一行提示，例如“还剩 2 个步骤 · 继续”。点按提示可打开待办，点按箭头可再次收起。

点按**撤销**或**显示 1 项隐藏内容**可恢复某一行。要恢复整个待办，请前往**设置**、**常规**、**设置待办**。**设置**、**常规**、**此设备**中也有相同的控制选项；**设置**、**应用**中始终会显示手机应用。

## 新版本

使用控制面板时，即使有新版本，也不会重新加载。只有在打开应用时，或窗口在后台或闲置几分钟后，才会加载新版本。未保存的文字或打开的对话框不会受到影响。点按顶部的**更新已备好**即可立即加载。

推出重要功能或改进时，会显示一条简短的**新功能**说明，每天最多显示一次。使用**返回**和**下一步**浏览，也可以滑动浏览。说明中的按钮会打开相应功能。点按**已完成**或 **×** 可关闭说明。说明不会覆盖正在进行的操作，关闭后也会在所有设备上消失。只会显示你开始使用后推出的内容。

## 消息

在 Mac 上按 `⌘K`，在 Windows 和 Linux 上按 `Ctrl K`，或在手机上点按搜索图标，即可打开搜索。输入至少两个字母后，**消息**会按意思或文字显示 The Machine 读取过的所有内容中最匹配的结果。较早的[历史记录](history.md)只按文字匹配。

你也可以在这里提问，例如空搜索框中显示的示例问题，The Machine 会根据你的消息简短作答（[键盘和命令面板](keyboard.md)）。

点按**查看所有结果**可打开完整列表，并查看所有账户或某个账户的结果。点按结果后会在阅读器中打开，并附上来源链接。搜索内容为空时，会显示最新的消息。

搜索会优先显示最匹配的结果。如果某条消息在手机上已有预览，且完整内容也出现在搜索结果中，则这条消息只显示一次。搜索所有账户并提问时，顶部会显示简短答案，并附上答案来源的消息。如果消息中没有答案，就不会显示答案。

## 心得

“心得”会显示 The Machine 从你这里学到的内容，以及待办的完成情况。没有内容的标签页会隐藏。

- **我学到的内容**：从你的笔记中学到的写作习惯、事实，以及你喜欢的做事方式。你可以用自己的话**编辑**任何内容，也可以**移除**不再正确的内容。你也可以在聊天中让 The Machine 忘记某件事（“忘记我搬家了”）：如果明显对应一条事实，就会将其删除，并在**设置**、**动态**和**更改**中提供**撤销**选项。如果有多条事实都可能对应，聊天会询问你要删除哪一条。当一条笔记让 The Machine 学到事实或规则时，待办的聊天中会显示**已保存到“我学到的内容”**，并提供**编辑**和**撤销**选项。
- 事实可以是**临时**的、**承诺**或**偏好**，并可设置其生效的**直到**日期。临时事实会在几周后淡出，偏好和承诺会在几个月后淡出，其他事实则会在一年后淡出。超过设定日期，或新消息表明事实已不再成立时，该事实会移至**已结束**，你可以用**恢复**将其还原。
- **事实**中保存通用事实，例如关于你以及你的工作方式。关于某个人、组织或项目的事实会保存在 Graph 中对应的页面下方的**已知信息**中，你可以在那里编辑。如果事实中提到了某人的全名，保存后就会移至该人的页面，待办的聊天中会显示已**添加到**对方的**Graph**页面。**事实**下方会显示一行提示，说明有多少条事实保存在 Graph 页面中；点开即可前往相应页面。来自你自己消息的事实会附上引用内容。
- 你提供的某人的电话号码或电子邮件地址会保存到 Graph 中对方的页面，而不会添加到事实中。如果号码已经关联到一条记录，且另一条记录的姓名相同，这两条记录就会合并。待办的聊天中会显示**添加到**以及对方姓名，并提供**撤销**选项。如果无法确定信息属于谁，就会将其保留为事实。
- 列表不会塞满。列表变长时，连续三周未使用的事实和规则会移至**搁置**，你可以用**恢复**还原其中一条。你编辑或恢复过的内容会保留在原处。处理相关待办或聊天时，搁置的事实仍会发挥作用；已结束的事实只会作为历史记录使用，不会被当作当前情况。
- 如果一条笔记换了说法，但表达的内容已经学过，就会替换原内容，避免重复列出。点按**撤销合并**可恢复旧的表述。你自己编辑过的内容不会被替换。
- **导入这些**：以前用过 OpenClaw 吗？如果其笔记（`MEMORY.md`、`USER.md`）中有值得保留的内容，这些内容会显示在顶部，并注明各自来源的文件。勾选要保留的内容，然后点按**保持勾选**：它们会像其他内容一样成为事实或规则。关于 Graph 中某个人的事实会移至该人的页面（生日也会添加到“生日”例行程序中）；关于你自己的事实会保留在“事实”中。点按**忽略其余内容**后，这些内容就不会再出现。文件不会被修改；如果文件中没有值得保留的内容，就不会显示任何内容。
- **更改**：从你的编辑、忽略操作和聊天中学到的内容，每项都可以**撤销**。请参阅[写作](writing.md#it-keeps-learning)。
- **决策**：记录你对待办所做选择的时间线。
- **已分享**：与 The Machine 团队分享的心得，以及等待你投票的内容（如果有）。请参阅[分享心得](share-learnings.md)。
- **运行情况**：显示过去 30 天的四项数据，数值越高越好。决定过 3 个待办（已执行或已忽略）后，数据才会开始显示；在此之前，会显示你已经决定了多少个待办。
  - **值得**：在你决定过的待办中，有多少个被你执行了（点按**执行**、已发送或已完成），而不是被忽略。
  - **一次成功**：在你通过**执行**开始处理的待办中，有多少个之后无需修改。
  - **已完成**：在你通过**执行**开始处理的待办中，有多少个无需你要求继续或重试就已完成。
  - **原样发送**：在你发送的草稿中，有多少个未编辑，也未先点按**要求修改**。
  - 每项数据都会与之前的 30 天进行比较。图表前两周按天显示柱状图，之后按周显示，最多展示 8 周。
  - **按来源看价值**：按来源统计你执行了多少个待办，例如**邮件**、**由你添加**（通过**新建待办**添加）、**手机通知**或**The Machine本身**（例如错误等问题）。
  - **错过的待办**：The Machine 每周会抽样检查一部分没有生成待办的消息，并估算其中有多少条可能需要待办。检查结果会列出找到的消息：点按**打开**或消息所在的行可查看消息，再点按**确实遗漏**或**不算遗漏**告诉 The Machine 判断是否正确。点按**确实遗漏**还会添加待办，并提供**撤销**选项（点按**打开待办**可前往该待办）。The Machine 也会从你的反馈中学习，以后会识别类似的消息。你的回答会让统计数字更准确，并保留在你的 Machine 上。首次每周检查后会显示此项。
