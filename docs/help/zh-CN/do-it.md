## 执行会做什么

**执行**会让你的 Machine 准备好待办事项：起草回复、查找信息、填写表单。它会像你一样使用你的账号和自己的浏览器。

它在浏览器中操作时，待办事项和聊天会实时显示当前页面，包括操作步骤之间，直到它在页面上完成操作。点击画面即可打开浏览器。在待办事项中，页面会以更大的尺寸显示，并提供**停止**：按一次就会立即结束本次运行。

在继续操作或转交之前，它会检查是否有更新的回复，包括队友的回复。如果事情已经处理完毕，待办事项会说明这一点。如果它修改了文档或页面，待办事项会附上链接。

在网站或工作流程中成功完成复杂任务后，你的 Machine 会将操作步骤保存为技能，不包含任何人的个人信息。之后在该网站上的待办事项会将这些步骤用作指引，但绝不会视为许可：发送或付款仍需你批准。你可以在**设置 > 技能**中找到这些技能，标记为**从任务中学到的**。

## 未经你确认，不会发送任何内容

- 回复会先以草稿形式提供。点击**审核并发送**即可打开并编辑草稿；只有按下**立即发送**后，内容才会发出。
- 一个待办事项中有两封或更多邮件时，可以在聊天中用一个按钮审核所有邮件。邮件会逐封显示，点击**下一步**即可继续；最后一步会发送所有邮件。每封邮件只有在实际发出后才会标记为已发送。
- 邮件会按实际发送后的样子显示，包括粗体、列表和链接。Slack 或聊天消息则以纯文本显示。
- 在同一窗口中点击**要求修改**，说明要修改的内容，你的 Machine 就会重新起草。
- 回复会回复邮件对话中的最新一封邮件，待办事项的来源链接会打开那封邮件。
- 提交、付款或预订等会正式生效的步骤，需要你确认，或在聊天中提出要求后才会执行。确认一个步骤不会让其他步骤自动执行：所有步骤都完成后，待办事项才会关闭。
- 点击这类步骤前，待办事项和聊天会显示该步骤会发送的内容。日历邀请会显示标题、时间、受邀人，以及是否会添加会议链接。
- 查找时间时，会考虑已连接的日历：它会先查看你那些日期的会议，再提供可选时间。
- 在待办事项的聊天中，草稿绝不会和起草它的同一条消息一起发送。
- 在你批准之前，待办事项会以**已备好**状态显示在**给你**中，列表也会说明未经批准不会发送任何内容。仍需你处理的待办事项会标记为**需要你**。只有回复实际发出后，待办事项才会显示已发送。
- 长草稿会先显示前 3 行。点击**展开**或草稿文本即可查看其余内容；点击**审核并发送**始终会显示完整草稿。

根据来源不同，它可以发送电子邮件、Slack 私信，或 WhatsApp、Telegram、LinkedIn 或 X 消息。每个连接的说明文章都会介绍它可以发送哪些内容。

## 编辑邮件

- 使用文本上方的按钮，或使用 `Ctrl B` 加粗、`Ctrl I` 设为斜体、`Ctrl K` 添加链接（Mac 上使用 `⌘`）。此外还有项目符号列表和编号列表按钮。
- 链接地址必须以 https:// 开头。粘贴的文本会以纯文本形式插入，不保留颜色或图片。
- 邮件不支持的格式会先移除，消息会显示发送后的样子。再次按下**立即发送**即可发送。
- 邮件会按显示的样子原样发出，并附带纯文本副本，供不显示格式的邮件应用使用。

## 无法继续时

- “无法从这里发送此内容。”表示你需要点击**复制草稿**，然后自行发送。
- **需要你帮忙**表示它有问题要问：点击**回复**作答。**卡住**表示它没有问题要问，但操作停止了；待办事项会说明原因。
- 有多个问题？每个问题都有自己的选项或简短输入框，有时会预先填入你上次的回答。点击**回复**即可一次提交所有回答。
- 缺少只有你才有的信息？它会向你询问，并只起草不依赖该信息的内容，例如确认日期的回复。它不会只起草一句“稍后发送”。
- 点击**重试**可再运行一次。点击**要求修改**可要求它做其他事情。对于卡住的待办事项，**重试**会优先显示；点击**详情**可查看它尝试过的操作。
- 如果是本次运行本身出错而卡住，你的 Machine 更新后会自动再尝试一次。
- 本次运行失败时，它最多会自动重试两次。之后会等待新内容，例如新消息、你在聊天中的留言，或你点击**重试**。
- 准备过程中，待办事项会用简短文字说明你的 Machine 正在做什么，例如“正在阅读邮件”“正在阅读 PDF”或“正在起草回复”。详细步骤会显示在待办事项的聊天中。
- 标记为**准备中…**的待办事项会在几秒内开始。如果需要等待，它会说明原因和大致等待时间，例如“当前任务完成后开始”。
- 你的 Machine 可能会在你提出要求前先准备好待办事项，但为了节省用量，暂时不会开始。它仍会显示**执行**：按下即可立即开始，优先于其他待办事项。未经你确认，不会发送任何内容。如果你的 AI 套餐达到用量上限，执行会说明情况，并在用量上限重置后开始。
- 如果网站要求登录，点击**登录**，或点击**打开浏览器**并在那里登录。之后它会自动继续。如果没有继续，点击**继续**。
- 发送到手机的验证码或缺少权限都会让操作暂停。待办事项会说明需要什么，然后提供**继续**或**重试**。如果来源尚未连接，例如 Slack，待办事项会显示**连接 Slack**，连接 Slack 后它会自动继续。
