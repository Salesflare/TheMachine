## 执行会做什么

**执行**会让你的 Machine 准备待办事项：拟好回复草稿、查找信息或填写表单。它会像你一样使用自己的账户和浏览器。

它在浏览器中操作时，待办事项和聊天会实时显示当前页面，包括操作步骤之间的页面，直到任务完成。点击页面图片即可打开浏览器。在待办事项中，图片会放大显示，并提供**停止**按钮：按一次就会立即结束本次运行。

转交之前或进行后续操作之前，它会检查是否有新回复，包括队友的回复。如果事情已经处理完毕，待办事项会说明这一点。如果它更改了文档或页面，待办事项会附上链接。

## 未经你同意，不会发送任何内容

- 回复会先以草稿形式返回。点击**审核并发送**即可打开草稿进行编辑；只有点击**立即发送**后，内容才会发出。
- 一个待办事项中有两封或更多邮件时，可以在聊天中通过一个按钮审核所有邮件。邮件会依次显示，每封都可以点击**下一步**查看，最后一步会发送所有邮件。每封邮件只有在发出后才会显示为已发送。
- 邮件会按实际发送时的样式显示，包括粗体、列表和链接。Slack 或聊天消息则显示为纯文本。
- 可以在同一个窗口中点击**要求修改**，说明要改什么，Machine 就会重新拟写草稿。
- 回复会回应邮件主题中的最新一封邮件，待办事项中的来源链接会打开那封邮件。
- 提交、付款或预订等会正式完成操作的步骤，需要等你确认，或者等你在聊天中提出要求。确认一个步骤不会让其他步骤自动完成：所有步骤都完成后，待办事项才会关闭。
- 待办事项和聊天会在你点击发送之前，显示此类步骤会发送的内容。日历邀请会显示标题、时间、来宾，以及是否添加会议链接。
- 查找时间时会考虑已连接的日历：它会先查看你那几天的会议，再提供可选时间。
- 在待办事项的聊天中，草稿不会和写出草稿的同一条消息一起发送。
- 在你批准之前，待办事项会在**给你**下等待，并标记为**已备好**；列表会提示内容只有在你批准后才会发出。仍需要你处理的待办事项会标记为**需要你**。只有回复发出后，待办事项才会显示它已发出。
- 较长的草稿会先显示开头 3 行。点击**展开**或草稿文字即可查看剩余内容；**审核并发送**始终会显示完整草稿。

根据来源不同，它可以发送邮件、Slack 私信，或 WhatsApp、Telegram、LinkedIn、X 消息。每种连接的帮助文章都会说明它能发送哪些内容。

## 编辑邮件

- 使用文字上方的按钮，或使用 `Ctrl B` 加粗、`Ctrl I` 设为斜体、`Ctrl K` 添加链接（Mac 上使用 `⌘`）。也有项目符号列表和编号列表按钮。
- 链接地址必须以 https:// 开头。粘贴的文字会以纯文本形式添加，不保留颜色或图片。
- 邮件不支持的格式会先移除，消息也会显示实际发送效果。再次点击**立即发送**即可发送。
- 邮件会按显示的内容原样发出，并附带一份纯文本副本，供无法显示格式的邮件应用使用。

## 无法完成时

- “无法从这里发送。”表示你需要点击**复制草稿**，然后自行发送。
- **需要你帮忙**表示它有问题要问你：点击**回复**。**卡住**表示它没有问题要问，但已停止；待办事项会说明原因。
- 如果它问了不止一个问题，每个问题都会有自己的选项或简短输入框，有时还会填入你上次的回答。点击**回复**即可一次提交所有答案。
- 如果缺少只有你才知道的信息，它会向你询问，并只拟写不依赖这些信息的内容，例如确认日期的回复。它不会只拟写一句“稍后发给你”。
- 点击**重试**会再运行一次。点击**要求修改**可以要求它做其他修改。对于卡住的待办事项，会优先显示**重试**；点击**详情**可以查看它尝试过的操作。
- 准备过程中，待办事项会用简短的文字说明 Machine 正在做什么，例如“正在阅读邮件”“正在阅读 PDF”或“正在撰写草稿”。详细步骤会显示在待办事项的聊天中。
- 标记为**准备中…**的待办事项会在几秒内开始。如果需要等待，待办事项会说明原因和大致开始时间，例如“当前任务完成后开始”。
- 网站要求登录时，点击**登录**，或者点击**打开浏览器**并在那里登录。之后它会自动继续。如果没有继续，点击**继续**。
- 如果需要输入发送到手机的验证码，或缺少权限，任务就会停止。待办事项会说明需要什么，然后提供**继续**或**重试**。如果来源尚未连接，例如 Slack，待办事项会显示**连接 Slack**；连接 Slack 后，任务会自动继续。
