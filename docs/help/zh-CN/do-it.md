## 执行会做什么

**执行**会让你的 Machine 准备好待办事项，例如起草回复、查找信息或填写表单。它会像你一样使用自己的账号和浏览器。

Machine 在浏览器中操作时，待办事项和对应的聊天会实时显示当前页面，包括操作步骤之间的页面，直到任务完成。点击页面画面即可打开浏览器。在待办事项中，页面会以更大的尺寸显示，并提供**停止**按钮，按一下就会立即结束本次运行。

在继续处理或转交之前，Machine 会检查是否有更新的回复，包括队友的回复。如果事情已经处理好，待办事项会说明这一点。如果它更改了文档或页面，待办事项会附上链接。

如果在网站或工作流程中成功完成了复杂任务，你的 Machine 会把操作步骤保存为技能，不会保存任何人的个人信息。之后处理该网站上的待办事项时，这些步骤会作为操作指南使用，但不会被视为授权。发送或付款仍需等你批准。你可以在**设置 > 技能**中找到这些技能，标记为**从任务中学到的**。

## 未经你同意，不会发送任何内容

- 回复会先以草稿形式提供。点击**审核并发送**即可打开草稿并进行编辑；只有点击**立即发送**后，内容才会发出。
- 如果一个待办事项中有两封或更多邮件，可以在对应的聊天中用一个按钮逐封审核。邮件会依次显示，点击**下一步**查看下一封，最后一步会发送全部邮件。每封邮件只有在实际发出后才会显示为已发送。
- 邮件会按最终效果显示，包括粗体、列表和链接。Slack 或聊天消息则为纯文本。
- 在同一个窗口中点击**要求修改**，说明需要修改的内容，Machine 就会重新起草。
- 回复会针对邮件线程中的最新一封邮件，待办事项中的来源链接会打开那封邮件。
- 对于提交、付款或预订等会确认操作的步骤，Machine 会等你确认，或等你在聊天中提出要求。确认某个步骤后，其他步骤仍会等待处理。只有所有步骤都完成后，待办事项才会关闭。
- 点击此类步骤之前，待办事项和聊天都会显示将要发送的内容。日历邀请会显示标题、时间、参与者，以及是否添加了会议链接。
- 查找可用时间时，Machine 会参考已连接的日历：先读取对应日期的会议安排，再提供时间选项。
- 在待办事项的聊天中，草稿不会和生成它的内容一起发送在同一条消息中。
- 在你批准之前，待办事项会在**给你**下显示为**已备好**，列表也会提示未经批准不会发送任何内容。仍需要你处理的事项会显示为**需要你**。只有内容实际发出后，待办事项才会显示草稿已发送。
- 长篇草稿会先显示开头 3 行。点击**展开**或点按文本即可查看其余内容；点击**审核并发送**时始终会显示全文。

根据内容来源，Machine 可以发送电子邮件、Slack 私信，或 WhatsApp、Telegram、LinkedIn 和 X 消息。每种连接的帮助文章都会说明可以发送哪些内容。

## 编辑邮件

- 使用文本上方的按钮，或使用 `Ctrl B` 加粗、`Ctrl I` 设为斜体、`Ctrl K` 添加链接（Mac 上使用 `⌘`）。你也可以使用项目符号列表和编号列表按钮。
- 链接地址必须以 https:// 开头。粘贴的文本会以纯文本形式插入，不保留颜色或图片。
- 邮件不支持的格式会先被移除，随后会显示邮件的最终效果。再次点击**立即发送**即可发送。
- 邮件会严格按照显示的内容发出，同时附带纯文本副本，供不支持格式的邮件应用使用。

## 遇到无法处理的情况

- “无法从这里发送。”表示你需要点击**复制草稿**，然后自行发送。
- **需要你帮忙**表示 Machine 有问题要问你，请点击**回复**。**卡住**表示它没有问题要问你，但已停止处理；待办事项会说明原因。
- 如果 Machine 问了多个问题，每个问题都会提供单独的选项或简短的输入框，有时还会预先填入你上次的答案。点击**回复**即可一次发送所有答案。
- 如果缺少只有你才有的信息，Machine 会向你询问，同时只起草不依赖这些信息的内容，例如确认日期的回复。它不会只起草一句“稍后回复”。
- 点击**重试**即可再次运行。点击**要求修改**可以提出其他要求。对于卡住的待办事项，**重试**会优先显示，点击**详情**可查看它尝试过的操作。
- 准备内容时，待办事项会用简短文字说明 Machine 正在做什么，例如“正在读取邮件”“正在读取 PDF”或“正在起草”。详细步骤会显示在待办事项的聊天中。
- 标记为**准备中…**的待办事项会在几秒内开始处理。如果需要等待，待办事项会说明原因和大致等待时间，例如“当前任务完成后开始”。
- 如果网站要求登录，请点击**登录**，或点击**打开浏览器**后在浏览器中登录。登录后 Machine 会自动继续。如果没有继续，请点击**继续**。
- 如果需要手机验证码或缺少权限，Machine 会暂停处理。待办事项会说明所需内容，然后显示**继续**或**重试**。如果来源尚未连接，例如 Slack，待办事项会显示**连接 Slack**，引导你完成连接；Slack 连接后，Machine 会自动继续。
