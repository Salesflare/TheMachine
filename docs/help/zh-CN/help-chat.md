点击侧边栏底部、**设置**上方的**帮助**，然后用自己的话提问，例如“如何稍后处理待办？”。按Enter提问，按Shift+Enter换行。帮助会使用应用的语言回答，或使用你提问时所用的语言。帮助页面的链接会以相应语言直接在面板中打开。

## 答案来自哪里

帮助会读取与你的问题相关的帮助页面；如果页面没有涵盖相关内容，也会查看应用代码。每个答案都会链接到所参考的页面。

它使用你这台Machine自己的模型，以独立的简短聊天形式运行。你可以在消息框下方为这次帮助聊天选择其他模型或思考强度（参阅[模型](model.md)）。传入的只有你的问题和相关页面，不包括你的任何消息、联系人或设置。

它会根据你的水平回答：对大多数人使用简单明了的说法，你的问题涉及技术内容时则提供更多细节。它会根据你的设置、角色和提问方式来判断你的水平，只会传入这个判断结果。

它会优先介绍The Machine已有的功能，只有内置功能无法满足需求时才建议使用技能。参阅[让它更懂你](personalize.md)。

## 团队能看到什么

为了改进帮助功能，你的Machine会统计每个问题涉及的少量关键词，例如“稍后处理待办”。不会统计你的问题或答案，也不会统计姓名、地址或数字，只会统计这些帮助页面中出现的词语。每天统计结果会发送给The Machine团队，但不会关联你的账号。

如要停止分享，请在**设置**中的**安全**下方、**The Machine团队**部分关闭**分享大家向助手求助的内容**，或选择**谨慎**[安全等级](security-levels.md)。此功能需要使用[The Machine Network](/network)。尚未发送的统计数据会被删除。

## 它无法做什么

帮助会回答问题，但无法查看你的数据，也不会更改任何内容，只会告诉你该点哪里。

如果你的描述听起来像是功能故障，而不是操作方法问题，答案末尾会显示**报告此错误**。点击后会打开**报告错误**，其中会简要说明你做了什么、原本预期会发生什么以及实际发生了什么，并默认勾选支持报告选项。你可以随意修改内容。按下**发送**后才会发送。

**报告错误**也是同一面板中的独立标签页。参阅[获取支持](get-support.md#report-a-bug)。
