笔记是某个主题的概览，例如一次旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一样，显示在 Graph 中。笔记保存在 The Machine 上，不会与你的团队共享。

## 开始写笔记

在笔记顶部点击**新建笔记**。输入标题并点击**开始写笔记**，即可打开笔记页面。点击**添加一行**，添加想保存的内容。每行文字都会单独显示为一行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和名称的前几个字母。从列表中选择人物、组织、项目或笔记，名称就会以链接的形式插入。你链接到的页面上会显示**链接自**，并列出这篇笔记。

## 笔记下的笔记

一篇笔记可以归在另一篇笔记下面，例如把“家电”归在“家”下面。笔记会以树状结构显示：点击笔记旁边的箭头，可以展开其下的笔记。要移动笔记，点击**编辑**，然后在**低于**下选择位置。点击 ⋯ 菜单中的**在此笔记下新建笔记**，即可在此处新建笔记。

## The Machine 保留的笔记

The Machine 也会根据你的消息自动撰写笔记，并持续更新。每一行都会注明内容来源，例如邮件的发送者，点击即可打开邮件。来自**我学到的内容**的行会标注为**根据我学到的内容**。

你所做的更改始终会保留。重命名笔记、移动笔记、更改日期或修改内容后，The Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它就不会再出现。之后有关同一主题的笔记，会放到你最初放置笔记的位置。

点击**恢复原状**，即可重新显示 The Machine 自己写的内容。编辑来自 The Machine 学到的内容的行，也会同步更改**我学到的内容**中的内容，因此只会保留一个版本。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，The Machine 会将其添加到**旅行**下的一次行程中。同一次旅程的预订会归在一起，例如去程、酒店和返程。行程会按时间顺序列出每项预订的预订代码、座位和票务信息，并显示行程日期。在[日历](calendar.md)中，行程会显示为横跨这些日期的一条横条，点击即可打开行程。

The Machine 会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。邮件中没有这些详情，就不会创建行程。更改预订后，对应内容会更新；取消预订后，对应内容会移除。行程中的所有预订都取消后，行程也会移除。

## 家

在**家**下，The Machine 会保存已知的家相关信息：**账单和订阅**、**家电**、**维修和保养**以及**房子**。某个部分至少有两行内容后才会显示。

- 定期产生的账单，例如能源费或水费，会显示一行内容，注明账单周期和最近一次账单的日期。点击**打开待办事项**即可查看账单本身；金额和付款详情会保留在账单中。
- 你保留的订阅会显示一行内容，点击即可打开对应的**订阅**待办事项。已取消的订阅不会列出。
- The Machine 学到的家相关信息，例如洗碗机的品牌，也会显示为一行。编辑后，**我学到的内容**中的信息也会同步更改。
- 如果你在某个部分保留了自己的笔记，例如在**家电**下为洗碗机写的笔记，相关内容就会放在这篇笔记中。The Machine 不会自行创建这类笔记。

这里只会使用“个人”账单和订阅，家相关笔记也始终为“个人”。每有一笔新账单、一个新订阅或一项新学到的信息，The Machine 都会让 AI 检查一次，判断它是否与你的家有关。对于账单，The Machine 会发送账单来源，但不会发送金额。

## 健康

在**健康**下，The Machine 会保存已知的个人健康信息：**预约**、**医生和医疗护理**、**药品**、**过敏和病症**以及**账单和保险**。某个部分至少有两行内容后才会显示。

- 日历中只有你参加的预约，例如看牙医，会显示一行内容，注明下次或上次预约日期。点击**根据你的日历**即可打开预约。
- 医生、牙医或药房开具的账单会显示一行内容，点击即可打开对应的待办事项。金额会保留在待办事项中。
- The Machine 学到的健康信息，例如过敏情况，也会显示为一行。编辑后，**我学到的内容**中的信息也会同步更改。
- 如果你在某个部分保留了自己的笔记，例如在**预约**下为理疗师写的笔记，相关内容就会放在这篇笔记中。

健康笔记始终为“个人”，即使账单发到了你的工作邮箱也是如此。每有一个新预约、一笔新账单或一项新学到的信息，The Machine 都会让 AI 检查一次，判断它是否与你个人的健康有关。对于预约，The Machine 会发送预约名称，但不会发送预约备注或其他受邀者的信息。

## 孩子

在**孩子**下，The Machine 会保存已知的子女相关信息：**学校**、**活动**、**医生和医疗护理**以及**账单和费用**。某个部分至少有两行内容后才会显示。

- The Machine 学到的子女相关信息，例如班主任或游泳日，会显示为一行，并链接到孩子的页面。当某人的**发给你**一栏注明其与你的关系，例如女儿或儿子时，The Machine 会将其视为你的孩子。
- 日历中只有你参加的活动，例如家长会，会显示一行内容，注明下次或上次活动日期。点击**根据你的日历**即可打开活动。
- 学校、社团或托儿服务的账单会显示一行内容，点击即可打开对应的待办事项。金额会保留在待办事项中。
- 如果你在某个部分为一个孩子保留了自己的笔记，例如在**学校**下为 Isla 写的笔记，相关内容就会放在这篇笔记中。

孩子相关笔记始终为“个人”，即使学校把邮件发到了你的工作邮箱也是如此。每有一项新内容，The Machine 都会让 AI 检查一次，判断它是否与你的孩子有关。

## 合并、删除和撤销

点击 ⋯ 菜单中的**合并到…**，即可将一篇笔记中的内容及其下的笔记移到另一篇笔记中。之后，The Machine 会继续将新内容添加到那篇笔记中。点击**删除**即可移除笔记。两种操作后都会短暂显示**撤销**，删除一行后也一样。

## 与会议笔记不同

会议笔记以及人物或组织页面上的笔记仍保留在原处。这里的笔记是独立的页面。
