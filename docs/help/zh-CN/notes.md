笔记是一个主题的概览，比如一次旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一起显示在 Graph 中。笔记保存在你的 Machine 上，不会分享给你的团队。

## 新建笔记

在笔记顶部点击**新建笔记**。输入标题并点击**开始写笔记**，笔记页面就会打开。点击**添加一行**，写下你想保存的内容。每行文字都会成为单独的一行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和姓名的前几个字母。从列表中选择人物、组织、项目或笔记，名称就会以链接的形式插入。你链接到的页面会在**链接自**下显示这篇笔记。

## 笔记中的笔记

一篇笔记可以归在另一篇笔记下，比如把家电归在家下面。笔记会以树状结构显示：点击笔记旁边的箭头，可以展开它下面的笔记。要移动笔记，点击**编辑**，然后在**低于**下选择放置位置。点击 ⋯ 菜单中的**在此笔记下新建笔记**，就能在当前位置新建笔记。

笔记页面顶部会显示它的位置，比如**笔记 › 孩子**。点击其中任意一部分即可前往对应位置。在手机上，中间的笔记会折叠到 ⋯ 菜单中。

## 你的 Machine 保存的笔记

你的 Machine 也会根据你的消息自动记笔记，并持续更新。每行都会注明内容的来源，比如邮件是谁发来的。点击即可打开消息。来自**我学到的内容**的一行会标注为**根据我学到的内容**。日历中的会议或预约不会单独成为一行，而是保存在[日历](calendar.md)中。

只有当你的 Machine 在**家**、**健康**和**孩子**中至少有两条实际内容时，这些分类才会显示，比如一笔账单或它学到的内容。在此之前，它们不会出现在列表中。如果之后又没有内容了，它们也会消失。

你的更改始终有效。重命名笔记、移动笔记、更改日期或修改其中一行后，你的 Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它不会再出现。之后关于同一主题的笔记会放到你最初放置的位置。

点击**恢复原状**，即可重新显示你的 Machine 写的内容。编辑来自你的 Machine 所学内容的一行，也会更改**我学到的内容**中的对应内容，因此只会保留一个版本。

## 自动撰写的页面

当一篇笔记中至少有两行来自你的消息或你的 Machine 所学内容时，你的 Machine 会在页面顶部撰写内容。它会阅读对话本身，而不只是对话主题：

- 简短摘要：说明主题内容和当前进展。
- 仅在有具体内容可写时，显示**关键信息**、**决策**、**待处理事项**和**时间线**。
- 笔记中的行会按编号列在下方的**来源**中。每句话末尾都会标出对应来源行的编号。点击编号即可跳转到那一行。

只有笔记中的行发生变化时，页面才会重新撰写，而且最多大约每天更新一次。如果来源中没有具体内容，页面就不会生成，只显示笔记中的行。删除一行后，页面中仅来自这一行的内容也会一并删除。笔记列表会在每篇笔记名称下显示页面摘要的开头。

项目或组织在 Graph 中已经有自己的页面，页面顶部会显示其描述。关于项目或组织的对话会放在对应页面中，而不是笔记里。

## 对话笔记

你的 Machine 会阅读完整对话，并将每段对话归入相关笔记：任何邮箱中的邮件会话、WhatsApp、Slack、Telegram、LinkedIn 或其他已连接应用中的聊天，以及你的会议记录。聊天消息会被视为同一段对话，直到聊天静默两天。

- 关于 Graph 中某个项目或组织的对话会放在对应页面中，而不会新建笔记。
- 对话可以归入**家**、**健康**或**孩子**中的某个分类，也可以归入你自己创建的笔记，或者你的 Machine 在**工作**、**汽车**、**税务**或其他文件夹下新建的笔记。
- 只有某个主题至少有两段对话，或你参与的某段对话明显还在继续时，你的 Machine 才会新建笔记。
- 每行对应一段对话，最新的排在最前面。点击即可打开对话。

它会向 AI 发送每段对话中的一小部分内容，不包含引用的回复或签名。每段对话只会询问一次 AI，之后的新消息会归入同一段对话。

群发邮件和聊天不会放入笔记，也不会发送给 AI，包括垃圾邮件、促销邮件、新闻通讯及其他列表邮件、自动通知、机器人消息和广播频道。你参与的对话仍会计入，**旅行**和**事件**的预订邮件也会计入。

首次整理时，它会在几小时内处理过去三个月的内容，并避开夜间时段，而且只有在你的 AI 方案有剩余空间时才会处理。之后，每当有十段新对话待处理，或有一段对话已等待半天，就会整理一次。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，你的 Machine 会在**旅行**下添加一趟行程。同一次旅程的预订会放在同一趟行程中，包括去程、酒店和返程。行程会按时间顺序列出每一项预订的预订代码、座位和票，并显示日期。在[日历](calendar.md)中，这趟行程会显示为横跨这些日期的一条色带，点击即可打开行程。

它会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。没有这些详情的邮件不会生成行程。在你的 Machine 保存的[历史记录](history.md)年份范围内，过去收到的预订邮件会在后台读取；历史记录导入后，会优先读取你的个人邮箱。之后才读到的旧确认邮件会添加到已有行程中。

预订变更后，对应行会更新；预订取消后，对应行会删除。如果一趟行程中的所有预订都已取消，这趟行程也会删除。

## 事件

音乐会、比赛、节日活动或会议的门票邮件到达后，你的 Machine 会在**事件**下添加活动，每场活动一篇笔记。每行会显示活动地点、预订代码、座位和门票数量。同一活动的第二笔订单会添加到同一篇笔记中。和旅行一样，活动会显示日期，并在[日历](calendar.md)中显示为一条色带，点击即可打开笔记。

- 每行会注明门票的发件方，比如**来自 Example Tickets**，点击即可打开邮件。
- 如果待办事项来自门票邮件，比如支付门票费用，点击**打开待办事项**即可查看。
- 使用工作邮箱预订的活动归为工作，否则归为个人。

它会直接读取票务平台在确认邮件中提供的门票详情，不使用 AI。没有这些详情的邮件不会生成活动。预订取消后，对应内容会删除；如果某场活动的所有门票都已取消，活动也会删除。

## 家

你的 Machine 会在**家**下保存它了解到的家相关信息，包括**账单和订阅**、**家电**、**维修和保养**及**房子**。某个分类至少有两行内容时才会显示。

- 定期寄来的账单，比如能源费或水费，会显示一行内容，注明寄送频率和最近一期账单的日期。点击**打开待办事项**即可查看账单本身；金额和付款详情会保存在账单中。
- 你保留的订阅会显示一行，点击即可打开它的**订阅**待办事项。已取消的订阅不会显示。
- 经常联系你家的人或机构，比如能源供应商、网络服务商或当地政府，会显示一行，注明联系频率。点击即可打开最新邮件。
- 你的 Machine 学到的家相关信息，比如洗碗机的品牌，也会显示为一行。编辑这一行也会更改**我学到的内容**中的对应内容。
- 如果你在某个分类下创建了自己的笔记，比如在**家电**下为洗碗机创建笔记，相关内容就会放进你的笔记中。你的 Machine 不会自行创建这类笔记。

只会使用个人账单、订阅和邮件，家相关笔记也始终归为个人。你的 Machine 会针对每笔新账单、每项新订阅或每条新学到的信息，各询问 AI 一次，以判断它是否与家有关。对于账单，它只会发送发件方信息，不会发送金额。

如上文**对话笔记**所述，你的对话也会放入这些笔记中。

## 健康

你的 Machine 会在**健康**下保存它了解到的个人健康信息，包括**预约**、**测试结果**、**医生和医疗护理**、**药品**、**过敏和病症**及**账单和保险**。某个分类至少有两行内容时才会显示。

- 来自医生、牙医或药房的账单会显示一行，点击即可打开对应的待办事项。金额会保存在待办事项中。
- 来自诊所、医院、实验室或健康保险公司的每封邮件都会成为一行，附上日期和主题，让你的记录逐渐累积。点击即可打开邮件。
- 你的 Machine 学到的健康信息，比如过敏情况，也会显示为一行。编辑这一行也会更改**我学到的内容**中的对应内容。
- 如果你在某个分类下为某件事创建了自己的笔记，比如在**预约**下为理疗师创建笔记，相关内容就会放进这篇笔记中。

健康笔记始终归为个人，即使账单发送到了你的工作邮箱也是如此。你的 Machine 会针对每笔新账单或每条新学到的信息，各询问 AI 一次，以判断它是否与你的个人健康有关。

## 孩子

你的 Machine 会在**孩子**下保存它了解到的孩子相关信息，包括**学校**、**活动**、**育儿**、**医生和医疗护理**及**账单和费用**。保姆或日托机构会归入育儿，不会归入医生和医疗护理。某个分类至少有两行内容时才会显示。

- 你的 Machine 学到的孩子相关信息，比如班主任或游泳课日期，会显示为链接到孩子页面的一行。当某个人的**发给你**信息表明对方是你的孩子，比如女儿或儿子时，系统就会将其视为你的孩子。
- 学校、俱乐部或育儿服务的账单会显示一行，点击即可打开对应的待办事项。金额会保存在待办事项中。
- 学校、俱乐部或育儿服务发来的每封邮件，比如活动通知或计划变更，都会成为一行，附上日期和主题，让所有邮件都集中在一处。点击即可打开邮件。
- 如果你在某个分类下为一个孩子创建了自己的笔记，比如在**学校**下为 Isla 创建笔记，相关内容就会放进这篇笔记中。

孩子笔记始终归为个人，即使学校发邮件到你的工作邮箱也是如此。你的 Machine 会针对每条新信息询问 AI 一次，以判断它是否与你的孩子有关。

## 合并、删除和撤销

在 ⋯ 菜单中点击**合并到…**，即可将一篇笔记中的行及其下级笔记移到另一篇笔记中。之后，你的 Machine 会继续向那篇笔记添加内容。点击**删除**即可删除笔记。这两种操作都会短暂显示**撤销**，删除一行后也一样。

## 与会议记录不同

会议记录以及人物或组织的笔记仍保留在原处。这里的笔记是独立页面。
