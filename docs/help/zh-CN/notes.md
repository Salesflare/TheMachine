笔记是某个主题的概览，例如旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一起显示在 Graph 中。笔记保存在你的 Machine 上，不会与团队共享。

## 开始写笔记

在“笔记”顶部点按 **新建笔记**。输入标题并点按 **开始写笔记**，笔记页面就会打开。点按 **添加一行**，添加想要记录的内容。每行文字都会单独成行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和姓名的前几个字母。从列表中选择人物、组织、项目或笔记，名称就会以链接的形式插入。你链接的对象的页面上会显示 **链接自**，并列出这篇笔记。

## 在笔记下添加笔记

一篇笔记可以放在另一篇笔记下，例如把“家电”放在“家”下。“笔记”会以树状结构显示这些笔记：点按笔记旁边的箭头，即可展开其下的笔记。要移动笔记，点按 **编辑**，然后在 **低于** 下选择它的新位置。点按 ⋯ 菜单中的 **在此笔记下新建笔记**，即可在当前位置新建笔记。

## Machine 保留的笔记

你的 Machine 也会根据你的消息自动撰写笔记，并保持内容更新。每行都会说明内容的来源，例如是谁发来的邮件。点按这一行即可打开邮件。来自 **我学到的内容** 的行会标注 **根据我学到的内容**。

你所做的更改始终有效。重命名笔记、移动笔记、更改日期或修改某一行后，Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它就不会再出现。之后记录的同一主题内容会放到你最初选择的位置。

点按 **恢复原状**，即可重新显示 Machine 原先写下的内容。编辑一行来自 Machine 学到的内容时，也会同步更改 **我学到的内容** 中的对应内容，因此只会保留一个版本。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，Machine 会在 **旅行** 下为其添加一趟行程。同一趟旅程的预订会放在一起，包括去程、酒店和返程。行程会按时间顺序列出每项预订的预订代码、座位和票务信息，并显示日期。在[日历](calendar.md)中，行程会显示为横跨这些日期的一条色带，点按即可打开行程。

Machine 会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。邮件中没有这些详情，就不会生成行程。Machine 会在[历史记录](history.md)载入后，于后台读取其保留的历史记录年份内更早的预订邮件。预订变更后，对应行程会更新；预订取消后，对应行程会移除。行程中的所有预订都取消后，行程也会移除。

## 事件

音乐会、比赛、节日或会议的门票邮件到达后，Machine 会在 **事件** 下为每个事件新建一篇笔记。每行会说明活动地点，并列出预订代码、座位和门票数量。同一活动的第二笔订单会添加到同一篇笔记中。和旅行一样，事件也会显示日期，并在[日历](calendar.md)中显示为一条色带，点按即可打开笔记。

- 每行会说明门票来自哪里，例如 **来自 Example Tickets**，点按即可打开对应邮件。
- 如果门票邮件生成了待办事项，例如支付门票费用，点按 **打开待办事项** 即可查看。
- 通过工作邮箱预订的事件属于工作，否则属于个人。

Machine 无需使用 AI，就能读取门票销售方在确认邮件中提供的门票详情。邮件中没有这些详情，就不会生成事件。预订取消后，对应内容会移除；某个事件的所有门票都取消后，该事件也会移除。

## 家

在 **家** 下，Machine 会记录所了解的家居信息，包括 **账单和订阅**、**家电**、**维修和保养** 以及 **房子**。某个分类至少有两行内容后才会显示。

- 定期收到的账单，例如能源或水费，会作为一行显示，并注明账单周期和最近一次账单的日期。点按 **打开待办事项** 可查看账单本身；金额和付款详情会保留在账单中。
- 你保留的订阅会作为一行显示，点按即可打开对应的 **订阅** 待办事项。取消的订阅不会列出。
- Machine 学到的家居信息，例如洗碗机的品牌，也会作为一行显示。编辑这行内容也会同步更改 **我学到的内容** 中的对应内容。
- 如果你在某个分类中保留了自己的笔记，例如在 **家电** 下记录洗碗机的信息，与该物品有关的内容就会放进你的笔记中。Machine 不会自行新建这类笔记。

这里只会使用个人账单和订阅，家相关的笔记始终属于个人。每有一笔新账单、新订阅或一项新学到的信息，Machine 都会让 AI 检查一次，判断它是否与你的家有关。对于账单，Machine 只会发送账单来源，不会发送金额。

## 健康

在 **健康** 下，Machine 会记录所了解的个人健康信息，包括 **预约**、**医生和医疗护理**、**药品**、**过敏和病症** 以及 **账单和保险**。某个分类至少有两行内容后才会显示。

- 日历中只有你一人参加的预约，例如看牙医，会作为一行显示，并注明下次或最近一次的日期。点按 **根据你的日历** 即可打开预约。
- 医生、牙医或药房的账单会作为一行显示，点按即可打开对应的待办事项。金额会保留在待办事项中。
- Machine 学到的健康信息，例如过敏情况，也会作为一行显示。编辑这行内容也会同步更改 **我学到的内容** 中的对应内容。
- 如果你在某个分类中为自己保留了笔记，例如在 **预约** 下记录理疗师的信息，与该事项有关的内容就会放进这篇笔记中。

健康笔记始终属于个人，即使账单发送到了你的工作邮箱也是如此。每有一项新预约、新账单或新学到的信息，Machine 都会让 AI 检查一次，判断它是否与你本人的健康有关。对于预约，Machine 只会发送预约名称，不会发送备注或其他受邀者的信息。

## 孩子

在 **孩子** 下，Machine 会记录所了解的孩子相关信息，包括 **学校**、**活动**、**医生和医疗护理** 以及 **账单和费用**。某个分类至少有两行内容后才会显示。

- Machine 学到的孩子相关信息，例如班主任或游泳日，会作为一行显示，并链接到孩子的页面。如果某人的 **发给你** 信息中表明对方是你的女儿或儿子，Machine 就会将其视为你的孩子。
- 日历中只有你一人参加的活动，例如家长会，会作为一行显示，并注明下次或最近一次的日期。点按 **根据你的日历** 即可打开活动。
- 学校、社团或托儿服务的账单会作为一行显示，点按即可打开对应的待办事项。金额会保留在待办事项中。
- 如果你在某个分类中为一个孩子保留了自己的笔记，例如在 **学校** 下为 Isla 记笔记，与该孩子有关的内容就会放进这篇笔记中。

孩子相关的笔记始终属于个人，即使学校联系的是你的工作邮箱也是如此。每有一项新内容，Machine 都会让 AI 检查一次，判断它是否与你的孩子有关。

## 合并、删除和撤销

点按 ⋯ 菜单中的 **合并到…**，即可将一篇笔记中的内容及其下的笔记移到另一篇笔记中。之后 Machine 会继续将新内容添加到那篇笔记中。点按 **删除** 可移除笔记。这两种操作完成后，都会短暂显示 **撤销**；删除一行后也会显示。

## 与会议笔记不同

会议笔记以及人物或组织的笔记仍会保留在原来的位置。这里的笔记则是独立的页面。
