笔记概述一个主题，比如旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一样，位于 Graph 中。笔记保存在你的 Machine 上，不会与团队共享。

## 新建笔记

在笔记顶部点击**新建笔记**。输入标题并点击**开始写笔记**，即可打开笔记页面。点击**添加一行**即可添加要保留的内容。每行文字都会单独成行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和名字的前几个字母。从列表中选择人物、组织、项目或笔记，名称就会作为链接插入。被链接对象的页面会显示**链接自**，并列出你的笔记。

## 在笔记下创建笔记

笔记可以归在另一篇笔记下，比如把家电归在家下面。笔记会以树状结构显示：点击笔记旁边的箭头，可以展开其下的笔记。要移动笔记，点击**编辑**，然后在**低于**下选择位置。点击 ⋯ 菜单中的**在此笔记下新建笔记**，即可在这里创建笔记。

笔记页面顶部会显示它所在的位置，比如**笔记 › 孩子**。点击任意部分即可前往对应位置。在手机上，中间层级的笔记会折叠到 ⋯ 菜单中。

## 你的 Machine 保存的笔记

你的 Machine 也会根据你的消息自动撰写并更新笔记。每一行都会注明内容的来源，比如邮件的发件人。点击即可打开对应消息。来自**我学到的内容**的行会标注为**根据我学到的内容**。日历中的会议或预约不会单独作为一行显示，而是保留在[日历](calendar.md)中。

只有当你的 Machine 至少有两条真实内容可写时，**家**、**健康**和**孩子**才会显示，比如一张账单或它学到的信息。在此之前，它们不会出现在列表中；如果之后又没有内容了，也会从列表中移除。

你做的更改会一直保留。重命名笔记、移动笔记、更改日期或修改某一行后，你的 Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它不会再出现。同一主题之后新增的笔记，会放到你首次放置该主题的位置。

点击**恢复原状**，即可再次显示你的 Machine 撰写的原文。编辑来自你的 Machine 学到内容的一行，也会同步更改**我学到的内容**中的对应内容，因此只会保留一个版本。

## 旅行

当机票、酒店、火车、巴士、渡轮或租车预订邮件到达时，你的 Machine 会在**旅行**下添加一趟行程。同一趟旅程的预订会归到同一条行程中，包括去程、酒店和返程。行程会按时间顺序显示每条记录的预订代码、座位和票券，并显示行程日期。在[日历](calendar.md)中，行程会显示为横跨这些日期的一条色带，点击即可打开行程。

你的 Machine 会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。没有这些详情的邮件不会生成行程。对于你的 Machine 保存的[历史邮件](history.md)中、早于当前时间的预订邮件，等历史邮件导入后，系统会在后台读取，优先处理你的个人邮箱。之后读取的旧确认邮件会添加到已有行程中。

预订变更后，对应记录也会更新；预订取消后，对应记录会移除。如果一趟行程中的所有预订都取消了，整趟行程也会移除。

## 事件

当音乐会、比赛、节日活动或会议的门票邮件到达时，你的 Machine 会在**事件**下添加事件，每个事件单独一篇笔记。每一行会显示活动地点、预订代码、座位和门票数量。同一活动的第二笔订单也会添加到同一篇笔记中。和旅行一样，事件会显示日期，并在[日历](calendar.md)中显示为一条色带，点击即可打开笔记。

- 每一行都会注明门票的来源，比如**来自 Example Tickets**，点击即可打开对应邮件。
- 如果门票邮件生成了待办事项，比如支付门票费用，点击**打开待办事项**即可查看。
- 通过工作邮箱预订的活动会归为工作，否则归为个人。

你的 Machine 会读取票务销售方在确认邮件中提供的门票详情，不会使用 AI。没有这些详情的邮件不会生成事件。预订取消后，对应记录会移除；如果某个活动的所有门票都取消了，整个活动也会移除。

## 家

在**家**下，你的 Machine 会保存关于你家的信息：**账单和订阅**、**家电**、**维修和保养**及**房子**。某个部分至少有两行内容后才会显示。

- 定期寄来的账单，比如能源或水费，会显示一行，注明账单寄送频率和最近一次账单的日期。点击**打开待办事项**即可查看账单本身；金额和付款详情会保留在待办事项中。
- 你保留的订阅会显示一行，点击即可打开对应的**订阅**待办事项。已取消的订阅不会显示。
- 定期联系你家的人或机构，比如能源供应商、网络服务商或市政部门，会显示一行，注明联系频率。点击即可打开他们最新的邮件。
- 你的 Machine 学到的关于你家的信息，比如洗碗机的品牌，也会显示为一行。编辑这行内容，也会同步更改**我学到的内容**中的对应内容。
- 如果你在某个部分保留了自己的笔记，比如在**家电**下为洗碗机写的笔记，关于洗碗机的内容就会放进这篇笔记。你的 Machine 不会自动创建这类笔记。

系统只会使用个人账单、订阅和邮件，家相关的笔记始终归为个人。你的 Machine 会就每一张新账单、每个新订阅或每条新学到的信息，向 AI 查询一次，判断它们是否与你的家有关。对于账单，系统会发送发件人信息，但不会发送金额。

对于**家**、**健康**和**孩子**这三类笔记，你的 Machine 还会就每个个人邮件发件人向 AI 查询一次。系统会发送发件人姓名、对方发来的邮件数量，以及隐藏数字后的最新邮件主题，但不会发送邮件本身。同一封邮件收到两次，或出现在两个邮箱中，都只计一次；同一邮件对话中主题相同的回复也只计一次。

群发邮件不会放入这些笔记，也不会发送给 AI，包括垃圾邮件、促销邮件、新闻简报及其他列表邮件，还有 no-reply 通知。你回复过的邮件对话中的邮件仍会计入，**旅行**和**事件**的预订邮件也会计入。

首次处理时，系统会在几小时内检查你过去一年的邮件，避开夜间，并且只在你的 AI 方案有剩余额度时进行。之后，系统每六小时检查一次新发件人。

## 健康

在**健康**下，你的 Machine 会保存关于你本人健康的信息：**预约**、**测试结果**、**医生和医疗护理**、**药品**、**过敏和病症**及**账单和保险**。某个部分至少有两行内容后才会显示。

- 医生、牙医或药房寄来的账单会显示一行，点击即可打开对应的待办事项。金额会保留在待办事项中。
- 诊所、医院、实验室或健康保险公司发来的每封邮件，都会作为一行显示日期和主题，逐渐积累成你的记录。点击即可打开邮件。
- 你的 Machine 学到的关于你健康的信息，比如过敏情况，也会显示为一行。编辑这行内容，也会同步更改**我学到的内容**中的对应内容。
- 如果你在某个部分写了自己的笔记，比如在**预约**下为理疗师写的笔记，关于理疗师的内容就会放进这篇笔记。

健康笔记始终归为个人，即使账单发到了你的工作邮箱也是如此。你的 Machine 会就每张新账单或每条新学到的信息，向 AI 查询一次，判断它们是否与你本人的健康有关。

## 孩子

在**孩子**下，你的 Machine 会保存关于你孩子的信息：**学校**、**活动**、**育儿**、**医生和医疗护理**及**账单和费用**。保姆或托儿所的信息会归在育儿下，不会归在医生和医疗护理下。某个部分至少有两行内容后才会显示。

- 你的 Machine 学到的关于孩子的信息，比如班主任或游泳日，会显示为一行，并链接到孩子的页面。如果某人的**发给你**信息中注明对方是你的孩子，比如女儿或儿子，系统就会将对方视为你的孩子。
- 学校、俱乐部或托儿所的账单会显示一行，点击即可打开对应的待办事项。金额会保留在待办事项中。
- 学校、俱乐部或托儿所发来的每封邮件，比如关于出游或计划变更的通知，都会作为一行显示日期和主题，让他们发来的邮件集中在一个地方。点击即可打开邮件。
- 如果你在某个部分为一个孩子写了自己的笔记，比如在**学校**下为 Isla 写的笔记，关于这个孩子的内容就会放进这篇笔记。

孩子相关的笔记始终归为个人，即使学校发邮件到了你的工作邮箱也是如此。你的 Machine 会就每条新信息向 AI 查询一次，判断它是否与你的孩子有关。

## 合并、删除和撤销

在 ⋯ 菜单中点击**合并到…**，即可将一篇笔记中的内容及其下的笔记移到另一篇笔记中。之后，你的 Machine 会继续将内容添加到那篇笔记中。点击**删除**即可移除笔记。这两种操作之后都会短暂显示**撤销**，删除一行后也一样。

## 不同于会议笔记

会议笔记以及人物或组织相关的笔记仍保留在原处。这里的笔记是独立页面。
