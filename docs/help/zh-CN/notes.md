笔记是某个主题的概览，比如旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一起显示在 Graph 中。笔记保存在你的 Machine 上，不会与你的团队共享。

## 新建笔记

在笔记页面顶部选择**新建笔记**。输入标题并选择**开始写笔记**，笔记页面就会打开。选择**添加一行**，添加想要保留的内容。每行文字都会单独显示。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和名字的前几个字母。从列表中选择人物、组织、项目或笔记，名称就会以链接的形式插入。你链接到的页面会在**链接自**下显示这条笔记。

## 笔记下的笔记

笔记可以放在另一篇笔记下，比如把家电放在家下面。笔记会以树状结构显示：选择笔记旁边的箭头，就能展开它下面的笔记。要移动笔记，选择**编辑**，然后在**低于**下选择要放到哪里。在 ⋯ 菜单中选择**在此笔记下新建笔记**，即可直接在这里新建笔记。

笔记页面顶部会显示笔记的位置，例如**笔记 › 孩子**。选择其中任意部分即可前往对应位置。在手机上，中间的笔记会折叠到 ⋯ 菜单中。

## 你的 Machine 保存的笔记

你的 Machine 也会根据你的消息自动撰写笔记，并持续更新。每行都会注明内容来源，例如邮件的发件人。点按即可打开对应消息。来自**我学到的内容**的一行会标记为**根据我学到的内容**。

日历中的会议或预约不会单独显示为一行，而是保存在[日历](calendar.md)中。相关邮件也一样，包括邀请、回复、更新和取消通知。

只有当你的 Machine 至少有两条真实内容可写时，**家**、**健康**和**孩子**才会显示，例如一张账单或它学到的内容。在此之前，它们不会出现在列表中。如果之后又没有内容了，也会从列表中消失。

你所做的更改始终有效。重命名笔记、移动笔记、更改日期或编辑某一行后，你的 Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它不会再出现。之后同一主题的新笔记会放到你第一次放置的位置。

选择**恢复原状**，即可重新显示你的 Machine 自己撰写的内容。编辑来自你的 Machine 所学内容的一行时，也会同步更改**我学到的内容**下的对应内容，确保只有一个版本。

## 自动撰写的页面

笔记中至少有两行来自你的消息或你的 Machine 学到的内容后，你的 Machine 就会在页面顶部撰写概览。它会阅读对话内容，而不只是对话主题：

- 简短总结：说明主题和当前进展。
- 只有在有具体内容时，才会显示**关键信息**、**决策**、**待处理事项**和**时间线**。
- 笔记中的各行会按编号列在**来源**下方。每句话末尾都会标出所依据内容的行号，点按行号即可跳转到对应内容。

只有笔记中的内容发生变化时，页面才会重新撰写，而且每天最多大约更新一次。如果来源中没有具体内容，就不会生成页面，只显示各行内容。删除某一行后，只基于这一行生成的内容也会从页面中删除。笔记列表会在笔记名称下方显示页面摘要的开头。

项目或组织在 Graph 中已经有自己的页面，页面顶部会显示简介。关于项目或组织的对话会放在对应页面中，而不是笔记里。

## 概览

如果一篇笔记下面还有其他笔记，比如**工作**或**家**，其中至少两篇有新内容时，顶部就会显示简短概览：一两句话说明近况，并列出近期有进展或接下来要处理的几件事。每项内容末尾都会标出来源笔记的名称，点按即可打开该笔记。

概览根据下级笔记的页面和最新内容生成，每天最多一次，而且只有内容发生变化时才会生成。没有近期内容时，就不会显示概览。笔记列表会在文件夹名称下方显示概览的开头。

## 对话笔记

你的 Machine 会阅读完整对话，并将每段对话归入相关笔记：你任意邮箱中的邮件会话、WhatsApp、Slack、Telegram、LinkedIn 或其他已连接应用中的聊天，以及会议笔记。聊天消息会被视为同一段对话，直到聊天安静两天。

- 关于 Graph 中某个项目或组织的对话会放在对应页面中，而不会新建笔记。
- 对话可以放在**家**、**健康**或**孩子**下的某个分类、你自己创建的笔记，或你的 Machine 在**工作**、**汽车**、**税务**或其他文件夹下新建的笔记中。
- 只有某个主题至少有两段对话，或你写过相关内容且主题显然仍在继续时，你的 Machine 才会新建笔记。
- 每行对应一段对话，最新的排在最前面。点按即可打开对话。

发送给 AI 的是每段对话中的简短内容，不包括引用的回复或签名。每段对话只会询问一次 AI，之后的新消息会接在原对话后面。

群发邮件和聊天不会放进笔记，也不会发送给 AI，包括垃圾邮件、促销邮件、新闻简报和其他邮件列表邮件、自动通知、机器人消息和广播频道。你参与撰写的对话仍会计入，**旅行**和**事件**的预订邮件也一样。

首次处理时，你的 Machine 会在几小时内查看过去三个月的内容，不会在夜间进行，而且只有在你的 AI 方案仍有可用额度时才会处理。之后，待分类的对话达到十段，或有一段等待了半天时，才会进行分类。

## OpenClaw 记忆中的笔记

如果你以前用过 OpenClaw，你的 Machine 会读取其记忆文件夹中的主题页面，每个页面只读取一次，例如旅行或健康相关页面。值得保留的内容会放进相关主题的笔记中，或新建一篇笔记。每行都会注明来源页面，例如**来自你的记忆页面 · Lisbon**，并标明日期。将鼠标悬停在这一行上，即可查看来源页面。

它不会更改这些页面，也会跳过每日记录、关于助手本身的页面，以及标记为敏感或私密的文件夹。它最多读取 80 个页面，每次读取少量页面，而且之后不会再读取。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件送达后，你的 Machine 会在**旅行**下添加一趟行程。一次旅程的预订会放在同一趟行程中，包括去程、酒店和返程。行程会按时间顺序列出每项预订的预订代码、座位和票券，并显示行程日期。在[日历](calendar.md)中，行程会显示为横跨这些日期的一条色带，点按即可打开行程。

它会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。没有这些详情的邮件不会生成行程。你的 Machine 保存的[历史记录](history.md)年份内的旧预订邮件，会在历史记录导入后于后台读取，并优先处理你的个人邮箱。之后才读取的旧确认邮件，会添加到已有行程中。

预订变更后，对应内容会更新；预订取消后，对应内容会删除。如果一趟行程中的所有预订都已取消，整趟行程也会删除。

## 事件

音乐会、比赛、节日或会议的门票邮件送达后，你的 Machine 会在**事件**下添加活动，每个活动对应一篇笔记。每行会列出活动地点、预订代码、座位和门票数量。同一活动的第二笔订单会放在同一篇笔记中。和行程一样，活动会显示日期，并在[日历](calendar.md)中显示为一条色带，点按即可打开对应笔记。

- 每行都会注明门票来源，例如**来自 Example Tickets**，点按即可打开对应邮件。
- 如果门票邮件生成了待办事项，例如支付门票费用，选择**打开待办事项**即可查看。
- 如果活动是在工作邮箱中预订的，就归为工作；否则归为个人。

它会直接读取售票方在确认邮件中提供的门票详情，不使用 AI。没有这些详情的邮件不会生成活动。预订取消后，对应内容会删除；如果活动的所有门票都已取消，活动也会删除。

## 家

在**家**下，你的 Machine 会保存它了解到的家庭信息，包括**账单和订阅**、**家电**、**维修和保养**以及**房子**。每个分类至少有两行内容后才会显示。

- 定期寄来的账单，例如能源费或水费，会显示一行，注明账单周期和最近一期的日期。选择**打开待办事项**即可查看账单本身；金额和付款详情会保留在账单中。
- 你保留的订阅会显示一行，点按即可打开对应的**订阅**待办事项。已取消的订阅不会列出。
- 经常联系你处理家庭事务的单位，例如能源供应商、网络服务商或当地政府，会显示一行，注明联系频率。点按即可打开最新邮件。
- 你的 Machine 学到的家庭信息也会显示为一行，例如洗碗机的品牌。编辑这一行时，也会同步更改**我学到的内容**下的对应内容。
- 如果你在某个分类下创建了自己的笔记，例如在**家电**下为洗碗机建了一篇笔记，相关内容就会放进这篇笔记中。你的 Machine 不会自动创建这类笔记。

只会使用个人账单、订阅和邮件，家相关笔记也始终归为个人。你的 Machine 会针对每笔新账单、每项新订阅或每条新学到的内容，向 AI 查询一次，以判断是否与家庭有关。对于账单，它只会发送来源信息，不会发送金额。

你的对话也会放进这些笔记中，详情见上文的**对话笔记**。

## 健康

在**健康**下，你的 Machine 会保存它了解到的个人健康信息，包括**预约**、**测试结果**、**医生和医疗护理**、**药品**、**过敏和病症**以及**账单和保险**。每个分类至少有两行内容后才会显示。

- 医生、牙医或药房的账单会显示一行，点按即可打开对应待办事项。金额会保留在待办事项中。
- 诊所、医院、实验室或健康保险公司的每封邮件，都会显示为带日期的一行，并标明主题，逐步整理出你的健康记录。点按即可打开邮件。
- 你的 Machine 学到的健康信息也会显示为一行，例如过敏情况。编辑这一行时，也会同步更改**我学到的内容**下的对应内容。
- 如果你在某个分类下创建了自己的笔记，例如在**预约**下为理疗师创建的笔记，与其相关的内容就会放进这篇笔记中。

健康笔记始终归为个人，即使账单寄到了你的工作邮箱也是如此。你的 Machine 会针对每笔新账单或每条新学到的内容，向 AI 查询一次，以判断是否与你的个人健康有关。

## 孩子

在**孩子**下，你的 Machine 会保存它了解到的孩子相关信息，包括**学校**、**活动**、**育儿**、**医生和医疗护理**以及**账单和费用**。保姆或日托机构的信息会放在育儿下，不会放在医生和医疗护理下。每个分类至少有两行内容后才会显示。

- 你的 Machine 学到的孩子相关信息，例如班主任或游泳日，会显示为一行并链接到孩子的页面。如果某人在**发给你**中被标记为你的孩子，例如女儿或儿子，就会被视为你的孩子。
- 学校、俱乐部或育儿服务的账单会显示一行，点按即可打开对应待办事项。金额会保留在待办事项中。
- 学校、俱乐部或育儿服务发来的每封邮件，例如旅行通知或计划变更，都会显示为带日期的一行，并标明主题，让所有邮件都集中在一处。点按即可打开邮件。
- 如果你在某个分类下为一个孩子创建了自己的笔记，例如在**学校**下为 Isla 创建的笔记，与这个孩子相关的内容就会放进这篇笔记中。

孩子相关笔记始终归为个人，即使学校发邮件到你的工作邮箱也是如此。你的 Machine 会针对每条新内容，向 AI 查询一次，以判断是否与你的孩子有关。

## 合并、删除和撤销

在 ⋯ 菜单中选择**合并到…**，即可将一篇笔记中的内容及其下级笔记移到另一篇笔记中。之后，你的 Machine 会将新内容添加到目标笔记中。选择**删除**即可删除笔记。删除笔记或移除某一行后，都会短暂显示**撤销**。

## 与会议笔记不同

会议笔记以及人物或组织的笔记仍保留在原处。这里的笔记是独立的页面。
