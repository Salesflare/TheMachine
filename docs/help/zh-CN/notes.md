笔记是某个主题的概览，例如一次旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一样，都位于 Graph 中。笔记保存在 The Machine 上，不会与团队共享。

## 开始写笔记

在笔记顶部点按**新建笔记**。输入标题并点按**开始写笔记**，笔记页面就会打开。点按**添加一行**，即可添加想要保留的内容。每行文字都会单独成为一行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和名字的几个字母。从列表中选择人物、组织、项目或笔记，所选名称就会作为链接插入。你链接到的页面会在**链接自**下显示这篇笔记。

## 笔记下的笔记

笔记可以放在另一篇笔记下，例如把家电放在家下面。笔记会以树状结构显示，点按笔记旁边的箭头即可展开其下的笔记。要移动笔记，点按**编辑**，然后在**低于**下选择放置位置。点按 ⋯ 菜单中的**在此笔记下新建笔记**，即可直接在这里新建笔记。

笔记页面顶部会显示笔记所在位置，例如**笔记 › 孩子**。点按其中任意一部分即可跳转到相应位置。在手机上，中间层级的笔记会折叠到 ⋯ 中。

## The Machine 保存的笔记

The Machine 也会根据你的消息自动记笔记，并保持内容更新。每条内容都会注明来源，例如是谁发来的邮件。点按即可打开邮件。来自**我学到的内容**的条目会标注为**根据我学到的内容**。日历中的会议或预约不会单独成为一条笔记，而是保留在[日历](calendar.md)中。

只有当 The Machine 至少有两条实际内容可写时，**家**、**健康**和**孩子**才会显示，例如一张账单或它学到的信息。在此之前，这些内容不会出现在列表中。如果后来又没有内容了，它们也会消失。

你所做的更改始终有效。重命名笔记、移动笔记、更改日期或修改条目后，The Machine 更新笔记时会保留这些更改。删除条目或笔记后，它们不会恢复。以后有关同一主题的笔记会放到你最初指定的位置。

点按**恢复原状**，即可重新显示 The Machine 自己写的内容。编辑来自 The Machine 所学内容的条目，也会同步修改**我学到的内容**中的对应内容，因此只会保留一个版本。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，The Machine 会在**旅行**下为其添加一趟行程。同一次旅程的预订会归到同一趟行程中，包括去程、酒店和返程。每条预订信息都包含预订代码、座位和票务信息，并按时间排序。行程还会显示日期。在[日历](calendar.md)中，行程会以横跨这些日期的一条色带显示，点按即可打开行程。

The Machine 会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。没有这些详情的邮件不会生成行程。对于 The Machine 所保留的[历史记录](history.md)年份内的旧预订邮件，系统会在导入历史记录后于后台读取，并优先处理你的个人邮箱。

预订变更后，相应条目会更新；预订取消后，相应条目会移除。行程中的所有预订都取消后，整趟行程也会移除。

## 事件

音乐会、比赛、节日或会议的门票邮件到达后，The Machine 会在**事件**下添加事件，每个事件一篇笔记。条目会显示活动地点、预订代码、座位和门票数量。同一事件的第二笔订单也会添加到同一篇笔记中。和旅行一样，事件会显示日期，并在[日历](calendar.md)中以一条色带显示，点按即可打开笔记。

- 每条内容都会注明门票来源，例如**来自 Example Tickets**，点按即可打开邮件。
- 如果门票邮件生成了待办事项，例如支付门票费用，点按**打开待办事项**即可查看。
- 通过工作邮箱预订的事件会归为工作，否则归为个人。

The Machine 不使用 AI，而是读取票务销售方在确认邮件中提供的门票详情。没有这些详情的邮件不会生成事件。预订取消后，相应条目会移除；事件的所有门票都取消后，整个事件也会移除。

## 家

在**家**下，The Machine 会保存它所了解的家中信息，包括**账单和订阅**、**家电**、**维修和保养**以及**房子**。某个部分至少有两条内容后才会显示。

- 定期产生的账单，例如能源费或水费，会作为一条内容显示，注明账单频率和上次账单的日期。点按**打开待办事项**可查看账单本身，金额和付款详情会保留在账单中。
- 你保留的订阅会作为一条内容显示，点按即可打开对应的**订阅**待办事项。已取消的订阅不会列出。
- 经常联系你家的人或机构，例如能源供应商、互联网服务商或市政部门，会作为一条内容显示，并注明联系频率。点按即可打开最新邮件。
- The Machine 学到的家中信息，例如洗碗机的品牌，也会作为一条内容显示。编辑后，**我学到的内容**下的对应信息也会更改。
- 如果你在某个部分中保留了自己的笔记，例如在**家电**下为洗碗机写了一篇笔记，与洗碗机有关的内容就会放到这篇笔记中。The Machine 不会自动新建这类笔记。

系统只会使用个人账单、订阅和邮件，家相关的笔记始终归为个人。对于每一项新账单、新订阅或新学到的信息，The Machine 都会向 AI 询问一次，以判断内容是否与家有关。对于账单，系统只会发送账单来源，不会发送金额。

对于**家**、**健康**和**孩子**，The Machine 还会针对每位个人邮件的发件人向 AI 询问一次。系统会发送发件人姓名、对方发来的邮件数量，以及隐藏数字后的最新邮件主题，但不会发送邮件本身。

首次处理时，系统会在几小时内检查你过去一年的邮件，不会在夜间进行，并且只会在你的 AI 方案有可用额度时进行。之后，系统每六小时检查一次新发件人。

## 健康

在**健康**下，The Machine 会保存它所了解的个人健康信息，包括**预约**、**测试结果**、**医生和医疗护理**、**药品**、**过敏和病症**以及**账单和保险**。某个部分至少有两条内容后才会显示。

- 医生、牙医或药房的账单会作为一条内容显示，点按即可打开对应的待办事项。金额会保留在待办事项中。
- 诊所、医院、实验室或健康保险公司的每封邮件都会作为带日期的条目显示，并附上邮件主题，让你的记录逐渐积累。点按即可打开邮件。
- The Machine 学到的健康信息，例如过敏情况，也会作为一条内容显示。编辑后，**我学到的内容**下的对应信息也会更改。
- 如果你在某个部分中为自己写了笔记，例如在**预约**下为理疗师写了一篇笔记，与这件事有关的内容就会放到这篇笔记中。

健康笔记始终归为个人，即使账单发到了你的工作邮箱也是如此。对于每一项新账单或新学到的信息，The Machine 都会向 AI 询问一次，以判断内容是否与你的健康有关。

## 孩子

在**孩子**下，The Machine 会保存它所了解的孩子相关信息，包括**学校**、**活动**、**育儿**、**医生和医疗护理**以及**账单和费用**。保姆或日托服务会归到育儿下，不会归到医生和医疗护理下。某个部分至少有两条内容后才会显示。

- The Machine 学到的孩子相关信息，例如班主任或游泳课时间，会作为一条链接到孩子页面的内容显示。如果某人在**发给你**中被标记为你的女儿或儿子等关系，系统就会将其视为你的孩子。
- 学校、社团或育儿服务的账单会作为一条内容显示，点按即可打开对应的待办事项。金额会保留在待办事项中。
- 学校、社团或育儿服务发来的每封邮件，例如每周通讯或有关郊游的通知，都会作为带日期的条目显示，并附上邮件主题，让所有邮件集中在一处。点按即可打开邮件。
- 如果你在某个部分中为一个孩子写了自己的笔记，例如在**学校**下为 Isla 写了一篇笔记，与这个孩子有关的内容就会放到这篇笔记中。

孩子相关的笔记始终归为个人，即使学校发邮件到你的工作邮箱也是如此。对于每一项新内容，The Machine 都会向 AI 询问一次，以判断内容是否与你的孩子有关。

## 合并、删除和撤销

点按 ⋯ 菜单中的**合并到…**，即可将一篇笔记中的条目和其下的笔记移到另一篇笔记中。之后，The Machine 会继续将内容添加到那篇笔记中。点按**删除**可删除笔记。这两种操作都会短暂显示**撤销**，删除条目时也一样。

## 与会议笔记不同

会议笔记以及人物或组织的笔记仍保留在原处。这里的笔记是独立页面。
