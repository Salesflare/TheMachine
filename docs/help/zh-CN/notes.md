笔记是某个主题的概览，比如一次旅行、你的家，或发票的处理方式。笔记和人物、组织及项目一起显示在 Graph 中。笔记保存在你的 Machine 上，不会与你的团队共享。

## 新建笔记

在“笔记”页面顶部选择 **新建笔记**。输入标题并选择 **开始写笔记**，笔记页面就会打开。选择 **添加一行**，即可添加想要保留的内容。每行文字都会单独显示为一行。

## 链接人物、项目和其他笔记

在一行中输入 @ 和姓名的前几个字母。从列表中选择人物、组织、项目或笔记，所选名称就会以链接形式添加。被链接对象的页面会在 **链接自** 下显示你的笔记。

## 笔记下的笔记

笔记可以放在另一篇笔记下，比如把“家电”放在“家”下。“笔记”会以树状结构显示笔记：点击笔记旁边的箭头，即可展开其下的笔记。要移动笔记，选择 **编辑**，然后在 **低于** 下选择放置位置。在 ⋯ 菜单中选择 **在此笔记下新建笔记**，即可直接在此处新建笔记。

## 你的 Machine 保存的笔记

你的 Machine 也会根据你的消息自动撰写笔记，并保持内容更新。每行都会说明内容的来源，比如是谁发来的邮件。点击该行即可打开邮件。来自 **我学到的内容** 的行会标记为 **根据我学到的内容**。

你的修改始终有效。重命名笔记、移动笔记、更改日期或修改某一行后，你的 Machine 更新笔记时会保留这些修改。删除一行或一篇笔记后，它就不会再出现。之后记录的同一主题内容，会添加到你最初放置笔记的位置。

选择 **恢复原状**，即可再次显示你的 Machine 撰写的内容。编辑一行来自你的 Machine 学到的内容时，也会同步更改 **我学到的内容** 下的内容，因此只会保留一个版本。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件送达后，你的 Machine 会在 **旅行** 下将其添加到一趟行程中。一次旅程的所有预订会放在同一趟行程里，包括去程、酒店和返程。行程会按时间顺序显示每项预订的预订代码、座位和票务信息，并显示行程日期。在 [日历](calendar.md) 中，行程会显示为横跨这些日期的一条色带，点击即可打开行程。

你的 Machine 会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。邮件中没有这些信息，就不会创建行程。预订有变更时，会更新对应内容；预订取消后，对应内容会移除。如果行程中的所有预订都已取消，行程也会移除。

## 事件

音乐会、比赛、节日或会议的门票邮件送达后，你的 Machine 会在 **事件** 下为每个活动添加一篇笔记。每行会显示活动地点、预订代码、座位和门票数量。同一活动的第二笔订单会添加到同一篇笔记中。和旅行一样，活动会显示日期，并在 [日历](calendar.md) 中显示为一条色带，点击即可打开笔记。

- 每行都会说明门票来自哪里，比如 **来自示例票务**，点击即可打开邮件。
- 如果门票邮件生成了待办事项，比如支付门票费用，选择 **打开待办事项** 即可查看。
- 通过工作邮箱预订的活动属于工作活动，其他则属于个人活动。

你的 Machine 会读取票务销售方在确认邮件中提供的门票详情，不使用 AI。邮件中没有这些信息，就不会创建活动。预订取消后，对应内容会移除；如果活动的所有门票都已取消，活动也会移除。

## 家

在 **家** 下，你的 Machine 会保存它了解到的与你的家有关的信息：**账单和订阅**、**家电**、**维修和保养**以及**房子**。某个类别至少有两行内容后才会显示。

- 定期产生的账单，比如能源费或水费，会显示一行，说明账单的周期和上一笔账单的日期。选择 **打开待办事项** 可查看账单本身；金额和付款详情会保留在那里。
- 你保留的订阅会显示一行，点击即可打开对应的 **订阅** 待办事项。已取消的订阅不会显示。
- 你的 Machine 学到的家中信息，比如洗碗机的品牌，也会显示为一行。编辑后，**我学到的内容** 下的信息也会同步更改。
- 如果你在某个类别中保留了自己的笔记，比如在 **家电** 下为洗碗机创建的笔记，与该物品有关的内容就会放在你的笔记中。你的 Machine 不会自行创建这类笔记。

只会使用个人账单和订阅，家相关的笔记始终是个人内容。每有一笔新账单、新订阅或新学到的事项，你的 Machine 都会向 AI 询问一次，以判断它是否与你的家有关。对于账单，它会发送账单来源，但不会发送金额。

## 健康

在 **健康** 下，你的 Machine 会保存它了解到的与你自身健康有关的信息：**预约**、**医生和医疗护理**、**药品**、**过敏和病症**以及**账单和保险**。某个类别至少有两行内容后才会显示。

- 日历中只有你参加的预约，比如看牙医，会显示一行，注明下次或上次预约的日期。选择 **根据你的日历** 即可打开预约。
- 医生、牙医或药房寄来的账单会显示一行，点击即可打开对应的待办事项。金额会保留在那里。
- 你的 Machine 学到的健康信息，比如过敏情况，也会显示为一行。编辑后，**我学到的内容** 下的信息也会同步更改。
- 如果你在某个类别中为自己保留了笔记，比如在 **预约** 下为理疗师创建的笔记，与该事项有关的内容就会放在这篇笔记中。

健康笔记始终是个人内容，即使账单寄到了你的工作邮箱也是如此。每有一项新预约、新账单或新学到的事项，你的 Machine 都会向 AI 询问一次，以判断它是否与你自身的健康有关。对于预约，它会发送预约名称，但不会发送备注或其他受邀人的信息。

## 孩子

在 **孩子** 下，你的 Machine 会保存它了解到的与你的孩子有关的信息：**学校**、**活动**、**医生和医疗护理**以及**账单和费用**。某个类别至少有两行内容后才会显示。

- 你的 Machine 学到的孩子相关信息，比如班主任或游泳日，会显示为一行，并链接到孩子的页面。当某个人的 **发给你** 信息表明对方是你的孩子，比如女儿或儿子时，Machine 就会将其视为你的孩子。
- 日历中只有你参加的活动，比如家长会，会显示一行，注明下次或上次的日期。选择 **根据你的日历** 即可打开活动。
- 学校、社团或托儿服务的账单会显示一行，点击即可打开对应的待办事项。金额会保留在那里。
- 如果你在某个类别中为一个孩子保留了自己的笔记，比如在 **学校** 下为 Isla 创建的笔记，与该孩子有关的内容就会放在这篇笔记中。

孩子相关的笔记始终是个人内容，即使学校邮件寄到了你的工作邮箱也是如此。每有一项新内容，你的 Machine 都会向 AI 询问一次，以判断它是否与你的孩子有关。

## 合并、删除和撤销

在 ⋯ 菜单中选择 **合并到…**，即可将一篇笔记中的各行内容及其下的笔记移到另一篇笔记中。之后，你的 Machine 会将新内容添加到那篇笔记中。选择 **删除** 可移除笔记。删除笔记、合并笔记或移除某一行后，都会短暂显示 **撤销**。

## 与会议笔记不同

会议笔记以及人物或组织页面上的笔记仍保留在原处。这里的笔记是独立页面。
