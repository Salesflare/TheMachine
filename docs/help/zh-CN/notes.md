笔记是对某个主题的概览，比如一次旅行、你的家，或发票的处理方式。笔记与人物、组织和项目一起显示在 Graph 中。笔记保存在你的 Machine 上，不会与团队共享。

## 开始写笔记

在笔记页顶部点击 **新建笔记**。输入标题并点击 **开始写笔记**，笔记页面就会打开。点击 **添加一行**，添加你想保留的内容。每段文字都会单独成行。

## 链接到人物、项目和其他笔记

在一行中输入 @ 和姓名的几个字母。从列表中选择人物、组织、项目或笔记，名称就会以链接的形式添加进去。被链接页面的 **链接自** 部分会显示你的笔记。

## 笔记下的笔记

笔记可以放在另一篇笔记下，比如把家电放在家下面。笔记会以树状结构显示：点击笔记旁的箭头，可以展开其下的笔记。要移动笔记，点击 **编辑**，然后在 **低于** 下选择放置位置。点击 ⋯ 菜单中的 **在此笔记下新建笔记**，即可直接在这里新建笔记。

笔记页面顶部会显示它所在的位置，比如 **笔记 › 孩子**。点击其中任意部分即可前往对应位置。在手机上，中间的笔记会收起到 ⋯ 菜单中。

## 你的 Machine 保存的笔记

你的 Machine 也会根据你的消息自动撰写笔记，并持续更新。每一行都会注明来源，比如邮件的发件人。点击即可打开消息。来自 **我学到的内容** 的行会标注为 **根据我学到的内容**。

日历中的会议或预约不会单独作为一行显示，而是保留在[日历](calendar.md)中。相关邮件也一样，包括邀请、回复、更新和取消通知。

只有当你的 Machine 至少有两条确切内容可以记录时，**家**、**健康**和**孩子**才会显示，比如一张账单或它学到的信息。在此之前，这些分类不会出现在列表中。如果其中再次没有内容，就会从列表中消失。

你的更改始终有效。重命名笔记、移动笔记、更改日期或修改其中一行后，你的 Machine 更新笔记时会保留这些更改。删除一行或一篇笔记后，它不会恢复。之后，同一主题的新笔记会放到你最初放置的位置。

点击 **恢复原状**，即可再次查看你的 Machine 自己撰写的内容。编辑一条来自你的 Machine 所学内容的行，也会同步修改 **我学到的内容** 中的内容，因此只保留一个版本。

## 撰写好的页面

一篇笔记中至少有两行来自你的消息或你的 Machine 学到的内容后，你的 Machine 就会在页面顶部撰写内容。它会阅读对话本身，而不只是对话主题：

- 简短摘要：说明主题以及当前进展。
- 仅在有具体内容可写时，才会显示 **关键信息**、**决策**、**待处理事项**和**时间线**。
- 笔记中的各行会按编号显示在 **来源** 下方。每句话结尾都会标出对应来源行的编号。点击编号即可跳转到该行。

只有笔记中的内容发生变化时，页面才会重新撰写，最多大约每天一次。如果来源中没有具体内容可写，就不会生成页面，只显示各行内容。删除一行后，页面中仅来自该行的内容也会一并删除。笔记列表会在笔记名称下方显示每篇页面摘要的开头。

项目或组织在 Graph 中已经有自己的页面，页面顶部会显示其简介。相关对话会放在该页面中，而不是笔记里。

## 对话笔记

你的 Machine 会阅读完整对话，并将每段对话整理到相关笔记中：包括你任一邮箱中的邮件往来、WhatsApp、Slack、Telegram、LinkedIn 或其他已连接应用中的聊天，以及会议笔记。聊天消息会被视为同一段对话，直到聊天安静两天。

- 关于 Graph 中某个项目或组织的对话会放在对应页面中，而不是新建笔记。
- 对话可以放在 **家**、**健康**或**孩子**的某个分类中，也可以放在你自己的笔记里，或你的 Machine 在 **工作**、**汽车**、**税务**等文件夹下新建的笔记里。
- 只有某个主题至少有两段对话，或你写了一段明显还在继续的对话时，你的 Machine 才会为它新建笔记。
- 每一行对应一段对话，按时间从新到旧排列。点击即可打开对话。

它会向 AI 发送每段对话中的一小部分，不包括引用的回复或签名。每段对话只会询问一次，之后的新消息会接着添加到该对话中。

群发邮件和聊天不会放进笔记，也不会发送给 AI，包括垃圾邮件、促销信息、新闻邮件和其他邮件列表邮件、自动通知、机器人消息和广播频道。你参与撰写的对话仍会计入，**旅行**和**事件**的预订邮件也一样。

首次整理时，它会在几小时内处理你过去三个月的内容，在夜间以外进行，并且只有在你的 AI 方案还有可用额度时才会处理。之后，待处理的对话达到十段，或有一段等待了半天时，它就会整理新的对话。

## 旅行

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，你的 Machine 会在 **旅行** 下为其添加一趟行程。同一趟旅程的预订会放在同一行程中，包括去程、酒店和返程。行程按时间顺序列出每项预订的预订代码、座位和票务信息，并显示日期。在[日历](calendar.md)中，行程会以横跨这些日期的条带显示，点击即可打开行程。

它会读取航空公司、酒店和预订网站在确认邮件中提供的预订详情。没有这些详情的邮件不会生成行程。对于较早收到的预订邮件，你的 Machine 会在导入所保留的[历史记录](history.md)后，在后台读取历史记录当年范围内的邮件，并优先处理你的个人邮箱。之后读取到更早的确认邮件时，会将内容添加到已有行程中。

预订有变更时，会更新对应行。预订取消后，对应行会被删除。当一趟行程中的所有预订都取消后，行程也会删除。

## 事件

演唱会、比赛、节日庆典或会议的门票邮件到达后，你的 Machine 会在 **事件** 下添加活动，每个活动对应一篇笔记。一行会注明活动地点、预订代码、座位和门票数量。同一活动的第二笔订单会添加到同一篇笔记中。和行程一样，活动会显示日期，并以横跨对应日期的条带显示在[日历](calendar.md)中，点击即可打开笔记。

- 每一行都会注明门票的来源，比如 **来自 Example Tickets**，点击即可打开对应邮件。
- 如果待办事项来自门票邮件，比如支付门票费用，点击 **打开待办事项** 即可查看。
- 通过工作邮箱预订的活动归为工作，其他活动则归为个人。

它会直接读取售票方在确认邮件中提供的门票详情，不使用 AI。没有这些详情的邮件不会生成活动。预订取消后，对应内容会被删除；活动的所有门票都取消后，活动也会删除。

## 家

在 **家** 下，你的 Machine 会保存所了解的家庭相关信息：**账单和订阅**、**家电**、**维修和保养**以及**房子**。某个分类至少有两行内容后才会显示。

- 定期账单，比如能源费或水费，会显示一行，注明账单周期和最近一期的日期。点击 **打开待办事项** 可查看账单本身，金额和付款详情会保留在账单中。
- 你保留的订阅会显示一行，点击即可打开对应的 **订阅**待办事项。已取消的订阅不会显示。
- 经常联系你的家庭服务方，比如能源供应商、网络服务商或市政机构，会显示一行，注明联系频率。点击即可打开最新邮件。
- 你的 Machine 学到的家庭信息，比如洗碗机的品牌，也会显示为一行。编辑该行也会同步修改 **我学到的内容** 下的内容。
- 如果你在某个分类中保留了自己的笔记，比如在 **家电** 下为洗碗机建了一篇笔记，相关内容就会放进那篇笔记。你的 Machine 不会自动创建这类笔记。

只会使用个人账单、订阅和邮件，家相关的笔记始终归为个人。对于每一笔新账单、每项新订阅或学到的新内容，你的 Machine 都会向 AI 询问一次，以判断它是否与家庭有关。对于账单，它只会发送发件方，不会发送金额。

你的对话也会整理到这些笔记中，具体说明见上文的 **对话笔记**。

## 健康

在 **健康** 下，你的 Machine 会保存所了解的个人健康信息：**预约**、**测试结果**、**医生和医疗护理**、**药品**、**过敏和病症**以及**账单和保险**。某个分类至少有两行内容后才会显示。

- 医生、牙医或药房的账单会显示一行，点击即可打开对应待办事项。金额会保留在待办事项中。
- 诊所、医院、实验室或健康保险公司的每封邮件都会显示为带日期的一行，并附上主题，方便你逐步积累记录。点击即可打开邮件。
- 你的 Machine 学到的健康信息，比如过敏情况，也会显示为一行。编辑该行也会同步修改 **我学到的内容** 下的内容。
- 如果你在某个分类中为自己保留了笔记，比如在 **预约** 下为理疗师建了一篇笔记，相关内容就会放进那篇笔记。

健康笔记始终归为个人，即使账单发送到了工作邮箱也是如此。对于每一笔新账单或学到的新内容，你的 Machine 都会向 AI 询问一次，以判断它是否与你的个人健康有关。

## 孩子

在 **孩子** 下，你的 Machine 会保存所了解的孩子相关信息：**学校**、**活动**、**育儿**、**医生和医疗护理**以及**账单和费用**。保姆或日托机构会归入育儿，不会归入医生和医疗护理。某个分类至少有两行内容后才会显示。

- 你的 Machine 学到的孩子相关信息，比如班主任或游泳日，会显示为一行，并链接到孩子的页面。当某人在 **发给你** 中被标注为你的孩子，比如女儿或儿子时，系统就会将其视为你的孩子。
- 学校、社团或育儿服务的账单会显示一行，点击即可打开对应待办事项。金额会保留在待办事项中。
- 学校、社团或育儿服务发来的每封邮件，比如关于旅行的通知或计划变更，都会显示为带日期的一行，并附上主题，方便你集中查看所有来信。点击即可打开邮件。
- 如果你在某个分类中为某个孩子保留了自己的笔记，比如在 **学校** 下为 Isla 建了一篇笔记，相关内容就会放进那篇笔记。

孩子相关的笔记始终归为个人，即使学校发邮件到了工作邮箱也是如此。对于每项新内容，你的 Machine 都会向 AI 询问一次，以判断它是否与你的孩子有关。

## 合并、删除和撤销

点击 ⋯ 菜单中的 **合并到…**，可以将一篇笔记中的各行以及其下的笔记移到另一篇笔记中。之后，你的 Machine 会将新内容添加到目标笔记中。点击 **删除** 可删除笔记。这两种操作完成后，都会短暂显示 **撤销**，删除一行后也一样。

## 与会议笔记不同

会议笔记以及人物或组织的笔记仍保留在原处。这里的笔记是独立页面。
