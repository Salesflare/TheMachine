想减少通知，或换一种通知方式？点击“设置”>“通知”，选择每种内容的通知方式：

- **新增待办**：只通知不能等的事，例如今天截止或标记为紧急的待办。
- **结果和问题**：准备好发送的回复、任务需要你登录，或 Fleet 提出问题。
- **提醒**：稍后处理的待办，以及等待回复的事项重新出现时。
- **早间摘要**：当天内容的简短摘要。详见下文。
- **晚间摘要**：当天完成的事项和明天待办的内容。详见下文。

每种内容都可以分别设置 **推送**（手机或电脑上的应用）、完成设置后通过 **Telegram** 接收，以及在托管版 Machine 或 The Machine Network 上的 Machine 中通过 **邮件** 接收。除 Telegram 上的摘要外，其他选项默认均已开启。

同一标签页中还可以设置 **工作时间**：工作日、允许发送通知的时间、稍后处理的待办返回的时间、摘要发送时间和时区。详见[工作时间](work-hours.md)。

## 只通知不能等的事

以下情况才会发送推送、Telegram 提醒或邮件：

- 待办今天截止，或已标记为紧急；
- 有人在等一条回复，回复已拟好并可发送；
- 有任务需要你登录；
- 稍后处理的待办在你选择的时间重新出现。

其他内容都会安静地出现在控制面板上（在 Telegram 中也不会发出提示音），等到早间摘要时再提醒。休息日只会提醒紧急或今天截止的事项。每天最多发送8条推送。如果你连续3天没有打开控制面板，就只会收到早间摘要，直到你回来。

## 何时发送通知

系统会判断你是否真的在使用控制面板，而不只是看它有没有打开：

- 正在使用（页面在前台，并且你在过去10分钟内点击、输入或滚动过）：不会发出提示音。Telegram 消息会静默送达。仅仅打开或重新加载页面不算。
- 暂时离开（页面在后台、已关闭，或10分钟没有操作）：离开1分钟后发送推送，除非你回来并已看到相关内容。
- 15分钟后你仍未收到提醒，而且事情不能等：会为这件事发送一封邮件，每小时最多一封。你已看过或处理过的内容不会放进邮件，每个待办只会出现一次，内容以当时的状态为准。大多数时候，你只会收到早间摘要邮件。
- 收到提醒，指通知已显示在手机或浏览器上，或 Telegram 已接收消息。手机关机、离线或关闭了通知都不算收到；你正在使用控制面板时，Telegram 也不算。若只在电脑上显示了通知，紧急或今天截止的内容仍会通过邮件发送，因为你可能不在电脑旁。
- 没有手机应用、浏览器通知或 Telegram？以上所有内容都会通过邮件发送。
- Telegram 无法送达：推送仍会发送一次，系统也会自动重试 Telegram。
- 队友交给你一个待办，而你的Machine无法通过手机或 Telegram 联系你：如果15分钟后你仍未看到，会收到一封邮件，其中包含待办标题和链接。关闭 **结果和问题** 的 **邮件** 即可停用此功能。
- Claude 登录将在3天内到期，或已经到期：每次登录只会收到一封邮件，其中有 **重新登录**。关闭 **结果和问题** 的 **邮件** 即可停用此功能。
- 不在工作时间内：不会发送通知，内容会放进早间摘要。
- 休息日收到新的工作待办时，它会等到下一个工作日的摘要发送时间。待办会显示预计通知时间，例如“通知 周一 11月2日 · 08:30”。

进度更新和编辑不会触发通知。对于你还没查看过的待办，如果有更新的结果，系统会直接更新内容，不会再发一条通知。一连串提醒只会响一次。应用图标会显示有多少待办需要你处理。

## 通知上的按钮

每条通知都提供了下一步操作按钮。在手机应用中：

- 新待办：**执行**、**稍后处理**、**标记为已完成**。
- 草稿已准备好：**打开草稿**、**稍后处理**、**标记为已完成**。
- 结果已准备好：**打开**、**标记为已完成**、**稍后处理**。
- 需要你回复、事项受阻或需要登录：**回复**、**打开**或**登录**，然后选择**稍后处理**或**标记为已完成**。
- 提醒：**标记为已完成**、**稍后处理**、**打开**。
- 早间摘要：点击即可打开。

浏览器和 Telegram 通知只显示其中两个按钮。Fleet 问题会一直显示**回复**和**拒绝**按钮。

通知不会帮你发送、付款或提交任何内容。草稿总会先打开，让你确认后再发送。点击**打开草稿**会在待办列表中显示该待办和完整草稿。点击**执行**只会开始处理新待办。

在手机应用中，点击**稍后处理**或**标记为已完成**前，需要先解锁。在浏览器中，这些按钮会打开控制面板并执行操作，同时提供**撤销**选项。稍后处理后，待办会在两小时后重新出现；提醒则会在第二天早上重新出现。

邮件中有**打开**链接（等待处理的事项还会有**稍后处理**链接）。这些链接只会打开控制面板。

点击通知，或点击邮件、Telegram 中的**打开**，会在待办列表中高亮显示该待办，无论它现在位于哪个视图：**刚刚完成**、**已完成**、**稍后回来**或其他视图。它不会打开聊天。如果页面还没更新，页面同步后会自动定位到该待办。

## 早间摘要

工作日的 **早间摘要**时间会发送摘要；如果没有内容，则不会发送。如果这个时间早于 **推迟的待办会在此时间返回**，摘要会等到该时间后5分钟发送，确保当天早上重新出现的待办也包含在内。点击 **预览**可以查看摘要，但不会发送。默认通过推送和邮件发送，内容简短，方便快速浏览：

- 开头会问候你并提示当天的重要事项，例如“早上好，Sam，有2条回复已准备好发送”，或者只有一个待办时显示“早上好，Sam，请确认：发送订单表”。只有需要审批草稿或结果的待办才算准备就绪；需要你先回复的待办不算；
- 问候语中提到的待办，每个都带有**打开**链接，并列出今天截止的事项；如果没有，则最多显示三件要做的事；
- 你自己添加、目前需要你处理的待办，最多五个，无论问候语中提到了多少待办；
- 还有多少事项可以稍后处理，以及按你的速度大约需要多久，例如“还有12项可以稍后处理，清理完大约需要5分钟”。等待你回复的待办不计入所需时间；今天截止但已推迟到稍后处理的待办，以及 The Machine 仍在处理的待办，在需要你处理之前都不会计入。这里的数量与你的待办列表中等待处理的数量一致；
- 用一行显示你的会议。

点击**打开**会在待办列表中高亮显示该待办，即使它已完成或已推迟。承诺会打开对应待办；如果还没有待办，则会打开承诺自己的页面。

推送中也会显示相同内容，但不带链接。点击推送，或点击邮件末尾的链接，可以在 **待办**中再次查看这份摘要。

## 晚间摘要

工作日会在“工作时间”中设置的时间发送一次，默认在 **直到**时间前15分钟发送，并通过上方该行中选定的方式送达。只有当天你有使用控制面板，或在控制面板、Telegram、聊天或语音中处理过待办，才会收到摘要。当天没有完成待办或参加会议，则不会收到摘要。

摘要会先用数字概括当天情况，例如“晚上好，Sam，今天完成了4个待办”，接着分为 **工作**和 **个人**两部分。没有内容的部分不会显示。关于你的Machine本身的提醒不会归入任何一部分。每部分包含：

- **今日已完成**：最多显示你或你的Machine完成的三个待办，然后显示“还有12项”和当天的会议，例如“还有3场会议：定价电话会议及另外2场”；
- **明天的待办**（周五则显示下一个工作日）：显示最早的几场会议和截止事项。

摘要末尾会显示还有多少待办需要你处理。点击推送，或点击邮件末尾的链接，可以再次查看摘要，并使用 **复制工作**和 **复制个人**。要停止接收，请关闭该行的选项。

## 隐私

推送会从你的Machine直接发送到设备，并针对该设备加密。邮件会经过 The Machine 的邮件服务器和你的邮件服务提供商。当[谨慎模式](security-levels.md)在通知中隐藏待办文字时，邮件中只会显示数量。关闭某类通知的 **邮件**，即可不通过邮件接收该类通知。

在 **此设备**中为设备开启推送，或查看[安装应用](phone-app.md)。[手机应用](mobile-app.md)会先通过 Apple 或 Google 获取一条纯文本消息，然后向你的Machine请求标题和下一步操作。
