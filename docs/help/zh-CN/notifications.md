想少收点通知，或者换种方式接收？在“设置”>“通知”中，选择每类通知的接收方式：

- **新增待办**：只通知不能等的事，比如今天截止或标记为紧急的待办。
- **结果和问题**：准备好发送的回复、任务需要登录，或 Fleet 提出的问题。
- **提醒**：稍后处理的待办，以及等待回复的待办重新回来时的通知。
- **早间摘要**：一份简短的每日摘要。详见下文。
- **晚间摘要**：今天完成的事项和明天待处理的事项。详见下文。

每类通知都可以分别开关**推送**（手机或电脑上的应用）、完成设置后的**Telegram**，以及托管版 Machine 或 The Machine Network 上的 Machine 所用的**邮件**。默认全部开启，Telegram 上的摘要除外。

同一标签页里还有你的**工作时间**设置：工作日、允许发送通知的时段、推迟的待办返回时间、摘要发送时间和时区。详见[工作时间](work-hours.md)。

## 只提醒不能等的事

只有以下情况会发送推送、Telegram 提醒或邮件：

- 待办今天截止，或已标记为紧急；
- 有人等待的回复已起草完毕，可以发送；
- 任务需要你登录；
- 推迟的待办在你设定的时间返回。

其他内容会安静地显示在控制面板上（在 Telegram 中也不会发出声音），等到早间摘要再提醒你。休息日只会提醒紧急事项或今天截止的待办。每天最多发送8条推送。如果你3天没有打开控制面板，在你回来之前只会收到早间摘要。

## 通知发送时间

系统会检查你是否真的在使用控制面板，而不只是看它有没有打开：

- 正在使用（页面在前台，并且你在过去10分钟内点击、输入或滚动过）：不会发出声音。Telegram 通知会静默送达。仅仅打开或重新加载页面不算。
- 暂时离开（页面在后台、已关闭，或10分钟没有操作）：离开1分钟后发送推送，除非你已经回来并看到了通知。
- 15分钟后仍未查看，且事情不能等：会为这件事发送一封邮件，每小时最多一封。你已经处理的内容不会放进邮件，每条待办只会出现一次，内容以发送时的状态为准。大多数时候，你只会收到早间摘要邮件。
- 队友把待办交给你，而你的 Machine 没有可联系到你的手机或 Telegram：如果15分钟后你仍未查看，会发送一封邮件，包含待办标题和链接。关闭**结果和问题**中的**邮件**即可停止此类邮件。
- 超出工作时间：不会发送通知，相关内容会放进早间摘要。
- 休息日新增的工作待办会等到下一个工作日的摘要时间再通知你。待办会显示通知时间，例如“通知：11月2日周一 · 08:30”。

进度更新和编辑不会触发通知。你尚未查看的待办有了新结果时，内容会更新，但不会再次通知。短时间内连续出现的通知只会提醒一次。应用图标会显示有多少条待办需要你处理。

## 通知上的按钮

每条通知都有用于下一步操作的按钮。在手机应用中：

- 新待办：**执行**、**稍后处理**、**标记为已完成**。
- 草稿已准备好：**打开草稿**、**稍后处理**、**标记为已完成**。
- 结果已准备好：**打开**、**标记为已完成**、**稍后处理**。
- 问题、卡住的事项或登录请求：**回答**、**打开**或**登录**，然后选择**稍后处理**或**标记为已完成**。
- 提醒：**标记为已完成**、**稍后处理**、**打开**。
- 早间摘要：点击通知即可打开。

浏览器和 Telegram 通知上会显示其中两个按钮。Fleet 问题仍会显示**回答一次**和**拒绝**。

不会通过通知发送、付款或提交任何内容。草稿总是先打开，让你检查后再发送。点击**打开草稿**会在待办列表中打开这条待办，并显示完整草稿。**执行**只会开始处理新待办。

在手机应用中，点击**稍后处理**或**标记为已完成**前，需要先解锁。在浏览器中，这些按钮会打开控制面板并执行操作，同时提供“撤销”。稍后处理会让待办在两小时后重新出现；提醒则会在第二天早上重新出现。

邮件中有“打开”链接（等待处理的事项还会有“稍后处理”链接）。这些链接只会打开控制面板。

点击通知，或点击邮件、Telegram 中的“打开”，会在待办列表中高亮显示这条待办，无论它现在位于哪个视图：**刚刚完成**、**已完成**、**稍后回来**或其他视图。通知不会打开聊天。如果页面还没更新，它会在同步后定位到这条待办。

## 早间摘要

工作日会在你设定的**早间摘要**时间发送；如果没有内容，就不会发送。如果这个时间早于**推迟的待办会在此时间返回**，摘要会等到该时间后5分钟再发送，确保包含当天早上返回的待办。点击**预览**可以查看摘要，但不会发送。默认通过推送和邮件发送，内容简短，方便快速浏览：

- 开头会问候你并概括当天的重要事项，例如“早上好，Sam，有2条回复已准备好发送”，如果只有一条待办，则会显示“早上好，Sam，请确认后发送：发送订单表”。只有有草稿或结果待你批准的待办才算准备好；需要先等你回复的待办不算；
- 列出问候语中提到的待办，每条都带有“打开”链接，并显示今天截止的事项；如果没有，则最多列出3件待办；
- 列出最多5条由你自己添加、正在等你处理的待办，无论问候语中统计了多少条；
- 显示还有多少条待办可以稍后处理，以及按你的处理速度大约需要多久，例如“还有12条可以稍后处理，大约需要5分钟处理完”。等待你回复的待办不计入所需时间。今天截止但已推迟到晚些时候的待办，以及 The Machine 仍在处理的待办，要等到它们开始等待你处理时才会计入。此处的数量与待办列表中等待处理的待办数量一致；
- 用一行显示你的会议。

点击“打开”会在待办列表中高亮显示对应待办，即使它已完成或已推迟也一样。承诺会打开对应待办；如果还没有对应待办，则会打开承诺自己的页面。

推送中的内容相同，但没有链接。点击推送，或点击邮件末尾的链接，即可在**待办**中重新查看这份摘要。

## 晚间摘要

工作日会在**工作时间**中设定的时间发送，默认比**直到**早15分钟，通过上方对应行中选择的方式发送。只有你当天使用过控制面板，或在控制面板、Telegram、聊天或语音中处理过待办，才会收到摘要。当天既没有完成待办，也没有参加会议，则不会收到摘要。

摘要会先用数量概括当天情况，例如“晚上好，Sam，今天完成了4条待办”，然后分为**工作**和**个人**两部分。没有内容的部分不会显示。每部分包含：

- **今日已完成**：最多列出3条由你或你的 Machine 完成的待办，之后显示“另有12条”，并列出当天的会议，例如“另有3场会议：定价会议和其他2场”；
- **明天的待办**（周五则显示下一个工作日）：首先列出会议和截止事项。

末尾会显示还有多少条待办需要你处理。点击推送，或点击邮件末尾的链接，即可再次查看摘要，并使用**复制工作**和**复制个人**。若要停止接收，请关闭对应行。

## 隐私

推送会从你的 Machine 直接发送到设备，并针对该设备加密。邮件会经过 The Machine 的邮件服务器和你的邮件服务商。如果[谨慎](security-levels.md)设置会在通知中隐藏待办文本，邮件中也只会显示数量。若要避免某类通知通过邮件发送，请关闭对应类别的**邮件**。

在**此设备**中开启设备推送，或查看[安装应用](phone-app.md)。[手机应用](mobile-app.md)会先通过 Apple 或 Google 获取一条纯文本通知，然后向你的 Machine 请求待办标题和下一步操作。
