想减少通知，或换一种通知方式？点击“设置”>“通知”，选择每类通知的接收方式：

- **新增待办**：只通知不能等待的事，例如今天截止或标记为紧急的待办。
- **结果和问题**：准备发送的回复、任务需要登录，或 Fleet 提出的问题。
- **提醒**：稍后处理的待办，以及等待回复后重新提醒你的待办。
- **早间摘要**：当天事项的简短摘要。详见下文。
- **晚间摘要**：当天完成的事项，以及明天待处理的事项。详见下文。

每类通知都可以选择 **推送**（手机或电脑上的应用）、设置好后通过 **Telegram** 接收，以及在托管的 Machine 或 The Machine Network 上的 Machine 通过 **邮件** 接收。默认全部开启，但 Telegram 上的摘要除外。

同一标签页中还可以设置 **工作时间**：工作日、可发送通知的时间、稍后处理的待办返回的时间、摘要发送时间和时区。详见[工作时间](work-hours.md)。

## 只通知不能等待的事

以下情况才会发送推送、Telegram 提醒或邮件：

- 待办今天截止，或标记为紧急；
- 有人等待的回复已起草完成，可以发送；
- 任务需要你登录；
- 稍后处理的待办在你设定的时间返回。

其他内容都会安静地出现在控制面板上（在 Telegram 中也不会发出提示音），等待早间摘要。休息日只会提醒紧急事项或今天截止的待办。每天最多发送8条推送。如果你连续3天没有打开控制面板，就只会收到早间摘要，直到你回来。

## 通知发送时间

系统会判断你是否正在使用控制面板，而不只是看它有没有打开：

- 正在使用（页面在前台，并且你在过去10分钟内点击、输入或滚动过）：不会发出提示音。Telegram 通知会静默送达。仅打开或重新加载页面不算正在使用。
- 暂时离开（页面在后台、已关闭，或10分钟没有操作）：你离开一分钟后会发送推送，除非你回来并看到了它。
- 15分钟后仍未查看，且事情不能等待：会为该事项发送一封邮件，每小时最多一封。已处理的事项不会包含在内，每条待办只会出现一次，内容以当前状态为准。大多数时候，你只会收到早间摘要邮件。
- 队友分配给你一条待办，而你的 Machine 无法通过手机或 Telegram 联系你：如果15分钟后仍未查看，会发送一封包含标题和链接的邮件。关闭 **结果和问题** 的 **邮件** 通知即可停用此类邮件。
- 在工作时间以外：不会发送通知。相关内容会出现在早间摘要中。
- 休息日新增的工作待办会等到下一个工作日的摘要发送时间再通知你。待办会显示通知时间，例如“通知：11月2日周一·08:30”。

进度变化和编辑不会触发通知。你尚未查看的待办有新结果时，内容会更新，但不会再次通知。短时间内有多条通知时，只会提醒一次。应用图标会显示需要你处理的待办数量。

## 通知上的按钮

每条通知都提供下一步操作按钮。在手机应用中：

- 新待办：**执行**、**稍后处理**、**标记为已完成**。
- 草稿已准备好：**打开草稿**、**稍后处理**、**标记为已完成**。
- 结果已准备好：**打开**、**标记为已完成**、**稍后处理**。
- 需要你回复、遇到阻碍或需要登录：**回复**、**打开**或**登录**，然后可以选择**稍后处理**和**标记为已完成**。
- 提醒：**标记为已完成**、**稍后处理**、**打开**。
- 早间摘要：点击即可打开。

浏览器和 Telegram 中会显示其中两个按钮。Fleet 问题会保留**回复**和**拒绝**按钮。

不会通过通知发送、付款或提交任何内容。草稿总会先打开，让你在发送前查看。点击**打开草稿**会在待办列表中打开该待办，并完整显示草稿。点击**执行**只会开始处理新待办。

在手机应用中，点击**稍后处理**或**标记为已完成**前需要先解锁。在浏览器中，这些操作会打开控制面板，完成操作后还会显示“撤销”。稍后处理后，待办会在两小时后返回；如果是提醒，则会在次日早晨返回。

邮件中有**打开**链接（等待处理的事项还会有**稍后处理**链接）。这些链接只会打开控制面板。

点击通知，或点击邮件或 Telegram 中的**打开**，会在待办列表中高亮显示该待办，无论它当前位于哪个视图：**刚刚完成**、**已完成**、**稍后回来**或其他视图。它不会打开聊天。如果页面尚未更新，页面更新后会自动定位到该待办。

## 早间摘要

工作日会在你设定的 **早间摘要** 时间发送；如果没有内容，则不会发送。如果早间摘要时间早于 **推迟的待办会在此时间返回**，则会等到该时间5分钟后发送，确保当天早晨返回的待办也包含在内。点击 **预览** 可查看摘要，但不会发送。默认通过推送和邮件发送，内容简短，方便快速浏览：

- 开头问候并概述当天重点，例如“早上好，Sam，有2条回复准备发送”，或只有一条待办时显示“早上好，Sam，请确认：发送订单表”。只有有草稿或结果需要你审批的待办才算准备就绪；需要你先回复的待办不算；
- 问候中提到的待办，每条都附有**打开**链接，并列出今天截止的事项；如果没有，则最多显示三件待办；
- 最多列出五条由你自己添加、正在等待你处理的待办，无论问候中提到了哪些事项；
- 显示还有多少件事可以稍后处理，以及按你的速度大约需要多久，例如“还有12件事可以稍后处理，约5分钟即可清完”。等待你回复的待办不计入所需时间；今天截止但已推迟到稍后处理的待办，以及 The Machine 仍在处理的待办，在开始等待你处理前也不会计入。数量与待办列表中等待处理的待办数量一致。
- 用一行显示你的会议。

点击**打开**会在待办列表中高亮显示该待办，即使它已完成或已推迟也一样。承诺会打开对应待办；如果还没有待办，则会打开承诺自己的页面。

推送内容相同，但不含链接。点击推送，或点击邮件末尾的链接，即可在 **待办** 中再次查看摘要。

## 晚间摘要

工作日会在 **工作时间** 中设定的时间发送，默认比 **直到** 提前15分钟，并通过上方对应一行中选择的方式发送。只有当天你在场时才会发送：你使用过控制面板，或在控制面板、Telegram、聊天或语音中处理过待办。当天既没有完成待办，也没有参加会议，则不会收到摘要。

摘要开头会用数量概括当天情况，例如“晚上好，Sam，今天完成了4条待办”，接着分为 **工作** 和 **个人** 两部分。没有内容的部分会省略。关于你的 Machine 本身的提醒不会出现在这两部分中。每部分包含：

- **今日已完成**：最多列出你或你的 Machine 完成的三条待办，之后显示“另有12项”，并列出当天的会议，例如“另有3场会议：定价电话会议和另外2场”；
- **明天的待办**（周五则显示下一个工作日）：接下来的会议和即将截止的事项。

摘要末尾会显示仍需你处理的待办数量。点击推送，或点击邮件末尾的链接，即可再次查看摘要，并使用 **复制工作** 和 **复制个人**。要停止接收摘要，请关闭对应一行。

## 隐私

推送会由你的 Machine 直接发送到设备，并针对该设备加密。邮件会经过 The Machine 的邮件服务器和你的邮件服务商。当[谨慎](security-levels.md)设置会在通知中隐藏待办内容时，邮件中只会显示数量。关闭某类通知的 **邮件**，即可阻止这类内容通过邮件发送。

在 **此设备** 中开启设备推送，或查看[安装应用](phone-app.md)。[手机应用](mobile-app.md)会先通过 Apple 或 Google 接收一条不含敏感内容的提示，然后向你的 Machine 请求标题和下一步操作。
