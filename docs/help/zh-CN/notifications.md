想减少通知，或更改通知方式？前往**设置**>**通知**，选择每类通知的送达方式：

- **新增待办**：只提醒不能等的事项，例如今天截止或标记为紧急的待办。
- **结果和问题**：有回复可以发送、任务需要登录，或 Fleet 有问题时提醒你。
- **提醒**：稍后处理的待办，以及你正在等待回复的事项重新出现时提醒你。
- **早间摘要**：为你汇总当天的简短摘要。详见下文。
- **晚间摘要**：汇总今天已完成的事项和明天待办的事项。详见下文。

每类通知都可以选择通过**推送**（手机或电脑上的应用）、设置好后的**Telegram**，以及托管在云端的 Machine 或 The Machine Network 上的 Machine 所用的**邮件**送达。默认全部开启，但 Telegram 的摘要除外。

同一标签页中还有你的**工作时间**设置：工作日、允许发送通知的时间、稍后处理的待办返回时间、摘要发送时间和时区。详见[工作时间](work-hours.md)。

## 只提醒不能等的事

只有以下情况才会发送推送、Telegram 提醒或邮件：

- 待办今天截止，或标记为紧急；
- 有人正在等一条已起草、可以发送的回复；
- 有任务需要你登录；
- 到了你设定的时间，稍后处理的待办重新出现。

其他内容会安静地显示在控制面板上（在 Telegram 中也不会发出提示音），等到早间摘要再提醒你。休息日只会提醒紧急事项或今天截止的待办。每天最多发送8条推送。如果你连续3天没有打开控制面板，在你回来之前，只会收到早间摘要。

## 通知发送时间

系统会检查你是否真的在使用控制面板，而不只是看页面有没有打开：

- 正在使用（页面在前台，且你在最近10分钟内点击、输入或滚动过）：不会有提示音。Telegram 通知会静默送达。仅打开或重新加载页面不算使用。
- 暂时离开（页面在后台、已关闭，或你有10分钟没有操作）：离开1分钟后会发送推送，除非你已回来并查看过。
- 15分钟后仍未查看，且事情不能等：会为此发送一封邮件，每小时最多一封。已处理的事项不会包含在内，每个待办只会出现一次，并显示最新状态。大多数时候，你只会收到早间摘要邮件。
- 队友交给你一个待办，而你的 Machine 没有可联系你的手机或 Telegram：如果15分钟后你仍未查看，会收到一封包含待办标题和链接的邮件。关闭**结果和问题**的**邮件**即可停用此通知。
- 不在工作时间内：不会发送通知，内容会放进早间摘要。
- 休息日新增的工作待办会等到下一个工作日的摘要发送时间。待办会显示预计送达时间，例如“通知：11月2日（周一）·08:30”。

进度更新和编辑不会触发通知。你还没查看的待办有新结果时，系统会更新原通知，不会再发一条。短时间内连续出现的通知只会提醒一次。应用图标会显示有多少待办需要你处理。

## 通知上的按钮

每条通知都提供可进行下一步操作的按钮。在手机应用中：

- 新待办：执行、稍后处理、标记为已完成。
- 草稿已备好：打开草稿、稍后处理、标记为已完成。
- 结果已备好：打开、标记为已完成、稍后处理。
- 需要你回复、任务卡住或需要登录：回答、打开或登录，然后选择稍后处理或标记为已完成。
- 提醒：标记为已完成、稍后处理、打开。
- 早间摘要：点击即可打开。

浏览器和 Telegram 通知会显示其中两个按钮。Fleet 问题仍会显示“回答一次”和“拒绝”。

通知不会发送、付款或提交任何内容。草稿总会先打开，让你先检查再发送。点击“打开草稿”会在待办列表中打开该待办，并完整显示草稿。只有新待办的“执行”会开始处理任务。

在手机应用中，选择“稍后处理”或“标记为已完成”前，需要先解锁。在浏览器中，这些操作会打开控制面板，完成操作后显示“撤销”。稍后处理会让待办在两小时后重新出现；如果是提醒，则会在第二天早上重新出现。

邮件中有“打开”链接（等待处理的事项也有“稍后处理”链接）。这些链接只会打开控制面板。

点击通知，或点击邮件或 Telegram 中的“打开”，会在待办列表中显示该待办并突出显示，无论它现在位于哪个视图：**刚刚完成**、**已完成**、**稍后回来**或其他视图。通知不会打开聊天。如果页面尚未更新，页面更新后会自动跟进该待办。

## 早间摘要

工作日会在你设定的**早间摘要**时间发送；如果没有内容，则不会发送。如果发送时间早于**推迟的待办会在此时间返回**，摘要会等到该时间后5分钟再发送，以便包含当天早上重新出现的待办。点击**预览**即可查看摘要，不会实际发送。默认通过推送和邮件发送，内容简短，方便快速浏览：

- 开头会问候你并概括当天的重要事项，例如“早上好，Sam，有2条回复可以发送”，或者只有一个待办时显示“早上好，Sam，等待你确认：发送订单表格”。只有有草稿或结果需要你批准的待办才算已备好；需要你先回复的待办不算；
- 列出问候语中提到的待办，每项附有“打开”链接，并列出今天截止的事项；否则最多列出三件要做的事；
- 列出你自己添加、仍需你处理的待办，最多五项，无论问候语中统计了多少项；
- 显示还有多少项可以稍后处理，以及按你的速度处理这些事项需要多长时间，例如“还有12项可以稍后处理，约需5分钟处理完”。等待你回复的待办不计入所需时间。今天截止但推迟到稍后处理的待办，以及 The Machine 仍在处理的待办，只有在它们开始等待你处理后才会计入。显示的数量与你的待办列表中等待处理的待办数量一致。
- 用一行列出你的会议。

点击“打开”会在待办列表中打开并突出显示该待办，即使它已完成或已推迟处理。承诺会打开对应的待办；如果还没有待办，则会打开承诺自己的页面。

推送会显示相同内容，但不包含链接。点击推送，或点击邮件末尾的链接，即可在**待办**中再次查看这份摘要。

## 晚间摘要

工作日会在你设定的时间发送一次，默认在**工作时间**中的**直到**时间前15分钟，通过上方该行中选择的方式发送。只有当天你有使用控制面板，或在控制面板、Telegram、聊天或语音中对待办做出选择，才会发送。如果当天没有完成待办或参加会议，则不会发送。

摘要会先统计当天的情况，例如“晚上好，Sam，今天完成了4个待办”，然后分为**工作**和**个人**两部分。没有内容的部分不会显示。每部分包含：

- **今日已完成**：最多列出你或你的 Machine 完成的3个待办，之后显示“另有12项”，并列出当天的会议，例如“另有3场会议：定价电话会议及另外2场”；
- **明天的待办**（周五则显示下一个工作日）：列出最先开始的会议和截止事项。

最后会显示还有多少待办需要你处理。点击推送，或点击邮件末尾的链接，即可再次查看摘要，并使用**复制工作**和**复制个人**。要停止接收摘要，请关闭对应行。

## 隐私

推送会由你的 Machine 直接发送到设备，并针对该设备加密。邮件会经过 The Machine 的邮件服务器和你的邮件服务提供商。如果[谨慎](security-levels.md)设置隐藏通知中的待办文本，邮件中只会显示数量。关闭某类通知的**邮件**，即可停止通过邮件接收这类通知。

在**此设备**中开启设备推送，或查看[安装应用](phone-app.md)。[手机应用](mobile-app.md)会先通过 Apple 或 Google 发送一条普通通知，然后向你的 Machine 请求标题和下一步操作。
