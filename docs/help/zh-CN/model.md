**设置**中的**模型**会显示哪个 AI 模型负责**后台任务**，以及你的登录方式，例如使用 ChatGPT 登录。

个人 ChatGPT 或 Claude 方案可能默认会使用你的聊天内容进行训练。点击**关闭使用你的数据进行训练**，即可前往服务商的设置关闭此功能；点击**已完成**可隐藏这条提示。

## 聊天的模型和思考强度

在**聊天**中，为待办聊天和帮助选择模型及思考强度。你只能看到当前登录方式支持的模型和思考等级。

提高思考强度有助于更好地回答难题，但速度更慢，也会消耗更多方案额度。**超高思考强度**会为最难的问题调动辅助模型，额度消耗也最多。新建 Machine 时，默认使用**思考等级：低**，效果不错，消耗的方案额度也少得多。更改会从下一条消息开始生效。

若只想更改某个聊天的设置，请点击消息输入框下方的模型或思考等级。再次选择“设置”即可恢复为跟随设置。

检查、新消息检查和提前准备的草稿使用各自的模型。

## 限额

如果你的方案有使用限额，例如 ChatGPT 或 Claude 方案的 5 小时限额和每周限额，这里会显示已用额度，以及各项限额的重置时间。查看用量不会消耗方案额度。

## 为你自己的聊天留出空间

后台任务会为你自己的聊天留出空间。达到 5 小时限额的约 65% 时，后台任务会暂停。新消息检查会持续到每周限额的约 90%；其他任务每天约使用每周额度的七分之一。没有限额的登录方式（例如 API 密钥）不会暂停。

后台任务不会使用 GPT-6 Astra，而会改用 GPT-6.2 Sol；如果尚未配置 GPT-6.2 Sol，则会使用 GPT-6.1 Sol。

## 达到限额时

仪表板顶部会显示已达到哪项限额，以及限额重置时间。任务会暂停，之后从中断处继续，不会丢失任何内容。如果你的 ChatGPT 方案支持重置，点击**使用重置**即可重新开始计算限额。否则，点击**在ChatGPT中查看重置记录**即可打开 ChatGPT 页面。

## 使用备用模型

如果你的 Machine 在其他方案或服务商处配置了备用模型，达到限额时备用模型会接手，任务不会暂停。仪表板顶部会显示“已达到 ChatGPT 限额，正在使用备用模型。”如果备用模型停止工作，任务就会再次暂停。

## 更改主模型

主模型供 The Machine 的其他功能使用。如果你使用托管版 Machine，可在设置页面的“你的 AI”下更改主模型。如果你在自己的电脑上运行，请参阅 [ChatGPT](chatgpt.md)、[Mistral](mistral.md) 和[模型指南](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)。
