**设置**中的**模型**会显示哪个 AI 模型负责你的**后台任务**，以及你的登录方式，例如通过 ChatGPT 登录。

使用 ChatGPT 登录的托管版 Machine，主模型是 GPT-6.2 Sol：价格相同，回答速度比 GPT-6.1 Sol 更快。

个人 ChatGPT 或 Claude 方案默认可能会使用你的聊天内容进行训练：**关闭使用你的数据进行训练**会打开服务提供方的相关设置，**已完成**会隐藏这一行。

## 聊天模型和思考强度

在**聊天**中，为待办聊天和帮助选择模型和思考强度。你只能看到登录方式支持的模型和强度。

思考越多，越能回答复杂问题，但速度更慢，也会消耗更多方案限额。**超高思考强度**会为最难的问题启用辅助模型，消耗的限额也最多。新的 Machine 默认使用**思考等级：低**：效果不错，消耗的方案限额少得多。更改会从下一条消息开始生效。

只想为某个聊天更改设置时，点击消息框下方的模型或思考强度。再次选择“设置”选项即可沿用设置中的选择。

检查、个人资料和提前准备的草稿使用各自的模型。

## 限额

如果你的方案有使用限额，例如 ChatGPT 或 Claude 方案的 5 小时和每周限额，这里会显示已用额度以及各项限额的重置时间。查看限额不会消耗方案额度。

## 为自己的聊天留出空间

后台任务会为自己的聊天留出空间。当 5 小时限额使用到约 65% 时，后台任务会暂停。检查新消息会持续到每周限额使用到约 90%；其他工作每天最多使用约七分之一的每周限额。没有使用限额的登录方式（例如 API 密钥）不会暂停。

后台任务不会在 GPT-6 Astra 上运行，而会改用 GPT-6.2 Sol；如果尚未设置 GPT-6.2 Sol，则会使用 GPT-6.1 Sol。

## 达到限额时

仪表板顶部会显示达到的限额以及重置时间。工作会暂停，之后从中断处继续，不会丢失任何内容。如果你的 ChatGPT 方案支持重置，**使用重置**会重新开始计算限额。否则，**在ChatGPT中查看重置记录**会打开 ChatGPT 页面。

## 使用备用模型

如果你的 Machine 在其他方案或服务提供方下设置了备用模型，达到限额时就会切换到备用模型，工作不会暂停。仪表板顶部会显示“已达到 ChatGPT 限额，正在使用备用模型”。如果备用模型停止工作，暂停就会恢复。

## 更改主模型

主模型供 The Machine 的其他部分使用。使用托管版 Machine 时，可在设置页面的“你的 AI”下更改主模型。使用自己的电脑时，请参阅 [ChatGPT](chatgpt.md)、[Mistral](mistral.md) 和[模型指南](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)。
