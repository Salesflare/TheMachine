**设置**中的**模型**会显示哪个 AI 模型负责**后台任务**，以及你的登录方式，例如通过 ChatGPT 登录。

使用 ChatGPT 登录的托管版 Machine，主模型是 GPT-6.2 Sol：价格相同，回答速度比 GPT-6.1 Sol 更快。

个人 ChatGPT 或 Claude 套餐默认可能会使用你的聊天内容训练模型。**关闭使用你的数据进行训练**会打开服务提供商的相关设置，**已完成**会隐藏这一行。

## 聊天使用的模型和思考强度

在**聊天**中，为待办聊天和帮助选择模型和思考强度。你只能看到当前登录方式支持的模型和思考等级。

思考得越多，越能回答复杂问题，但速度较慢，也会消耗更多套餐用量。**超高思考强度**会为最难的问题启用辅助模型，用量也最多。新建的 Machine 默认使用**思考等级：低**，效果不错，也能大幅节省套餐用量。更改会从下一条消息开始生效。

若只想为某个聊天更改设置，请点按消息框下方的模型或思考等级。再次选择**设置**选项，即可改为遵循设置中的选项。

检查、你的个人资料和提前准备的草稿会使用各自的模型。

## 用量限制

如果你的套餐有用量限制，例如 ChatGPT 或 Claude 套餐的 5 小时和每周限制，页面会显示已使用的用量，以及各项限制何时重置。查看用量不会消耗套餐额度。

## 为你自己的聊天留出空间

后台任务会为你自己的聊天留出空间。在 5 小时用量达到约 65% 时，后台任务会暂停。新消息检查会持续到每周用量达到约 90%；其他任务每天约占一周用量的七分之一。使用没有用量限制的登录方式（例如 API 密钥）时，后台任务不会暂停。

后台任务不会使用 GPT-6 Astra。使用 ChatGPT 登录时，后台任务目前会使用 GPT-6.1 Sol，即使你的主模型是 GPT-6.2 Sol 也是如此：该登录方式上的 GPT-6.2 目前还无法复用缓存的指令，因此会消耗更多套餐用量。你的聊天仍会使用你选择的模型。

## 达到用量限制时

控制面板顶部会显示已达到的限制以及重置时间。任务会等待限制重置，然后从中断处继续。不会丢失任何内容。如果你的 ChatGPT 套餐支持重置，**使用重置**即可重新开始计算用量限制。否则，**在ChatGPT中查看重置记录**会打开 ChatGPT 的相关页面。

## 使用备用模型

如果你的 Machine 在其他套餐或服务提供商上配置了备用模型，达到用量限制时，备用模型会接手，任务不会等待。控制面板顶部会显示“已达到 ChatGPT 用量限制，正在使用备用模型。”如果备用模型停止工作，任务就会再次暂停。

## 更改主模型

主模型是 The Machine 其他部分使用的模型。托管版 Machine 可在设置页面的“你的 AI”下更改主模型。在自己的电脑上使用时，请参阅 [ChatGPT](chatgpt.md)、[Mistral](mistral.md) 和[模型指南](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)。
