**设置**中的**模型**会显示哪个 AI 模型负责**后台任务**，以及你的登录方式，例如通过 ChatGPT 登录。

个人 ChatGPT 或 Claude 方案默认可能会使用你的聊天内容进行训练。**关闭使用你的数据进行训练**会打开服务提供商的相关设置，**已完成**则会隐藏这一行。

## 聊天模型和思考强度

在**聊天**下，为待办聊天和帮助选择模型和思考等级。你只能看到当前登录方式支持的模型和等级。

思考强度越高，越擅长回答难题，但速度更慢，也会消耗更多方案额度。**超高思考强度**会为最难的问题调用辅助模型，额度消耗也最多。新建的 The Machine 默认使用**思考等级：低**，效果不错，也能大幅节省方案额度。更改会从下一条消息开始生效。

若只想为单个聊天更改设置，点击消息框下方的模型或思考等级。再次选择“设置”选项即可跟随设置中的选择。

检查、你的个人资料和提前准备的草稿各自使用独立的模型。

## 额度

如果你的方案有使用额度限制，例如 ChatGPT 或 Claude 方案的 5 小时和每周额度，这里会显示已使用的额度，以及各项额度的重置时间。查看不会消耗方案额度。

## 为你自己的聊天留出空间

后台任务会为你自己的聊天留出空间。达到 5 小时额度的约 65% 时，后台任务会暂停。检查新消息会持续到每周额度的约 90%；其他任务每天最多使用一周额度的约七分之一。没有额度限制的登录方式，例如 API 密钥，不会暂停。

后台任务不会使用 GPT-6 Astra，而会改用 GPT-6.1 Sol。

## 达到额度限制时

控制面板顶部会显示已达到的额度限制及重置时间。任务会等待，之后从中断处继续，不会丢失任何内容。如果你的 ChatGPT 方案支持重置额度，**使用重置**会重新开始计算额度。否则，**在ChatGPT中查看重置记录**会打开 ChatGPT 页面。

## 使用备用模型

如果你的 The Machine 在其他方案或服务提供商处设置了备用模型，达到额度限制时，备用模型会接手，任务无需等待。控制面板顶部会显示“已达到 ChatGPT 额度限制，正在使用备用模型”。如果备用模型停止工作，任务就会再次暂停。

## 更改主模型

主模型供 The Machine 的其他功能使用。对于托管版 The Machine，请在设置页面的“你的 AI”下更改主模型。在自己的电脑上使用时，请参阅 [ChatGPT](chatgpt.md)、[Mistral](mistral.md) 和[模型指南](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)。
