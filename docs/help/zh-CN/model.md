**设置**中的**模型**会显示哪个 AI 模型在执行**后台任务**，以及你的登录方式，例如通过 ChatGPT 登录。

在使用 ChatGPT 登录的托管版 Machine 上，主模型是 GPT-6.2 Sol：价格相同，但回答速度比 GPT-6.1 Sol 更快。

个人 ChatGPT 或 Claude 套餐默认可能会使用你的聊天内容进行训练。**关闭使用你的数据进行训练**会打开服务提供商的相关设置，**已完成**会隐藏这条提示。

## 聊天使用的模型和思考强度

在**聊天**中，为待办聊天和帮助选择模型和思考等级。这里只会显示你的登录方式支持的模型和等级。

思考得越多，越能回答复杂问题，但速度更慢，也会消耗更多套餐额度。**超高思考强度**会调用助手来处理最难的问题，消耗的额度也最多。新 Machine 默认使用**思考等级：低**，效果不错，而且套餐额度消耗少得多。更改会从下一条消息开始生效。

如果只想更改某个聊天的设置，点按消息框下方的模型或思考等级。再次选择“设置”选项即可跟随设置中的选择。

检查、个人资料和提前准备的草稿会使用各自的模型。

## 使用限额

如果你的套餐有使用限额，例如 ChatGPT 或 Claude 套餐的 5 小时和每周限额，这里会显示已用额度，以及各项限额的重置时间。查看不会消耗套餐额度。

## 为自己的聊天留出空间

后台任务会为自己的聊天留出空间。达到 5 小时限额的约 65% 时，后台任务会暂停。检查新消息会继续进行，直到达到每周限额的约 90%；其他任务每天最多使用每周额度的约七分之一。没有使用限额的登录方式（例如 API 密钥）不会暂停。

后台任务不会使用 GPT-6 Astra。使用 ChatGPT 登录时，后台任务目前会使用 GPT-6.1 Sol，即使主模型是 GPT-6.2 Sol 也一样：该登录方式下，6.2 目前还不能复用缓存的指令，因此会消耗更多套餐额度。聊天仍会使用你选择的模型。

## 达到限额前

如果你的 ChatGPT 套餐还有重置次数，后台任务开始减速时，“待办”中会显示一条简短提示：此时已达到 5 小时限额的约 65%，或每周限额的约 90%。提示会显示已用额度和剩余重置次数。确认后，选择**使用重置**即可重新开始计算限额。点按 × 可隐藏这条提示，直到限额重置。如果没有剩余重置次数，就不会显示新提示。

## 达到限额时

控制面板顶部会显示已达到的限额以及重置时间。任务会暂停，之后从中断处继续，不会丢失任何内容。如果你的 ChatGPT 套餐有重置次数，选择**使用重置**即可重新开始计算限额。否则，选择**在ChatGPT中查看重置记录**即可打开 ChatGPT 页面。

## 使用备用模型

如果你的 Machine 在其他套餐或服务提供商处设置了备用模型，达到限额时就会切换到备用模型，不会暂停任务。控制面板顶部会显示“已达到 ChatGPT 限额，正在使用备用模型。”如果备用模型停止工作，任务就会再次暂停。

## 更改主模型

主模型供 The Machine 的其他部分使用。在托管版 Machine 上，可在设置页面的“你的 AI”下更改主模型。在自己的电脑上，请参阅 [ChatGPT](chatgpt.md)、[Mistral](mistral.md) 和[模型指南](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)。
