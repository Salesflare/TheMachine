## 日历显示的内容

从今天开始的日程，包括：

- 已连接日历中的会议，
- 当天截止的待办，以及在推迟后重新出现的待办，
- 你交接出去的工作进度回报，
- 有日期的承诺，
- 来自预订和票务邮件的[行程和活动](calendar.md#trips-and-events)。

同一场会议出现在两个日历中时，只显示一次。别人与你共享的日历会显示他们的活动，颜色较淡，并标注对方的名字；这些活动不会生成待办。全天和多日活动会在涵盖的每一天显示为全天活动。行程会在日程中排在每一天的首位，在周视图和月视图中则显示为横跨多天的条带，例如“里斯本之旅”。

一起制定的计划算作一项承诺，会标注“与”和对方的名字。如果承诺是当天要和某人讨论会议相关的事，它会显示在该会议所在的行上。

**已逾期**的待办排在最前面。有关联待办的会议会显示待办状态：**准备就绪**、**正在准备**或**待办**。看起来已经完成的待办（你已经回复，或运行结果显示已完成）不会显示为**截止**。

## 日程、周视图或月视图

- **日程**会按天列出活动。向下滚动可查看之后的日期，向上滚动或点按**显示更早的日期**可查看更早的日期。日历连接后，可以回溯一周，顶部会标明从哪一天开始。载入[历史记录](history.md)后，可以回溯约一年。
- **周**会显示从周一到周日的网格。手机上会显示三天。
- **月**会显示整个月。电脑上每天最多显示三项活动；手机上会显示圆点，点按后可查看当天的活动。

点按顶部的**今天**、‹ 和 ›，即可切换周或月份。选择的视图会保存在这台设备上。

在周视图网格中，同一时间的活动会并排显示，同时确保每项活动都清晰可读。其余活动会显示为**+N**，点按后会打开当天的日程。

## 打开内容

点按一行即可打开对应的待办聊天、承诺、行程、活动或会议。无法在此修改的会议（例如别人的会议或有受邀者的会议）会显示详情：时间、地点和参与者。Graph 中已有的人，以及会议关联的组织和项目，都会链接到各自的页面。点按它们下方的**在 Google Calendar 中打开**（或**在 Outlook 中打开**）即可在对应服务中打开。查看不会造成任何更改。

如果会议预订了会议室，会议室会显示在地点下方，不会显示为人物，也不会出现在 Graph 中。

会议链接会显示对应的服务名称，例如 Zoom、Google Meet 或 Teams；也可能显示为**视频通话**。打开会议即可加入。

## 行程和活动

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，你的 Machine 会将它添加到行程中。同一趟旅程的预订会放在同一个行程里，例如去程、酒店和返程。行程会显示为横跨多天的条带。打开行程即可按时间顺序查看每项预订的预订编号、座位和票务信息。

音乐会、比赛、节日活动或会议的门票会生成活动，每场活动单独列出，并显示地点、预订编号、座位和门票数量。同一活动的第二笔订单会归到同一项活动中。通过工作邮箱预订的活动会标记为工作活动，否则会标记为个人活动。

- 每一行都会标明预订来自哪里，例如**来自 Example Tickets**，点按后会打开对应邮件。
- 如果邮件生成了待办，例如支付门票费用，点按**打开待办事项**即可查看。
- 预订有更改时，对应行会更新；预订取消后，对应行会移除。所有预订都取消后，行程或活动也会移除。

The Machine 会读取航空公司、酒店、预订网站和票务商在确认邮件中填写的详情，不使用 AI。邮件中没有这些详情时，不会生成任何内容。你的 Machine 会保留[历史记录](history.md)所涵盖年份的预订邮件，载入历史记录后会在后台读取这些邮件。

## 会议笔记和文字记录

会议详情分为两部分。**笔记**是摘要，包括决定和待办事项。**文字记录**是逐字记录的会议内容。文字记录默认折叠显示，并标明时长；点按**显示**即可展开。

如果内容未能加载，系统会自动重试约半分钟。之后，请点按**重试**。

每部分都有各自的**添加备注**或**添加转录稿**选项，以及用于上传 Markdown 或文本文件的**上传文件**、**编辑**和**移除**选项（需点按两次）。添加到其中一部分的内容会保留在该部分中。对于可修改的会议，点按会议表单下方的**笔记**即可打开笔记。

连接 [Zoom](zoom.md) 或 [Google Meet](google-meet.md) 后，会议笔记会显示在“笔记”中，文字记录会显示在“文字记录”中，并标记为**来自Zoom**或**来自Google Meet**。这些内容不会替换你添加的内容；两者都有时，会同时显示。

会议自己的日历活动中也可能包含笔记，这些笔记会在会议开始后添加；也可能通过 Zoom 或 Gemini 邮件收到。会议结束后，The Machine 只会根据明确的后续行动生成待办。同一份笔记通过两种方式收到时，只会生成一个待办，来源会标明会议，例如：“来源：会议笔记”。

如果会议有文字记录但没有笔记，会显示**生成笔记**。The Machine 会根据文字记录生成笔记，包括简短摘要、决定和待办事项，并标明负责人。笔记使用会议所用的语言。

系统会显示**正在写笔记…**，即使关闭会议也会继续生成。较长的会议可能需要几分钟，并会使用你自己的模型。笔记会标注**由 The Machine 撰写**，不会替换你添加的笔记。

你也可以让 The Machine 添加笔记。在待办中提出要求，例如“把这份文字记录添加到今天的董事会会议中”。文字记录会添加到“文字记录”中，摘要会添加到“笔记”中。日历中有笔记或文字记录的会议会显示**笔记**或**文字记录**。

The Machine 会读取笔记和文字记录，了解会议的后续事项。这些事项会根据会议标记为工作或个人，只有会议属于团队时，后续事项才会发送给团队。

无论从哪里打开会议，都会显示相同的详情，例如从时间线、消息搜索结果或待办来源打开。会议详情底部的**原始邀请**会显示收到的邀请原文。

## 添加或更改活动

你可以在这里修改自己的 Google 日历。Outlook 和其他日历只能查看。点按**新活动**即可添加活动（手机上可点按顶部栏中的**+**）：选择日历、标题和时间。点按该日历中没有受邀者的活动即可修改，或点按**删除**（需点按两次）将其删除。

输入文字时，**地点**会推荐地点：先显示你以前使用过的地点和组织，再显示来自免费地图 [OpenStreetMap](https://www.openstreetmap.org) 的地址。系统只会发送你输入的文字来查找地点。你可以选择推荐地点，也可以保留自己输入的文字。

**邀请**可添加 Graph 中的人，也可以添加任意电子邮件地址。此选项只适用于你自己的日历。按钮上方会列出邀请对象，按钮也会显示人数，例如：**添加并邀请 2 人**。只有点按后 Google 才会发送邀请，不会提前发送。没有受邀者时，不会邀请任何人，也不会向任何人发送更新。

待办也可能提供更改建议，例如添加接送安排。系统会明确显示具体更改，只有点按**添加**、**保存**或**删除**后才会生效。

还没有会议？如果尚未连接日历，点按**连接日历**即可打开“连接”，并连接 [Google Calendar](google-calendar.md)、[Outlook Calendar](microsoft.md) 或[其他日历](other-calendars.md)。

## 与其他日历中的活动冲突

工作会议与个人日历中的活动时间重叠，或个人日历中的活动与工作会议重叠时，The Machine 会针对两项活动中较晚的一项创建一个待办。The Machine 可以起草一条简短消息来改期，也可以建议拒绝邀请。只有你批准后，消息才会发送。

全天、空闲和暂定活动不会计入冲突，每项冲突只会提醒一次。工作待办只会说明有冲突，因此团队看不到个人活动。只有你能看到与什么活动冲突。

## 为会议做好准备

与公司外部人员开会前，The Machine 会创建一个待办：**准备会议**。待办会提供简短的会前资料：

- **谁：**对方是谁，信息来自 Graph。
- **最近联系：**你们最近一次的交流。会议结束后，该消息会成为待办的来源。
- **待履行承诺：**你或对方仍需履行的承诺。
- **未解答问题：**仍未得到回答的问题。
- **需要决定或带上：**需要确定的事项或需要带上的物品。

资料会在工作日早上生成：如果会议在下午举行，就在会议当天生成；否则会在会议前一个工作日生成。资料只会使用你已有的 Machine 上的信息，仅供查看：读完后点按**已完成**。资料中需要跟进的承诺或问题会各自生成待办。

没有有用的历史记录时，不会生成待办。定期会议、内部会议、个人会议和已拒绝的会议都不会生成待办。会议改期后，原待办会保留，并更新为新的时间。已忽略的待办不会再次出现，会议取消后，对应待办会自动关闭。

会议详情中的**待办**下方会显示对应待办，点按一次即可打开它的聊天。
