## 显示内容

从今天开始的日程，包括：

- 已连接的日历中的会议，
- 截止日期在当天的待办，以及当天重新出现的已推迟待办，
- 你交接出去的工作的跟进，
- 有日期的承诺，
- 来自预订和票务邮件的[行程和活动](calendar.md#trips-and-events)。

同一场会议出现在两个日历中时，只显示一次。有人与你共享的日历会显示对方的活动，颜色较淡，并标注对方的名字。这些活动不会生成待办。全天活动和跨多天活动会在涉及的每一天都显示为全天活动。在日程视图中，行程会排在涉及的每一天的最前面；在周视图和月视图中，则会显示为横跨这些日期的一条色带，例如“里斯本之旅”。

一起制定的计划算作一个承诺，会标注“与”以及对方的名字。如果某个承诺与当天和同一个人的会议有关，就会显示在该会议的那一行。

**已逾期**的待办会排在最前面。会议有未完成的待办时，会显示其状态：**准备就绪**、**正在准备**或**待办**。看起来已经完成的待办（你已经回复过，或运行结果表明它已完成）不会显示为**截止**。

## 日程、周或月

- **日程**会列出每一天。向下滚动可查看之后的日期，向上滚动或点按**显示更早的日期**可查看之前的日期。它最多会显示到你连接日历前一周，并在顶部标明起始日期。载入[历史记录](history.md)后，日程会显示到大约一年前。
- **周**会以网格显示周一到周日。手机上会显示三天。
- **月**会显示整个月。电脑上每天最多显示三项；手机上会显示圆点，点按后可查看当天的安排。

点按顶部的**今天**、‹ 或 ›，可切换周或月份。所选视图会保存在当前设备上。

在周视图网格中，同一时间的活动会并排显示，同时保证文字清晰可读。其余活动会显示为**+N**，点按后会打开当天的日程。

## 打开内容

点按一行可打开对应的待办聊天、承诺、行程或活动，也可打开会议。无法在此更改的会议，例如别人的会议或有与会者的会议，会显示详细信息：时间、地点和参与者。The Machine 的 Graph 中已知的人，以及会议所属的组织和项目，都会链接到对应页面。点按下方的**在 Google Calendar 中打开**（或**在 Outlook 中打开**）可在相应日历中打开会议。查看不会造成任何更改。

会议中预订的会议室会显示在地点下方，不会显示为人物，也不会出现在 Graph 中。

会议链接会显示其服务名称，例如 Zoom、Google Meet 或 Teams；也可能显示为**视频通话**。打开会议即可加入。

## 行程和活动

航班、酒店、度假屋、火车、公交车、渡轮、租车、出租车或机场停车的预订邮件到达后，你的 Machine 会将其添加到行程中。同一趟旅程的预订会合并到一个行程中，邮件可以来自你的任何邮箱：去机场的火车、航班、租车、住宿和返程。只要预订日期有重叠，或前一项结束时后一项随即开始，就会合并到一起。

行程会以一条色带横跨涉及的日期。打开行程即可按时间顺序查看每项预订，以及对应的时间、地址、预订代码和座位。

音乐会、比赛、节日活动或会议的门票会生成活动，每场活动单独显示，并附上地点、预订代码、座位和门票数量。同一场活动的第二笔订单会合并到原活动中。通过工作邮箱预订的活动会标记为“工作”，否则标记为“个人”。行程期间的活动门票会添加到行程中。

对于尚未开始的行程，你的 Machine 会指出缺少的安排，例如**尚未预订住宿，共 2 晚**，或尚未预订从机场到酒店的交通。这些提示会以较浅的颜色显示，并标记为**没有预订**。完全没有住宿安排的行程不会提示住宿晚数。

- 每一项都会标明预订邮件的来源，例如**来自 Example Tickets**，点按后会打开该邮件。
- 如果邮件生成了待办，例如支付门票费用，点按**打开待办事项**即可查看。
- 预订变更后，对应内容会更新；预订取消后，对应内容会移除。所有预订都取消后，行程或活动也会移除。
- 别人的预订不会加入你的行程，例如同事转发给你的航班信息。

大多数确认邮件都包含你的 Machine 无需 AI 就能读取的详细信息。对于无法直接读取的邮件，例如转发的邮件或来自小型预订网站的邮件，你的[模型](model.md)会在后台分批读取，并在你接近用量上限时暂停。你的 Machine 会在载入[历史记录](history.md)后，于后台读取历史记录所涵盖年份中的预订邮件。

## 会议笔记和文字记录

会议详情分为两部分。**笔记**是摘要，包括决定和行动事项。**文字记录**是逐字记录的谈话内容。文字记录默认折叠，并显示时长；点按**显示**即可展开。

如果内容无法载入，系统会自动重试大约半分钟。之后请点按**重试**。

笔记和文字记录各自都有**添加备注**或**添加转录稿**、用于上传 Markdown 或文本文件的**上传文件**、**编辑**和**移除**（需点按两次）。一项内容只会保存在对应的位置。在可以更改的会议中，点按会议表单下方的**笔记**即可打开笔记。

连接了 [Zoom](zoom.md)、[Google Meet](google-meet.md) 或 [Granola](granola.md) 后，来自这些服务的笔记会显示在“笔记”中，文字记录会显示在“文字记录”中，并标注为**来自Zoom**、**来自Google Meet**或**来自 Granola**。它们不会替换你添加的内容；两种内容都有时，会同时显示。

会议笔记也可能来自会议自己的日历活动，在会议开始后添加，或通过 Zoom 或 Gemini 的邮件发送。会议结束后，The Machine 只会根据其中明确的后续行动创建待办。同一份笔记通过两种方式传来时，只会生成一个待办，来源标记为会议，例如“来源：会议笔记”。

有文字记录但没有笔记的会议会显示**生成笔记**。The Machine 会根据文字记录生成笔记，包括简短摘要、决定，以及注明负责人和会议所用语言的行动事项。

系统会显示**正在写笔记…**；即使关闭会议，也会继续生成。较长的会议需要几分钟，会使用你自己的模型。笔记会标注**由 The Machine 撰写**，且不会替换你添加的笔记。

你也可以让 The Machine 添加内容。在待办中提出要求即可，例如“把这份文字记录添加到今天的董事会会议中”。文字记录会添加到“文字记录”，摘要会添加到“笔记”。有这些内容的会议会在日历中显示**笔记**或**文字记录**。

The Machine 会读取笔记和文字记录，跟进会议后续事项。这些待办会像会议一样标记为工作或个人。只有会议属于团队事务时，相关待办才会发送给团队。

无论你在哪里找到会议，都可以打开并查看这些详情，例如时间线、消息搜索结果或待办的来源。底部的**原始邀请**会显示收到的邀请原文。

## 添加或更改活动

你可以在此更改自己的 Google 日历。Outlook 和其他日历只能查看。点按**新活动**可添加活动（手机上可点按顶部栏中的**+**）：选择日历，填写标题和时间。点按该日历中没有与会者的活动即可更改，也可以点按**删除**将其删除（需点按两次）。

输入时，**地点**会提供建议：先显示你以前用过的地点和所属组织，然后显示来自[OpenStreetMap](https://www.openstreetmap.org)（一个免费地图）的地址。系统只会发送你输入的文字来查找地点。选择一个建议，或保留自己输入的文字。

**邀请**可添加 Graph 中的人，也可添加任何电子邮箱地址。只有在自己的日历中才能使用此功能。按钮上方会列出受邀者，按钮也会显示人数，例如：**添加并邀请 2 人**。点按按钮后，Google 才会发送邀请。没有与会者时，不会邀请任何人，也不会发送更新。

待办也可能建议更改活动，例如添加接送安排。建议会明确显示具体更改内容，只有点按**添加**、**保存**或**删除**后才会生效。

还没有会议？如果尚未连接日历，点按**连接日历**会打开“连接”，然后连接 [Google Calendar](google-calendar.md)、[Outlook Calendar](microsoft.md) 或[其他日历](other-calendars.md)。

## 与其他日历中的安排冲突

工作会议与个人日历中的活动重叠，或个人活动与工作会议重叠时，The Machine 会针对较晚创建的那个安排生成一个待办。它可以草拟一条简短消息，请对方改期，也可以建议你拒绝邀请。经你批准前，不会发送任何内容。

全天、空闲和暂定活动不会计入冲突，每个冲突只会提示一次。工作待办只会说明存在冲突，因此团队不会看到个人活动。只有你能看到与之冲突的安排。

## 为会议做好准备

在与公司外部人员开会前，The Machine 会生成一个待办：**准备会议**。内容是一份简短的会议简报：

- **谁：**对方是谁，以及 Graph 中的相关信息；如果已知，还会附上对方的背景信息。
- **组织：**对方所在公司与会议相关的业务信息。
- **进展：**你们讨论、询问和提出过什么，以及目前的进展。会议结束后，这些消息会作为待办的来源。
- **未兑现的承诺：**你或对方仍需履行的承诺。
- **未解答的问题：**仍未得到答复的问题。
- **需要决定或准备的事项：**需要敲定或带上的内容，以及对方可能关心的事情。

待办会在工作日早上生成：如果会议在下午，就在会议当天生成；否则在会议前一个工作日生成。它只能查看，读完后点按**已完成**。其中需要处理的承诺或问题会各自生成待办。

它会使用你 Machine 中已有的信息。你第一次与某家公司的人开会时，The Machine 还会简要搜索对方姓名和公司，并在找到的信息旁显示链接。发送给搜索服务的只有对方的公开姓名、公司名称和公司网站，不会发送你的消息。搜索结果会重复使用 30 天。如果在“设置”的“安全”中关闭**查找工作联系人**，系统就不会搜索。

没有有用的历史记录时，不会生成待办。周期性会议、内部会议、个人会议和已拒绝的会议都不会生成待办。会议改期后，原来的待办会保留，并更新到新时间。忽略的待办不会再次出现，会议取消后，对应待办会自动关闭。

无论从哪里打开会议详情，都可以点按**待办**，直接进入会议对应的待办聊天。
