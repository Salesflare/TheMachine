## 显示内容

从今天起的每天，包含：

- 已连接日历中的会议，
- 当天截止的待办，以及当天重新出现的推迟处理的待办，
- 交接出去的工作的跟进，
- 有日期的承诺，
- [笔记](notes.md)，例如旅行计划。

同一场会议出现在两个日历中时，只显示一次。别人与你分享的日历会显示他们的活动，并以浅色显示，同时标注对方的名字。这些活动不会生成待办。全天和多日活动会在其涵盖的每一天显示为全天活动。旅行会在「日程」中排在每天的最前面，在「周」和「月」视图中则显示为横跨这些日期的一条色带，例如“里斯本之旅”。

共同制定的计划算作一项承诺，会标注“与”以及对方的名字。如果某项承诺是与某人在当天的会议有关，就会显示在该会议所在的行中。

**已逾期**的待办排在最前面。会议有尚未完成的待办时，会显示其状态：**准备就绪**、**正在准备**或**待办**。看起来已完成的待办（你已经回复，或运行结果显示它已完成）不会显示为**截止**。

## 日程、周或月

- **日程**会逐日列出活动。向下滚动可查看之后的日期，向上滚动或点击**显示更早的日期**可查看之前的日期。最多可查看到连接日历前一周的内容，顶部会标明起始日期。加载[历史记录](history.md)后，最多可以查看大约一年前的内容。
- **周**会显示周一到周日的网格。在手机上会显示三天。
- **月**会显示整个月。在电脑上每天最多显示三项活动；在手机上会显示圆点，点按后可查看当天的活动。

点击顶部的**今天**、‹ 和 ›，可以切换周或月份。所选视图会保存在当前设备上。

在周视图的网格中，同一时间的活动会并排显示，同时确保每项活动都清晰可读。其余活动会显示为**+N**，点击后会在日程中打开当天内容。

## 打开内容

点击一行，可打开待办聊天、承诺、笔记或会议。无法在此处更改的会议（例如别人的会议，或有来宾的会议）会显示详细信息：时间、地点和参与者。Graph 中已知的人，以及会议所属的组织和项目，都会链接到各自的页面。点击它们下方的**在 Google Calendar 中打开**（或**在 Outlook 中打开**），即可在对应应用中打开会议。查看不会更改任何内容。

会议预订的会议室会显示在地点下方，不会显示为联系人，也不会出现在 Graph 中。

会议链接会显示对应的服务名称，例如 Zoom、Google Meet 或 Teams；如果无法识别，则会显示为**视频通话**。打开会议即可加入。

## 会议笔记和文字记录

会议详情分为两部分。**笔记**是摘要，包括决定和行动事项。**文字记录**是会议内容的逐字记录。文字记录初始为折叠状态，并显示时长；点击**显示**即可展开。

如果内容无法加载，系统会自动重试大约半分钟。之后，点按**重试**。

笔记和文字记录各自都有**添加备注**或**添加转录稿**、用于上传 Markdown 或文本文件的**上传文件**、**编辑**和**移除**（需点按两次）。添加到其中一处的内容会保留在那里。对于可以更改的会议，在会议表单下方点击**笔记**即可打开笔记。

连接了 [Zoom](zoom.md) 或 [Google Meet](google-meet.md) 后，来自 Zoom 的笔记会显示在「笔记」中，文字记录会显示在「文字记录」中，并标注为**来自Zoom**或**来自Google Meet**。这些内容不会替换你添加的内容；两者都有时，会同时显示。

笔记也可能来自会议自己的日历活动，在会议开始后添加，或通过 Zoom 或 Gemini 邮件发送。会议结束后，The Machine 只会根据其中明确的下一步行动创建待办。同一份笔记通过两种方式收到时，只会创建一个待办，并以会议为来源，显示“来源：会议笔记”。

有文字记录但没有笔记的会议会显示**生成笔记**。The Machine 会根据文字记录生成笔记，包括简短摘要、决定和标明负责人的行动事项，并使用会议所用的语言。

系统会显示**正在写笔记…**，即使关闭会议也会继续生成。较长的会议可能需要几分钟，并会使用你自己的模型。笔记会标注**由 The Machine 撰写**，不会替换你添加的笔记。

你也可以让 The Machine 添加笔记。在待办中提出要求即可，例如“把这份文字记录添加到今天的董事会会议”。文字记录会添加到「文字记录」，摘要会添加到「笔记」。日历中有这类内容的会议会显示**笔记**或**文字记录**。

The Machine 会同时读取笔记和文字记录，以处理会议后续事项。这些事项会与会议一样归类为「工作」或「个人」，只有会议属于团队时，后续事项才会发送给团队。

无论从哪里打开会议，都会显示这些详情，例如时间线、消息搜索结果，或待办的来源。底部的**原始邀请**会显示收到的邀请原文。

## 添加或更改活动

你可以在这里更改自己的 Google 日历。Outlook 和其他日历只能查看。点击**新活动**即可添加活动（手机上需要点击顶部栏中的**+**）：选择日历、填写标题并设置时间。点击该日历中没有来宾的活动即可更改，也可以点击**删除**将其删除（需点按两次）。

输入内容时，**地点**会推荐地点：先显示你用过的地点和所属组织的地址，然后显示来自免费地图 [OpenStreetMap](https://www.openstreetmap.org) 的地址。系统只会发送你输入的文字来查找地点。选择一个推荐地点，也可以保留自己输入的内容。

**邀请**可以添加 Graph 中的联系人，也可以添加任意电子邮件地址。此功能仅适用于自己的日历。按钮上方会列出收到邀请的人，按钮也会显示人数，例如：**添加并邀请 2 人**。只有点按按钮后，Google 才会发送邀请。没有来宾时，不会邀请任何人，也不会发送更新。

待办也可能建议更改日历，例如添加接送安排。系统会明确显示具体更改内容，只有点击**添加**、**保存**或**删除**后才会执行。

还没有会议？如果尚未连接日历，点击**连接日历**会打开「连接」，你可以连接 [Google Calendar](google-calendar.md)、[Outlook Calendar](microsoft.md) 或[其他日历](other-calendars.md)。

## 与其他日历中的活动冲突

如果工作会议与个人日历中的活动时间重叠，或反过来，The Machine 会针对两项活动中较晚创建的一项生成一个待办。The Machine 可以起草一条简短消息来调整时间，也可以建议拒绝会议。只有你批准后，消息才会发出。

全天、空闲和暂定活动不会计入，每项冲突也只会出现一次。工作待办只会说明有冲突，不会让团队看到个人活动。只有你能看到与之冲突的活动。

## 提前准备会议

在与公司外部人员的会议前，The Machine 会生成一个待办：**准备会议**。其中包含简短的会前资料：

- **谁：**对方的身份信息，来自 Graph。
- **最近联系：**你们最近一次交流。会议结束后，这条消息会作为待办的来源。
- **待处理的承诺：**你或对方仍需履行的事项。
- **待解答的问题：**尚未得到答复的问题。
- **需要决定或带上的内容：**需要确定的事项或需要带上的东西。

待办会在工作日早上生成：如果会议在下午，就在会议当天生成；否则会在会议前一个工作日生成。待办只会使用你在自己的 Machine 上已有的信息，只供阅读。阅读后点按**已完成**。其中需要执行的承诺或问题会各自生成待办。

没有有用的历史记录时，不会生成待办。重复会议、内部会议、个人会议和已拒绝的会议都不会生成待办。会议改期后，原有待办会保留并显示新的时间。已忽略的待办不会再次出现；会议取消后，对应待办会自动关闭。

会议详情中的**待办**下方会显示对应待办，点按一次即可打开聊天。
