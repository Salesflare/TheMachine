## 日历显示的内容

从今天开始的日程，包括：

- 你已连接的日历中的会议，
- 当天截止的待办，以及在重新处理那天显示的稍后处理的待办，
- 你交接出去的工作的跟进事项，
- 有日期的承诺，
- 来自预订和票务邮件的[行程和活动](calendar.md#trips-and-events)。

同一场会议如果出现在两个日历中，只显示一次。别人与你共享的日历会显示对方的活动，颜色较淡，并标注对方的名字。这些活动不会生成待办。全天活动和多日活动会在涵盖的每一天都显示为全天活动。行程会在日程视图中排在每天的第一项，在周视图和月视图中则显示为横跨多天的一条色带，例如“里斯本之旅”。

共同制定的计划算作一项承诺，会标注“与”和对方的名字。如果某项承诺与当天和同一个人的会议有关，就会显示在该会议所在的行中。

**已逾期**的事项排在最前面。有未完成待办的会议会显示待办状态：**准备就绪**、**正在准备**或**待办**。看起来已完成的待办（你已经回复，或处理流程发现它已完成）不会显示为**截止**。

## 日程、周或月

- **日程**会列出每天的安排。向下滚动可查看之后的日期，向上滚动或点按**显示更早的日期**可查看之前的日期。日程会显示到连接日历前一周，顶部会标明起始日期。加入[历史记录](history.md)后，日程会显示约一年前的内容。
- **周**视图以网格显示周一到周日。手机上会显示三天。
- **月**视图会显示整个月。电脑上每天最多显示三项活动；手机上会显示圆点，点按后可查看当天的活动。

点按顶部的**今天**、‹ 和 › 可切换周或月份。所选视图会保存在这台设备上。

在周视图网格中，同一时间的活动会并排显示，同时保持清晰易读。其余活动会显示为 **+N**，点按即可在日程视图中打开当天。

## 打开内容

点按一行即可打开待办聊天、承诺、行程、活动或会议。无法在此处更改的会议（例如别人的会议，或有受邀人的会议）会显示详细信息：时间、地点和参与者。Graph 中认识的人，以及会议所属的组织和项目，都会链接到各自的页面。点按下方的**在 Google 日历中打开**（或**在 Outlook 中打开**）可在对应应用中打开会议。查看不会做出任何更改。

会议中预订的会议室会显示在地点下方，不会作为人物显示，也不会出现在 Graph 中。

会议链接会显示对应服务的名称，例如 Zoom、Google Meet 或 Teams；也可能显示为**视频通话**。打开会议即可加入。

## 行程和活动

航班、酒店、火车、巴士、渡轮或租车预订邮件到达后，你的 Machine 会将其添加到行程中。同一趟旅程的预订会归到一个行程里，包括去程、酒店和返程。行程会显示为横跨多天的一条色带。打开行程即可按时间顺序查看每项预订的预订代码、座位和票券。

演唱会、比赛、节日庆典或会议的票券会生成一项活动，每场活动单独显示，并列出地点、预订代码、座位和票数。同一活动的第二笔订单也会添加到这项活动中。通过工作邮箱预订的活动会标记为“工作”，否则会标记为“个人”。

- 每一行都会注明预订邮件的来源，例如**来自 Example Tickets**，点按后可打开邮件。
- 如果邮件生成了待办，例如支付票款，点按**打开待办事项**即可查看。
- 预订变更后，对应条目也会更新；取消的预订会被移除。所有预订都取消后，行程或活动也会被移除。

它会读取航空公司、酒店、预订网站和票务平台在确认邮件中提供的详细信息，不使用 AI。邮件中没有这些信息时，不会生成任何内容。加入[历史记录](history.md)后，你的 Machine 会在后台读取其中保存年份范围内的预订邮件。

## 会议笔记和文字记录

会议详情分为两部分。**笔记**是摘要，包括决定事项和行动项。**文字记录**是逐字记录的谈话内容。文字记录默认收起，并显示时长；点按**显示**即可展开。

如果内容没有加载，会自动重试约半分钟。之后请点按**重试**。

每部分都有各自的**添加备注**或**添加转录稿**、用于上传 Markdown 或文本文件的**上传文件**、**编辑**和**移除**（点按两次）。添加到其中一部分的内容会保留在该部分。你可以更改的会议下方有**笔记**，点按即可打开笔记。

连接 [Zoom](zoom.md)、[Google Meet](google-meet.md) 或 [Granola](granola.md) 后，对应的笔记会显示在“笔记”中，文字记录会显示在“文字记录”中，并标注为**来自Zoom**、**来自Google Meet**或**来自 Granola**。这些内容不会替换你添加的内容；如果两者都有，就会同时显示。

会议自己的日历活动中也可能包含笔记，会议开始后添加的笔记也会显示在这里；你也可以通过 Zoom 或 Gemini 的邮件添加笔记。会议结束后，The Machine 只会根据其中明确的后续步骤创建待办。同一份笔记通过两种方式添加时，只会生成一个待办，并以会议为来源，标注为“来源：会议笔记”。

有文字记录但没有笔记的会议会显示**生成笔记**。The Machine 会根据文字记录，用会议所用的语言撰写简短摘要、决定事项和包含执行人的行动项。

页面会显示**正在写笔记…**，关闭会议后也会继续生成。较长的会议需要几分钟，并会使用你自己的模型。笔记会标注为**由 The Machine 撰写**，且不会替换你添加的笔记。

你也可以让 The Machine 添加笔记。在待办中提出请求即可，例如“把这份文字记录添加到今天的董事会会议中”。文字记录会添加到“文字记录”，摘要会添加到“笔记”。日历中有这些内容的会议会显示**笔记**或**文字记录**。

The Machine 会同时读取笔记和文字记录，查找会议的后续事项。这些事项会根据会议标记为“工作”或“个人”，只有会议属于团队时才会添加到团队中。

无论你在哪里找到会议，都可以打开它查看这些详细信息，包括时间线、消息搜索结果或待办来源。底部的**原始邀请**会显示收到的邀请原文。

## 添加或更改活动

你可以在此处更改自己的 Google 日历。Outlook 和其他日历只能查看。点按**新活动**可添加活动（手机上可点按顶部栏中的 **+**）：选择日历、填写标题并设置时间。点按该日历中没有受邀人的活动即可更改，也可以点按**删除**将其删除（点按两次）。

输入时，**地点**会推荐地点：先显示你之前用过的地点和所属组织，再显示来自免费地图 [OpenStreetMap](https://www.openstreetmap.org) 的地址。只有你输入的文字会被发送出去进行查询。选择一个推荐地点，也可以保留自己输入的文字。

**邀请**可添加 Graph 中的人，也可添加任意邮箱地址。只有在自己的日历中才能使用此功能。按钮上方会列出受邀人，按钮会显示受邀人数，例如：**添加并邀请 2 人**。点按按钮后，Google 才会发送邀请。在没有受邀人的情况下，不会邀请任何人，也不会向任何人发送更新。

待办也可能会建议更改，例如添加接送安排。它会明确显示要更改的内容，只有点按**添加**、**保存**或**删除**后才会做出更改。

还没有会议？如果尚未连接日历，点按**连接日历**会打开“连接”，你可以连接 [Google 日历](google-calendar.md)、[Outlook 日历](microsoft.md)或[其他日历](other-calendars.md)。

## 与其他日历的时间冲突

工作会议与个人日历中的活动重叠，或个人活动与工作会议重叠时，The Machine 会根据创建时间较晚的活动生成一项待办。它可以起草一条简短消息，请对方更改时间，也可以建议你拒绝邀请。只有你批准后，消息才会发出。

全天、空闲和暂定活动不会计入，每次冲突只会显示一次。工作待办只会说明存在冲突，因此团队不会看到个人活动。只有你能看到冲突的具体活动。

## 为会议做好准备

在与公司外部人员的会议开始前，The Machine 会创建一项待办：**准备会议**。内容是一份简短的会前简报：

- **谁：**对方是谁，信息来自你的 Graph。
- **最近联系：**你们最近的往来消息。会议结束后，该消息会作为待办的来源。
- **未完成的承诺：**你或对方仍需要履行的承诺。
- **未解决的问题：**尚未得到答复的问题。
- **需要决定或带上的东西：**需要确定的事项或需要带上的东西。

简报会在工作日早上送达：如果会议安排在下午，就在会议当天送达；否则会在前一个工作日送达。它只会使用你 Machine 上已有的信息。简报仅供查看；读完后点按**已完成**。其中需要跟进的承诺或问题会有各自的待办。

没有有用的历史记录时，不会生成待办。周期性会议、内部会议、个人会议和已拒绝的会议都不会生成待办。会议改期后，其待办会保留，并更新为新时间。已忽略的待办不会再次出现，会议取消后，待办会自动关闭。

在会议详情中的**待办**下方可以看到对应待办，点按一次即可打开聊天。
