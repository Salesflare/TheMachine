## 日历显示的内容

从今天起的日程包括：

- 你已连接的日历中的会议，
- 截止日期在当天的待办，以及当天重新出现的已推迟待办，
- 你交接出去的工作进度提醒，
- 设有日期的承诺，
- 来自预订和票务邮件的[行程和活动](calendar.md#trips-and-events)。

同一场会议如果出现在两个日历中，只显示一次。别人与你共享的日历会显示他们的活动，颜色较淡，并标注对方的名字。这些活动不会生成待办。全天活动和多日活动会在涵盖的每一天显示为全天活动。行程在「日程」中会显示在每一天的最前面，在「周」和「月」视图中则会以一条横条贯穿行程日期，例如“里斯本之旅”。

一起制定的计划会作为一项承诺显示，标注“与”以及对方的名字。如果某项承诺与当天和同一个人的会议有关，它会显示在该会议所在的行。

**已逾期**的项目会排在最前面。有未完成待办的会议会显示待办状态：**准备就绪**、**正在准备**或**待办**。看起来已完成的待办（你已经回复，或运行结果显示已完成）不会显示为**截止**。

## 日程、周或月

- **日程**按天列出安排。向下滚动可查看之后的日期，向上滚动或点击**显示更早的日期**可查看之前的日期。连接日历后，可以回看一周；顶部会显示起始日期。载入[历史记录](history.md)后，可以回看大约一年前的内容。
- **周**以网格显示周一至周日。手机上会显示三天。
- **月**显示整个月。电脑上每天最多显示三项活动；手机上会显示圆点，点按后可查看当天安排。

顶部的**今天**、‹ 和 › 可切换周或月份。所选视图会保存在这台设备上。

在周视图网格中，同一时间的活动会并排显示，同时确保每项活动都清晰可读。其余活动会显示为**+N**，点按后可在日程中查看当天安排。

## 打开项目

点击一行可打开对应的待办聊天、承诺、行程或活动，也可以打开会议。无法在这里修改的会议，例如别人的会议或有参会者的会议，会显示会议详情：时间、地点和参会者。Graph 中认识的人，以及会议所属的组织和项目，都会链接到各自的页面。点击其下方的**在 Google 日历中打开**（或**在 Outlook 中打开**）可在对应应用中打开。查看不会进行任何更改。

会议预订的会议室会显示在地点下方，不会作为人物或 Graph 中的项目显示。

会议链接会显示对应的服务，例如 Zoom、Google Meet 或 Teams，也可能显示为**视频通话**。打开会议即可加入。

## 行程和活动

航班、酒店、度假屋、火车、巴士、渡轮、租车、出租车或机场停车场的预订邮件到达后，你的 Machine 会将其添加到行程中。同一趟旅程的预订会合并到一个行程中，无论邮件来自哪个邮箱：去机场的火车、航班、租车、住宿和返程交通都会显示在一起。如果预订日期有重叠，或其中一项结束时另一项正好开始，它们就会合并。

行程会以一条横条贯穿行程日期。打开后，可以按时间顺序查看每项预订，以及对应的时间、地址、预订代码和座位。

音乐会、比赛、节日或会议的门票会创建活动，每场活动单独显示，并列出地点、预订代码、座位和票数。同一场活动的第二笔订单会添加到同一个活动中。通过工作邮箱预订的活动会标记为 Work，否则标记为 Personal。行程期间参加的活动会添加到行程中，而不是单独显示。

对于尚未开始的行程，你的 Machine 会提示缺少的预订，例如**还没有预订住宿，共 2 晚**，或没有预订从机场到酒店的交通。这些提示颜色较淡，并标记为**没有预订**。如果行程完全没有住宿预订，就不会提示住宿晚数。

- 每一行都会注明预订邮件的来源，例如**来自 Example Tickets**，点按后可打开邮件。
- 如果邮件生成了待办，例如支付票款，点击**打开待办事项**即可查看。
- 预订变更后，对应信息会更新；预订取消后，对应信息会移除。所有预订都取消后，行程或活动也会移除。
- 如果预订是为别人安排的，例如同事转发给你的航班信息，就不会出现在你的行程中。

大多数确认邮件都以一种格式包含详细信息，你的 Machine 无需使用 AI 就能读取。对于无法直接读取的邮件，例如转发的邮件或小型预订网站发来的邮件，你的[模型](model.md)会在后台分批读取，每次处理少量邮件；接近使用限额时会暂停。你的 Machine 会在[历史记录](history.md)载入后，在后台读取其中保留年份的预订邮件。

## 会议笔记和文字记录

会议详情分为两部分。**笔记**是摘要，包含决定和行动项。**文字记录**是逐字记录的会议内容。文字记录默认折叠，并显示时长；点击**显示**可展开。

如果内容无法载入，系统会自动重试约半分钟。之后请点按**重试**。

笔记和文字记录各自都有**添加备注**或**添加转录稿**、用于上传 Markdown 或文本文件的**上传文件**、**编辑**和**移除**选项（需点按两次）。添加到其中一项的内容会保留在该项中。在可修改的会议中，点击会议表单下方的**笔记**即可打开笔记。

连接了 [Zoom](zoom.md)、[Google Meet](google-meet.md) 或 [Granola](granola.md) 后，会议笔记会显示在「笔记」中，文字记录会显示在「文字记录」中，并标记为**来自Zoom**、**来自Google Meet**或**来自 Granola**。这些内容不会替换你添加的内容；两者都有时会同时显示。

会议笔记也可能来自会议对应的日历活动，在会议开始后添加，或通过 Zoom 或 Gemini 邮件发送。会议结束后，The Machine 只会根据明确的后续步骤创建待办。同一份笔记通过两种方式收到时，只会创建一项待办，来源会标记为该会议：“来源：会议笔记”。

有文字记录但没有笔记的会议会显示**生成笔记**。The Machine 会根据文字记录生成笔记，包括简短摘要、决定和行动项，并用会议所用的语言撰写，同时注明由谁负责。

界面会显示**正在写笔记…**；即使关闭会议，生成也会继续。较长的会议需要几分钟，并会使用你自己的模型。笔记会标注**由 The Machine 撰写**，且不会替换你添加的笔记。

你也可以让 The Machine 添加内容。在待办中提出请求，例如“把这份文字记录添加到今天的董事会会议”。文字记录会添加到「文字记录」，摘要会添加到「笔记」。包含这些内容的会议会在日历中显示**笔记**或**文字记录**。

The Machine 会读取两者，以整理会议后续事项。后续事项会像会议一样标记为 Work 或 Personal；只有会议本身归团队所有时，后续事项才会发送给团队。

无论在何处找到会议，都可以打开会议并查看这些详情，包括时间线、消息搜索结果或待办的来源。底部的**原始邀请**会显示收到的邀请原文。

## 添加或更改活动

你可以在这里修改自己的 Google 日历。Outlook 和其他日历只能查看。点击**新活动**可添加活动（手机上请点顶部栏的**+**）：选择日历、标题和时间。点击该日历中没有参会者的活动即可修改，或点击**删除**将其删除（需点按两次）。

输入文字时，**地点**会推荐地点：先显示你之前用过的地点和你的组织，再显示来自免费地图 [OpenStreetMap](https://www.openstreetmap.org) 的地址。系统只会发送你输入的文字来查询地点。选择一个推荐地点，也可以保留自己输入的文字。

**邀请**可以添加 Graph 中的人，也可以添加任意电子邮件地址。只有在你自己的日历中才会显示此选项。按钮上方会列出受邀者，按钮会显示人数，例如**添加并邀请 2 人**。只有点按按钮后，Google 才会发送邀请。没有参会者时，不会发送邀请，也不会向任何人发送更新。

待办也可能提供更改建议，例如添加接送安排。系统会明确显示将要更改的内容，只有点按**添加**、**保存**或**删除**后才会进行更改。

还没有会议？如果尚未连接日历，点击**连接日历**会打开「连接」，可连接 [Google 日历](google-calendar.md)、[Outlook 日历](microsoft.md)或[其他日历](other-calendars.md)。

## 与其他日历中的安排冲突

如果工作会议与个人日历中的安排重叠，或个人安排与工作会议重叠，The Machine 会针对时间较晚的安排创建一项待办。The Machine 可以起草一条简短消息来改期，也可以建议拒绝邀请。在你批准之前，不会发送任何内容。

全天、空闲和暂定活动不会计入冲突，每项冲突只会出现一次。Work 待办只会说明存在冲突，不会让团队看到个人活动。只有你能看到与哪项安排冲突。

## 为会议做好准备

与公司外部人员开会前，The Machine 会创建一项待办：**准备会议**。内容是一份简短的会前简报：

- **谁：**对方是谁，信息来自你的 Graph。
- **最近联系：**你们最近一次交流。会议结束后，该消息会作为待办的来源。
- **未履行的承诺：**你或对方仍需完成的事项。
- **未解决的问题：**尚未回答的问题。
- **需要决定或携带的内容：**需要敲定或带上的东西。

简报会在工作日早上生成：如果会议在下午，就在会议当天生成；否则在前一个工作日生成。简报只会使用 Machine 上已有的信息，仅供查看。读完后点按**已完成**。其中需要处理的承诺或问题会各自生成待办。

没有有用的历史信息时，不会生成待办。重复会议、内部会议、个人会议和已拒绝的会议都不会生成待办。会议改期后，原有待办会保留，并更新到新的时间。已忽略的待办不会再次出现；会议取消后，对应待办会自动关闭。

会议详情会在**待办**下显示对应待办，点按一次即可打开聊天。
