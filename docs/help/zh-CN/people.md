所有与你联系的人都会显示在这里，按亲疏程度排序，信息来自你的消息和会议。除非你回复，否则新闻简报、收据和其他群发邮件不会添加联系人。它们会显示在列表下方的“隐藏的发件人”中；点击“显示为联系人”即可添加。三种列表的字段、标签和导入方式都相同，每种列表都有自己的筛选条件：请参阅[Graph](graph.md)。

共享收件箱（info@、客服邮箱、商店自己的名称）会归到所属组织名下，不会作为联系人添加，即使你给它发过邮件也是如此。

## 联系人页面

页面顶部显示联系人的照片、姓名、职位、组织和所在地，以及一行你们的联系情况（“每天交谈 · 上次联系是昨天 · 下次会议是10月27日，周二”）。最近联系时间会显示为“刚刚”“3小时前”“昨天”或“3天前”，更早的联系则显示日期；将鼠标悬停即可查看准确日期。下方还会显示：

- **联系人**：联系人的电话和邮箱。点击即可拨打电话或发邮件，也可以点击**复制**。这里还会显示对方的**生日**及其来源（Google 联系人、Google 日历、Facebook、你的笔记或你本人）：请参阅[Graph](graph.md#birthday)。
- **和你一起**：对方与你的关系、是工作联系人还是个人联系人，以及对方属于你的家人或 Fleet，并提供**在Fleet中查看**。
- **也在**：你们交谈过的其他平台。点击**Slack**可在 Slack 中打开对方，或打开你们最近的 Slack 话题。
- 对方参与的**人员**和**项目**、**你们之间未关闭的**事项（双方的承诺，可**标记为已完成**或**放弃**），以及对方的**时间线**。

如果能确定是同一个人，联系人的不同地址和聊天记录会自动合并。例如，工作邮箱抄送了对方的个人邮箱。

如果页面显示**无法加载此页面。**，请点击**重试**。如果问题仍然存在，请点击页面底部的**遇到问题了？**。

## 摘要

摘要显示在联系人页面顶部，用几句话概括你们商定、询问、计划或承诺的事项，并注明相关人员。只有你确实有联系的人才会有摘要。有新内容时，The Machine 会先检查每句话，再重新撰写摘要。通常每天更新一次；如果你们之间的事情有变化，例如出现新截止日期或撤回请求，则会在几小时内更新。

含糊不清的内容不会列出；如果没有具体内容可写，就不会显示摘要。每句话都链接到其来源：同一天的消息会合并显示日期和消息数量，点击即可展开。

点击**编辑**，用自己的方式撰写摘要。有新消息时，The Machine 会提供**建议的更新**，你可以选择**使用**或**保留我的**。点击**让The Machine来写**，即可交由 The Machine 撰写。

会议准备也会使用摘要，但只会采用与该待办相同类别（工作或个人）的内容。摘要只保存在你的 Machine 上，团队看不到。

## 时间线

每个人和组织的页面都有时间线，按时间倒序显示邮件、会议及其 Zoom 摘要、Intercom 对话（提供**在Intercom中打开**）、WhatsApp、Telegram、Slack、LinkedIn 和 X 聊天、待办、承诺和项目动态。顶部的标签一次显示一个来源。点击**展开**可加载更早的内容。

即将举行的会议会按时间顺序显示在顶部的**即将开始**下方；点击**显示所有即将到来的内容**可查看其余会议。会议会显示参会人员，同一个人只显示一次。有笔记或文字记录的会议会标注**笔记**或**文字记录**；点击即可查看。

你的时间线仅对你可见：团队的 Graph 只会显示共享规则允许查看的内容。在页面的时间线顶部点击**团队**，可查看队友分享的内容，每项都会注明分享者；点击**我的**则只显示你自己的内容。

## 工作和个人

**工作**和**个人**标签页会根据联系人的类型列出人员，类型显示在联系人页面上。你自己选择的类型（点击**编辑**）优先。否则，你的家人和朋友，以及把你视为家人或朋友的人（例如妻子、父亲），都会归为个人联系人，无论他们用哪个地址发消息。团队看不到个人联系人。

## 添加联系人

点击“人员”页面顶部的**新建人员**，或在手机上点击顶部栏中的**+**。填写姓名；如果有邮箱和所属组织，也可以一并填写。如果 Graph 中已有类似联系人，表单会优先显示他们，你可以改为打开已有联系人。点击**添加**即可打开新建的联系人页面。

添加的联系人会一直保留，即使还没有消息记录。对方发来第一条消息后，消息会自动关联到该联系人。

## 编辑联系人

点击联系人页面顶部的**编辑**，即可修改姓名、职位、组织、所在地、LinkedIn、电话和邮箱、对方与你的关系，以及工作或个人类别。**笔记**字段可用于记录你想记住的内容；合并联系人时，笔记会保留。点击**保存**以保存更改，或点击**取消**放弃更改。

你所做的修改会保留，即使系统重新查找了对方的信息，或执行了**合并**和**撤销**也是如此。清空字段即可恢复系统查找到的值。清空姓名后，会恢复对方消息中使用的姓名。

如需更换照片，请点击照片，然后选择**上传图片**、选择系统找到的照片，或点击**移除图片**。照片只保存在你的 Machine 上。

## 合并两个人

如果两个人可能是同一人，他们的页面会询问是否为同一个人，“人员”列表也会在**是同一个人？**下方列出他们。点击**合并**即可将两人合并，所有消息、笔记、角色和项目都会一并保留。点击**不一样**即可让他们继续保持分开。你的选择会短暂显示在这两人旁边，随后他们会从列表中移除。没有待确认的项目后，整个列表就会消失。

如果某人的地址看起来像你认识的联系人的地址，例如 acme-corp.example 和 acmecorp.example，系统不会建议将他们视为同一个人，而且只有你可以为他们指定角色。

仅凭姓名无法判断不同域名下的两个人是同一人，因为任何人都可以使用相同的姓名。只有存在其他关联时，例如有共同联系人或共同参与的项目，系统才会建议合并不同域名下的地址。有人使用你的姓名，但地址并非你的地址时，系统也不会建议合并。请改为在“设置”中的[你的地址](settings.md#your-addresses)里添加其他地址。

如果不同域名下的联系人只匹配了名字，例如“Sam”和“Sam Lee”，只有电话号码或 LinkedIn 个人资料相同，系统才会建议合并。

共享地址（例如 info@ 或邮件列表）不会与通过它发邮件的人合并。公司外部的工作联系人和仅姓名相同的个人聊天对象不会自动合并，而是会作为待确认问题列出。

点击**全部合并**，即可一次合并列表中的所有联系人对，但你标记为**不一样**的除外。合并后立即点击**撤销**，即可全部恢复。

如需自行合并两个人，请打开其中一人的页面，点击**⋯**，选择**与……是同一个人**，然后选中另一个人。合并后的联系人页面会在**合并来源**下列出合并原因，并提供**撤销**选项供你拆分联系人。

## 永久删除联系人

在联系人页面打开 ⋯ 菜单，选择**永久删除…**，然后点击**删除**。这会删除该联系人以及你的 Machine 保存的相关信息：联系人条目、地址、系统查找到的详情、仅属于你们两人的消息，以及关于对方的笔记。

涉及该联系人的待办会保留，但会移除对方姓名。此联系人不会再次添加，导入联系人或创建带有其姓名或地址的 Facebook 生日待办也不会添加。此操作无法撤销。

## 邮件退回

发给某人的邮件被退回时，对方的地址旁会显示**退回**和日期，并优先显示对方的其他地址。如果已知其他地址，新建草稿时绝不会使用被退回的地址。如果这是对方唯一的地址，发送邮件时会显示警告，但你仍然可以发送。

如果邮件服务器表示该地址不存在，或一周内连续出现 3 次临时失败，就会将邮件计为退回。对方再次从该地址发来邮件，或发往该地址的邮件成功送达后，退回状态就会清除。

## 职位和照片

使用公司邮箱的联系人会显示系统查找到的职位、照片、LinkedIn 和所在城市，查找方式与[组织详情](organization-data.md)相同。在托管的 Machine 上，查找时只会使用联系人的姓名和公司域名。Gravatar 获取照片时使用的是其工作邮箱的哈希值，不会获取邮箱地址本身。你可以在**设置**的“安全”下关闭此功能：**查找工作联系人**。

查找到联系人后，他们的页面还会显示个人简介、开始当前职位的时间以及此前的两个职位。会议准备也会读取这些信息；只有联系人没有自己的简介时，才会使用个人简介内容。

你的连接会根据联系人已经公开的信息补充详情：Slack 中的职位、电话和时区，X 中的简介和所在地，LinkedIn 中的标题和照片，Google 联系人和 Salesflare 中的职位，以及 Salesflare 保存的联系人照片。将鼠标悬停在姓名下方的内容上，即可查看来源。

Outlook 会添加你所在组织的同事和 Outlook 联系人的照片，以及联系人职位和所属公司信息（[Microsoft](microsoft.md#photos-of-colleagues-and-contacts)）。

WhatsApp 和 Telegram 的照片会通过 WhatsApp 同步和 Telegram 聊天连接导入：每个平台每天最多 50 张，只适用于已在 Graph 中的联系人。系统不会向他们发送任何内容。导入 Facebook 生日时，保存联系人后，如果对方还没有照片，也会添加其个人头像（[例行程序](routines.md)）。所有内容都只保存在你的 Machine 上。

在工作 Fleet 的[团队 Graph](team-graph.md)中，联系人的共享记录会附带一张较小的工作照片副本。来自 Google 联系人、WhatsApp、Telegram 或 Facebook 的照片，以及你更改或移除的照片，都不会共享。

## 关于你

你自己的地址和号码（包括别名）始终属于你，不会被当作 Graph 中的其他联系人。搜索自己，或添加使用你某个地址的联系人时，会打开**关于你**；导入时也会跳过你自己的记录。

“关于你”会列出你的地址及各自的来源；如需修改，请前往“设置”的“账户”。如需将自己的联系方式分享给队友或朋友，请选择**分享我的联系方式**。请参阅[分享联系方式](share-contact.md)。

## 对方与你的关系

The Machine 会从消息中识别出与你的关系，并在联系人页面的**发给你**下方显示，只保留能体现这种关系的词语，例如职位。仅凭对方说自己是你的会计师或客户还不够，还需要来自你这边的信息，例如你发给对方的消息或与你们有关的会议。系统不会等待你确认。如果关系有误，可以在联系人页面点击**编辑**进行修正，也可以点击**近期更改**对应条目旁的**⋯**。系统会根据你的修改进行学习。

## 系统了解的联系人信息

联系人的事实会显示在其页面的**已知信息**下方；一般性的信息则保留在“心得”中。点击**添加**，即可用自己的话补充一条信息。每条信息都有一个菜单：

- 点击**编辑**可直接修改。
- 点击**与对方无关**，可将其恢复为一般性信息，并移至**心得**下的**事实**。
- 点击**移除**可将其彻底删除。

## 近期更改

人物、组织或项目时间线正上方折叠显示的**近期更改**，会列出你的 Machine 对其做出的更改或学到的信息，例如角色、工作单位、两个人的关系、事实或项目动态。每条内容都会显示日期和来源；点击来源即可查看消息。

如果内容有误，点击对应条目旁的**⋯**即可直接修正：选择**编辑**、**移除**、**与对方无关**，或点击**撤销**将项目恢复到之前的位置。列表会先显示 3 条，点击**展开**可查看其余内容。

如果你的 Machine 今天更新了某位联系人，“人员”列表中的联系人旁会显示一个小圆点，列表顶部也会显示**今天更新了 4 位联系人**。请参阅[Graph](graph.md)。

## 关于某人的待办

在人物、组织或项目的 **⋯** 菜单中点击**新建待办**，即可创建与其相关的待办。
