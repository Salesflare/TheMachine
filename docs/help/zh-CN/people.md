你联系过的所有人，按亲密程度从高到低排列，来自你的消息和会议。订阅邮件、收据和其他群发邮件不会自动添加联系人，除非你回复了邮件。它们会显示在列表下方的“已隐藏的发件人”中；点击 **显示为联系人** 即可将其添加为联系人。三个列表的字段、标签和导入方式都相同，但各自有不同的筛选条件：参阅[The Graph](graph.md)。

共享收件箱（info@、客服邮箱、商店自己的名称）会归到对应的组织名下，不会算作个人，即使你给它发过邮件也一样。

## 某人的页面

页面顶部会显示对方的照片、姓名、职位、组织和所在地，以及一行你们的联系情况（“每天聊天 · 昨天联系过 · 下次会议：10月27日周二”）。最近联系的时间会显示为“刚刚”“3小时前”“昨天”或“3天前”，更早的联系则显示日期；将鼠标悬停在日期上可查看确切日期。下方内容包括：

- **联系人**：对方的电话号码和邮箱。点击即可拨打电话或发送邮件，也可以点击 **复制**。这里也会显示对方的 **生日**，以及生日信息的来源（Google 通讯录、Google 日历、Facebook 或你）：参阅[The Graph](graph.md#birthday)。
- **和你一起**：对方与你的关系、对方是工作联系人还是个人联系人，以及对方所属的家庭或Fleet，并提供 **在Fleet中查看**。
- **也在**：你们聊天的其他平台。点击 **Slack** 可在Slack中打开对方，或打开你们最新的Slack对话。
- 对方参与的 **人员** 和 **项目**、**你们之间未关闭的**（双方之间的承诺，可 **标记为已完成** 或 **放弃**），以及对方的 **时间线**。

如果能够确认某人的多个地址和聊天都属于同一个人，系统会自动合并，例如工作邮箱的抄送栏中有对方自己的邮箱地址。

如果页面显示 **无法加载此页面。**，点击 **重试**。如果仍然如此，请使用页面底部的 **遇到问题了？**。

## 摘要

摘要位于人员页面顶部，由几行简短内容组成，记录已决定、询问、计划或承诺的事项，并注明涉及的所有人。有新内容时，The Machine 会为你真正联系过的人更新摘要，并逐行检查。通常每天更新一次；如果与对方相关的事项有变化，例如出现新的截止日期或有人撤回请求，则会在几小时内更新。

内容含糊的事项不会列出；如果没有具体内容可写，就不会显示摘要。每行都链接到其来源：同一天的消息会合并显示日期和消息数量，点击后即可展开。

点击 **编辑**，按你的方式修改摘要。有新消息时，The Machine 会显示 **建议的更新**，并提供 **使用** 和 **保留我的**。点击 **让The Machine来写**，即可恢复由它撰写。

会议准备内容会使用摘要，但只会采用该待办对应类别（工作或个人）的内容。摘要保存在你的 Machine 上，团队看不到。

## 时间线

每个人和组织的页面都有时间线，按时间倒序排列，包含邮件、会议及其Zoom摘要、Intercom对话（提供 **在Intercom中打开**）、WhatsApp、Telegram、Slack、LinkedIn 和 X 聊天、待办、承诺和项目动态。顶部的筛选标签一次显示一个来源。点击 **展开** 可加载更早的内容。

即将举行的会议显示在顶部的 **即将开始** 区域，按时间从近到远排列；点击 **显示所有即将到来的内容** 可查看其余会议。会议条目会显示参会者，每个人只显示一次。带有笔记或文字记录的会议会显示 **笔记** 或 **文字记录**；点击即可查看。

你的时间线只属于你：团队的Graph只会显示符合你的共享规则的内容。在页面中，点击时间线上的 **团队** 可查看队友分享的内容，每项都会注明分享者；点击 **我的** 则只显示你的内容。

## 工作和个人

**工作** 和 **个人** 标签会根据每个人页面上的类型列出联系人。你自己的选择（点击 **编辑** 设置）优先。否则，你的家庭成员和朋友，以及与你是家庭成员或朋友关系的人（例如妻子、父亲），都会归为个人联系人，无论他们用哪个地址给你写信。团队看不到你的个人联系人。

## 添加人员

点击“人员”页面顶部的 **新建人员**，或在手机上点击顶栏中的 **+**。填写姓名；如果有邮箱和组织信息，也可以一并填写。如果Graph中已有类似联系人，表单会优先显示对方，你可以改为打开现有联系人。点击 **添加** 即可打开新页面。

添加的人员会保留下来，即使还没有任何消息。对方发送第一条消息后，消息会与其关联。

## 编辑人员

点击页面顶部的 **编辑**，可以更改对方的姓名、职位、组织、所在地、LinkedIn、电话号码和邮箱、你们之间的关系，以及工作或个人类别。**笔记** 字段可用于记录你想记住的内容；合并后笔记也会保留。点击 **保存** 保存更改，点击 **取消** 则保留原样。

你做的更改会一直保留，包括再次查找对方信息后，以及 **合并** 和 **撤销** 后。清空某个字段即可重新使用查找到的值。清空姓名后，会恢复为对方消息中使用的姓名。

要更改对方的照片，点击照片，然后 **上传图片**、选择查找到的照片，或点击 **移除图片**。照片会保存在你的 Machine 上。

## 合并两个人

如果两个人可能是同一个人，他们的页面会询问是否为同一人，“人员”列表中也会在 **是同一个人？** 下列出他们。点击 **合并** 可将他们合并，包含所有消息、笔记、关系和项目。点击 **不一样** 则会永久保留为两个人。你的选择会短暂显示在这两个人的条目上，随后他们会从列表中移除。没有待确认的条目后，列表就会消失。

如果某人的地址看起来像你认识的人的地址，例如 acme-corp.example 和 acmecorp.example，这两个人绝不会被建议合并，而且只有你能为此人指定关系。

共享地址（例如 info@ 或邮件列表）绝不会与通过该地址发信的人合并。公司外的工作联系人和仅仅姓名相同的个人聊天对象不会自动合并，而是会作为待确认项列出。

点击 **全部合并** 可一次合并列表中的所有人员，但不会合并你标记为 **不一样** 的人员。合并后立即点击 **撤销**，即可再次拆分所有人员。

要手动合并两个人，打开其中一人的页面，然后依次点击 **⋯**、**与……是同一个人**，再选择另一个人。合并后的人员页面会在 **合并来源** 下列出合并原因，点击 **撤销** 即可再次拆分。

## 永久删除人员

打开对方的页面，点击 ⋯ 菜单并选择 **永久删除…**，然后点击 **删除**。此操作会删除该人员以及你的 Machine 了解的相关内容：人员条目、地址、查找到的详细信息、仅在你们两人之间的消息，以及关于对方的笔记。

与对方相关的待办会保留，但会移除对方的姓名。此人不会再被添加，即使导入联系人，或导入了包含其姓名或地址的Facebook生日待办也一样。此操作无法撤销。

## 退信

发给某人的邮件退回时，对应地址会显示 **已退信** 和日期，并将对方的另一个地址排在前面。如果已知其他地址，新草稿就不会发送到这个地址。如果这是对方唯一的地址，发送界面会发出警告，但你仍然可以发送。

如果邮件服务器提示地址不存在，或一周内出现3次临时发送失败，就会计为退信。对方再次从该地址给你发信，或你成功向该地址发送邮件后，退信状态就会清除。

## 职位和照片

有公司邮箱的人员会显示查找到的职位、照片、LinkedIn和城市，查找方式与[组织信息](organization-data.md)相同。在托管版 Machine 上，查找时只会获取对方的姓名和公司域名。查找Gravatar照片时会发送对方工作邮箱的哈希值，不会发送邮箱地址本身。要关闭此功能，请前往 **设置** 中的“安全”部分，然后关闭 **查找工作联系人**。

查找到人员信息后，他们的页面还会显示个人简介文本、开始担任当前职位的时间，以及之前的两个职位。准备内容也会读取这些信息；只有在对方没有自己的简介时，才会使用个人简介文本。

你连接的平台会利用已有信息补充联系人资料：Slack会提供职位、电话和时区，X会提供简介和所在地，LinkedIn会提供标题和照片，Google通讯录和Salesflare会提供职位；如果Salesflare本身保存了联系人的照片，也会提供这张照片。将鼠标悬停在姓名下方的那一行，即可查看信息来源。

Outlook会添加你所在组织的同事和Outlook联系人的照片，以及联系人的职位和公司（[Microsoft](microsoft.md#photos-of-colleagues-and-contacts)）。

WhatsApp和Telegram的照片会通过你的WhatsApp同步和Telegram聊天连接获取：每个平台每天最多50张照片，且只会获取Graph中已有人员的照片。系统不会向他们发送任何内容。导入Facebook生日信息并保存后，如果某人还没有照片，系统也会添加其个人资料照片（[例行程序](routines.md)）。所有内容都会保存在你的 Machine 上。

在工作Fleet的[团队Graph](team-graph.md)中，共享人员记录时会附带一张小尺寸的工作照片。来自Google通讯录、WhatsApp、Telegram或Facebook的照片，以及你更改或移除过的照片，都不会共享。

## 关于你

你自己的地址和号码（包括别名）始终属于你，不会作为Graph中的其他人员。搜索自己，或添加一个使用你地址的人员时，会打开 **关于你**；导入时也会跳过你自己的条目。

“关于你”会列出你的地址及各自的来源；要更改地址，请前往 **设置** 中的“账户”。要将自己的联系方式发送给队友或朋友，请选择 **分享我的联系方式**。参阅[分享联系人](share-contact.md)。

## 对方与你的关系

The Machine 会从消息中识别你与对方的关系，并在对方页面的 **发给你** 下显示关系和识别依据。你无需确认。识别有误？在对方页面点击 **编辑**，或点击 **近期更改** 中对应条目的 **⋯**。系统会根据你的修改学习。

## 关于某人的信息

关于对方的事实会显示在其页面的 **已知信息** 下；一般性的信息则会保存在“心得”中。点击 **添加**，即可用自己的话添加一条信息。每条信息都有菜单：

- **编辑** 可直接修改信息。
- 点击 **与对方无关**，可将其改回一般性信息，放到 **心得** 下的 **事实** 中。
- **移除** 会将其彻底删除。

## 近期更改

人物、组织或项目时间线正上方的 **近期更改** 默认会折叠，其中列出你的 Machine 对相关对象所做的更改或学到的信息，例如关系、工作地点、两个人之间的关系、事实或项目动态。每条内容都显示日期和来源；点击来源即可查看消息。

如果内容有误，点击对应条目的 **⋯** 即可直接更正：选择 **编辑**、**移除**、**与对方无关**，或点击 **撤销** 将项目恢复到原来的位置。列表会显示3条内容；点击 **展开** 可查看其余内容。

你的 Machine 今天更新过的人员会在“人员”列表中显示一个小圆点，列表顶部的 **今天已更新4人** 会列出这些人员。参阅[The Graph](graph.md)。

## 关于某人的待办

在人员、组织或项目的 **⋯** 菜单中点击 **新建待办**，即可创建与其相关的待办。
