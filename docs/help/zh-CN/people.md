你联系过的所有人，按亲近程度排序，来自你的消息和会议。订阅邮件、收据和其他群发邮件不会自动添加联系人，除非你回复了对方。它们会显示在列表下方的“隐藏发件人”中，点击“显示为人员”即可添加。三个列表中的字段、标签和导入方式都相同，但每个列表都有自己的筛选条件：参见[Graph](graph.md)。

共享收件箱（info@、客户服务邮箱、商店名称等）归属于对应组织，不算作个人，即使你给它发过邮件也一样。

## 某人的个人页面

页面开头会显示对方的照片、姓名、职位、组织和所在地，以及一行联系情况（“每天聊天 · 昨天联系过 · 下次会议：10月27日周二”）。最近联系时间会显示为“刚刚”“3小时前”“昨天”或“3天前”，更早的联系会显示日期；将鼠标悬停在日期上可查看具体日期。下方还会显示：

- **联系人**：对方的电话号码和电子邮箱。点击其中一项即可拨打或发送消息，也可以点击**复制**。这里也会显示对方的**生日**及其来源（Google 通讯录、Google Calendar、Facebook、你的笔记或你）：参见[Graph](graph.md#birthday)。
- **和你一起**：对方与你的关系、属于工作还是个人联系人，以及对方所在的 Family 或 Fleet，并提供**在Fleet中查看**。
- **也在**：你们交谈过的其他平台。点击**Slack**可在 Slack 中打开对方，或打开你们最近的 Slack 对话。
- 对方参与的**人员**和**项目**、**你们之间未关闭的**（双方的承诺，可**标记为已完成**或**放弃**），以及对方的**时间线**。

当系统能确定多个地址和聊天属于同一个人时，会自动将它们关联起来，例如对方使用工作邮箱发信，并将自己的地址抄送其中。

如果页面显示**无法加载此页面。**，请点击**重试**。如果仍然如此，请点击页面底部的**遇到问题了？**。

## 摘要

摘要显示在个人页面顶部，由几行简短内容组成，概述已经决定、提出、计划或承诺的事项，并列出相关人员。The Machine 会在有新进展时重写摘要，只针对你确实有联系的人，并会先核对每一行内容。通常每天更新一次；如果与对方相关的事情有变化，例如新增截止日期或撤回请求，则会在几小时内更新。

含糊不清的内容会被略过；如果没有具体内容可写，就不会显示摘要。每一行都链接到来源：同一天的消息会合并为一项，显示日期和消息数量，点击即可展开。

点击**编辑**即可按自己的方式修改。有新消息时，The Machine 会显示**建议的更新**，并提供**使用**和**保留我的**选项。点击**让The Machine来写**即可交由 The Machine 重新撰写。

会议准备会使用摘要，但只会采用与该待办的类别（工作或个人）相符的内容。摘要保存在你的 Machine 上，团队看不到。

## 时间线

每个人和组织的页面都有时间线，按时间从新到旧排列，包含邮件、会议及其 Zoom 摘要、Intercom 对话（提供**在Intercom中打开**）、WhatsApp、Telegram、Slack、LinkedIn 和 X 聊天、待办、承诺和项目动态。顶部的筛选标签一次显示一个来源。点击**展开**可加载更早的内容。

即将举行的会议会显示在顶部的**即将开始**下方，按时间从近到远排列；点击**显示所有即将到来的内容**可查看其余会议。会议会显示参与者，每个人只列一次。带有笔记或文字记录的会议会显示**笔记**或**文字记录**；点击即可查看。

你的时间线只属于你：团队的 Graph 仅显示分享规则允许查看的内容。在页面的时间线上方点击**团队**，可查看队友分享的内容，每项都会标明分享者；点击**我的**则只显示你的内容。

## 工作和个人

**工作**和**个人**标签会根据联系人的类型列出人员，类型显示在个人页面上。你自己的选择（点击**编辑**）优先。否则，你的 Family 和 Friends，以及与你有亲属或朋友关系的人（例如妻子、父亲），都会归为个人联系人，不受他们使用哪个地址联系你的影响。团队看不到个人联系人。

## 添加人员

点击“人员”页面顶部的**新建人员**，或在手机上点击顶部栏中的**+**。填写姓名；如果知道对方的电子邮箱和组织，也可以一并填写。如果 Graph 中已经有类似的人，表单会优先显示已有联系人，你可以改为打开那个人的页面。点击**添加**即可打开新建的个人页面。

添加的联系人会保留下来，即使还没有消息记录也一样。对方发来第一条消息后，消息会关联到此联系人。

## 编辑人员

点击个人页面顶部的**编辑**，即可修改对方的姓名、职位、组织、所在地、LinkedIn、电话号码和电子邮箱、你与对方的关系，以及工作或个人类型。**笔记**字段可用于记录你想记住的内容；合并联系人后，笔记仍会保留。点击**保存**以保存更改，点击**取消**则保留原样。

你所做的修改会一直保留，即使系统重新查找对方的信息，或你执行了**合并**和**撤销**也一样。清空某个字段后，系统会重新使用查找到的值。清空姓名后，系统会恢复对方在消息中使用的姓名。

要更改照片，请点击照片，然后选择**上传图片**、挑选系统为对方找到的照片，或点击**移除图片**。照片会保存在你的 Machine 上。

## 合并两个人

如果两个人可能是同一人，他们的个人页面会询问是否为同一个人，“人员”列表中也会将他们列在**是同一个人？**下方。点击**合并**即可合并他们的所有消息、笔记、关系和项目。点击**不一样**则会将他们永久分开。你的选择会在这两个人旁显示一会儿，然后他们就会从列表中移除。没有待确认的问题后，整个列表也会消失。

如果某人的地址只是看起来像你认识的人的地址，例如 acme-corp.example 和 acmecorp.example，系统绝不会建议将他们视为同一个人，而且只有你可以为他们设置关系。

只有姓名相同绝不足以判定不同域名下的两个人是同一人，因为任何人都可以使用相同姓名：只有存在其他关联信息时，系统才会建议合并不同域名下的地址，例如有相同联系人或项目。如果有人使用你的姓名，但地址不是你的，系统绝不会建议合并。请改为在**设置**中的[你的地址](settings.md#your-addresses)下添加你的其他地址。

如果不同域名下的联系人只匹配名字，例如“Sam”和“Sam Lee”，只有在电话号码或 LinkedIn 个人资料相同的情况下，系统才会建议合并。

共享地址（例如 info@ 或邮件列表）绝不会与通过它发信的人合并。来自公司外部的工作联系人和仅仅姓名相同的私人聊天对象不会自动合并，而是会列为待确认的问题。

点击**全部合并**可一次合并列表中的所有人，已标记为**不一样**的人除外。立即点击**撤销**可将他们全部拆分。

要手动合并两个人，请先打开其中一人的页面，然后点击**⋯**、**与……是同一个人**，再选择另一个人。合并后的个人页面会在**合并来源**下列出合并原因，点击**撤销**即可将他们拆分。

## 永久删除某人

在对方的个人页面中打开 ⋯ 菜单，选择**永久删除…**，然后点击**删除**。这会删除对方以及你的 Machine 对其掌握的信息，包括联系人条目、地址、查找到的详细信息、仅存在于你们两人之间的消息，以及关于对方的笔记。

与对方有关的待办会保留，但会移除对方的姓名。之后不会再次添加此人，包括通过导入，或通过包含其姓名或地址的 Facebook 生日待办添加。此操作无法撤销。

## 退信

发送给某人的邮件被退回时，对方的地址旁会显示**退信**和日期，并优先显示对方的其他地址。如果已知其他地址，新草稿不会发送到这个地址。如果这是对方唯一的地址，发送窗口会发出警告，但你仍然可以发送。

如果邮件服务器报告地址不存在，或者一周内出现 3 次临时发送失败，就会计为退信。对方再次从该地址给你发信，或你成功向该地址发送邮件后，退信标记会清除。

## 职位和照片

使用公司地址的联系人会显示查找到的职位、照片、LinkedIn 和城市，查找方式与[组织详细信息](organization-data.md)相同。在托管版 Machine 上，查找时只会发送对方的姓名和公司域名。获取照片时，Gravatar 只会收到对方工作地址的哈希值，不会收到地址本身。你可以在**设置**的“安全”下关闭此功能：**查找工作联系人**。

找到相关信息后，个人页面还会显示对方的简介文本、开始担任当前职位的时间，以及之前的两个职位。会议准备也会读取这些信息；只有对方没有自己的简介时，才会使用简介文本。

你连接的平台会利用已有信息补充联系人资料：Slack 中的职位、电话和时区，X 中的简介和所在地，LinkedIn 中的标题和照片，Google 通讯录和 Salesflare 中的职位，以及 Salesflare 自行保存的联系人照片。将鼠标悬停在姓名下方的信息上，即可查看来源。

Outlook 会添加你所在组织的同事和 Outlook 联系人的照片，以及联系人的职位和公司信息（[Microsoft](microsoft.md#photos-of-colleagues-and-contacts)）。

WhatsApp 和 Telegram 的照片通过 WhatsApp 同步和 Telegram 聊天连接导入：每个平台每天最多 50 张，且只针对 Graph 中已有的联系人。系统不会向他们发送任何内容。导入 Facebook 生日时，如果某人没有照片，保存后会添加其头像（[例行程序](routines.md)）。所有内容都保存在你的 Machine 上。

在工作 Fleet 的[团队 Graph](team-graph.md)中，联系人的共享记录会附带一张小尺寸的工作照片副本。来自 Google 通讯录、WhatsApp、Telegram 或 Facebook 的照片，以及你更改过或移除的照片，都不会共享。

## 关于你

你的地址和电话号码，包括别名，始终属于你，不会被视为 Graph 中的其他人。搜索自己，或添加一个使用你地址的联系人时，系统会打开**关于你**；导入时也会跳过你自己的条目。

“关于你”会列出你的地址及各自的来源；要更改地址，请前往**设置**中的“账户”。要将自己的联系方式发给队友或朋友，请选择**分享我的联系方式**。参见[分享联系人](share-contact.md)。

## 对方与你的关系

The Machine 会从消息中识别出你与对方的关系，并在对方页面的**发给你**下方显示，同时附上识别依据。无需等待你确认。如果识别有误，可以在对方页面点击**编辑**进行修正，也可以点击**近期更改**中对应项目旁的**⋯**。The Machine 会从你的修改中学习。

## 它知道的关于某人的信息

关于对方的事实会显示在个人页面的**已知信息**下；常规信息会保存在“心得”中。点击**添加**可用自己的话添加一条信息。每条信息都有一个菜单：

- 点击**编辑**可直接修改。
- 点击**并非关于此人**可将其恢复为常规信息，归入**心得**、**事实**。
- 点击**移除**可将其从所有位置删除。

## 近期更改

人物、组织或项目的时间线上方有可折叠的**近期更改**区域，其中会列出你的 Machine 对其所做的更改或新学到的信息，例如关系、工作地点、两个人之间的关系、事实或项目动态。每项都会显示日期和来源；点击来源即可查看消息。

如果某项内容有误，点击旁边的**⋯**即可直接修正：选择**编辑**、**移除**、**并非关于此人**，或点击**撤销**将项目恢复原状。默认显示三项；点击**展开**可查看其余内容。

你的 Machine 今天更新过的人，会在“人员”列表中显示一个小圆点；列表顶部的**今天已更新 4 人**也会列出这些人。参见[Graph](graph.md)。

## 关于某人的待办

在人物、组织或项目的 **⋯** 菜单中点击**新建待办**，即可创建一项与其相关的待办。
