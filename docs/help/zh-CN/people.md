按亲近程度排列与你有联系的人，数据来自你的消息和会议。除非你回复，否则新闻邮件、收据和其他群发邮件不会添加联系人。它们会显示在列表下方的“已隐藏的发件人”中；点按“显示为联系人”即可将其添加进来。三个列表中的字段、标签和导入方式都相同，每个列表都有自己的筛选条件：请参阅[Graph](graph.md)。

共享收件箱（如 info@、客服邮箱或商店自用名称）归属于对应的组织，不算作联系人，即使你给它写过邮件也一样。

## 联系人页面

页面顶部会显示联系人的照片、姓名、职位、组织和所在地，以及一行联系情况（“每天交谈 · 昨天联系过 · 下次会议：10 月 27 日，周二”）。最近联系时间会显示为“刚刚”“3 小时前”“昨天”或“3 天前”；更早的联系会显示日期。将鼠标悬停在时间上可查看准确日期。下方会显示：

- **联系人**：联系人的电话号码和邮箱。点按其中一项即可拨打电话或发送消息，也可以点按**复制**。这里也会显示联系人的**生日**和来源（Google 联系人、Google Calendar、Facebook、你的笔记或你自己）：请参阅[Graph](graph.md#birthday)。
- **和你一起**：联系人与你的关系、是工作联系人还是个人联系人，以及他们是否属于你的家庭或 Fleet，并提供**在Fleet中查看**。
- **也在**：你与联系人交谈过的其他平台。点按**Slack**可在 Slack 中打开联系人，或打开你们最近的 Slack 话题。
- 联系人参与的**人员**和**项目**、**你们之间未关闭的**（双方的承诺，可**标记为已完成**或**放弃**），以及他们的**时间线**。

如果能确定某人的多个地址和聊天属于同一个人，系统会自动将它们合并，例如工作邮箱抄送了此人的私人地址。

如果页面显示**无法加载此页面。**，请点按**重试**。如果仍然如此，请点按页面底部的**遇到问题了？**。

## 摘要

摘要位于联系人页面顶部，由几行简短内容组成，列出已决定、询问、计划或承诺的事项，并写明相关人员。出现新内容时，The Machine 会为与你确实有联系的人重写摘要，并逐行检查。通常每天更新一次；如果与此人有关的事项发生变化，例如出现新的截止日期或撤回请求，则会在几小时内更新。

模糊不清的内容会被略过；如果没有具体内容可写，就不会显示摘要。每一行都会链接到对应来源：同一天的消息会合并显示为一个日期，并标注消息数量，点按后即可展开。

点按**编辑**，即可按自己的方式修改摘要。有新消息时，The Machine 会显示**建议的更新**，并提供**使用**和**保留我的**选项。点按**让The Machine来写**即可交由 The Machine 更新。

会议准备内容也会使用摘要，但只包含该待办对应一侧（工作或个人）的内容。摘要仅保存在你的 The Machine 上，团队看不到。

## 时间线

每个人和组织的页面都有时间线，按时间从新到旧排列，包含邮件、会议及其 Zoom 摘要、Intercom 对话（可点按**在Intercom中打开**）、WhatsApp、Telegram、Slack、LinkedIn 和 X 聊天、待办、承诺和项目动态。顶部的筛选项可一次显示一个来源。点按**展开**可加载更早的内容。

即将举行的会议会按时间先后显示在顶部的**即将开始**下方；点按**显示所有即将到来的内容**可查看其余会议。会议会显示参会者，每个人只列出一次。有笔记或文字记录的会议会标有**笔记**或**文字记录**；点按即可查看。

你的时间线只属于你：团队的 Graph 只会显示符合分享规则的内容。在页面的时间线上方点按**团队**可查看队友分享的内容，每项都会标明分享者；点按**我的**则只显示你自己的内容。

## 工作和个人

**工作**和**个人**标签页会根据联系人的类型列出联系人，类型显示在联系人页面上。你自己的选择（**编辑**）优先。如果你没有选择，属于你家庭或朋友的人，以及把你当作家人或朋友的人（例如妻子、父亲），无论他们使用什么地址，都归为个人联系人。团队看不到你的个人联系人。

## 添加联系人

点按“人员”顶部的**新建人员**，或在手机上点按顶部栏中的**+**。输入姓名；如果有，也可以填写邮箱和组织。如果 Graph 中已有类似联系人，表单会优先显示他们，你可以改为打开已有联系人。点按**添加**即可打开新联系人的页面。

添加的联系人会一直保留，即使还没有消息往来也一样。收到他们的第一条消息后，消息会与联系人关联。

## 编辑联系人

点按联系人页面顶部的**编辑**，可以修改姓名、职位、组织、所在地、LinkedIn、电话号码和邮箱、联系人与你的关系，以及工作或个人类型。**笔记**字段可用于记录你想记住的内容；合并联系人后，笔记仍会保留。点按**保存**以保留更改，或点按**取消**以放弃更改。

即使之后重新查找联系人的信息，或执行**合并**和**撤销**操作，你的修改也会保留。清空某个字段即可重新使用查找到的值。清空姓名后，会恢复为消息中显示的姓名。

要更改照片，请点按照片，然后选择**上传图片**、选用为此人找到的照片，或点按**移除图片**。照片会保存在你的 The Machine 上。

## 合并两个人

如果两个人可能是同一人，他们的页面会询问是否为同一人，“人员”列表也会在**是同一个人？**下列出他们。点按**合并**即可将他们合并，包括所有消息、笔记、角色和项目。点按**不一样**则会让他们始终保持分开。你的选择会短暂显示在这对联系人上，随后他们会从列表中移除。没有待确认的联系人后，列表也会消失。

如果某人的地址只是看起来与你认识的人的地址相似，例如 acme-corp.example 和 acmecorp.example，系统绝不会将他们推荐为同一人，而且只有你可以为他们指定角色。

共享地址（如 info@ 或邮件列表）绝不会与通过该地址联系的人合并。来自公司外部的工作联系人，以及仅仅名字相同的个人聊天联系人，不会自动合并，而是会作为待确认的问题列出。

点按**全部合并**可一次合并列表中的所有联系人对，但你标记为**不一样**的除外。之后立即点按**撤销**即可将他们全部拆分。

要手动合并两个人，先打开其中一人的页面，再点按**⋯**、**与……是同一个人**，然后选择另一个人。合并后的联系人页面会在**合并来源**下列出合并原因，并提供**撤销**选项以再次拆分。

## 永久删除联系人

打开联系人的页面，点按**⋯**菜单并选择**永久删除…**，然后点按**删除**。这会删除联系人以及你的 The Machine 知道的相关内容：联系人条目、地址、查找到的详细信息、仅在你们之间的消息，以及关于此人的笔记。

与此人有关的待办会保留，但会移除其姓名。此人不会再被添加回来，导入时不会添加，Facebook 生日待办中即使包含其姓名或地址也不会添加。此操作无法撤销。

## 退信

发给某人的邮件退回时，其地址旁会显示**已退信**和日期，其他已知地址会排在前面。如果已知另一个地址，新的草稿绝不会发往退信地址。如果这是对方唯一的地址，发送窗口会提醒你，但你仍然可以发送。

邮件服务器报告地址不存在时，或一周内出现 3 次临时发送失败后，系统会将邮件视为退信。如果对方再次从该地址给你发邮件，或你成功向该地址发送邮件，退信状态就会清除。

## 职位和照片

使用公司邮箱地址的联系人会显示查找到的职位、照片、LinkedIn 和城市，查找方式与[组织详情](organization-data.md)相同。在托管版 The Machine 上，查找时只会使用联系人的姓名和公司域名。Gravatar 会根据联系人的工作邮箱地址生成哈希值来查找照片，不会获取邮箱地址本身。要关闭此功能，请前往**设置**中的安全性，然后关闭**查找工作联系人**。

查找到联系人的信息后，其页面还会显示个人简介、他们开始担任当前职位的时间，以及此前的两个职位。会议准备内容也会使用这些信息；只有在联系人没有自己的简介时，才会使用个人简介。

你的连接会根据已读取的信息补充更多内容：Slack 中的职位、电话和时区，X 中的简介和所在地，LinkedIn 中的标题和照片，Google 联系人和 Salesflare 中的职位，以及 Salesflare 中联系人自己的照片。将鼠标悬停在姓名下方的那一行，即可查看信息来源。

Outlook 会添加你所在组织的同事和 Outlook 联系人的照片，还会添加联系人的职位和公司信息（[Microsoft](microsoft.md#photos-of-colleagues-and-contacts)）。

WhatsApp 和 Telegram 照片会通过 WhatsApp 同步和 Telegram 聊天连接导入：每个平台每天最多 50 张，且只针对 Graph 中已有的联系人。系统不会向这些联系人发送任何内容。导入 Facebook 生日时，保存待办后，会为没有照片的联系人添加个人头像（[例行程序](routines.md)）。所有内容都会保存在你的 The Machine 上。

在工作 Fleet 的[团队 Graph](team-graph.md)中，分享联系人的记录时会附带一张缩小版的工作照片。来自 Google 联系人、WhatsApp、Telegram 或 Facebook 的照片，以及你更改或移除的照片，都不会分享。

## 关于你

你自己的地址和号码（包括别名）始终属于你，不会被当作 Graph 中的联系人。搜索自己，或添加一个使用你地址的联系人时，系统会打开**关于你**；导入时也会跳过你自己的条目。

“关于你”会列出你的地址及各自的来源；如需更改，请前往**设置**中的“账户”。要向队友或朋友发送自己的联系方式，请点按**分享我的联系方式**。请参阅[分享联系人](share-contact.md)。

## 你与他们的关系

The Machine 会从消息中识别关系，并在联系人页面的**发给你**下方显示，同时附上识别到的原文。无需等待你确认。如果识别错了，可以在联系人页面点按**编辑**进行修正，也可以点按**近期更改**中对应条目旁的**⋯**。The Machine 会从你的修改中学习。

## The Machine 了解的联系人信息

联系人的事实会显示在其页面的**已知信息**下；通用事实会保存在**心得**中。点按**添加**即可用自己的话补充一条信息。每条事实都有一个菜单：

- 点按**编辑**可直接修改。
- 点按**与此人无关**可将其恢复为通用事实，并移至**心得**中的**事实**。
- 点按**移除**可将其彻底删除。

## 近期更改

联系人、组织或项目的时间线上方有一个可折叠的**近期更改**区域，其中列出你的 The Machine 对其进行的更改或学到的信息，例如角色、工作地点、两个人之间的关系、事实或项目动态。每项都会显示日期和来源；点按来源即可查看消息。

如果某项内容有误，点按旁边的**⋯**即可直接修正：选择**编辑**、**移除**、**与此人无关**，或点按**撤销**将项目恢复到之前的状态。默认显示三项；点按**展开**可查看其余内容。

今天有内容更新的联系人会在“人员”列表中显示一个小圆点，列表顶部的**今天已更新 4 位联系人**也会列出他们。请参阅[Graph](graph.md)。

## 关于某人的待办

打开联系人、组织或项目的**⋯**菜单，点按**新建待办**即可创建与其相关的待办。
