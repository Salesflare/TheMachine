The Machine 会读取所有新内容，只有需要你处理时才创建待办。无论一件事涉及多少条消息，都只创建一条待办。

## 待办位于哪里

**待办**页面会将待办分组：

- **刚刚完成**：位于顶部，显示你确认的最后一步是否已完成，例如表单或问题是否已处理。你离开期间完成的步骤会保留在这里，直到你点按**知道了**，最多保留一天，你的手机也会收到通知。
- **给你**：所有等待你处理的事项，按紧急程度排列。每条待办会标记为**已备好**（工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要先由你决定或回复）、**准备中…**（The Machine 正在处理）或**待读**（摘要或简报，无需做决定）。
- **等待其他人**：收起显示下一步由别人处理的待办（见下文）。
- **稍后回来**：已推迟的待办，以及没有回复**还需要吗？**的待办（见下文）。
- **承诺**：你承诺要做的事，以及别人对你的承诺。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按完成时间从新到旧排列，并显示完成时间，例如“5 分钟前完成”。看起来已经完成的待办会标记为**看起来已完成**。

发送后会显示一条简短提示，说明待办去了哪里，例如“已发送。已移至已完成。”或“已发送。已移至稍后处理，截止周一。”点按**打开**即可查看待办。你可以按标题或收件人搜索待办，也可以搜索稍后处理和已完成的待办。

**给你**会优先显示已逾期或明天截止的事项，然后是 Fleet 中的问题、看板的后续事项，最后是其他事项。同一组内按最新优先排列。The Machine 准备待办期间以及待办完成后，它在列表中的位置都不会改变，只有标记会变。其他未完成分组会优先显示已逾期或明天截止的事项，其余按最新优先排列。侧边栏中的顺序也相同。

**看起来已完成**表示 The Machine 发现事情已经办妥，例如“PR #3451 已合并”，但待办还没有关闭。点按**重新打开**可将它放回列表，The Machine 也会从中学习。这些待办不会显示为逾期。一天后，待办会自动关闭，并显示**撤销**。你已经自行处理的待办也会自动关闭，例如你已在 Gmail 或 Slack 中回复。

如果消息来自一个看起来像熟人的地址，例如 sam@acme-corp.example，而你认识的人使用的是 sam@acmecorp.example，待办会明确说明：“这不是 Sam Lee。”待办会显示对方自己的地址，而不是他们使用的名字。The Machine 会向你已有的联系人地址确认这类消息，不会联系发件人。

仍在等待别人处理的待办，例如等待审核或回复的事项，会显示**等待：**以及下一步。它会收起并显示在**等待其他人**中，位于“稍后回来”上方，直到有新消息让它重新出现。你向对方提问后也是如此：待办会在截止日期前一天早上重新出现；如果截止日期是当天稍后，则会在截止时间出现；如果截止时间已过，则会在第二天早上出现，并说明仍在等谁回复。

如果待办的目标是等待别人交付某项结果，例如签署合同，**详情**中会显示**完成条件**。发送你负责的内容并不会关闭待办：它会留在**等待其他人**中，直到有消息表明结果已交付，然后自动关闭，并显示**撤销**。如果到了该跟进的时间仍没有消息，待办会回到聊天中，并显示**写一条简短提醒**。要修改完成条件，请在聊天中告诉 The Machine。

如果一条待办一周都没人处理，The Machine 会询问一次：**还需要吗？**点按**不需要**会关闭待办，并显示**撤销**。点按**保留**会保留待办，此后不再询问。如果又过了一周仍未回复，待办会收起并移到“稍后回来”，应用图标上的数字和早间摘要也不再计入它。打开待办、发送聊天消息、编辑、稍后处理或收到新消息，都会让它重新出现。

每周最多会有 3 条待办，针对已经安静下来且没有未完成事项的项目，每条待办都会给出一个具体的下一步。请参阅[项目](projects.md)。

没有需要你处理的事项时，The Machine 会在空列表上休息。检查期间，它会醒来并告知你。如果检查失败或延迟，列表中的提示会说明情况，并显示**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**可切换显示所有待办或只显示其中一类。手机和电脑上的选择会保持一致。选中“工作”或“个人”时，点按**全部显示**即可返回。关于 The Machine 本身的提醒，例如某个组件不断重启，既不属于工作，也不属于个人，只会在“全部”中显示。

列表顶部的提示行也可以直接切换到另一类：在**仅个人**视图中，点按**工作**或**全部显示**即可。

列表顶部一行会显示最近的早间或晚间摘要名称，以及摘要统计的内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可再次查看摘要，也可以点按**复制**，将其粘贴到任意位置。打开摘要或点按其**×**后，摘要会在所有设备上保留，直到下一份摘要生成。

如果没有近期摘要，这里会显示**今天截至目前**：今天已完成和仍未完成的事项，显示工作和个人两类，或只显示筛选出的类别。

项目中的待办会在标题下显示项目名称。点按名称即可打开项目。点按**详情**下的**项目**可更改项目或移除项目。请参阅[项目待办](projects.md#a-project-s-to-dos)。

点按**详情**下的**区域**可将待办移到另一个区域。待办可读取和发送的内容也会随之改变。点按提示中的**撤销**可将它移回。

如果待办需要转到另一个区域才能继续，而且它关联的消息都在该区域，待办会自动移过去并继续处理。否则会显示**移至工作**，只有点按后才会移动。创建待办时没有选择工作或个人，待办会在找到所属区域后自动移过去。在此之前，它不会标记为工作或个人，并会保持私密。

待办始终可以读取它关联的消息。如果需要读取另一个区域中的其他消息，会询问你是否**将这封邮件用于此待办**。你标记为“个人”的工作邮箱也会归为个人。发给你其他公司的邮件会归入那家公司的待办；与你个人生活有关的待办，例如家人写信到你的工作地址，则从一开始就属于个人。

通过个人账户收到的工作事项，例如 WhatsApp 上的客户消息或个人邮箱中的订单，从一开始就属于工作。你自行移动或归类的待办会一直留在指定位置。“工作”或“个人”决定待办显示在哪里、与谁共享，而不会决定从哪里回复：回复始终会发到对话所在的位置，即使待办已移动也是如此，除非你选择其他方式。

这类个人待办仍会从收到邮件时使用的工作地址回复，也绝不会显示在工作 Fleet 或 Team Graph 中。

有两条或更多待办等待处理时，点按“给你”标题中的**逐项检查**，即可按列表顺序逐条处理。每条待办都会完整显示草稿，并提供**发送**或**执行**、**要求修改**、**稍后处理**和**跳过**。在电脑上，按 Enter 可发送当前内容，按 `S` 可推迟，按 `→` 可跳过，按 Esc 可停止。标题下方还会按你自己的节奏估算处理时间，例如“大约 2 分钟”。

需要你回答问题的待办不会包含在其中，因为它需要你的回复，而不是点按按钮。

## 立即检查

The Machine 每隔几分钟、昼夜不停地读取每个来源。收到 40 条消息，或某人的最早一条消息已等待 15 分钟时，The Machine 就会检查收到的内容。新闻邮件、通知和收据会在下一次检查时一并处理，最迟不超过一小时。

夜间 00:00 到 06:30 之间会暂停检查：新消息仍会被读取和保存，并在 06:30 一起检查，让待办在早间摘要前准备好。连接中的“检查”会显示“夜间暂停，将于 06:30 补查”。夜间打开应用、在聊天中发消息或点按待办后，检查会像往常一样恢复，直到你离开一小时为止。点按**立即检查**始终会马上检查。

点按**立即检查**会立刻读取所有来源。没有未完成待办时，点按 The Machine 的提示行即可查看状态，其中的**详情**会打开“连接”下的“检查”。有未完成待办时，电脑端会在列表顶部显示此项。只有检查正在运行、失败或延迟时，这里才会显示简短提示。你也可以在聊天中询问。

LinkedIn、X 和 Salesflare 按各自的节奏运行。

## 上次检查

读取新消息的检查完成后，待办列表上方会显示一行提示，说明从所有已读取来源中发现的内容，例如“已于 16:11 检查 13 条消息 · 无需你处理”或“· 2 条新待办”。如果有新待办要等到更合适的时间再显示，例如等到早间摘要，就会显示等待到什么时候：“1 条待办将保留到明天 08:30”。

点按提示行可查看每封邮件、聊天和通知，并显示其来源图标：发件人、主题或开头文字，以及新待办或无需处理的原因，例如“你只在抄送栏中，队友正在回复”或“会议已安排在周四”。如果检查只给出了模糊原因，对话就不会显示原因。点按任意一项即可阅读。

默认显示前 10 项，点按下方可查看其余内容。名字后的数字，例如 (3)，表示该聊天有多少条新消息。手机上关于已列出消息的通知只会显示一次。检查后，这行提示会保留 12 小时。

这里只统计发给你的邮件。The Machine 会读取你自己的回复以了解上下文和承诺，但不会将它们视为新邮件。The Machine 发给你的邮件，例如早间摘要或修复通知，从不会被读取或列出。有关账单、试用或邀请的邮件照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

点按**要求修改**可说明要修改什么：如何执行，或者草稿准备好后要修改草稿中的哪些内容。**标记为已完成**表示事情已处理：没有草稿的已备好待办会直接显示此按钮，其他待办则会在**…**菜单顶部显示，包括需要你决定的待办。点按后待办会立即从列表中移除，并在提示中显示**撤销**。向左滑动提示，或用鼠标将它拖走，可以更快关闭。所做的更改会保留。

要换一种方式处理，请在待办的**聊天**中说明。

在**…**菜单中：

- **正在转交……**：将待办交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请别人审核](ask-to-review.md)。
- **重复…**：待办会[按固定周期重新出现](recurring.md)。
- **不需要**：移除待办。你也可以选择原因：**无关**、**事实有误**或**已处理**。The Machine 会从中学习。

点按标题或**详情**下的**名称**可重命名待办。标题会保留。

点按**重新打开**可恢复已关闭的待办。有新情况时，例如收到对方的新消息，待办也会自动重新出现，但你自己发出的回复不会触发这一操作。

无论来自哪个国家，只要账单需要你亲自付款，都会变成一条待办，并包含金额、截止日期和账单提供的付款信息。自动付款的账单，例如直接扣款或已保存银行卡的账单，不会创建待办。之后的邮件表明账单已付时，例如发件人确认已收到付款，待办会自动关闭。**撤销**可以在一天内恢复待办。

如果一条待办只在某个时间之前有效，例如会议前需要确认的事项，过了该时间就会自动关闭。它会以“不再需要”的状态移至**已完成 / 已忽略**。**撤销**可以在一天内恢复待办。

在为某人发送消息或转交待办并将其标记为已备好之前，The Machine 会检查你与相关人员最近的聊天，包括群聊，并等待 Slack 读取这些消息。之后有新消息表明事情已经办妥时，例如对方被询问后答应了，待办就会自动关闭。**撤销**可以在一天内恢复待办。

较新的消息改变计划时，例如聚会换了地点或预订取消，The Machine 会自行更新相关待办。仍然需要处理的待办会按新计划更新。没有后续事项的待办会以“不需要”的状态移至**已完成 / 已忽略**，聊天中会说明“已更新：”及原因，并显示**撤销**，可以在一天内恢复待办。

首次查看待办时，会显示简短提示，介绍重要操作：**要求修改**和**不需要**，以及按下**发送**之前不会发送任何内容。使用提示中的按钮或按 × 后，提示就会永久消失。

使用的第一天，待办列表顶部会向你问候，并指出等你回复最久的人。系统会优先为这条回复起草内容，让你到达时就能直接处理。

每条待办都从标题开始。标题下方会显示相关人员、相关组织（只有确实与组织有关时才显示，不会仅仅因为某人在该组织工作就显示）、项目、工作或个人，以及收到时间。点按姓名可在 Graph 中打开对方的页面。

如果 Graph 中有照片或标志，姓名和组织就会显示对应图片，否则会显示姓名首字母。太小就无法辨认的标志，例如透明背景上的白色标志或宽幅文字标志，也会改为显示首字母。

有时会显示一条淡色提示，说明未知信息，例如“上次通过邮件联系是 12 天前，此后没有新消息。”如果最近一次联系时间较久，或对方尚未回复，就会显示此提示，并指出尚未连接的渠道，例如 WhatsApp。The Machine 会说明它不知道什么，而不会猜测。

如果提示中提到尚未连接的渠道，点按旁边的**连接**即可连接该渠道。

标题会说明需要做什么，只有待办内容变化时才会更新。已完成的待办会保留原来的标题，并在下方说明完成方式，例如“已完成：Sam 于周二签署”。

草稿上方的淡色提示会显示它来自哪条消息，并带有相应服务的标志。点按即可查看对话。草稿会显示发送渠道的标志，让你一眼看出这是 Slack 回复还是邮件。

如果草稿参考了其他地方的输入，例如队友在 Slack 中的建议，提示行会说明这一点，例如“根据 Sam 在 #ops 中的消息”。点按即可查看该消息。

聊天（Slack、WhatsApp、Telegram、Intercom 等）会按时间顺序显示为一段对话：包括待办关联消息之前的内容，以及之后的回复。在 WhatsApp、Telegram 或 Signal 中，你发出的消息会像应用里一样显示在右侧。待办关联的消息会标记为“此待办”，并在视图中打开。点按**显示更早的内容**可加载更早的消息。邮件会将同一邮件线程的其余内容收起，显示在邮件上方和下方。

邮件的**详情**只会显示邮件标题栏中没有的信息，例如完整的抄送地址、密送地址或不同的回复地址；没有其他信息时则不会显示。

Slack 线程中的回复还会显示线程开始前的内容。待办中指向相关消息的链接也会在这里打开，并在底部显示**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你最近的备注，以及编程助手的结果。点按标题可打开聊天。已完成的待办会保持简洁；关联消息会显示在**详情**中。

“等待”类待办会链接到你发给对方的最后一条消息，也就是你正在等待回复的那条消息，例如“给 Pat 的邮件 · 周二”。

## 自己创建待办

点按电脑端**搜索**下方的**新建待办**、手机上的**+**或 `N`，即可为任何事情创建待办。创建待办不会发送任何内容。如果没有选择**工作**或**个人**，待办会根据相关人员和事项自动归类。它也会找到待办所跟进的邮件，即使邮件较早也能找到。

- **截止**：可以用文字输入日期或时间，例如“明天”“下周五”“11 月 3 日”“下午 2 点”或“2 小时后”，也支持你的语言。日历图标中有快捷选项和**选择日期**。
- **重复频率**：待办会按固定周期重新出现。请参阅[定期待办](recurring.md)。
- **人员**：关联相关人员或公司，最多 5 个。
- 消息图标：关联相关消息，可以是邮件、Slack、Teams、WhatsApp、Telegram 或 The Machine 中的其他消息。可以按文字或发件人搜索。每条结果都会显示来源、发件人和时间。
- **文件**：点按回形针、粘贴截图，或将文件拖到表单中。在手机上，点按旁边的相机即可拍照。最多可添加 5 个文件，与聊天中的限制相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 可移除文件。

文件会保留在待办中，The Machine 处理待办时会读取这些文件。只添加文件也可以：The Machine 会根据 PDF 或文本文件填写待办内容。照片会显示为小图，点按即可查看原图。
