你的 The Machine 会阅读所有新消息，只有在需要你处理时才创建待办。每件事只创建一条待办，不管涉及多少条消息。

## 待办在哪里

**待办**页面会将待办分组：

- **刚刚完成**：位于顶部，显示你离开期间完成的最后一步，例如提交表单或处理问题。最多保留一天，直到你点按**知道了**，手机上也会收到通知。
- **给你**：所有等你处理的事项，按紧急程度排序。每条待办都会标注**已备好**（工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要你先做决定或回复）、**准备中…**（你的 The Machine 正在处理）或**待读**（摘要或简报，不需要做决定）。
- **等待其他人**：折叠显示下一步要由其他人完成的待办（见下文）。
- **稍后回来**：已推迟的待办，以及没有回复**还需要吗？**的待办（见下文）。
- **承诺**：你承诺要做的事，以及别人对你的承诺。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按完成时间从新到旧排列，并显示完成时间，例如“5 分钟前已完成”。看起来已经完成的待办会标记为**看起来已完成**。

发送后，会显示一条简短提示，说明待办去了哪里，例如“已发送。已移至已完成。”或“已发送。已移至稍后处理，直到周一。”点按**打开**即可查看待办。搜索可以按待办标题或收件人查找，也能找到稍后处理和已完成的待办。

**给你**会优先显示已逾期或明天到期的事项，然后是 Fleet 中的问题，再然后是看板中的跟进事项，最后是其他事项。每组内按最新优先排列。待办在 The Machine 准备期间以及完成后都会留在原位，只有标记会变化。其他未完成分组会优先显示已逾期或明天到期的事项，其余按最新优先排列。侧边栏也会保持相同顺序。

**看起来已完成**表示 The Machine 认为待办已经完成，例如“PR #3451 已合并”，但待办还没有关闭。点按**重新打开**可将待办放回列表，The Machine 也会从中学习。这些待办不会显示为逾期。一天后，它会自动关闭，并提供**撤销**。如果你已经自行处理了待办，例如在 Gmail 或 Slack 中回复，待办也会自动关闭。

如果消息来自一个看起来像你认识的人、实际却不同的地址，例如 sam@acme-corp.example 冒充 sam@acmecorp.example，待办会明确说明：“这不是 Sam Lee。”显示时会使用对方的实际地址，而不是对方使用的姓名。The Machine 会向你已有的地址对应的人核实这类消息，而不会联系发件人。

如果待办在等其他人处理，例如等待审核或回复，就会显示**等待：**以及对应的步骤。它会折叠显示在**等待其他人**分组中，位于“稍后回来”上方，直到有新消息将它重新带回。如果你反过来向对方提了问题，也会如此：待办会在截止日期前一天早上重新出现；如果截止日期是今天稍晚，则会在截止时间重新出现；如果截止时间已过，则会在第二天早上重新出现，并说明还在等谁回复。

如果待办的目标是等待其他人交付结果，例如签署合同，**详情**中会将目标显示为**完成条件**。发送你这边的内容不会关闭待办：待办会留在**等待其他人**中，直到有消息表明结果已交付，然后自动关闭，并提供**撤销**。如果到了该催促对方的时间仍没有消息，待办会重新出现，并在聊天中提供**写一条简短提醒**。要修改完成条件，可以在聊天中说明什么才算完成。

如果一条待办一周都无人处理，它会询问一次：**还需要吗？**点按**不需要**即可关闭，并提供**撤销**。点按**保留**会保留待办，之后不会再询问。如果再过一周仍没有回复，待办会折叠到“稍后回来”中，应用图标上的数字和早间摘要也不再统计它。打开待办、发送聊天消息、编辑、推迟或收到新消息，都会让它重新出现。

每周最多有三个安静了一段时间且没有未完成事项的项目会收到一条待办，内容是一个明确的下一步。请参阅[项目](projects.md)。

没有需要你处理的事情时，The Machine 会休眠，列表为空。检查期间，它会唤醒并说明情况。如果检查失败或延迟，状态行会显示原因，并在下方提供**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**可以显示所有待办，或只显示其中一类。手机和电脑上的选择会保持一致。选择“工作”或“个人”时，点按**全部显示**即可返回。如果是关于 The Machine 本身的提醒，例如某个组件一直在重启，它既不属于工作，也不属于个人，只会显示在“全部”中。

列表顶部的状态行也能直接切换到另一种筛选：在**仅个人**下，点按**工作**或**全部显示**。

列表顶部的行会显示最近一份早间或晚间摘要的名称和统计内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可重新阅读该摘要，也可以点按**复制**，将其粘贴到任何地方。打开摘要或点按其中的 **×** 后，摘要会在所有设备上保留，直到下一份摘要生成。

如果没有近期摘要，这里会显示**今天截至目前**：今天已完成和仍未完成的工作与个人待办，或者你筛选的那一类待办。

项目待办的标题下方会显示项目名称。点按即可打开项目。在**详情**下点按**项目**可以更改项目或移除项目关联。请参阅[项目待办](projects.md#a-project-s-to-dos)。

在**详情**下点按**区域**，可以将待办移到另一个区域。待办可读取和发送内容的范围也会随之改变。点按提示中的**撤销**即可移回。

如果待办需要转到另一个区域才能继续，且相关消息都在那个区域，它会自动移过去并继续处理。否则会显示**移至工作**，只有点按后才会移动。如果你新建待办时没有选择“工作”或“个人”，它会在找到所属区域后自动移动。在此之前，它不会标记为工作或个人，并会保持私密。

待办始终可以读取相关消息。如果需要读取你另一个区域中的其他消息，会显示**将这封邮件用于此待办**。如果你把工作邮箱标记为个人邮箱，它就会被视为个人邮箱。其他公司的邮件会进入对应公司的待办；关于你个人生活的待办，例如家人发到你工作地址的邮件，从一开始就属于个人。

如果工作内容发到了个人账户，例如客户通过 WhatsApp 联系你，或订单发到了个人邮箱，从一开始就属于工作。你亲自移动或归类的待办会一直留在所选位置。“工作”或“个人”决定待办显示在哪里、与谁共享，但不会改变回复发往哪里：回复始终会发回原对话所在的位置，即使待办已移动也是如此，除非你另选回复方式。

这样的个人待办仍会使用邮件原本发往的工作地址回复，也不会出现在工作 Fleet 或 Team Graph 中。

如果有两条或更多待办等待处理，点按“给你”标题中的**逐项检查**，即可按列表顺序逐条查看，并显示每条待办的完整草稿，以及**发送**或**执行**、**要求修改**、**稍后处理**和**跳过**选项。在电脑上，按 Enter 会发送当前内容，按 `S` 会推迟，按 `→` 会跳过，按 Esc 会停止。标题下方还会显示按你自己的节奏处理这些待办所需的时间，例如“约 2 分钟”。

需要你回答问题的待办不会包含在其中：它需要你的回答，而不是点按按钮。

## 立即检查

你的 The Machine 每隔几分钟、昼夜不停地读取每个信息来源。收到 40 条消息，或来自某人的最早一条消息等待 15 分钟后，就会检查新内容。新闻简报、通知和收据会在下一轮检查中处理，最迟不超过一小时。

夜间 00:00 至 06:30 会暂停检查：新消息仍会被读取和保存，并在 06:30 一并检查，让待办在早间摘要前准备好。连接中的检查状态会显示“夜间暂停，06:30 继续处理”。夜间只要你在应用中点击、输入或滚动，在聊天中发送消息，或点按待办，检查就会照常运行，直到你离开一小时。点按**立即检查**始终会立刻检查。

**立即检查**会立即读取所有信息来源。如果没有未完成待办，点按 The Machine 的状态行即可查看状态，其中的**详情**会打开连接中的“检查”页面。如果有未完成待办，电脑上会在顶部显示此选项。只有检查正在进行、失败或延迟时，才会显示简短状态行。你也可以在聊天中提出要求。

LinkedIn、X 和 Salesflare 会按各自的频率运行。

## 上次检查

检查读取了新消息后，待办上方会显示一行摘要，列出读取的所有信息来源中的检查结果，例如“16:11 检查了 13 条消息 · 无需你处理”或“· 2 条新待办”。如果新待办要等到更合适的时间处理，例如早间摘要时，就会显示等待截止时间：“1 条待办保留到明天 08:30”。

点按这行内容，即可查看每封邮件、每段聊天和每条通知，并带有来源图标。每项会显示发件人、主题或开头文字，以及新待办，或无需处理的原因，例如“只抄送了你，队友正在回复”或“会议已安排在周四”。如果检查只得出了模糊的原因，对话中就不会显示原因。点按任意一项即可阅读。

首先显示前 10 项，点按下方即可查看其余内容。姓名后的数字，例如 (3)，表示该聊天中的新消息数量。手机上已列出的消息通知只会显示一次。这行内容会在检查后保留 12 小时。

这里只统计发给你的邮件。你的回复会作为上下文和承诺来读取，但不会计为新邮件。The Machine 发给你的邮件，例如早间摘要或修复通知，绝不会被读取或列出。账单、试用期或邀请相关邮件仍会照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

**要求修改**会说明需要改什么：可以修改处理方式；草稿准备好后，也可以修改草稿内容。**标记为已完成**表示待办已处理：没有草稿的待办准备好后会直接显示这个选项，其他情况则会放在**…**菜单顶部，包括需要你做决定的待办。待办会立即从列表中移除，并在提示中提供**撤销**。将提示向左滑动，或用鼠标将其拖走，也可以更快关闭。更改会保留。

如果想换一种方式处理，可以在待办的**聊天**中说明。

在**…**菜单下：

- **正在转交……**：将待办交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请人审核](ask-to-review.md)。
- **重复…**：待办会[按固定周期重新出现](recurring.md)。
- **不需要**：移除待办。你也可以选择原因：**无关**、**事实有误**或**已处理**。The Machine 会从中学习。

点按标题，或在**详情**下点按**名称**，即可重命名。标题会保留你输入的内容。

点按**重新打开**即可恢复已关闭的待办。有新情况时，例如对方发来新消息，待办也会自动重新出现，但你自己的回复不会触发重新出现。

任何国家的账单，只要还需要你亲自付款，就会成为一条待办，并包含账单上的金额、截止日期和付款信息。自动付款的账单，例如自动扣款或已绑定卡片的账单，不会创建待办。之后的邮件显示账单已付清时，例如发件人确认已收到付款，待办会自动关闭。点按**撤销**可在一天内恢复。

如果待办只在特定时间之前有用，例如会议前需要确认，它会在该时间过后自动关闭，并移至**已完成 / 已忽略**，标记为“不再需要”。点按**撤销**可在一天内恢复。

在为他人准备消息或转交待办之前，The Machine 会检查你最近与相关人员的聊天，包括群聊，并等待 Slack 读取这些聊天。如果之后的消息表明事情已经完成，例如对方收到请求并答应了，待办会自动关闭。点按**撤销**可在一天内恢复。

有新消息改变计划时，例如聚会改到另一个地点，或预订被取消，The Machine 会自动更新相关待办。仍然需要处理的待办会按新计划更新。已没有后续事项的待办会移至**已完成 / 已忽略**，标记为“不需要”，并在聊天中说明“已更新：”以及原因。点按**撤销**可在一天内恢复。

第一次使用待办时，会显示简短提示，介绍关键操作：**要求修改**和**不需要**，并说明只有按下**发送**后，内容才会发出去。使用提示中的按钮或按下 × 后，提示就会永久消失。

第一天使用时，待办顶部会向你问候，并告诉你谁等你的回复等得最久。它的回复会优先起草好，让你一打开就能发送。

每条待办都以标题开头。标题下方会显示相关人员、相关组织（只有事情确实与该组织有关时才显示，不会只因为某人在那里工作就显示）、项目、“工作”或“个人”，以及待办的创建时间。点按姓名即可在 Graph 中打开对方的页面。

如果 Graph 中有头像或标志，姓名和组织旁会显示对应图片，否则显示姓名首字母。如果标志缩小后难以辨认，例如透明背景上的白色标志或横向文字标志，也会改为显示首字母。

有时会显示一行淡色文字，说明尚不清楚的信息，例如“12 天前通过邮件联系过；之后没有新消息”。如果最近一次联系已久或尚未得到回复，就会显示此提示，并标出尚未连接的渠道，例如 WhatsApp。The Machine 会说明自己不知道什么，而不是猜测。

如果提到了尚未连接的渠道，点按旁边的**连接**即可打开该连接。

标题会说明需要做什么，只有事项本身发生变化时才会更改。已完成的待办会保留原来的标题，并在下方说明完成方式，例如“已完成：Sam 周二签署了文件”。

草稿上方会用一行浅色文字显示关联消息，并带有对应服务的标志。点按即可阅读对话。草稿会显示发送目标的标志，让你一眼看出这是 Slack 回复还是邮件。

如果草稿是根据其他地方某人的意见撰写的，例如队友在 Slack 中提出的建议，会显示一行说明，例如“根据 Sam 在 #ops 中的消息”。点按即可阅读那条消息。

聊天（Slack、WhatsApp、Telegram、Intercom 等）会按时间顺序显示为一段对话：先显示待办所涉消息之前的内容，再显示之后的回复。在 WhatsApp、Telegram 或 Signal 中，你的消息会像应用中一样显示在右侧。待办所涉消息会标记为“此待办”，并自动显示在视野中。点按**显示更早的内容**可加载更早的消息。邮件则会将同一邮件会话中的其他内容折叠显示在上方和下方。

邮件的**详情**只显示邮件标题中没有的信息，例如完整的抄送地址、密送地址或不同的回复地址；如果没有额外信息，就不会显示详情。

Slack 线程中的回复也会显示线程开始前的内容。待办关联到自身消息时，也会在此处打开，并在底部显示**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你的上条备注，以及编程代理的处理结果。点按标题可打开聊天。已完成的待办会保持简短，相关消息会显示在**详情**下。

“等待”待办会链接到你发给对方的最后一条消息，也就是你正在等对方回复的那条，例如“发给 Pat 的邮件 · 周二”。

## 自己新建待办

点按**新建待办**（电脑上位于**搜索**下方，手机上点按 **+**，或按 `N`），即可为任何事项新建待办。创建待办不会发送任何内容。如果没有选择**工作**或**个人**，待办会根据对象和事项自动归入合适的区域。它还会找到待办所跟进的邮件，即使邮件较早也可以。

- **截止**：输入日期或时间，例如“明天”“下周五”“11 月 3 日”“下午 2 点”或“2 小时后”，也可以使用自己的语言。日历图标中有快捷选项和**选择日期**。
- **重复频率**：设置待办按固定周期重新出现。请参阅[周期性待办](recurring.md)。
- **人员**：关联与待办相关的人或公司，最多 5 个。
- 消息图标：关联相关消息，可以是邮件、Slack、Teams、WhatsApp、Telegram 或 The Machine 中的其他消息。可以按文字或发件人搜索。每条搜索结果都会显示来源、发件人和时间。
- **文件**：点按回形针，粘贴截图，或将文件拖到表单中。手机上可以点按旁边的相机拍照。最多添加 5 个文件，和聊天中的数量相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 可移除文件。

文件会保留在待办中，The Machine 处理待办时会读取文件。只添加文件也可以：它会根据 PDF 或文本文件填写待办内容。照片会显示为缩略图，点按即可查看原图。
