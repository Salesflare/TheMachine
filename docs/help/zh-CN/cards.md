你的 Machine 会读取所有新内容，只有在有事需要你处理时才创建待办。无论一件事涉及多少条消息，都只创建一个待办。

## 待办的位置

**待办**页面会将待办分组：

- **刚刚完成**：位于顶部，显示你确认过的最后一步，例如表单或问题，在你离开期间已完成。此项会保留，直到你点按**知道了**，最长一天，你的手机也会收到通知。
- **给你**：所有等待你处理的事项，按紧急程度排序。每项会显示**已备好**（准备工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要先由你决定或回复）、**准备中…**（你的 Machine 正在处理）或**待读**（摘要或简报，无需做决定）。
- **更早**：收起一周内没有新进展的待办（见下文）。
- **等待其他人**：收起下一步要由其他人处理的待办（见下文）。
- **稍后回来**：已推迟的待办，以及尚未回答**还需要吗？**的待办（见下文）。
- **承诺**：你作出的承诺，以及其他人对你的承诺。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按最新完成时间排序，并显示完成时间，例如“5 分钟前已完成”。看起来已经完成的待办会标记为**看起来已完成**。

发送后，系统会简短说明待办去了哪里，例如“已发送。已移至已完成。”或“已发送。已移至稍后处理，截止时间为周一。”如果回复只是承诺会完成工作，例如“我会在周二前发给你”，待办仍会保持开启状态：“已发送。仍保持开启。”点按**打开**即可查看待办。搜索可以按标题或收件人查找待办，也能搜索稍后处理和已完成的待办。

**给你**会优先显示已逾期或明天到期的事项，然后是来自 Fleet 的问题、看板的后续事项，最后是其他事项。每组内按最新优先排序。你的 Machine 准备待办期间以及待办完成后，它在列表中的位置不变，只有标记会变化。其他未完成分组会优先显示已逾期或明天到期的事项，其余按最新优先排序。侧边栏也使用相同的顺序。

**看起来已完成**表示你的 Machine 判断事情已经完成，例如“PR #3451 已合并”，但待办尚未关闭。点按**重新打开**会将它放回列表，你的 Machine 也会从中学习。这些待办不会显示为逾期。一天后，待办会自动关闭，并提供**撤销**。如果你已经自行处理了待办，例如在 Gmail 或 Slack 中回复，它也会自动关闭。

如果消息来自一个看起来像你认识的人、但实际不同的地址，例如 sam@acme-corp.example，而你认识的人是 sam@acmecorp.example，待办会明确说明：“这不是 Sam Lee。”系统会使用对方自己的地址显示此人，而不会使用其自称的姓名。你的 Machine 会向你已有的地址所对应的人核实此类消息，而不会联系发信人。

仍在等待他人处理的待办，例如等待审核或回复的事项，会显示**等待：**以及等待的步骤。它会收起在**等待其他人**分组中，位于“稍后回来”上方，直到有新消息让它重新出现。你向对方提问后也一样：待办会在截止日期前一天早上重新出现；如果截止日期是今天，则会在截止时间重新出现；如果截止日期已过，则会在第二天早上重新出现，并注明仍在等待谁。

如果待办需要等待其他人交付结果，例如签署合同，**详情**会将其标记为**完成条件**。发送你负责的内容不会关闭待办：它会留在**等待其他人**分组，直到有消息表明结果已交付，然后自动关闭，并提供**撤销**。如果到了该跟进的时间仍没有消息，待办会重新出现，并在聊天中显示**写一条简短提醒**。要修改完成条件，请在聊天中说明什么才算完成。

一周没有新进展的待办会从“给你”移至**更早**，这样你离开几天后回来时，新事项会优先显示。“没有新进展”是指没有关于它的新消息，你也没有对它进行任何操作，例如发送聊天消息、编辑或推迟。仅仅打开查看不算。

紧急事项、即将到期的事项和正在发送的事项会留在“给你”。点按**全部忽略**并确认一次，即可将“更早”中的所有待办标记为不需要；逐项处理时则可点按**不需要**。两种操作都提供**撤销**。有新进展的待办会回到“给你”。

一周无人处理的待办会询问一次：**还需要吗？**点按**不需要**会关闭待办，并提供**撤销**。点按**保留**会保留待办，系统也不会再询问。如果又过了一周仍未回答，待办会收起到“稍后回来”，应用图标上的数量和早间摘要也不再计入它。打开待办、发送聊天消息、编辑、推迟或收到新消息，都会让它重新出现。

每周，对于已安静下来且没有未完成事项的项目，系统最多会创建三个待办，每个待办都包含一个明确的下一步。请参阅[项目](projects.md)。

没有需要你处理的事项时，你的 Machine 会在空列表中休息。检查期间，它会唤醒并告知你。如果检查失败或延迟，列表中会显示原因，并提供**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**可以显示所有待办，或只显示其中一类。手机和电脑会使用相同的选择。选中“工作”或“个人”时，点按**全部显示**即可返回。关于你的 Machine 本身的提醒，例如某个部件不断重启，不属于工作或个人，只会显示在“全部”中。

列表顶部的提示也可以直接切换到另一类：在**仅个人**视图下，点按**工作**或**全部显示**。

列表顶部的行会显示最近一次早间或晚间摘要的名称和统计内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可再次阅读该摘要，也可以点按**复制**，将内容粘贴到任意位置。打开摘要或点按其**×**后，摘要会在所有设备上保留，直到下次摘要生成。

如果没有近期摘要，这里会显示**今天截至目前**：今天已完成和仍未完成的事项，包含工作和个人，或仅显示你筛选的类别。

项目待办会在标题下方显示项目名称。点按名称即可打开项目。在**详情**中点按**项目**可以更改项目或移除项目。请参阅[项目待办](projects.md#a-project-s-to-dos)。

在**详情**中点按**区域**，可将待办移至另一个区域。待办可以读取和发送的内容也会随之改变。点按提示中的**撤销**即可移回原处。

如果待办需要转到你的另一个区域才能继续处理，而且相关消息都在该区域，它会自动移过去并继续处理。否则会显示**移至工作**，点按之前不会移动。你创建待办时如果没有选择工作或个人，它会在找到所属类别后自动移动。在此之前，它不会标记为工作或个人，并且会保持私密。

待办始终可以读取与之相关的消息。如果需要读取你另一个区域中的其他消息，它会询问是否**将这封邮件用于此待办**。你标记为“个人”的工作邮箱会视为个人邮箱。发往你其他公司的邮件会进入该公司的待办；与你个人生活有关的待办，例如家人发到你工作地址的邮件，从一开始就属于个人。

通过个人账户联系你的工作事项，例如客户在 WhatsApp 上联系你，或订单发到你的个人邮箱，从一开始就属于工作。你亲自移动或归类的待办会始终留在指定位置。“工作”或“个人”决定待办显示在哪里，以及与谁共享，但不会决定回复发往哪里：回复始终会发送到对话所在的位置，即使待办已移动也是如此，除非你选择其他方式。

这类个人待办仍会从收到邮件时使用的工作地址回复，也绝不会出现在工作 Fleet 或团队 Graph 中。

有两个或更多待办等待处理时，点按“给你”标题中的**逐项检查**，即可按列表顺序逐一查看。每项都会显示完整草稿，并提供**发送**或**执行**、**要求修改**、**稍后处理**和**跳过**。在电脑上，按 Enter 发送当前内容，按 `S` 推迟，按 `→` 跳过，按 Esc 停止。标题下方还会按你的节奏估算处理时间，例如“大约 2 分钟”。

需要你回答问题的待办不会列入这两组，因为它需要你的回答，而不是点按操作。

## 立即检查

你的 Machine 每隔几分钟昼夜不停地读取各个来源。当有 40 条待处理消息，或来自某人的最早一条消息已等待 15 分钟时，它会检查收到的内容。新闻简报、通知和收据会在下一次检查时一并处理，最迟不超过一小时。

夜间 00:00 至 06:30 会暂停检查：新消息仍会被读取和保存，并在 06:30 一并检查，确保早间摘要生成前待办已准备好。**连接**中的检查状态会显示“夜间暂停，06:30 继续处理”。夜间在应用中点按、输入或滚动，在聊天中发送消息，或点按待办，检查就会照常运行，直到你离开一小时。点按**立即检查**始终会立刻检查。

**立即检查**会立刻读取所有来源。没有未完成事项时，点按你的 Machine 所在行即可查看状态和**详情**；点按**详情**会打开**连接**中的“检查”。有未完成待办时，电脑端的**立即检查**会显示在顶部。检查正在运行、失败或延迟时，那里才会显示简短提示。你也可以在聊天中询问。

LinkedIn、X 和 Salesflare 按各自的节奏运行。

## 上次检查

检查并读取新消息后，待办列表上方会显示一行提示，汇总所有已检查来源的结果，例如“已检查 13 条消息，时间 16:11 · 没有需要你处理的事项”或“· 2 个新待办”。如果新待办会等到更合适的时间处理，例如等到早间摘要，它会注明等待到什么时候：“1 个待办将保留至明天 08:30”。

点按提示行可查看每封邮件、聊天和通知，并显示其来源图标、发件人、主题或开头，以及对应的新待办，或无需处理的原因，例如“仅抄送，队友正在回复”或“会议已定在周四”。如果检查只给出模糊原因，消息旁边不会显示原因。点按消息即可阅读。

最初会显示前 10 条，点按下方即可查看其余内容。姓名后的数字，例如 (3)，表示该聊天中有多少条新消息。关于已列出消息的手机通知只会显示一次。检查完成后，这行提示会保留 12 小时。

这里只统计发给你的邮件。系统会读取你自己的回复以了解上下文和承诺，但不会将其视为新邮件。The Machine 发给你的邮件，例如早间摘要或修复通知，不会被读取或列出。关于账单、试用期或邀请的邮件照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

点按**要求修改**并说明要改什么：可以说明如何处理，也可以在草稿准备好后说明要修改草稿的哪些内容。**标记为已完成**表示事情已处理：没有草稿的已备好待办会直接显示此按钮，其他情况则可在**…**菜单顶部找到，包括需要你决定的待办。待办会立即从列表中移除，并在提示中提供**撤销**。将消息滑走，或用鼠标将其拖出，也可以更快关闭。所做的更改会保留。

如果想换一种方式处理，请在待办的**聊天**中说明。

在**…**菜单中：

- **转交…**：交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请人审核](ask-to-review.md)。
- **重复…**：待办会[按固定节奏重新出现](recurring.md)。
- **不需要**：将待办移除。你可以选择原因：**无关**、**事实有误**或**已处理**。你的 Machine 会从中学习。

点按标题或**详情**中的**名称**即可重命名，也可以在聊天中提出要求，例如“将名称改为……”。标题会保留。

点按**重新打开**即可恢复已关闭的待办。有新情况时，例如对方发来新消息，待办也会自动重新出现，但你自己的回复不会触发此操作。待办会显示重新出现的时间，并按新事项排序。即使过了几周，聊天也会从之前的位置继续。

任何国家的账单，只要仍需你亲自付款，就会生成一个待办，其中包含金额、截止日期和账单提供的付款信息。自动扣款的账单，例如直接借记或已登记银行卡付款，则不会生成待办。如果之后的邮件显示已付款，例如发件人确认已收到款项，待办会自动关闭。你可以在一天内点按**撤销**恢复。

如果待办只在某个时间之前有效，例如会议前需要确认，它会在该时间过后自动关闭，并以“不再需要”的状态移至**已完成 / 已忽略**。你可以在一天内点按**撤销**恢复。

在将涉及其他人的消息或转交标记为已备好之前，你的 Machine 会检查你与相关人员最近的聊天，也包括群聊，并等待 Slack 读取消息。如果之后的消息表明事情已完成，例如对方已被询问并答应了，待办会自动关闭。你可以在一天内点按**撤销**恢复。

如果较新的消息改变了计划，例如聚会换了地点或预订取消，The Machine 会自动更新待办。仍然需要处理的待办会根据新计划调整。无需再处理的待办会以“不需要”的状态移至**已完成 / 已忽略**，聊天中会说明“已更新：”及原因。你可以在一天内点按**撤销**恢复。

首次使用待办时，系统会显示简短提示，介绍关键操作：**要求修改**和**不需要**，并说明按下**发送**之前不会发送任何内容。使用提示中的按钮或按下 × 后，提示就会永久消失。

第一天使用时，“待办”顶部会向你问候，并指出等待你回复最久的人。系统会优先为这封回复起草内容，让你到达时就能直接使用。

每个待办都以标题开头。标题下方会显示相关人员、涉及的组织（仅在确实与组织有关时显示，不会只因为某人在那里工作就显示）、项目、工作或个人类别，以及收到时间。点按姓名即可在 Graph 中打开对方的页面。

如果 Graph 中有人物或组织的照片或标志，就会显示照片或标志，否则显示姓名首字母。尺寸太小而无法辨认的标志，例如透明背景上的白色标志或宽幅文字标志，也会改为显示首字母。

有时会用一行较淡的文字说明尚不清楚的信息，例如“12 天前通过邮件联系，之后没有消息”。如果上次与对方联系已久或仍未得到回复，就会显示这行文字，也会指出尚未连接的渠道，例如 WhatsApp。你的 Machine 会说明它不知道什么，而不是猜测。

如果提示中提到尚未连接的渠道，点按旁边的“连接”即可打开该连接。

标题会说明需要做什么，只有待办内容变化时才会更改。已完成的待办会保留标题，并在下方说明完成方式，例如“已完成：Sam 于周二签署”。

草稿上方较淡的一行会标出草稿所对应的消息，并显示该服务的标志。点按即可阅读对话。草稿会显示发送渠道的标志，因此你能立即看出它是 Slack 回复还是邮件。

如果草稿参考了其他地方某人的意见，例如队友在 Slack 中的建议，系统会用一行文字说明，例如“依据 #ops 中 Sam 的意见”。点按即可阅读该消息。

聊天（Slack、WhatsApp、Telegram、Intercom……）会按时间顺序显示为一段对话：先显示待办所涉及消息之前的内容，再显示之后的回复。在 WhatsApp、Telegram 或 Signal 中，你的消息会像应用里一样显示在右侧。待办对应的消息会标记为“此待办”，并自动显示在视野中。点按**显示更早的内容**即可添加较早的消息。邮件会将同一邮件串的其他内容收起在邮件上方和下方。

点按**在Gmail中打开**，即可在收到邮件的 Gmail 账号中打开邮件。在 Android 上，如果已安装 Gmail 应用，邮件会在该应用中打开。

邮件的**详情**只显示邮件头中没有的信息，例如完整的抄送地址、密送地址或不同的回复地址。如果没有其他信息可补充，就不会显示详情。

Slack 线程中的回复也会显示线程开始前的内容。待办中指向其对应消息的链接也会在这里打开该消息，页面底部还有**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你最近留下的备注，以及编码代理的结果。点按标题即可打开聊天。已完成的待办会保持简洁；待办对应的消息可在**详情**中查看。

“等待”的待办会链接到你发给对方的最后一条消息，也就是你正在等待回复的那条，例如“发给 Pat 的邮件 · 周二”。

## 自己创建待办

点按**新建待办**（电脑端位于**搜索**下方，手机端为**+**，也可以按 `N`），即可为任何事情创建待办。创建待办不会发送任何内容。如果没有选择**工作**或**个人**，系统会根据对象和事项内容自动归类。它也会找到待办对应的邮件，包括较早的邮件。

- **截止**：输入日期或时间，例如“明天”“下周五”“11 月 3 日”“下午 2 点”或“2 小时后”，也可以使用你的语言输入。点按日历图标可选择快捷日期或**选择日期**。
- **重复频率**：待办会按固定节奏重新出现。请参阅[重复待办](recurring.md)。
- **人员**：关联相关人员或公司，最多 5 个。
- 消息图标：附上相关消息，可以是邮件、Slack、Teams、WhatsApp、Telegram 或 The Machine 中的任何其他消息。按文本或发件人搜索。每条结果都会显示来源、发件人和时间。
- **文件**：点按回形针、粘贴截图，或将文件拖到表单中。在手机上，点按旁边的相机图标即可拍照。最多可添加 5 个文件，与聊天中的限制相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 可移除文件。

文件会随待办一起保存，The Machine 处理待办时会读取文件。仅添加文件也可以，系统会根据 PDF 或文本文件填写待办内容。照片会以缩略图显示，点按即可查看完整尺寸。
