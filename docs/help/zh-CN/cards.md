The Machine 会读取所有新消息，只在有事需要你处理时创建待办。每件事只创建一个待办，不管它涉及多少条消息。

## 待办显示在哪里

**待办**页面会将待办分组：

- **给你**：所有等待你处理的事项，按紧急程度排序。每个待办会标为**已备好**（工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要你先做决定或回复），或**准备中…**（你的 Machine 正在处理）。
- **刚刚完成**：你确认的最后一步已完成，例如提交表单或处理问题，但当时你不在。待办会保留，直到你点按**知道了**，最长一天。你的手机也会收到通知。
- **稍后回来**：已推迟的待办，以及没有回复**还需要吗？**的待办（见下文）。
- **承诺**：你承诺要做的事，以及别人承诺为你做的事。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按完成时间从近到远排列，并显示完成时间，例如“5 分钟前已完成”。看起来已经完成的待办会标为**看起来已完成**。

发送后，会显示一条简短提示，说明待办去了哪里，例如“已发送。已移至‘已完成’。”或“已发送。已移至‘稍后处理’，截止时间为周一。”点按**打开**即可查看待办。搜索可以按标题或接收对象查找待办，也包括“稍后处理”和“已完成”中的待办。

**给你**会优先显示已逾期或明天到期的事项，其次是来自 Fleet 的问题，然后是其他待办。每组内按创建时间从近到远排列。The Machine 准备待办或待办完成后，待办的位置不会改变，只有状态标记会更新。其他未完成分组会优先显示已逾期或明天到期的待办，其他待办按创建时间从近到远排列。侧边栏也会保持相同顺序。

**看起来已完成**表示 The Machine 发现待办已经完成，例如“PR #3451 已合并”，但待办还没有关闭。点按**重新打开**即可将它放回列表，The Machine 也会从中学习。这类待办不会显示为逾期。一天后，待办会自动关闭，并提供**撤销**。如果你已经自行处理了待办，例如在 Gmail 或 Slack 中回复，它也会自动关闭。

如果消息来自一个看起来像你认识的人的地址，例如 sam@acme-corp.example，而不是 sam@acmecorp.example，待办会明确说明：“这不是 Sam Lee。”待办会显示对方自己的邮箱地址，而不会显示对方使用的名称。The Machine 会向你已有记录中的地址所对应的人核实这类消息，不会联系发件人。

如果待办还在等别人处理某一步，例如审核或回复，就会显示**等待：**以及等待的事项。待办会折叠在“稍后回来”上方的**等待其他人**分组中，直到收到新消息后重新出现。你向对方提出问题后也是如此：待办会在截止日期前一天早上重新出现；如果截止日期是当天稍晚，则会在截止当天重新出现；如果截止日期已过，则会在次日早上重新出现，并注明仍在等谁回复。

如果待办要等别人交付结果，例如签署合同，**详情**会将其显示为**完成条件**。发送你负责的部分并不会关闭待办：待办会留在**等待其他人**中，直到收到显示结果已交付的消息，然后自动关闭，并提供**撤销**。如果到了该催促对方的时间还没收到消息，待办会重新出现，并在聊天中显示**写一条简短提醒**。在聊天中告诉 The Machine 什么情况算完成，即可更改完成条件。

如果一个待办一周都没人处理，就会询问一次：**还需要吗？**点按**不需要**即可关闭待办，并提供**撤销**。点按**保留**即可保留待办，此后不会再询问。如果再过一周仍未回复，待办会折叠到“稍后回来”中，应用图标上的数字和早间摘要也不再计入它。打开待办、发送聊天消息、编辑或推迟待办，以及收到新消息，都会让它重新出现。

每周最多会有三个待办，分别为一个已经沉寂且没有未完成事项的项目提供一个明确的下一步。请参阅[项目](projects.md)。

如果没有需要你处理的事，你的 Machine 会在空列表上休息。检查期间，它会醒来并告知你。如果检查失败或延迟，状态提示会说明情况，并显示**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**会显示所有待办，或只显示其中一种。手机和电脑上的筛选选择会保持一致。选择“工作”或“个人”时，点按**全部显示**即可返回。关于 Machine 本身的提醒，例如某个组件反复重启，不属于工作或个人，只会显示在“全部”中。

列表顶部的提示也可以直接切换到另一个筛选项：**仅个人 · 工作 · 全部显示**。

列表顶部的摘要栏会显示最近一份早间或晚间摘要的名称和统计内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可再次阅读摘要，并点按**复制**将其粘贴到任意位置。打开摘要或点按它的**×**后，摘要会在你的所有设备上保留，直到下一份摘要生成。

如果没有近期摘要，列表会显示**今天截至目前**：今天已完成和仍未完成的工作与个人事项，或者你筛选出的其中一类事项。

项目中的待办会在标题下方显示项目名称。点按即可打开项目。点按**详情**下方的**项目**即可更改项目或移除待办与项目的关联。请参阅[项目待办](projects.md#a-projects-to-dos)。

点按**详情**下方的**区域**可将待办移至另一个区域。待办可以读取和发送的内容也会随之调整。点按提示中的**撤销**即可移回原处。

如果待办需要转到另一个区域才能继续处理，而且相关消息都在该区域，它会自动移过去并继续处理。否则会显示**移至工作**，只有点按后才会移动。如果你创建待办时没有选择“工作”或“个人”，待办会在找到合适的区域后自动移过去。在此之前，它不会标为工作或个人，并会保持私密。

待办始终可以读取相关消息。如果它需要读取你另一个区域中的其他消息，就会询问你是否**将这封邮件用于此待办**。你标记为“个人”的工作邮箱也算作个人邮箱。发给你其他公司的邮件会归到该公司的待办中；关于你个人生活的待办，例如家人发到你工作邮箱的邮件，从一开始就属于个人。

通过个人账户收到的工作事项，例如客户在 WhatsApp 上联系你，或订单发到你的个人邮箱，从一开始就属于工作。你亲自移动或创建的待办会始终留在你指定的区域。“工作”或“个人”决定待办显示在哪里以及与谁共享，不会决定它从哪里回复：回复始终会发送到原对话所在的位置，即使待办已移动也是如此，除非你另选回复方式。

这类个人待办仍会使用收到邮件时对应的工作邮箱地址回复，而且绝不会显示在 Work Fleet 或 Team Graph 中。

有两个或更多待办等待你处理时，点按“给你”标题栏中的**逐项检查**，即可按列表顺序逐个处理。每项都会完整显示草稿，并提供**发送**或**执行**、**要求修改**、**稍后处理**和**跳过**选项。在电脑上，按 Enter 发送当前内容，按 `S` 推迟，按 `→` 跳过，按 Esc 停止。标题下方的标题栏还会显示按你自己的节奏处理这些待办所需的时间，例如“约 2 分钟”。

需要你回答问题的待办不会包含在内，因为它需要你的回复，而不是点按操作。

## 立即检查

你的 Machine 昼夜不停，每隔几分钟读取每个信息来源。当有 40 条消息等待处理，或某个人的最早一条消息已等待 15 分钟时，The Machine 就会检查新收到的消息。新闻邮件、通知和收据会在下一次检查时一并处理，最迟不超过一小时。

夜间 00:00 至 06:30 会暂停检查：新消息仍会被读取并保存，并在 06:30 一并检查，让待办在早间摘要前准备好。**连接**中的“检查”会显示“夜间暂停，将于 06:30 补上检查”。夜间打开应用、在聊天中发送消息或点按待办后，检查会恢复正常，直到你离开一小时。点按**立即检查**始终会立即检查。

**立即检查**会立即读取所有信息来源。如果没有未完成待办，点按你的 Machine 状态提示即可查看，并点按**详情**打开**连接**中的“检查”页面。如果有未完成待办，电脑上的列表顶部会显示此选项。只有检查正在进行、失败或延迟时，才会显示简短的状态提示。你也可以在聊天中询问。

LinkedIn、X 和 Salesflare 会按各自的频率运行。

## 上次检查

检查并读取新消息后，待办列表上方会显示一条提示，说明从每个已读取的信息来源中发现了什么，例如“已于 16:11 检查 13 条消息 · 暂无需要你处理的事项”或“· 2 个新待办”。如果新待办要等到更合适的时间才出现，例如早间摘要时，提示会说明等待到何时：“1 个待办将保留至明天 08:30”。

点按提示即可查看每封邮件对话、聊天和通知，以及对应的信息来源图标、发件人、主题或开头几句话，还有新待办或无需处理的原因，例如“只抄送了你，队友正在回复”或“会议已安排在周四”。如果检查只给出了模糊的原因，对话不会显示原因。点按即可阅读。

最多显示前 10 条，点按其下方即可查看其余内容。姓名后的数字，例如 (3)，表示该聊天中有几条新消息。关于已列出的消息的手机通知只会显示一次。检查完成后，这条提示会保留 12 小时。

这里只统计发给你的邮件。你的回复会被读取，用于了解上下文和承诺，但不会算作新邮件。The Machine 发给你的邮件，例如早间摘要或修复通知，绝不会被读取或列出。关于账单、试用期或邀请的邮件会照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

**要求修改**会说明要修改什么：如何完成待办，或草稿准备好后要修改草稿的哪些部分。**标记为已完成**表示待办已处理：如果待办已备好且没有草稿，此选项会直接显示；否则会放在**…**菜单顶部，包括需要你做决定的待办。待办会立即从列表中移除，并在提示中提供**撤销**。向旁边滑动提示，或用鼠标将其拖走，可以更快关闭。更改会保留。

如果想用其他方式完成待办，请在它的**聊天**中说明。

在**…**菜单中：

- **正在转交……**：将待办交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请人审核](ask-to-review.md)。
- **重复…**：待办会[按固定周期重新出现](recurring.md)。
- **不需要**：移除待办。你也可以选择原因：**无关**、**事实有误**或**已处理**。The Machine 会从中学习。

点按标题，或点按**详情**下方的**名称**，即可重命名待办。你设置的标题会保留。

点按**重新打开**即可恢复已关闭的待办。如果有新情况，例如对方发来新消息，待办也会自动重新出现，但你自己的回复不会触发此操作。

任何国家的账单，只要需要你亲自付款，都会变成一个待办，并附上账单提供的金额、到期日和付款信息。自动支付的账单，例如直接扣款或使用已保存卡片支付的账单，不会变成待办。之后的邮件如果显示账单已付，例如发件人确认已收到款项，待办就会自动关闭，并提供**撤销**，可在一天内恢复。

如果待办只在某个时间之前有效，例如会议前需要确认的事项，它会在该时间之后自动关闭，并在**已完成 / 已忽略**中显示为“不再需要”。点按**撤销**可在一天内恢复。

向某人发送消息或转交待办之前，The Machine 会检查你最近与相关人员的聊天，包括群聊，并等待 Slack 读取这些聊天。如果之后收到的消息表明事情已经完成，例如对方收到请求并答应了，待办就会自动关闭，并提供**撤销**，可在一天内恢复。

如果较新的消息改变了计划，例如聚会改到别的场地或预订取消，The Machine 会自行更新待办。仍需处理的待办会根据新计划更新。不再需要处理的待办会移至**已完成 / 已忽略**，并标记为“不需要”。聊天中会显示“已更新：”以及原因，并提供**撤销**，可在一天内恢复。

首次查看待办时，会显示一条简短提示，介绍关键操作：**要求修改**和**不需要**，并说明只有点按**发送**后内容才会发出。使用提示中的按钮或点按 × 后，提示就会永久消失。

第一天使用时，待办顶部会向你问好，并告诉你谁等你的回复最久。The Machine 会优先为这条回复准备草稿，让你打开应用时就能直接使用。

每个待办都以标题开头。标题下方会显示相关人员、相关组织（仅在待办确实与组织有关时显示，不会只因为某人在那里工作就显示）、项目、工作或个人标记，以及收到时间。点按姓名即可在 Graph 中打开对方的页面。

如果 Graph 中有姓名和组织对应的照片或徽标，就会显示照片或徽标，否则会显示首字母。如果徽标缩小后难以辨认，例如透明背景上的白色徽标或宽幅文字标志，也会显示首字母。

有时会显示一条简短提示，说明尚不清楚的信息，例如“12 天前通过邮件联系过；之后没有消息。”如果最近一次联系时间较久，或对方尚未回复，就会显示此提示，并指出尚未连接的渠道，例如 WhatsApp。The Machine 会说明自己不知道什么，而不是猜测。

如果提示中提到尚未连接的渠道，点按旁边的“连接”即可打开对应的连接。

标题会说明需要做什么，只有待办内容变化时才会更新。已完成的待办会保留原有标题，并在下方说明如何完成，例如“已完成：Sam 于周二签署”。

草稿上方有一行淡色文字，说明草稿来自哪条消息，并显示对应服务的徽标。点按即可阅读对话线程。草稿会显示发送目标的徽标，让你一眼看出它是 Slack 回复还是邮件。

如果草稿参考了别处的意见，例如队友在 Slack 中的建议，会显示一行说明，例如“根据 Sam 在 #ops 中的意见”。点按即可阅读该消息。

聊天记录（Slack、WhatsApp、Telegram、Intercom 等）会按时间从早到晚显示为一段对话：包括待办所涉消息之前的消息，以及之后的回复。在 WhatsApp、Telegram 或 Signal 中，你发出的消息会像应用中一样显示在右侧。待办所涉消息会标记为“此待办”，并自动显示在视野中。点按**显示更早的内容**即可加载更早的消息。邮件会将同一邮件线程中的其他内容折叠显示在上方和下方。

邮件的**详情**只会显示邮件标题中没有的信息，例如完整的抄送地址、密送地址或不同的回复地址；如果没有其他信息，就不会显示详情。

Slack 线程中的回复还会显示线程开始前的内容。点按待办中链接到原消息的链接，也可以在这里打开该消息，并在底部点按**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你最后留下的备注，以及编程智能体的结果。点按**聊天 ›**即可打开聊天。已完成的待办会简要显示；相关消息可在**详情**中查看。

“等待”状态的待办会链接到你发给对方的最后一条消息，也就是你正在等回复的那条消息：“发给 Pat 的邮件 · 周二”。

## 自己创建待办

点按**新建待办**（电脑上位于**搜索**下方），即可为任何事情创建待办。创建待办不会发送任何内容。如果没有选择“工作”或“个人”，待办会根据相关人员和事项自动归类到合适的位置。The Machine 也会查找待办所跟进的邮件，即使邮件很早之前收到也会查找。

- **截止**：输入日期或时间，也可以用自己的语言输入，例如“明天”、“下周五”、“11 月 3 日”、“下午 2 点”或“2 小时后”。日历图标中有快捷选项和**选择日期**。
- **消息**：附上待办所涉及的消息，可以是 The Machine 收到的邮件、Slack、Teams、WhatsApp、Telegram 或其他消息。按文字或发件人搜索。每条结果都会显示来源、发件人和时间。
- **文件**：点按回形针，粘贴截图，或将文件拖到表单中。在手机上，点按旁边的相机即可拍照。最多可添加 5 个文件，与聊天中的限制相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 即可移除文件。

文件会保留在待办中，The Machine 处理待办时会读取这些文件。只添加文件也可以：The Machine 会根据 PDF 或文本文件填写待办内容。照片会显示为小图，点按即可查看原始大小。
