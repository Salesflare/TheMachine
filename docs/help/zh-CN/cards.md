你的 Machine 会读取所有新内容，只有在需要你处理时才创建待办。每件事对应一条待办，无论涉及多少条消息。

## 待办的位置

**待办**页面会将待办分组：

- **刚刚完成**：显示在顶部。你不在时，某个已确认的最后步骤（例如提交表单或处理问题）已完成。它会保留，直到你点按**知道了**，最长一天，你的手机也会收到提醒。
- **给你**：所有等待你处理的待办，最紧急的排在最前面。每条待办会显示**已备好**（工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要你先做决定或回复）、**准备中…**（你的 Machine 正在处理）或**待读**（摘要或简报，无需决定）。
- **等待其他人**：折叠显示下一步要由其他人完成的待办（见下文）。
- **稍后回来**：已推迟处理的待办，以及没有回复**还需要吗？**的待办（见下文）。
- **承诺**：你承诺要做的事，以及别人承诺为你做的事。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按完成时间从新到旧排列，并显示完成时间，例如「5分钟前已完成」。看起来已经完成的待办会标记为**看起来已完成**。

发送后，会显示一条简短提示，说明待办的去向，例如「已发送。已移至已完成。」或「已发送。已移至稍后处理，直到周一。」点按**打开**即可前往待办。搜索可以按标题或收件人查找待办，也可以搜索稍后处理和已完成的待办。

**给你**会先显示已逾期或明天到期的待办，然后是 Fleet 中的问题、看板的后续事项，最后是其他待办。每组内按最新优先排列。你的 Machine 准备待办或完成待办时，待办的位置不会变，只有状态标记会变。其他未完成分组会先显示已逾期或明天到期的待办，其余按最新优先排列。侧边栏也保持相同顺序。

**看起来已完成**表示你的 Machine 发现事情已经办妥，例如「PR #3451 已合并」，但待办还没有关闭。点按**重新打开**可将它放回列表，你的 Machine 也会从中学习。这类待办不会显示为逾期。一天后，它会自动关闭，并显示**撤销**。如果你已经自行处理待办，例如在 Gmail 或 Slack 中回复，它也会自动关闭。

如果消息来自一个看起来像你认识的人、但实际不同的地址，例如 sam@acme-corp.example，而不是 sam@acmecorp.example，待办会明确说明：「这不是 Sam Lee。」待办会显示对方实际使用的地址，而不会显示对方使用的名称。你的 Machine 会向你已有的地址所对应的人核实这类消息，而不是向发件人核实。

如果待办仍在等待其他人处理，例如等待审核或回复，会显示**等待：**以及所等的步骤。它会折叠显示在**等待其他人**中，位于「稍后回来」上方，直到有新消息让它重新出现。你反过来提出问题后也一样：待办会在截止日期前一天早上重新出现；如果截止日期是当天稍后，则在截止时间重新出现；如果截止日期已过，则在次日早上重新出现，并说明仍在等待谁的回复。

如果待办要等别人交付结果，例如签署合同，**详情**会显示**完成条件**。发送你这边的内容不会关闭待办：它会留在**等待其他人**中，直到收到表明结果已交付的消息，然后自动关闭，并显示**撤销**。如果到了该催促对方的时间仍未收到消息，待办会重新出现，并在聊天中显示**写一条简短提醒**。在聊天中告诉它什么情况算完成，即可更改完成条件。

一条待办连续一周无人处理后，会询问一次：**还需要吗？**点按**不需要**会关闭待办，并显示**撤销**。点按**保留**即可保留待办，它之后不会再询问。如果又一周没有回复，待办会折叠到「稍后回来」中，应用图标上的数字和早间摘要也不再计入它。打开待办、发送聊天消息、编辑、推迟处理或收到新消息，都会让它重新出现。

每周最多有三个安静下来且没有未完成待办的项目，会收到一条包含具体下一步的待办。请参阅[项目](projects.md)。

没有需要你处理的事时，你的 Machine 会在空列表中休息。检查期间，它会醒来并告知你。如果检查失败或延迟，状态行会说明情况，并显示**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**可以显示所有待办，或只显示其中一种。手机和电脑会使用相同的筛选项。选择「工作」或「个人」时，点按**全部显示**即可返回。关于你的 Machine 本身的提醒，例如某个组件不断重启，既不属于工作，也不属于个人，只会显示在「全部」中。

列表顶部的状态行也可以直接切换到另一个筛选项：在**仅个人**视图中，点按**工作**或**全部显示**。

列表顶部的行会显示你最近一次早间或晚间摘要的名称及统计内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可再次阅读该摘要，也可以点按**复制**，将内容粘贴到任意位置。打开摘要或点按其**×**后，摘要会在你的所有设备上保留，直到下一份摘要生成。

如果没有近期摘要，这里会显示**今天截至目前**：今天已完成和仍未完成的待办，按工作和个人分类显示，或者只显示当前筛选的类别。

属于项目的待办会在标题下方显示项目名称。点按名称即可打开项目。点按**详情**下的**项目**可以更改项目，或移除待办与项目的关联。请参阅[项目的待办](projects.md#a-project-s-to-dos)。

点按**详情**下的**区域**可将待办移到另一个区域。待办可读取和发送的内容也会随之改变。点按提示中的**撤销**即可移回原处。

如果待办需要转到另一个区域才能继续处理，而且它关联的所有消息都在该区域，待办就会自动移过去并继续处理。否则会显示**移至工作**，只有点按后才会移动。你新建待办时如果没有选择「工作」或「个人」，待办会在找到所属区域后自动移过去。在此之前，它不会标记为工作或个人，并且会保持私密。

待办始终可以读取关联的消息。如果它需要读取另一个区域中的其他消息，会询问你是否**将这封邮件用于此待办**。你标记为「个人」的工作邮箱也会视为个人邮箱。发往你其他公司的邮件会归入对应公司的待办；与个人生活有关的待办，例如家人写信到你的工作地址，从一开始就属于个人。

通过个人账户联系你的工作事务，例如客户在 WhatsApp 上联系你，或订单发到你的个人邮箱，从一开始就属于工作。你自行移动或创建的待办会一直留在指定区域。「工作」或「个人」决定待办显示在哪里、与谁共享，但不会决定回复从哪里发出：除非你选择其他方式，否则回复始终发到原对话中，即使待办已移动也是如此。

这类个人待办仍会使用收到相关邮件的工作地址回复，也不会显示在工作 Fleet 或 Team Graph 中。

有两条或更多待办等待处理时，点按「给你」标题中的**逐项检查**，即可按列表顺序逐条处理，并完整查看每条草稿，选用**发送**或**执行**、**要求修改**、**稍后处理**或**跳过**。在电脑上，按 Enter 发送屏幕上显示的内容，按 `S` 推迟处理，按 `→` 跳过，按 Esc 停止。标题下方还会显示按你自己的节奏处理这些待办所需的时间，例如「约 2 分钟」。

需要你回答问题的待办不包括在内，因为你需要回复，而不是点按按钮。

## 立即检查

你的 Machine 每隔几分钟、昼夜不停地读取每个来源。待处理消息达到 40 条，或某个人最早发来的消息等待了 15 分钟后，它就会检查新内容。新闻邮件、通知和收据会在下一次检查时一并处理，最迟不超过一小时。

夜间 00:00 至 06:30 会暂停检查：新消息仍会读取并保留，并在 06:30 一并检查，让待办在早间摘要前准备好。连接中的检查状态会显示「夜间暂停，06:30 恢复检查」。夜间在应用中点按、输入或滚动，在聊天中发消息，或点按待办，都会让检查照常运行，直到你离开应用一小时。点按**立即检查**始终会马上检查。

点按**立即检查**会立刻读取所有来源。如果没有未完成待办，点按你的 Machine 的状态行即可查看详情，其中的**详情**会打开「连接」下的「检查」。如果有未完成待办，电脑上的列表顶部会显示该选项。只有检查正在进行，或检查失败、延迟时，那里才会显示简短状态行。你也可以在聊天中提出要求。

LinkedIn、X 和 Salesflare 按各自的频率运行。

## 上次检查

检查并读取新消息后，待办列表上方会显示一行状态，汇总它从所有读取来源中发现的内容，例如「已于 16:11 检查 13 条消息 · 无需你处理」或「· 2 条新待办」。如果新待办要等到更合适的时间处理，例如等到早间摘要，它会显示等待到何时：「1 条待办暂缓至明天 08:30」。

点按状态行，即可查看每封邮件的对话、聊天和通知，并附有各来源的图标。列表会显示发件人、主题或开头内容，以及对应的新待办或无需处理的原因，例如「仅抄送，队友正在回复」或「会议已安排在周四」。如果检查只得出笼统原因，对话就不会显示原因。点按任意一项即可阅读。

最初会显示前 10 条，点按列表下方即可查看其余内容。姓名后的数字，例如 (3)，表示该聊天中的新消息数量。关于已列出消息的手机通知只会显示一次。状态行会在检查后保留 12 小时。

这里只统计发给你的邮件。你的回复会被读取，用于了解上下文和承诺，但不算新邮件。The Machine 发给你的邮件，例如早间摘要或修复通知，绝不会被读取或列出。关于账单、试用或邀请的邮件则会照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

**要求修改**可以说明需要更改的内容：如何处理，或者草稿准备好后要修改草稿的哪部分。**标记为已完成**表示事情已经处理：对于没有草稿的已备好待办，该选项会直接显示；其他待办，包括需要你决定的待办，可以在**…**菜单顶部找到。待办会立即从列表中移除，并在提示中显示**撤销**。将提示滑开，或用鼠标将它拖走，可以更快关闭。所做的更改会保留。

如果希望用其他方式处理，请在待办的**聊天**中说明。

在**…**菜单下：

- **正在转交……**：将待办交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请别人审核](ask-to-review.md)。
- **重复…**：待办会[按周期重新出现](recurring.md)。
- **不需要**：待办会移除。你也可以选择原因：**无关**、**事实有误**或**已处理**。你的 Machine 会从中学习。

点按标题或**详情**下的**名称**即可重命名。你设置的标题会保留。

点按**重新打开**可恢复已关闭的待办。发生新情况时，例如对方发来新消息，待办也会自动恢复，但你自己的回复不会触发恢复。恢复后会显示恢复时间，并按新待办排序。即使过了几周，待办中的聊天也会从上次中断处继续。

任何国家的账单，只要需要你亲自付款，就会创建一条待办，其中包含账单金额、截止日期和账单提供的付款详情。自动付款的账单，例如自动扣款或已绑定卡片支付的账单，不会创建待办。之后的邮件显示账单已支付时，例如发件人确认已收到款项，待办会自动关闭。点按**撤销**可在一天内恢复。

只在特定时间前有效的待办，例如会议前需要确认的事项，会在时间过后自动关闭，并以「不再需要」移至**已完成 / 已忽略**。点按**撤销**可在一天内恢复。

在某人的消息或转交内容显示为已备好之前，你的 Machine 会检查你最近与相关人员的聊天，包括群聊，并等待 Slack 读取这些内容。如果之后的消息表明事情已经办妥，例如有人提出请求且对方答应了，待办会自动关闭。点按**撤销**可在一天内恢复。

新消息改变计划时，例如聚会换了场地或预订取消，The Machine 会自行更新待办。仍需处理的待办会按照新计划更新。没有后续事项的待办会以「不需要」移至**已完成 / 已忽略**，聊天中会说明「已更新：」以及原因，点按**撤销**可在一天内恢复。

首次使用待办时，会显示简短提示，介绍关键操作：**要求修改**和**不需要**，并说明只有点按**发送**后内容才会发出。点按提示中的按钮或按 × 后，提示就会永久消失。

第一天使用时，待办页面顶部会向你问好，并告诉你谁等待你的回复最久。它会优先为你准备这条回复，让你打开应用时就能直接发送。

每条待办都以标题开头。标题下方会显示相关人员、涉及的组织（仅在确实与组织有关时显示，不会仅因某人在那里工作就显示）、项目、工作或个人，以及待办收到的时间。点按姓名即可在 Graph 中打开对方的页面。

如果 Graph 中有人员或组织的照片或标志，就会显示照片或标志，否则显示名称首字母。如果标志缩小后无法辨认，例如透明背景上的白色标志或宽幅文字标志，也会改为显示首字母。

有时会显示一行较淡的文字，说明尚不清楚的信息，例如「上次通过邮件联系是 12 天前，此后没有新消息。」如果最近一次联系已过去很久，或对方尚未回复，就会显示这行提示，并标出尚未连接的渠道，例如 WhatsApp。你的 Machine 会明确说明未知信息，不会猜测。

如果提示中提到了尚未连接的渠道，点按旁边的「连接」即可打开该连接。

标题会说明需要做什么，并且只有待办内容发生变化时才会改变。已完成的待办会保留原有标题，并在下方显示完成方式，例如「已完成：Sam 周二签署了文件」。

草稿上方有一行浅色文字，标明草稿来自哪条消息，并显示对应服务的标志。点按即可阅读对话。草稿会显示发送渠道的标志，让你一眼看出这是 Slack 回复还是邮件。

如果草稿参考了其他地方某人的意见，例如队友在 Slack 中的建议，会显示一行说明，例如「根据 Sam 在 #ops 中的建议」。点按即可阅读该消息。

聊天（Slack、WhatsApp、Telegram、Intercom……）会按时间从早到晚显示为一段对话，包括待办所关联消息之前的消息和之后的回复。在 WhatsApp、Telegram 或 Signal 中，你发出的消息会像应用里一样显示在右侧。待办关联的消息会标记为「此待办」，并自动滚动到该处。点按**显示更早的内容**即可加载更早的消息。邮件会将同一邮件串中的其余内容折叠显示在上下方。

点按**在Gmail中打开**即可在收到邮件的 Gmail 账号中打开邮件。在 Android 上，如果安装了 Gmail 应用，邮件会在该应用中打开。

邮件的**详情**只会显示邮件头中没有的信息，例如完整的 Cc 地址、Bcc 或其他回复地址；没有补充信息时则不会显示详情。

Slack 线程中的回复还会显示线程开始前的内容。待办关联到自己的消息时，也会在此处打开，并在底部显示**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你最近添加的备注，以及编程智能体的结果。点按标题即可打开聊天。已完成的待办会保持简洁，来源消息可在**详情**中查看。

「等待」待办会链接到你发给对方的最后一条消息，也就是你正在等待回复的那条消息，例如：「发给 Pat 的邮件 · 周二」。

## 自己新建待办

点按电脑上**搜索**下方的**新建待办**、手机上的**+**，或按 `N`，即可为任何事情添加待办。创建待办不会发送任何内容。如果没有选择**工作**或**个人**，待办会根据相关人员和事项自动归入合适的区域。它还会查找待办所跟进的邮件，包括较早的邮件。

- **截止**：输入日期或时间，例如「明天」「下周五」「11月3日」「下午2点」或「2小时后」，也可以使用自己的语言。日历图标中有快捷选项和**选择日期**。
- **重复频率**：待办会按周期重新出现。请参阅[重复待办](recurring.md)。
- **人员**：关联与待办相关的人员或公司，最多 5 个。
- 消息图标：关联相关消息，例如邮件、Slack、Teams、WhatsApp、Telegram 或 The Machine 中的其他消息。可按文本或发件人搜索。每条结果都会显示来源、发件人和时间。
- **文件**：点按回形针、粘贴截图，或将文件拖到表单中。在手机上，点按旁边的相机图标即可拍照。最多可添加 5 个文件，与聊天中的限制相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 可移除文件。

文件会保留在待办中，The Machine 处理待办时会读取这些文件。只添加文件也可以创建待办：它会根据 PDF 或文本文件填写待办内容。照片会以小图显示，点按即可查看原图。
