你的 Machine 会读取所有新内容，只有在需要你处理时才创建待办。无论一件事涉及多少条消息，都只创建一个待办。

## 待办的位置

**待办**页面会将待办分组：

- **刚刚完成**：位于顶部。你离开时，某个已确认的最后步骤（例如提交表单或处理问题）已完成。它最多保留一天，直到你点按**知道了**。手机也会收到通知。
- **给你**：所有等你处理的事项，按紧急程度排序。每个待办会标记为**已备好**（准备工作已完成，点按**执行**或**发送**即可完成）、**需要你**（需要你先做决定或回复）、**准备中…**（你的 Machine 正在处理），或**待读**（摘要或简报，不需要你做决定）。
- **等待其他人**：折叠显示下一步要由其他人完成的待办（见下文）。
- **稍后回来**：已推迟的待办，以及没有回复**还需要吗？**的待办（见下文）。
- **承诺**：你做出的承诺和别人对你的承诺。请参阅[承诺](promises.md)。
- **已完成 / 已忽略**：所有已完成的待办，按最新完成时间排序，并显示完成时间，例如“5 分钟前已完成”。看起来已完成的待办会标记为**看起来已完成**。

发送后会显示一条简短提示，说明待办去了哪里，例如“已发送。已移至已完成。”或“已发送。已移至稍后，直到周一。”点按**打开**即可查看待办。搜索可以按标题或接收对象查找待办，也会搜索稍后和已完成的待办。

**给你**会优先显示已逾期或明天到期的事项，其次是 Fleet 中的问题、看板的后续事项，最后是其他事项。每组内按最新时间排序。待办在 Machine 准备期间和完成后都会保留原位，只会改变标记。其他未完成分组会优先显示已逾期或明天到期的事项，其余按最新时间排序。侧边栏也会保持相同的顺序。

**看起来已完成**表示你的 Machine 发现事情已经完成，例如“PR #3451 已合并”，但待办尚未关闭。点按**重新打开**可将它放回列表，Machine 也会从中学习。这些待办不会显示为逾期。一天后，待办会自动关闭，并提供**撤销**。如果你已自行处理某个待办，例如已在 Gmail 或 Slack 中回复，它也会自动关闭。

如果消息来自一个看起来像是你认识的人的地址，例如 sam@acme-corp.example，而你认识的人使用的是 sam@acmecorp.example，待办会明确说明：“这不是 Sam Lee。”显示的会是对方自己的邮箱地址，而不是对方使用的姓名。你的 Machine 会向你已有记录的邮箱地址对应的人核实消息，不会联系发件人。

如果待办还在等其他人完成某个步骤，例如审核或回复，会显示**等待：**以及等待的步骤。待办会折叠显示在**等待其他人**中，位于“稍后回来”上方，直到收到新消息后重新出现。如果你向对方提出了问题，也同样会重新出现：在截止日期前一天早上出现；如果截止日期是今天晚些时候，则在截止时间出现；如果截止时间已过，则在第二天早上出现。待办还会注明仍在等谁。

如果待办需要其他人交付某项结果，例如签署合同，**详情**会通过**完成条件**显示这一点。你发送自己的部分后，待办不会关闭，而是会留在**等待其他人**中，直到消息表明结果已交付，然后自动关闭，并提供**撤销**。如果到催促对方的时间还没收到消息，待办会重新出现，并在聊天中显示**写一条简短提醒**。你可以在聊天中说明什么情况才算完成。

如果某个待办一周都没人处理，系统会询问一次：**还需要吗？**点按**不需要**即可关闭，并提供**撤销**。点按**保留**会保留待办，之后不会再询问。如果再过一周仍未回复，待办会折叠到“稍后回来”中，应用图标上的数字和早间摘要也不再统计它。打开待办、发送聊天消息、编辑、推迟或收到新消息，都会让它重新出现。

每周最多会为一个已沉寂且没有未完成事项的项目创建一个待办，里面会列出一个具体的下一步。每周最多创建三个。请参阅[项目](projects.md)。

没有需要你处理的事时，你的 Machine 会在空列表上休息。检查期间，它会唤醒并告诉你。如果检查失败或延迟，它会显示相应提示，并在下方提供**立即检查**。

侧边栏顶部的**全部**、**工作**和**个人**可显示所有待办，也可只显示某一类。手机和电脑会使用相同的筛选条件。选择“工作”或“个人”时，点按**全部显示**即可返回。与 Machine 本身有关的提醒，例如某个组件不断重启，既不属于“工作”，也不属于“个人”，只会显示在“全部”中。

列表顶部的文字也可以直接切换到另一项：在**仅个人**下，点按**工作**或**全部显示**。

列表顶部的行会显示你最近一次早间或晚间摘要的名称及统计内容，例如**昨天晚间摘要** · 已完成 12 项，未完成 3 项。点按即可重新阅读该摘要，也可以点按**复制**，将摘要粘贴到任意位置。打开摘要或点按其中的 × 后，它会在所有设备上保留，直到下一份摘要生成。

如果没有最近的摘要，这里会显示**今天截至目前**：今天已完成和仍未完成的事项，可查看“工作”和“个人”的内容，也可只查看当前筛选的类别。

项目中的待办会在标题下方显示项目名称。点按名称即可打开项目。在**详情**下点按**项目**可更改项目或移除项目关联。请参阅[项目待办](projects.md#a-project-s-to-dos)。

在**详情**下点按**区域**可将待办移到另一个区域。待办可以读取和发送的内容也会随之改变。点按提示中的**撤销**即可移回原处。

如果待办需要在另一个区域继续处理，而且相关消息都在那里，它会自动移到该区域并继续处理。否则会显示**移至工作**，只有点按后才会移动。你新建待办时如果没有选择“工作”或“个人”，它会在找到所属区域后自动移动。在此之前，它既不属于“工作”，也不属于“个人”，并会保持私密。

待办始终可以读取与之相关的消息。如果它需要读取另一个区域中的其他消息，会询问你是否**将这封邮件用于此待办**。你标记为“个人”的工作邮箱也会按个人邮箱处理。发给你其他公司的邮件会归入该公司的待办；与个人生活有关的待办，例如家人发到你工作邮箱的消息，从一开始就属于“个人”。

通过个人账户收到的工作内容，例如客户在 WhatsApp 上发来的消息，或发送到个人邮箱的订单，从一开始就属于“工作”。你自行移动或分类的待办会始终留在你指定的位置。“工作”或“个人”决定待办显示在哪里、与谁共享，不会决定回复从哪里发出：回复始终会发送到对话所在的位置。移动待办后也一样，除非你选择其他方式。

这类“个人”待办仍会使用收到邮件时的工作邮箱地址回复，而且不会显示在“工作”Fleet 或 Team Graph 中。

有两个或更多待办等待处理时，点按“给你”标题中的**逐项检查**，即可按列表顺序逐个查看。每项都会完整显示草稿，并提供**发送**或**执行**、**要求修改**、**稍后处理**和**跳过**。在电脑上，按 Enter 发送当前内容，按 `S` 推迟，按 `→` 跳过，按 Esc 停止。标题下方还会按你的节奏显示大致所需时间，例如“约 2 分钟”。

需要你回答问题的待办不会出现在这两处：它需要的是你的回复，而不是点按操作。

## 立即检查

你的 Machine 日夜每隔几分钟读取一次各个来源。当未读消息达到 40 条，或某个人发来的最早一条消息已等待 15 分钟时，它会检查新内容。简报、通知和收据会在下一次检查时一并处理，最长不超过一小时。

夜间 00:00 至 06:30 会暂停检查：新消息仍会被读取并保存，并在 06:30 一起检查，让待办在早间摘要前准备好。“连接”中的检查状态会显示“夜间暂停，06:30 继续检查”。如果你在夜间点击、输入或滚动应用内容、在聊天中发送消息，或点按待办，检查就会像平时一样继续，直到你离开应用一小时。点按**立即检查**始终会立刻检查。

点按**立即检查**会立刻读取所有来源。如果没有未完成的待办，点按 Machine 的状态行即可查看状态和**详情**，其中会打开“连接”下的“检查”。如果有未完成的待办，电脑上会在列表顶部显示该选项。只有检查正在进行、失败或延迟时，状态行才会显示简短提示。你也可以在聊天中询问。

LinkedIn、X 和 Salesflare 会按各自的频率检查。

## 上次检查

如果检查读取了新消息，待办列表上方会显示一行提示，汇总读取的所有来源中发现的内容，例如“16:11 检查了 13 条消息 · 无需你处理”或“· 2 个新待办”。如果新待办要等到更合适的时间处理，例如早间摘要时，会显示等待到什么时候：“1 个待办暂缓至明天 08:30”。

点按此行可查看每封邮件、每段聊天和每条通知，并显示来源图标、发件人、主题或开头内容，以及对应的新待办或无需处理的原因，例如“仅抄送，队友正在回复”或“会议已安排在周四”。如果检查只得出模糊的原因，对话就不会显示原因。点按任意一项即可阅读。

默认显示前 10 条，点按下方即可查看其余内容。姓名后的数字，例如 (3)，表示该聊天中的新消息数量。手机不会重复通知已在列表中显示的消息。检查完成后，这一行会保留 12 小时。

这里只统计发给你的邮件。你的回复会被读取，用于了解上下文和承诺，但不会算作新邮件。Machine 发给你自己的邮件，例如早间摘要或修复通知，既不会被读取，也不会列出。与账单、试用或邀请相关的邮件会照常读取。

## 按钮

待办会显示下一步操作，例如**执行**或**审核并发送**，旁边还有**稍后处理**。请参阅[执行](do-it.md)和[稍后处理](snooze.md)。

**要求修改**会说明要改什么：如何执行，或者草稿准备好后要修改哪些内容。**标记为已完成**表示事情已经处理好：对于没有草稿且已备好的待办，此按钮会直接显示；其他待办则在**…**菜单顶部显示，包括需要你做决定的待办。点按后待办会立即从列表中移除，并显示一条包含**撤销**的消息。向左滑动消息，或用鼠标将其拖走，也可以提前关闭。所做的更改会保留。

如果想用其他方式完成，请在待办的**聊天**中说明。

在**…**菜单下：

- **正在转交……**：交给队友、[Claude Code 或 Codex](hand-to-agent.md)，或[请人审核](ask-to-review.md)。
- **重复…**：待办会[按固定频率再次出现](recurring.md)。
- **不需要**：移除待办。你也可以选择原因：**无关**、**事实有误**或**已处理**。你的 Machine 会从中学习。

点按标题，或在**详情**下点按**名称**，即可重命名。你设置的标题会保留。

点按**重新打开**可恢复已关闭的待办。发生新情况时，例如收到对方的新消息，待办也会自动重新出现，但你自己的回复不会触发此操作。

无论来自哪个国家，只要账单需要你亲自付款，就会变成待办，并附上账单中的金额、到期日和付款信息。自动付款的账单，例如自动扣款或已绑定卡片付款的账单，不会创建待办。如果后续邮件显示账单已付清，例如发件人确认已收到款项，待办就会自动关闭。**撤销**可在一天内恢复待办。

如果待办只需在某个固定时间前处理，例如会议前确认，它会在该时间过后自动关闭，并以“不再需要”为由移至**已完成 / 已忽略**。**撤销**可在一天内恢复待办。

在显示给某人的消息或转交事项为已备好之前，你的 Machine 会检查你与相关人员最近的聊天，也包括群聊，并等待 Slack 完成读取。如果后续消息表明事情已经完成，例如对方已收到请求并同意，待办就会自动关闭。**撤销**可在一天内恢复待办。

如果较新的消息更改了计划，例如派对改到其他地点或预订已取消，The Machine 会自行更新相关待办。仍然需要处理的待办会按新计划更新。无需再处理的待办会以“不需要”为由移至**已完成 / 已忽略**，聊天中会显示“已更新：”及原因，**撤销**可在一天内恢复待办。

第一次查看待办时，会显示简短提示，介绍重要操作：**要求修改**和**不需要**，以及只有点按**发送**后内容才会发出。使用提示中的按钮或点按 × 后，提示就会永久消失。

你首次使用的当天，待办顶部会向你问好，并告诉你谁等你的回复最久。系统会优先起草这条回复，让你打开应用时就能直接发送。

每个待办都以标题开头。标题下方会显示相关人员、相关组织（只有事项确实与组织有关时才显示，不会仅因为对方在那里工作就显示）、项目、“工作”或“个人”，以及收到时间。点按姓名可在 Graph 中打开对方的页面。

如果 Graph 中有联系人照片或组织标志，就会显示照片或标志；否则会显示姓名首字母。太小就难以辨认的标志，例如透明背景上的白色标志或宽幅文字标志，也会改为显示首字母。

有时会显示一行较淡的提示，说明哪些信息未知，例如“12 天前通过邮件联系过；之后没有消息”。如果最近一次联系时间较久或尚未得到回复，系统会显示这行提示，并指出尚未连接的渠道，例如 WhatsApp。你的 Machine 会说明自己不知道什么，而不是猜测。

如果提示中提到了尚未连接的渠道，点按旁边的“连接”即可连接该渠道。

标题会说明需要处理什么，只有待办内容发生变化时才会更改。已完成的待办会保留标题，并在下方说明完成情况，例如“已完成：Sam 周二签署了文件”。

草稿上方会用一行浅色文字标出草稿来源消息，并显示对应服务的标志。点按即可阅读对话。草稿会显示发送位置的标志，让你一眼看出这是 Slack 回复还是邮件。

如果草稿参考了其他地方某人的意见，例如队友在 Slack 中的建议，系统会用一行文字说明，例如“根据 Sam 在 #ops 中的消息”。点按即可阅读该消息。

Slack、WhatsApp、Telegram、Intercom 等聊天会按时间从早到晚显示为一段对话，包括待办相关消息之前的内容和之后的回复。在 WhatsApp、Telegram 或 Signal 中，你发出的消息会像应用内一样显示在右侧。待办相关消息会标记为“此待办”，并自动滚动到该消息。点按**显示更早的内容**可查看更早的消息。邮件会将同一邮件串中的其他内容折叠显示在上方和下方。

点按**在 Gmail 中打开**，即可在收到邮件的 Gmail 账户中打开邮件。如果你使用 Android 且安装了 Gmail 应用，邮件会在 Gmail 应用中打开。

邮件的**详情**只显示邮件标题中没有的信息，例如完整的抄送地址、密送地址或不同的回复地址。如果没有其他信息，就不会显示详情。

Slack 线程中的回复还会显示线程开始前的内容。待办链接到自己的消息时，也会在此处打开，并在底部显示**在Slack中打开**。

**详情**会显示待办名称、项目和区域（点按即可更改）、你的最后一条备注以及编程助手的结果。点按标题可打开聊天。已完成的待办会保持简短；来源消息会显示在**详情**下。

“等待”类待办会链接到你发给对方的最后一条消息，也就是你正在等待回复的那条，例如“发给 Pat 的邮件 · 周二”。

## 自己创建待办

点按电脑上**搜索**下方的**新建待办**、手机上的 **+**，或按 `N`，即可为任何事情创建待办。创建待办不会发送任何内容。如果没有选择**工作**或**个人**，待办会根据相关人员和事项归入合适的区域。系统也会查找待办后续跟进的邮件，包括较早的邮件。

- **截止**：输入日期或时间，也可以用自己的语言输入，例如“明天”“下周五”“11 月 3 日”“下午 2 点”或“2 小时后”。日历图标提供快捷选项和**选择日期**。
- **重复频率**：待办会按固定频率再次出现。请参阅[重复待办](recurring.md)。
- **人员**：关联与待办有关的个人或公司，最多 5 个。
- 消息图标：添加相关消息，包括邮件、Slack、Teams、WhatsApp、Telegram 或 The Machine 中的其他消息。可按文字或发件人搜索。每条结果都会显示来源、发件人和时间。
- **文件**：点按回形针、粘贴屏幕截图，或将文件拖到表单中。在手机上，点按旁边的相机即可拍照。最多可添加 5 个文件，与聊天中的限制相同（请参阅[添加文件](card-chat.md#add-files)）。点按 × 可移除文件。

文件会保留在待办中，The Machine 处理待办时会读取这些文件。只添加文件也可以：The Machine 会根据 PDF 或文本文件填写待办内容。照片会显示为小图，点按即可查看原图。
