The Machine 会根据你的消息、会议和决策，整理出你联系的人以及正在进行的事项。无需设置，数据会留在你的 The Machine 上。

- [人物](people.md)：你联系过的所有人，以及每个人的摘要和时间线。
- [组织](organizations.md)：他们就职的公司，以及这些公司的人员和项目。
- [项目](projects.md)：正在进行的事项，按阶段显示在看板上，类似 CRM 中的交易。

## 今日更新

每个列表顶部都会显示一行简短提示，说明你的 The Machine 今天更新了什么，例如 **今天更新了 4 位联系人**。点击提示即可查看哪些内容发生了变化；点击姓名可打开对应页面，并展开**近期更改**。今天有更新的行和看板卡片旁会显示一个小圆点。这里只统计你的 The Machine 从午夜起自行进行的更改。

## 筛选和排序

标签页旁的**筛选**可缩小列表范围。每个列表都有自己的筛选条件。人物：亲密度、最近联系时间、组织、所有者、标签和**有打开的项目**。组织：行业、专业领域、规模、国家/地区、最近联系时间、所有者、标签和**有打开的项目**。项目：所有者、看板、阶段、标签、组织、价值、预计结束日期和**超过10天未回复**。

你选中的筛选条件会显示在列表上方，旁边有**清除**。在项目中，列表和看板共用同一组筛选条件。在手机上，筛选条件会以底部面板的形式打开。

排序菜单可更改列表顺序。人物和组织可按亲密度、最近或最早联系时间以及姓名排序，组织还可按规模排序。项目可按最近活动、姓名、阶段、**值**和**结束日期**排序。排序菜单下方的**下载CSV**可将当前标签页保存为电子表格。

## 字段和标签

在人物、组织或项目的字段区域，点击某个值即可修改：点击**保存**或按 Enter 键保存，点击**取消**或按 Escape 键放弃，点击**移除**可清空该字段。

**管理字段**（没有字段时显示**添加字段**）可为该类的所有记录添加或移除字段。点击**新建字段**可添加字段，类型包括文本、数字、日期或列表选项。

点击**+ 添加标签**可添加标签，例如 VIP 或合作伙伴；点击**×**可移除标签。标签会显示在列表中，也可以通过**筛选**查找。

## 生日

人物的生日会显示在联系信息下方，并注明来源：Google 联系人、Google 日历中的生日（生日例行程序会为亲密联系人保存生日）、Facebook 导入、你的笔记或你本人。点击**编辑**可设置或更正生日：填写月份和日期，也可以填写年份（填写后还会显示年龄）。

你填写的生日优先于其他来源，并会保留。点击**移除**可删除生日；联系人信息或导入内容不会将它恢复。

如果还没有生日，可以在字段区域点击**添加生日**。生日例行程序读取的生日与页面上显示的相同。生日属于个人信息，不会分享给团队，即使记录是共享的也一样。

## 导入电子表格

在人物、组织或项目列表的排序菜单下方，点击**导入CSV…**即可添加以 CSV 格式保存的电子表格。

1. 检查列。你的 The Machine 会根据列标题和内容推测每列的类型，你可以更改任何推测结果。如果模型可以运行，它也会检查这些列，并在不确定时简要说明原因。它只能看到列标题、每列的少量值，以及规则无法读取的单元格。
2. 检查修正内容。**审核**会以修改前和修改后的形式列出修正项：多余空格、全大写姓名、国际格式的电话号码、电子邮件拼写错误（gmial.com）、仅保留域名的网站、各种格式的日期和值（“€12k”会转换为 12000）、同一单元格中的多个标签、拼写不同的阶段，以及重复行。取消勾选某种修正或某一行，即可保留原样。
3. 检查预览。每一行都会标记为新增、与 Graph 中已有记录匹配，或跳过，并说明原因。人物按电子邮件匹配（没有电子邮件时按姓名和组织匹配），组织按网站或名称匹配，项目按名称匹配。
4. 点击**导入**即可添加新记录并填充匹配记录。空单元格不会更改任何内容。

导入后可立即点击**撤销**，也可以在排序菜单下方点击**撤销上次导入**，前提是这些记录自导入后没有更改。如果撤销会覆盖之后的修正，系统会说明原因。文件会保留在你的 The Machine 上。

## 所有者

在工作 Fleet 中，每个人物、组织和项目都有一位所有者，显示在对应页面「与你相关」下方的**所有者**处。默认是你，也可以选择工作 Fleet 中的其他人。筛选中的**所有者**可只显示属于你的记录。每次更改都会显示在时间线中。

## 团队

点击「我的」旁的**团队**，即可查看队友分享的内容，并使用相同的标签页和排序菜单。**筛选**可按分享者、组织（人物）或状态（项目）缩小范围。在这里添加的内容只属于你。

客户工作会与队友的 Machines 共享，包括所有者、字段和标签；队友分享的内容也会显示在你的 Machine 中。每个对话串都会标记为**团队**或**只有你**。请参阅[团队 Graph](team-graph.md)。
