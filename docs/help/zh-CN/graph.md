你的 Machine 会根据你的消息、会议和决策，绘制一张关系图，展示你与谁联系，以及正在发生什么。无需设置，数据也会留在你的 Machine 上。

- [人物](people.md)：你联系过的所有人，每个人都有摘要和时间线。
- [组织](organizations.md)：他们工作的公司，以及公司中的人员和项目。
- [项目](projects.md)：正在进行的事项，按阶段显示在看板上，就像 CRM 中的交易。
- [笔记](notes.md)：每个主题都有一个易读的页面，例如旅行或家。

## 今日更新

每个列表顶部都有一行提示，告诉你今天的 Machine 更新了哪些内容，例如**今日更新了4位联系人**。点按即可查看更改了谁、什么内容；点按姓名可打开对方的页面，并展开**近期更改**。每个今天有更改的行和看板卡片旁都会显示一个小圆点。这里仅统计你的 Machine 从午夜起自行进行的更改。

## 筛选和排序

标签旁边的**筛选**可以缩小列表范围。每个列表都有自己的筛选条件。人物：亲密度、最近联系时间、组织、所有者、标签和**有打开的项目**。组织：行业、专业领域、规模、国家、最近联系时间、所有者、标签和**有打开的项目**。项目：所有者、看板、阶段、标签、组织、金额、预计结束日期和**超过10天未回复**。

所选筛选条件会显示在列表上方，旁边有**清除**。在“项目”中，列表和看板共用一个筛选条件。在手机上，筛选条件会以底部弹层的形式打开。

排序菜单可以对列表排序。人物和组织可以按亲密度、最近或最早联系时间以及姓名排序，组织还可以按规模排序。项目可以按最近活动、名称、阶段、**值**和**结束日期**排序。排序菜单下的**下载CSV**会将当前标签页保存为电子表格。

## 字段和标签

在人物、组织或项目的“字段”下，点按某个值即可更改：点按**保存**或按 Enter 保存，点按**取消**或按 Escape 放弃更改，点按**移除**清空该值。

**管理字段**（没有字段时显示**添加字段**）可以为该类型的所有记录添加或移除字段。**新建字段**可以添加文本、数字、日期或列表选项字段。

**+ 添加标签**可以添加标签，例如 VIP 或合作伙伴；点按**×**可移除标签。标签会显示在列表中，也可以通过**筛选**查找。

## 生日

联系人的生日会显示在“联系信息”下方，并注明来源：Google 联系人、Google 日历中的生日（生日例行程序会为亲密联系人保存生日）、Facebook 导入、你的笔记，或你手动添加。点按**编辑**即可设置或更正生日：填写月份和日期，知道年份的话也可以填写（填写后还会显示年龄）。

你手动填写的生日优先于所有其他来源，并会保留。点按**移除**后会删除生日；联系人信息或导入数据不会再次添加它。

如果没有生日，可以在“字段”下点按**添加生日**。生日例行程序读取的生日与页面显示的相同。生日属于个人信息，即使记录已共享，也不会分享给团队。

## 导入电子表格

在“人物”、“组织”或“项目”的排序菜单下，点按**导入CSV…**即可添加以 CSV 格式保存的电子表格。

1. 检查列。你的 Machine 会根据列标题和内容猜测每列对应的字段，你可以修改任何猜测结果。如果你的模型可以运行，它也会检查这些列；不确定时会简要说明原因。它只能看到列标题、每列的少量值，以及规则无法读取的单元格。
2. 检查修正内容。**审核**会以修改前后对照的方式列出修正内容：多余空格、全大写姓名、国际格式的电话号码、电子邮件拼写错误（gmial.com）、以域名形式填写的网站、任意格式的日期和值（“€12k”会转换为 12000）、同一单元格中的多个标签、拼写不同的阶段，以及重复的行。取消勾选某种修正或某一行，即可保留原样。
3. 检查预览。每一行都会标记为新记录、与 Graph 中已有记录匹配，或跳过，并说明原因。人物按电子邮件匹配（没有电子邮件时，按姓名和组织匹配），组织按网站或名称匹配，项目按名称匹配。
4. 点按**导入**添加新记录并填写匹配记录中的信息。空单元格不会更改任何内容。

导入后可以立即点按**撤销**，也可以在排序菜单下点按**撤销上次导入**，撤回最近一次导入，前提是这些记录自导入后没有更改。如果撤销会覆盖之后的修正，系统会说明原因，而不会撤销。文件会留在你的 Machine 上。

## 所有者

在 Work Fleet 中，每个人物、组织和项目都有一个所有者：页面“与你相关”下方的**所有者**。默认是你，也可以选择 Work Fleet 中的其他人。筛选中的**所有者**可以只显示归你所有的记录。每次更改都会显示在时间线中。

## 团队

点按“我的”旁边的**团队**，即可查看队友分享的内容，并使用相同的标签和排序菜单。通过**筛选**可以按分享者、组织（人物）或状态（项目）缩小范围。在这里添加的内容归你所有。

客户工作会与队友的 Machines 共享，包括所有者、字段和标签；队友的内容也会显示在你的 Machine 中。每个会话都会标记为**团队**或**只有你**。请参阅[团队 Graph](team-graph.md)。
