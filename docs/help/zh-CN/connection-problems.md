## 查看状态

打开 **连接**。每个来源都会显示当前状态：

- **正在自动重新连接**：暂时出了点问题，系统会自动重试。
- **等待首次同步**：刚刚连接，请等几分钟。
- **再次读取时间** 07:00：X 和 LinkedIn 只会在白天读取内容。无需操作。
- **需要你帮忙**：打开 **详情**，查看出了什么问题以及该怎么处理。
- **手机已断开连接**：你的 Android 手机无法连接到你的 Machine。请在手机上打开 OpenClaw 应用。

如果某个来源长时间没有同步内容，会显示 **等待新一轮同步**。同步成功后，此状态会自动消失。

**连接**上的数字只统计需要你帮忙的来源。

## 常见解决方法

- “请重新登录 Google”（或 Microsoft）：点击一次 **重新连接**，即可恢复该账号的所有来源，例如 Gmail 和日历。
- “需要你重新登录”：点击 **重新连接**并登录。
- Microsoft 仍在设置访问权限：系统会自动重试。
- Slack：点击 **重新连接**。如果是用 Maton 密钥连接的，请检查密钥和 Maton 中的 Slack 连接。
- Android：在手机上打开 OpenClaw 应用，并允许其访问通知。

在自己的电脑上运行 `assistant doctor`，即可检查所有来源并查看每个问题的解决方法。

还是无法解决？请参阅[获取支持](get-support.md)。
