## 创建例行程序

在侧边栏中打开 **例行程序**，用一句话说明要做什么、何时做，例如：“每周一早上 9 点，汇总未完成的交易”或“每个工作日早上，列出我还没回复的邮件”。然后点击 **添加**。

如果没有指定时间，它会在 8:00 运行。时间以你的 Machine 时钟为准。第一次运行后，它会获得一个简短名称。

点击 **添加** 会先试运行，让你先看看结果再决定是否保留。试运行不会发送或保存任何内容。然后，点击 **添加** 会让它按设定的节奏运行；点击 **更改** 可以尝试其他描述或新名称；点击 **取消** 则会将其删除。

## 模板

在例行程序页面底部的 **模板** 中，点击 **添加** 即可启用现成的例行程序。它会立即运行一次，然后每天早上 7:30 运行（清理垃圾邮件每小时运行一次，二手好物每 3 小时运行一次，订阅和试用期每月运行一次）。它的卡片会像其他例行程序一样显示具体内容，点击 **编辑** 可以修改内容或名称。

如果收到很多邮件简报，而邮件简报清理处于关闭状态（一周内收到 25 封或更多，且至少来自 5 位发件人），待办事项上方会显示收到的邮件数量和它会采取的操作，并提供 **开启** 和 **不了，谢谢** 两个选项。

如果一周内有 5 封或更多邮件被手动移入垃圾邮件，也会以相同方式推荐清理垃圾邮件。点击 **开启** 会像这里的 **添加** 一样启用它。点击 **不了，谢谢** 后不会再推荐；如果你之前用过这个模板，也不会再次推荐。

**邮件简报清理** 会按类别（工作和个人）各创建一个待办事项，其中列出过去一天收到的邮件简报，每封邮件都可以选择 **保留** 或 **退订**。退订时会使用邮件列表提供的一键退订链接，或者在允许发送邮件时，从你的地址发送退订邮件。否则，The Machine 会在自己的浏览器中打开邮件列表页面并退订。如果需要登录、完成验证码或进行选择，都需要你自己操作。对应的邮件会说明原因，并提供 **打开取消订阅页面**。

收据、订单和付款通知不会列出。通过群组地址（例如 Google Group）收到的邮件会归到发件人名下，也不会让你退订群组。如果发件人没有提供退订方式，对应邮件会显示 **手动退订**。

**清理垃圾邮件** 会按类别各创建一个待办事项，列出看起来像垃圾邮件的陌生发件人邮件，每封邮件都可以选择 **垃圾邮件** 或 **不是垃圾邮件**。Outlook 会将垃圾邮件移到“垃圾邮件”文件夹，Gmail 会将其标记为垃圾邮件。它每小时检查一次，所以你通常能及时发现垃圾邮件。只要待办事项还未完成，新发现的垃圾邮件就会继续添加到其中。

以只读方式连接的 Gmail（例如托管版 Machine）无法将邮件移入垃圾邮件文件夹。在这种情况下，点击 **垃圾邮件** 会显示一个链接，让你在 Gmail 中标记邮件；The Machine 也会记住该发件人是垃圾邮件发件人。如果没有连接邮箱，模板会显示 **连接邮箱**，而不是 **添加**。

“陌生发件人”指你从未联系过的人；只有在你发起的邮件对话中，主题以“Re:”开头的邮件才会被视为对话的一部分。如果你之前在待办事项中或邮箱里将某位发件人的邮件标记为垃圾邮件，但之后又收到对方的邮件，下一条待办事项会将其标记为 **之前已标记为垃圾邮件**。你手动移入垃圾邮件的邮件也有助于它识别类似邮件。

只有在待办事项中确认后，操作才会生效。点击发件人可以先阅读邮件：邮件仍会保持未读，且不会发生任何变化。在清理垃圾邮件中，网页图片不会加载，因此发件人无法知道你打开过邮件。你已经做出决定的发件人不会再次询问。如果某天没有邮件简报或垃圾邮件，就不会创建待办事项；这些待办事项也不会发送通知。

决定好所有发件人的处理方式后，待办事项会显示已完成，并提供 **标记为已完成**。

**每日摘要** 每天会将值得你关注的少数邮件简报内容整理到一个待办事项中。每条内容都会用一句话说明它为什么与你相关。点击内容即可阅读邮件，也可以点击 **在邮件中打开**。它只处理邮件简报，不会处理个人邮件、收据或你已退订的发件人邮件，也不会处理你已经读过的内容。如果没有值得关注的内容，就不会创建待办事项。

它会根据你打开、加星标或未读归档的内容，以及你对每条推荐内容选择 **多来点这样的** 或 **减少类似内容**，逐渐了解你关注什么。它会挑选的主题显示在例行程序卡片上的 **更多** 和 **减少** 下。点击 × 可移除主题，也可以添加自己的主题。虚线框中的主题是它自行学到的。新的摘要会替换尚未处理的摘要，也不会发送通知。

它只读取每封新邮件简报的发件人、主题和开头内容，并每天向你的 AI 提出一个简短问题，数量有上限，以控制成本。点击 **更改时间** 可以调整运行时间。修改描述后，它就会像其他例行程序一样，按照你写的内容运行。

**生日** 会为今天过生日的亲近联系人各创建一个待办事项：也就是你会主动联系的人，例如朋友、家人和经常联系的人。每个待办事项都会附上一段简短的祝福草稿，放在你通常与对方聊天的地方，例如他们的 WhatsApp 聊天或你们的邮件对话中，并使用对方的语言。只有你发送后，祝福才会发出。如果当天没人过生日，就不会创建待办事项。

生日信息来自你的日历（Google 的生日活动和“生日”日历，即使尚未同步也会每天早上读取；以及 Outlook 的“生日”日历）、自托管 Machine 上的 Google 联系人，以及 Graph 中联系人名为 Birthday 的日期字段。如果这些来源都没有生日信息，结果会显示 **暂无生日信息**，并说明如何添加。

**从Facebook导入生日**：启用生日后，会有一条待办事项提示读取 Facebook 的生日页面。点击 **导入** 后，The Machine 会在自己的浏览器中打开该页面，滚动页面，直到加载完所有月份，然后读取每位好友的姓名和生日。它会显示找到的生日数量，以及其中有多少人能通过名字和姓氏与 Graph 中的联系人匹配。如果多人同名，就会跳过并列出这些姓名。

只有点击 **保存** 才会保存信息，并写入每个人的个人资料页面：包括生日，以及尚无头像的人的 Facebook 头像。你在该页面设置的生日或头像会保留；已有头像不会被替换。不会向 Facebook 写入任何信息。

它不会自动重新读取。点击待办事项中的 **重新导入** 才会再次读取。浏览器必须已登录 Facebook。如果尚未登录，点击待办事项中的 **登录Facebook** 并在那里登录；登录后，它会自动读取页面。The Machine 不会替你登录。

Graph 中没有对应联系人的好友会计入数量，并显示几个姓名。点击 **添加……为个人联系人** 可一次性添加所有这些人，即使你已经点击过“保存”也可以：每个人都会添加姓名和生日，而且绝不会与 Work Fleet 共享。若 Graph 中已有同名联系人，或你曾永久删除过同名联系人，则会跳过。只有你会主动联系的人才会收到生日提醒。

在待办事项中点击 **撤销**，即可准确移除这些人，即使是在点击 **重新导入** 后也一样。

**订阅和试用期** 每月会读取收据、发票和续订通知，并将订阅汇总到一个待办事项中：包括每项订阅的费用、下次扣款时间，以及试用期即将结束或价格上涨的标记。只会列出它能确定的订阅。如果没有找到任何订阅，就不会创建待办事项。

为每项订阅选择 **保留** 或 **取消**。选择保留后，除非价格发生变化，否则不会再次询问。点击 **取消** 会提供取消页面，或一封请求对方取消的草稿。只有你发送后，草稿才会发出。两次月度运行之间，它会每天检查；如果试用期或续订将在 7 天内扣款，就会创建待办事项。

**保持联系** 会时不时提醒你联系亲近的人，但只有确实有理由时才会提醒。在它的卡片上，从简短名单中选择要包含的人。名单中的人都是你几个月来一直互相联系的人。点击 × 可移除联系人。

只有当你比平时隔了更久没有联系对方，而且有具体的联系理由时，才会出现提醒，例如对方分享的近况、尚未兑现的承诺，或你一直没有回复的消息。它会创建一个待办事项，说明提醒原因，并在你通常联系对方的地方用对方的语言写一段简短草稿。只有你发送后，消息才会发出。没有可说的内容时，就不会创建待办事项。

它每周最多发送两条提醒，每人每月最多一条，而且不会提醒你刚联系过的人。在提醒上选择 **不需要**，下次提醒这个人的等待时间就会更长；每次选择后，等待时间都会进一步延长。它不会发送通知，而且只保留在个人空间中，绝不会与 Work Fleet 共享。

**二手好物** 会监控二手网站上的搜索结果，例如 Marktplaats、Vinted、eBay 或 Facebook Marketplace。在网站上设置好筛选条件并搜索，然后复制结果页地址，点击 **添加** 后粘贴进去。你也可以用自己的话添加筛选条件，例如“低于 300，30 公里以内，不要‘配件’”。每项搜索都是一个独立的例行程序，想添加另一项搜索时需要再次添加。

它每 3 小时会在 The Machine 自己的浏览器中打开搜索页面，查找尚未见过的商品。它会先用简单代码检查价格、距离和你排除的关键词。

每件符合条件的新商品都会被打开，然后由你的 AI 根据照片和描述判断商品状况，并根据卖家的评价、评分和账号注册时间判断卖家。符合条件的商品会汇总到一个待办事项中，每件商品都附有照片、标题、价格和一句结论。点击商品即可在 The Machine 的浏览器中打开商品页面。

待办事项打开期间，新发现的商品会添加到列表顶部，数量也会增加，并再次通知你，因为好价商品往往很快就会售出。标记为已完成后，下次发现的商品会创建新的待办事项。如果一次运行没有发现合适商品，不会有任何变化。

它会谨慎处理，以控制成本：每次运行只读取一次搜索结果，最多打开 6 个商品，并在打开商品之间暂停；所有搜索合计每天最多检查 40 个商品。每次检查都会向你的 AI 提出一个简短问题，并附上一张照片。第一次运行会检查最新的几个商品，并将其余商品记为已看过，因此之后的运行只会显示新商品。

如果网站要求登录、显示机器人验证或阻止读取，待办事项会说明情况，并提供 **打开**，让你在 The Machine 的浏览器中查看。你需要在那里自行登录或完成验证；下次运行时会再次读取。The Machine 不会替你登录或完成验证，也不会联系卖家、出价或购买。

在例行程序卡片中点击 **修改搜索条件** 可以更换网址或筛选条件，点击 **更改时间** 可以调整运行节奏，例如“每 6 小时运行一次”。

只要模板例行程序保留模板中的内容，它就会使用自己的代码运行，不会消耗你的 AI 计划额度（清理垃圾邮件会先用代码列出陌生发件人的新邮件，只有发现邮件时才会向你的 AI 提出一个简短问题；保持联系只会询问它选出的一个或两个人）。改名不会改变这一点。修改内容后，它就会像其他例行程序一样，按照你写的内容运行。

邮件简报清理和清理垃圾邮件仍会为每封邮件创建一个带有选项的待办事项。编辑生日后，它会显示结果，最多附带一份草稿，不会为每个人分别创建待办事项。在 **编辑** 中点击 **恢复为模板**，即可还原模板内容。

## 例行程序的运行方式

到达设定时间后，你的 Machine 会读取所需内容，例如消息、会议和 Graph，然后将结果显示在例行程序页面上。每次运行的结果都会显示 **已备好**、**暂无新内容**（并说明原因）或 **没起作用**（并说明原因）。如果运行结束时没有产生结果，就算作运行失败，而不是完成。

例行程序只会读取信息，例如消息、网页、GitHub，以及浏览器中的 X 等网站。它们不会发送消息、回复、发布内容或更改任何内容。只有模板会修改邮件，而且只会执行你在其待办事项中确认的操作。

如果例行程序要以发布内容或发送消息作为最后一步，它会先完成此前的所有步骤，然后显示草稿，例如 **准备发布到 X：**。实际运行后，草稿会作为待办事项出现，供你批准；试运行只会显示草稿。待办事项名称会说明内容和发布位置，按钮会注明操作步骤，例如 **发布**，下方的 **来自你的例行程序** 会打开该例行程序。

待办事项会默认归入要发送内容的账号所属区域，例如，使用公司的 X 账号时会归到“工作”。因此，它不会询问你是否要移动待办事项。

运行时可以根据例行程序的工作内容，使用已启用的[技能](skills.md)：只有适用的技能才会被完整读取。结果会在 **已使用：** 下列出这些技能。技能不会让例行程序发送或更改任何内容。

你的例行程序会显示在 **你的例行程序** 下方，排在所有建议之后。较长的结果会折叠成简短预览；点击 **展开** 或直接点击预览即可打开完整内容。

每次运行都会记住上一次的结果，因此可以说明自上次以来有哪些变化。

成功运行后，你的 Machine 可能会为每次都相同的读取操作编写一份配方，例如要查看哪些邮件或 GitHub 变更。下次运行时会先用简单代码读取这些内容，再由 AI 挑选重要信息并撰写结果，从而减少 token 用量。配方只会读取信息；如果配方失效，运行会自动读取并修复。它会显示在 ⋯ 菜单中的 **高级：脚本步骤** 下。

## 错过的日期

如果你的 Machine 处于关闭或忙碌状态，错过的运行不会累积：只会运行最新的一次，而且只运行一次。每个日期只会运行一次，即使重启后也一样。

例行程序会逐个运行；和所有后台任务一样，如果 AI 计划的用量较低，它们会等待。点击 **立即运行** 可立刻运行；结果准备好后会显示在卡片上。

## 修改或停止

这些操作都在例行程序的 ⋯ 菜单中。点击 **编辑** 可以更改名称和工作内容；运行时间和已有结果会保留。点击 **更改时间** 可以用自己的话设置新的运行节奏，例如“每个工作日早上 8 点”。两种操作都可以点击 **保存** 或 **取消**；在电脑上也可以按 Esc 键或点击外部取消。

在 **编辑** 中点击 **试用**，即可按新内容运行一次并在此查看结果。点击 **保存** 之前，例行程序仍会保持原样。

点击 **暂停** 会停止运行，直到在卡片上点击 **恢复**。已暂停的例行程序会显示在你的例行程序下方的 **已暂停** 区域；暂停期间错过的运行之后不会补上。点击 **停止** 会永久结束例行程序。

最多可创建 20 个例行程序，包括已暂停的例行程序。要添加更多例行程序，请先停止一个。

如果你在例行程序的待办事项中点击 **要求修改**，或在它的聊天中留言，而且你的要求是针对之后每次运行的，例如“不要使用表情符号”，待办事项和聊天回复下方都会显示 **同时更改例行程序**。它会显示例行程序内容将如何更改；只有点击 **更改** 后，例行程序才会更新。点击 **保持原样** 则不会更改。如果只是修改当前草稿，就不会显示此选项。

## 高级：脚本步骤

无需编写脚本：用自己的话说明例行程序要做什么，你的 Machine 会处理其余部分。

高级用户也可以让例行程序在自己的 Machine 上运行自定义命令：打开 ⋯ 菜单，然后选择 **高级：脚本步骤**。只有例行程序已有脚本步骤时，点击 **编辑** 才会显示这些步骤。点击 **获取数据** 会先运行一条命令，在指定文件夹中执行（如果未指定，则使用主目录），运行时间不超过设定的秒数。命令输出的内容会提供给本次运行使用。如果没有其他说明，命令输出的内容就是运行结果。

**检查** 会在运行后将结果作为输入。如果命令以错误状态退出，运行结果会显示 **没起作用**，并附上检查结果中的信息。获取数据命令失败时也会以相同方式显示。

命令必须写成一行，并且不会通过 shell 执行：不支持管道或变量。脚本步骤由你自行设置，只会保存在你的控制面板中。试运行和 **试用** 也会运行获取数据命令，并会明确说明；但仍然不会发送或保存任何内容。例行程序不会发送任何内容，因此脚本步骤也只能用于读取。

## 来自你的 OpenClaw 任务

如果你之前在 OpenClaw 中创建过定时任务，你的 Machine 会读取这些任务（但绝不会更改它们），并将适合作为例行程序的任务列在 **建议的** 下。每个建议任务都已经运行过一次，因此你可以看到真实结果。

它会保留你对任务内容的修正，并去掉任务曾发送或发布的内容。如果任务运行过脚本，或读取过脚本任务收集的内容，会一并将其作为获取数据步骤带入。点击 **添加** 会将其创建为例行程序；点击 **不了，谢谢** 后就不会再询问该任务。如果任务会提醒你做某件事，它会改为在待办事项中推荐定期待办事项。

添加建议之前，可以在 ⋯ 菜单中使用 **编辑** 和 **更改时间**，像修改其他例行程序一样调整它。点击 **再次运行** 可按当前内容立即运行一次，查看更新后的结果，例如在安静的周末之后重新运行。它只会读取内容；每次点击只运行一次，新结果会替换旧结果。

同时最多会有三条待处理建议。例行程序成功运行一周后，会询问 **要关闭旧的OpenClaw任务吗？**。只有点击 **关闭** 才会关闭旧任务；你可以在 OpenClaw 中重新开启。点击 **保留** 则会让两个任务继续运行。

## 根据你的操作提供建议

即使没有使用 OpenClaw，你的 Machine 也会留意你定期进行的工作，并在 **建议的** 下提供例行程序建议。它会查找以下情况：

- 连续三次或更多次提出相同要求，例如每周一都说“汇总未解决的支持工单”；
- 定期发送的邮件，例如每周发给团队的报告；
- 每周持续收到的邮件简报和更新邮件；
- 其他人每周都会在其中发言的繁忙 Slack 频道；
- 你逐封转发给同一个人的邮件，例如转发给伴侣的学校和俱乐部邮件。为对方整理每周摘要，可以省去转发操作；
- 你定期回复的相同请求，例如每月批准同一个人的申请。

每条建议都会说明发现了什么，例如“连续提出了 4 次”或“3 周内向 Sam 转发了 6 封邮件”，而且已经运行过一次，因此你可以看到真实结果。你可以用它来整理团队周报、准备每周会议简报、汇总支持或开发进展、跟踪数据变化，或整理收到的邮件简报。

它只会推荐与你本人相关且确实有用的内容：新闻摘要只会根据你自己的邮件简报生成，不会生成通用摘要。如果没有合适的内容，就不会提供建议。

它每天最多检查一次，每周最多添加一条新建议，也不会发送通知。点击 **不了，谢谢** 后，那条建议就不会再出现。转发和回复会保留在原发送账号中，因此工作和个人内容不会混在一起。所有内容都保留在你的 Machine 上。定期关闭的待办事项会改为推荐定期待办事项。

## 例行程序和定期待办事项

[定期待办事项](recurring.md)会提醒你去做某件事。例行程序则由你的 Machine 自动完成工作，并向你展示结果。像“每月 1 号付房租”这样的事情适合用定期待办事项；像“每周五告诉我哪些交易已经没了动静”这样的事情适合用例行程序。
