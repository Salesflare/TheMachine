当看板上的联系人不再回复时，你的 Machine 会用你的语气，在同一段对话中为你起草跟进消息。此功能默认关闭，开启后才会运行。如果看板适用你的某项技能，草稿就会遵循该技能，包括邮件内容的先后顺序。

## 开启跟进

点击看板上的 **⋯**，然后选择 **跟进…**，勾选 **未收到回复时跟进**。设置会应用于看板上的所有项目。你也可以点击看板名称下方的 **已关闭跟进**，或在包含 10 天以上未获回复项目的阶段中点击 **跟进他们**。

若要为单个项目设置跟进，请点击看板上该项目的 **⋯**，或前往项目页面并点击 **跟进…**。选择 **用于此项目**，再选 **已开启**、**关闭**，或沿用看板设置。项目自己的设置优先于看板设置。

## 设置

- 默认情况下，等待 3 到 7 天仍未收到回复。等待时间最短后会起草跟进消息，最长后会发送，即使你的用量紧张也一样。
- **仅限工作日**：休息日不会起草或发送消息（休息日设置位于 **设置** > **通知** > **工作时间**）。这期间到期的跟进会等到下一个工作日早上处理。工作看板默认开启，个人看板默认关闭。
- 默认跟进 1 到 3 次。系统总会发送最少次数，并为其余次数起草消息。如果系统认为最好停止，草稿会说明原因（“The Machine 会在此停止：自 8 月以来有 9 封邮件未获回复”），且不会勾选。你可以发送、跳过，或选择 **停止在此处跟进**。跟进次数绝不会超过上限。
- **阶段**：默认选择 **所有未完成阶段**，不包括看板的最后一个阶段，也不包括“停滞或已拒绝”。点击 **自定义** 可开启或关闭阶段，也可以为某个阶段单独设置等待时间。
- **频道**：选择已连接且可用于发送的频道。跟进消息会通过上一条消息使用的同一频道发送。开启 **未收到回复时切换渠道** 后，系统会尝试下一个允许使用的频道。
- 如果看板有“停滞或已拒绝”这一行，**最后一个之后移至停滞或已拒绝** 默认开启。

## 发送前询问或自动发送

默认选择 **发送前先问我**：草稿会留在待办中。选择 **直接发送**，即表示持续允许该看板或项目自动发送。任何异常情况或发送失败仍会等待你处理，且谨慎级别始终会先询问。跟进消息绝不会重复发送。跟进不会通过推送或邮件通知你，草稿会留在待办列表和早间摘要中。

发送前，系统会重新检查对话。如果草稿创建后有人发了消息，就不会发送，并会显示“未发送：对话中有新消息”。待办会显示该消息、发送者和时间，并提供 **阅读它** 和 **为这条消息重新执行**。选择后者会重新起草消息，并考虑这条新消息。

## 查看跟进

看板上的跟进会合并为一个待办，而不是每封邮件各一个。起草期间会显示“正在撰写 3 条跟进…”，完成后会显示“Alpha 测试人员有 8 条跟进已备好”。

点击 **审核**，即可逐条查看完整内容，只需滚动一次就能看完。当前跟进会显示 **发送**、**编辑** 和 **跳过**。使用键盘时，按 j 和 k（或方向键）移动，按 Enter 发送，按 e 编辑，按 s 跳过（再次按下可撤销），按 x 勾选或取消勾选，按 c 修改。点击 **发送所有已勾选项**，即可发送仍处于勾选状态的跟进。

每条跟进都会附带草稿。如果无法撰写，系统会说明需要先补充什么（“没有草稿。需要先提供：收件人。”），且不会勾选；点击 **撰写** 仍可要求系统起草。如果草稿有多个可能的收件人，系统会显示“选择收件人：点击发送时选择”，点击 **发送** 后即可选择。

点击 **跳过** 会取消勾选草稿，并将它移到列表底部，标记为“已跳过”，同时提供 **撤销**。关闭审核后，该草稿才算正式跳过。如果没有更新的跟进，之后可以在项目的跟进列表或“已完成”中的待办里点击 **恢复**，重新显示已跳过的跟进。单个项目的跟进会作为普通待办处理。

点击 **要求修改…**，即可按照你的要求重写所有已勾选的草稿，或仅重写当前草稿。此操作不会发送任何消息，点击 **撤销更改** 可恢复原文。修改框打开期间或重写过程中，无法发送消息。修改过的草稿会再次显示，供你确认后发送。

连续发送多条消息时，即使选择了“直接发送”，每个邮箱也会每隔 30 到 45 秒发送一条。待办会显示发送进度，例如“正在发送第 3 条，共 8 条…”。点击 **停止发送** 可停止剩余发送：已经开始发送的消息仍会发出，其余消息会作为草稿返回审核列表，之后可以再发送（“已停止。已发送 1 条，另有 11 条保留为草稿。”）。

## 你的 Machine 读取邮箱前发送的邮件

你在其他应用中发送的邮件，即使是在你的 Machine 读取该邮箱之前发送的，也会计入。系统会读取整段对话；如果无法读取，就会查看你最近一封邮件中引用的早期邮件。因此，连续三封邮件没有回复，就会计为三封，“未回复时长”也会从第一封开始计算。如果已经达到上限，系统就不会再起草跟进。

## 停止跟进的情况

对方回复、项目已赢单或已流失、项目已归档或移至已关闭阶段，以及你稍后处理或跳过跟进时，跟进都会停止。起草前，你的 Machine 会检查对话中是否有更新，以免在对方已通过其他渠道回复后仍继续催促。

点击 **跟进…** 中的 **暂停**，即可暂停看板或项目的跟进，而不必关闭跟进功能。暂停期间不会起草或发送消息，跟进轮次也不会结束，尚未完成的跟进待办会继续保留。你可以选择恢复日期，也可以在准备好时点击 **恢复**。等待时间会从暂停处继续计算，到期的跟进会逐条处理。暂停期间会显示 **已暂停**。

最后一条跟进发出后仍未收到回复，项目会显示“跟进 3 次后仍未收到回复”。如果已开启相应设置，项目还会移至“停滞或已拒绝”。如果在发出任何跟进前就停止，项目会显示“跟进已停止”，并留在当前阶段。

如果对方的邮箱退信，且对方还有其他地址，跟进会改发到其他地址（“邮件退信，现改发至 <address>”）。如果草稿对应的地址在发送前退信，系统会暂缓该草稿，并显示“未发送：<address> 退信”，然后将跟进改发到对方的其他地址，等待你发送。

如果对方没有其他邮箱地址，且允许使用 LinkedIn 或 WhatsApp，并且你已在该渠道与对方联系，跟进就会改到该渠道发送。否则，跟进会停止，并显示“邮件退信”。如果项目很重要，系统会创建待办，让你查找新的邮箱地址。

## 查看跟进

看板标题栏会显示“跟进已开启，下次为周四”。看板上的项目会显示下次跟进时间，或提示跟进已备好。项目页面会列出已发出的跟进，包括自动发送的内容。

你的 Machine 忙碌或接近用量上限时，跟进会暂缓，之后再继续。共享看板上的跟进仅由项目所有者的 Machine 处理。
