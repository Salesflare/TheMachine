跟踪你承诺要做的事，以及别人承诺给你的事。你的 Machine 会自动从消息中识别承诺。

## 承诺在哪里

在待办事项页面的 **承诺** 下：

- 你说要做的事，以及你要为谁做：**你已承诺**。
- 别人说要做的事：**承诺给你**。

每项都有一个 **⋯** 菜单：

- 对你自己的承诺，选择 **执行**：它会立即变成待办事项，你的 Machine 会为你准备好。对别人的承诺，选择 **提醒**：你的 Machine 会在对方做出承诺的地方起草一条简短的跟进消息，同时让你留在列表中。会显示一条简短提示，说明消息即将发出，并提供 **打开待办**；这条承诺也会显示“现在是待办事项”。发送前不会发出任何内容。如果它已经是待办事项，就会打开该待办事项。
- **标记为已完成**：承诺已兑现。
- **不会发生**：这件事不会发生，因此你的 Machine 会停止跟踪，也不会创建待办事项。

未关闭的承诺也会在截止时自动变成待办事项（你自己的承诺会在截止日期前一天早上变成待办，这样你有一天时间处理），并显示在 [日历](calendar.md) 对应的日期上。已经变成待办事项的承诺会链接到该待办事项；选择 **标记为已完成** 或 **不会发生**，也会关闭该待办事项。当你的 Machine 发现事情已完成时，两者都会关闭，并显示一条说明。

已经兑现了呢，比如你已回复，或相关会议已经结束？它会自动关闭，不会创建待办事项。

后来有了新的日期，比如“改到下周”？同一条承诺和它的待办事项都会改期，不会再创建一条。承诺页面会显示新日期和较新的消息。

没有日期的承诺会有一个**跟进**日期：你做出承诺后三天，别人做出承诺后一周。到那时还未关闭？它就会变成待办事项。

来自 Slack 的承诺会显示对方的姓名。

来自你从未联系过的人的邮件承诺也会被记录，并标记为**未经验证的发件人**：这只是对方的说法。对应的待办事项会以“未经验证：你以前没有联系过对方。”开头。

[每周回顾](weekly-recap.md)会统计已兑现和未关闭的承诺。在你自己的电脑上，`assistant promises` 会在终端中列出这些承诺。
