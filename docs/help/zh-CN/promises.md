追踪你承诺要做的事，以及别人承诺为你做的事。你的 Machine 会自动从消息中识别承诺。

## 哪里查看

在待办事项页面的 **承诺** 下：

- 你承诺要做的事，以及承诺对象：**你已承诺**。
- 别人承诺要做的事：**承诺给你**。

每项承诺都有一个 **⋯** 菜单：

- 对你自己的承诺选择 **执行**：它会立即变成待办，你的 Machine 会为你做好准备。对别人的承诺选择 **提醒**：你的 Machine 会在对方作出承诺的地方拟好一条简短的跟进消息，同时让你留在列表中。你会看到一条简短提示，说明消息即将准备好，并显示 **打开待办**，承诺也会显示“现在是待办”。发送前不会发出任何内容。已经是待办的承诺会直接打开对应待办。
- **标记为已完成**：表示承诺已兑现。
- **不会发生**：表示这件事不会发生，你的 Machine 会停止追踪，也不会创建待办。

未完成的承诺也会在日期前后自动变成待办（你自己的承诺会在前一天早上变成待办，让你有一天时间处理；别人的承诺会在当天早上变成待办，前提是仍未完成），并显示在 [日历](calendar.md) 对应日期。已经变成待办的承诺会链接到该待办，选择 **标记为已完成** 或 **不会发生** 也会关闭对应待办。你的 Machine 发现事情已完成时，会同时关闭两项，并附上一条说明。

如果回复只是承诺会完成这件事，比如“我会在周二前发送文件”，并不代表待办已完成。待办会保持未完成，并保留该日期，承诺也会链接到待办。发送前，发送确认页面会说明这一点。

如果事情已经兑现，比如你已发送回复，或相关会议已经举行，承诺会自动关闭，不会创建待办。

如果之后给了承诺一个新日期，比如“改到下周吧”，同一项承诺和它的待办都会改期，不会再创建一项。承诺页面会显示新日期和较新的消息。

没有日期的承诺会有一个**跟进日期**：你作出的承诺是三天后，别人作出的承诺是一周后。如果到那时仍未完成，就会变成待办。

来自 Slack 的承诺会显示对方姓名。

如果通过邮件收到从未联系过的人的承诺，也会被记录，并标记为 **未经验证的发件人**：这只是对方单方面的承诺。对应待办开头会显示“未经验证：你之前没有联系过对方。”

## 退款

商店、航空公司、房东或保险公司承诺退款时，比如承诺退还已取消订单的款项，或支付已获批的理赔，你的 Machine 会记录金额、付款方和预计到账日期。只有消息明确说明这三项信息时，才会显示在 **承诺给你** 下。

如果退款先到账，比如收到“退款已处理”的邮件、支付服务的通知，或手机银行应用的通知，承诺会自动关闭，不会创建待办。

到了预计到账日还没收到退款？系统会创建一项不会打扰你的待办：“跟进来自……的 42 欧元退款”，并拟好一封简短邮件，注明订单号或案件编号。发送前不会发出任何内容。如果之后退款到账，待办会自动关闭。**撤销**可以在一天内恢复它。

[每周回顾](weekly-recap.md)会统计已兑现和未完成的承诺。在你自己的电脑上，可以在终端运行 `assistant promises` 查看这些承诺。
