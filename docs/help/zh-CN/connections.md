## 查看连接状态

**连接**标签页会按类型列出你的来源，并在分隔线下方显示**登录方式**和**检查**。在手机上，点按某个类型可打开它，点按**连接**可返回。如果某个类型下有来源需要你处理，它会优先打开。每个来源显示为一行：当前状态（已连接、等待首次同步、正在自动重新连接或需要你处理）以及最近收到的内容。点按来源可打开它的卡片和**详情**。

如果后续同步已补上之前失败的同步，失败记录会显示为灰色。只有最近一次同步仍然失败时，才会显示为问题，并注明下次重试时间。

计数会显示来源引入的所有内容，包括其[历史记录](history.md)、过去 24 小时收到的内容，以及尚未检查的内容。日历会统计其中的活动。

每个来源都以其账号名称命名，名称由对应服务提供，例如你的邮箱地址、X 个人资料、Slack 工作区，或 Signal 或 Telegram 账号的所属者。名称下方会先显示**工作**或**个人**；如果名称本身没有说明，则还会显示邮箱地址或用户名。如果同一类型的两个来源名称相同，还会注明用于区分的信息，例如 Slack 或 X 账号，或工作区地址。

每个来源还会用一行说明它会引入什么内容；如果它能执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加来源

打开一种类型（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下方选择来源。如果还没有连接任何来源，也可以在列表下方选择。最后会显示通用选项：邮件下的**其他邮箱**，以及日历下的**日历链接（ICS）**和**其他日历**。Exchange Server 用于读取会议，因此归在日历下。

如果你的 Machine 发现了添加某个来源的理由，**连接**上方就会显示**为你推荐**，并用一行说明原因，例如收到 Stripe 邮件、日历中有 Zoom 会议、收到包含 Google Docs 链接的消息，或尚未完成的设置。该来源也会保留在自己的分组中，并标记为**建议的**。这些判断只会在你的 Machine 上进行，不会向外发送任何内容。已连接的来源不会显示为推荐。

Microsoft Teams 会显示两次：在**聊天**下显示聊天，在**会议**下以**Teams会议**显示会议记录。两者使用同一个 Microsoft 登录方式，因此连接其中一个时，另一个也会连接。

如果你已连接某个来源，它会在列表中显示账号信息。选择它即可在旁边再添加一个：表单会注明这一点，并链接到已有来源。

填写所需信息（例如密钥或地址），选择**工作**并填写公司名称，或选择**个人**（邮件和日历只会在无法从地址判断时询问），然后按下**连接**。LinkedIn 或 X 这类网站会在你的 Machine 浏览器中打开登录页面；登录后，流程会自动继续。GitHub、WhatsApp 和 Codex 会显示供你输入的代码，Telegram 聊天和 Signal 聊天则会显示供你扫描的二维码。

按下**取消**即可停止添加。还没完成就离开了？在任何设备上重新打开**连接**，流程会从上次停下的步骤继续。连接成功后，你的 Machine 会立即开始读取内容，并显示首次同步的进度。

在托管的 Machine 上，拥有独立登录方式的来源可以直接在这里登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按下对应的登录按钮，例如**使用 Google 登录**。之后会返回此表单，并显示登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和你的 Android 手机也会在这里显示代码。

在自己的电脑上，将 Machine 与账号关联后，这些来源也会自动登录：首次使用时按下**关联这台Machine**。有些来源也提供其他方式，例如使用你自己的应用或密钥。

在来源上按下**重新连接**，或在**需要你**中选择来源，都会打开同一个表单。在自己的电脑上，也可以在终端中运行 `assistant connect` 来完成同样的操作。

## 工作还是个人

每个来源都归为工作（属于你指定的公司）或个人。你可以在**详情**中更改分类。**推测**表示你的 Machine 根据地址进行了判断。工作待办会等到你的工作日再处理。

Google 和 Microsoft 邮件及日历会在地址信息明确时自动分类：Gmail 或 Outlook.com 这类邮件服务商会归为个人，你团队的域名会归为工作。否则，登录后会询问一次。按下**更改**可自行设置。如果之后邮件内容显示分类不符，**充分利用The Machine**待办会询问你是否要更改。

## 功能

来源可以引入信号（收到的内容会变成待办）、为待办执行操作（读取文档，或在你确认后发送、回复或更改内容），也可以两者兼有。如果两种功能都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。其中一个开关必须保持开启；如要全部停止，请断开连接。聊天来源只有**可以执行操作**。

关闭**引入信号**后，来源不会同步。关闭**可以执行操作**后，你的 Machine 就不会通过该来源读取、起草或更改任何内容。

## 移除来源

打开来源，选择**详情**，然后按下**断开连接**。来源将停止读取。已引入的内容会保留。在托管的 Machine 上，如果来源的登录方式由设置页面管理（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），会显示**断开连接 ↗**，按下后会打开设置页面。

**最近断开连接**会列出你在过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账号，以及移除时间。在服务确认之前，状态会显示为待处理，并会继续尝试断开连接。Google 账号只会显示一次，即使 Google Meet 或 Docs 使用了独立登录方式也是如此。每个账号会显示在对应类型下：Google 或 Microsoft 账号在**邮件**下，Slack 在**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 这类网站时，勾选**保存以备下次使用**。之后，**登录方式**会列出这些网站；如果网站让你的 Machine 退出登录，只需点按一次即可重新登录。密码会在你的 Machine 上加密保存。按下**忘记**即可移除一项。

一个网站可以保存多个账号，例如**工作**和**个人**账号。**另存为**会默认使用待办对应的分类，**其他名称…**则可让你自定义名称。待办会使用适合它的账号登录。如果无法判断，系统会询问你一次要使用哪个账号，并记住该待办的选择。

**登录方式**会按网站列出条目，并在每个网站下显示对应账号：用户名，以及显示账号分类的菜单。你可以随时在菜单中更改分类。为账号功能推出前保存的登录方式会显示**工作还是个人？**，直到你选择分类。更改分类后，使用过该登录方式的待办会重新选择账号。

按下**导入**即可从密码管理器导入登录方式。选择一种方式：

- **LastPass**、**Bitwarden**或**Google 密码管理工具**：密码管理器的导出页面会在你的 Machine 浏览器中打开。在那里登录后，你的 Machine 会继续操作并导出文件。一行提示会说明还需要你完成什么，例如输入主密码。在手机上，页面会放大到需要输入的位置。如果页面与预期不同，系统会改为显示手动完成的步骤。你的 Machine 会获取文件、读取一次，然后删除文件。
- **1Password**：在电脑上的 1Password 应用中导出 CSV，然后选择该文件。如果 1Password 的 `op` 已在你的 Machine 上登录，系统会改为从那里读取（LastPass 的 `lpass` 也一样）。
- **从导出文件导入**：选择 1Password、LastPass、Bitwarden 或 Chrome 导出的 CSV。完成后请删除文件。

接着勾选要保留的登录方式。你的 Machine 不会代你登录密码管理器，不会输入或读取主密码，也不会向助手显示密码管理器页面。你需要自行在页面中输入密码。

已保存的登录方式只会用于对应的网站地址：同一网站、`https` 和端口。不会用于相似的网址，也不会用于其他子域名。

## 检查

**检查**会显示你的 Machine 如何读取收到的内容：最近的检查，以及每次检查发现的内容。请参阅[没有新的待办](reviews-paused.md)。

本部分为每个连接都提供了一篇单独的文章，说明它会读取什么以及可以发送什么。
