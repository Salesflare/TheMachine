## 连接状态

**连接**标签页按类型列出数据源，下方横线后是**登录方式**和**检查**。在手机上，点按某个类型即可打开，点按**连接**即可返回。需要你处理的数据源所在类型会优先打开。每个数据源占一行，显示其状态（已连接、等待首次同步、正在自动重新连接或需要你的帮助）以及最近导入的内容。点按数据源可打开信息卡和**详情**。

如果某次同步失败，但之后的同步已补上，这次失败会以灰色显示。只有最近一次同步仍然失败时，才会显示为问题，并注明下次重试时间。

数据源的计数会显示导入的所有内容，包括[历史记录](history.md)、过去 24 小时导入的内容，以及尚未检查的内容。日历会统计日程。

每个数据源都以账号名称命名，名称由相应服务提供，例如你的地址、X 个人资料、Slack 工作区，或 Signal 或 Telegram 账号所属者。名称下方会先显示**工作**或**个人**，如果名称里没有地址或用户名，也会显示地址或用户名。同一类型的两个数据源如果名称相同，还会显示用于区分它们的信息，例如 Slack 或 X，或工作区地址。

每个数据源还会用一行说明它会导入什么内容。如果它还可以执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加数据源

打开一个类型（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下选择数据源。如果还没有连接任何数据源，也可以在列表下方选择。兜底选项排在最后：邮件下的**其他邮箱**，以及日历下的**日历链接（ICS）**和**其他日历**。Exchange Server 用于读取会议，因此归在日历下。

如果你的Machine发现了添加某个数据源的理由，**为你推荐**会显示在**连接**顶部，并用一行说明原因，例如来自 Stripe 的邮件、日历中的 Zoom 会议、包含 Google Docs 链接的消息，或尚未完成的设置。这个数据源也会继续显示在所属分类中，并标记为**建议的**。这些数据只会在你的Machine上统计，不会离开你的Machine。已连接的数据源不会显示为推荐。

Microsoft Teams 会显示两次：**聊天**下显示聊天内容，**会议**下显示**Teams会议**，用于记录会议笔记。两者使用同一个 Microsoft 登录账号，因此连接其中一个也会连接另一个。

列表会标出你已连接的数据源及其账号。选择它即可在旁边添加另一个同类数据源：表单会说明这一点，并链接到你已有的数据源。

填写所需信息（例如密钥或地址），选择**工作**并填写公司名称，或选择**个人**（邮件和日历只有在地址无法说明时才会询问），然后按下**连接**。对于 LinkedIn 或 X 这类网站，你的Machine浏览器会打开登录页面，登录后会自动继续。GitHub、WhatsApp 和 Codex 会显示需要输入的代码，Telegram 聊天和 Signal 聊天则会显示需要扫描的二维码。

按下**取消**即可停止添加。还没完成就离开了吗？在任何设备上重新打开**连接**，流程都会从上次停下的步骤继续。连接成功后，你的Machine会立即开始读取数据，并显示首次同步的状态。

在托管版Machine上，以下数据源会直接在此处登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按下相应的登录按钮，例如**使用 Google 登录**。之后会返回此表单，查看登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和你的 Android 手机也会在这里显示代码。

在自己的电脑上，Machine 与账号关联后，这些相同的数据源就会登录：首次使用时按下**关联这台Machine**。部分数据源还有其他方式，例如使用自己的应用或密钥。

在数据源上按下**重新连接**，或在**需要你**中选择它，都会打开相同的表单。在自己的电脑上，也可以在终端中运行 `assistant connect`。

## 工作或个人

每个数据源都属于工作（对应你填写的公司）或个人。可在**详情**中更改。**推测**表示你的Machine根据地址进行了判断。工作待办会等到你的工作日再处理。

如果地址足以判断，Google 和 Microsoft 的邮件及日历会根据地址自动分类：Gmail 或 Outlook.com 这类邮件服务会归为个人，团队域名则归为工作。否则，登录后会询问一次。按下**更改**即可自行设置。如果之后邮件内容表明分类可能有误，**充分利用The Machine**待办会询问一次是否要更改。

## 功能

数据源可以导入信号（导入的内容会变成待办）、帮你处理待办（读取文档，或在你确认后发送、回复或更改内容），也可以兼具两者。如果两者都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。至少有一个开关必须保持开启。要同时关闭两者，请断开数据源。聊天数据源只有**可以执行操作**。

关闭**引入信号**后，数据源不会同步。关闭**可以执行操作**后，你的Machine不会通过它读取、起草或更改任何内容。

## 移除数据源

打开数据源，选择**详情**，然后按下**断开连接**。数据源会停止读取，已导入的内容会保留。在托管版Machine上，如果登录信息由设置页面管理（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），数据源会显示**断开连接 ↗**，点按后会打开设置页面。

**最近断开连接**会列出过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账号，并显示移除时间。在服务确认之前，状态会显示为“待处理”，并会继续尝试断开连接。Google 账号只显示一次，即使 Google Meet 或 Docs 也有自己的登录信息。每个账号都会显示在对应类型下：Google 或 Microsoft 账号在**邮件**下，Slack 账号在**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 这类网站时，勾选**保存以备下次使用**。之后，**登录方式**会列出这些网站。网站让你的Machine退出登录时，只需点按一次即可重新登录。密码会加密保存在你的Machine上。选择**忘记**即可移除某个登录信息。

一个网站可以保存多个账号，例如**工作**和**个人**。**另存为**会默认使用待办所属的类别，选择**其他名称…**即可自定义名称。待办会使用适合自己的账号登录。如果无法判断，系统会在对话框中询问一次要使用哪个账号，并记住该待办的选择。

**登录方式**会逐个列出网站，并在其下方列出对应账号。在支持多个账号之前保存的登录信息会显示为**默认**，直到你为其选择类别。

**导入**可从密码管理器导入登录信息：导入 1Password、LastPass、Bitwarden 或 Chrome 导出的 CSV 文件；或者在此电脑上已登录 1Password 或 LastPass 时，直接从它们的命令行工具导入。你可以勾选要保留的登录信息。你的Machine不会登录密码管理器，也不会索要主密码。导入完成后，请删除导出的文件。

已保存的登录信息只会用于对应的网址：必须是同一个网站、`https` 和端口。相似的网址或其他子域名都不行。

## 检查

**检查**会显示你的Machine如何读取新内容：最近的检查，以及每次检查发现的内容。请参阅[没有新的待办](reviews-paused.md)。

本节为每个连接都提供了单独的文章，介绍它会读取什么内容，以及可以发送什么内容。
