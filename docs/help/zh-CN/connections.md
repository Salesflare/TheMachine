## 状态如何

**连接**标签页会按类别列出你的来源，分隔线下方是**登录方式**和**检查**。在手机上，点按某个类别即可打开，点按**连接**即可返回。需要你处理的来源所属类别会优先打开。每个来源都显示为一行，其中包括状态（已连接、等待首次同步、正在自动重新连接或需要你的帮助）以及近期收到的内容。点按来源可查看详情卡片和**详情**。

如果后续同步已补上之前失败的同步，失败记录会显示为灰色。只有最近一次同步仍然失败时，才会显示为问题，并注明下次尝试时间。

来源的计数会显示它带来的所有内容，包括[历史记录](history.md)、过去 24 小时收到的内容，以及尚未检查的内容。日历会统计其中的日程。

每个来源都以其账号名称命名，名称由对应服务提供，例如你的邮箱地址、X 个人主页、Slack 工作区，或说明属于哪个 Signal 或 Telegram 账号。名称下方会先显示**工作**或**个人**，如果名称中没有体现，再显示地址或用户名。如果同一类别中有两个同名来源，还会显示可用于区分的信息，例如 Slack 或 X，或工作区地址。

每个来源还会用一行文字说明它会带来什么内容。如果它能执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加来源

打开某个类别（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下方选择来源；如果还没有连接任何来源，也可以在列表下方选择。最后会列出通用选项：邮件类别下的**其他邮箱**，日历类别下的**日历链接（ICS）**和**其他日历**。Exchange Server 会读取会议，因此列在日历类别下。

当你的 Machine 发现有理由添加某个来源时，**为你推荐**会显示在**连接**顶部，并用一行文字说明原因，例如收到 Stripe 邮件、日历中有 Zoom 会议、收到链接到 Google Docs 的消息，或某项设置尚未完成。该来源也会继续显示在所属类别中，并标记为**建议的**。这些推荐只会在你的 Machine 上统计，不会向外发送任何内容。已连接的来源不会显示为推荐。

Microsoft Teams 会显示两次：聊天类别下显示其聊天，会议类别下则以**Teams会议**的名称显示会议记录。两者使用同一个 Microsoft 登录账号，因此连接其中一个也会连接另一个。

列表中会标明你已连接的来源及其账号。选择它即可在现有来源旁边再添加一个：表单会说明这一点，并链接到已有来源。

填写所需信息（例如密钥或地址），选择**工作**并填写公司名称，或选择**个人**（邮件和日历只有在地址无法判断时才会询问），然后按**连接**。对于 LinkedIn 或 X 这类网站，系统会在你的 Machine 浏览器中打开登录页面，登录后会自动继续。GitHub、WhatsApp 和 Codex 会显示需要输入的代码，Telegram 聊天和 Signal 聊天则会显示需要扫描的二维码。

按**取消**即可停止添加。如果还没完成就离开了，再次打开**连接**，无论使用哪台设备，流程都会从上次停下的步骤继续。连接完成后，你的 Machine 会立即开始读取内容，并显示首次同步的进度。

在托管版 Machine 上，以下来源会直接在此登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按相应的登录按钮，例如**使用 Google 登录**。你会返回此表单，查看登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和你的 Android 手机也会在此显示代码。

在自己的电脑上，将 Machine 与账号关联后，这些来源就会登录：首次使用时按**关联这台Machine**。部分来源还支持其他方式，例如使用你自己的应用或密钥。

在来源上或**需要你**中按**重新连接**，会打开同一个表单。在自己的电脑上，也可以在终端运行 `assistant connect` 来执行相同操作。

## 工作还是个人

每个来源都属于工作（对应你填写的公司）或个人。可以在**详情**中更改。**已推测**表示你的 Machine 根据地址判断了类别。工作待办会等到工作日再处理。

如果 Google 和 Microsoft 邮件或日历的地址能明确判断类别，系统会自动设置：Gmail 或 Outlook.com 这类邮件服务商属于个人，公司团队的域名则属于工作。无法判断时，系统会在你登录后询问一次。按**更改**可自行设置。如果之后收到的邮件表明类别应为另一种，**充分利用The Machine**待办会询问你是否要更改，只询问一次。

## 功能

来源可以带来信号（收到的内容会变成待办），也可以为待办执行操作（读取文档，或在你确认后发送、回复或更改内容），还可以兼具两种功能。如果两种功能都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。其中一个开关必须保持开启；如要关闭两者，请断开连接。聊天来源只有**可以执行操作**。

关闭**引入信号**后，来源不会同步。关闭**可以执行操作**后，你的 Machine 不会使用该来源读取、起草或更改任何内容。

## 移除来源

打开来源，选择**详情**，然后按**断开连接**。来源将停止读取。它已经带来的内容会保留。在托管版 Machine 上，如果某个来源的登录信息由设置页面保存（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），会显示**断开连接 ↗**，点按后会打开设置页面。

**最近断开连接**会列出你在过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账号，以及移除时间。在服务确认之前，状态会显示为待处理，系统会继续尝试。Google 账号只显示一次，即使 Google Meet 或 Docs 使用了单独的登录信息也是如此。每个账号都会显示在所属类别下：Google 或 Microsoft 账号位于**邮件**下，Slack 位于**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 这类网站时，勾选**保存以备下次使用**。之后，这些网站会列在**登录方式**中。网站将你的 Machine 登出后，只需点按一次即可重新登录。密码会加密保存在你的 Machine 上。按**忘记**即可移除某个登录信息。

同一个网站可以保存多个账号，例如**工作**和**个人**。**另存为**会从待办所属的类别开始，**其他名称…**则可让你自行命名。待办会使用适合它的账号登录。如果无法判断，系统会在对话框中询问你一次，并记住该待办所用的账号。

**登录方式**会按网站列出，每个网站只显示一次，账号列在下方：包括用户名和标明类别的菜单。你可以随时在菜单中更改类别。添加账号功能推出前保存的登录信息，在你选择类别前会显示**工作还是个人？**。更改登录信息的类别后，使用该登录信息的待办会重新选择账号。

**导入**可从密码管理器导入登录信息。选择其中一种方式：

- **LastPass**、**Bitwarden**或**Google 密码管理工具**：对应服务的导出页面会在你的 Machine 浏览器中打开，并直接显示在对话框中，类似待办的**执行**页面。登录后，你的 Machine 会继续操作并开始导出。页面会用一行文字说明还需要你做什么，例如输入主密码。在手机上，页面会放大到需要输入的位置。如果页面与预期不同，系统会改为显示手动完成步骤。你的 Machine 会读取文件一次，然后将其删除。
- **1Password**：在电脑上的 1Password 应用中导出 CSV，然后选择该文件。如果你的 Machine 已登录 1Password 的 `op`，系统会改为从那里读取（LastPass 的 `lpass` 也是如此）。
- **从导出文件导入**：导入 1Password、LastPass、Bitwarden 或 Chrome 导出的 CSV。完成后请删除文件。

接着勾选要保留的登录信息。你的 Machine 不会代你登录密码管理器，不会输入或读取其主密码，也不会向助手显示相关页面。你需要自行在页面中输入密码。

已保存的登录信息只能用于对应的网址：同一网站、`https` 和端口。不适用于相似的网址或其他子域名。

## 检查

**检查**会显示你的 Machine 如何读取收到的内容，包括近期检查和每次检查发现的内容。请参阅[没有新的待办](reviews-paused.md)。

本节中每种连接都有自己的文章，介绍会读取哪些内容以及可以发送什么。
