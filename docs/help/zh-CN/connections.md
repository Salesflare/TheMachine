## 状态

**连接**标签页按类型列出你的来源，分隔线下方是**登录方式**和**检查**。在手机上，轻点类型即可打开，轻点**连接**即可返回。需要你处理的类型会优先显示。每个来源占一行，显示状态（已连接、等待首次同步、正在自动重新连接或需要你处理）以及最近导入的内容。轻点来源可打开信息卡和**详情**。

如果后续同步补上了之前失败的同步，失败记录会显示为灰色。只有最新一次同步仍然失败时，才会显示为问题，并注明下次尝试的时间。

计数会显示来源导入的所有内容，包括[历史记录](history.md)，以及过去 24 小时内导入的内容和未检查的内容。日历会统计日程。

每个来源都以其账户名称命名，名称由相应服务提供，例如你的邮箱地址、X 个人资料、Slack 工作区，或 Signal、Telegram 账户所属的人。名称下方会先显示**工作**或**个人**，如果名称本身没有说明，则还会显示地址或用户名。同一类型下有两个同名来源时，也会显示用于区分的信息，例如 Slack 或 X，或工作区地址。

每个来源还会用一句话说明它会导入什么内容；如果它可以执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加来源

打开一种类型（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下选择来源。如果还没有连接任何来源，也可以在列表下方选择。通用选项排在最后：邮件下的**其他邮箱**，以及日历下的**日历链接（ICS）**和**其他日历**。Exchange Server 会读取会议，因此列在日历下。

当你的 Machine 发现有理由添加某个来源时，**为你推荐**会显示在**连接**顶部，并用一句话说明原因，例如 Stripe 邮件、日历中的 Zoom 会议、包含 Google Docs 链接的消息，或尚未完成的设置。该来源也会保留在所属分组中，并标记为**建议的**。这些信息只在你的 Machine 上统计，不会发送到其他地方。已连接的来源不会出现在推荐中。

Microsoft Teams 会显示两次：在**聊天**下显示聊天，在**会议**下以**Teams会议**显示会议笔记。两者使用同一个 Microsoft 登录方式，因此连接其中一个时，另一个也会连接。

列表会标明你已连接的来源及其账户。选择它即可在旁边再添加一个，表单会说明这一点，并链接到你已有的来源。

填写所需信息（例如密钥或地址），选择**工作**并填写公司名称，或选择**个人**（如果邮箱和日历的地址无法说明类别，才会询问），然后按**连接**。LinkedIn 或 X 这类网站会在你的 Machine 浏览器中打开登录页面，登录后会自动继续。GitHub、WhatsApp 和 Codex 会显示需要输入的代码，Telegram 聊天和 Signal 聊天则会显示需要扫描的二维码。

按**取消**即可停止添加。如果中途离开了，随时可以在任何设备上重新打开**连接**，流程会从上次停下的步骤继续。连接完成后，你的 Machine 会立即开始读取，并显示首次同步的进度。

在托管的 Machine 上，以下来源会直接在此处登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按相应的登录按钮，例如**使用 Google 登录**。完成后会返回此表单，并显示登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和 Android 手机也会在此处显示代码。

在自己的电脑上，先将 Machine 与账户关联，之后相同的来源就可以登录：首次使用时按**关联这台Machine**。部分来源也提供其他方式，例如使用你自己的应用或密钥。

来源上的**重新连接**和**需要你**中的**重新连接**都会打开同一个表单。在自己的电脑上，也可以在终端中运行 `assistant connect`。

## 工作或个人

每个来源都归类为工作（属于你指定的公司）或个人。可在**详情**中更改。**已猜测**表示你的 Machine 根据地址推测了类别。工作待办会等到你的工作日再处理。

Google 和 Microsoft 的邮件与日历会在地址含义明确时自动判断：Gmail 或 Outlook.com 这类邮件服务属于个人，团队使用的域名属于工作。否则，登录后会询问一次。按**更改**即可自行设置。如果之后邮件内容显示类别可能相反，**充分利用The Machine**待办会询问你是否要更改。

## 功能

来源可以导入信号（收到的内容会变成待办）、为待办执行操作（读取文档，或在你确认后发送、回复或更改内容），也可以同时做到这两点。如果两项功能都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。至少有一项必须保持开启。若要全部停止，请断开来源。聊天来源只有**可以执行操作**。

关闭**引入信号**后，来源不会同步。关闭**可以执行操作**后，你的 Machine 不会通过该来源读取、起草或更改任何内容。

## 移除来源

打开来源，进入**详情**，然后按**断开连接**。来源会停止读取，但已导入的内容会保留。在托管的 Machine 上，如果来源的登录信息由设置页面管理（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），会显示**断开连接 ↗**，点击后会打开设置页面。

**最近断开连接**会列出你在过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账户，并显示移除时间。在服务确认断开前，状态会显示为待处理，并持续重试。Google 账户只会显示一次，即使 Google Meet 或 Docs 有单独的登录方式也是如此。每个账户会显示在对应类型下：Google 或 Microsoft 账户在**邮件**下，Slack 在**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 这类网站时，勾选**保存以备下次使用**。之后可在**登录方式**中查看这些登录信息。网站将你的 Machine 登出后，只需轻点一下即可重新登录。密码会在你的 Machine 上加密保存。按**忘记**即可移除登录信息。

一个网站可以保存多个账户，例如**工作**和**个人**账户。**另存为**会默认使用待办所属的类别，**其他名称…**则可让你自定义名称。待办会使用适合自己的账户登录。如果无法确定，系统会询问你一次要使用哪个账户，并记住待办的选择。

**登录方式**会按网站列出登录信息，并在每个网站下方显示其账户：用户名以及标明类别的菜单。你可以随时在菜单中更改类别。在支持账户分类前保存的登录信息会显示**工作还是个人？**，直到你选好类别。更改类别后，使用过该登录信息的待办会重新选择账户。

**导入**可从密码管理器导入登录信息：可以导入 1Password、LastPass、Bitwarden 或 Chrome 导出的 CSV 文件；如果已在这台电脑上登录，也可以直接通过 1Password 和 LastPass 的命令行工具导入。你可以勾选要保留的登录信息。你的 Machine 不会登录密码管理器，也不会索要其主密码。导入完成后，请删除导出的文件。

已保存的登录信息只会用于对应的网站地址：相同的网站、`https` 和端口。不会用于相似的网站地址或其他子域名。

## 检查

**检查**会显示你的 Machine 如何读取收到的内容，包括最近的检查以及每次检查发现的内容。请参阅[没有新待办](reviews-paused.md)。

本部分为每种连接都提供了一篇说明文章，介绍它会读取什么内容以及可以发送什么内容。
