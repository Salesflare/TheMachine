## 状态

**连接**标签页会按类型列出你的来源，分隔线下方是**登录方式**和**检查**。在手机上，点按某个类型可打开它，点按**连接**可返回。需要你处理的来源会优先显示。每个来源占一行，显示其状态（已连接、等待首次同步、正在自动重新连接或需要你的帮助）以及最近收到的内容。点按来源可打开信息卡和**详情**。

如果后续同步已弥补之前同步失败，失败记录会显示为灰色。只有最近一次同步仍然失败时，才会显示为问题，并注明下次重试时间。

计数会显示来源带来的所有内容，包括[历史记录](history.md)、过去 24 小时收到的内容，以及尚未检查的内容。日历的计数显示其中的活动。

每个来源都以其账号名称命名，名称由对应服务提供，例如你的邮箱地址、X 个人资料、Slack 工作区，或 Signal、Telegram 账号所属人的名称。名称下方会先显示**工作**或**个人**；如果名称中没有地址或用户名，也会一并显示。若同一类型下有两个名称相同的来源，还会显示用于区分它们的信息，例如 Slack 或 X，或者工作区地址。

每个来源还会用一行说明它会带来什么内容；如果它可以执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加来源

打开一种类型（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下方选择来源。如果还没有连接任何来源，也可以在列表下方选择。通用选项位于最后：邮件下方的**其他邮箱**，以及日历下方的**日历链接（ICS）**和**其他日历**。Exchange Server 用于读取会议，因此列在日历下方。

当你的 Machine 发现添加某个来源的理由时，**连接**顶部会显示**为你推荐**，并用一行说明原因，例如来自 Stripe 的邮件、日历中的 Zoom 会议、包含 Google Docs 链接的消息，或尚未完成的设置。该来源也会保留在自己的分组中，并标记为**建议的**。这些内容只会在你的 Machine 上统计，不会传出。已连接的来源不会出现在推荐中。

Microsoft Teams 会显示两次：在**聊天**下显示其聊天，在**会议**下以**Teams会议**的名称显示其会议记录。两者使用同一个 Microsoft 登录方式，因此连接其中一个也会连接另一个。

如果某个来源已连接，列表中会显示其账号。选择它即可在旁边再添加一个账号：表单会说明这一点，并链接到已有账号。

填写所需信息（例如密钥或地址），选择**工作**并填写公司名称，或选择**个人**（仅当邮箱和日历的地址无法判断时才会询问），然后按**连接**。LinkedIn 或 X 这类网站会在你的 Machine 浏览器中打开登录页面，登录后会自动继续。GitHub、WhatsApp 和 Codex 会显示需要输入的代码，Telegram 聊天和 Signal 聊天则会显示需要扫描的二维码。

按**取消**可停止添加。还没完成就离开了？在任何设备上重新打开**连接**，即可从上次停下的步骤继续。连接成功后，你的 Machine 会立即开始读取，并显示首次同步的进度。

在托管的 Machine 上，以下来源可直接在此登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按对应的登录按钮，例如**使用 Google 登录**。你会返回此表单，查看登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和你的 Android 手机也会在此显示代码。

在自己的电脑上，先将 Machine 与账号关联，这些来源就会使用该账号登录：首次使用时按**关联这台Machine**。部分来源还提供其他方式，例如使用自己的应用或密钥。

在来源上或**需要你**中按**重新连接**，会打开同一个表单。在自己的电脑上，也可以在终端中运行`assistant connect`。

## 工作还是个人

每个来源都归为工作（属于你指定的公司）或个人。你可以在**详情**中更改。**推测结果**表示你的 Machine 根据地址做出了判断。工作待办会等到工作日再处理。

如果地址信息明确，Google 和 Microsoft 的邮件及日历会根据地址自动分类：Gmail 或 Outlook.com 这类邮箱服务会归为个人，你团队的域名会归为工作。否则，登录后会询问一次。按**更改**可自行设置。如果之后收到的邮件表明分类不符，**充分利用The Machine**待办会询问你是否要更改。

## 功能

来源可以带来信号（收到的内容会变成待办）、为待办执行操作（读取文档，或在你确认后发送、回复或更改内容），也可以兼具两者。如果两种功能都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。至少要保留一个开启；若要全部关闭，请断开连接。聊天来源只有**可以执行操作**。

关闭**引入信号**后，来源不会同步。关闭**可以执行操作**后，你的 Machine 不会使用该来源读取、起草或更改任何内容。

## 移除来源

打开来源，选择**详情**，然后按**断开连接**。它会停止读取，但已带入的内容会保留。在托管的 Machine 上，如果来源的登录信息保存在设置页面中（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），会显示**断开连接 ↗**，按下后会打开设置页面。

**最近断开连接**会列出你在过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账号，以及移除时间。在服务确认之前，状态会显示为“等待中”，并会继续尝试断开。Google 账号只会显示一次，即使 Google Meet 或 Docs 使用了单独的登录方式也一样。每个账号会显示在对应类型下：Google 或 Microsoft 账号显示在**邮件**下，Slack 显示在**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 这类网站时，勾选**保存以备下次使用**。之后这些网站会列在**登录方式**中。当网站将你的 Machine 登出时，只需点按一次即可重新登录。密码会加密保存在你的 Machine 上。按**忘记**可移除登录方式。

一个网站可以保存多个账号，例如**工作**和**个人**账号。**另存为**会默认使用待办对应的类别，选择**其他名称…**则可以自定义名称。待办会使用适合它的账号登录。如果无法判断，系统会询问一次要使用哪个账号，并记住该待办的选择。

**登录方式**会按网站列出登录信息，并在每个网站下方显示账号：用户名，以及带有账号类别的菜单。你可以随时在菜单中更改类别。账号类别功能推出前保存的登录信息会显示**工作还是个人？**，直到你选择类别。更改类别后，使用过该登录信息的待办会重新选择账号。

**导入**可从密码管理器导入登录信息。选择一种方式：

- **LastPass**、**Bitwarden**或**Google 密码管理工具**：对应的导出页面会在你的 Machine 浏览器中打开。在页面中登录并导出，操作步骤会显示在旁边。你的 Machine 会找到导出文件，读取一次后将其删除。
- **1Password**：在电脑上的 1Password 应用中导出 CSV，然后选择该文件。如果你的 Machine 已登录 1Password 的`op`，则会从那里读取（LastPass 的`lpass`也一样）。
- **从导出文件导入**：选择从 1Password、LastPass、Bitwarden 或 Chrome 导出的 CSV。完成后请删除该文件。

然后勾选要保留的登录信息。你的 Machine 不会替你登录密码管理器，也不会询问主密码；你需要自行在页面中输入主密码。

已保存的登录信息只会用于对应的网站地址：必须是同一网站、`https`和端口。相似的网址或其他子域名均不适用。

## 检查

**检查**会显示你的 Machine 如何读取收到的内容：最近的检查，以及每次检查发现的内容。请参阅[没有新的待办](reviews-paused.md)。

本部分为每个连接提供单独的文章，介绍它会读取什么以及可以发送什么。
