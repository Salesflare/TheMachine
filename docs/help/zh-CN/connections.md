## 查看状态

**连接**标签页会按类型列出你的来源，分隔线下方是**登录方式**和**检查**。在手机上，点按某个类型即可打开，点按**连接**即可返回。如果某个类型下有需要你处理的来源，会优先打开它。每个来源显示为一行：当前状态（已连接、等待首次同步、正在自动重新连接或需要你帮助）以及最近收到的内容。点按来源即可查看卡片和**详情**。

如果之后的同步已补上之前失败同步的数据，失败记录会显示为灰色。只有最近一次同步仍然失败时，才会显示问题和下次重试时间。

来源的计数包括它带来的所有内容，也包括[历史记录](history.md)、过去 24 小时收到的内容，以及尚未检查的内容。日历的计数显示日程数量。

来源名称取自其账户名，和服务显示的一样：你的地址、X 个人资料、Slack 工作区，或 Signal、Telegram 所属者的名称。名称下方会先显示**工作**或**个人**，如果名称本身没有说明，还会显示地址或账号名。同一类型下有两个同名来源时，还会显示用于区分它们的信息，例如 Slack 或 X，或工作区地址。

每个来源还会用一行说明它会带来什么内容；如果它可以执行操作，也会说明只有在你按下**发送**或确认后才会执行。

## 添加来源

打开一种类型（**邮件**、**日历**、**聊天**、**会议**、**文档和文件**、**客户**、**项目与代码**、**其他**），然后在**再添加一个**下选择来源。如果还没有连接任何来源，也可以在列表下方选择。兜底选项排在最后：邮件下方的**其他邮箱**，以及日历下方的**日历链接（ICS）**和**其他日历**。Exchange Server 用于读取会议，因此归在日历下。

当你的 Machine 发现有理由添加某个来源时，**连接**顶部会显示**为你推荐**，并用一行说明原因，例如来自 Stripe 的邮件、日历中的 Zoom 会议、包含 Google Docs 链接的消息，或尚未完成的设置。该来源也会继续显示在自己的分组中，并标记为**建议的**。这些信息只在你的 Machine 上统计，不会传出去。已连接的来源不会出现在推荐中。

Microsoft Teams 会显示两次：在**聊天**下显示聊天，在**会议**下以**Teams会议**显示会议记录。两者使用同一个 Microsoft 登录方式，因此连接其中一个也会连接另一个。

如果你已经连接了某个来源，列表中会显示它及其账户。选择它即可在旁边再添加一个：表单会说明这一点，并链接到你已有的来源。

填写所需信息（密钥、地址等），选择**工作**并填写公司名称，或选择**个人**（邮件和日历只会在地址无法说明时询问），然后按**连接**。LinkedIn 或 X 等网站会在 Machine 的浏览器中打开登录页面，登录后会自动继续。GitHub、WhatsApp 和 Codex 会显示需要输入的代码，Telegram 聊天和 Signal 聊天则会显示需要扫描的二维码。

按**取消**即可停止添加。还没完成就离开了？在任意设备上重新打开**连接**，流程会从上次停下的步骤继续。连接成功后，你的 Machine 会立即开始读取，并显示首次同步的状态。

在托管的 Machine 上，以下来源会直接在此登录：Google、Microsoft（Outlook、OneDrive 和 Teams）、Google Meet、Google Docs、Slack、Zoom、Stripe、Intercom、Salesforce 和 Trello。

选择**工作**或**个人**，然后按相应的登录按钮，例如**使用 Google 登录**。系统会返回此表单并显示登录结果。GitHub、WhatsApp、Codex、Telegram 聊天和你的 Android 手机也会在此显示代码。

在自己的电脑上，Machine 与你的账户关联后，这些来源会自动登录：首次使用时按**关联这台Machine**。其中一些来源也提供其他方式，例如使用自己的应用或密钥。

在来源上按**重新连接**，或在**需要你**中选择它，都会打开同一个表单。在自己的电脑上，也可以在终端中运行 `assistant connect` 完成相同操作。

## 工作或个人

每个来源都属于工作（对应你填写的公司）或个人。可在**详情**中更改。**猜测**表示你的 Machine 根据地址判断了类型。工作待办会等到你的工作日再处理。

如果地址信息明确，Google 和 Microsoft 邮件及日历会根据地址自动判断：Gmail 或 Outlook.com 等邮件服务商会归为个人，你所在团队的域名会归为工作。否则，系统会在你登录后询问一次。选择**更改**即可自行设置。如果之后邮件内容显示应属于另一类型，**充分利用The Machine**待办会询问你是否要更改。

## 功能

来源可以带来信号（收到的内容会变成待办），也可以为待办执行操作（读取文档，或在你确认后发送、回复或更改内容），也可以两者兼具。如果两者都有，**详情**中会分别显示开关：**引入信号**和**可以执行操作**。至少一个开关会保持开启；若要全部停止，请断开连接。聊天来源只有**可以执行操作**开关。

关闭**引入信号**后，来源不会同步。关闭**可以执行操作**后，你的 Machine 不会读取、起草或更改其中的任何内容。

## 移除来源

打开来源，选择**详情**，然后按**断开连接**。Machine 将停止读取，但已经带来的内容会保留。在托管的 Machine 上，如果来源的登录信息由设置页面管理（Google、Microsoft、Google Meet、Slack、Zoom、Stripe 和 Salesforce），会显示**断开连接 ↗**，点按后会打开设置页面。

**最近断开连接**会列出你在过去 30 天内移除的 Google、Microsoft、Zoom、Slack、Stripe 和 Salesforce 账户及移除时间。在服务确认之前，状态会显示为“等待中”，并持续重试。Google 账户只会显示一次，即使 Google Meet 或 Docs 使用了单独的登录方式也是如此。每个账户会显示在对应类型下：Google 或 Microsoft 账户显示在**邮件**下，Slack 显示在**聊天**下。

## 已保存的登录

登录 LinkedIn 或 X 等网站时，勾选**保存以备下次使用**。之后，这些网站会列在**登录方式**中。当网站将你的 Machine 登出时，点按一次即可重新登录。密码会加密保存在你的 Machine 上。选择**忘记**即可移除某个登录方式。

## 检查

**检查**会显示你的 Machine 如何读取收到的内容，包括最近的检查以及每次检查发现的内容。另请参阅[没有新的待办](reviews-paused.md)。

本部分为每个连接提供单独的文章，介绍它会读取什么，以及可以发送什么。
