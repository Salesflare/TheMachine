## 你的 The Machine

- 在自己的电脑上运行：免费。The Machine 的所有功能，使用你自己的模型。
- 托管版：Standard Machine 每月 {price.standard}，Bigger Machine 每月 {price.big}，均不含增值税。每人可免费试用一次，试用期为 {trial_days} 天，试用结束前不会扣费。如果试用开始时没有添加银行卡，请在试用期结束前前往账号页面添加。

你的 AI 套餐由 OpenAI 等服务提供商收费。我们不会额外收费。

## 在 Network 上

- 亲友：搭配任何 Machine 免费使用。在 Family Fleet 中，前两台托管 Machine 合计收费 {price.family_pair}，之后每台收费 {price.family_seat}，均不含增值税。
- Work Fleet：每个席位每月 {price.seat}，Bigger Machine 每个席位每月 {price.seat_big}，均不含增值税。使用自己的 Machine 的队友每月支付 {price.network}。已经在为托管版 Machine 付费的队友加入时，可以申请由 Fleet 接管，并将其作为一个席位。所有者确认后，队友自己的套餐会停止。在此之前，或者如果所有者拒绝，队友会继续按当前方式付费。每个 Fleet 都有自己的银行卡和账单，所有者会在每笔费用扣款前确认金额。

所有价格均为月费，不含增值税。查看[定价](/pricing)。

如果你在 Network 免费之前开通了亲友 Network，它会显示在**设置** › **账号**中，直到你取消为止。点击**管理**即可前往账号页面取消服务或更换银行卡。你的用户名和好友不会变。

## 银行卡和账单

前往**设置** › **账号**，点击**账单**，再点击**管理订阅**。系统会打开 Stripe，你可以在其中更换银行卡并下载账单。我们不会收到你的银行卡信息。

随时更改 Machine 的规格：前往**设置** › **账号**，点击**更改套餐**。
