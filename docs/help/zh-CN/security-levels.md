## 两种级别

打开 **设置**，然后选择 **安全**。

- **标准**：使用今天的默认设置，不做任何更改。
- **谨慎**：设置更严格，适合希望手机上显示更少内容、保留更少信息的情况。

级别只是起始设置。之后更改任何设置，级别就会显示为 **自定义**。再次选择一个级别即可重置设置。

## 谨慎模式会有哪些变化

- 关闭 **通知中的文本**：通知只会显示“新待办”或“已备好”，不会显示待办内容。
- 关闭 **询问是否保存登录信息**。已保存的登录信息会继续保留，直到你点按 **忘记所有已保存的登录**。
- 关闭 **查找工作联系人**、**询问是否分享心得**和**分享大家向助手求助的内容**。
- 关闭 **检查我的哪些联系人有The Machine**和**允许知道我邮箱的人找到我**。
- 关闭 **保留“执行”详情90天**：详情会保留30天。
- 将 **其他Machine可以向我的Machine提出什么请求**设为 **关闭**：不再与其他 Machine 协调日程。请参阅[好友和 Network](friends.md#scheduling-with-other-machines)。
- 在家庭中，查询空闲或忙碌时间前会先征求你的同意。与好友交流时，会拒绝提供会议背景信息。

## 工作 Fleet 的级别

Fleet 的所有者或管理员可在 Fleet 设置中选择级别：打开 **设置** › **账号**，点按 **Fleet**。Fleet 中的所有人都会看到这个级别。设为谨慎时：

- 回复队友的问题前会先征求你的同意，不显示姓名，而且仅关于工作账号中的联系人。
- 引荐和转交也会先征求你的同意。
- 团队 Graph 会分享客户的邮箱地址，但不分享附件。
- 工作待办的通知不会显示文本。
- 不会查找工作联系人。
- 除非你自行开启，否则 The Machine 不会在 Network 上检查你的联系人，也不会让别人通过邮箱找到你。
- 所有人每7天都要重新登录。
- 邀请链接只能由收到邀请的邮箱使用。

成员可以选择比 Fleet 更严格的设置，但不能更宽松。成员自己的选择会保留；如果 Fleet 恢复为标准，这些选择也会恢复。

## 两种级别相同的部分

未经你同意，不会发送任何内容：你可以查看每份草稿，然后点按 **发送**。执行和编码代理的工作方式不变。登录始终需要身份验证器验证码或通行密钥。
