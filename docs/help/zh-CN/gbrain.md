## 开启

GBrain 是一款开源的助手记忆工具，有些人已经在使用。除非你主动开启，否则它不会启用，而且只会在你自己电脑上的 Machine 上启用。先安装 GBrain，然后打开 **连接**、**其他**、**GBrain**。

你的 Machine 会决定同步哪些内容：Graph 中的联系人和项目，以及指向它们的链接，还有它了解到的你的工作方式。聊天内容不会同步。GBrain 可能会将这些内容发送给自己的 AI 服务提供商。勾选 **我同意**，然后选择 **连接GBrain**。

## 功能

检查可以读取你的记忆（搜索和读取页面，但不会写入），从而生成更好的待办事项。你的 Machine 会在每个页面的明确标记之间写入自己的内容。你编辑或删除这部分内容后，Machine 会保留你的修改。你在 GBrain 中为某个人写的笔记会同步回你的 Machine，这样检查和聊天就能在查看此人的信息时看到这些笔记。它们会保留在你的 Machine 上。

只有勾选 **包括工作联系人和公司** 后，工作联系人和公司才会同步。队友的 Team Graph 数据不会同步。

## 关闭

再次打开 **GBrain**，然后按 **关闭**。你的记忆和页面会保留。你的 Machine 只会移除自己与 GBrain 的链接，以及同步回来的笔记。
