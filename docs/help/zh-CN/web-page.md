## 它会读取什么

每个连接每隔几小时读取一个公开网页，每小时最多读取一次。菜单、页脚、Cookie 提示和广告都会跳过。网页内容发生变化时，The Machine 会查看具体变化，只有重要变化才会创建待办，例如价格更新或政策变更。日期、计数器和小幅改写不会创建待办。网页内容没有变化时，不会产生费用。

它会先检查网站的 robots.txt。如果网站不允许访问，就不会读取网页。需要登录才能访问的网页，以及完全通过 JavaScript 构建的网页，都无法监控。

## 它能做什么

什么也做不了。它只会读取网页。

## 连接

1. 在控制面板中打开 **连接**，然后打开 **其他**，再选择“网页”。或者运行 `assistant connect web_page`。
2. 粘贴网页地址。

也可以在聊天中说：“监控这个网页的价格变化”，并附上网页地址。你可以询问正在监控哪些网页，也可以让它停止监控某个网页。

## 移除

在控制面板中打开 **连接**，选择该网页，再打开 **详情**，然后选择 **断开连接**。也可以在聊天中让它停止监控该网页。
