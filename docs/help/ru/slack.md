## Что она читает

Переписки, в которых вы участвуете: каналы, закрытые каналы, личные и групповые сообщения. При подключении она читает сообщения за последние 7 дней, а затем всё новое. Она никогда не вступает в каналы и не открывает переписки сама. В неактивный канал она заглядывает примерно раз в день. Если для задачи нужны самые свежие сообщения, The Machine читает их сразу.

Старые сообщения примерно за год загружаются позже, понемногу, в виде [истории](history.md).

Люди отображаются по имени, а приложения по названию, но не по Slack ID. Если чей-то аккаунт Slack удалён, этот человек отображается как бывший пользователь Slack.

## Что она может отправлять

Личное сообщение одному человеку от вашего имени, только после того, как вы одобрите его в задаче. Ответ на сообщение Slack, из которого появилась задача, попадёт в ветку этого сообщения в личном чате или канале. В черновике будет указано **В ветке**. Она никогда не начинает новую публикацию в канале.

## Что она хранит

Всё, что она читает, остаётся на вашей Machine, пока вы не удалите данные или саму Machine. Хостинг-сервис не хранит копии ваших сообщений или данные для входа в Slack. Модели ИИ не обучаются на ваших данных из Slack. The Machine использует ИИ, который может ошибаться, поэтому перед отправкой вы увидите каждое сообщение.

## Подключение

1. Выберите **Подключения**, **Чат**, **Slack**, затем **Войти через Slack** и разрешите доступ в Slack. Если вы используете собственный компьютер, сначала подключите Machine к своей учётной записи на themachine.computer.
2. Сначала загрузятся новые сообщения и личные переписки. Slack позволяет приложениям читать примерно одну переписку в минуту, поэтому загрузка старых сообщений займёт несколько часов.

Или используйте ключ API Maton: войдите на maton.ai, подключите там Slack и скопируйте ключ API Maton с главной страницы. Затем откройте **Или используйте ключ API Maton** в разделе Slack и вставьте ключ или выполните `assistant connect slack` на своём компьютере. Подключение Slack через Maton продолжит работать как обычно.

## Удаление подключения

- В панели управления: выберите **Подключения**, откройте Slack, затем **Подробности** и **Отключить**. Уже загруженные данные останутся.
- На размещённой Machine можно также нажать **Удалить** рядом с подключением на странице настройки.

## Удаление приложения в Slack

Если вы вошли через Slack, откройте в Slack страницу управления приложениями рабочего пространства и удалите The Machine. Она сразу перестанет читать сообщения и попросит вас войти снова. Уже загруженные данные останутся. Если подключение выполнено через Maton, удалите подключение Slack в Maton и удалите предоставленный вами ключ API Maton. Администратор Slack также может удалить любое из приложений в разделе управления приложениями рабочего пространства.
