## Что она читает

Уведомления GitHub: запросы на проверку, упоминания, назначения, ответы и неудачные запуски CI. Она никогда не помечает их как прочитанные.

## Что она умеет

Чтение ничего не меняет на GitHub. Если в задаче есть шаг с GitHub, например создание issue, задача сообщает об этом. Шаг выполняется только после нажатия **Подтвердить** или если вы попросили именно об этом в чате задачи. Скриншоты загружаются через браузер The Machine. Если GitHub не подключён, задача сообщит, что будет использовать браузер, и покажет **Подключить GitHub**.

## Подключение

В облачной версии The Machine:

1. Откройте **Подключения**, затем **Проекты и код** и выберите GitHub.
2. Выберите **Работа** или **Личное** и нажмите **Войти через GitHub**.
3. Нажмите **Открыть GitHub ↗**, введите показанный код и разрешите доступ. Подключение произойдёт автоматически.

На странице настройки app.themachine.computer/setup есть такая же возможность войти в разделе **Другие источники**.

На своём компьютере:

1. Откройте **Подключения**, затем **Проекты и код** и выберите GitHub.
2. Выберите **Работа** и компанию или **Личное**, затем нажмите **Подключить**.
3. Если появится запрос, нажмите **Открыть GitHub ↗**, введите код и разрешите доступ. Подключение произойдёт автоматически.

Или запустите `assistant connect github` и подтвердите вход в GitHub.

## Отключение

- Откройте **Подключения**, затем GitHub, **Подробнее** и **Отключить**. Она перестанет читать уведомления. Всё, что она уже получила, останется.
- В облачной версии The Machine можно также нажать **Удалить** рядом с GitHub на странице настройки.

## Удаление GitHub

На GitHub откройте Настройки, Приложения, Авторизованные OAuth-приложения и отзовите доступ GitHub CLI. На своём компьютере команда `gh auth logout` также выполнит выход.
