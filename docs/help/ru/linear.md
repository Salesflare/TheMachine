## Что она читает

Ваши входящие Linear и задачи, назначенные вам. Она импортирует:

- Задачи, назначенные вам: новые, а также те, у которых изменились статус, срок или название. Когда задача в Linear выполнена или отменена, связанная с ней задача в The Machine закрывается автоматически. **Отменить** снова открывает её.
- Упоминания вас, комментарии и ответы в обсуждениях задач, за которыми вы следите.
- Запросы на проверку и задачи, добавленные в очередь на разбор.
- Напоминания о сроках.

Каждая из них становится задачей, только если по её содержанию видно, что от вас что-то требуется. Ваши собственные изменения не импортируются. При первой синхронизации загружаются данные за последние 7 дней. Люди привязываются к вашему [Graph](graph.md) по адресу электронной почты, который Linear показывает для них.

Чтобы использовать её только для выполнения действий, отключите **Получает сигналы** в разделе **Подробности**.

## Что она может делать

Для каждого из этих действий в соответствующей задаче она ждёт вашего подтверждения:

- Оставить комментарий к задаче или ответить в ветке комментариев. Комментарий будет опубликован от вашего имени.
- Изменить статус задачи на один из статусов команды.
- Назначить задачу кому-то из команды или вам.
- Создать новую задачу в одной из ваших команд.

Она никогда не удаляет, не архивирует задачи и не перемещает их в другую команду.

## Подключение

1. В панели управления выберите **Подключения**, **+ Добавить**, Linear. Или на странице настройки размещённой Machine по адресу app.themachine.computer/setup выберите **Другие источники**, Linear. На собственном компьютере сначала свяжите Machine со своим аккаунтом.
2. Нажмите **Войти через Linear**, выберите рабочее пространство и разрешите доступ.
3. Вернувшись в The Machine, вы сразу увидите, что вход выполнен, и название рабочего пространства.

Чтобы подключить другое рабочее пространство, добавьте Linear ещё раз. Выберите **Работа** или **Личное**, как и для любого подключения.

## Вместо этого вставьте ключ API

В разделе **Или вставьте ключ API** нажмите **Получить токен**. В Linear откройте **Настройки**, **Безопасность и доступ**: создайте персональный ключ API, скопируйте и вставьте его, затем нажмите **Подключить**. На собственном компьютере `assistant connect linear` тоже запросит ключ.

## Отключение

- В панели управления выберите **Подключения**, откройте Linear, затем **Подробности** и нажмите **Отключить**. Уже импортированные данные останутся.
- На размещённой Machine можно также нажать **Удалить** рядом с Linear на странице настройки.

## Отзыв доступа в Linear

В Linear откройте **Настройки**, **Безопасность и доступ**, затем отзовите доступ The Machine в списке разрешённых приложений. Если вы вставили ключ, отзовите его на той же странице.
