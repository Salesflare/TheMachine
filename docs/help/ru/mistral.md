## Для чего это нужно

Mistral, европейский поставщик ИИ. С API-ключом Mistral ваша Machine читает и составляет черновики с помощью моделей Mistral. У The Machine нет собственного ИИ: запросы отправляются напрямую в Mistral, от вашего имени и на условиях Mistral.

## Получите ключ

В Mistral нет входа через другие приложения, поэтому для подключения нужен API-ключ. Откройте раздел API keys в [консоли Mistral](https://console.mistral.ai/) и создайте ключ. В Le Chat Pro каждый месяц включены API-кредиты. После их использования Mistral взимает плату за каждое обращение.

## Подключите Mistral

Если The Machine размещена на хостинге, откройте страницу настройки, перейдите в раздел «Ваш ИИ» и откройте **Другие ИИ-сервисы**. Выберите Mistral, вставьте ключ и нажмите **Сохранить ключ**. Сначала ваша Machine проверит ключ одним коротким запросом. Если ключ неверный, вы сразу увидите сообщение, а ключ не сохранится.

Основной моделью станет Mistral Large. Также доступна Mistral Small, более дешёвый вариант для чатов или запасная модель.

Если The Machine установлена на вашем компьютере, см. [руководство по моделям](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).

## Использование

В разделе **Настройки**, **Модель** указано: «Использует ваш API-ключ Mistral». У API-ключа нет ограничений на использование, поэтому фоновые задачи не будут приостанавливаться из-за лимита. Подробнее: [Модель](model.md).

## Отключите Mistral

На странице настройки в разделе «Ваш ИИ» нажмите **Удалить** рядом с Mistral в разделе **Ключи**. Ключ будет удалён из вашей Machine. Если Mistral использовалась как основная модель, её заменит другая подключённая модель. Чтобы отозвать сам ключ, удалите его в консоли Mistral.
