Приложение открывает панель управления в отдельном окне. В углу экрана появляется маленький робот: нажмите на него, чтобы добавить задачу, спросить о сообщениях или узнать, что для вас. Это прототип.

## Скачать

По каждой ссылке всегда доступна последняя версия:

- Windows 10 или 11, 64-разрядная версия: [the-machine-desktop-setup.exe](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-setup.exe)
- Mac с macOS 13 или новее: [the-machine-desktop-mac.zip](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-mac.zip)
- Linux, 64-разрядная версия: [AppImage](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-x86_64.AppImage), [.deb](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-amd64.deb) для Ubuntu и Debian или [PKGBUILD](https://github.com/Salesflare/TheMachine/releases/latest/download/PKGBUILD) для Arch и Omarchy

Эти ссылки есть и в панели управления. На компьютере в **Настройки** → **Приложения** перечислены все три версии, а на вашем компьютере рядом с нужной стоит отметка **Этот компьютер**. В задаче **Узнайте, на что способна The Machine** есть пункт **Скачать приложение для компьютера**. Он скачивает версию для вашего компьютера или открывает инструкцию для Linux ниже. Задача исчезнет, когда вы войдёте в свою Machine через приложение. Ни список, ни задача не отображаются на телефоне или в приложении для компьютера.

## Windows

Откройте установщик. Он устанавливает приложение только для вас, без прав администратора, и подписан Salesflare. Если на компьютере раньше не использовался WebView2, его настройка займёт ещё несколько секунд, после чего приложение сразу запустится. Приложение обновляется автоматически. В **Настройки** указано, когда будет готова новая версия.

## Mac

Распакуйте архив, переместите The Machine в папку «Программы» и откройте приложение оттуда. macOS один раз спросит, открывать ли приложение из интернета: выберите «Открыть». Приложение подписано и нотариально заверено, а обновления устанавливаются автоматически.

## Linux

- Любой дистрибутив: разрешите запуск AppImage командой `chmod +x` и запустите его. Если появится сообщение об отсутствии FUSE, установите его командой `fuse3`.
- Ubuntu 22.04, Debian 12 или новее: `sudo apt install ./the-machine-desktop-amd64.deb`. WebKitGTK и gtk-layer-shell устанавливаются вместе с приложением.
- Arch и Omarchy: поместите PKGBUILD в пустую папку и выполните там `makepkg -si`. Он скачает эту версию, сверит её с контрольной суммой в файле и установит. В Hyprland, как в Omarchy, робот остаётся поверх других окон и не занимает отдельное окно.

В Linux приложение не обновляется автоматически. Чтобы установить новую версию, скачайте файл заново или скачайте новый PKGBUILD.

## Проверка загрузки

Для каждого файла GitHub предоставляет подтверждение происхождения сборки. Оно показывает, что файл собран из кода The Machine с помощью собственного рабочего процесса The Machine. С помощью [GitHub CLI](https://cli.github.com): `gh attestation verify <file> -R Salesflare/TheMachine`.

## Вход

При первом запуске откроется окно входа. Для размещённой у нас Machine или Machine в The Machine Network приложение откроет вашу учётную запись в браузере, а затем вернётся. Для самостоятельно размещённой Machine нужен её адрес, доступный с компьютера в вашей сети Tailscale.

Чтобы вместо этого установить панель управления как приложение Chrome или Edge, см. статью [Установить приложение](phone-app.md).

## Робот

Робот исчезает, пока окно приложения находится на переднем плане, и появляется снова, когда на переднем плане оказывается другое окно, а также при сворачивании или закрытии окна приложения. Если подключено несколько мониторов, робот появляется на том, где открыто окно приложения, пока вы не перетащите его на другой монитор. В Hyprland, Sway и KDE он появляется на основном мониторе. Чтобы включить или выключить робота, откройте **Настройки** (Ctrl+comma или Command-comma на Mac) и выберите **Показывать робота**.
