Приложение для компьютера открывает вашу панель в отдельном окне. В углу экрана появляется маленький робот. Нажмите на него, чтобы добавить задачу, спросить о сообщениях или посмотреть, что для вас. Это прототип.

## Скачать

По каждой ссылке всегда доступна последняя версия:

- Windows 10 или 11, 64-разрядная версия: [the-machine-desktop-setup.exe](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-setup.exe)
- Mac с macOS 13 или новее: [the-machine-desktop-mac.zip](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-mac.zip)
- Linux, 64-разрядная версия: [AppImage](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-x86_64.AppImage), [.deb](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-amd64.deb) для Ubuntu и Debian или [PKGBUILD](https://github.com/Salesflare/TheMachine/releases/latest/download/PKGBUILD) для Arch и Omarchy

Они есть и на вашей панели. На компьютере откройте **Настройки** и **Приложения**. Там перечислены все три варианта, а на вашем компьютере рядом будет пометка **Этот компьютер**. В задаче **Узнайте, на что способна The Machine** есть пункт **Скачать приложение для компьютера**. Он скачает версию для вашего компьютера или откроет инструкции для Linux ниже. Задача исчезнет, когда приложение войдёт в вашу Machine. Ни задача, ни эти варианты не отображаются на телефоне и в приложении для компьютера.

## Windows

Откройте установщик. Он установит приложение только для вас, без прав администратора, и подписан Salesflare. Если на компьютере раньше не использовался WebView2, установка займёт ещё несколько секунд. После этого приложение сразу запустится. Оно обновляется автоматически. В **Настройках** появится сообщение, когда будет готова новая версия.

## Mac

Распакуйте архив, переместите The Machine в Applications и откройте её оттуда. macOS один раз спросит, открыть ли приложение из интернета. Выберите «Открыть». Приложение подписано и нотариально заверено, а обновляется автоматически.

## Linux

- Для любого дистрибутива: сделайте AppImage исполняемым с помощью `chmod +x` и запустите его. Если появится сообщение, что не хватает FUSE, установите `fuse3`.
- Ubuntu 22.04, Debian 12 или новее: `sudo apt install ./the-machine-desktop-amd64.deb`. WebKitGTK и gtk-layer-shell установятся вместе с приложением.
- Arch и Omarchy: поместите PKGBUILD в пустую папку и выполните там `makepkg -si`. Команда скачает эту версию, проверит её по контрольной сумме в файле и установит. В Hyprland, как в Omarchy, робот будет поверх других окон и без собственного окна.

AppImage обновляется автоматически, если находится в вашей папке, например ~/Applications. В **Настройках** появится сообщение, когда будет готова новая версия. Пакеты .deb и Arch обновляются через apt и pacman. В **Настройках** появится сообщение о новой версии, а рядом будет кнопка **Скачать** для .deb или PKGBUILD. AppImage, распакованный в папку, не обновляется автоматически. Используйте AppImage как есть.

## Проверить загрузку

Для каждого файла есть подтверждение сборки GitHub, которое показывает, что файл собран из кода The Machine с помощью её собственного процесса сборки. С [GitHub CLI](https://cli.github.com): `gh attestation verify <file> -R Salesflare/TheMachine`.

## Войти

При первом запуске откроется окно для входа. Если вы используете размещённую Machine или Machine в The Machine Network, в браузере откроется ваша учётная запись, а затем приложение вернётся. Для Machine на собственном сервере нужен её адрес. Его можно получить с компьютера в вашей сети Tailscale.

Если вместо этого вы хотите установить панель как приложение Chrome или Edge, см. статью [Установить приложение](phone-app.md).

## Робот

Робот скрывается, когда окно приложения на переднем плане, и появляется снова, когда на переднем плане другое окно, или когда вы сворачиваете либо закрываете приложение. Если у вас несколько мониторов, робот отображается на том, где находится окно приложения, пока вы не перетащите его на другой монитор. В Hyprland, Sway и KDE он отображается на основном мониторе. Чтобы включить или выключить робота, откройте **Настройки** (Ctrl+запятая или Command-запятая на Mac) и выберите **Показывать робота**.
