Настольное приложение открывает панель управления в отдельном окне. В углу экрана стоит небольшой робот: нажмите на него, чтобы добавить задачу, спросить о сообщениях или посмотреть, что для вас. Это прототип.

## Скачать

По каждой ссылке всегда доступна последняя версия:

- Windows 10 или 11, 64-разрядная версия: [the-machine-desktop-setup.exe](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-setup.exe)
- Mac с macOS 13 или новее: [the-machine-desktop-mac.zip](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-mac.zip)
- Linux, 64-разрядная версия: [AppImage](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-x86_64.AppImage), [.deb](https://github.com/Salesflare/TheMachine/releases/latest/download/the-machine-desktop-amd64.deb) для Ubuntu и Debian или [PKGBUILD](https://github.com/Salesflare/TheMachine/releases/latest/download/PKGBUILD) для Arch и Omarchy

Эти ссылки есть и на панели управления. На компьютере в разделе **Настройки** → **Приложения** перечислены все три версии, а на вашем компьютере указано **Этот компьютер**. В задаче **Узнайте, на что способна The Machine** есть пункт **Скачать приложение для компьютера**. Он скачает версию для вашего компьютера или откроет инструкции для Linux ниже. Пункт исчезнет, когда вы войдёте в приложение и подключите его к своей Machine. На телефоне и в самом настольном приложении эти пункты не отображаются.

## Windows

Откройте установщик. Он установит приложение только для вас, без прав администратора. Установщик подписан Salesflare. Если на компьютере раньше не использовался WebView2, его установка займёт ещё несколько секунд. После этого приложение сразу запустится. Оно обновляется автоматически. В настройках приложения будет указано, когда выйдет новая версия.

## Mac

Распакуйте zip-архив, переместите The Machine в папку Applications и откройте приложение оттуда. При первом запуске приложения из интернета macOS спросит, открыть ли его. Выберите **Открыть**. Приложение подписано и нотариально заверено, а также обновляется автоматически.

## Linux

- Любой дистрибутив: сделайте AppImage исполняемым командой `chmod +x` и запустите его. Если появится сообщение, что не хватает FUSE, установите `fuse3`.
- Ubuntu 22.04, Debian 12 или новее: `sudo apt install ./the-machine-desktop-amd64.deb`. WebKitGTK и gtk-layer-shell входят в пакет.
- Arch и Omarchy: поместите PKGBUILD в пустую папку и запустите там `makepkg -si`. Он скачает эту версию, проверит её по контрольной сумме в файле и установит. В Hyprland, как в Omarchy, робот остаётся поверх других окон, но без отдельного окна.

AppImage обновляется автоматически, если находится в вашей папке, например ~/Applications. В настройках будет указано, когда выйдет новая версия. Пакет .deb и пакет для Arch обновляются через apt и pacman. В настройках будет указано, когда выйдет новая версия, и появится кнопка **Скачать** для .deb или PKGBUILD. AppImage, распакованный в папку, не обновляется автоматически. Используйте AppImage как есть.

## Проверить загрузку

Для каждого файла GitHub предоставляет подтверждение сборки. Оно показывает, что файл собран из кода The Machine с помощью собственного рабочего процесса. С помощью [GitHub CLI](https://cli.github.com) выполните команду `gh attestation verify <file> -R Salesflare/TheMachine`.

## Войти

При первом запуске откроется окно входа. Для размещённой Machine или Machine в The Machine Network в браузере откроется ваша учётная запись, а затем приложение вернётся на передний план. Для самостоятельно размещённой Machine нужен её адрес, доступный с компьютера в вашей сети Tailscale.

Страница вашей Machine может вывести приложение на передний план по специальной ссылке `computer.themachine.desktop://open`. Ссылка только открывает приложение и не передаёт никаких данных.

Чтобы вместо этого установить панель управления как приложение Chrome или Edge, см. статью [Установить приложение](phone-app.md).

## Робот

Робот исчезает, пока окно приложения на переднем плане, и появляется снова, когда на переднем плане другое окно или когда вы сворачиваете либо закрываете приложение. Если у вас несколько мониторов, робот находится на том же мониторе, что и окно приложения, пока вы не перетащите его на другой. В Hyprland, Sway и KDE робот находится на главном мониторе. Чтобы показать или скрыть робота, откройте **Настройки** (Ctrl+запятая, а на Mac Command+запятая) и выберите **Показывать робота**.
