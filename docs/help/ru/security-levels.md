## Два уровня

Откройте **Настройки**, затем **Безопасность**.

- **Стандарт**: настройки по умолчанию. Ничего не меняется.
- **Осторожно**: более строгие настройки, если вы хотите хранить меньше данных на телефоне и меньше данных вообще.

Уровень задаёт начальные настройки. Если потом изменить любую из них, вместо уровня будет указано **Другое**. Выберите уровень ещё раз, чтобы сбросить настройки.

## Что меняется для вас при выборе «Осторожно»

- **Текст в уведомлениях** выключен: в уведомлении написано «Новая задача» или «Подготовлена», но не указано, о чём задача.
- **Предлагать сохранять данные для входа** выключено. Сайты, на которых вы вошли и сохранили данные, останутся в списке, пока вы не нажмёте **Забыть все сохранённые входы**.
- **Найти рабочие контакты**, **Предлагать делиться выводами** и **Поделиться тем, о чём просят в разделе «Помощь»** выключены.
- **Проверить, у кого из моих контактов есть Machine** и **Разрешить людям, у которых есть мой адрес эл. почты, находить меня** выключены.
- **Хранить подробности выполнения задач 90 дней** выключено: они хранятся 30 дней.
- Для настройки **Что другие Machine могут запросить у вашей Machine** выбрано **Выключено**: планировать встречи с другими Machine нельзя. Подробнее: [Друзья и Network](friends.md#scheduling-with-other-machines).
- В Family ваша Machine сначала спрашивает вас, прежде чем сообщить, когда вы свободны или заняты. Друзьям не сообщается контекст встречи.

## Уровень для рабочего Fleet

Владелец Fleet или администратор выбирает уровень в настройках Fleet: откройте **Настройки** › **Аккаунт** и нажмите **Fleet**. Его видят все участники Fleet. Если выбрано «Осторожно»:

- Ответы коллегам отправляются только после вашего подтверждения, без указания имён и только о людях из рабочих аккаунтов.
- Знакомства и передачи тоже требуют вашего подтверждения.
- Командный Graph передаёт письма клиентов без вложений.
- В уведомлениях о рабочих задачах нет текста.
- Рабочие контакты не ищутся.
- Ваша Machine не проверяет контакты в Network и не позволяет находить вас по адресу эл. почты, если только вы сами не включили эту настройку.
- Всем нужно заново входить в аккаунт каждые 7 дней.
- Ссылка-приглашение работает только для адреса эл. почты, на который её отправили.

Участники могут выбрать более строгие настройки, чем в Fleet, но не менее строгие. Их настройки сохраняются и снова включаются, если для Fleet вернуться к «Стандарту».

## Что не меняется

Ничего не отправляется без вашего подтверждения: вы видите каждый черновик и нажимаете **Отправить**. Функция «Выполнить» и агенты для программирования работают так же. Для входа всегда нужен код из приложения-аутентификатора или ключ доступа.
