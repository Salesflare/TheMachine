## Два уровня

Откройте **Настройки**, затем **Безопасность**.

- **Стандартный**: настройки по умолчанию на сегодня. Ничего не меняется.
- **Осторожный режим**: более строгие настройки, если вы хотите хранить меньше данных на телефоне и в целом.

Уровень задаёт начальные настройки. Если изменить любую из них, отобразится **Другое**. Выберите уровень ещё раз, чтобы сбросить настройки.

## Что меняется для вас в осторожном режиме

- **Текст в уведомлениях** выключен: в уведомлении будет написано «Новая задача» или «Готово», но не будет текста задачи.
- **Предлагать сохранять данные для входа** выключено. Сохранённые входы на сайты останутся, пока вы не нажмёте **Забыть все сохранённые входы**.
- **Найти рабочие контакты**, **Предлагать делиться выводами** и **Поделиться тем, о чём просят в разделе «Помощь»** выключены.
- **Проверить, у кого из моих контактов есть Machine** и **Разрешить людям, у которых есть мой адрес эл. почты, находить меня** выключены.
- **Хранить подробности выполнения задач 90 дней** выключено: они хранятся 30 дней.
- В семейном кругу доступность свободного времени сначала нужно подтвердить. В кругу друзей контекст встреч не раскрывается.

## Уровень рабочего Fleet

Владелец Fleet или администратор выбирает уровень в настройках Fleet: откройте **Настройки** › **Аккаунт** и нажмите **Fleet**. Его видят все участники Fleet. Если выбран осторожный режим:

- Ответы коллегам отправляются только после вашего подтверждения, без имён и только о людях из ваших рабочих аккаунтов.
- Знакомства и передачи тоже ждут вашего подтверждения.
- Командный Graph делится письмами клиентов без вложений.
- В уведомлениях о рабочих задачах нет текста.
- Поиск рабочих контактов выключен.
- Ваша Machine не проверяет ваши контакты в Network и не позволяет находить вас по адресу эл. почты, если вы сами не включили эти функции.
- Всем нужно заново входить каждые 7 дней.
- Ссылка-приглашение работает только для адреса эл. почты, на который её отправили.

Участники могут выбрать настройки строже, чем в Fleet, но не мягче. Их собственные настройки сохраняются и возвращаются, если Fleet снова перейдёт на стандартный уровень.

## Что одинаково на обоих уровнях

Ничего не отправляется без вашего подтверждения: вы видите каждый черновик и нажимаете «Отправить». Функция «Выполнить» и агенты для программирования работают так же. Для входа всегда нужен код из приложения-аутентификатора или ключ доступа.
