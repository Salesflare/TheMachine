## Откуда берутся данные

- На размещённой Machine данные об организациях ищутся бесплатно.
- На собственном компьютере эта функция отключена, пока вы не добавите ключ службы поиска данных, например Apollo, People Data Labs или Hunter. Подробнее в [руководстве по настройке](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md).

Отправляется только веб-адрес организации, но не ваши сообщения и не данные о ваших знакомых там. Размещённая Machine или Machine в The Machine Network ищет данные не более чем для 1 000 организаций в день, в остальных случаях лимит составляет 50. Данные обновляются раз в 90 дней. Данные об общих сайтах и почтовых сервисах, например gmail.com, не ищутся. Для людей поиск выполняется отдельно: см. [Должность и фото](people.md#job-title-and-photo).

Если при поиске не найден логотип, The Machine использует иконку, указанную на сайте организации, и сохраняет её на вашей Machine. Сервис логотипов не узнает, с кем вы работаете. Если доступны и логотип, и иконка, в небольших местах, например в строке задачи, показывается квадратная иконка.

Если при поиске найдены специализации организации, под её описанием показывается до 5 специализаций. Список организаций можно отфильтровать по специализации: **Фильтровать**, затем **Специализация**. Если при поиске данных о человеке также найдены данные о его компании, они добавляются к данным организации, поэтому отдельный поиск не нужен. Данные, найденные за последние 90 дней, не обновляются.

## Исправить ошибку

На странице организации:

- Нажмите **Изменить**, чтобы поменять название, отрасль, размер, местоположение, год основания, описание, веб-сайт, LinkedIn, заметки и ваше отношение к организации. Ваши изменения сохраняются. Очистите поле, чтобы снова использовать найденное значение.
- Нажмите **Не та компания, удалить данные** в разделе **Изменить**, если найдена не та компания.
- Нажмите **Найти снова**, чтобы получить свежие данные. Эта кнопка появится после удаления данных.
