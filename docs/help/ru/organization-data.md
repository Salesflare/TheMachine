## Откуда берутся данные

- На размещённой Machine данные организаций находятся автоматически и бесплатно.
- На своём компьютере эта функция отключена, пока вы не добавите ключ для сервиса поиска, например Apollo, People Data Labs или Hunter. См. [руководство по настройке](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md).

Передаётся только веб-адрес организации, но не ваши сообщения и не информация о том, с кем вы знакомы в этой организации. За день можно найти данные не более чем для 50 организаций. Данные каждой организации обновляются раз в 90 дней. Общие сайты и почтовые сервисы, например gmail.com, не проверяются. Для людей есть отдельный поиск: см. [Должность и фото](people.md#job-title-and-photo).

Если в результатах поиска нет логотипа, The Machine использует значок с сайта организации и сохраняет его на вашей Machine. Сервис логотипов не узнаёт, с кем вы работаете. Если доступны и логотип, и значок, в небольших элементах интерфейса, например в строке задачи, отображается квадратный значок.

Если данные найдены, под описанием организации отображается до 5 специализаций. Список организаций можно отфильтровать по специализации: **Фильтровать**, затем **Специализация**. Если при поиске данных о человеке находятся также данные его компании, они добавляются к организации, поэтому искать их отдельно не нужно. Данные, найденные за последние 90 дней, остаются без изменений.

## Исправить данные об организации

На странице организации:

- Нажмите **Изменить**, чтобы изменить название, отрасль, размер, местоположение, год основания, описание, веб-сайт, страницу в LinkedIn и ваши отношения с организацией. Ваши изменения сохраняются. Очистите поле, чтобы снова использовать найденное значение.
- Нажмите **Не та компания, удалить данные**, если найдена не та компания.
- Нажмите **Найти снова**, чтобы получить актуальные данные.
