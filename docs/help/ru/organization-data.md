## Откуда берутся данные

- В размещённой версии The Machine данные об организациях ищутся автоматически и бесплатно.
- На своём компьютере эта функция отключена, пока вы не добавите ключ для сервиса поиска, например Apollo, People Data Labs или Hunter. См. [руководство по настройке](https://github.com/Salesflare/TheMachine/blob/main/docs/configuration.md).

Передаётся только веб-адрес организации, но не ваши сообщения и не информация о том, с кем вы там знакомы. Размещённая Machine или Machine в The Machine Network выполняет до 1 000 поисков в день, в остальных случаях доступно до 50. Данные обновляются раз в 90 дней. Общие сайты и почтовые сервисы, например gmail.com, не проверяются. Для людей предусмотрен отдельный поиск: см. [Должность и фото](people.md#job-title-and-photo).

Если поиск не находит логотип, The Machine использует значок с сайта организации и сохраняет его на вашей Machine. Сервис логотипов не узнаёт, с кем вы взаимодействуете. Если доступны и логотип, и значок, в небольших элементах интерфейса, например в строке задачи, показывается квадратный значок.

Если поиск находит специализации организации, под её описанием отображается до 5 из них. Список организаций можно отфильтровать по специализации: **Фильтровать**, затем **Специализация**. Если при поиске информации о человеке находятся данные о его компании, они также добавляются в данные организации, и отдельный поиск не требуется. Данные, найденные за последние 90 дней, остаются без изменений.

## Исправить данные организации

На странице организации:

- Нажмите **Изменить**, чтобы поменять название, отрасль, размер, местоположение, год основания, описание, веб-сайт, LinkedIn, заметки и ваше отношение к организации. Ваши изменения сохраняются. Очистите поле, чтобы снова использовать найденное значение.
- Если найдена не та компания, нажмите **Не та компания, удалить данные** в разделе **Изменить**.
- После очистки данных появится кнопка **Найти снова**. Нажмите её, чтобы получить актуальную информацию.
