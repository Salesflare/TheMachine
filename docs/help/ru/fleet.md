Fleet позволяет вашей Machine работать вместе с Machine вашей команды, семьи или друзей через The Machine Network. Всё, чем они обмениваются, защищено сквозным шифрованием, а ваша Machine отвечает только по установленным вами правилам.

## Виды Fleet

- **Рабочий Fleet**: ваша команда. Передавайте задачи, спрашивайте, кто кого знает, получайте знакомства и сводку команды.
- **Семейный Fleet**: до 6 человек. Когда все свободны, общие задачи и планы. Бесплатно; для размещённых в нём Machine действует семейная цена. Подробнее: [Семья](family.md).
- **Друзья**: любые пользователи The Machine, по одному. Бесплатно. Подробнее: [Друзья](friends.md).

## Вкладка Fleet

Она появляется, когда вы вступаете в Fleet. Для каждого Fleet есть отдельная панель, а также панели «Друзья», «Network», «Общий доступ» и «Активность». Владельцы и администраторы также видят **Управлять**, а в рабочем Fleet, где открыт общий доступ к Graph, есть раздел **Что доступно другим**.

## Стоимость, выход и создание Fleet

Под названием каждого Fleet пункт **Сколько он стоит** показывает количество мест, кто оплачивает вашу Machine, а для владельца также карту Fleet и счета. Нажмите **Покинуть этот Fleet**, чтобы выйти. Владелец сначала должен передать Fleet кому-то ещё. Нажмите **Создать ещё один Fleet**, чтобы создать новый.

Каждый пункт открывает соответствующий раздел вашей учётной записи. Если цена изменится, сначала покажется сумма для подтверждения. На Machine, размещённой у вас, они открывают вашу учётную запись в новой вкладке, где нужно войти.

## Спросить Fleet

Спросите «кто кого знает в Acme?» на вкладке Fleet или нажмите **Спросить Fleet** для организации в [Graph](graph.md). Machine каждого участника отвечает по собственным правилам общего доступа и сначала спрашивает разрешение, если этого требует правило.

По любому другому вопросу используйте **Спросите о чём угодно** на панели вашего рабочего Fleet. Каждый участник получает черновик ответа, составленный по данным его рабочих аккаунтов. Ответ не будет отправлен, пока участник сам его не отправит.

## Автоматические ответы в рабочем Fleet

В стандартном рабочем Fleet ваша Machine сама отвечает на три вида вопросов коллег: **кто кого знает**, **контекст встречи** («кто этот гость?») и **кто обрабатывает общие письма**. Она использует только сведения, уже доступные команде в [Team Graph](team-graph.md), и никогда не использует личные, частные или конфиденциальные переписки. Каждый ответ появляется на вкладке Fleet, в разделе **Активность**.

Чтобы отключить один из этих ответов, выберите **Никогда** в разделе **Общий доступ**. Если для правила выбрано **Сначала спросить меня**, оно действует как **Всегда**. Пока общий доступ к Team Graph отключён, вопросы о том, кто кого знает, и контексте встречи сначала передаются вам.

В рабочих Fleet с осторожным режимом, у друзей и в семейном Fleet ваша Machine по-прежнему сначала спрашивает вас. Для знакомств, передачи задач и бесплатных вопросов действуют собственные правила.

## Выводы команды

Ваша Machine записывает, как работает команда, на основе переписок с клиентами, уже доступных команде в Team Graph. Это происходит не чаще одного раза в день. Например: «На запросы о возврате средств отвечают из ящика поддержки, используя шаблон возврата». Выводы появляются на панели рабочего Fleet в разделе **Выводы команды** и доступны всем участникам Fleet. Каждый вывод также отображается в разделе **Активность**. Сначала вас не спрашивают.

- Учитываются только переписки, в которых участвовал кто-то из вашей команды. Личные, частные и конфиденциальные переписки не используются.
- Учитывается только то, что повторяется у нескольких клиентов: процесс, инструмент, стиль письма или распределение обязанностей. Не учитываются сведения об отдельном клиенте, отзывы о вашем продукте, имена, адреса, числа и цитаты.
- Сомнительные выводы отбрасываются.

Готовя рабочую задачу для этой компании, ваша Machine использует подходящие выводы. Ваши личные факты, правила и навыки важнее, а для личных задач выводы не используются. В задаче будет указано, если использован вывод, например: «Использован вывод команды: возвраты оформляются из ящика поддержки». Нажмите там **Удалить**, чтобы убрать его для всего Fleet.

Любой участник Fleet может нажать **Удалить**, чтобы вывод исчез у всех. Он не будет создан снова. Чтобы отключить такие выводы, в разделе «Настройки» → «Безопасность» выключите **Предлагать делиться выводами**. В рабочих Fleet с осторожным режимом выводы не создаются.

## Сводка команды

Выберите **Ежедневно** или **Еженедельно** для пункта «Сводка команды» на вкладке Fleet, в разделе **Общий доступ**. После этого ваша Machine запрашивает у Machine коллег количество и даты. То, что требует вашего внимания, появляется в разделе «Задачи» → «Работа»: например, клиент ждёт ответа коллеги, компания не выходила на связь две недели или дольше, двое из вас пишут одним и тем же людям или у вас общая встреча.

- В задаче указано, от кого ждут ответа, с какого времени, о чём просили и что поставлено на карту, например текущий проект. Если добавить нечего, пункт останется в сводке, но задачей не станет.
- Ссылки на компанию и коллег ведут на их страницы. Нажмите **Подробности**, чтобы посмотреть, что они написали, что поставлено на карту, кто из команды общается с компанией и последние переписки. Здесь доступны только сведения, открытые через [Team Graph](team-graph.md).
- Если нужная информация есть только в почте коллеги, в задаче будет указано, у кого спросить.
- Нажмите **Спросить команду**, чтобы отправить коллегам готовый вопрос. Их ответы появятся в задаче.
- Нажмите **Не нужно**, чтобы закрыть задачу. Сводка учтёт это, и задача появится снова, только если возникнет что-то новое.
- Когда кто-то отвечает или берётся за задачу, она закрывается автоматически. Если задача касается компании, для которой у вас уже есть задача, она добавится к ней.

## Запросы на сводку

Каждое утро Machine коллеги с включённой сводкой команды запрашивает у вашей Machine количество и даты. В рабочем Fleet ваша Machine отвечает автоматически, используя только сведения, уже доступные через [Team Graph](team-graph.md). Пока общий доступ к Team Graph выключен, ответов не будет. Каждый ответ появляется на вкладке Fleet, в разделе **Активность**, но не как задача или уведомление.

Чтобы отключить ответы, выключите **Поделиться с командой моими фактами из брифа** на вкладке Fleet, в разделе **Общий доступ**. После этого в сводке коллег будет указано, что ответа от вас нет.

В Fleet с осторожным режимом запросы появляются на вкладке Fleet в разделе **Запросы на сводку**. Выберите **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда**. Пока вы не выберете действие, данные не передаются. Неотвеченные запросы со временем истекают.

## Team Graph

В рабочем Fleet данные о работе с клиентами доступны команде после вашей проверки. Подробнее: [Team Graph](team-graph.md).

## Общие подключения

Владелец или администратор может один раз подключить Stripe или Intercom и открыть к ним доступ команде через раздел **Общие подключения** на вкладке Fleet. Участники команды могут просматривать данные, но не изменять их, и видят, кто открыл доступ. Изменять или отключать подключение могут только администраторы. Подробнее: [Stripe](stripe.md) и [Intercom](intercom.md).

## На что отвечает ваша Machine

Настройте это отдельно для каждого Fleet на панели «Общий доступ». Подробнее: [Правила общего доступа](sharing-rules.md). Быстрый переход к этим настройкам есть в разделе **Настройки**: **Правила Fleet**.

## Вход через аккаунт компании

Разрешите коллегам вступать в Fleet с аккаунтом компании. В размещённом у нас рабочем Fleet владелец или администратор, вошедший через Google Workspace или Microsoft 365, может включить **Вход через аккаунт компании** на странице аккаунта.

Коллеги, вошедшие с доменом компании, увидят **Попросить присоединиться**. Владелец или администратор должен **Одобрить** каждый запрос. Личные аккаунты Gmail и Outlook.com не подходят.

Удаление участника из Fleet приводит к выходу из аккаунта на всех устройствах.

Информацию о вступлении в Fleet, создании Fleet или подключении Machine на собственном компьютере см. в статьях [Тарифы и оплата](plans-and-billing.md) и [Друзья и Network](friends.md).

## Для владельцев и администраторов

В разделе **Управлять** на вкладке Fleet перечислены все Fleet, которыми вы управляете: участники, их роли и приглашения. На размещённой Machine можно сразу приглашать людей, менять их роли, удалять их и отвечать на запросы о вступлении. Если действие повлияет на цену, сначала откроется ваша учётная запись для подтверждения. На Machine, размещённой у вас, здесь показаны участники и ссылка на настройки Fleet в вашей учётной записи, где можно управлять участниками и приглашениями.

Пункт **Настройки Fleet** под названием Fleet на его панели и в разделе «Управлять» открывает настройки этого Fleet в вашей учётной записи. Там можно настроить общие подключения, безопасность, вход через аккаунт компании, выбор Machine, которая отвечает, и ещё два раздела:

- **Недавно удалено**: список удалённых участников и тех, кто вышел сам. Статус «Удалено, подтверждено» означает, что Machine участника удалила рабочие данные и он вышел из аккаунта на всех устройствах. До этого отображается статус **Ожидает** и причина.
- **Активность**: кто и когда что делал: приглашения, вступления, удаления, изменения ролей, размещённые Machine, оплата, общие подключения и одобрения. Здесь также отмечается каждый случай, когда наша служба поддержки просматривала отчёт участника о Machine или её журналы. Содержимое сообщений не показывается. Нажмите **Скачать CSV**, чтобы выгрузить данные. Они хранятся 12 месяцев.

**Спрашивать меня, прежде чем запускать Machine участника** (для владельца): если включено, Machine нового участника будет ждать вашего разрешения, даже в бесплатном Fleet. Если выключено, в бесплатном Fleet она запустится сразу, а вас уведомят. Если использование Machine платное, запуск всегда ждёт вашего подтверждения суммы.

После нажатия **Отключить общий доступ** для общего подключения статус изменится на «Удалено, подтверждено», когда все Machine потеряют к нему доступ.
