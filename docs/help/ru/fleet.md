Fleet позволяет вашей Machine работать с Machine вашей команды, семьи или друзей через The Machine Network. Они обмениваются данными со сквозным шифрованием, а ваша Machine отвечает только по вашим правилам.

## Виды Fleet

- **Рабочий Fleet**: ваша команда. Передавайте задачи, спрашивайте, кто кого знает, знакомьтесь с нужными людьми и получайте сводку команды.
- **Семейный Fleet**: до 6 человек. Когда все свободны, можно пользоваться общими задачами и планами, а также задавать вопросы Machine друг друга. Бесплатно; за размещённые в нём Machine действует семейная цена. Подробнее: [Семья](family.md).
- **Друзья**: любые пользователи The Machine, по одному. Бесплатно. Подробнее: [Друзья](friends.md).

## Вкладка Fleet

Она появляется, когда вы присоединитесь к Fleet. В ней есть отдельная панель для каждого Fleet, а также разделы «Друзья», «Network», «Общий доступ» и «Активность». Владельцы и администраторы также видят **Управлять**, а в рабочем Fleet, который открывает доступ к своему Graph, есть раздел **Что доступно другим**.

## Стоимость, выход из Fleet и создание нового

Под названием каждого Fleet раздел **Сколько он стоит** показывает количество мест, кто платит за вашу Machine, а для владельца ещё и карту и счета Fleet. Нажмите **Покинуть этот Fleet**, чтобы выйти из него. Владелец сначала должен передать Fleet другому человеку. Нажмите **Создать ещё один Fleet**, чтобы создать новый.

Каждый из этих пунктов открывает соответствующий раздел вашей учётной записи. Если цена изменится, сначала появится сумма для подтверждения. На Machine с самостоятельным хостингом откроется ваша учётная запись в новой вкладке, где нужно будет войти.

## Задайте вопрос своему Fleet

Задайте вопрос «кто кого знает в Acme?» во вкладке Fleet или нажмите **Спросить Fleet** на странице организации в [Graph](graph.md). Machine каждого участника ответит по его собственным правилам общего доступа и сначала спросит его, если этого требуют правила.

Для всего остального воспользуйтесь пунктом **Спросите о чём угодно** на панели рабочего Fleet. Каждый участник получит черновик ответа на основе своих рабочих аккаунтов, но он никуда не отправится, пока участник сам его не отправит. В черновике учитывается только то, что участник написал или обсуждал на встречах. Входящие письма, которые участник только получил, например рассылка или копия письма, будут найдены, но черновик по ним не создаётся.

## Автоматические ответы в рабочем Fleet

В стандартном рабочем Fleet ваша Machine автоматически отвечает на три типа вопросов от участников команды: **кто кого знает**, **контекст встречи** («кто этот гость?») и **кто обрабатывает общие письма**. Она использует только данные из [Graph команды](team-graph.md), уже доступные команде, и никогда не использует личные, частные или конфиденциальные переписки. Все ответы появляются во вкладке Fleet, в разделе **Активность**.

Чтобы отключить один из этих ответов, выберите **Никогда** в разделе **Общий доступ**. Для правила **Сначала спросить меня** используется вариант **Всегда**. Пока общий доступ к Graph команды выключен, Machine сначала будет спрашивать вас, прежде чем отвечать на вопросы о том, кто кого знает, и о контексте встреч.

В рабочих Fleet с режимом Careful, а также в Fleet для друзей и семьи Machine по-прежнему сначала спрашивает вас. Для тёплых знакомств, передачи задач и бесплатных вопросов действуют собственные правила.

## Выводы команды

Ваша Machine записывает особенности работы команды, используя переписки с клиентами, уже доступные в Graph команды, не чаще одного раза в день. Например: «На запросы о возврате отвечают из папки входящих службы поддержки по шаблону для возвратов». Выводы появляются на панели рабочего Fleet в разделе **Выводы команды** и доступны всем участникам Fleet. Каждый вывод также отображается в разделе **Активность**. Machine не спрашивает разрешения.

- Учитываются только переписки, в которых кто-то из команды писал. Личные, частные и конфиденциальные переписки не учитываются.
- Учитывается только то, что характерно для работы с несколькими клиентами: процесс, инструмент, стиль письма или распределение обязанностей. Не учитываются сведения об одном клиенте и отзывы о вашем продукте. Имена, адреса, номера и цитаты не используются.
- Неуверенные выводы отбрасываются.

Готовя рабочую задачу для этой компании, ваша Machine учитывает подходящие выводы. Ваши личные факты, правила и навыки важнее, а в личных задачах выводы не используются. В задаче указывается, если при её подготовке использовался вывод, например: «Использован вывод команды: возвраты оформляются из папки входящих службы поддержки». Нажмите **Удалить**, чтобы удалить его для всего Fleet.

Любой участник Fleet может нажать **Удалить** для вывода. Он исчезнет у всех, и Machine больше не создаст его снова. Чтобы отключить выводы, выключите параметр **Предлагать делиться выводами** в разделе «Настройки» → «Безопасность». В рабочих Fleet с режимом Careful выводы не создаются.

## Сводка команды

Выберите **Ежедневно** или **Еженедельно** для параметра **Сводка команды** во вкладке Fleet, в разделе **Общий доступ**. После этого ваша Machine запрашивает у Machine коллег числа и даты. Задачи, требующие вашего внимания, появляются в разделе «Задачи», в категории «Работа»: например, клиент ждёт ответа от коллеги, компания не проявляла активности две недели или дольше, двое из вас пишут одним и тем же людям или предстоит общая встреча.

- В задаче указано, кто должен ответить, с какого времени, о чём его попросили и что на кону, например текущий проект. Если нечего добавить, информация останется строкой в сводке, а не станет задачей.
- Ссылки на компанию и коллег ведут на их страницы. В разделе **Подробности** указано, что они написали (нажмите, чтобы прочитать), что на кону, кто из команды поддерживает с ними связь и какие у них последние переписки. Доступны только данные, открытые в [Graph команды](team-graph.md).
- Если сообщение доступно только в почте коллеги, в задаче будет указано, кого спросить.
- Нажмите **Спросить команду**, чтобы задать коллегам готовый вопрос. Их ответы появятся в задаче.
- Нажмите **Не нужно**, чтобы закрыть задачу. Сводка учтёт это и вернёт задачу, только если появится что-то новое.
- Задача закрывается автоматически, когда кто-то отвечает или берёт её на себя. Если для компании уже есть задача, новая присоединится к ней.

## Запросы на сводку

Каждое утро Machine коллег, у которых включена сводка команды, запрашивают у вашей Machine числа и даты. В рабочем Fleet ваша Machine отвечает автоматически, используя только данные, уже доступные в [Graph команды](team-graph.md). При выключенном общем доступе к Graph команды она не отвечает. Каждый ответ появляется во вкладке Fleet, в разделе **Активность**, но не в виде задачи или уведомления.

Чтобы отключить ответы, выключите параметр **Поделиться с командой моими фактами из брифа** во вкладке Fleet, в разделе **Общий доступ**. Тогда в сводке коллег будет указано, что вы не ответили.

В Fleet с режимом Careful запросы появятся для вас во вкладке Fleet, в разделе **Запросы на сводку**. Выберите **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда**. Данные не будут переданы, пока вы не выберете действие. Необработанные запросы со временем истекают.

## Graph команды

В рабочем Fleet работа с клиентами доступна команде после вашей проверки. Подробнее: [Graph команды](team-graph.md).

## Общие подключения

Владелец или администратор может один раз подключить Stripe или Intercom и открыть доступ команде. Для этого во вкладке Fleet нужно перейти в раздел **Общие подключения**. Коллеги смогут просматривать подключение, но не менять его, и увидят, кто его добавил. Менять подключение или отключать его могут только администраторы. Подробнее: [Stripe](stripe.md) и [Intercom](intercom.md).

## На что отвечает ваша Machine

Настройте правила для каждого Fleet на панели «Общий доступ». Подробнее: [Правила общего доступа](sharing-rules.md). Быстрый переход к ним есть в разделе **Настройки**: **Правила Fleet**.

## Вход с рабочей учётной записью

Разрешите коллегам присоединяться с рабочей учётной записью. В размещённом рабочем Fleet владелец или администратор, вошедший через Google Workspace или Microsoft 365, может включить параметр **Вход с рабочей учётной записью** на странице аккаунта.

Коллеги, которые войдут с адресом на домене компании, увидят **Запросить доступ**. Владелец или администратор должен **Одобрить** каждый запрос. Личные аккаунты Gmail и Outlook.com не подходят.

Если удалить участника из Fleet, он выйдет из аккаунта на всех устройствах.

Чтобы присоединиться к Fleet, создать его или подключить Machine на своём компьютере, см. [Тарифы и оплата](plans-and-billing.md) и [Друзья и Network](friends.md).

## Для владельцев и администраторов

В разделе **Управлять** во вкладке Fleet перечислены все Fleet, которыми вы управляете: их участники, роли участников и приглашения. На Machine с хостингом здесь можно приглашать участников, менять их роли, удалять их и отвечать на запросы о присоединении. Если действие повлияет на цену, сначала откроется ваша учётная запись для подтверждения. На Machine с самостоятельным хостингом отображаются участники и ссылка на настройки Fleet в вашей учётной записи. Там можно управлять участниками и приглашениями.

Пункт **Настройки Fleet** под названием каждого Fleet на его панели и в разделе «Управлять» открывает настройки этого Fleet в вашей учётной записи. Там можно управлять общими подключениями, безопасностью, входом с рабочей учётной записью, тем, какие Machine отвечают, а также двумя параметрами:

- **Недавно удалены**: здесь указаны удалённые участники и те, кто вышел сам. Статус «Удаление подтверждено» означает, что Machine участника удалила рабочие данные, а сам участник вышел из аккаунта на всех устройствах. До этого отображается статус **Ожидает подтверждения** и причина.
- **Активность**: кто, что и когда сделал: отправил приглашение, присоединился к Fleet или покинул его, удалил участника, изменил роль, добавил Machine с хостингом, изменил оплату, поделился подключением или одобрил запрос. Здесь также записывается каждый случай, когда наша служба поддержки просматривала отчёт о Machine участника или её журналы. Содержание сообщений не записывается. Нажмите **Скачать CSV**, чтобы экспортировать данные. Они хранятся 12 месяцев.

**Спрашивать меня перед запуском Machine участника**, для владельца: если включено, Machine нового участника будет ждать вашего разрешения, даже в бесплатном Fleet. Если выключено, в бесплатном Fleet Machine запустится сразу, а вы получите уведомление. Machine, использование которой платное, всегда ждёт, пока вы не подтвердите сумму.

После нажатия **Отключить общий доступ** подключение получит статус «Удаление подтверждено», когда все Machine потеряют к нему доступ.
