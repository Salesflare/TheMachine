Fleet позволяет вашей Machine работать вместе с Machine команды, семьи или друзей через The Machine Network. Они обмениваются данными со сквозным шифрованием, а ваша Machine отвечает только по заданным вами правилам.

## Виды Fleet

- **Рабочий Fleet**: для вашей команды. Передавайте задачи, спрашивайте, кто кого знает, знакомьтесь через коллег и получайте сводку для команды.
- **Семейный Fleet**: до 6 человек. Общие задачи и планы, когда все свободны, и вопросы к Machine друг друга. Бесплатно; размещение Machine в нём стоит по семейному тарифу. Подробнее: [Семья](family.md).
- **Друзья**: любые пользователи The Machine, по одному. Бесплатно. Подробнее: [Друзья](friends.md).

## Вкладка Fleet

Она появляется, когда вы вступаете в Fleet. Для каждого Fleet есть отдельная панель, а также панели «Друзья», Network, «Общий доступ» и «Активность». Владельцы и администраторы также видят **Управлять**, а в рабочем Fleet, который предоставляет общий доступ к своему Graph, есть раздел **Что доступно другим**.

## Стоимость, выход из Fleet и создание нового

Под названием каждого Fleet раздел **Сколько он стоит** показывает количество мест, кто платит за вашу Machine, а для владельца ещё карту и счета Fleet. Кнопка **Покинуть этот Fleet** выводит вас из него. Владелец должен сначала передать его другому участнику. Кнопка **Создать ещё один Fleet** создаёт новый Fleet.

Каждый пункт открывает соответствующий раздел аккаунта. Если цена изменится, перед подтверждением вы увидите сумму. На Machine с собственным размещением они откроют аккаунт в новой вкладке, где нужно будет войти.

## Задайте вопрос Fleet

Спросите «кто кого знает в Acme?» во вкладке Fleet или нажмите **Спросить Fleet** рядом с организацией в [Graph](graph.md). Machine каждого коллеги ответит по своим правилам общего доступа и сначала спросит его, если этого требует правило.

Для всего остального воспользуйтесь кнопкой **Спросите о чём угодно** на панели рабочего Fleet. Каждый коллега получит черновик ответа на основе своих рабочих аккаунтов. Ответ не будет отправлен, пока коллега сам этого не сделает.

## Автоматические ответы в рабочем Fleet

В стандартном рабочем Fleet ваша Machine сама отвечает на три типа вопросов коллег: **кто кого знает**, **контекст встречи** («кто этот гость?») и **кто обрабатывает общие письма**. Она использует только данные, которыми [Graph команды](team-graph.md) уже делится с командой, и никогда не обращается к личным, частным или конфиденциальным перепискам. Каждый ответ появляется во вкладке Fleet, в разделе **Активность**.

Чтобы отключить какой-либо тип ответов, выберите для него **Никогда** в разделе **Общий доступ**. Если для правила выбрано **Сначала спросить меня**, оно действует как **Всегда**. Пока общий доступ к Graph команды отключён, Machine сначала спрашивает вас, прежде чем отвечать на вопросы о том, кто кого знает, и о контексте встречи.

В рабочих Fleet с осторожными правилами, а также в Fleet для друзей и семьи Machine по-прежнему сначала спрашивают вас. Для тёплых знакомств, передачи задач и бесплатных вопросов действуют отдельные правила.

## Выводы команды

Ваша Machine записывает, как работает команда, на основе переписок с клиентами, которыми уже делится Graph команды. Это происходит не чаще одного раза в день. Например: «Запросы на возврат обрабатываются из почты поддержки с помощью шаблона для возврата». Выводы видны всем участникам Fleet на панели рабочего Fleet, в разделе **Выводы команды**. Каждый вывод также отображается в **Активность**. Machine не спрашивают вашего разрешения.

- Только переписки, в которых участвовал кто-то из команды. Не личные, частные или конфиденциальные переписки.
- Только то, что повторяется в работе с разными клиентами: процесс, инструмент, стиль письма или распределение обязанностей. Не сведения об одном клиенте, не отзывы о вашем продукте, а также не имена, адреса, числа и цитаты.
- Сомнительные выводы отбрасываются.

Ваша Machine учитывает подходящие выводы, когда готовит рабочую задачу для этой компании. Ваши личные факты, правила и навыки важнее. Для личных задач выводы не используются. Если при подготовке задачи использован вывод, об этом будет сказано, например: «Использован вывод команды: возвраты оформляются из почты поддержки». Нажмите там **Удалить**, чтобы убрать его для всего Fleet.

Любой участник Fleet может нажать **Удалить** рядом с выводом. Он исчезнет у всех и больше не будет создаваться. Чтобы запретить это, отключите **Предлагать делиться выводами** в настройках безопасности. В рабочих Fleet с осторожными правилами выводы не создаются.

## Сводка для команды

Выберите **Ежедневно** или **Еженедельно** для пункта **Сводка для команды** во вкладке Fleet, в разделе **Общий доступ**. После этого ваша Machine запросит у Machine коллег числа и даты. Задачи, требующие вашего внимания, появятся в разделе «Задачи» в категории «Работа»: например, клиент ждёт ответа от коллеги, компания не проявляла активности две недели или больше, двое из вас пишут одним и тем же людям или запланирована общая встреча.

- В задаче указано, от кого ждут ответа, с какого времени, о чём попросили и что поставлено на карту, например текущий проект. Если нет конкретной информации, вопрос останется строкой в сводке, а не станет задачей.
- Ссылки на компанию и коллег ведут на их страницы. В разделе **Подробности** можно посмотреть, что они написали (нажмите, чтобы прочитать), что поставлено на карту, кто из команды с ними общается и последние переписки. Доступны только данные, которыми делится [Graph команды](team-graph.md).
- Если сообщение есть только в почте коллеги, в задаче будет указано, кого спросить.
- Кнопка **Спросить команду** отправляет коллегам готовый вопрос. Ответы появятся в задаче.
- Кнопка **Не нужно** закрывает задачу, и сводка учитывает это. Задача появится снова, только если появится что-то новое.
- Когда кто-то ответит или возьмёт задачу, она закроется автоматически. Если для компании у вас уже есть задача, новая присоединится к ней.

## Запросы на сводку

Каждое утро Machine коллег, у которых включена сводка для команды, запрашивают у вашей Machine числа и даты. В рабочем Fleet ваша Machine отвечает сама, используя только данные, которыми уже делится [Graph команды](team-graph.md). Если общий доступ к Graph команды отключён, она не отвечает. Каждый ответ отображается во вкладке Fleet, в разделе **Активность**, а не в виде задачи или уведомления.

Чтобы отключить ответы, выключите **Поделиться с командой моими фактами из брифа** во вкладке Fleet, в разделе **Общий доступ**. После этого в сводках коллег будет указано, что вы не ответили.

В Fleet с осторожными правилами запросы появляются во вкладке Fleet, в разделе **Запросы на сводку**. Выберите **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда**. Данные не будут переданы, пока вы не выберете вариант. Запросы без ответа со временем истекают.

## Graph команды

В рабочем Fleet вы можете делиться с командой данными о работе с клиентами после того, как проверите их. Подробнее: [Graph команды](team-graph.md).

## Общие подключения

Владелец или администратор может один раз подключить Stripe или Intercom и открыть к нему общий доступ для команды в разделе **Общие подключения** во вкладке Fleet. Коллеги могут просматривать подключение, но не изменять его, и видят, кто открыл к нему доступ. Изменять подключение или отключать его могут только администраторы. Подробнее: [Stripe](stripe.md) и [Intercom](intercom.md).

## На что отвечает ваша Machine

Настройте это отдельно для каждого Fleet на панели «Общий доступ». Подробнее: [Правила общего доступа](sharing-rules.md). Быстро открыть правила можно в разделе **Настройки**, выбрав **Правила Fleet**.

## Вход с рабочим аккаунтом

Разрешите коллегам вступать в Fleet с рабочим аккаунтом. В размещённом рабочем Fleet владелец или администратор, вошедший через Google Workspace или Microsoft 365, может включить **Вход с рабочим аккаунтом** на странице аккаунта.

Коллеги, которые войдут с домена компании, увидят кнопку **Попросить доступ**. Владелец или администратор должен **Одобрить** каждый запрос. Личные аккаунты Gmail и Outlook.com не подходят.

Если удалить участника из Fleet, он выйдет из аккаунта на всех устройствах.

Подробнее о вступлении в Fleet, создании Fleet и подключении Machine на своём компьютере см. в статьях [Тарифы и оплата](plans-and-billing.md) и [Друзья и Network](friends.md).

## Для владельцев и администраторов

В разделе **Управлять** во вкладке Fleet перечислены все ваши Fleet, их участники, роли и приглашения. На размещённой Machine прямо здесь можно приглашать участников, менять их роли, удалять их и отвечать на запросы о вступлении. Если изменение повлияет на цену, сначала откроется аккаунт для подтверждения. На Machine с собственным размещением отображается список участников и ссылка на настройки Fleet в аккаунте. Там можно управлять участниками и приглашениями.

Раздел **Настройки Fleet** под названием каждого Fleet на его панели, а также в меню «Управлять», открывает настройки Fleet в аккаунте. Там можно управлять общими подключениями, безопасностью, входом с рабочим аккаунтом и тем, какая Machine отвечает. Там же доступны ещё два раздела:

- **Недавно удалённые**: список удалённых участников и тех, кто вышел из Fleet. Статус «Удалён, подтверждено» означает, что Machine участника удалила рабочие данные и он вышел из аккаунта на всех устройствах. До этого будет показан статус **Ожидает подтверждения** и причина.
- **Активность**: кто, что и когда сделал: приглашения, вступления, удаления, смены ролей, размещённые Machine, платежи, общие подключения и подтверждения. Здесь также отображается каждый случай, когда наша служба поддержки читала отчёт участника о Machine или её журналы. Содержание сообщений не отображается. Нажмите **Скачать CSV**, чтобы скачать данные. Они хранятся 12 месяцев.

Владелец может включить или выключить настройку **Спрашивать меня перед запуском Machine участника**. Если она включена, Machine нового участника будет ждать вашего разрешения, даже в бесплатном Fleet. Если она выключена, в бесплатном Fleet Machine запустится сразу, а вы получите уведомление. Machine, за которую нужно платить, всегда будет ждать вашего подтверждения суммы.

После нажатия **Отключить общий доступ** у общего подключения появится статус «Удалён, подтверждено», когда все Machine потеряют к нему доступ.
