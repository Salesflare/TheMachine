## Что она читает

Ваши встречи, вместе с участниками, комнатами и заметками: прошедшую неделю и следующий месяц на момент подключения, а затем все изменения. Они отображаются в календаре и в подготовке к встречам.

Доступно только чтение: она не добавляет, не переносит и не удаляет встречи. Почту с Exchange Server она пока не читает.

## Microsoft 365 или Exchange Server?

Exchange Server работает в вашей компании. Microsoft 365 (Exchange Online) работает в облаке Microsoft. Для него выберите **Календарь Outlook**. Если окажется, что ваш адрес относится к Microsoft 365, форма сообщит об этом.

## Подключение

1. На панели управления откройте **Подключения**, затем **Календарь** и выберите **Exchange Server**.
2. Укажите рабочий адрес электронной почты и пароль Windows.
3. Нажмите **Подключить**.

Сервер определяется по вашему адресу (Autodiscover). Не удалось найти сервер? Откройте **Настройки сервера** и введите адрес сервера, который IT-отдел предоставил для Outlook, например `mail.example.com`. Если для входа используется имя, отличное от адреса, укажите его в поле **Имя пользователя**: `DOMAIN\name`.

Вход выполняется по NTLM или Basic и только через https.

## Если подключение перестало работать

- **Сервер календаря отклонил пароль**: ваш пароль Windows изменился. Подключите календарь заново.
- **Почтовый ящик Microsoft 365**: ваш почтовый ящик перенесли в Microsoft 365. Отключите этот календарь и подключите **Календарь Outlook**.
- **Не удалось связаться с сервером календаря**: она попробует подключиться снова автоматически. Некоторые серверы доступны только из сети компании или через VPN.

## Как отключить

Откройте **Подключения**, выберите календарь, нажмите **Подробнее**, затем **Отключить**. Уже добавленные встречи останутся.
