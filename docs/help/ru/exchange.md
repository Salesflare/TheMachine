## Какие данные он читает

Встречи, участники, комнаты и заметки за прошедшую неделю и на следующий месяц на момент подключения, а затем все изменения. Они отображаются в разделе **Календарь** и при подготовке к встречам.

Доступ только для чтения: встречи нельзя добавлять, переносить или удалять. Почту из Exchange Server пока прочитать нельзя.

## Microsoft 365 или Exchange Server?

Exchange Server работает на серверах вашей компании. Microsoft 365 (Exchange Online) работает в облаке Microsoft. Для него выберите **Календарь Outlook**.

Сначала введите свой адрес. Если он относится к Microsoft 365, форма сообщит об этом и вместо поля для пароля покажет кнопку **Войти через Microsoft**. Она откроет окно входа в Календарь Outlook, пароль вводить не нужно. Если служба не найдётся за несколько секунд или компания использует собственный сервер, форма для ввода пароля останется.

## Подключение

1. На панели управления откройте **Подключения**, затем **Календарь** и выберите **Exchange Server**.
2. Укажите рабочий адрес электронной почты и пароль Windows.
3. Нажмите **Подключить**.

Сервер определяется по вашему адресу с помощью Autodiscover. Если сервер не найден, откройте **Настройки сервера** и введите адрес сервера, который ИТ-отдел указал для Outlook, например `mail.example.com`. Если для входа используется имя, отличное от вашего адреса, введите его в поле **Имя пользователя**: `DOMAIN\name`.

Вход выполняется по протоколу NTLM или Basic, только через HTTPS.

## Если подключение перестало работать

- **Сервер календаря отклонил пароль**: вы сменили пароль Windows. Подключите календарь заново.
- **Почтовый ящик Microsoft 365**: ваш почтовый ящик перенесли в Microsoft 365. Отключите это подключение и подключите **Календарь Outlook**.
- **Не удалось подключиться к серверу календаря**: система повторит попытку автоматически. Некоторые серверы доступны только из корпоративной сети или через VPN.

## Как отключить

Откройте **Подключения**, выберите календарь, затем **Подробности** и **Отключить**. Уже загруженные данные останутся.
