В **Настройки** → **Модель** указано, какая модель ИИ выполняет **Работа в фоновом режиме** и как вы вошли, например через ChatGPT.

На размещённой Machine со входом через ChatGPT используется основная модель GPT-6.2 Sol: она отвечает быстрее GPT-6.1 Sol при той же цене.

В личных тарифах ChatGPT или Claude по умолчанию ваши чаты могут использоваться для обучения моделей: **Отключить обучение на ваших данных** откроет эту настройку у провайдера, а **Готово** скроет эту строку.

## Модель и уровень размышления для чатов

В разделе **Чаты** выберите модель и уровень размышления для чатов с задачами и справки. Вы увидите только модели и уровни, доступные при вашем способе входа.

Чем больше модель размышляет, тем лучше она отвечает на сложные вопросы, но тем медленнее работает и тем больше расходует лимит вашего тарифа. **Ультраразмышление** подключает помощников для самых сложных вопросов и расходует больше всего лимита. В новой Machine по умолчанию выбран **Низкий уровень размышления**: результаты хорошие, а лимита расходуется гораздо меньше. Изменение применится со следующего сообщения.

Чтобы изменить настройку только для одного чата, нажмите на модель или уровень размышления под полем ввода. Снова выберите вариант из Настроек, чтобы использовать общие настройки.

Для проверок, вашего профиля и заранее подготовленных черновиков используется собственная модель.

## Лимиты

Если у вашего тарифа есть лимиты использования, например 5-часовой и недельный лимиты тарифа ChatGPT или Claude, здесь указано, сколько уже использовано и когда каждый лимит сбросится. Просмотр не расходует лимит вашего тарифа.

## Лимит для ваших чатов

Фоновая работа оставляет место для ваших чатов. Она приостанавливается примерно на отметке 65% от 5-часового лимита. Проверки новых сообщений продолжаются примерно до 90% недельного лимита; на остальные задачи расходуется около одной седьмой недельного лимита в день. Вход без лимитов, например по API-ключу, не приостанавливается.

Фоновая работа не выполняется на GPT-6 Astra. Вместо неё используется GPT-6.2 Sol или GPT-6.1 Sol, если GPT-6.2 не настроена.

## Когда лимит исчерпан

В верхней части панели указано, какой лимит исчерпан и когда он сбросится. Работа подождёт, а затем продолжится с того места, где остановилась. Ничего не потеряется. Если в вашем тарифе ChatGPT доступны сбросы, **Использовать сброс** сбросит лимиты. В противном случае **Посмотреть сбросы в ChatGPT** откроет соответствующую страницу ChatGPT.

## Если настроена резервная модель

Если для вашей Machine настроена резервная модель на другом тарифе или у другого провайдера, она начнёт работать после исчерпания лимита, и ожидания не будет. В верхней части панели появится сообщение «Лимит ChatGPT исчерпан, используется резервная модель». Если резервная модель перестанет работать, снова начнутся паузы.

## Изменить основную модель

Основная модель используется во всех остальных функциях The Machine. На размещённой Machine измените её на странице настройки, в разделе «Ваш ИИ». На своём компьютере см. [ChatGPT](chatgpt.md), [Mistral](mistral.md) и [руководство по моделям](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).
