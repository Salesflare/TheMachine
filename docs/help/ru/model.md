В разделе **Настройки** → **Модель** показано, какая модель ИИ выполняет **Работа в фоновом режиме** и через какой аккаунт вы вошли, например через ChatGPT.

На размещённой Machine с входом через ChatGPT основная модель, GPT-6.2 Sol. Она отвечает быстрее, чем GPT-6.1 Sol, по той же цене.

Срок входа через Claude истекает примерно через четыре недели после входа. За три дня до этого появится сообщение **Ждёт вас**, а после истечения срока вы получите одно уведомление. **Войти снова** поможет восстановить доступ за один шаг.

Личный тариф ChatGPT или Claude может по умолчанию использовать ваши чаты для обучения. Кнопка **Отключить обучение на ваших данных** открывает соответствующую настройку у провайдера, а **Готово** скрывает эту строку.

## Модель и уровень размышления в чатах

В разделе **Чаты** выберите модель и уровень размышления для чатов с задачами и раздела «Справка». Вы увидите только те модели и уровни, которые доступны при вашем способе входа.

Чем выше уровень размышления, тем лучше ответы на сложные вопросы, но тем медленнее работа и больше расходуется лимит тарифа. **Ультраразмышление** подключает помощников для самых сложных вопросов и расходует больше всего. Новая Machine начинает с **Низкий уровень размышления**. Результаты хорошие, а расход лимита намного меньше. Изменение вступит в силу со следующего сообщения.

Чтобы изменить настройку только для одного чата, нажмите на модель или уровень размышления под полем ввода сообщения. Снова выберите вариант **Настройки**, чтобы использовать общие настройки.

Проверки, ваш профиль и подготовленные заранее черновики используют собственную модель.

## Лимиты

Если у вашего тарифа есть лимиты использования, например 5-часовые и недельные лимиты тарифов ChatGPT или Claude, здесь показано, сколько уже использовано и когда каждый лимит сбросится. Просмотр не расходует лимиты тарифа.

## Запас для ваших чатов

Фоновая работа оставляет запас для ваших чатов. Она приостанавливается, когда использовано примерно 65% 5-часового лимита. Проверки новых сообщений продолжаются, пока не будет использовано примерно 90% недельного лимита. Остальные задачи расходуют примерно одну седьмую недельного лимита в день. Вход без лимитов, например с помощью API-ключа, никогда не приостанавливается.

Фоновая работа никогда не выполняется на GPT-6 Astra. При входе через ChatGPT и версии OpenClaw ниже 2026.11.10 она использует GPT-6.1 Sol, даже если основная модель у вас GPT-6.2 Sol. В этом случае GPT-6.2 не использует повторно инструкции из кэша, поэтому расходует больше лимита. Начиная с OpenClaw 2026.11.10, фоновая работа снова использует основную модель. Для ваших чатов сохраняется выбранная вами модель.

Перед проверкой небольшая модель (GPT-6 Luna при входе через ChatGPT, Haiku при входе через Claude) отбирает рассылки, рекламу и уведомления приложений, которые явно не требуют внимания. Так на проверках расходуется меньше лимита. Эти сообщения по-прежнему можно найти через поиск. Сообщения от людей, счета, предупреждения безопасности и коды для входа всегда проверяются.

## Перед достижением лимита

Если у вашего тарифа ChatGPT остались сбросы, в разделе «Задачи» появится короткое сообщение, когда фоновая работа замедлится: примерно при использовании 65% 5-часового лимита или 90% недельного лимита. В сообщении указано, сколько уже использовано и сколько сбросов осталось. Кнопка **Использовать сброс** обнуляет лимиты после вашего подтверждения. Нажмите ×, чтобы скрыть сообщение до сброса этого лимита. Если сбросов нет, новое сообщение не появится.

На размещённой Machine ваша Machine увидит и использует сбросы, когда в Codex на вашей Machine будет выполнен вход в тот же аккаунт ChatGPT. До этого в разделах «Задачи» и «Настройки» будет показана кнопка **Включить сбросы**. Она откроет шаг Codex на странице настройки, где нужно войти по коду, как при входе в ChatGPT.

## Когда лимит достигнут

В верхней части панели показано, какой лимит достигнут и когда он сбросится. Работа подождёт, а затем продолжится с того места, где остановилась. Ничего не потеряется. Если в вашем тарифе ChatGPT есть сбросы, кнопка **Использовать сброс** обнулит лимиты. Если на размещённой Machine не выполнен вход в Codex, кнопка **Включить сбросы** откроет страницу настройки. В остальных случаях кнопка **Посмотреть сбросы в ChatGPT** откроет соответствующую страницу ChatGPT.

## Резервная модель

Если у вашей Machine есть резервная модель в другом тарифе или у другого провайдера, она начнёт работать при достижении лимита, и ничего не будет ждать. В верхней части панели появится сообщение «Достигнут лимит ChatGPT, используется резервная модель». Если резервная модель перестанет работать, паузы возобновятся.

## Изменить основную модель

Основную модель использует остальная часть The Machine. На размещённой Machine измените её на странице настройки, в разделе «Ваш ИИ». На собственном компьютере см. статьи [ChatGPT](chatgpt.md), [Mistral](mistral.md) и [руководство по моделям](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).
