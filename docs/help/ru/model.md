В разделе **Настройки** на странице **Модель** указано, какая модель ИИ выполняет задачи в разделе **Работа в фоновом режиме** и как вы вошли в аккаунт, например через ChatGPT.

## Модель и уровень размышления в чатах

В разделе **Чаты** выберите модель и уровень размышления для чатов с задачами и справки. Вы увидите только модели и уровни, доступные при выбранном способе входа.

Чем больше размышлений, тем лучше модель отвечает на сложные вопросы, но тем медленнее она работает и тем больше расходует ресурсов вашего плана. **Ультраразмышление** подключает помощников для самых сложных вопросов и расходует больше всего ресурсов. На новой The Machine установлен **Низкий уровень размышления**: результат хороший, а ресурсов плана расходуется гораздо меньше. Изменение начнёт действовать со следующего сообщения.

Чтобы изменить настройку только для одного чата, нажмите на модель или уровень размышления под полем ввода сообщения. Снова выберите вариант **Настройки**, чтобы использовать настройки по умолчанию.

Для проверок, вашего профиля и заранее подготовленных черновиков используются отдельные модели.

## Лимиты

Если у вашего плана есть лимиты использования, например 5-часовой и недельный лимиты в планах ChatGPT или Claude, здесь показано, сколько уже использовано и когда лимиты сбросятся. Просмотр этой информации не расходует ресурсы вашего плана.

## Место для ваших чатов

Фоновая работа оставляет ресурсы для ваших чатов. Она приостанавливается, когда используется примерно 65% 5-часового лимита. Проверки новых сообщений продолжаются, пока не будет использовано примерно 90% недельного лимита. На другие задачи каждый день расходуется примерно седьмая часть недельного лимита. Вход без лимитов, например с помощью API-ключа, не приводит к приостановке.

Фоновая работа никогда не выполняется на GPT-6 Astra. Вместо неё используется GPT-6.1 Sol.

## Когда лимит исчерпан

В верхней части панели управления указано, какой лимит исчерпан и когда он сбросится. Работа приостанавливается, а затем продолжается с того места, на котором остановилась. Ничего не теряется. Если в вашем плане ChatGPT доступны сбросы, выберите **Использовать сброс**, чтобы начать отсчёт лимитов заново. В противном случае выберите **Посмотреть сбросы в ChatGPT**, чтобы открыть страницу ChatGPT.

## С резервной моделью

Если для вашей The Machine настроена резервная модель в другом плане или у другого провайдера, она начнёт работать, когда лимит будет исчерпан. Работа не будет ждать. В верхней части панели управления появится сообщение: «Лимит ChatGPT исчерпан, используется резервная модель». Если резервная модель перестанет работать, задачи снова будут приостанавливаться.

## Сменить основную модель

Основная модель используется во всех остальных функциях The Machine. Если The Machine размещена в облаке, смените модель на странице настройки в разделе «Ваш ИИ». Если The Machine работает на вашем компьютере, см. статьи о [ChatGPT](chatgpt.md), [Mistral](mistral.md) и [моделях](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).
