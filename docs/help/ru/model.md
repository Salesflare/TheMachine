В разделе **Настройки** → **Модель** указано, какая модель ИИ выполняет **Работу в фоновом режиме** и как вы вошли в систему, например через ChatGPT.

Для Machine на хостинге, если вы вошли через ChatGPT, основная модель: GPT-6.2 Sol. Она отвечает быстрее, чем GPT-6.1 Sol, при той же цене.

В личных тарифах ChatGPT или Claude ваши чаты по умолчанию могут использоваться для обучения. Пункт **Отключить обучение на ваших данных** открывает соответствующую настройку у поставщика, а пункт **Готово** скрывает эту строку.

## Модель и уровень размышления в чатах

В разделе **Чаты** выберите модель и уровень размышления для чатов с задачами и раздела «Помощь». Вы увидите только модели и уровни, доступные при вашем способе входа.

При более глубоком размышлении модель лучше отвечает на сложные вопросы, но работает медленнее и расходует больше лимитов вашего тарифа. **Ультраразмышление** подключает помощников для самых сложных вопросов и расходует больше всего лимитов. Новая Machine начинает с уровня **Низкий уровень размышления**: результаты хорошие, а лимитов расходуется гораздо меньше. Изменение вступает в силу со следующего сообщения.

Чтобы изменить настройки только для одного чата, нажмите на модель или уровень размышления под полем ввода. Чтобы использовать настройки из раздела «Настройки», снова выберите соответствующий вариант.

Для проверок, вашего профиля и заранее подготовленных черновиков используется своя модель.

## Лимиты

Если в вашем тарифе есть лимиты использования, например лимиты на 5 часов и на неделю в тарифах ChatGPT или Claude, здесь указано, сколько уже использовано и когда лимиты сбросятся. Просмотр этой информации не расходует лимиты вашего тарифа.

## Лимиты для ваших чатов

Работа в фоновом режиме оставляет место для ваших чатов. Она приостанавливается, когда использовано примерно 65% лимита на 5 часов. Проверки новых сообщений продолжаются, пока не будет использовано примерно 90% недельного лимита. На прочую работу ежедневно уходит примерно одна седьмая недельного лимита. При входе без лимитов, например с помощью ключа API, работа не приостанавливается.

Работа в фоновом режиме не выполняется на GPT-6 Astra. Пока при входе через ChatGPT для неё используется GPT-6.1 Sol, даже если основная модель: GPT-6.2 Sol. В этом аккаунте GPT-6.2 пока не использует кэшированные инструкции повторно, поэтому расходует больше лимитов вашего тарифа. В чатах остаётся выбранная вами модель.

## Когда лимит исчерпан

В верхней части панели управления указано, какой лимит исчерпан и когда он сбросится. Работа ждёт, а затем продолжается с того места, где остановилась. Ничего не теряется. Если в вашем тарифе ChatGPT есть сбросы, кнопка **Использовать сброс** обнуляет лимиты. В противном случае кнопка **Посмотреть сбросы в ChatGPT** открывает соответствующую страницу ChatGPT.

## Резервная модель

Если для вашей Machine настроена резервная модель в другом тарифе или у другого поставщика, она включается при исчерпании лимита, и работа не ждёт. В верхней части панели управления появится сообщение: «Лимит ChatGPT исчерпан, используется резервная модель». Если резервная модель перестанет работать, работа снова будет приостанавливаться.

## Смена основной модели

Основная модель используется в остальных функциях The Machine. Для Machine на хостинге измените её на странице настройки, в разделе «Ваш ИИ». На собственном компьютере см. материалы [ChatGPT](chatgpt.md), [Mistral](mistral.md) и [руководство по моделям](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).
