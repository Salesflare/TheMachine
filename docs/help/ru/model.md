В **Настройки** → **Модель** указано, какая модель ИИ выполняет **Работа в фоновом режиме** и как вы вошли, например через ChatGPT.

На размещённой Machine основная модель при входе через ChatGPT это GPT-6.2 Sol. Она отвечает быстрее, чем GPT-6.1 Sol, при той же цене.

На размещённой Machine вход через Claude действует около года. С `claude auth login` он завершается примерно через четыре недели после входа. За три дня до этого появится уведомление **Ждёт вас**, а вам придёт письмо. Когда срок действия входа закончится, вы получите одно уведомление и письмо, если оно ещё не приходило. **Войти снова** можно в один шаг.

Личный тариф ChatGPT или Claude может по умолчанию использовать ваши чаты для обучения. **Отключить обучение на ваших данных** открывает эту настройку у провайдера, а **Готово** скрывает эту строку.

## Модель и уровень размышления в чатах

В разделе **Чаты** выберите модель и уровень размышления для чатов с задачами и раздела «Помощь». Вы увидите только модели и уровни, доступные при вашем способе входа.

Более глубокое размышление помогает лучше отвечать на сложные вопросы, но занимает больше времени и расходует больше лимитов вашего тарифа. **Ультраразмышление** подключает помощников для самых сложных вопросов и расходует больше всего лимитов. На новой Machine установлен **Низкий уровень размышления**. Он даёт хорошие результаты и расходует гораздо меньше лимитов вашего тарифа. Изменение применяется со следующего сообщения.

Чтобы изменить настройку только для одного чата, нажмите на модель или уровень размышления под полем ввода сообщения. Чтобы снова использовать настройку из раздела «Настройки», выберите вариант «Настройки».

Для проверок, вашего профиля и заранее подготовленных черновиков используется собственная модель.

## Лимиты

Если у вашего тарифа есть лимиты использования, например 5-часовые и недельные лимиты тарифа ChatGPT или Claude, здесь указано, сколько уже использовано и когда каждый лимит сбросится. Просмотр не расходует лимиты вашего тарифа.

## Резерв для ваших чатов

Работа в фоновом режиме оставляет резерв для ваших чатов. Она приостанавливается, когда использовано примерно 65% 5-часового лимита. Проверка новых сообщений продолжается, пока не будет использовано около 90% недельного лимита. На остальные задачи ежедневно уходит примерно одна седьмая недельного лимита. Вход без лимитов, например по API-ключу, никогда не приостанавливается.

Работа в фоновом режиме не выполняется на GPT-6 Astra. При входе через ChatGPT и версии OpenClaw ниже 2026.11.10 для неё используется GPT-6.1 Sol, даже если основная модель это GPT-6.2 Sol. В этом случае GPT-6.2 не использует повторно кешированные инструкции и расходует больше лимитов вашего тарифа. Начиная с OpenClaw 2026.11.10 снова используется основная модель. В чатах остаётся выбранная вами модель.

Перед проверкой небольшая модель (GPT-6 Luna при входе через ChatGPT, Haiku при входе через Claude) отбирает рассылки, рекламу и уведомления приложений, которым явно не требуется внимание. Так проверки расходуют меньше лимитов вашего тарифа. Эти сообщения остаются доступными для поиска. Сообщения от людей, счета, предупреждения безопасности и коды входа всегда проверяются.

## Перед достижением лимита

Если в вашем тарифе ChatGPT остались сбросы, в разделе «Задачи» появится короткое сообщение, когда работа в фоновом режиме замедлится: примерно при использовании 65% 5-часового лимита или 90% недельного лимита. В нём указано, сколько лимитов использовано и сколько сбросов осталось. **Использовать сброс** начинает отсчёт лимитов заново после вашего подтверждения. Кнопка × скроет сообщение до сброса этого лимита. Если сбросов нет, новое сообщение не появится.

На размещённой Machine ваша Machine увидит сбросы и сможет их использовать, когда вы войдёте в Codex на своей Machine с той же учётной записью ChatGPT. До этого в разделах «Задачи» и «Настройки» будет показываться **Включить сбросы**. Эта кнопка открывает шаг Codex на странице настройки, где нужно войти с помощью кода, как и при входе через ChatGPT.

## Когда лимит исчерпан

В верхней части панели управления будет указано, какой лимит исчерпан и когда он сбросится. Работа приостановится, а затем продолжится с того места, где остановилась. Ничего не потеряется. Если в вашем тарифе ChatGPT есть сбросы, кнопка **Использовать сброс** начинает отсчёт лимитов заново. Если это размещённая Machine, в которую ещё не выполнен вход в Codex, кнопка **Включить сбросы** вместо этого откроет страницу настройки. В остальных случаях кнопка **Посмотреть сбросы в ChatGPT** откроет страницу ChatGPT.

## С резервной моделью

Если для Machine настроена резервная модель на другом тарифе или у другого провайдера, при достижении лимита она подменит основную модель, и работа не будет приостановлена. В верхней части панели управления появится сообщение «Лимит ChatGPT исчерпан, используется резервная модель». Если резервная модель перестанет работать, работа снова будет приостанавливаться.

## Изменение основной модели

Основная модель используется во всех остальных функциях The Machine. На размещённой Machine её можно изменить на странице настройки в разделе «Ваш ИИ». На своём компьютере см. статьи [ChatGPT](chatgpt.md), [Mistral](mistral.md) и [руководство по моделям](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md).
