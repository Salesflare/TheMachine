Всё, чему учится ваша Machine, принадлежит вам. Передайте эти знания другому ИИ, например ChatGPT или Claude, или сохраните их у себя.

## Экспортируйте знания

1. Откройте **Настройки** › **Общие** › **Экспортировать** и нажмите **Экспортировать** рядом с пунктом **Знания для другого ИИ**.
2. Пункт **Текст сообщения** по умолчанию выключен: в файле указываются только источник каждого элемента и дата. Включите его, чтобы добавить текст сообщений.
3. Включайте **Конфиденциально и осторожно**, только если хотите добавить проекты только для вас, приватные ветки и Fleet с режимом Careful.
4. При желании задайте **Кодовая фраза** (не менее 10 символов), чтобы зашифровать файл.
5. Нажмите **Скачать**. Файл можно скачать только один раз.

Экспорт работает одинаково и в размещённой в облаке Machine, и на вашем компьютере.

## Что войдёт в файл

- Люди, организации и проекты: отдельная страница Markdown для каждого, с описанием связей между ними.
- Факты и предпочтения: что ваша Machine знает о вас и о них.
- Устаревшие факты: то, что больше не актуально (завершено, отложено или заменено), с указанием, на что это заменили. Удалённые вами факты не попадут в файл.
- Правила, особенности вашего письма и подписи: то, чему следуют ваши черновики.
- Навыки: ваши инструкции, включённые и выключенные.
- Контекст: краткие описания команды, сводки, обещания и незакрытые задачи.
- Источники: откуда взят каждый элемент, с указанием идентификатора и даты.

Контакты и задачи также экспортируются в таблицы (CSV). В начале файла есть README с инструкциями для ИИ. Загрузите ZIP в ИИ как файл знаний или проект.

## Что не попадёт в файл

Пароли, ключи и данные для входа не экспортируются. Данные коллег по команде, настройки и фотографии тоже не попадут в файл. Чтобы перенести Machine целиком, см. [Как перенести на другой компьютер](moving.md).
