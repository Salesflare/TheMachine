Всё, чему учится ваша Machine, принадлежит вам. Передайте эти знания другому ИИ, например ChatGPT или Claude, или оставьте их себе.

## Экспорт

1. В **Настройки** › **Общие** › **Экспортировать** нажмите **Экспортировать** рядом с пунктом **Знания для другого ИИ**.
2. По умолчанию **Текст сообщения** выключен: экспортируются только источник каждого элемента и дата. Включите этот параметр, чтобы добавить текст.
3. Включайте **Приватное и «Осторожно»**, только если хотите добавить проекты только для вас, личные переписки и Fleet в режиме «Осторожно».
4. При желании задайте **Парольная фраза** (не менее 10 символов), чтобы зашифровать файл.
5. Нажмите **Скачать**. Файл можно скачать только один раз.

Экспорт работает одинаково на размещённой Machine и на вашем компьютере.

## Что входит в экспорт

- Люди, организации и проекты: отдельная страница Markdown для каждого с описанием их связей.
- Факты и предпочтения: что ваша Machine знает о вас и о них.
- Факты, утратившие актуальность: что больше не действует (завершилось или было заменено) и чем это заменили. Удалённые вами факты не включаются.
- Правила, стиль письма и подписи: требования, которым следуют ваши черновики.
- Навыки: ваши инструкции, включённые и выключенные.
- Контекст: сводки для команды, строки с кратким описанием, обещания и незакрытые задачи.
- Источники: откуда взят каждый элемент, с указанием идентификатора и даты.

Контакты и задачи также входят в экспорт в виде таблиц (CSV). В начале архива есть файл README с инструкциями для ИИ. Загрузите ZIP-архив в ИИ как файл знаний или проект.

## Что не входит в экспорт

Пароли, ключи и данные для входа не включаются. Данные коллег, настройки и фотографии тоже не включаются. Чтобы перенести всю Machine, см. статью [Перенос на другой компьютер](moving.md).
