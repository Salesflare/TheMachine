## Что считывает

Ваши компании, контакты и сделки в Salesflare, а также ленту каждой компании: письма коллег, в которых вы не участвовали, и встречи с заметками.

## Что может изменить

Ничего. (На собственном компьютере настройка `join_pipelines` может добавлять вас в компании из выбранных воронок. По умолчанию она отключена.)

## Подключение

1. В Salesflare откройте [Настройки, API-ключи](https://app.salesflare.com/#/settings/apikeys) и создайте ключ.
2. В размещённой Machine откройте страницу настройки на app.themachine.computer/setup, перейдите в **Дополнительные источники**, откройте Salesflare CRM, вставьте ключ и нажмите **Подключить**.
3. В панели управления откройте **Подключения**, **Клиенты**, Salesflare CRM, вставьте ключ и нажмите **Подключить**. На карточке появится ход синхронизации.

## Сведения о синхронизации

В разделе **Подключения**, **Клиенты** на карточке Salesflare отображается ход синхронизации: компании, проверенные за этот цикл, компании, пропущенные из-за медленной работы Salesflare, и компании, к которым нет доступа по вашему ключу API (**Нет доступа**). Если цикл длится несколько часов, появится сообщение, что синхронизация могла зависнуть.

На плитках указано количество компаний, которые система прочитала за эту неделю, а также писем и встреч, которые она добавила.

Если доступа нет к нескольким компаниям, ничего исправлять не нужно: остальные данные поступят как обычно. Если по вашему ключу API не открывается ни одна компания, на карточке появится статус **Ждёт вашей помощи**. Используйте ключ пользователя, которому они доступны. Новый ключ начинает синхронизацию заново и повторно считывает данные за последнюю неделю. Если Salesflare продолжает прерывать соединение по тайм-ауту, но каждая повторная попытка проходит успешно, появится сообщение, что Salesflare **иногда работает медленно**.

Если Salesflare не включила для вашей команды доступ к ленте через ключи API, на карточке появится соответствующее сообщение. Письма и встречи не поступят, пока служба поддержки Salesflare не включит доступ. Система повторяет проверку каждые 10 минут в первый день, затем примерно раз в час. Когда доступ заработает, синхронизация продолжится автоматически.

- **Остановить**: новые данные не поступают, пока вы не нажмёте **Начать**. Синхронизация продолжится с того места, где остановилась.
- **Перезапустить синхронизацию**: начинает синхронизацию заново и повторно считывает данные за последнюю неделю. Уже добавленные данные не пропадут.
- **API-ключи**: открывает страницу API-ключей Salesflare, где можно создать новый ключ.

## Отключение

- В панели управления откройте **Подключения**, выберите Salesflare, нажмите **Подробности**, затем **Отключить**. Уже добавленные данные сохранятся.
- В размещённой Machine также можно нажать **Удалить** рядом с Salesflare на странице настройки.

## Отзыв доступа в Salesflare

Удалите ключ API в Salesflare, в разделе **Настройки**, **API-ключи**.
