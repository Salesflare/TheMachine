## Что считывается

Ваши аккаунты, контакты и сделки в Salesflare, а также лента каждого аккаунта: письма коллег, в которых вас не было среди получателей, и встречи с заметками.

## Что можно изменить

Ничего. (На вашем компьютере настройка `join_pipelines` позволяет добавлять вас в аккаунты из выбранных воронок. По умолчанию она отключена.)

## Подключение

1. В Salesflare откройте [Settings, API keys](https://app.salesflare.com/#/settings/apikeys) и создайте ключ.
2. Если The Machine размещена на хостинге: откройте страницу настройки по адресу app.themachine.computer/setup, выберите **Другие источники**, откройте Salesflare CRM, вставьте ключ и нажмите **Подключить**.
3. В панели управления выберите **Подключения**, **Клиенты**, Salesflare CRM, вставьте ключ и нажмите **Подключить**. На карточке появится информация о ходе синхронизации.

## Подробнее о синхронизации

В разделе **Подключения**, **Клиенты** на карточке Salesflare отображается ход синхронизации: сколько аккаунтов прочитано за этот цикл и сколько пропущено, потому что Salesflare отвечала слишком медленно. Если цикл длится несколько часов, возможно, синхронизация застряла.

На карточке указано количество аккаунтов, которые удалось открыть, а также полученных писем и встреч. Если с помощью вашего ключа API нельзя открыть ни один аккаунт, появится сообщение **Ждёт вашей помощи**: используйте ключ пользователя, которому они доступны. Если Salesflare часто не отвечает вовремя, но повторные попытки проходят успешно, появится сообщение, что Salesflare **иногда работает медленно**.

Если в Salesflare для вашей команды не включён доступ к ленте через ключи API, на карточке появится сообщение об этом. Письма и встречи не будут поступать, пока служба поддержки Salesflare не включит доступ. В первый день система будет проверять это каждые 10 минут, затем примерно раз в час. Как только доступ заработает, синхронизация продолжится автоматически.

- **Остановить**: новые данные не поступают, пока вы не нажмёте **Начать**. Синхронизация продолжится с того места, где остановилась.
- **Перезапустить синхронизацию**: запускает её заново и повторно считывает данные за последнюю неделю. Уже полученные данные не удаляются.
- **Ключи API**: открывает страницу ключей API в Salesflare, где можно создать новый ключ.

## Отключение

- В панели управления выберите **Подключения**, откройте Salesflare, нажмите **Подробности**, затем **Отключить**. Уже полученные данные останутся.
- Если The Machine размещена на хостинге, Salesflare также можно удалить на странице настройки: нажмите **Удалить** рядом с ним.

## Отзыв доступа в Salesflare

Удалите ключ API в Salesflare: откройте Settings, API keys.
