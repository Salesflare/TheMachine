## Друзья

Добавьте человека по точному имени пользователя во вкладке **Fleet**, в разделе «Друзья». Друзья могут узнавать, кто знаком с тем или иным человеком, получать контекст о встречах и знакомиться через общих знакомых, а также видеть, когда вы заняты (только время, не содержание). Вы можете в любой момент удалить друга или заблокировать его.

## Найдите знакомых

В **Fleet**, в разделе **Network**:

- «Проверить, у кого из моих контактов есть Machine» предложит знакомых.
- «Разрешить людям с моим адресом электронной почты находить меня» позволит им найти вас.

Обе настройки включены по умолчанию и выключены при уровне безопасности «Осторожный». Вы можете в любой момент выключить любую из них. Выбранные настройки сохраняются. Вас можно найти по адресу электронной почты, который вы используете для входа (эта возможность всегда включена), и по подключённым адресам. Для каждого из них есть отдельный переключатель в разделе **Можно найти по**, кроме общих адресов вроде info@. Для них эта возможность выключена, пока вы её не включите.

Знакомые появятся сразу после включения настройки, а новые пользователи будут появляться по мере присоединения. Для каждого доступны варианты «Подключиться», «Не сейчас» или **Никогда не предлагать**. Когда вы станете друзьями, этот человек больше не будет появляться в предложениях. Нажмите **Покинуть Network**, чтобы выйти из неё.

В списке людей рядом с найденными пользователями появится отметка **Есть Machine**. Machine проверяет адреса в ваших сообщениях и адреса, которые вы добавили к контакту с помощью **Изменить**. Если человек зарегистрировался с другого адреса, добавьте его к контакту. На странице найденного человека нажмите **Добавить в друзья**, чтобы отправить тот же запрос, что и при выборе «Подключиться». В меню ⋯ есть вариант **Добавить как члена семьи**.

Если у человека нет Machine, появится вариант **Пригласить в The Machine**. Он откроет письмо, которое человек получит. В окне **Отправить это письмо?** его можно изменить, как и любое письмо для задачи. Письмо не отправится, пока вы не нажмёте **Отправить сейчас**. Если закрыть окно, приглашение останется задачей. Если у вас нет почтового ящика, с которого можно отправлять письма, выберите **Копировать** или **Открыть в почте**.

Учитываются и номера телефонов: номера людей, которым вы писали или с которыми встречались в чатах WhatsApp, а также номера, добавленные с помощью **Изменить**. По привязанному номеру WhatsApp и номерам в разделе «О вас» вас можно найти. Для каждого номера есть отдельный переключатель в разделе **Можно найти по**. Номер поможет найти человека, только если он тоже искал вас или вы уже друзья. Поэтому никто не сможет перебирать номера, чтобы узнать, у кого есть Machine.

## Планирование с другими Machine

Если человек с Machine напишет «давайте встретимся на следующей неделе», ваша Machine запросит у его Machine свободное время и подберёт время, которое подходит вам обоим и входит в ваши рабочие часы. Каждый из вас получит одну задачу, например «Встретиться с Alex Example», а под ней будет указано время. Нажмите **Забронировать**, **Другое время** или **Не нужно**. Приглашение отправится, только когда вы оба нажмёте «Забронировать».

Передаются только сведения о свободном или занятом времени. Они сквозным образом зашифрованы, передаются максимум на 14 дней вперёд и округляются до 15 минут. Приватные события считаются занятостью. Machine может отправить запрос, только если вы оба писали друг другу по электронной почте. Выберите вариант в разделе **Что другие Machine могут запросить у вашей Machine**: **Свободна/занята для планирования** или **Выключено**. Там же задайте длительность встречи, перерыв между встречами и предпочтительное время. Каждый запрос отображается в разделе «Активность», во вкладке «Календарь».

Если у человека нет Machine или он не ответил, в черновике письма появится ссылка, по которой он сможет выбрать одно из ваших свободных окон. Его выбор появится как задача с кнопкой **Забронировать**. Встреча не будет забронирована, пока вы не нажмёте её.

По ссылке доступны только свободные окна, определённые по тем же правилам. Она не раскрывает никакую другую информацию о вас. Ссылка перестанет работать после бронирования встречи или через 14 дней. В письме она отображается как «Выбрать время». Внизу страницы написано: «Ваша Machine нашла это время. Найдите своё». Там же указано ваше имя. Отключите эту подпись с помощью настройки **Нижний колонтитул в ссылках для бронирования**. Каждая ссылка и выбор времени отображаются в разделе «Активность».

## Machine на вашем компьютере

Чтобы присоединиться к Network с Machine, которую вы запускаете самостоятельно:

1. Откройте **Настройки** в панели управления Machine и нажмите **Присоединиться к Network**.
2. На открывшейся странице войдите в аккаунт (или создайте его) и подтвердите действие. Machine подключится сама, перезапуск не нужен.

Можно также подключить её с помощью кода: на странице аккаунта в app.themachine.computer нажмите «Подключить Machine на собственном сервере», затем запустите `assistant fleet-pair` с кодом на своём компьютере и перезапустите Machine. Код действует один раз в течение 15 минут.

К одному аккаунту можно подключить до 5 Machine. Каждую из них можно отключить на этой же странице.
