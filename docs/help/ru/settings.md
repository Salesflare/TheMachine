Откройте **Настройки** с помощью значка шестерёнки вверху. Вкладки:

- **Аккаунт**: вверху находятся **Ваши адреса** (адреса, которые считаются вашими) и **Выйти**. В облачной версии Machine здесь также есть ваш тариф, счета, Fleet, друзья, вход и данные, а в самом низу **Отменить подписку** и **Удалить аккаунт**. В версии Machine на вашем компьютере, подключённой к Network, здесь находятся ваш Fleet, имя пользователя, друзья и вход. У каждого пункта есть ссылка на соответствующий раздел аккаунта, где нужно войти. Внизу находится **Удалить аккаунт**. Если вы ещё не подключились, вверху будет **Присоединиться к Network**. Подробнее: [Тарифы и оплата](plans-and-billing.md).
- **Общие**: язык и регион, это устройство, голосовой ввод, браузер вашей Machine, ваш Fleet, экспорт и импорт, а также версия, на которой она работает. Если вкладки «Аккаунт» нет, в конце будет **Присоединиться к Network**.
- **Безопасность**: стандартный или осторожный режим. Подробнее: [Уровни безопасности](security-levels.md). Здесь также есть **Доступ службы поддержки**, пока он включён. Подробнее: [Связаться с поддержкой](get-support.md#support-access).
- **Активность**: всё, что The Machine сделала для вас, начиная с самого недавнего. Подробнее: [Активность](activity.md).
- **Уведомления**: какие уведомления и куда приходят, а также ваши рабочие часы. Подробнее: [Уведомления](notifications.md) и [Рабочие часы](work-hours.md).
- **Стиль письма**: подписи и то, как вы пишете. Подробнее: [Стиль письма](writing.md).
- **Навыки**: инструкции, которым следует ваша Machine. Подробнее: [Навыки](skills.md).
- **Приложения**: сначала приложения The Machine для телефона и компьютера, затем Claude, ChatGPT и другие подключённые вами ИИ, а также разрешённые для каждого действия. Подробнее: [Мобильное приложение](mobile-app.md) и [Подключение других ИИ](ai-connections.md).
- **Модель**: ИИ, который читает и составляет тексты для вас, а также его ограничения. Подробнее: [Модель](model.md). Здесь также есть **Codex и Claude Code**. Подробнее: [Передать задачу в Claude Code или Codex](hand-to-agent.md). И **Поиск по смыслу** ниже.

Вкладка без содержимого скрыта.

## Общие

- **Язык и регион**: выбранный **Регион** определяет формат дат, времени и чисел (24 окт. или окт. 24). **Формат времени** позволяет выбрать 12-часовой (2:05 PM) или 24-часовой формат (14:05). Задачи, сообщения в Telegram, дайджест и сообщения Fleet учитывают оба параметра. При регистрации облачная версия Machine использует выбранный вами часовой пояс.
- **Язык**: English, Nederlands, Français, Deutsch, Español, Italiano, Português (Brasil), 简体中文, 日本語, 한국어 или Русский. По умолчанию используется язык браузера. Интерфейс, справка, уведомления, Telegram, еженедельный обзор и задачи, которые создаёт ваша Machine, переключаются на выбранный язык сразу. Старый текст остаётся без изменений. Участники команды получают вопросы Fleet и Семьи на своём языке, а черновики для других людей остаются на языке переписки.
- **Это устройство**: **Установить приложение**, **Уведомления** с пунктом **Отправить тестовое сообщение** и **Светлая тема**. Эти настройки действуют только для этого браузера или телефона. Подробнее: [Установить приложение и включить уведомления](phone-app.md). На [Omarchy](omarchy.md) также доступна **Тема Omarchy**.
- **Голосовой ввод**: как ваша речь преобразуется в текст и какой голос используется в режиме «Разговор в реальном времени». Подробнее: [Голосовой ввод](voice-input.md) и [Разговор в реальном времени](talk-live.md).
- **Открыть браузер Machine ↗**: браузер, который ваша Machine использует для сайтов, например LinkedIn.
- **Правила Fleet**: см. [Правила общего доступа](sharing-rules.md).
- **Экспортировать**:
  - **Всё**: всё, что знает ваша Machine, в одном зашифрованном файле. Его можно перенести или сохранить. Пункт **Импортировать** позволяет загрузить такой файл. Подробнее: [Перенос на другой компьютер](moving.md).
  - **Знания для другого ИИ**: сведения, которые собрала ваша Machine, в файлах, доступных для чтения любому ИИ. Подробнее: [Знания для другого ИИ](knowledge-export.md).

## Версия

Версия, на которой работает ваша Machine. Обновления устанавливаются автоматически. Когда для облачной версии Machine будет готова новая версия, пункт **Обновить** установит её сразу. Это займёт несколько минут, ваши данные сохранятся.

На собственном компьютере новые подписанные версии устанавливаются в Linux ежедневно по таймеру. Подробнее: [Запустите The Machine на своём компьютере](self-hosted-setup.md).

## Поиск по смыслу

В **Настройки** выберите **Модель**. Эта функция находит письма, сообщения и заметки по их смыслу, а не только по словам. В облачной версии Machine поиск выполняет небольшая модель ИИ прямо на устройстве, и данные никуда не отправляются. При объёме памяти от 8 ГБ он включён. На устройстве с 4 ГБ памяти включите его переключателем. Поиск использует около половины гигабайта памяти, поэтому при высокой нагрузке Machine может работать медленнее. Если поиск выключен, при подготовке задачи всё равно ищутся связанные сообщения, но только по словам.

На собственном компьютере эта функция задаётся блоком `embeddings` в `config.json`. После изменения перезапустите Machine.

## На этой Machine

Когда ваша Machine работает на собственном компьютере, некоторые действия выполняются там, в терминале:

- Файл настроек `config.json`: все настройки собраны в одном месте. После изменения перезапустите Machine.
- `assistant connect`: добавление источника, например `assistant connect gmail` или `assistant connect outlook`.
- `assistant telegram on` или `off`: сообщения в Telegram. Подробнее: [Telegram](telegram.md).
- `assistant doctor`: проверяет всё и выводит способ исправить каждую проблему.

## Ваши адреса

Все ваши адреса, которые нашла Machine: аккаунты, псевдонимы Gmail или Outlook, календарь, профили Slack и Intercom. Письма и встречи с любого из них считаются вашими. Нажмите **Удалить**, если адрес вам не принадлежит.

Общий адрес, например info@ или адрес Google Group, никогда не считается вашим автоматически. Адрес, в отношении которого Machine не уверена, появится в разделе **Возможно, ваше**. Выберите один из вариантов:

- **Моё: отвечаю только я**: адрес считается вашим. Письма на него могут стать вашими задачами.
- **Командный: отвечают и другие**: адрес не считается вашим. Письма, отправленные только на него, не создают для вас задач и черновиков. При этом они учитываются в Graph.
- **Не моё**: адрес не будет считаться вашим.

Выбирайте вариант в зависимости от того, кто отвечает на письма сейчас. Общий адрес команды, например support@, принадлежит команде. Адрес вроде partnerships@, на который отвечаете только вы, считается вашим. Измените настройку, если на него начнут отвечать и другие.

Нажмите **Изменить** в строке адреса, чтобы поменять настройку позже. Ваш адрес для входа всегда считается вашим.

### Домены вашей компании

Домены ваших собственных адресов считаются доменами компании. Если вы также используете другой домен, например acme.co наряду с acme.com, введите его в поле **Домены вашей компании** и нажмите **Добавить**.

Люди с этих доменов будут считаться коллегами, а не клиентами: их переписки не попадут в Graph команды, и отдельная организация для домена не будет создана. Нажмите **Удалить**, чтобы убрать домен. Бесплатные почтовые домены, например gmail.com, добавить нельзя.

Псевдоним Gmail также может быть адресом в поле **От** черновика, если Gmail подтвердит, что вы можете отправлять с него письма. Подробнее: [Gmail](gmail.md#what-it-can-send).
