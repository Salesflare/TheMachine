Откройте **Настройки** с помощью значка шестерёнки вверху. Вкладки:

- **Аккаунт**: вверху находятся **Ваши адреса** (адреса, которые считаются вашими) и **Выйти**. Если The Machine размещена на сервере, здесь также доступны подписка, счета, Fleet, друзья, вход и данные. В самом низу находятся **Отменить подписку** и **Удалить аккаунт**. Если The Machine установлена на вашем компьютере и подключена к Network, здесь доступны Fleet, имя пользователя, друзья и вход. У каждого пункта есть ссылка на соответствующий раздел аккаунта, где нужно войти. Внизу находится **Удалить аккаунт**. Если The Machine ещё не подключена, вверху будет **Присоединиться к Network**. Подробнее: [Тарифы и оплата](plans-and-billing.md).
- **Общие**: язык и регион, это устройство, голосовой ввод, браузер The Machine, Fleet, экспорт и импорт, а также версия The Machine. Если вкладки «Аккаунт» нет, в конце будет **Присоединиться к Network**.
- **Безопасность**: стандартный или осторожный режим. Подробнее: [Уровни безопасности](security-levels.md). Здесь также находится **Доступ службы поддержки**, пока он включён. Подробнее: [Получить помощь](get-support.md#support-access).
- **Активность**: всё, что The Machine сделала для вас, начиная с самого нового. Подробнее: [Активность](activity.md).
- **Уведомления**: куда и какие уведомления приходят, а также ваше рабочее время. Подробнее: [Уведомления](notifications.md) и [Рабочее время](work-hours.md).
- **Пишет**: подписи и ваш стиль письма. Подробнее: [Стиль письма](writing.md).
- **Навыки**: инструкции, которым следует ваша The Machine. Подробнее: [Навыки](skills.md).
- **Приложения**: приложения The Machine для телефона и компьютера, затем подключённые вами Claude, ChatGPT и другие ИИ, а также доступные им действия. Подробнее: [Мобильное приложение](mobile-app.md) и [Подключить другие ИИ](ai-connections.md).
- **Модель**: ИИ, который читает и составляет черновики для вас, и его ограничения. Подробнее: [Модель](model.md). Здесь также есть **Codex и Claude Code**. Подробнее: [Передать задачу Claude Code или Codex](hand-to-agent.md). Ниже находится **Поиск по смыслу**.

Вкладки без содержимого скрыты.

## Общие

- **Язык и регион**: настройка **Регион** определяет формат дат, времени и чисел (Oct 24 или 24 Oct). В **Формат времени** можно выбрать 12-часовой (2:05 PM) или 24-часовой (14:05) формат. Задачи, Telegram, дайджест и сообщения Fleet используют оба параметра. Для размещённой на сервере The Machine используется часовой пояс, выбранный при регистрации.
- **Язык**: English, Nederlands, Français, Deutsch, Español, Italiano, Português (Brasil), 简体中文, 日本語, 한국어 или Русский. По умолчанию используется язык браузера. Панель управления, справка, уведомления, Telegram, еженедельная сводка и задачи, которые пишет The Machine, переключаются на выбранный язык. Старый текст остаётся без изменений. Коллеги получают вопросы Fleet и Family на своём языке, а черновики для других людей остаются на языке переписки.
- **Это устройство**: **Установить приложение**, **Уведомления** с кнопкой **Отправить тестовое сообщение** и **Светлая тема**. Настройки действуют только в этом браузере или на этом телефоне. Подробнее: [Установить приложение и включить уведомления](phone-app.md). На [Omarchy](omarchy.md) также доступна **Тема Omarchy**.
- **Голосовой ввод**: как ваши слова превращаются в текст и какой голос используется в режиме Talk live. Подробнее: [Голосовой ввод](voice-input.md) и [Talk live](talk-live.md).
- **Открыть браузер The Machine ↗**: браузер, который The Machine использует для сайтов вроде LinkedIn.
- **Правила Fleet**: см. [Правила совместного доступа](sharing-rules.md).
- **Экспортировать**:
  - **Всё**: все данные, которые знает The Machine, в одном зашифрованном файле. Сохраните его или перенесите, а затем воспользуйтесь кнопкой **Импортировать**, чтобы загрузить файл. Подробнее: [Перенести на другой компьютер](moving.md).
  - **Знания для другого ИИ**: знания The Machine в файлах, которые может прочитать любой ИИ. Подробнее: [Знания для другого ИИ](knowledge-export.md).

## Версия

Версия The Machine, которая у вас запущена. Обновления устанавливаются автоматически. Когда для размещённой на сервере The Machine будет доступна новая версия, нажмите **Обновить**, чтобы установить её сразу. Это займёт несколько минут, ваши данные сохранятся.

На собственном компьютере ежедневный таймер устанавливает каждый новый подписанный выпуск Linux. Подробнее: [Запустить на собственном компьютере](self-hosted-setup.md).

## Поиск по смыслу

В **Настройки** → **Модель**. Поиск находит письма, сообщения и заметки по смыслу, а не только по словам. На размещённой на сервере The Machine поиск выполняет небольшая модель ИИ на самой The Machine. Данные никуда не отправляются. При объёме памяти от 8 GB функция включена. При 4 GB включите её переключателем. Поиск занимает около половины гигабайта памяти, поэтому при высокой нагрузке The Machine может работать медленнее.

На собственном компьютере за поиск отвечает блок `embeddings` в `config.json`. После изменения перезапустите The Machine.

## На этой The Machine

Если The Machine работает на вашем компьютере, несколько действий нужно выполнять там, в терминале:

- Файл настроек `config.json`: все настройки собраны в одном месте. После изменения перезапустите The Machine.
- `assistant connect`: добавляет источник, например `assistant connect gmail` или `assistant connect outlook`.
- `assistant telegram on` или `off`: сообщения в Telegram. Подробнее: [Telegram](telegram.md).
- `assistant doctor`: проверяет всё и выводит исправление для каждой проблемы.

## Ваши адреса

Здесь показаны все найденные The Machine ваши адреса: аккаунты, псевдонимы Gmail или Outlook, календарь, профили Slack и Intercom. Письма и встречи с любого из этих адресов считаются вашими. Нажмите **Удалить**, если адрес не ваш.

Общий адрес, например info@ или адрес группы Google, сам по себе никогда не считается вашим. Если The Machine не уверена насчёт адреса, он появится в разделе **Возможно, ваше**. Выберите один из вариантов:

- **Моё: отвечаю только я**: адрес считается вашим. Письма на него могут становиться вашими задачами.
- **Команде: другие тоже отвечают**: адрес не считается вашим. Письма, отправленные только на него, не создают для вас задачи и черновики. Они по-прежнему учитываются в Graph.
- **Не моё**: адрес не будет считаться вашим.

Выбирайте вариант, исходя из того, кто отвечает на письма сейчас. Общий ящик команды, например support@, принадлежит команде. Адрес вроде partnerships@, на который отвечаете только вы, считается вашим. Измените выбор, когда на него начнут отвечать другие.

Нажмите **Изменить** в строке адреса, чтобы сменить вариант позже. Ваш адрес для входа всегда считается вашим.

### Домены вашей компании

Домены ваших адресов считаются доменами компании. Если вы используете и другой домен, например acme.co наряду с acme.com, введите его в поле **Домены вашей компании** и нажмите **Добавить**.

Тогда люди с этих доменов будут считаться коллегами, а не клиентами: их переписки не попадут в Graph команды, и для них не будет создана организация. Нажмите **Удалить**, чтобы убрать домен. Бесплатные почтовые домены, например gmail.com, добавить нельзя.

Псевдоним Gmail также можно указать в поле **От** черновика, если Gmail подтвердил, что вы можете отправлять с него письма. Подробнее: [Gmail](gmail.md#what-it-can-send).
