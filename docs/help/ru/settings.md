Откройте **Настройки**, нажав на шестерёнку вверху. Вкладки:

- **Аккаунт**: вверху находятся **Ваши адреса** (адреса, которые считаются вашими) и **Выйти**. Если Machine размещена в облаке, здесь также доступны тариф, счета, Fleet, друзья, вход и данные, а в самом низу **Отменить подписку** и **Удалить аккаунт**. Если Machine работает на вашем компьютере и подключена к Network, здесь доступны Fleet, имя пользователя, друзья и вход. Рядом с каждым пунктом есть ссылка на соответствующую часть аккаунта, где можно войти. Внизу находится **Удалить аккаунт**. Если подключение ещё не настроено, вверху будет **Присоединиться к Network**. Подробнее: [Тарифы и оплата](plans-and-billing.md).
- **Общие**: язык и регион, это устройство, голосовой ввод, браузер Machine, Fleet, экспорт и импорт, а также версия Machine.
- **Безопасность**: «Стандартный» или «Осторожный». Подробнее: [Уровни безопасности](security-levels.md). Пока включён **Доступ службы поддержки**, он тоже отображается здесь. Подробнее: [Связаться с поддержкой](get-support.md#support-access).
- **Активность**: всё, что The Machine сделала для вас, от новых событий к старым. Подробнее: [Активность](activity.md).
- **Уведомления**: какие уведомления и куда приходят, а также ваши рабочие часы. Подробнее: [Уведомления](notifications.md) и [Рабочие часы](work-hours.md).
- **Стиль письма**: подписи и ваш стиль письма. Подробнее: [Стиль письма](writing.md).
- **Навыки**: инструкции, которым следует ваша Machine. Подробнее: [Навыки](skills.md).
- **Приложения**: приложения The Machine для телефона и компьютера, затем подключённые Claude, ChatGPT и другие ИИ, а также действия, которые им разрешены. На компьютере здесь перечислены приложения для Windows, Mac и Linux. Рядом с каждым есть кнопка **Скачать**, а приложение для **Этот компьютер** отмечено отдельно. Подробнее: [Мобильное приложение](mobile-app.md), [Настольное приложение](desktop-app.md) и [Подключить другие ИИ](ai-connections.md).
- **Модель**: ИИ, который читает и составляет тексты для вас, и его ограничения. Подробнее: [Модель](model.md). Здесь же находится **Codex и Claude Code**. Подробнее: [Передать задачу в Claude Code или Codex](hand-to-agent.md). Ниже доступен **Поиск по смыслу**.

Вкладки, в которых нечего показать, скрыты.

## Общие

- **Язык и регион**: параметр **Регион** задаёт формат дат, времени и чисел, например 24 окт. или 24 окт. **Формат времени** задаёт 12-часовой (2:05 PM) или 24-часовой (14:05) формат. На оба параметра ориентируются задачи, Telegram, дайджест и сообщения Fleet. Для размещённой в облаке Machine начальным часовым поясом служит выбранный при регистрации.
- **Язык**: English, Nederlands, Français, Deutsch, Español, Italiano, Português (Brasil), 简体中文, 日本語, 한국어 или Русский. По умолчанию используется язык браузера. Интерфейс, раздел «Помощь», уведомления, Telegram, еженедельный отчёт и задачи, которые пишет ваша Machine, переключатся на выбранный язык. Старые тексты останутся без изменений. Коллеги получают вопросы Fleet и Family на своём языке, а черновики для других людей остаются на языке переписки.
- **Это устройство**: **Установить приложение**, **Уведомления** с кнопкой **Отправить тестовое сообщение** и **Светлая тема**. Настройки относятся только к этому браузеру или телефону. Подробнее: [Установите приложение и включите уведомления](phone-app.md). В [Omarchy](omarchy.md) также доступна **Тема Omarchy**.
- **Голосовой ввод**: как сказанное вами превращается в текст и какой голос используется в режиме Talk live. Подробнее: [Голосовой ввод](voice-input.md) и [Разговор в реальном времени](talk-live.md).
- **Открыть браузер Machine ↗**: браузер, который ваша Machine использует для сайтов, например LinkedIn.
- **Правила Fleet**: Подробнее: [Правила общего доступа](sharing-rules.md).
- **Экспортировать**:
  - **Всё**: все знания вашей Machine в одном зашифрованном файле, чтобы перенести их или сохранить. Кнопка **Импортировать** позволяет загрузить такой файл. Подробнее: [Перенос на другой компьютер](moving.md).
  - **Знания для другого ИИ**: знания, которые ваша Machine собрала в файлах, доступных для чтения любому ИИ. Подробнее: [Знания для другого ИИ](knowledge-export.md).

## Версия

Версия, на которой работает ваша Machine. Обновления устанавливаются автоматически. Когда для размещённой в облаке Machine доступна новая версия, нажмите **Обновить**, чтобы установить её сразу. Это займёт несколько минут, ваши данные сохранятся.

На собственном компьютере новые подписанные версии Linux устанавливаются по ежедневному расписанию. Подробнее: [Запустите The Machine на своём компьютере](self-hosted-setup.md).

## Поиск по смыслу

В разделе **Настройки** откройте **Модель**. Поиск находит письма, сообщения и заметки по смыслу, а не только по словам. На размещённой в облаке Machine поиск выполняет небольшая модель ИИ прямо на самой Machine, данные никуда не отправляются. При объёме памяти от 8 ГБ эта функция включена. На устройстве с 4 ГБ её можно включить переключателем. Она использует около половины гигабайта памяти, поэтому при высокой нагрузке Machine может работать медленнее. Если функция выключена, при подготовке задачи всё равно ищутся связанные сообщения по словам.

На собственном компьютере эта функция задаётся блоком `embeddings` в `config.json`. После изменения перезапустите Machine.

## На этой Machine

Если Machine работает на вашем компьютере, некоторые действия выполняются там, в терминале:

- Файл настроек, `config.json`: все настройки собраны в одном месте. После изменения перезапустите Machine.
- `assistant connect`: добавление источника, например `assistant connect gmail` или `assistant connect outlook`.
- `assistant telegram on` или `off`: сообщения в Telegram. Подробнее: [Telegram](telegram.md).
- `assistant doctor`: проверка всех параметров и вывод решения для каждой проблемы.

## Ваши адреса

Здесь перечислены все найденные Machine ваши адреса: аккаунты, псевдонимы Gmail или Outlook, календарь, профили Slack и Intercom. Письма и встречи с любого из них считаются вашими. Нажмите **Удалить**, если адрес вам не принадлежит.

Общий адрес, например info@ или Google Group, сам по себе никогда не считается вашим. Если Machine не уверена насчёт адреса, он появится в разделе **Возможно, ваше**. Выберите один из вариантов:

- **Моё: отвечаю только я**: адрес считается вашим. Письма на него могут становиться вашими задачами.
- **Командный: отвечают и другие**: адрес не считается вашим. Письма, отправленные только на него, не создают для вас задачи или черновики. При этом они учитываются в Graph.
- **Не моё**: адрес не будет считаться вашим.

Выбирайте вариант по тому, кто отвечает с этого адреса сейчас. Общий ящик команды, например support@, принадлежит команде. Адрес вроде partnerships@, на который отвечаете только вы, принадлежит вам. Если на него начнут отвечать другие, измените выбор.

Позже выбор можно изменить с помощью кнопки **Изменить** в строке адреса. Адрес, который используется для входа в ваш аккаунт, всегда считается вашим.

### Домены вашей компании

Домены ваших адресов считаются доменами компании. Если вы также используете другой домен, например acme.co вместе с acme.com, введите его в поле **Домены вашей компании** и нажмите **Добавить**.

Люди с этих доменов будут считаться коллегами, а не клиентами: их переписки не попадут в Graph команды, и для них не будет создана организация. Нажмите **Удалить**, чтобы убрать домен. Бесплатные почтовые домены, например gmail.com, добавить нельзя.

Псевдоним Gmail можно также указать в поле **От** черновика, если Gmail подтверждает, что вы можете отправлять письма с этого адреса. Подробнее: [Gmail](gmail.md#what-it-can-send).
