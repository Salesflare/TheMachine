## Настройте правила

Решите, что ваша Machine будет сообщать в Fleet. Откройте вкладку **Fleet**, затем выберите **Общий доступ**. Для каждого типа вопросов есть своё правило:

- **Сначала спросить меня**: вы видите каждый вопрос и решаете, что делать.
- **Всегда**: ваша Machine отвечает сама.
- **Никогда**: ваша Machine отказывает.
- **Имена**: решите, может ли ответ указывать, о ком идёт речь, например называть гостя, или должен обходиться без имён.

Содержимое писем и темы ваших встреч никогда не передаются. Настройте правило для одного человека с помощью пункта **Для кого-то иначе? Добавьте исключение**.

Менять правила можно только в панели управления, а не через сообщение.

## В рабочем Fleet

В стандартном рабочем Fleet для правил о том, кто с кем знаком, о контексте встреч и о том, кто отвечает за общие письма, доступны только варианты **Всегда** и **Никогда**. При выборе **Всегда** ваша Machine отвечает только тем, чем уже делится с командой [командный Graph](team-graph.md), и называет только тех, чьи имена доступны команде. Правило, сохранённое как **Сначала спросить меня**, работает как **Всегда**.

Пока командный Graph не делится данными, для правил о том, кто с кем знаком, и о контексте встреч также доступен вариант **Сначала спросить меня**. Он доступен и в Fleet с уровнем «Осторожно». Подробнее: [Fleet](fleet.md#answered-by-itself-in-a-work-fleet).

## Когда кто-то спрашивает впервые

Если для ответа нужно ваше решение, вы получите задачу с вариантами **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда не делиться**.
