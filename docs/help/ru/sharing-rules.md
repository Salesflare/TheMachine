## Настроить правила

Решите, что ваша Machine рассказывает вашему Fleet. Откройте вкладку **Fleet** и выберите **Общий доступ**. Для каждого типа вопросов действует своё правило:

- **Сначала спросить меня**: вы видите каждый вопрос и решаете, что делать.
- **Всегда**: ваша Machine отвечает сама.
- **Никогда**: ваша Machine отказывает.
- **Имена**: можно ли называть людей в ответе, например имя гостя, или нужно опускать имена.

Ваша Machine не пересылает целые письма и не рассказывает, о чём ваши встречи. В вашей семье для **Вопросы** (например, «Есть новости про ковёр?») доступны варианты «Сначала спросить меня» и «Никогда». Вариант **Всегда** можно настроить только для одного человека: см. [Семья](family.md#always-for-one-person). Пункт **Для кого-то иначе? Добавьте исключение** задаёт правило для одного человека.

Менять правила можно только на панели управления, не в сообщениях.

## В рабочем Fleet

В стандартном рабочем Fleet для вопросов о том, кто кого знает, о контексте встреч и о том, кто обрабатывает общие письма доступны только варианты **Всегда** и **Никогда**. При варианте **Всегда** ваша Machine отвечает только тем, чем уже делится с командой [Graph команды](team-graph.md), и называет только тех, чьими именами делится. Сохранённое правило **Сначала спросить меня** работает как **Всегда**.

Пока Graph команды не делится информацией, для вопросов о том, кто кого знает, и о контексте встреч также доступен вариант **Сначала спросить меня**. Он доступен и в осторожном Fleet. Подробнее: [Fleet](fleet.md#answered-by-itself-in-a-work-fleet).

## Когда кто-то спрашивает впервые

Если для ответа нужно ваше решение, вопрос появится как задача с вариантами **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда не делиться**.
