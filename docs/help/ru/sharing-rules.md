## Настройте правила

Решите, чем ваша Machine делится с Fleet. На вкладке **Fleet** откройте **Общий доступ**. Для каждого типа вопроса можно задать правило:

- **Сначала спросить меня**: вы видите каждый вопрос и решаете, что делать.
- **Всегда**: ваша Machine отвечает сама.
- **Никогда**: она отказывает.
- **Имена**: можно ли называть людей в ответе, например имя гостя, или имена нужно опускать.

Она никогда не делится содержимым писем и темами ваших встреч. С помощью настройки **Для кого-то иначе? Добавьте исключение** можно задать правило для одного человека.

Правила можно менять только в панели управления, но не в сообщении.

## В рабочем Fleet

В Fleet для стандартной работы для правил «кто с кем знаком», контекста встреч и того, кто отвечает за общие письма, доступны только варианты **Всегда** и **Никогда**. При выборе **Всегда** ваша Machine отвечает только на основе данных, которыми [Graph команды](team-graph.md) уже делится с командой, и называет только тех людей, чьи имена он показывает. Сохранённое правило **Сначала спросить меня** действует как **Всегда**.

Пока Graph команды не делится данными, для правил «кто с кем знаком» и контекста встреч также доступен вариант **Сначала спросить меня**. Он доступен и в Fleet с осторожным режимом. Подробнее: [Fleet](fleet.md#answered-by-itself-in-a-work-fleet).

## Когда кто-то спрашивает впервые

Вопрос, для ответа на который нужно ваше решение, появится как задача с вариантами **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда не делиться**.
