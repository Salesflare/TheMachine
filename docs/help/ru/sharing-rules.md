## Настройка правил

Решите, что ваша Machine будет сообщать в Fleet. Откройте вкладку **Fleet** и выберите **Общий доступ**. Для каждого типа вопросов можно задать правило:

- **Сначала спросить меня**: вы видите каждый вопрос и принимаете решение.
- **Всегда**: ваша Machine отвечает сама.
- **Никогда**: ваша Machine отказывает.
- **Имена**: можно ли указывать, кто это, например имя гостя, или нужно опускать имена.

Ваша Machine никогда не пересылает целые письма и не рассказывает, о чём ваши встречи. В семейном Fleet для **Вопросы** (например, «Есть новости про ковёр?») можно выбрать только «Сначала спросить меня» или «Никогда». Подробнее: [Семья](family.md). Параметр **Для кого-то иначе? Добавьте исключение** позволяет задать правило для одного человека.

Правила можно изменить только на панели управления, но не в сообщении.

## В рабочем Fleet

В стандартном рабочем Fleet для вопросов о том, кто с кем знаком, контексте встреч и ответственных за общие письма доступны только варианты **Всегда** и **Никогда**. При выборе **Всегда** ваша Machine отвечает, используя только сведения, которыми [Graph команды](team-graph.md) уже делится с вашей командой, и называет только тех людей, сведения о которых доступны команде. Если сохранить правило **Сначала спросить меня**, оно будет работать как **Всегда**.

Пока Graph команды не делится сведениями, для вопросов о том, кто с кем знаком, и контексте встреч также доступен вариант **Сначала спросить меня**. Он доступен и в Fleet с осторожным режимом. Подробнее: [Fleet](fleet.md#answered-by-itself-in-a-work-fleet).

## Когда кто-то спрашивает впервые

Если для ответа нужно ваше решение, вы получите задачу с вариантами **Поделиться один раз**, **Всегда делиться**, **Отклонить** или **Никогда не делиться**.
