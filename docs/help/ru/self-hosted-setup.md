Запустите The Machine на своём компьютере бесплатно. Это приложение с открытым исходным кодом (AGPL), а ваши данные остаются у вас. Для установки понадобится терминал. Для подключения аккаунтов он не нужен.

## Что понадобится

- OpenClaw 2026.11.2 или новее, агент с открытым исходным кодом, на котором работает The Machine. Установщик предложит установить его.
- Python 3.12 или новее и Node.js 24 (24.22.1 или новее) либо 26.12.1 или новее, но не 25.
- Tailscale, чтобы открывать панель управления с телефона.
- Обычная учётная запись пользователя, не root.

## Установка

На Linux или macOS (macOS пока в бета-версии):

1. `git clone https://github.com/Salesflare/TheMachine.git ~/.openclaw/workspace/tools/personal-assistant`
2. `cd ~/.openclaw/workspace/tools/personal-assistant && ./install.sh`

На Windows (бета-версия) приложение работает в WSL2. В PowerShell выполните `irm https://raw.githubusercontent.com/Salesflare/TheMachine/main/install.ps1 | iex`. Команда настроит WSL2 с Ubuntu и всем необходимым для приложения, а затем запустит `./install.sh`.

Установщик найдёт ваши аккаунты, подключит их по одному и покажет предварительный просмотр за прошлую неделю, прежде чем что-либо включится.

## После установки

- Подключите почту: в верхней части **Задачи** нажмите **Gmail** (или **Outlook**), затем **Связать эту Machine**, чтобы связать её со своей учётной записью. Если у вас нет аккаунта, чуть ниже находится кнопка **Использовать своё приложение**.
- Затем нажмите **Войти с помощью Google** (или **Войти с помощью Microsoft** для Outlook). Почта и календарь подключатся вместе.
- Другие источники: откройте **Подключения**, затем выберите тип источника. Чтобы использовать собственный клиент Google или приложение Entra, выполните в терминале команду `assistant connect`.
- Проверьте всё с помощью `assistant doctor`. Она покажет, как исправить каждую проблему.
- Устанавливается последняя подписанная версия. Обновления тоже выходят в виде подписанных версий.
- Свяжите The Machine со своей учётной записью, и после входа мобильное приложение откроет её. Отвязка удалит эту связь.

Полное руководство доступно в репозитории: [Начало работы](https://github.com/Salesflare/TheMachine/blob/main/docs/getting-started.md).
