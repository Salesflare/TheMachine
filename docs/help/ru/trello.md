## Что она читает

Изменения карточек, комментарии и активность на одной доске Trello для каждого подключения. Она не отмечает доску как просмотренную.

## Что она умеет

Ничего в Trello. Она только читает.

## Подключение

1. В панели управления: **Подключения**, **Проекты и код**, Trello. Или на странице настройки размещённой Machine по адресу app.themachine.computer/setup: **Другие источники**, Trello. Сначала подключите Machine к своей учётной записи на собственном компьютере.
2. Нажмите **Войти через Trello** и разрешите доступ только для чтения. Trello показывает, что приложение создано Salesflare.
3. Выберите доску и нажмите **Подключить**. Чтобы подключить другую доску, добавьте Trello ещё раз.

## Отключение

- В панели управления: **Подключения**, откройте доску, выберите **Сведения**, затем **Отключить**. Уже добавленные данные останутся.
- На размещённой Machine также можно нажать **Удалить** рядом с Trello на странице настройки.

## Отзыв доступа в Trello

Отзовите доступ The Machine в настройках учётной записи Trello, в разделе «Приложения».
