Всё, чему учится ваша The Machine, принадлежит вам: сообщения, задачи, черновики, Graph, воспоминания и навыки. Перенесите всё в другую The Machine или сохраните копию.

## Экспорт

На своём компьютере:

1. Откройте **Настройки** › **Общие** › **Экспортировать** и нажмите **Экспортировать** рядом с пунктом «Всё».
2. При желании задайте парольную фразу. Если её не задать, вы получите код экспорта. Запишите его, он понадобится для импорта.
3. При желании включите **Включить ключи и токены** (для этого нужна парольная фраза), чтобы не подключать источники заново.
4. Нажмите **Начать экспорт**, затем **Скачать**. Файл будет удалён через 24 часа. Чтобы удалить его сразу, нажмите **Удалить**.

В облачной версии The Machine кнопка **Экспортировать** рядом с пунктом «Всё» открывает страницу аккаунта. Нажмите **Экспортировать всё**, затем **Скачать**. The Machine удалит файл через 24 часа или сразу, если нажать **Удалить сейчас**.

Файл всегда зашифрован. После этого в разделе Настройки будет указано, что вошло в файл, а что нет. В аккаунты Google и Microsoft, подключённые через нашу облачную авторизацию, на другом компьютере нужно будет войти снова.

## Импорт

1. Откройте **Настройки** › **Общие** › **Экспортировать**, нажмите **Выберите файл** рядом с пунктом «Импорт» и выберите файл экспорта.
2. Введите парольную фразу или код экспорта и нажмите **Открыть**. Сначала The Machine проверит весь файл.
3. В облачной версии нажмите **Импортировать сейчас**. На своём компьютере нажмите **Заменить этим экспортом**, затем **Заменить**. Через несколько минут The Machine перезапустится с этим экспортом, а в Настройках появится статус **Импортировано**.

Импорт заменит данные на этой The Machine, предварительно сохранив их копию. Ничего не отправится автоматически: отправки из очереди будут ждать вас.

Если раздел Настройки не сможет перезапустить The Machine на вашем компьютере, он покажет команды, которые нужно выполнить.

На новом компьютере сначала [установите The Machine](self-hosted-setup.md). Затем отмените подписку на облачную версию, если она вам больше не нужна: см. [Отмена или удаление](cancel-and-delete.md).
