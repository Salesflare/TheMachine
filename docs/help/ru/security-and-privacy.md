## Кратко

- Ваша Machine: размещённая в облаке работает в дата-центре в ЕС только для вас и никогда не используется совместно с кем-то ещё. Или запустите её на своём компьютере.
- Мы не читаем вашу почту: сообщения хранятся в зашифрованном виде, и наши инструменты поддержки не могут их открыть.
- Ничего не отправляется без вашего согласия: Machine читает и создаёт черновики, а вы решаете, что отправлять. См. [Выполнить](do-it.md).
- Данные не используются для обучения ИИ: у нас нет собственного ИИ. Ваш провайдер ИИ работает через вашу учётную запись и на своих условиях.
- Выводы для команды, если вы их не отключили: время от времени несколько общих советов, без личной информации, которые проверяются перед отправкой. См. [Делиться выводами](share-learnings.md).
- Отчёты об ошибках, если вы их не отключили: при сбое отправляются тип ошибки и место в коде. Ваши сообщения, имена и адреса не отправляются. См. [Отчёты об ошибках](error-reports.md).
- Статистика использования размещённой Machine: ежедневное количество действий (например, открытых задач или отправленных писем), без их содержимого.
- Заберите свои данные или удалите их: экспортируйте всё в разделе **Настройки** › **Общие** или удалите Machine и её резервные копии одной кнопкой. См. [Отмена подписки или удаление](cancel-and-delete.md).
- Наш доступ регистрируется: каждый раз, когда наша команда просматривает отчёт или журналы размещённой Machine. Владельцы и администраторы Fleet видят эту информацию в разделе **Активность**. См. [Fleet](fleet.md).

## Уровни безопасности

**Стандарт** сохраняет текущие настройки по умолчанию. В режиме **Осторожно** в уведомлениях не отображается текст, данные для входа не сохраняются, и хранится меньше информации. Администратор рабочего Fleet может включить для Fleet режим **Осторожно**. См. [Уровни безопасности](security-levels.md).

## Вход

Для входа в панель управления размещённой Machine нужен ключ доступа или вход через Google либо Microsoft с кодом из приложения-аутентификатора.

## Подключения

В статье о каждом подключении указано, какие данные оно читает и что может отправлять. Отключить любое подключение можно в любой момент: см. [Подключения](connections.md).

## Справка

Справка работает на вашей Machine и не видит ваши данные. Команде The Machine отправляется только тема каждого вопроса, но не его текст. См. [Задать вопрос в справке](help-chat.md#what-the-team-sees).
