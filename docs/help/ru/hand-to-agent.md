## Передать задачу

1. Откройте в задаче **…**, затем **Передать…** и выберите **Codex** или **Claude Code**. Здесь отображаются только настроенные инструменты.
2. Проверьте краткое описание и доступные данные, при желании добавьте заметку и нажмите **Передать**. Кнопка **Посмотреть задание целиком** открывает полное описание.

В задаче отобразится статус **В работе…**, а затем результат с разделами **Что сделал агент** и **Показать изменения**. Кнопка **Попросить изменить** отправит агенту запрос на изменения. Пункт **Передать…** в меню **…** позволит начать заново. Нажмите **Скрыть**, чтобы убрать результат. Если передать зависшую задачу, на время выполнения задания вместо статуса **Застряла** будет отображаться **В работе…**.

Задание никогда ничего не отправляет от вашего имени. Если оно доходит до шага публикации или развёртывания, нажмите **Выполнить** в задаче, чтобы запустить этот шаг. Написанный ответ останется черновиком, который вы отправите сами.

## В приложении Codex

- **Открыть в Codex** открывает переписку с заданием в приложении Codex после его выполнения.
- **Попросить изменить** продолжает ту же беседу в Codex, и задача обновляется вслед за ней.
- Задание останавливается, если в течение 30 минут нет прогресса, или по истечении 6 часов. Перезапуск не останавливает его.

## Настроить

В разделе **Настройки**, пункт **Модель**, подраздел **Codex и Claude Code**:

- **Codex**: где он запускается. На вашей Machine или компьютере здесь больше ничего настраивать не нужно. Кнопка **Изменить** открывает страницу настройки.
- **Облачный Codex**: укажите идентификатор среды из Codex и при желании **Ветка**, с которой нужно начать.
- **Claude Code**: ссылка на сеанс Claude Code.

Claude возвращает результат через коннектор The Machine. Добавьте его один раз на claude.ai: **Настройки**, **Коннекторы**, **Добавить пользовательский коннектор**, затем укажите адрес, показанный под сеансом.

## Где запускается Codex

На размещённой Machine выберите вариант на странице настройки, в разделе **Добавить в любое время**, **Codex**:

- **На вашей Machine** (по умолчанию): нажмите **Подключить Codex** и введите код, который появится на сайте OpenAI. Codex использует тот же тариф ChatGPT, что и ваша модель, а задания выполняются на вашей Machine. Терминал не нужен. Если вы вошли в тот же аккаунт ChatGPT, ваша Machine также сможет видеть, когда обновляется лимит использования, и использовать его.
- **Другие способы**, **На моём компьютере**: задание выполняется на вашем компьютере, где выполнен вход в Codex. Передача данных зашифрована, и подключение действует только для этого компьютера. Установите там The Machine, подключите её на странице аккаунта, запустите `codex login` и не выключайте The Machine. Результат появится в задаче. Если компьютер выключен, задания будут ждать.
- **Другие способы**, **Облачный Codex**: задание выполняется в облаке OpenAI. Нажмите **Подключить Codex**. Codex использует тот же тариф ChatGPT, что и ваша модель, а OpenAI запросит ещё один код для Codex. Затем укажите среду Codex cloud в настройках.

Или войдите через панель управления: **Подключения**, **Проекты и код**, **Codex**, **Получить код**. Machine на собственном хостинге выполняет тот же вход самостоятельно.

На размещённой Machine раздел **Codex и Claude Code** появится в настройках после подключения GitHub или Codex. Для разработчиков: [руководство по агентам](https://github.com/Salesflare/TheMachine/blob/main/docs/agents.md).
