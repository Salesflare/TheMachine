## Передать задачу

1. Откройте в задаче **…**, затем **Передать…** и выберите **Codex** или **Claude Code**. Появятся только настроенные вами инструменты.
2. Проверьте краткое описание и доступные данные, при желании добавьте примечание и нажмите **Передать**. Кнопка **Посмотреть полное задание** открывает полное описание.

В задаче появится статус выполнения, а затем результат с пунктами **Что сделано** и **Показать изменения**. Кнопка **Попросить изменить** отправит инструменту, что нужно изменить. Пункт **Передать…** в меню **…** запускает работу заново. Кнопка **Скрыть** убирает результат. Если передать застрявшую задачу, вместо статуса **Застряла** появится **В работе…** на время выполнения задания.

Задание никогда ничего не отправляет за вас. Если оно доходит до публикации или развёртывания, нажмите **Выполнить** в задаче, чтобы выполнить этот шаг. Написанный ответ остаётся черновиком, который вы отправляете сами.

## В приложении Codex

- Кнопка **Открыть в Codex** открывает ветку задания в приложении Codex, когда задание будет выполнено.
- Кнопка **Попросить изменить** продолжает работу в том же разговоре Codex, а задача следит за его ходом.
- Задание останавливается, если прогресс не меняется 30 минут, или по истечении 6 часов. Перезапуск его не остановит.

## Настройка

В разделе **Настройки**, **Модель**, в пункте **Codex и Claude Code**:

- **Codex**: где он запускается. Для запуска на вашей Machine или компьютере здесь больше ничего не нужно; кнопка **Изменить** открывает страницу настройки.
- **Codex в облаке**: ID среды из Codex и, при желании, **Ветка**, с которой начать.
- **Claude Code**: ссылка на сеанс Claude Code.

Claude отправляет результат через коннектор The Machine. Добавьте его один раз на claude.ai: откройте «Настройки», «Коннекторы», «Добавить пользовательский коннектор» и укажите адрес, показанный под сеансом.

## Где запускается Codex

На облачной Machine выберите способ на странице настройки, в разделе **Добавить в любое время**, **Codex**:

- **На вашей Machine** (по умолчанию): нажмите **Подключить Codex** и введите код, который появится на сайте OpenAI. Codex использует тот же тариф ChatGPT, что и ваша модель, а задания запускаются на вашей Machine. Терминал не нужен.
- **Другие способы**, **На моём компьютере**: задание запускается на вашем компьютере, где выполнен вход в Codex. Данные передаются в зашифрованном виде и только на этот компьютер. Установите The Machine на компьютере, свяжите его со своей учётной записью на странице аккаунта, запустите `codex login` и не выключайте The Machine. Результат появится в задаче. Когда компьютер выключен, задания ждут.
- **Другие способы**, **Codex в облаке**: задание запускается в облаке OpenAI. Нажмите **Подключить Codex**. Codex использует тот же тариф ChatGPT, что и ваша модель, а OpenAI запросит ещё один код для Codex. Затем укажите среду Codex в облаке в настройках.

Также можно войти в систему через панель управления: **Подключения**, **Проекты и код**, **Codex**, **Получить код**. На самостоятельно размещённой Machine вход выполняется таким же способом.

На облачной Machine раздел **Codex и Claude Code** появится в настройках после подключения GitHub или Codex. Для разработчиков: [руководство по агентам](https://github.com/Salesflare/TheMachine/blob/main/docs/agents.md).
