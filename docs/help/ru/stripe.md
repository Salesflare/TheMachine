## Что она читает

События в вашем аккаунте Stripe, которые могут требовать вашего внимания: неуспешные платежи, споры, отмены и крупные новые подписки, а также данные о соответствующих клиентах. По электронной почте клиента событие связывается с этим человеком и его организацией в [Graph](graph.md).

## Что она может делать

Ничего в Stripe. Она не возвращает деньги, не повторяет платежи и не меняет данные. Ей нужны только права на чтение, и Stripe покажет это перед установкой.

## Подключение

Войдите через Stripe, это просто:

1. В панели управления откройте **Подключения**, **Клиенты**, Stripe. Или на странице настройки размещённой Machine на app.themachine.computer/setup откройте **Другие источники**, Stripe. На собственном компьютере сначала свяжите Machine со своим аккаунтом.
2. Нажмите **Войти через Stripe**. Stripe спросит, какой аккаунт использовать, и покажет, что The Machine сможет читать.
3. Нажмите **Установить**. Вы вернётесь на прежнюю страницу, а Stripe будет подключён.

На собственном компьютере вместо этого можно вставить ключ с ограниченными правами:

1. Создайте в Stripe ключ с ограниченными правами: разрешите чтение Events, Customers и Account, а для всего остального выберите None.
2. Найдите идентификатор аккаунта (acct_...) в разделе **Настройки**, **Данные компании**.
3. Откройте Stripe, как описано выше (или выполните `assistant connect stripe`), выберите **Или вставьте ключ с ограниченными правами**, вставьте идентификатор аккаунта и ключ, затем нажмите **Подключить**.

На собственном компьютере, если вход через Stripe пока недоступен, в разделе «Подключения» появится соответствующее сообщение и сразу откроется эта форма.

## Подключение для всей команды

В рабочем Fleet владелец или администратор один раз подключает Stripe и делится им с командой:

1. Подключите Stripe на своей Machine (см. выше). В блоке **Общие подключения** на вкладке Fleet также есть кнопка **Подключить Stripe**.
2. На вкладке Fleet откройте **Поделиться Stripe**. По умолчанию отмечены все участники. Снимите отметки с тех, кому доступ не нужен, и нажмите **Поделиться**.

Теперь Machine коллег тоже смогут читать данные. В разделе «Подключения» видно, кто поделился доступом. Изменить настройки или отключить доступ могут только администраторы Fleet. Ваша Machine обновляет доступ коллег каждый час, поэтому, пока она выключена, их доступ к Stripe приостанавливается. Данные для входа никто не получает. Подробнее: [Fleet](fleet.md).

Если коллега сам подключит тот же аккаунт Stripe, данные будут считываться только один раз: общее подключение не будет использоваться.

Поделиться Stripe, подключённым через сервис, чей единый ключ открывает доступ и к другим приложениям, нельзя. Вместо этого подключите Stripe напрямую для команды.

## Отключение

- В панели управления откройте **Подключения**, выберите Stripe, нажмите **Подробности**, затем **Отключить**. Уже импортированные данные останутся.
- На размещённой Machine у Stripe, подключённого через вход, будет кнопка **Отключить ↗**. Она откроет страницу настройки: нажмите рядом с ним **Удалить**.
- Если вы поделились Stripe с Fleet, сначала нажмите **Отключить общий доступ** на вкладке Fleet.

## Отзыв доступа в Stripe

- Если вы вошли через Stripe, откройте в Stripe раздел **Настройки**, **Установленные приложения** и удалите The Machine.
- Если использовали ключ с ограниченными правами, откройте в Stripe раздел **Разработчики**, **Ключи API** и удалите ключ или замените его.
