## Что она читает

События в вашем аккаунте Stripe, на которые может потребоваться ваше внимание: неудачные платежи, споры, отмены и крупные новые подписки с указанием клиента. Адрес электронной почты клиента связывает событие с этим человеком и его организацией в [Graph](graph.md).

## Что она может делать

Ничего в Stripe. Она не возвращает деньги, не повторяет попытки платежа и ничего не меняет. Она запрашивает только доступ на чтение, и Stripe показывает это до установки.

## Подключение

Войдите через Stripe, это просто:

1. В панели управления: **Подключения**, **Клиенты**, Stripe. Или на странице настройки облачной версии The Machine на app.themachine.computer/setup: **Другие источники**, Stripe. На собственном компьютере сначала подключите её к своему аккаунту.
2. Нажмите **Войти через Stripe**. Stripe спросит, какой аккаунт использовать, и покажет, что The Machine сможет читать.
3. Нажмите **Установить**. Вы вернётесь туда, откуда начали, и Stripe будет подключён.

Или вставьте ограниченный ключ:

1. В Stripe создайте ограниченный ключ с правом «Чтение» для разделов Events, Customers и Account, а для всех остальных установите «Нет».
2. Найдите идентификатор аккаунта (acct_...) в разделе Настройки, Данные компании.
3. Откройте Stripe, как описано выше (или выполните `assistant connect stripe`), выберите **Или вставить ограниченный ключ**, вставьте идентификатор аккаунта и ключ, затем нажмите **Подключить**.

На собственном компьютере, если вход через Stripe пока недоступен, в разделе «Подключения» об этом сообщается и сразу открывается эта форма.

## Подключение для всей команды

В командном Fleet владелец или администратор один раз подключает Stripe и открывает к нему доступ команде:

1. Подключите Stripe на своей Machine (см. выше). В блоке **Общие подключения** на вкладке Fleet также есть кнопка **Подключить Stripe**.
2. На вкладке Fleet откройте **Поделиться Stripe**. По умолчанию выбраны все участники. Снимите отметку с тех, кому доступ не нужен. Нажмите **Поделиться**.

Теперь Machines коллег тоже смогут читать эти данные. В разделе «Подключения» видно, кто открыл к ним доступ. Изменить или отключить его могут только администраторы Fleet. Ваша Machine обновляет их доступ каждый час, поэтому, пока она выключена, доступ коллег к Stripe приостанавливается. Ваши данные для входа никому не передаются. Подробнее: [Fleets](fleet.md).

Если коллега сам подключит тот же аккаунт Stripe, данные будут считываться только один раз: общее подключение не будет использоваться.

Подключение Stripe через сервис, ключ которого даёт доступ и к другим приложениям, нельзя сделать общим. Вместо этого подключите Stripe напрямую для команды.

## Удаление подключения

- В панели управления: **Подключения**, откройте Stripe, выберите **Подробности**, затем **Отключить**. Данные, которые уже были загружены, останутся.
- На облачной Machine также можно нажать **Удалить** рядом с подключением на странице настройки.
- Если подключение общее для Fleet, сначала выберите **Прекратить общий доступ** на вкладке Fleet.

## Отзыв доступа в Stripe

- Если вы вошли через Stripe: в Stripe откройте Настройки, Установленные приложения и удалите The Machine.
- Если вы используете ограниченный ключ: в Stripe откройте Developers, API keys и удалите ключ или замените его новым.
