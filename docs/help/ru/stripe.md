## Что читает

События в вашем аккаунте Stripe, которые могут требовать вашего внимания: неудачные платежи, споры, отмены и крупные новые подписки, а также данные о соответствующих клиентах. Адрес электронной почты клиента связывает событие с этим человеком и его организацией в [Graph](graph.md).

В событии о неудачном платеже указано, за что он был (первый платёж, продление) и когда Stripe повторит попытку. Причину отклонения карты оно не указывает: Stripe не включает её в событие, поэтому откройте его в Stripe, чтобы узнать причину.

## Что может делать

Ничего в Stripe. The Machine не возвращает деньги, не повторяет попытки оплаты и ничего не меняет. Для подключения нужен только доступ на чтение, и Stripe сообщает об этом перед установкой.

## Подключение

Войдите через Stripe, это самый простой способ:

1. В панели управления выберите **Подключения**, **Клиенты**, Stripe. Или на странице настройки размещённой Machine по адресу app.themachine.computer/setup выберите **Другие источники**, Stripe. На своём компьютере сначала свяжите Machine со своей учётной записью.
2. Нажмите «Войти через Stripe». Stripe предложит выбрать аккаунт и покажет, какие данные The Machine сможет читать.
3. Нажмите **Установить**. Вы вернётесь на прежнюю страницу, и Stripe будет подключён.

На своём компьютере вместо этого можно вставить ключ с ограниченными правами:

1. В Stripe создайте ключ с ограниченными правами: для Events, Customers и Account выберите Read, для всего остального выберите None.
2. Найдите идентификатор аккаунта (acct_...) в разделе Настройки, Сведения о компании.
3. Откройте Stripe, как описано выше (или выполните `assistant connect stripe`), откройте **Или вставьте ключ с ограниченными правами**, вставьте идентификатор аккаунта и ключ, затем нажмите **Подключить**.

На своём компьютере, если вход через Stripe пока недоступен, в разделе «Подключения» появится соответствующее сообщение и сразу откроется эта форма.

## Однократное подключение для команды

В рабочем Fleet владелец или администратор один раз подключает Stripe и делится подключением с командой:

1. Подключите Stripe на своей Machine (см. выше). В блоке **Общие подключения** на вкладке Fleet также есть кнопка **Подключить Stripe**.
2. На вкладке Fleet откройте **Поделиться Stripe**. По умолчанию выбраны все участники. Снимите отметку с тех, кому не нужно давать доступ. Нажмите **Поделиться**.

Теперь Stripe будет доступен и на Machine коллег. В разделе «Подключения» видно, кто поделился подключением. Только администраторы Fleet могут изменить настройки или отключить его. Ваша Machine обновляет доступ каждый час. Пока она выключена, доступ коллег к Stripe приостанавливается. Данные для входа никому не передаются. Подробнее: [Fleet](fleet.md).

Если коллега подключит тот же аккаунт Stripe самостоятельно, данные будут считываться только один раз: общее подключение не будет использоваться.

Подключением Stripe через сервис, чей ключ также открывает доступ к другим приложениям, нельзя поделиться. Вместо этого подключите Stripe напрямую для команды.

## Удаление подключения

- В панели управления выберите **Подключения**, откройте Stripe, нажмите **Подробности**, затем **Отключить**. Уже импортированные данные останутся.
- На размещённой Machine для Stripe, подключённого через вход, появится кнопка **Отключить ↗**. Она откроет страницу настройки: нажмите рядом с Stripe **Удалить**.
- Если подключением поделились с Fleet, сначала выберите **Отключить общий доступ** на вкладке Fleet.

## Отзыв доступа в Stripe

- Если вы вошли через Stripe: в Stripe откройте Настройки, Установленные приложения и удалите The Machine.
- Если использовали ключ с ограниченными правами: в Stripe откройте Developers, API keys и удалите или замените ключ.
