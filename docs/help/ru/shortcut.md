## Что она читает

Истории в рабочей области Shortcut, которые меняют статус, с указанием ответственных и сроков.

## Что она умеет

Ничего. Она только читает, хотя токен Shortcut даёт ей больше прав.

## Подключение

1. Если The Machine размещена в облаке: откройте страницу настройки на app.themachine.computer/setup, перейдите в **Другие источники** и откройте Shortcut. Если The Machine установлена на вашем компьютере: откройте **Подключения**, **Проекты и код**, Shortcut или `assistant connect shortcut`.
2. Нажмите **Получить токен**. Shortcut откроет страницу API Tokens в новой вкладке. Создайте токен и скопируйте его.
3. Вставьте токен и нажмите **Подключить**. The Machine сразу проверит токен и покажет, от чьего имени и к какой рабочей области она подключилась.

У вас несколько рабочих областей Shortcut? Токен связан с одной рабочей областью, поэтому сначала переключитесь на неё в Shortcut.

## Отключение

- В панели управления: откройте **Подключения**, выберите Shortcut, затем **Подробнее** и **Отключить**. Уже загруженные данные останутся.
- Если The Machine размещена в облаке, на странице настройки можно также нажать **Удалить** рядом с Shortcut.

## Отзыв токена в Shortcut

Удалите токен на той же странице API Tokens.
