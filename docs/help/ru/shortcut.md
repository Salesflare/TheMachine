## Какие данные она читает

Истории в вашем рабочем пространстве Shortcut, в которых меняется статус, с указанием ответственных и сроков.

## Что она умеет

Ничего не меняет в Shortcut. Только читает данные.

## Подключение

1. В панели управления выберите **Подключения**, **Проекты и код**, Shortcut. Или на странице настройки хостинговой версии The Machine по адресу app.themachine.computer/setup выберите **Другие источники**, Shortcut. На собственном компьютере сначала привяжите The Machine к своему аккаунту.
2. Нажмите **Войти через Shortcut** и разрешите доступ на чтение. The Machine запрашивает у Shortcut только доступ на чтение.
3. The Machine сразу проверит вход и покажет, от чьего имени и в каком рабочем пространстве выполнено подключение.

У вас несколько рабочих пространств Shortcut? Сначала переключитесь на нужное в Shortcut. Чтобы подключить другое рабочее пространство, добавьте Shortcut ещё раз.

## Вместо этого вставьте токен

В разделе **Или вставьте API-токен** нажмите **Получить токен**. Shortcut откроет в новой вкладке страницу токенов API: создайте токен, скопируйте и вставьте его, затем нажмите **Подключить**. На собственном компьютере `assistant connect shortcut` тоже запросит токен. Токен предоставляет полный доступ к вашему аккаунту, но The Machine использует его только для чтения.

## Удаление подключения

- В панели управления выберите **Подключения**, откройте Shortcut, нажмите **Подробности**, затем **Отключить**. Уже импортированные данные останутся.
- В хостинговой версии The Machine также можно нажать **Удалить** рядом с Shortcut на странице настройки.

## Отзыв доступа в Shortcut

Если вы вставили токен, удалите его на странице токенов API. Если вы вошли через Shortcut, отключение здесь прекратит чтение данных.
