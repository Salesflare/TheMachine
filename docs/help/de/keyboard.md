## Die Palette

Drück `⌘K` auf einem Mac oder `Ctrl K` unter Windows und Linux, oder `/`, um **Suche und Befehle** zu öffnen. Tippe einen Teil eines Namens: eine Aktion, eine Seite, eine Aufgabe, eine Person, eine Organisation oder ein Projekt. Nutze die Pfeiltasten und Enter, oder Esc zum Schließen. Letzte Befehle stehen zuerst.

Auf dem Handy tippst du auf das Suchsymbol in der oberen Leiste.

## Tastenkürzel

Drück `?` für **Tastenkürzel**, die vollständige Liste für deinen Computer.

- Zu einer Seite springen: `G`, dann `S` Vorschläge, `C` Kalender, `E` Termine, `P` Personen, `O` Organisationen, `J` Projekte, `F` Fleet, `B` Feedback, `N` Verbindungen, `,` Einstellungen.
- `C` legt eine neue Aufgabe an. `J` und `K` bewegen sich durch eine Liste, Enter öffnet.
- Bei einer Aufgabe: `E` benennt sie um, `S` stellt sie zurück, `D` markiert sie als erledigt, `R` schreibt in ihren Chat.

Tasten funktionieren nicht, während du in ein Feld tippst.

## Keine Taste sendet etwas

Senden, Freigeben oder Posten passiert nie über eine Taste oder direkt aus der Palette. Einträge wie E-Mail prüfen öffnen nur den Entwurf, wo du ihn lesen, ändern und mit seinem eigenen Button senden kannst.
