## Was „Ausführen“ bewirkt

**Ausführen** bittet deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie nutzt dafür deine Konten und ihren eigenen Browser, so wie du es tun würdest.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat die jeweilige Seite live an, auch zwischen den einzelnen Schritten, bis die Arbeit dort erledigt ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt und bietet die Schaltfläche **Stoppen**: Ein Klick beendet diesen Durchlauf sofort.

Vor einer Nachfassnachricht oder Übergabe prüft sie, ob es neuere Antworten gibt, auch von Teammitgliedern. Wenn die Aufgabe bereits erledigt ist, steht das dort. Hat sie ein Dokument oder eine Seite geändert, enthält die Aufgabe einen Link dazu.

Wenn eine anspruchsvolle Aufgabe auf einer Website oder in einem Ablauf gelingt, speichert deine Machine die Schritte als Skill, ohne persönliche Angaben. Bei späteren Aufgaben auf dieser Website dienen sie als Anleitung, niemals als Erlaubnis: Senden oder Bezahlen wartet weiterhin auf deine Zustimmung. Die Skills findest du unter **Einstellungen > Skills** mit dem Hinweis **Aus einer Aufgabe gelernt**.

## Nichts wird ohne dein Okay gesendet

- Eine Antwort wird als Entwurf bereitgestellt. **Prüfen und senden** öffnet ihn, damit du ihn bearbeiten kannst. Gesendet wird er erst, wenn du auf **Jetzt senden** klickst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat prüfen. Jede E-Mail wird nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten, und im letzten Schritt werden alle gesendet. Eine E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chatnachricht ist einfacher Text.
- Mit **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe öffnest du diese E-Mail.
- Ein Schritt, der etwas verbindlich macht, etwa Absenden, Bezahlen oder Buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, bleiben die anderen offen. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen, was bei einem solchen Schritt gesendet wird, bevor du ihn bestätigst. Bei einer Kalendereinladung siehst du den Titel, die Uhrzeit, die Gäste und ob ein Besprechungslink hinzugefügt wird.
- Verbundene Kalender werden bei der Suche nach einem passenden Zeitpunkt berücksichtigt. Bevor sie Zeiten vorschlägt, liest sie deine Termine für die betreffenden Tage.
- In einem Aufgaben-Chat wird ein Entwurf niemals in derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmal, dass nichts gesendet wird, bevor du zustimmst. **Vorbereitet** bedeutet, dass ein Entwurf oder Ergebnis bereit zur Freigabe ist. Endet die Arbeit ohne ein Ergebnis, weil sie dich braucht, etwa für eine Entscheidung, eine fehlende Angabe, eine Anmeldung oder eine Auswahl, steht bei der Aufgabe stattdessen **Braucht dich**, mit einem Hinweis darauf, was benötigt wird. Das gilt auch, wenn sie nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“) und **Ausführen** noch nicht verwendet wurde. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Erst wenn etwas tatsächlich gesendet wurde, steht dort, dass ein Entwurf gesendet wurde.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Mit **Mehr anzeigen** oder einem Tipp auf den Text öffnest du den Rest. **Prüfen und senden** zeigt immer den vollständigen Text.

Je nach Quelle kann sie eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## Eine E-Mail bearbeiten

- Verwende die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Außerdem gibt es Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link muss mit https:// beginnen. Eingefügter Text wird ohne Farben und Bilder als einfacher Text übernommen.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Die Nachricht zeigt dann, wie sie gesendet wird. Klicke noch einmal auf **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so gesendet, wie sie angezeigt wird. Zusätzlich wird eine einfache Textversion mitgeschickt, damit sie auch in Mail-Apps ohne Formatierungsanzeige lesbar ist.

## Wenn es nicht klappt

- „Das kann nicht von hier aus gesendet werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- Bei **Braucht dich**, wenn nichts gesendet, geöffnet oder gelesen werden muss, steht zuerst **Antworten**: Sag, was benötigt wird, und die Aufgabe wird fortgesetzt. Bei einem Schritt, den nur du selbst erledigen kannst, etwa einer Zahlung über deine Bank, steht zuerst **Als erledigt markieren**.
- **Braucht deine Hilfe** bedeutet, dass eine Frage offen ist: **Antworten**. **Hängt fest** bedeutet, dass die Aufgabe ohne offene Frage angehalten wurde. In der Aufgabe steht warum.
- Wurden mehrere Dinge gefragt? Für jede Frage gibt es eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, manchmal schon mit deiner letzten Antwort ausgefüllt. Mit **Antworten** sendest du alles zusammen.
- Bittet dich jemand um Informationen oder Dateien? Die Aufgabe entwirft eine Antwort mit den gefundenen Angaben und fragt dich nur nach dem Rest.
- Fehlt etwas, das nur du hast? Sie fragt danach und entwirft nur, was auch ohne diese Angabe verschickt werden kann, etwa eine Antwort, die einen Termin bestätigt. Sie entwirft keine Antwort, die nur sagt, dass die Information noch kommt.
- **Erneut versuchen** startet die Aufgabe noch einmal. **Änderungen anfragen** bittet um etwas anderes. Bei einer festgefahrenen Aufgabe steht **Erneut versuchen** an erster Stelle. Unter **Details** siehst du, was sie versucht hat.
- Ist die Aufgabe fehlgeschlagen, weil der Durchlauf selbst nicht geklappt hat? Nach einem Update deiner Machine versucht sie es automatisch noch einmal.
- Einen fehlgeschlagenen Durchlauf wiederholt sie höchstens zweimal automatisch. Danach wartet sie auf etwas Neues, etwa eine neue Nachricht oder deine Nachricht im Chat, oder darauf, dass du **Erneut versuchen** auswählst.
- Während der Vorbereitung steht in der Aufgabe in einer kurzen Zeile, was deine Machine gerade tut, etwa „Liest die E-Mail“, „Liest das PDF“ oder „Schreibt den Entwurf“. Die einzelnen Schritte findest du im Aufgaben-Chat.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** beginnt innerhalb weniger Sekunden. Muss sie warten, steht dort warum und ungefähr wie lange, etwa „Beginnt nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, damit die Nutzung begrenzt bleibt. **Ausführen** wird trotzdem angezeigt. Klicke darauf, um sofort zu starten, noch vor den anderen Aufgaben. Ohne dein Okay wird nichts gesendet. Ist das Nutzungslimit deines KI-Tarifs erreicht, weist **Ausführen** darauf hin. Sobald das Limit zurückgesetzt wird, startet die Aufgabe.
- Fordert eine Website dich auf, dich anzumelden, klicke auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht die Aufgabe automatisch weiter. Falls nicht, klicke auf **Weiter**.
- Ein an dein Handy gesendeter Code oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was benötigt wird. Wähle dann **Weiter** oder **Erneut versuchen**. Ist eine Quelle wie Slack nicht verbunden, kannst du in der Aufgabe **Slack verbinden** auswählen. Sobald Slack verbunden ist, macht die Aufgabe automatisch weiter.
