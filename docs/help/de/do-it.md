## Was **Ausführen** bewirkt

**Ausführen** lässt deine Machine die Aufgabe vorbereiten: eine Antwort entwerfen, etwas nachschlagen oder ein Formular ausfüllen. Sie nutzt deine eigenen Konten und ihren eigenen Browser, so wie du selbst.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat die Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt, mit **Stopp**: Einmal drücken beendet diesen Durchlauf sofort.

Vor einer Rückfrage oder Übergabe prüft sie, ob neuere Antworten eingegangen sind, auch von einer Teamkollegin oder einem Teamkollegen. Wenn die Aufgabe bereits erledigt ist, steht das dort. Wenn sie ein Dokument oder eine Seite geändert hat, verlinkt die Aufgabe darauf.

## Nichts wird ohne deine Zustimmung verschickt

- Eine Antwort wird als Entwurf zurückgegeben. **Prüfen und senden** öffnet sie, damit du sie bearbeiten kannst. Sie wird erst verschickt, wenn du auf **Jetzt senden** drückst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat der Aufgabe prüfen. Sie werden nacheinander angezeigt, jeweils mit **Weiter**. Im letzten Schritt werden alle verschickt. Jede E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich verschickt wurde.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chat-Nachricht ist reiner Text.
- Mit **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe wird diese E-Mail geöffnet.
- Bei einem Schritt, der etwas verbindlich ausführt, etwa absenden, bezahlen oder buchen, wartet die Aufgabe auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, warten die anderen weiter. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen vor dem Tippen, was ein solcher Schritt verschickt. Bei einer Kalendereinladung werden Titel, Uhrzeit, Gäste und die Angabe angezeigt, ob ein Meeting-Link hinzugefügt wird.
- Verbundene Kalender werden bei der Suche nach einem Termin berücksichtigt: Die Aufgabe liest deine Termine für diese Tage, bevor sie dir Zeiten vorschlägt.
- In einem Aufgaben-Chat wird ein Entwurf nie in derselben Nachricht verschickt, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmal, dass nichts verschickt wird, bevor du zustimmst. Wenn noch etwas von dir gebraucht wird, steht dort **Braucht dich**. Erst nach dem Versand steht dort, dass ein Entwurf verschickt wurde.
- Bei einem langen Entwurf werden die ersten 3 Zeilen angezeigt. Über **Mehr anzeigen** oder durch Tippen auf den Text öffnest du den Rest. **Prüfen und senden** zeigt immer den vollständigen Entwurf.

Je nach Quelle kann die Aufgabe eine E-Mail, eine Direktnachricht in Slack oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X verschicken. Im Artikel zu jeder Verbindung steht, was sie verschicken kann.

## E-Mails bearbeiten

- Nutze die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Es gibt auch Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link muss mit https:// beginnen. Eingefügter Text wird als reiner Text übernommen, ohne Farben oder Bilder.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Die Nachricht zeigt dann, wie sie verschickt wird. Drücke erneut auf **Jetzt senden**, um sie zu verschicken.
- Die E-Mail wird genau wie angezeigt verschickt, zusätzlich mit einer Nur-Text-Kopie für Mail-Apps, die keine Formatierung anzeigen.

## Wenn es nicht geht

- „Das kann nicht von hier aus verschickt werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst verschickst.
- **Braucht deine Hilfe** bedeutet, dass eine Frage vorliegt: Tippe auf **Antworten**. **Hängt fest** bedeutet, dass die Aufgabe ohne Frage angehalten wurde. In der Aufgabe steht, warum.
- Wurden mehrere Dinge gefragt? Für jede Frage gibt es eigene Auswahlmöglichkeiten oder ein kurzes Feld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Über **Antworten** schickst du alle Antworten zusammen ab.
- Fehlt etwas, das nur du hast? Die Aufgabe fragt danach und erstellt nur Entwürfe für Dinge, die auch ohne diese Information möglich sind, etwa eine Antwort zur Bestätigung eines Datums. Sie erstellt keinen Entwurf, der nur sagt, dass die Information noch kommt.
- **Erneut versuchen** führt die Aufgabe noch einmal aus. **Änderungen anfragen** bittet um etwas anderes. Bei einer angehaltenen Aufgabe wird **Erneut versuchen** zuerst angezeigt. Unter **Details** siehst du, was die Aufgabe versucht hat.
- Während der Vorbereitung zeigt die Aufgabe in einer einfachen Zeile, was deine Machine gerade tut, etwa „Liest die E-Mail“, „Liest das PDF“ oder „Schreibt den Entwurf“. Die einzelnen Schritte stehen im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** startet innerhalb weniger Sekunden. Muss sie warten, steht dort, warum und ungefähr wie lange, etwa „Startet nach der aktuellen Aufgabe“.
- Eine Website fordert dich auf, dich anzumelden: Tippe auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht die Aufgabe selbstständig weiter. Falls nicht, tippe auf **Weiter**.
- Ein Code, der an dein Telefon gesendet wird, oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was sie braucht. Tippe dann auf **Weiter** oder **Erneut versuchen**. Ist eine Quelle nicht verbunden, etwa Slack, kannst du in der Aufgabe auf **Slack verbinden** tippen. Sobald Slack verbunden ist, macht die Aufgabe selbstständig weiter.
