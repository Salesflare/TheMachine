## Was „Ausführen“ macht

**Ausführen** bittet deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie nutzt deine Konten und ihren eigenen Browser, so wie du es tun würdest.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat die jeweilige Seite live an, auch zwischen den einzelnen Schritten, bis die Arbeit dort abgeschlossen ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt und enthält **Stoppen**: Ein Klick beendet diesen Durchlauf sofort.

Vor einer Nachfassnachricht oder einer Übergabe prüft sie, ob es neuere Antworten gibt, auch von einem Teammitglied. Wenn die Aufgabe schon erledigt ist, steht das in der Aufgabe. Wenn sie ein Dokument oder eine Seite geändert hat, verlinkt die Aufgabe darauf.

Wenn deine Machine eine schwierige Aufgabe auf einer Website oder in einem Workflow erfolgreich erledigt, merkt sie sich die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website nutzen sie als Anleitung, aber niemals als Erlaubnis: Senden und Bezahlen musst du weiterhin selbst bestätigen. Die Skills findest du unter **Einstellungen > Skills**. Dort sind sie mit **Aus einer Aufgabe gelernt** gekennzeichnet.

## Nichts wird ohne dein Okay gesendet

- Eine Antwort wird als Entwurf zurückgegeben. Mit **Prüfen und senden** öffnest du sie und kannst sie bearbeiten. Sie wird erst gesendet, wenn du auf **Jetzt senden** klickst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie im Chat der Aufgabe alle mit einer Schaltfläche prüfen. Sie werden nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten, und im letzten Schritt werden alle gesendet. Jede E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, mit Fettdruck, Listen und Links. Eine Slack- oder Chat-Nachricht ist unformatiert.
- Mit **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine überarbeitet dann den Entwurf.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe öffnest du diese E-Mail.
- Ein Schritt, der etwas verbindlich macht, zum Beispiel Absenden, Bezahlen oder Buchen, wartet auf deine Bestätigung. Du kannst auch im Chat darum bitten. Wenn du einen Schritt bestätigst, bleiben die anderen weiterhin offen: Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen, was ein solcher Schritt sendet, bevor du ihn antippst. Bei einer Kalendereinladung werden Titel, Uhrzeit, Gäste und die Angabe angezeigt, ob ein Meeting-Link hinzugefügt wird.
- Verbundene Kalender werden bei der Suche nach einem passenden Zeitpunkt berücksichtigt: Bevor sie Zeiten vorschlägt, liest sie deine Termine für diese Tage.
- Ein Entwurf im Chat einer Aufgabe wird niemals in derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du etwas freigibst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht außerdem einmal der Hinweis, dass nichts gesendet wird, bevor du es freigibst. **Vorbereitet** bedeutet, dass ein Entwurf oder Ergebnis zur Freigabe bereitsteht. Wenn die Arbeit ohne Entwurf oder Ergebnis endet, weil sie dich braucht, etwa für eine Entscheidung, eine fehlende Information, eine Anmeldung oder eine Auswahl, zeigt die Aufgabe stattdessen **Braucht dich** und nennt in einer Zeile, was sie braucht. Das gilt auch, wenn sie nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“). In diesem Fall wird zuerst **Ausführen** angezeigt. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Ein Entwurf wird erst dann als gesendet bezeichnet, wenn er tatsächlich gesendet wurde.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Mit **Mehr anzeigen** oder durch Tippen auf den Text öffnest du den Rest. Unter **Prüfen und senden** wird immer der gesamte Entwurf angezeigt.

Je nach Quelle kann sie eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## Eine E-Mail bearbeiten

- Nutze die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Es gibt auch Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link braucht eine Adresse, die mit https:// beginnt. Eingefügter Text wird unformatiert übernommen, ohne Farben oder Bilder.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Die Nachricht zeigt dann, wie sie gesendet wird. Klicke noch einmal auf **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau wie angezeigt gesendet, zusammen mit einer unformatierten Textversion für Mail-Apps, die keine Formatierung anzeigen.

## Wenn es nicht geht

- „Das kann nicht von hier aus gesendet werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- **Braucht deine Hilfe** bedeutet, dass die Aufgabe eine Frage hat: **Antworten**. **Hängt fest** bedeutet, dass sie ohne Frage angehalten wurde. In der Aufgabe steht warum.
- Hast du mehr als eine Frage gestellt? Jede Frage hat eine eigene Auswahl oder ein kurzes Eingabefeld, das manchmal schon mit der letzten Antwort ausgefüllt ist. Mit **Antworten** sendest du alles zusammen.
- Fehlt etwas, das nur du hast? Sie fragt danach und entwirft nur, was auch ohne diese Information möglich ist, zum Beispiel eine Antwort, die einen Termin bestätigt. Sie entwirft keine Antwort, die nur sagt, dass sie noch kommt.
- **Erneut versuchen** startet die Aufgabe noch einmal. Mit **Änderungen anfragen** bittest du um etwas anderes. Bei einer Aufgabe, die festhängt, wird zuerst **Erneut versuchen** angezeigt. Unter **Details** siehst du, was sie versucht hat.
- Hängt die Aufgabe fest, weil der Durchlauf selbst fehlgeschlagen ist? Nachdem deine Machine aktualisiert wurde, versucht sie die Aufgabe selbst noch einmal.
- Einen fehlgeschlagenen Durchlauf versucht sie höchstens zweimal selbst erneut. Danach wartet sie auf etwas Neues, zum Beispiel eine neue Nachricht, eine Nachricht von dir im Chat oder **Erneut versuchen**.
- Während der Vorbereitung steht in der Aufgabe in einer einfachen Zeile, was deine Machine gerade tut, zum Beispiel „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird geschrieben“. Die ausführlichen Schritte findest du im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** beginnt innerhalb weniger Sekunden. Wenn sie warten muss, nennt sie den Grund und ungefähr, wann es weitergeht, zum Beispiel „Startet nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, während sie die Nutzung spart. **Ausführen** wird trotzdem angezeigt: Klicke darauf, um die Aufgabe sofort und vor den anderen zu starten. Ohne dein Okay wird nichts gesendet. Wenn das Nutzungslimit deines KI-Tarifs erreicht ist, weist Ausführen darauf hin. Sobald das Limit zurückgesetzt wird, startet die Aufgabe.
- Wenn eine Website eine Anmeldung verlangt, klicke auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht die Aufgabe selbst weiter. Falls nicht, klicke auf **Weiter**.
- Ein Code, der an dein Handy gesendet wird, oder eine fehlende Berechtigung hält die Aufgabe an. Sie sagt dir, was sie braucht. Klicke dann auf **Weiter** oder **Erneut versuchen**. Wenn eine Quelle nicht verbunden ist, zum Beispiel Slack, führt **Slack verbinden** direkt in der Aufgabe weiter. Sobald Slack verbunden ist, macht die Aufgabe selbst weiter.
