## Was Ausführen macht

**Ausführen** bittet deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie verwendet deine Konten und ihren eigenen Browser, so wie du es tun würdest.

Während sie in ihrem Browser arbeitet, zeigen die Aufgabe und ihr Chat die Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt und du siehst **Stopp**: Einmal drücken, und dieser Durchlauf wird sofort beendet.

Vor einer Rückfrage oder Übergabe prüft sie, ob es neuere Antworten gibt, auch von einem Teammitglied. Wenn die Aufgabe bereits erledigt ist, steht das in der Aufgabe. Wenn sie ein Dokument oder eine Seite geändert hat, verlinkt die Aufgabe darauf.

Wenn eine schwierige Aufgabe auf einer Website oder in einem Workflow klappt, speichert deine Machine die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website nutzen die Schritte als Anleitung, aber niemals als Erlaubnis: Senden oder Bezahlen musst du weiterhin selbst bestätigen. Die Skills findest du unter **Einstellungen > Skills** mit dem Hinweis **Aus einer Aufgabe gelernt**.

## Nichts wird ohne dein Okay gesendet

- Eine Antwort wird als Entwurf erstellt. **Prüfen und senden** öffnet sie, damit du sie bearbeiten kannst. Gesendet wird sie erst, wenn du auf **Jetzt senden** drückst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie im Chat der Aufgabe alle mit einer Schaltfläche prüfen. Jede E-Mail wird nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten, und im letzten Schritt werden alle gesendet. Jede E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chat-Nachricht besteht aus einfachem Text.
- Mit **Änderungen anfragen** im selben Fenster kannst du angeben, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe wird diese E-Mail geöffnet.
- Bei einem Schritt, der etwas verbindlich macht, etwa beim Absenden, Bezahlen oder Buchen, wartet deine Machine auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, bleiben die anderen offen. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen, was bei einem solchen Schritt gesendet wird, bevor du darauf tippst. Bei einer Kalendereinladung werden Titel, Uhrzeit und Gäste angezeigt sowie, ob ein Meeting-Link hinzugefügt wird.
- Bei der Suche nach einem passenden Zeitpunkt berücksichtigt sie verbundene Kalender: Bevor sie Zeiten vorschlägt, liest sie deine Termine für die betreffenden Tage.
- Ein Entwurf im Chat einer Aufgabe wird niemals mit derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmal, dass nichts gesendet wird, bevor du zustimmst. Wenn noch etwas von dir gebraucht wird, steht dort **Braucht dich**. Dass ein Entwurf gesendet wurde, wird erst angezeigt, wenn er tatsächlich rausgegangen ist.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Mit **Mehr anzeigen** oder durch Tippen auf den Text öffnest du den Rest. **Prüfen und senden** zeigt immer den vollständigen Entwurf.

Je nach Quelle kann sie eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## Eine E-Mail bearbeiten

- Nutze die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf dem Mac). Außerdem gibt es Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link muss mit https:// beginnen. Eingefügter Text wird ohne Farben und Bilder als einfacher Text übernommen.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Anschließend wird die Nachricht so angezeigt, wie sie verschickt wird. Drücke noch einmal auf **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so verschickt, wie sie angezeigt wird, zusätzlich mit einer Nur-Text-Version für E-Mail-Apps, die keine Formatierung anzeigen.

## Wenn etwas nicht klappt

- „Das lässt sich hier nicht senden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- **Braucht deine Hilfe** bedeutet, dass eine Frage offen ist: **Antworten**. **Hängt fest** bedeutet, dass die Aufgabe ohne offene Frage angehalten wurde. In der Aufgabe steht, warum.
- Wurden mehrere Fragen gestellt? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Mit **Antworten** werden alle Antworten zusammen gesendet.
- Fehlt etwas, das nur du hast? Sie fragt danach und erstellt nur Entwürfe, die auch ohne diese Information verschickt werden können, etwa eine Antwort, die einen Termin bestätigt. Sie erstellt keinen Entwurf, der nur sagt, dass die Information noch kommt.
- Mit **Erneut versuchen** wird die Aufgabe noch einmal ausgeführt. Mit **Änderungen anfragen** kannst du um etwas anderes bitten. Bei einer angehaltenen Aufgabe ist **Erneut versuchen** die erste Option. Unter **Details** siehst du, was die Aufgabe versucht hat.
- Während der Vorbereitung steht in der Aufgabe in einer kurzen Zeile, was deine Machine gerade tut, zum Beispiel „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird geschrieben“. Die detaillierten Schritte stehen im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** startet innerhalb weniger Sekunden. Wenn sie warten muss, steht dort warum und ungefähr wie lange, zum Beispiel „Startet nach der aktuellen Aufgabe“.
- Wenn eine Website dich auffordert, dich anzumelden, drücke auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht die Aufgabe selbstständig weiter. Wenn nicht, drücke auf **Weiter**.
- Ein Code, der an dein Telefon gesendet wird, oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was benötigt wird. Drücke dann auf **Weiter** oder **Erneut versuchen**. Wenn eine Quelle nicht verbunden ist, zum Beispiel Slack, kannst du in der Aufgabe auf **Slack verbinden** drücken. Sobald Slack verbunden ist, macht die Aufgabe selbstständig weiter.
