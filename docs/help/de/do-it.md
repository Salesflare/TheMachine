## Was Ausführen macht

Mit **Ausführen** bittest du deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie nutzt deine eigenen Konten und ihren eigenen Browser, so wie du es auch tun würdest.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat die aufgerufene Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt, zusammen mit **Stoppen**. Ein Klick darauf beendet den aktuellen Durchlauf sofort.

Vor einer Nachfassnachricht oder Übergabe prüft sie, ob es neuere Antworten gibt, auch von Teammitgliedern. Wenn sich die Sache bereits erledigt hat, steht das in der Aufgabe. Wenn sie ein Dokument oder eine Seite geändert hat, enthält die Aufgabe einen Link dazu.

Wenn eine schwierige Aufgabe auf einer Website oder in einem Workflow klappt, merkt sich deine Machine die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website nutzen die Schritte als Anleitung, aber nie als Berechtigung: Senden oder Bezahlen musst du weiterhin selbst freigeben. Die Skills findest du unter **Einstellungen > Skills** mit dem Hinweis **Aus einer Aufgabe gelernt**.

## Nichts wird gesendet, bevor du zustimmst

- Eine Antwort wird als Entwurf zurückgegeben. **Prüfen und senden** öffnet sie und du kannst sie bearbeiten. Gesendet wird sie erst, wenn du auf **Jetzt senden** tippst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat prüfen. Sie werden nacheinander angezeigt. Tippe auf **Weiter**, um zur nächsten zu gehen. Im letzten Schritt werden alle gesendet. Jede E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chatnachricht ist einfacher Text.
- Mit **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine überarbeitet dann den Entwurf.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe wird diese E-Mail geöffnet.
- Ein Schritt, der etwas verbindlich macht, etwa Absenden, Bezahlen oder Buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, bleiben die anderen offen. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen vor dem Antippen, was bei einem solchen Schritt gesendet wird. Bei einer Kalendereinladung werden Titel, Uhrzeit, Gäste und die Angabe angezeigt, ob ein Meeting-Link hinzugefügt wird.
- Bei der Suche nach einem passenden Zeitpunkt berücksichtigt sie verbundene Kalender: Bevor sie Zeiten vorschlägt, liest sie deine Termine für die jeweiligen Tage.
- Ein Entwurf in einem Aufgabenchat wird nie in derselben Nachricht gesendet, in der er verfasst wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmal, dass nichts gesendet wird, bevor du zustimmst. Wenn noch etwas von dir gebraucht wird, steht dort **Braucht dich**. Erst wenn ein Entwurf gesendet wurde, steht dort, dass er rausgegangen ist.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Tippe auf **Mehr anzeigen** oder auf den Text, um den Rest zu öffnen. Unter **Prüfen und senden** wird immer der vollständige Entwurf angezeigt.

Je nach Quelle kann sie eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## E-Mail bearbeiten

- Nutze die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Außerdem gibt es Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link braucht eine Adresse, die mit https:// beginnt. Eingefügter Text wird ohne Farben und Bilder übernommen.
- Formatierungen, die in einer E-Mail nicht funktionieren, werden zuerst entfernt. Die Nachricht zeigt dann, wie sie aussehen wird. Tippe noch einmal auf **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so gesendet, wie sie angezeigt wird. Dazu kommt eine Textversion für Mail-Apps, die keine Formatierungen anzeigen.

## Wenn es nicht klappt

- „Das kann von hier aus nicht gesendet werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- **Braucht deine Hilfe** bedeutet, dass eine Frage offen ist: Tippe auf **Antworten**. **Hängt fest** bedeutet, dass die Aufgabe ohne Frage angehalten wurde. In der Aufgabe steht der Grund.
- Wurden mehrere Dinge gefragt? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Mit **Antworten** sendest du alle Antworten zusammen ab.
- Fehlt etwas, das nur du hast? Sie fragt danach und entwirft nur, was auch ohne diese Information möglich ist, zum Beispiel eine Antwort, die einen Termin bestätigt. Sie entwirft keine Antwort, die nur sagt, dass noch etwas kommt.
- **Erneut versuchen** startet die Aufgabe noch einmal. Mit **Änderungen anfragen** kannst du um etwas anderes bitten. Bei einer angehaltenen Aufgabe steht **Erneut versuchen** an erster Stelle. Unter **Details** siehst du, was sie versucht hat.
- Ist die Aufgabe angehalten, weil der Durchlauf selbst fehlgeschlagen ist? Sobald deine Machine aktualisiert wurde, versucht sie die Aufgabe noch einmal von selbst.
- Einen fehlgeschlagenen Durchlauf wiederholt sie höchstens zweimal von selbst. Danach wartet sie auf etwas Neues, zum Beispiel eine neue Nachricht, deine Nachricht im Chat oder einen Tipp auf **Erneut versuchen**.
- Während sie die Aufgabe vorbereitet, steht in einer kurzen Zeile, was deine Machine gerade tut, etwa „Liest die E-Mail“, „Liest das PDF“ oder „Schreibt den Entwurf“. Die einzelnen Schritte findest du im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** startet innerhalb weniger Sekunden. Wenn sie warten muss, steht dort warum und ungefähr wie lange, zum Beispiel „Startet nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, damit sie weniger Nutzung verbraucht. **Ausführen** wird trotzdem angezeigt. Tippe darauf, um die Aufgabe sofort und vor den anderen zu starten. Nichts wird gesendet, bevor du zustimmst. Wenn das Nutzungslimit deines KI-Tarifs erreicht ist, meldet Ausführen das und die Aufgabe startet, sobald das Limit zurückgesetzt wird.
- Möchte eine Website, dass du dich anmeldest? Tippe auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht die Aufgabe von selbst weiter. Falls nicht, tippe auf **Weiter**.
- Ein an dein Handy gesendeter Code oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was sie braucht. Tippe dann auf **Weiter** oder **Erneut versuchen**. Ist eine Quelle nicht verbunden, zum Beispiel Slack, führt dich **Slack verbinden** direkt in der Aufgabe weiter. Sobald Slack verbunden ist, macht sie von selbst weiter.
