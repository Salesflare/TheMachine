## Was Ausführen macht

**Ausführen** weist deine Machine an, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie verwendet deine eigenen Konten und ihren eigenen Browser, so wie du es auch tun würdest.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat die jeweilige Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt, mit **Stoppen**: Einmal drücken, und der aktuelle Vorgang wird sofort beendet.

Vor einer Nachfassnachricht oder Übergabe prüft sie, ob es neuere Antworten gibt, auch von einem Teammitglied. Wenn die Aufgabe bereits erledigt ist, steht das dort. Wenn sie ein Dokument oder eine Seite geändert hat, enthält die Aufgabe einen Link dazu.

Wenn eine schwierige Aufgabe auf einer Website oder in einem Ablauf funktioniert, speichert deine Machine die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website erhalten sie als Anleitung, aber niemals als Erlaubnis: Senden oder Bezahlen musst du weiterhin selbst freigeben. Du findest diese Skills unter **Einstellungen > Skills** mit der Kennzeichnung **Aus einer Aufgabe gelernt**.

Wenn die Schritte eines solchen Skills bei drei Aufgaben hintereinander nicht funktionieren, deaktiviert deine Machine ihn. Er bleibt deaktiviert, bis eine spätere Aufgabe zeigt, was jetzt funktioniert, oder du ihn wieder aktivierst.

## Nichts wird ohne dein Okay gesendet

- Eine Antwort wird als Entwurf erstellt. Mit **Prüfen und senden** öffnest du sie und kannst sie bearbeiten. Sie wird erst gesendet, wenn du **Jetzt senden** drückst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat der Aufgabe prüfen. Jede E-Mail wird nacheinander angezeigt, mit **Weiter** geht es zur nächsten. Im letzten Schritt werden alle gesendet. Eine E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chatnachricht ist unformatiert.
- Mit **Änderungen anfragen** im selben Fenster kannst du sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort geht an die neueste E-Mail im Thread. Über die Quelle der Aufgabe öffnest du diese E-Mail.
- Ein Schritt, der etwas verbindlich macht, etwa absenden, bezahlen oder buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, warten die anderen weiterhin. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen, was ein solcher Schritt sendet, bevor du ihn antippst. Bei einer Kalendereinladung werden Titel, Uhrzeit und Gäste angezeigt, ebenso wie die Information, ob ein Meeting-Link hinzugefügt wird.
- Bei der Suche nach einem passenden Zeitpunkt berücksichtigt sie verbundene Kalender: Bevor sie Zeiten vorschlägt, liest sie deine Termine für die betreffenden Tage.
- Ein Entwurf wird im Chat einer Aufgabe nie in derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du etwas freigibst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmal, dass erst nach deiner Freigabe etwas gesendet wird. **Vorbereitet** bedeutet, dass ein Entwurf oder Ergebnis zur Freigabe bereitsteht. Endet die Arbeit ohne Entwurf oder Ergebnis, weil sie dich braucht, etwa für eine Entscheidung, eine fehlende Information, eine Anmeldung oder eine Auswahl, zeigt die Aufgabe stattdessen **Braucht dich** und nennt den Grund. Das gilt auch, wenn sie nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“). In diesem Fall steht **Ausführen** an erster Stelle. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Eine Nachricht wird erst dann als gesendet bezeichnet, wenn sie tatsächlich gesendet wurde.
- Ein Entwurf, der noch nicht verwendet werden kann, etwa ein Angebot ohne Preis, zeigt ebenfalls **Braucht dich**. Die Frage steht darunter, und **Antworten** führt dich weiter. Der Entwurf bleibt bei der Aufgabe. Du findest **Senden** unter **⋯** oder **Entwurf kopieren** über den Schaltflächen. Ergänze die fehlenden Angaben selbst, und der Status wechselt wieder zu **Vorbereitet**.
- Ein Entwurf, der so gesendet werden kann, wie er ist, bleibt **Vorbereitet**. Wenn ein Punkt noch verbessert werden könnte, steht das darunter: „Der Entwurf ist bereit. Eine Frage: …“.
- Bei einem langen Entwurf werden die ersten 3 Zeilen angezeigt. Über **Mehr anzeigen** oder durch Antippen des Textes öffnest du den Rest. Mit **Prüfen und senden** wird immer der vollständige Entwurf angezeigt.

Je nach Quelle kann sie eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## E-Mail bearbeiten

- Verwende die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Es gibt auch Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link braucht eine Adresse, die mit https:// beginnt. Eingefügter Text wird unformatiert übernommen, ohne Farben oder Bilder.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Anschließend wird angezeigt, wie die Nachricht aussehen wird. Drücke erneut **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so gesendet, wie sie angezeigt wird, zusätzlich mit einer unformatierten Textversion für Mail-Apps, die keine Formatierung anzeigen.

## Wenn es nicht geht

- „Das kann von hier aus nicht gesendet werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- Bei **Braucht dich**, wenn noch nichts gesendet, geöffnet oder gelesen werden kann, führt **Antworten** weiter: Sag, was gebraucht wird, und die Aufgabe wird fortgesetzt. Ein Schritt, den nur du selbst erledigen kannst, etwa eine Zahlung bei deiner Bank, führt zu **Als erledigt markieren**.
- **Braucht deine Hilfe** bedeutet, dass eine Frage offen ist: **Antworten**. **Hängt fest** bedeutet, dass die Aufgabe ohne offene Frage angehalten wurde. In der Aufgabe steht, warum.
- Wurden mehrere Dinge gefragt? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Feld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Mit **Antworten** werden alle Antworten zusammen gesendet.
- Hat jemand dich um Informationen oder Dateien gebeten? Die Aufgabe entwirft eine Antwort mit den gefundenen Angaben und fragt nur noch nach dem Rest.
- Fehlt etwas, das nur du hast? Die Aufgabe fragt danach und entwirft nur den Teil, der auch ohne diese Angabe gesendet werden kann, etwa eine Antwort zur Bestätigung eines Datums. Sie entwirft keine Antwort, die nur sagt, dass die Information noch nachgereicht wird.
- **Erneut versuchen** führt die Aufgabe noch einmal aus. Mit **Änderungen anfragen** kannst du um etwas anderes bitten. Bei einer Aufgabe, die festhängt, steht **Erneut versuchen** an erster Stelle. Unter **Details** siehst du, was sie versucht hat.
- Ist die Aufgabe fehlgeschlagen, weil der Vorgang selbst nicht funktioniert hat? Nach einem Update deiner Machine versucht sie es automatisch noch einmal.
- Sie versucht einen fehlgeschlagenen Vorgang höchstens zweimal automatisch erneut. Danach wartet sie auf etwas Neues, etwa eine neue Nachricht oder deine Nachricht im Chat, oder darauf, dass du **Erneut versuchen** drückst.
- Während der Vorbereitung steht in der Aufgabe in einer kurzen Zeile, was deine Machine gerade macht, etwa „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird geschrieben“. Die einzelnen Schritte findest du im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** beginnt innerhalb weniger Sekunden. Wenn sie warten muss, nennt sie den Grund und ungefähr, wann sie fortfährt, etwa „Beginnt nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, während sie die Nutzung spart. **Ausführen** bleibt trotzdem sichtbar: Drücke die Schaltfläche, um die Aufgabe sofort und vor den anderen zu starten. Nichts wird ohne dein Okay gesendet. Wenn das Nutzungslimit deines KI-Tarifs erreicht ist, weist Ausführen darauf hin. Die Aufgabe startet, sobald das Limit zurückgesetzt wird.
- Fordert eine Website dich auf, dich anzumelden, drücke **Anmelden** oder **Browser öffnen** und melde dich dort an. Anschließend macht die Aufgabe automatisch weiter. Falls nicht, drücke **Weiter**.
- Ein an dein Handy gesendeter Code oder eine fehlende Berechtigung hält die Aufgabe an. Sie sagt dir, was sie braucht, und zeigt dann **Weiter** oder **Erneut versuchen**. Wenn eine Quelle nicht verbunden ist, zum Beispiel Slack, führt **Slack verbinden** direkt in der Aufgabe weiter. Sobald Slack verbunden ist, macht die Aufgabe automatisch weiter.
