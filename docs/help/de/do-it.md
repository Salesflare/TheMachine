## Was „Ausführen“ macht

**Ausführen** bittet deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie nutzt dafür deine Konten und ihren eigenen Browser, so wie du es auch tun würdest.

Während deine Machine im Browser arbeitet, zeigen die Aufgabe und ihr Chat die jeweilige Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klick auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt und du siehst **Stoppen**: Einmal drücken beendet den Durchlauf sofort.

Vor einer Nachfassnachricht oder Übergabe prüft deine Machine, ob es neuere Antworten gibt, auch von Teammitgliedern. Wenn die Aufgabe bereits erledigt ist, steht das in der Aufgabe. Wenn deine Machine ein Dokument oder eine Seite geändert hat, findest du dort einen Link dazu.

Wenn deine Machine eine knifflige Aufgabe auf einer Website oder in einem Workflow löst, speichert sie die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website erhalten sie als Anleitung, aber nie als Erlaubnis: Senden oder Bezahlen muss weiterhin von dir bestätigt werden. Die Skills findest du unter **Einstellungen > Skills** mit der Kennzeichnung **Aus einer Aufgabe gelernt**.

## Nichts wird ohne deine Zustimmung gesendet

- Eine Antwort wird als Entwurf bereitgestellt. Über **Prüfen und senden** kannst du ihn öffnen und bearbeiten. Gesendet wird er erst, wenn du **Jetzt senden** drückst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat prüfen. Sie werden nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten, und im letzten Schritt werden alle gesendet. Eine E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie später aussieht, mit Fettdruck, Listen und Links. Eine Slack- oder Chatnachricht ist unformatierter Text.
- Über **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe wird diese E-Mail geöffnet.
- Ein Schritt, bei dem etwas verbindlich ausgeführt wird, zum Beispiel Absenden, Bezahlen oder Buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einem Schritt zustimmst, warten die anderen weiter. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen vor dem Antippen an, was bei einem solchen Schritt gesendet wird. Bei einer Kalendereinladung werden Titel, Uhrzeit, Gäste und die Angabe angezeigt, ob ein Meeting-Link hinzugefügt wird.
- Bei der Terminsuche berücksichtigt deine Machine verbundene Kalender. Bevor sie Zeiten vorschlägt, liest sie deine Termine für die betreffenden Tage.
- Ein Entwurf wird im Chat einer Aufgabe nie mit derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** als **Vorbereitet**. In der Liste steht außerdem, dass nichts gesendet wird, bevor du zustimmst. **Vorbereitet** bedeutet, dass ein Entwurf oder Ergebnis zur Freigabe bereit ist. Wenn die Arbeit ohne ein Ergebnis endet, weil deine Machine dich braucht, etwa für eine Entscheidung, eine fehlende Angabe, eine Anmeldung oder eine Auswahl, wird stattdessen **Braucht dich** angezeigt. Darunter steht, was benötigt wird. Das gilt auch, wenn deine Machine nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“). In diesem Fall wird zuerst **Ausführen** angezeigt. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Erst wenn ein Entwurf tatsächlich gesendet wurde, steht dort, dass er gesendet wurde.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Über **Mehr anzeigen** oder durch Antippen des Textes kannst du den Rest öffnen. Unter **Prüfen und senden** wird immer der ganze Entwurf angezeigt.

Je nach Quelle kann deine Machine eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Hilfeartikel zu jeder Verbindung steht, was deine Machine darüber senden kann.

## Eine E-Mail bearbeiten

- Nutze die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf dem Mac). Es gibt auch Schaltflächen für Listen mit Aufzählungszeichen und nummerierte Listen.
- Für einen Link ist eine Adresse erforderlich, die mit https:// beginnt. Eingefügter Text wird unformatiert übernommen, ohne Farben oder Bilder.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Danach wird angezeigt, wie die Nachricht versendet wird. Drücke erneut **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so versendet, wie sie angezeigt wird. Dazu kommt eine unformatierte Textversion für E-Mail-Apps, die keine Formatierungen anzeigen.

## Wenn etwas nicht geht

- „Das kann nicht von hier aus gesendet werden.“ bedeutet, dass du den Entwurf über **Entwurf kopieren** kopierst und selbst sendest.
- Bei **Braucht dich**, wenn nichts gesendet, geöffnet oder gelesen werden muss, geht es mit **Antworten** weiter: Sag, was benötigt wird, und deine Machine macht weiter. Bei einem Schritt, den nur du selbst erledigen kannst, etwa einer Zahlung bei deiner Bank, geht es mit **Als erledigt markieren** weiter.
- **Braucht deine Hilfe** bedeutet, dass deine Machine eine Frage hat: **Antworten**. **Hängt fest** bedeutet, dass sie ohne Frage angehalten hat. In der Aufgabe steht, warum.
- Hast du um mehr als eine Sache gebeten? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Über **Antworten** sendest du alle Antworten zusammen.
- Fehlt eine Information, die nur du hast? Deine Machine fragt danach und erstellt nur Entwürfe für Dinge, die ohne diese Information erledigt werden können, zum Beispiel eine Antwort, die einen Termin bestätigt. Einen Entwurf, der nur sagt, dass die Antwort noch kommt, erstellt sie nicht.
- Über **Erneut versuchen** wird die Aufgabe noch einmal ausgeführt. **Änderungen anfragen** bittet deine Machine, etwas anderes zu tun. Bei einer festgefahrenen Aufgabe wird zuerst **Erneut versuchen** angezeigt. Unter **Details** siehst du, was deine Machine versucht hat.
- Wenn die Aufgabe festhängt, weil der Durchlauf selbst fehlgeschlagen ist, versucht deine Machine nach einem Update automatisch noch einmal, sie auszuführen.
- Deine Machine versucht einen fehlgeschlagenen Durchlauf höchstens zweimal automatisch erneut. Danach wartet sie auf etwas Neues, zum Beispiel eine neue Nachricht oder deine Nachricht im Chat, oder darauf, dass du **Erneut versuchen** drückst.
- Während deine Machine eine Aufgabe vorbereitet, steht in der Aufgabe in einfachen Worten, was sie gerade tut, zum Beispiel „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird erstellt“. Die einzelnen Schritte findest du im Chat der Aufgabe.
- Eine Aufgabe mit dem Status **Wird vorbereitet…** startet innerhalb weniger Sekunden. Wenn sie warten muss, steht dort warum und ungefähr wie lange, zum Beispiel „Startet nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, damit weniger Nutzung anfällt. **Ausführen** wird trotzdem angezeigt. Drück darauf, um die Aufgabe sofort und vor den anderen zu starten. Nichts wird ohne deine Zustimmung gesendet. Wenn das Nutzungslimit deines KI-Tarifs erreicht ist, steht das bei Ausführen. Die Aufgabe startet, sobald das Limit zurückgesetzt wird.
- Wenn eine Website eine Anmeldung verlangt, drück **Anmelden** oder **Browser öffnen** und melde dich dort an. Deine Machine macht dann automatisch weiter. Falls nicht, drück **Weiter**.
- Ein Code, der an dein Handy gesendet wird, oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was benötigt wird. Danach kannst du **Weiter** oder **Erneut versuchen** drücken. Wenn eine Quelle nicht verbunden ist, zum Beispiel Slack, wird **Slack verbinden** in der Aufgabe angezeigt. Deine Machine macht automatisch weiter, sobald Slack verbunden ist.
