## Was „Ausführen“ macht

**Ausführen** bittet deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie verwendet deine Konten und ihren eigenen Browser, so wie du es tun würdest.

Während sie im Browser arbeitet, zeigen die Aufgabe und ihr Chat diese Seite live, auch zwischen einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt, mit **Stoppen**: Einmal drücken beendet diesen Durchlauf sofort.

Vor einer Nachfassnachricht oder einer Übergabe prüft sie, ob neuere Antworten eingegangen sind, auch von einem Teammitglied. Wenn die Sache bereits erledigt ist, steht das in der Aufgabe. Wenn sie ein Dokument oder eine Seite geändert hat, enthält die Aufgabe einen Link dazu.

Wenn eine schwierige Aufgabe auf einer Website oder in einem Workflow klappt, speichert deine Machine die Schritte als Skill, ohne persönliche Angaben. Bei späteren Aufgaben auf dieser Website dienen sie als Anleitung, aber nie als Erlaubnis: Gesendet oder bezahlt wird weiterhin erst, wenn du zustimmst. Du findest sie unter **Einstellungen > Skills** mit dem Hinweis **Aus einer Aufgabe gelernt**.

Wenn die Schritte eines solchen Skills bei drei Aufgaben hintereinander nicht funktionieren, schaltet deine Machine ihn aus. Er bleibt ausgeschaltet, bis eine spätere Aufgabe zeigt, was jetzt funktioniert, oder du ihn wieder einschaltest.

## Nichts wird ohne dein Ja gesendet

- Eine Antwort kommt als Entwurf zurück. **Prüfen und senden** öffnet ihn, sodass du ihn bearbeiten kannst. Er wird erst gesendet, wenn du auf **Jetzt senden** drückst.
- Bei zwei oder mehr E-Mails in einer Aufgabe kannst du sie alle über eine Schaltfläche im Chat der Aufgabe prüfen. Sie werden nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten, und im letzten Schritt werden alle gesendet. Jede E-Mail wird erst dann als gesendet angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chat-Nachricht ist einfacher Text.
- Mit **Änderungen anfragen** im selben Fenster kannst du sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe wird diese E-Mail geöffnet.
- Ein Schritt, der etwas verbindlich abschließt, etwa Absenden, Bezahlen oder Buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, warten die anderen weiterhin. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen dir, was ein solcher Schritt sendet, bevor du darauf tippst. Bei einer Kalendereinladung siehst du Titel, Uhrzeit, Gäste und ob ein Besprechungslink hinzugefügt wird.
- Verbundene Kalender werden bei der Suche nach einem passenden Zeitpunkt berücksichtigt: Bevor deine Machine Zeiten vorschlägt, liest sie deine Termine an den betreffenden Tagen.
- Ein Entwurf wird im Chat einer Aufgabe nie mit derselben Nachricht gesendet, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** als **Vorbereitet**. In der Liste steht einmalig, dass nichts gesendet wird, bis du zustimmst. **Vorbereitet** bedeutet, dass ein Entwurf oder Ergebnis zur Bestätigung bereit ist. Wenn die Arbeit ohne Entwurf oder Ergebnis endet, weil deine Machine dich braucht, etwa wegen einer Entscheidung, einer fehlenden Angabe, einer Anmeldung oder einer Auswahl, wird die Aufgabe stattdessen als **Braucht dich** angezeigt, mit einer Zeile dazu, was benötigt wird. Das gilt auch, wenn sie nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“). Dann steht **Ausführen** an erster Stelle. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Ein Entwurf wird erst dann als gesendet angezeigt, wenn er tatsächlich rausgegangen ist.
- Auch bei einem Entwurf, der noch nicht verwendet werden kann, etwa einem Angebot ohne Preis, wird **Braucht dich** angezeigt: Die Frage steht in der Zeile und führt zu **Antworten**. Der Entwurf bleibt erhalten. **Senden** findest du unter **⋯** oder **Entwurf kopieren** über den Schaltflächen. Ergänze selbst, was fehlt, dann wird der Status wieder **Vorbereitet**.
- Bei einer Zwischenmeldung, die nur verspricht, die Arbeit zu erledigen („Ich melde mich mit dem Angebot“), wird **Braucht dich** angezeigt: „Zwischenmeldung bereit. Noch zu erledigen: Angebot senden.“ **Senden** steht weiterhin an erster Stelle, und die Aufgabe bleibt danach offen.
- Ein Entwurf, der so gesendet werden kann, bleibt **Vorbereitet**. Wenn ein Punkt noch verbessert werden könnte, steht das in der Zeile: „Der Entwurf ist bereit. Eine Frage: …“.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Über **Mehr anzeigen** oder durch Tippen auf den Text öffnest du den Rest. Unter **Prüfen und senden** wird immer der vollständige Entwurf angezeigt.

Je nach Quelle kann deine Machine eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X senden. Im Artikel zu jeder Verbindung steht, was sie senden kann.

## E-Mail bearbeiten

- Verwende die Schaltflächen über dem Text oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Es gibt auch Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link braucht eine Adresse, die mit https:// beginnt. Eingefügter Text wird ohne Farben und Bilder als einfacher Text übernommen.
- Formatierungen, die eine E-Mail nicht übertragen kann, werden zuerst entfernt. Die Nachricht zeigt dir dann, wie sie gesendet wird. Drücke erneut auf **Jetzt senden**, um sie zu senden.
- Die E-Mail wird genau so gesendet, wie sie angezeigt wird, und zusätzlich als einfacher Text für E-Mail-Apps, die keine Formatierung anzeigen.

## Wenn es nicht geht

- „Das kann von hier aus nicht gesendet werden.“ bedeutet, dass du den Entwurf mit **Entwurf kopieren** kopierst und selbst sendest.
- Bei **Braucht dich**, wenn noch nichts gesendet, geöffnet oder gelesen werden kann, steht **Antworten** an erster Stelle: Sag, was benötigt wird, dann macht deine Machine weiter. Wenn nur du einen Schritt ausführen kannst, etwa eine Zahlung bei deiner Bank, steht dort **Als erledigt markieren**.
- **Braucht deine Hilfe** bedeutet, dass eine Frage offen ist: **Antworten** darauf. **Hängt fest** bedeutet, dass die Aufgabe ohne offene Frage angehalten wurde. In der Aufgabe steht, warum.
- Wurden mehrere Dinge gefragt? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, das manchmal mit deiner letzten Antwort vorausgefüllt ist. Über **Antworten** schickst du alle Antworten zusammen ab.
- Hat dich jemand um Informationen oder Dateien gebeten? Deine Machine entwirft eine Antwort mit den gefundenen Informationen und fragt dich nur nach dem Rest.
- Fehlt etwas, das nur du hast? Deine Machine fragt dich danach und entwirft nur, was auch ohne diese Angabe gesendet werden kann, etwa eine Antwort zur Bestätigung eines Termins. Sie entwirft keine Antwort, die nur sagt, dass noch etwas kommt.
- Mit **Erneut versuchen** wird die Aufgabe noch einmal ausgeführt. Mit **Änderungen anfragen** kannst du um etwas anderes bitten. Bei einer festgefahrenen Aufgabe steht **Erneut versuchen** an erster Stelle. Unter **Details** siehst du, was deine Machine versucht hat.
- Ist die Aufgabe fehlgeschlagen, weil der Durchlauf selbst nicht geklappt hat? Nachdem deine Machine aktualisiert wurde, versucht sie die Aufgabe noch einmal von selbst.
- Einen fehlgeschlagenen Durchlauf wiederholt deine Machine höchstens zweimal von selbst. Danach wartet sie auf etwas Neues, etwa eine neue Nachricht oder eine Nachricht von dir in ihrem Chat, oder darauf, dass du **Erneut versuchen** auswählst.
- Während der Vorbereitung steht in der Aufgabe in einer einfachen Zeile, was deine Machine gerade macht, etwa „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird geschrieben“. Die einzelnen Schritte findest du im Chat der Aufgabe.
- Eine als **Wird vorbereitet…** markierte Aufgabe beginnt innerhalb weniger Sekunden. Wenn sie warten muss, nennt sie den Grund und ungefähr, wann es weitergeht, etwa „Beginnt nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du darum bittest, kann warten, damit weniger Nutzung anfällt. **Ausführen** wird trotzdem angezeigt: Drücke darauf, um die Aufgabe sofort und vor den anderen zu starten. Nichts wird gesendet, bis du zustimmst. Wenn das Nutzungslimit deines KI-Plans erreicht ist, wird das bei **Ausführen** angezeigt. Die Aufgabe startet, sobald das Limit zurückgesetzt wird.
- Möchte eine Website, dass du dich anmeldest? Drücke auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Danach macht deine Machine selbstständig weiter. Falls nicht, drücke auf **Weiter**: Deine Machine prüft zuerst noch einmal ihren Browser. Wenn die Website dort weiterhin die Anmeldung verlangt, teilt sie dir das mit, statt von vorn anzufangen.
- Ein Code, der an dein Handy gesendet wird, oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was benötigt wird. Wähle dann **Weiter** oder **Erneut versuchen**. Wenn eine Quelle nicht verbunden ist, etwa Slack, wird **Slack verbinden** in der Aufgabe angezeigt. Sobald Slack verbunden ist, macht deine Machine selbstständig weiter.
