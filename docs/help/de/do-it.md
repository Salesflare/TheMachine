## Was „Ausführen“ macht

Mit **Ausführen** bittest du deine Machine, die Aufgabe vorzubereiten: eine Antwort zu entwerfen, etwas nachzuschlagen oder ein Formular auszufüllen. Sie nutzt dafür deine Konten und ihren eigenen Browser, so wie du es auch tun würdest.

Während deine Machine im Browser arbeitet, zeigen die Aufgabe und ihr Chat die Seite live an, auch zwischen den einzelnen Schritten, bis sie dort fertig ist. Klicke auf das Bild, um den Browser zu öffnen. In der Aufgabe wird er größer angezeigt. Dort kannst du auf **Stoppen** klicken, um den aktuellen Durchlauf sofort zu beenden.

Vor einer Nachfassnachricht oder einer Übergabe prüft deine Machine, ob es neuere Antworten gibt, auch von Teammitgliedern. Wenn die Aufgabe bereits erledigt ist, steht das in der Aufgabe. Wenn deine Machine ein Dokument oder eine Seite geändert hat, enthält die Aufgabe einen Link dazu.

Wenn deine Machine eine knifflige Aufgabe auf einer Website oder in einem Workflow erfolgreich erledigt, speichert sie die Schritte als Skill, ohne persönliche Angaben. Spätere Aufgaben auf dieser Website erhalten den Skill als Anleitung, aber nie als Erlaubnis: Zum Verschicken oder Bezahlen brauchst du weiterhin dein Okay. Die Skills findest du unter **Einstellungen > Skills** mit dem Hinweis **Aus einer Aufgabe gelernt**.

Wenn die Schritte eines solchen Skills bei drei Aufgaben hintereinander nicht funktionieren, schaltet deine Machine ihn aus. Das bleibt so, bis eine spätere Aufgabe zeigt, was jetzt funktioniert, oder du ihn wieder einschaltest.

## Ohne dein Okay wird nichts verschickt

- Eine Antwort wird als Entwurf bereitgestellt. Mit **Prüfen und senden** öffnest du ihn und kannst ihn bearbeiten. Verschickt wird er erst, wenn du auf **Jetzt senden** klickst.
- Gibt es in einer Aufgabe mindestens zwei E-Mails, kannst du sie alle über eine Schaltfläche im Chat der Aufgabe prüfen. Sie werden nacheinander angezeigt. Mit **Weiter** kommst du zur nächsten. Im letzten Schritt werden sie alle verschickt. Jede E-Mail wird erst dann als verschickt angezeigt, wenn sie tatsächlich rausgegangen ist.
- Eine E-Mail wird so angezeigt, wie sie aussehen wird, einschließlich Fettdruck, Listen und Links. Eine Slack- oder Chatnachricht ist reiner Text.
- Mit **Änderungen anfragen** kannst du im selben Fenster sagen, was geändert werden soll. Deine Machine erstellt den Entwurf dann neu.
- Eine Antwort bezieht sich auf die neueste E-Mail im Thread. Über die Quelle der Aufgabe öffnest du diese E-Mail.
- Ein Schritt, der etwas verbindlich macht, etwa etwas einzureichen, zu bezahlen oder zu buchen, wartet auf deine Bestätigung oder darauf, dass du im Chat darum bittest. Wenn du einen Schritt bestätigst, bleiben die anderen weiterhin offen. Die Aufgabe wird erst geschlossen, wenn alle Schritte erledigt sind.
- Die Aufgabe und ihr Chat zeigen, was bei einem solchen Schritt verschickt wird, bevor du darauf tippst. Bei einer Kalendereinladung werden Titel, Uhrzeit, Gäste und die Information angezeigt, ob ein Meeting-Link hinzugefügt wird.
- Verbundene Kalender werden bei der Suche nach einem passenden Termin berücksichtigt. Deine Machine liest die Termine an den betreffenden Tagen, bevor sie dir Zeiten vorschlägt.
- Ein Entwurf wird im Chat einer Aufgabe niemals mit derselben Nachricht verschickt, in der er erstellt wurde.
- Bis du zustimmst, wartet die Aufgabe unter **Für dich** mit dem Status **Vorbereitet**. In der Liste steht einmalig, dass nichts verschickt wird, bis du zustimmst. **Vorbereitet** bedeutet, dass ein Entwurf oder ein Ergebnis zur Bestätigung bereitsteht. Endet die Arbeit ohne Entwurf oder Ergebnis, weil deine Machine etwas von dir braucht, etwa eine Entscheidung, eine fehlende Angabe, eine Anmeldung oder eine Auswahl, zeigt die Aufgabe stattdessen **Braucht dich** und erklärt in einer Zeile, was benötigt wird. Das gilt auch, wenn deine Machine nur geantwortet oder etwas erklärt hat („Beantwortet. Noch nichts erledigt.“). Dann wird zuerst **Ausführen** angezeigt. Dasselbe gilt für die Benachrichtigung und die morgendliche Zusammenfassung. Dass ein Entwurf verschickt wurde, steht dort erst, wenn er tatsächlich rausgegangen ist.
- Auch bei einem Entwurf, der noch nicht verwendet werden kann, etwa einem Angebot ohne Preis, steht **Braucht dich**. Die Frage steht in der Zeile und **Antworten** führt dich weiter. Der Entwurf bleibt in der Aufgabe. **Senden** findest du unter **⋯** oder **Entwurf kopieren** oberhalb der Schaltflächen. Ergänze selbst, was fehlt, und der Status lautet wieder **Vorbereitet**.
- Bei einer Zwischenmeldung, die nur verspricht, die Arbeit zu erledigen („Ich melde mich mit dem Angebot“), steht **Braucht dich**: „Zwischenmeldung bereit. Noch zu erledigen: Angebot senden.“ **Senden** steht weiterhin an erster Stelle, und die Aufgabe bleibt danach offen.
- Ein Entwurf, der so verschickt werden kann, bleibt **Vorbereitet**. Falls ein Punkt noch verbessert werden könnte, steht das in der Zeile: „Der Entwurf ist bereit. Eine Frage noch: …“.
- Bei einem langen Entwurf werden die ersten drei Zeilen angezeigt. Über **Mehr anzeigen** oder durch Tippen auf den Text öffnest du den Rest. Mit **Prüfen und senden** wird immer der vollständige Entwurf angezeigt.

Je nach Quelle kann deine Machine eine E-Mail, eine Slack-Direktnachricht oder eine Nachricht über WhatsApp, Telegram, LinkedIn oder X verschicken. Im Artikel zu jeder Verbindung steht, was sie verschicken kann.

## E-Mail bearbeiten

- Nutze die Schaltflächen oberhalb des Textes oder `Ctrl B` für Fettdruck, `Ctrl I` für Kursivschrift und `Ctrl K` für einen Link (`⌘` auf einem Mac). Es gibt auch Schaltflächen für Aufzählungen und nummerierte Listen.
- Ein Link muss mit https:// beginnen. Eingefügter Text wird ohne Farben und Bilder als reiner Text übernommen.
- Formatierungen, die eine E-Mail nicht unterstützt, werden zuerst entfernt. Die Nachricht zeigt dir, wie sie verschickt wird. Klicke noch einmal auf **Jetzt senden**, um sie zu verschicken.
- Die E-Mail wird genau so verschickt, wie sie angezeigt wird. Dazu gibt es eine Textversion für Mail-Apps, die keine Formatierungen anzeigen.

## Wenn es nicht geht

- „Das kann nicht von hier aus verschickt werden.“ bedeutet, dass du den Entwurf über **Entwurf kopieren** kopieren und selbst verschicken musst.
- Bei **Braucht dich**, wenn noch nichts verschickt, geöffnet oder gelesen werden kann, führt **Antworten** weiter: Sag, was benötigt wird, und deine Machine macht weiter. Wenn du einen Schritt selbst erledigen musst, etwa eine Zahlung bei deiner Bank, führt **Als erledigt markieren** weiter.
- **Braucht deine Hilfe** bedeutet, dass deine Machine eine Frage hat: **Antworten**. **Hängt fest** bedeutet, dass sie ohne Frage angehalten hat. In der Aufgabe steht warum.
- Wurden mehrere Fragen gestellt? Jede Frage hat eigene Auswahlmöglichkeiten oder ein kurzes Eingabefeld, das manchmal schon mit deiner letzten Antwort ausgefüllt ist. Mit **Antworten** werden alle Antworten zusammen abgeschickt.
- Bittet dich jemand um Informationen oder Dateien? Deine Machine entwirft eine Antwort mit den gefundenen Angaben und fragt dich nur nach dem Rest.
- Fehlt etwas, das nur du hast? Deine Machine fragt dich danach und entwirft nur, was auch ohne diese Angabe verschickt werden kann, etwa eine Antwort, die ein Datum bestätigt. Sie entwirft keine Antwort, die nur sagt, dass die fehlende Angabe noch kommt.
- **Erneut versuchen** startet die Aufgabe noch einmal. Mit **Änderungen anfragen** kannst du um etwas anderes bitten. Bei einer Aufgabe, die feststeckt, wird zuerst **Erneut versuchen** angezeigt. Unter **Details** siehst du, was deine Machine versucht hat.
- Ist die Aufgabe fehlgeschlagen, weil der Durchlauf selbst nicht funktioniert hat? Nach einer Aktualisierung deiner Machine versucht sie die Aufgabe automatisch noch einmal.
- Deine Machine versucht einen fehlgeschlagenen Durchlauf höchstens zweimal automatisch erneut. Danach wartet sie auf etwas Neues, etwa eine neue Nachricht, deine Nachricht im Chat oder einen Klick auf **Erneut versuchen**.
- Während deine Machine die Aufgabe vorbereitet, steht in der Aufgabe in einer kurzen Zeile, was sie gerade macht, etwa „E-Mail wird gelesen“, „PDF wird gelesen“ oder „Entwurf wird geschrieben“. Die einzelnen Schritte stehen im Chat der Aufgabe.
- Eine als **Wird vorbereitet…** markierte Aufgabe startet innerhalb weniger Sekunden. Wenn sie warten muss, steht dort warum und ungefähr wie lange, etwa „Startet nach der aktuellen Aufgabe“.
- Eine Aufgabe, die deine Machine vorbereitet, bevor du sie anforderst, kann warten, um die Nutzung zu sparen. **Ausführen** wird trotzdem angezeigt. Klicke darauf, um sofort und vor den anderen Aufgaben zu starten. Ohne dein Okay wird nichts verschickt. Wenn das Nutzungslimit deines KI-Tarifs erreicht ist, weist **Ausführen** darauf hin. Die Aufgabe startet, sobald das Limit zurückgesetzt wird.
- Möchte eine Website, dass du dich anmeldest? Klicke auf **Anmelden** oder auf **Browser öffnen** und melde dich dort an. Deine Machine macht dann automatisch weiter. Falls sie nicht weitermacht, klicke auf **Weiter**.
- Ein Code, der an dein Handy geschickt wird, oder eine fehlende Berechtigung hält die Aufgabe an. In der Aufgabe steht, was benötigt wird. Klicke dann auf **Weiter** oder **Erneut versuchen**. Ist eine Quelle nicht verbunden, etwa Slack, führt **Slack verbinden** in der Aufgabe weiter. Sobald Slack verbunden ist, macht deine Machine automatisch weiter.
