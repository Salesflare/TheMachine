## Was es liest

Storys in deinem Shortcut-Workspace, die ihren Status ändern, mit ihren Verantwortlichen und Fristen.

## Was es tun kann

Nichts in Shortcut. Es liest nur, obwohl Shortcut-Tokens mehr könnten.

## Verbinden

1. Öffne in Shortcut Settings, Account, API Tokens und erstelle ein Token.
2. Auf einer gehosteten Machine: Öffne deine Einrichtungsseite unter app.themachine.computer/setup, geh zu **Weitere Quellen** und öffne Shortcut. Auf deinem eigenen Computer: **Verbindungen**, **+ Hinzufügen**, Shortcut, oder `assistant connect shortcut`.
3. Gib die Adresse oder den Slug deines Workspace an, füge das Token ein und tippe dann auf **Verbinden**.

## Entfernen

- Im Dashboard: **Verbindungen**, Shortcut öffnen, **Details**, dann **Trennen**. Was es schon reingebracht hat, bleibt.
- Auf einer gehosteten Machine kannst du auch auf deiner Einrichtungsseite daneben auf **Entfernen** tippen.

## In Shortcut widerrufen

Lösche das Token auf derselben Seite API Tokens.
