Een gehoste Machine draait in de cloud, in de EU, alleen voor jou. Wij houden hem draaiend en up-to-date.

## Aanmelden

1. Druk op app.themachine.computer op **Doorgaan met Google** of **Doorgaan met Microsoft**. Zo maak je je account aan.
2. Scan de code met een authenticator-app, typ de zes cijfers en druk op **Aanzetten**. Een passkey kan later.
3. Kies de grootte en de naam van je Machine, en voeg dan je betaalkaart toe. De eerste {trial_days} dagen zijn gratis en er wordt niets aangerekend voordat ze voorbij zijn.

## Je setuppagina

Je Machine start, en daarna leidt de setuppagina je door de rest, stap voor stap:

1. **Mail en agenda**: koppel Google of Microsoft. Dat kan terwijl je Machine start. Na het inloggen zegt de stap dat hij bezig is tot je Machine geïnstalleerd is en je mail gelezen heeft, ongeveer een minuut. Zie [Gmail](gmail.md) en [Microsoft](microsoft.md).
2. **Je AI**: log in met ChatGPT of Claude, of gebruik een sleutel van je AI-aanbieder. Zie [ChatGPT](chatgpt.md).
3. Reviews gaan vanzelf aan. De eerste to-do's komen uit je nieuwste mail, daarna uit je laatste 7 dagen.

Onder **Voeg later meer toe** staan de optionele: **Meer bronnen** zoals Slack, WhatsApp of GitHub, [Telegram](telegram.md), [Codex](hand-to-agent.md) en de koppeling met je browser. Geen ervan is nodig om te beginnen. Je dashboard stelt ze voor als ze helpen, bijvoorbeeld GitHub zodra er mail van blijft binnenkomen.

Zodra je Machine klaar is, staat **Open je dashboard** bovenaan de pagina. Zet het op het beginscherm van je telefoon voor meldingen: zie [De app installeren en meldingen aanzetten](phone-app.md).

## Vraag een bron aan

Mis je een bron? Vul bij **Bronnen**, onder **Vraag een bron aan**, de dienst in en wat er gelezen moet worden, en druk op **Bouwen**. Je eigen AI schrijft en test hem op je Machine. Deel je hem, dan opent The Machine er een pull request voor op GitHub voor je. Een GitHub-account is niet nodig; [verbind GitHub](github.md) om als co-auteur genoemd te worden.

## Later terugkomen

Je setuppagina blijft op app.themachine.computer/setup. Voeg daar altijd bronnen toe of verwijder ze. In het dashboard heeft **Instellingen** de knop **Account openen**.
