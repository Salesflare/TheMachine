## Wat het leest

Stories in je Shortcut-workspace die van status veranderen, met hun eigenaars en deadlines.

## Wat het kan doen

Niets in Shortcut. Het leest alleen, ook al kunnen Shortcut-tokens meer.

## Koppelen

1. Op een gehoste Machine: open je setuppagina op app.themachine.computer/setup, ga naar **Meer bronnen** en open Shortcut. Op je eigen computer: **Koppelingen**, **Projecten en code**, Shortcut, of `assistant connect shortcut`.
2. Druk op **Haal je token op**. Shortcut opent zijn pagina API Tokens in een nieuw tabblad: maak een token aan en kopieer het.
3. Plak het en druk op **Verbinden**. Het token wordt meteen gecontroleerd, en je ziet als wie en in welke workspace het gekoppeld is.

In meer dan één Shortcut-workspace? Een token hoort bij één workspace, dus schakel eerst in Shortcut naar die workspace.

## Verwijderen

- In het dashboard: **Koppelingen**, open Shortcut, **Details**, dan **Ontkoppelen**. Wat al binnengehaald is, blijft.
- Op een gehoste Machine kun je ook op **Verwijderen** ernaast drukken op je setuppagina.

## Intrekken in Shortcut

Verwijder het token op dezelfde pagina API Tokens.
