## Wat het leest

Het logboek van je OpenClaw Gateway: mislukte runs, geweigerde overdrachten, Telegram-berichten die niet verstuurd zijn, en de eigen fouten van The Machine. Een to-do laat je weten wanneer er iets hersteld moet worden.

## Fixes die een update opzij zette

Als The Machine bijwerkt en een van zijn eigen fixes niet meer past op de nieuwe versie, zet de update die fix opzij en gaat verder, zodat je Machine nooit op een oude versie blijft. Een to-do, **Doe een fix opnieuw die de update opzij zette**, noemt de fix. Vraag om hem opnieuw te doen op de nieuwe versie, of sluit de to-do.

## Wat het kan doen

Niets. Het leest alleen het logboek op je eigen Machine.

## Koppelen

- Op een gehoste Machine staat het op je setuppagina, onder **Meer bronnen**, als OpenClaw Gateway log. Eén per Machine.
- Op je eigen computer: voer `assistant connect gateway` uit.

## Verwijderen

- In het dashboard: **Koppelingen**, open het, **Details**, dan **Ontkoppelen**.
- Op een gehoste Machine kun je ook op **Verwijderen** ernaast drukken op je setuppagina.

Je hoeft nergens anders iets te verwijderen.
