Tik bovenaan op **Help**, naast **Instellingen**, en stel je vraag in je eigen woorden, bijvoorbeeld: "Hoe snooze ik een to-do?". Enter verstuurt je vraag, Shift+Enter voegt een regel toe. Help antwoordt in de taal van je app of in de taal waarin je schrijft. Links naar helppagina’s openen meteen in het paneel, in die taal.

## Waar de antwoorden vandaan komen

Help leest de helppagina’s die bij je vraag passen en gebruikt de code van de app voor alles wat die pagina’s niet behandelen. Elk antwoord linkt naar de pagina’s die zijn gebruikt.

Help draait op het eigen model van je Machine als een korte, aparte chat. Onder het berichtvak kun je een ander model of denkwerkniveau kiezen voor deze Help-chat (zie [Model](model.md)). Alleen je vraag en de bijbehorende pagina’s worden gebruikt. Je berichten, personen en instellingen niet.

Help stemt het antwoord af op jouw niveau: eenvoudige woorden voor de meeste mensen en meer details als je vragen technisch zijn. Help schat je niveau in op basis van je configuratie, je rol en hoe je vragen stelt. Alleen die inschatting wordt gebruikt.

Help wijst eerst op wat The Machine al kan en stelt alleen een skill voor als er geen ingebouwde functie is die aan je vraag voldoet. Zie [Maak het eigen](personalize.md).

## Wat het team ziet

Om de Help te verbeteren, telt je Machine een paar woorden over het onderwerp van elke vraag, zoals "een to-do snoozen". Je vraag en het antwoord worden nooit gedeeld, en ook geen namen, adressen of nummers. Alleen woorden uit deze helppagina’s. Eén keer per dag worden de tellingen naar **Het team van The Machine** gestuurd, zonder je accountgegevens.

Je kunt dit uitzetten met **Delen wat aan Help gevraagd wordt** onder **Instellingen** > **Beveiliging** > **Het team van The Machine**. Je kunt ook het beveiligingsniveau **Voorzichtig** kiezen ([beveiligingsniveaus](security-levels.md)). Hiervoor is [The Machine Network](/network) nodig. Alles wat nog niet is verstuurd, wordt verwijderd.

## Wat Help niet kan

Help beantwoordt vragen. Het kan je gegevens niet zien en verandert niets. In plaats daarvan vertelt Help waar je moet tikken.

Als wat je beschrijft klinkt als iets dat niet werkt, in plaats van een vraag over hoe je iets doet, eindigt het antwoord met **Deze bug melden**. Daarmee open je **Een bug melden**, met een korte beschrijving van wat je hebt gedaan, wat je verwachtte en wat er gebeurde. De ondersteuningsmelding is aangevinkt. Je kunt daar alles aanpassen. Er wordt niets verstuurd totdat je op **Versturen** drukt.

**Een bug melden** is ook een eigen tabblad in hetzelfde paneel. Zie [Ondersteuning krijgen](get-support.md#report-a-bug).
