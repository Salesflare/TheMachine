## Definir as regras

Na aba **Fleet**, abra Compartilhamento. Cada tipo de pergunta tem uma regra:

- Perguntar antes: você vê cada pergunta e decide.
- Sempre: a sua Machine responde sozinha.
- Nunca: ela recusa.
- Nomes: só nomes, sem detalhes.

Ela nunca compartilha o conteúdo de e-mails, nem o assunto das suas reuniões. "Diferente para alguém? Adicione uma exceção" define uma regra para uma pessoa.

As regras só mudam no painel, nunca por uma mensagem.

## A primeira vez que alguém pergunta

Uma pergunta que precisa de você chega como uma tarefa, com **Compartilhar uma vez**, **Sempre compartilhar**, **Recusar** ou **Nunca compartilhar**.
