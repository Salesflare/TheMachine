## 실행하면 하는 일

**실행**을 누르면 The Machine이 할 일을 준비해요. 답장 초안을 작성하고, 정보를 찾아보고, 양식을 작성해요. 직접 작업할 때처럼 본인 계정과 자체 브라우저를 사용해요.

브라우저에서 작업하는 동안 할 일과 채팅에 해당 페이지가 실시간으로 표시돼요. 단계가 진행되는 동안에도 표시되며, 브라우저에서 작업이 끝날 때까지 계속돼요. 화면을 클릭하면 브라우저가 열려요. 할 일에서는 화면이 더 크게 열리고 **중지**가 표시돼요. 한 번 누르면 해당 실행이 바로 끝나요.

후속 작업이나 인계 전에 팀원의 답장을 포함해 새 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경하면 할 일에 링크가 표시돼요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 돌아와요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열려요. **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에 이메일이 두 개 이상 있으면 채팅에서 버튼 하나로 모두 검토할 수 있어요. 이메일이 하나씩 차례로 표시되고, **다음**을 누르면 마지막 단계에서 모두 전송돼요. 각 이메일은 실제로 전송된 후에만 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크가 적용된 모습 그대로 표시돼요. Slack 메시지나 채팅 메시지는 일반 텍스트예요.
- 같은 창에서 **수정 요청**을 누르고 변경할 내용을 말하면 The Machine이 초안을 다시 작성해요.
- 답장은 해당 대화에서 가장 최근에 받은 이메일에 대한 답변이고, 할 일의 출처를 누르면 그 이메일이 열려요.
- 제출, 결제, 예약처럼 확정되는 단계는 확인을 기다려요. 채팅에서 해당 작업을 요청해도 돼요. 한 단계를 확인해도 다른 단계는 계속 대기해요. 모든 단계가 끝나야 할 일이 완료돼요.
- 할 일의 채팅에서 초안을 작성한 메시지가 그대로 전송되는 일은 없어요.
- 승인하기 전까지 할 일은 **나를 위한** 아래에서 **준비됨** 상태로 대기해요. 목록에는 승인하기 전에는 아무것도 전송되지 않는다는 안내도 표시돼요. 아직 필요한 정보가 있으면 **조치가 필요해요**라고 표시돼요. 답장은 실제로 전송된 후에만 전송됐다고 표시돼요.
- 긴 초안은 처음 세 줄만 표시돼요. **더 보기**를 누르거나 텍스트를 탭하면 나머지가 열려요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지 또는 WhatsApp, Telegram, LinkedIn, X 메시지를 보낼 수 있어요. 각 연동의 도움말 문서에서 전송할 수 있는 항목을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위에 있는 버튼을 사용하거나, 굵게 표시하려면 `Ctrl B`, 기울임꼴로 표시하려면 `Ctrl I`, 링크를 추가하려면 `Ctrl K`을 사용해요. Mac에서는 `⌘`를 사용해요. 글머리 기호 목록과 번호 매기기 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거하고, 전송될 메시지의 모습을 보여줘요. **지금 보내기**를 다시 누르면 전송돼요.
- 이메일은 화면에 표시된 그대로 전송돼요. 서식을 표시하지 않는 메일 앱을 위해 일반 텍스트 사본도 함께 전송돼요.

## 할 수 없는 경우

- "여기서 전송할 수 없어요."라는 메시지가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 보내야 해요.
- **도움이 필요해요**는 질문이 있다는 뜻이에요. **답변**을 눌러 답해 주세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 중단된 이유가 표시돼요.
- 질문이 여러 개라면 각 질문에 선택지가 있거나 짧은 입력란이 표시돼요. 이전에 답한 내용이 입력란에 미리 채워져 있을 수도 있어요. **답변**을 누르면 답변을 모두 한꺼번에 전송해요.
- 본인만 알고 있는 정보가 없으면 해당 정보를 요청하고, 날짜를 확인하는 답장처럼 그 정보 없이도 보낼 수 있는 내용만 초안으로 작성해요. 나중에 보내겠다는 말만 담긴 답장은 작성하지 않아요.
- **다시 시도**를 누르면 작업을 한 번 더 실행해요. **수정 요청**을 누르면 다른 작업을 요청할 수 있어요. 멈춘 할 일에서는 **다시 시도**가 먼저 표시되고, **세부 정보**에서 시도한 내용을 확인할 수 있어요.
- 준비하는 동안 할 일에는 The Machine이 하는 일이 "메일 읽는 중", "PDF 읽는 중", "초안 작성 중"처럼 간단히 표시돼요. 자세한 단계는 할 일의 채팅에서 확인할 수 있어요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 대기해야 하는 경우에는 "현재 작업이 끝난 후 시작돼요"처럼 이유와 대략적인 시작 시점을 알려줘요.
- 사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 누르고 브라우저에서 로그인해요. 그러면 작업이 자동으로 계속돼요. 계속되지 않으면 **계속**을 누르세요.
- 휴대폰으로 전송된 코드가 필요하거나 권한이 없으면 작업이 멈춰요. 할 일에 필요한 내용이 표시되고, 그다음 **계속** 또는 **다시 시도**를 누르면 돼요. Slack처럼 연결되지 않은 출처의 경우 할 일에 **Slack 연결**이 표시돼요. Slack을 연결하면 작업이 자동으로 계속돼요.
