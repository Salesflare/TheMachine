## 실행하면 무엇을 하나요

**실행**을 누르면 내 Machine이 할 일을 준비해요. 답장 초안을 작성하고, 필요한 내용을 찾아보고, 양식을 작성해요. 직접 할 때처럼 내 계정과 자체 브라우저를 사용해요.

내 Machine이 브라우저에서 작업하는 동안 할 일과 채팅에 해당 페이지가 실시간으로 표시돼요. 단계 사이에도 표시되며, 브라우저에서 작업이 끝날 때까지 계속 보여요. 화면을 클릭하면 브라우저가 열려요. 할 일에서는 화면이 더 크게 열리고 **중지** 버튼이 표시돼요. 한 번 누르면 진행 중인 작업이 즉시 끝나요.

후속 작업이나 인계 전에 팀원의 답장을 포함해 새 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경했으면 할 일에 링크가 표시돼요.

웹사이트나 워크플로에서 복잡한 작업을 완료하면 내 Machine은 누구의 개인 정보도 포함하지 않는 스킬로 작업 단계를 저장해요. 나중에 같은 사이트에서 할 일을 진행할 때 이 단계를 참고하지만, 권한으로 취급하지는 않아요. 전송이나 결제는 여전히 승인을 기다려요. 저장된 스킬은 **설정 > 스킬**에서 **작업에서 배운 점**으로 표시돼요.

어떤 스킬의 단계가 할 일 3개 연속으로 작동하지 않으면 내 Machine이 해당 스킬을 꺼요. 이후 할 일에서 현재 작동하는 방법을 확인하거나 직접 다시 켤 때까지 꺼진 상태로 유지돼요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 돌아와요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열리고, **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에서 이메일을 2개 이상 보내는 경우, 채팅에 모든 이메일을 검토하는 버튼 하나가 표시돼요. 이메일이 하나씩 표시되고 **다음**을 누르면 마지막 단계에서 모두 전송돼요. 각 이메일은 실제로 전송된 뒤에만 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크를 포함해 실제로 표시될 모양으로 보여요. Slack 메시지나 채팅 메시지는 일반 텍스트로 표시돼요.
- 같은 창에서 **수정 요청**을 누르고 바꿀 내용을 말하면 내 Machine이 초안을 다시 작성해요.
- 답장은 해당 대화의 가장 최근 이메일에 답하고, 할 일의 출처를 누르면 그 이메일이 열려요.
- 제출, 결제, 예약처럼 확정하는 단계는 직접 확인하거나 채팅에서 요청할 때까지 대기해요. 한 단계를 확인해도 나머지 단계는 계속 대기해요. 모든 단계를 마쳐야 할 일이 닫혀요.
- 할 일과 채팅에는 그런 단계에서 전송할 내용이 미리 표시돼요. 캘린더 초대에는 제목, 시간, 참석자, 회의 링크 추가 여부가 표시돼요.
- 시간을 찾을 때 연결된 캘린더도 확인해요. 가능한 시간을 제안하기 전에 해당 날짜의 회의를 읽어요.
- 할 일의 채팅에서 초안을 작성하는 메시지와 같은 메시지로 초안을 전송하는 일은 없어요.
- 승인 전까지 할 일은 **내 확인** 아래에서 **준비됨** 상태로 대기하고, 목록에는 승인 전에는 아무것도 전송되지 않는다는 안내가 한 번 표시돼요. **준비됨**은 초안이나 결과를 승인할 수 있는 상태라는 뜻이에요. 결정, 누락된 정보, 로그인, 선택 등 직접 확인할 내용이 있어 결과를 만들지 못한 채 작업이 끝나면, 할 일에 **확인 필요**가 표시되고 필요한 내용이 함께 안내돼요. 답변이나 설명만 제공한 경우에도 같은 상태가 표시돼요. 이때는 "답변했어요. 아직 완료된 작업은 없어요."라는 안내와 함께 **실행**이 표시돼요. 알림과 아침 요약에도 같은 내용이 표시돼요. 초안은 실제로 전송된 뒤에만 전송됐다고 표시돼요.
- 가격이 없는 제안서처럼 아직 사용할 수 없는 초안도 **확인 필요**로 표시돼요. 필요한 질문이 안내되고 **답변하기** 버튼이 표시돼요. 초안은 할 일에 그대로 남고, **보내기**는 **⋯** 아래에, **초안 복사**는 버튼 위에 표시돼요. 빠진 내용을 직접 입력하면 다시 **준비됨** 상태가 돼요.
- 작업을 약속하는 내용만 담은 답장, 예를 들어 "견적을 보내드릴게요"라는 답장은 **확인 필요**로 표시돼요. "일단 답장할 준비가 됐어요. 아직 할 일: 견적 보내기."라는 안내가 표시돼요. **보내기**가 여전히 첫 번째 버튼이고, 답장을 보낸 뒤에도 할 일은 열려 있어요.
- 그대로 보낼 수 있는 초안은 **준비됨** 상태로 유지돼요. 더 다듬을 부분이 있으면 "초안이 준비됐어요. 한 가지 확인할 점: …"이라는 안내가 표시돼요.
- 긴 초안은 처음 3줄만 표시돼요. **더 보기**를 누르거나 텍스트를 누르면 나머지 내용이 열려요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지, WhatsApp, Telegram, LinkedIn 또는 X 메시지를 보낼 수 있어요. 각 서비스 연결 도움말에서 보낼 수 있는 내용을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위의 버튼을 사용하거나, 굵게 표시하려면 `Ctrl B`, 기울임꼴은 `Ctrl I`, 링크는 `Ctrl K`을 사용해요. Mac에서는 `⌘`를 사용해요. 글머리 기호 목록과 번호 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거되고, 메시지가 어떻게 전송될지 표시돼요. **지금 보내기**를 다시 누르면 전송돼요.
- 이메일은 화면에 표시된 그대로 전송되고, 서식을 표시하지 않는 메일 앱을 위한 일반 텍스트 사본도 함께 전송돼요.

## 실행할 수 없는 경우

- "여기에서는 전송할 수 없어요."라는 안내가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 전송해요.
- 보낼 수 있거나 열거나 읽을 수 있는 내용이 없는 상태에서 **확인 필요**가 표시되면 **답변하기**가 먼저 표시돼요. 필요한 내용을 알려주면 작업을 계속해요. 은행 결제처럼 직접 해야 하는 단계에는 **완료로 표시**가 표시돼요.
- **도움이 필요해요**는 질문이 있다는 뜻이에요. **답변하기**를 눌러 답해요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 이유가 표시돼요.
- 질문이 여러 개인가요? 질문마다 선택지나 짧은 입력란이 따로 있고, 이전 답변이 미리 입력돼 있을 수도 있어요. **답변하기**를 누르면 모든 답변을 한꺼번에 보내요.
- 정보나 파일을 요청받았나요? 내 Machine은 찾은 내용을 바탕으로 답변 초안을 작성하고, 나머지 내용만 요청해요.
- 내게만 있는 정보가 빠졌나요? 해당 정보를 요청하고, 날짜 확인 답장처럼 그 정보 없이 보낼 수 있는 내용만 초안으로 작성해요. 단순히 나중에 보내겠다는 답장은 작성하지 않아요.
- **다시 시도**를 누르면 작업을 한 번 더 실행해요. **수정 요청**을 누르면 다른 내용을 요청해요. 멈춘 할 일에는 **다시 시도**가 먼저 표시되고, **세부 정보**를 누르면 시도한 내용을 확인할 수 있어요.
- 작업 실행 자체가 실패해 멈췄나요? 내 Machine이 업데이트된 뒤 해당 할 일을 한 번 더 시도해요.
- 실패한 작업은 자동으로 최대 두 번 다시 시도해요. 그 뒤에는 새 메시지나 채팅에 입력한 내용 같은 새로운 정보가 들어오거나 **다시 시도**를 누를 때까지 대기해요.
- 작업을 준비하는 동안 내 Machine이 하는 일을 "메일 읽는 중", "PDF 읽는 중", "초안 작성 중"처럼 간단한 문구로 표시해요. 자세한 단계는 할 일의 채팅에서 확인할 수 있어요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 하면 이유와 대략적인 시작 시점을 안내해요. 예: "현재 작업이 끝나면 시작해요."
- 요청하기 전에 내 Machine이 준비한 할 일은 사용량을 아끼기 위해 대기할 수 있어요. 그래도 **실행**은 표시돼요. 누르면 다른 할 일보다 먼저 바로 시작돼요. 승인 전에는 아무것도 전송되지 않아요. AI 요금제의 사용량 한도에 도달하면 실행에 한도 도달 안내가 표시되고, 한도가 초기화되면 작업이 시작돼요.
- 웹사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 눌러 브라우저에서 로그인해요. 그러면 작업이 자동으로 계속돼요. 계속되지 않으면 **계속**을 눌러요.
- 휴대폰으로 전송된 코드가 필요하거나 권한이 없으면 작업이 중단돼요. 할 일에 필요한 내용이 표시되고, **계속** 또는 **다시 시도**를 누르면 돼요. Slack처럼 연결되지 않은 서비스는 할 일에서 **Slack 연결**을 누르면 돼요. Slack을 연결하면 작업이 자동으로 계속돼요.
