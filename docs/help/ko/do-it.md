## 실행하면 어떤 일이 있나요?

**실행**을 누르면 내 Machine이 할 일을 준비해요. 답장 초안을 작성하고, 정보를 찾아보고, 양식을 작성해요. 직접 하는 것처럼 내 계정과 내 Machine의 브라우저를 사용해요.

내 Machine이 브라우저에서 작업하는 동안, 할 일과 채팅에 진행 중인 페이지가 실시간으로 표시돼요. 단계 사이에도 작업이 끝날 때까지 표시돼요. 화면을 클릭하면 브라우저가 열려요. 할 일에서는 화면이 더 크게 열리고, **중지** 버튼을 누르면 해당 작업이 바로 끝나요.

후속 작업이나 인계 전에 팀원의 답장을 포함해 새로 온 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경한 경우에는 할 일에 링크가 표시돼요.

사이트나 워크플로에서 까다로운 작업을 성공적으로 마치면, 내 Machine은 개인 정보를 남기지 않고 그 단계를 스킬로 저장해요. 나중에 같은 사이트에서 하는 할 일에는 해당 단계가 안내로 표시되지만, 권한으로 사용되지는 않아요. 전송이나 결제는 계속 승인을 기다려요. 스킬은 **설정 > 스킬**에서 **작업에서 배운 점**으로 표시돼요.

이런 스킬의 단계가 할 일 세 개에서 연달아 작동하지 않으면 내 Machine이 스킬을 꺼요. 나중에 할 일에서 현재 작동하는 방법을 확인하거나 스킬을 다시 켤 때까지 꺼져 있어요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 돌아와요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열리고, **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에 이메일이 두 통 이상 있으면 채팅에 있는 버튼 하나로 모두 검토할 수 있어요. 이메일이 하나씩 표시되고, **다음**을 누르면 마지막 단계에서 모두 전송돼요. 각각 실제로 전송된 뒤에야 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크가 포함된 실제 모양으로 표시돼요. Slack이나 채팅 메시지는 일반 텍스트로 표시돼요.
- 같은 창에서 **수정 요청**을 누르고 변경할 내용을 말하면 내 Machine이 초안을 다시 작성해요.
- 답장은 해당 이메일 대화의 최신 이메일에 회신하고, 할 일의 출처를 누르면 그 이메일이 열려요.
- 제출, 결제, 예약처럼 확정하는 단계는 직접 확인하거나 채팅에서 진행해 달라고 할 때까지 기다려요. 한 단계를 확인해도 나머지 단계는 계속 대기해요. 모든 단계를 마쳐야 할 일이 닫혀요.
- 할 일과 채팅에는 이런 단계에서 전송될 내용이 먼저 표시돼요. 캘린더 초대에는 제목, 시간, 참석자와 회의 링크 추가 여부가 표시돼요.
- 시간을 찾을 때는 연결된 캘린더도 확인해요. 가능한 시간을 제안하기 전에 해당 날짜의 회의를 확인해요.
- 할 일 채팅에서 초안은 초안을 작성한 메시지와 함께 전송되지 않아요.
- 승인할 때까지 할 일은 **내 확인** 아래 **준비됨**으로 표시되고, 목록에는 승인 전에는 아무것도 전송되지 않는다는 안내가 표시돼요. **준비됨**은 승인할 초안이나 결과가 준비됐다는 뜻이에요. 결정이나 누락된 정보, 로그인 또는 선택이 필요해 작업을 끝냈지만 초안이나 결과가 없는 경우에는 대신 **확인 필요**로 표시되고 필요한 내용이 안내돼요. 답변이나 설명만 한 경우("답변했어요. 아직 처리된 내용은 없어요.")에도 먼저 **실행**이 표시되며, 같은 방식으로 안내돼요. 알림과 아침 요약에도 같은 내용이 표시돼요. 초안은 실제로 전송된 뒤에만 전송됐다고 표시돼요.
- 긴 초안은 처음 세 줄만 표시돼요. **더 보기**를 누르거나 텍스트를 탭하면 나머지 내용이 열려요. **검토 후 보내기**를 누르면 언제나 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지, WhatsApp, Telegram, LinkedIn 또는 X 메시지를 전송할 수 있어요. 각 연결에 관한 도움말에서 전송할 수 있는 내용을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위의 버튼을 사용하거나, 굵게 표시하려면 `Ctrl B`, 기울임꼴로 표시하려면 `Ctrl I`, 링크를 추가하려면 `Ctrl K`을 사용해요(Mac에서는 `⌘`). 글머리 기호 목록과 번호 매기기 목록을 만드는 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 유지할 수 없는 서식은 먼저 제거되고, 전송될 모양이 표시돼요. 전송하려면 **지금 보내기**를 다시 누르세요.
- 이메일은 표시된 그대로 전송되며, 서식을 표시하지 않는 메일 앱을 위해 일반 텍스트 사본도 함께 제공돼요.

## 처리할 수 없는 경우

- "여기서는 전송할 수 없어요."라고 표시되면 **초안 복사**를 눌러 초안을 복사한 뒤 직접 전송하세요.
- 보낼 내용도 열거나 읽을 내용도 없이 **확인 필요**로 표시되면 **답변하기**가 먼저 나와요. 필요한 내용을 말하면 작업을 이어서 진행해요. 은행에서 결제하는 것처럼 직접 해야만 하는 단계에서는 **완료로 표시**가 먼저 나와요.
- **도움이 필요해요**는 질문이 있다는 뜻이에요. **답변하기**를 누르세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 이유가 표시돼요.
- 질문이 여러 개라면 각각 선택지가 있거나 짧은 입력란이 표시돼요. 이전 답변이 입력란에 미리 채워져 있을 수도 있어요. **답변하기**를 누르면 답변을 한꺼번에 전송해요.
- 누군가 정보나 파일을 요청했나요? 찾은 내용으로 답변 초안을 작성하고, 나머지 내용만 요청해요.
- 나만 가지고 있는 정보가 필요한가요? 해당 정보를 요청하고, 날짜를 확인하는 답장처럼 그 정보 없이도 보낼 수 있는 내용만 초안으로 작성해요. 곧 보내겠다는 말만 담긴 답장은 작성하지 않아요.
- **다시 시도**를 누르면 작업을 한 번 더 실행해요. **수정 요청**을 누르면 다른 작업을 요청할 수 있어요. 멈춘 할 일에는 **다시 시도**가 먼저 표시되고, **세부 정보**를 누르면 시도한 내용이 표시돼요.
- 실행 자체가 실패해 멈췄나요? 내 Machine이 업데이트된 뒤 해당 할 일을 한 번 더 자동으로 시도해요.
- 실행에 실패하면 최대 두 번까지 자동으로 다시 시도해요. 그 뒤에는 새 메시지나 채팅에 입력한 내용이 도착하거나 **다시 시도**를 누를 때까지 기다려요.
- 준비하는 동안 할 일에는 내 Machine이 하는 일이 "메일 읽는 중", "PDF 읽는 중", "초안 작성 중"처럼 간단히 표시돼요. 자세한 단계는 할 일 채팅에 표시돼요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 하면 이유와 대략적인 시작 시각이 표시돼요. 예: "현재 작업이 끝난 뒤 시작해요."
- 요청하기 전에 내 Machine이 준비한 할 일은 사용량을 아끼기 위해 대기할 수 있어요. 이때도 **실행**이 표시돼요. 누르면 다른 할 일보다 먼저 시작돼요. 승인 전에는 아무것도 전송되지 않아요. AI 요금제의 사용량 한도에 도달하면 실행을 눌렀을 때 안내가 표시되고, 한도가 초기화되면 작업이 시작돼요.
- 사이트에서 로그인하라고 하나요? **로그인**을 누르거나 **브라우저 열기**를 누른 뒤 브라우저에서 로그인하세요. 그러면 작업이 자동으로 이어져요. 이어지지 않으면 **계속**을 누르세요.
- 휴대전화로 전송된 코드가 필요하거나 권한이 없으면 작업이 중단돼요. 할 일에 필요한 내용이 표시되고, **계속** 또는 **다시 시도**를 누르면 돼요. Slack처럼 연결되지 않은 출처의 경우 할 일에 **Slack 연결**이 표시돼요. Slack을 연결하면 작업이 자동으로 이어져요.
