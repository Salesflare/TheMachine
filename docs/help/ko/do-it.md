## 실행하면 하는 일

**실행**을 누르면 내 Machine이 할 일을 준비해요. 답장 초안을 작성하고, 정보를 찾아보고, 양식을 작성해요. 직접 하는 것처럼 내 계정과 자체 브라우저를 사용해요.

브라우저에서 작업하는 동안에는 단계 사이에도 할 일과 채팅에 현재 페이지가 실시간으로 표시돼요. 해당 작업이 끝날 때까지 계속 표시돼요. 화면을 클릭하면 브라우저가 열려요. 할 일에서는 화면이 더 크게 열리고 **중지** 버튼이 표시돼요. 한 번 누르면 진행 중인 작업이 바로 멈춰요.

후속 작업이나 인계를 하기 전에는 팀원의 답장을 포함해 새 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경했다면 할 일에 해당 항목의 링크가 표시돼요.

사이트나 워크플로에서 까다로운 작업을 성공적으로 마치면, 내 Machine은 개인 정보를 담지 않고 작업 단계를 스킬로 저장해요. 나중에 해당 사이트에서 할 일을 할 때 이 단계가 안내로 사용돼요. 권한으로 사용되는 건 아니므로 전송이나 결제는 여전히 승인이 필요해요. 저장된 스킬은 **설정 > 스킬**에서 **작업에서 배운 점**으로 표시돼요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 돌아와요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열려요. **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에 이메일이 두 개 이상 있으면 채팅에 모든 이메일을 검토하는 버튼 하나가 표시돼요. 이메일이 하나씩 차례로 열리고, **다음**을 누르면 마지막 단계에서 모두 전송돼요. 각 이메일은 실제로 전송된 뒤에만 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크를 포함해 실제로 보이는 모습 그대로 표시돼요. Slack이나 채팅 메시지는 일반 텍스트예요.
- 같은 창에서 **수정 요청**을 누르고 변경할 내용을 말하면 내 Machine이 초안을 다시 작성해요.
- 답장은 해당 대화의 최신 이메일에 회신하고, 할 일의 출처를 열면 그 이메일이 표시돼요.
- 제출, 결제, 예약처럼 확정이 필요한 단계는 확인을 기다려요. 채팅에서 해당 작업을 요청해도 돼요. 한 단계를 확인해도 나머지 단계는 계속 대기해요. 모든 단계가 끝나야 할 일이 완료돼요.
- 이런 단계에서 확인을 누르기 전에 할 일과 채팅에 전송될 내용이 표시돼요. 캘린더 초대에는 제목, 시간, 참석자와 회의 링크 추가 여부가 표시돼요.
- 시간을 찾을 때는 연결된 캘린더도 확인해요. 가능한 시간을 제안하기 전에 해당 날짜의 일정을 읽어요.
- 할 일의 채팅에서 초안은 초안을 작성한 메시지와 함께 전송되지 않아요.
- 승인할 때까지 할 일은 **내 확인** 아래 **준비됨** 상태로 대기해요. 목록에는 승인하기 전까지 아무것도 전송되지 않는다는 안내가 한 번 표시돼요. 아직 확인이 필요한 할 일은 **확인 필요**로 표시돼요. 초안은 실제로 전송된 뒤에만 전송됐다고 표시돼요.
- 긴 초안은 처음 세 줄만 표시돼요. **더 보기**를 누르거나 텍스트를 탭하면 나머지 내용이 열려요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지 또는 WhatsApp, Telegram, LinkedIn, X 메시지를 보낼 수 있어요. 각 연결 서비스의 도움말에서 보낼 수 있는 내용을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위의 버튼을 사용하거나, 굵게는 `Ctrl B`, 기울임꼴은 `Ctrl I`, 링크는 `Ctrl K`을 사용해요. Mac에서는 `⌘`를 사용해요. 글머리 기호 목록과 번호 매기기 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거되고, 메시지가 어떻게 전송될지 표시돼요. 다시 **지금 보내기**를 눌러 전송해요.
- 이메일은 표시된 그대로 전송되고, 서식을 표시하지 않는 메일 앱을 위한 일반 텍스트 사본도 함께 전송돼요.

## 처리할 수 없는 경우

- "여기에서는 전송할 수 없어요."라는 메시지가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 전송해요.
- **도움이 필요해요**는 질문이 있다는 뜻이에요. **답변**을 눌러 답해주세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 이유가 표시돼요.
- 질문이 여러 개라면 각 질문에 선택지가 있거나 짧은 입력란이 표시돼요. 이전 답변이 미리 입력되는 경우도 있어요. **답변**을 누르면 모든 답변을 한꺼번에 보내요.
- 나만 알고 있는 정보가 필요하면 해당 정보를 요청하고, 날짜 확인 답장처럼 그 정보 없이도 가능한 내용만 초안으로 작성해요. 도착할 예정이라는 말만 담은 답장은 작성하지 않아요.
- **다시 시도**를 누르면 한 번 더 실행해요. **수정 요청**을 누르면 다른 내용을 요청할 수 있어요. 멈춘 할 일에는 **다시 시도**가 먼저 표시되고, **세부 정보**에서 시도한 내용을 확인할 수 있어요.
- 준비하는 동안 할 일에는 내 Machine이 하는 일이 "메일 읽는 중", "PDF 읽는 중", "초안 작성 중"처럼 쉬운 문구로 표시돼요. 자세한 단계는 할 일의 채팅에서 확인할 수 있어요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 할 때는 이유와 대략적인 시작 시점을 알려줘요. 예를 들면 "현재 작업이 끝난 뒤 시작해요"라고 표시돼요.
- 사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 눌러 브라우저에서 로그인해요. 그러면 작업이 자동으로 계속돼요. 계속되지 않으면 **계속**을 눌러요.
- 휴대폰으로 전송된 코드가 필요하거나 권한이 없으면 작업이 멈춰요. 할 일에 필요한 내용이 표시되고, 이어서 **계속** 또는 **다시 시도**를 누를 수 있어요. Slack처럼 연결되지 않은 서비스가 출처라면 할 일에 **Slack 연결**이 표시돼요. Slack을 연결하면 작업이 자동으로 계속돼요.
