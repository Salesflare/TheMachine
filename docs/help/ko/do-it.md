## 실행 기능

**실행**을 누르면 내 Machine이 할 일을 준비해요. 답장 초안을 작성하고, 정보를 찾아보고, 양식을 작성해요. 직접 할 때처럼 내 계정과 자체 브라우저를 사용해요.

브라우저에서 작업하는 동안 할 일과 채팅에 해당 페이지가 실시간으로 표시돼요. 단계 사이에도 계속 표시되며, 그 페이지에서 작업이 끝날 때까지 유지돼요. 화면을 클릭하면 브라우저가 열려요. 할 일에서 열면 더 크게 표시되고 **중지** 버튼도 보여요. 한 번 누르면 해당 실행이 바로 중지돼요.

후속 작업을 하거나 인계하기 전에 새 답장이 있는지 확인해요. 팀원의 답장도 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경했다면 할 일에 해당 문서나 페이지로 연결되는 링크가 표시돼요.

사이트나 워크플로에서 어려운 작업을 성공적으로 마치면 내 Machine은 개인 정보를 포함하지 않고 단계를 스킬로 저장해요. 나중에 해당 사이트에서 진행하는 할 일에는 이 단계가 안내로 제공돼요. 권한으로 쓰이지는 않으므로 전송이나 결제는 여전히 직접 승인해야 해요. 저장된 스킬은 **설정 > 스킬**에서 **작업에서 배운 점**으로 표시돼요.

## 승인 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 제공돼요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열리고, **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에서 이메일을 두 개 이상 보내는 경우, 채팅에 이메일을 모두 검토하는 버튼 하나가 표시돼요. 이메일이 **다음** 버튼과 함께 하나씩 표시되고, 마지막 단계에서 모두 전송돼요. 각 이메일은 실제로 전송된 후에만 전송 완료로 표시돼요.
- 이메일은 굵게 표시한 글씨, 목록, 링크를 포함해 실제로 표시될 모습으로 보여요. Slack 메시지나 채팅 메시지는 일반 텍스트예요.
- 같은 창에서 **수정 요청**을 누르고 변경할 내용을 말하면 내 Machine이 초안을 다시 작성해요.
- 답장은 이메일 스레드의 최신 이메일에 회신하고, 할 일의 출처를 열면 해당 이메일이 표시돼요.
- 제출, 결제, 예약처럼 확정이 필요한 단계는 직접 확인하거나 채팅에서 실행해 달라고 요청할 때까지 대기해요. 한 단계를 확인해도 나머지 단계는 계속 대기해요. 모든 단계가 완료되어야 할 일이 종료돼요.
- 이런 단계에서 전송되는 내용은 누르기 전에 할 일과 채팅에 표시돼요. 캘린더 초대에는 제목, 시간, 참석자와 회의 링크 추가 여부가 표시돼요.
- 연결된 캘린더는 가능한 시간을 찾을 때 참고해요. 시간을 제안하기 전에 해당 날짜의 일정을 확인해요.
- 할 일의 채팅에서 작성한 초안은 초안을 작성한 메시지와 함께 전송되지 않아요.
- 승인할 때까지 할 일은 **내 확인** 아래 **준비됨** 상태로 대기해요. 목록에는 승인 전까지 아무것도 전송되지 않는다는 안내가 한 번 표시돼요. 아직 직접 해야 할 일이 있으면 **확인 필요**로 표시돼요. 초안이 전송됐다는 표시는 실제로 전송된 후에만 나타나요.
- 긴 초안은 처음 세 줄만 표시돼요. **더 보기**를 누르거나 텍스트를 탭하면 나머지를 볼 수 있어요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지, WhatsApp, Telegram, LinkedIn 또는 X 메시지를 전송할 수 있어요. 각 연결 서비스의 도움말 문서에서 전송할 수 있는 항목을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위의 버튼을 사용하거나, 굵게 표시하려면 `Ctrl B`, 기울임꼴로 표시하려면 `Ctrl I`, 링크를 추가하려면 `Ctrl K`를 누르세요. Mac에서는 `⌘`를 사용해요. 글머리 기호 목록과 번호 매기기 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여넣은 텍스트는 색상이나 그림 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거되고, 전송될 모습이 표시돼요. 다시 **지금 보내기**를 누르면 전송돼요.
- 이메일은 표시된 그대로 전송돼요. 서식을 표시하지 못하는 메일 앱을 위해 일반 텍스트 사본도 함께 전송돼요.

## 실행할 수 없는 경우

- “여기서는 전송할 수 없어요.”라는 메시지가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 전송하세요.
- **도움이 필요해요**는 답할 질문이 있다는 뜻이에요. **답변**을 눌러 답하세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 중단된 이유가 표시돼요.
- 질문이 여러 개라면 각 질문에 선택 항목이나 짧은 입력란이 표시돼요. 이전 답변이 입력란에 채워져 있을 수도 있어요. **답변**을 누르면 모든 답변을 한꺼번에 보내요.
- 나만 알고 있는 정보가 빠졌다면 해당 정보를 요청하고, 그 정보 없이 진행할 수 있는 내용만 작성해요. 예를 들어 날짜를 확인하는 답장을 작성할 수 있어요. 단순히 나중에 보내겠다는 내용만 담은 답장은 작성하지 않아요.
- **다시 시도**를 누르면 작업을 한 번 더 실행해요. **수정 요청**을 누르면 다른 작업을 요청할 수 있어요. 멈춘 할 일에서는 **다시 시도**가 먼저 표시되고, **세부 정보**에서 시도한 내용을 확인할 수 있어요.
- 실행 자체에 실패해 작업이 멈췄나요? 내 Machine이 업데이트되면 해당 할 일을 한 번 더 자동으로 시도해요.
- 준비하는 동안 할 일에 내 Machine이 하는 일이 간단한 문장으로 표시돼요. 예를 들면 “메일 읽는 중”, “PDF 읽는 중”, “초안 작성 중”이라고 표시돼요. 자세한 단계는 할 일의 채팅에서 확인할 수 있어요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 할 때는 이유와 대략적인 시작 시점을 알려줘요. 예를 들면 “현재 작업이 끝나면 시작해요”라고 표시돼요.
- 사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 눌러 브라우저에서 로그인하세요. 그러면 작업이 자동으로 계속돼요. 계속되지 않으면 **계속**을 누르세요.
- 휴대전화로 전송된 인증 코드가 필요하거나 권한이 없으면 작업이 중지돼요. 할 일에 필요한 내용이 표시된 다음 **계속** 또는 **다시 시도**를 누르면 돼요. Slack처럼 연결되지 않은 서비스는 할 일에서 **Slack 연결**을 누르세요. Slack이 연결되면 작업이 자동으로 계속돼요.
