## 실행으로 할 수 있는 일

**실행**을 누르면 Machine이 할 일을 준비해요. 답장 초안을 작성하고, 정보를 찾아보고, 양식을 작성해요. 직접 작업할 때처럼 본인 계정과 자체 브라우저를 사용해요.

Machine이 브라우저에서 작업하는 동안 할 일과 채팅에 해당 페이지가 실시간으로 표시돼요. 단계 사이에도 표시되며, 브라우저에서 작업이 끝날 때까지 계속 보여요. 이미지를 누르면 브라우저가 열려요. 할 일에서 이미지를 누르면 더 크게 볼 수 있고 **중지** 버튼도 표시돼요. 한 번 누르면 해당 작업이 즉시 중단돼요.

후속 작업이나 인계 전에 팀원의 답장을 포함해 새 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경한 경우 할 일에 링크가 표시돼요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 돌아와요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열려요. **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에 이메일이 두 개 이상 있으면 채팅에서 버튼 하나로 모두 검토할 수 있어요. 이메일이 **다음** 버튼과 함께 하나씩 표시되고, 마지막 단계에서 모두 전송돼요. 각 이메일은 실제로 전송된 뒤에만 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크가 포함된 실제 표시 형태로 보여요. Slack 메시지나 채팅 메시지는 일반 텍스트로 표시돼요.
- 같은 창에서 **수정 요청**을 누르고 변경할 내용을 말하면 Machine이 초안을 다시 작성해요.
- 답장은 해당 대화에서 가장 최근에 받은 이메일에 답하고, 할 일의 출처를 누르면 그 이메일이 열려요.
- 제출, 결제, 예약처럼 실제 처리가 이루어지는 단계는 확인을 기다려요. 또는 채팅에서 진행해 달라고 요청할 때까지 기다려요. 한 단계를 확인해도 다른 단계는 계속 대기 상태예요. 모든 단계가 완료되어야 할 일이 종료돼요.
- 할 일과 채팅에는 이런 단계에서 전송될 내용이 버튼을 누르기 전에 표시돼요. 캘린더 초대에는 제목, 시간, 참석자와 회의 링크 추가 여부가 표시돼요.
- 시간을 찾을 때는 연결된 캘린더도 확인해요. 가능한 시간을 제안하기 전에 해당 날짜의 회의 일정을 읽어요.
- 할 일의 채팅에서는 초안을 작성한 메시지와 같은 메시지로 초안을 전송하지 않아요.
- 승인할 때까지 할 일은 **내 확인** 아래 **준비됨** 상태로 대기해요. 목록에는 승인하기 전에는 아무것도 전송되지 않는다는 안내가 한 번 표시돼요. 아직 확인이 필요한 할 일은 **확인 필요**로 표시돼요. 초안은 실제로 전송된 뒤에만 전송됐다고 표시돼요.
- 긴 초안은 처음 세 줄만 표시돼요. **더 보기**를 누르거나 텍스트를 누르면 나머지를 볼 수 있어요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지 또는 WhatsApp, Telegram, LinkedIn, X 메시지를 보낼 수 있어요. 각 연결 관련 도움말에서 보낼 수 있는 항목을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위에 있는 버튼을 사용하거나, 굵게는 `Ctrl B`, 기울임꼴은 `Ctrl I`, 링크는 `Ctrl K`을 사용해요. Mac에서는 링크에 `⌘`를 사용해요. 글머리 기호 목록과 번호 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거되고, 메시지가 실제로 전송될 형태로 표시돼요. 전송하려면 **지금 보내기**를 다시 누르세요.
- 이메일은 화면에 표시된 그대로 전송되며, 서식을 표시하지 않는 메일 앱을 위한 일반 텍스트 사본도 함께 전송돼요.

## 처리할 수 없는 경우

- "여기서는 전송할 수 없어요."라는 메시지가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 보내세요.
- **도움이 필요해요**는 질문이 있다는 뜻이에요. **답변**을 눌러 답하세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 할 일에 이유가 표시돼요.
- 질문이 여러 개라면 질문마다 선택지나 짧은 입력란이 있어요. 이전에 답한 내용이 입력란에 미리 채워져 있을 때도 있어요. **답변**을 누르면 답변을 한꺼번에 보내요.
- 본인만 제공할 수 있는 정보가 없으면 해당 정보를 요청하고, 날짜를 확인하는 답장처럼 그 정보 없이도 가능한 내용만 초안으로 작성해요. 단지 나중에 보내겠다는 내용만 담은 답장은 작성하지 않아요.
- **다시 시도**를 누르면 작업을 한 번 더 실행해요. **수정 요청**을 누르면 다른 내용을 요청할 수 있어요. 멈춘 할 일에는 **다시 시도**가 먼저 표시되고, **세부 정보**를 누르면 시도한 내용이 표시돼요.
- 준비 중에는 할 일에 Machine이 하는 일이 "메일 읽는 중", "PDF 읽는 중", "초안 작성 중"처럼 간단한 문구로 표시돼요. 자세한 단계는 할 일의 채팅에 표시돼요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 할 때는 "현재 작업이 끝난 뒤 시작해요"처럼 이유와 대략적인 시작 시점을 알려줘요.
- 사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 누른 뒤 브라우저에서 로그인하세요. 로그인하면 작업이 자동으로 계속돼요. 계속되지 않으면 **계속**을 누르세요.
- 휴대전화로 전송된 코드가 필요하거나 권한이 없으면 작업이 중단돼요. 할 일에 필요한 내용이 표시되면 **계속** 또는 **다시 시도**를 누르세요. Slack처럼 연결되지 않은 출처의 경우 할 일에서 **Slack 연결**을 누르세요. Slack을 연결하면 작업이 자동으로 계속돼요.
