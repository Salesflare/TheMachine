## 실행하면 하는 일

**실행**을 누르면 내 Machine이 할 일을 준비해요. 답장 초안을 작성하거나, 정보를 찾거나, 양식을 작성해요. 직접 할 때처럼 내 계정과 자체 브라우저를 사용해요.

브라우저에서 작업하는 동안 할 일과 채팅에 해당 페이지가 실시간으로 표시돼요. 단계 사이에도 표시되며, 해당 페이지에서 작업이 끝날 때까지 계속돼요. 화면을 누르면 브라우저가 열려요. 할 일에서 화면을 누르면 더 크게 열리고 **중지**가 표시돼요. 한 번 누르면 해당 실행이 바로 끝나요.

후속 작업이나 인계를 하기 전에 팀원의 답장을 포함해 새 답장이 있는지 확인해요. 이미 처리된 경우 할 일에 표시돼요. 문서나 페이지를 변경한 경우 할 일에 링크가 표시돼요.

사이트나 워크플로에서 어려운 작업을 성공적으로 마치면 내 Machine은 다른 사람의 세부 정보 없이 작업 단계를 스킬로 저장해요. 나중에 같은 사이트에서 할 일을 처리할 때 이 단계를 안내로 활용해요. 권한으로 사용하지는 않아요. 전송이나 결제는 계속 승인을 기다려요. 저장된 스킬은 **설정 > 스킬**에서 **작업에서 배운 점**으로 표시돼요.

## 승인하기 전에는 아무것도 전송되지 않아요

- 답장은 초안으로 표시돼요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열려요. **지금 보내기**를 눌러야 전송돼요.
- 할 일 하나에 이메일이 두 개 이상 있으면 채팅에 모두 검토할 수 있는 버튼이 하나 표시돼요. 이메일이 하나씩 차례로 열리고 **다음**을 누르면 마지막 단계에서 모두 전송돼요. 각각 실제로 전송된 뒤에야 전송 완료로 표시돼요.
- 이메일은 굵은 글씨, 목록, 링크가 적용된 모습 그대로 표시돼요. Slack 메시지나 채팅 메시지는 일반 텍스트로 표시돼요.
- 같은 창에서 **수정 요청**을 눌러 변경할 내용을 말하면 내 Machine이 초안을 다시 작성해요.
- 답장은 해당 대화의 최신 이메일에 답하고, 할 일의 출처를 누르면 그 이메일이 열려요.
- 제출, 결제, 예약처럼 확정이 필요한 단계는 직접 확인하거나 채팅에서 실행해 달라고 할 때까지 기다려요. 한 단계를 확인해도 다른 단계는 계속 대기 상태예요. 모든 단계가 끝나야 할 일이 닫혀요.
- 이런 단계에서 전송되는 내용은 누르기 전에 할 일과 채팅에 표시돼요. 캘린더 초대에는 제목, 시간, 참석자와 회의 링크 추가 여부가 표시돼요.
- 시간을 찾을 때는 연결된 캘린더를 확인해요. 시간을 제안하기 전에 해당 날짜의 회의 일정을 읽어요.
- 할 일의 채팅에서 초안을 작성한 메시지는 같은 메시지에서 전송되지 않아요.
- 승인할 때까지 할 일은 **내 확인** 아래에 **준비됨** 상태로 대기하고, 목록에는 승인하기 전까지 아무것도 전송되지 않는다는 안내가 한 번 표시돼요. **준비됨**은 초안이나 결과를 승인할 수 있는 상태라는 뜻이에요. 결정, 누락된 정보, 로그인 또는 선택이 필요해 결과 없이 작업이 끝나면 대신 **확인 필요**가 표시되고 필요한 내용이 한 줄로 안내돼요. 알림과 아침 요약에도 같은 내용이 표시돼요. 초안이 전송됐다는 안내는 실제로 전송된 뒤에만 표시돼요.
- 초안이 길면 처음 세 줄이 표시돼요. **더 보기**를 누르거나 텍스트를 누르면 나머지를 볼 수 있어요. **검토 후 보내기**를 누르면 항상 전체 내용이 표시돼요.

출처에 따라 이메일, Slack 다이렉트 메시지, WhatsApp, Telegram, LinkedIn 또는 X 메시지를 보낼 수 있어요. 각 연결 서비스의 도움말에서 전송할 수 있는 내용을 확인할 수 있어요.

## 이메일 수정하기

- 텍스트 위의 버튼을 사용하거나 `Ctrl B`로 굵게, `Ctrl I`로 기울임꼴, `Ctrl K`으로 링크를 적용해요. Mac에서는 `⌘`를 사용해요. 글머리 기호 목록과 번호 목록 버튼도 있어요.
- 링크 주소는 https://로 시작해야 해요. 붙여 넣은 텍스트는 색상이나 이미지 없이 일반 텍스트로 들어와요.
- 이메일에서 지원하지 않는 서식은 먼저 제거하고, 실제 전송될 모양을 보여 줘요. 다시 전송하려면 **지금 보내기**를 누르세요.
- 이메일은 표시된 그대로 전송되며, 서식을 표시하지 않는 메일 앱을 위해 일반 텍스트 사본도 함께 전송돼요.

## 실행할 수 없는 경우

- “여기서는 전송할 수 없어요.”라는 안내가 표시되면 **초안 복사**를 눌러 초안을 복사한 다음 직접 전송하세요.
- **도움이 필요해요**는 답해야 할 질문이 있다는 뜻이에요. **답변**을 눌러 답하세요. **멈춤**은 질문 없이 작업이 중단됐다는 뜻이에요. 이유는 할 일에 표시돼요.
- 질문이 여러 개 있나요? 각 질문에 선택 항목이나 짧은 입력란이 따로 표시돼요. 이전 답변이 미리 입력되는 경우도 있어요. **답변**을 누르면 모두 한꺼번에 전송돼요.
- 나만 알고 있는 정보가 필요한가요? 해당 정보를 요청하고, 날짜 확인 답장처럼 그 정보 없이도 보낼 수 있는 내용만 작성해요. 단순히 곧 보내겠다고만 하는 답장은 작성하지 않아요.
- **다시 시도**를 누르면 한 번 더 실행해요. **수정 요청**을 누르면 다른 작업을 요청할 수 있어요. 멈춘 할 일에서는 **다시 시도**가 먼저 표시되고, **세부 정보**에서 시도한 내용을 확인할 수 있어요.
- 실행 자체가 실패해 멈췄나요? 내 Machine이 업데이트된 뒤 해당 할 일을 한 번 더 자동으로 시도해요.
- 실패한 실행은 자동으로 최대 두 번까지 다시 시도해요. 그 뒤에는 새 메시지나 채팅에 입력한 내용 같은 새 정보가 오거나 **다시 시도**를 누를 때까지 기다려요.
- 준비하는 동안 할 일에는 “메일을 읽는 중”, “PDF를 읽는 중”, “초안을 작성하는 중”처럼 내 Machine이 하는 일이 쉬운 문장으로 표시돼요. 자세한 단계는 할 일의 채팅에서 확인할 수 있어요.
- **준비 중…**으로 표시된 할 일은 몇 초 안에 시작돼요. 기다려야 하는 경우에는 이유와 대략적인 시작 시점을 안내해요. 예를 들어 “현재 작업이 끝나면 시작해요”라고 표시돼요.
- 요청하기 전에 내 Machine이 준비한 할 일은 사용량을 절약하기 위해 대기할 수 있어요. 그래도 **실행**이 표시되므로, 누르면 다른 할 일보다 먼저 바로 시작돼요. 승인하기 전까지 아무것도 전송되지 않아요. AI 요금제의 사용량 한도에 도달하면 실행할 때 안내가 표시되고, 한도가 초기화되면 시작돼요.
- 사이트에서 로그인을 요청하면 **로그인**을 누르거나 **브라우저 열기**를 눌러 브라우저에서 로그인하세요. 그러면 자동으로 계속 진행돼요. 진행되지 않으면 **계속**을 누르세요.
- 휴대전화로 전송된 코드가 필요하거나 권한이 없으면 작업이 중단돼요. 할 일에 필요한 내용이 표시되고, 이어서 **계속** 또는 **다시 시도**를 누르면 돼요. Slack처럼 출처가 연결되지 않은 경우 할 일에 **Slack 연결**이 표시돼요. Slack을 연결하면 작업이 자동으로 계속돼요.
