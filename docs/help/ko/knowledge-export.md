The Machine이 학습한 내용은 모두 본인 소유예요. ChatGPT나 Claude 같은 다른 AI에 전달하거나 보관할 수 있어요.

## 내보내기

1. **설정** › **일반** › **내보내기**에서 **다른 AI를 위한 지식** 옆의 **내보내기**를 눌러요.
2. **메시지 내용**은 기본적으로 꺼져 있어요. 이 상태에서는 각 항목의 출처와 날짜만 포함돼요. 메시지 내용도 추가하려면 켜세요.
3. 본인 전용 프로젝트, 비공개 스레드, 신중한 Fleet도 추가하려는 경우에만 **비공개 및 신중함**을 켜세요.
4. 파일을 암호화하려면 선택 사항으로 **암호 문구**를 설정하세요. 10자 이상이어야 해요.
5. **다운로드**를 눌러요. 파일은 한 번만 다운로드할 수 있어요.

호스팅된 The Machine과 본인 컴퓨터에서 실행하는 The Machine 모두 같은 방식으로 이용할 수 있어요.

## 파일에 포함되는 내용

- 사람, 조직, 프로젝트: 각 항목마다 관계를 설명하는 Markdown 페이지가 하나씩 있어요.
- 사실과 선호 사항: The Machine이 본인과 다른 사람에 대해 알고 있는 내용이에요.
- 과거 사실: 더 이상 유효하지 않은 내용(종료, 보류 또는 대체됨)과 이를 대체한 내용이에요. 삭제한 사실은 포함되지 않아요.
- 규칙, 글쓰기 방식, 서명: 초안 작성에 적용되는 내용이에요.
- 스킬: 사용 여부와 관계없이 사용 방법이 포함돼요.
- 맥락: 팀 브리핑, 요약 문구, 약속, 진행 중인 할 일이 포함돼요.
- 출처: 각 항목의 출처를 ID와 날짜로 표시해요.

연락처와 할 일은 스프레드시트(CSV)로도 제공돼요. 맨 위에 있는 README에서 AI가 모든 파일을 읽는 방법을 안내해요. zip 파일을 지식 파일이나 프로젝트로 AI에 업로드하세요.

## 포함되지 않는 내용

비밀번호, 키, 로그인 정보는 포함되지 않아요. 팀원의 데이터, 설정, 사진도 포함되지 않아요. The Machine 전체를 옮기려면 [다른 컴퓨터로 이동](moving.md)을 참고하세요.
