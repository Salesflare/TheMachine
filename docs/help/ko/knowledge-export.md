내 Machine이 배운 내용은 모두 내 것이에요. ChatGPT나 Claude 같은 다른 AI에 전달하거나 그대로 보관할 수 있어요.

## 내보내기

1. **설정** › **일반** › **내보내기**에서 **다른 AI를 위한 지식** 옆의 **내보내기**를 누르세요.
2. **메시지 내용**은 기본적으로 꺼져 있어요. 각 항목의 출처와 시점만 포함돼요. 메시지 내용도 추가하려면 켜세요.
3. 나만 볼 수 있는 프로젝트, 비공개 스레드, 신중한 Fleet을 추가하려는 경우에만 **비공개 및 신중**을 켜세요.
4. 원한다면 파일을 암호화하도록 **암호 문구**를 설정하세요. 10자 이상이어야 해요.
5. **다운로드**를 누르세요. 파일은 한 번만 다운로드할 수 있어요.

호스팅된 Machine과 내 컴퓨터에서 실행하는 Machine 모두 같은 방식으로 작동해요.

## 포함되는 내용

- 사람, 조직, 프로젝트: 각각 Markdown 페이지 하나씩 제공되며, 서로 어떤 관계인지도 포함돼요.
- 사실과 선호 사항: 내 Machine이 나와 각 대상에 대해 알고 있는 내용이에요.
- 지난 사실: 더는 유효하지 않은 내용, 즉 종료되거나 대체된 내용과 이를 대체한 내용이에요. 삭제한 사실은 포함되지 않아요.
- 규칙, 글쓰기 방식, 서명: 초안에 적용되는 내용이에요.
- 스킬: 켜짐/꺼짐 상태를 포함한 사용법이에요.
- 맥락: 팀 브리핑, 요약 문구, 약속, 진행 중인 할 일이에요.
- 출처: 각 항목의 출처를 ID와 날짜로 표시해요.

연락처와 할 일은 스프레드시트(CSV)로도 제공돼요. 맨 위의 README에는 AI가 모든 내용을 읽는 방법이 안내돼 있어요. ZIP 파일을 지식 파일이나 프로젝트로 AI에 업로드하세요.

## 포함되지 않는 내용

비밀번호, 키, 로그인 정보는 포함되지 않아요. 팀원의 데이터, 설정, 사진도 포함되지 않아요. Machine 전체를 옮기려면 [다른 컴퓨터로 옮기기](moving.md)를 확인하세요.
