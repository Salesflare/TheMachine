## 열기

할 일에서 **채팅**을 누르거나 사이드바 목록에서 할 일을 선택해요. 제목을 탭하거나 클릭하면 제목을 수정할 수 있어요.

## 채팅에 표시되는 이메일

이메일에는 새로 추가된 내용만 표시돼요. 인용된 이전 메시지는 **이전 메시지** 아래에 접혀 있어요. **대화 읽기**를 누르면 이메일 전체를 볼 수 있어요.

## 진행 내역

메시지를 처리하는 동안 준비 중인 할 일에서처럼, 입력 중 표시 위에 가장 최근 단계가 표시돼요. 예를 들면 “이메일을 읽는 중”이라고 나와요. 브라우저를 사용하면 페이지의 작은 이미지도 표시돼요.

작업을 마칠 때마다 “12개 확인함”처럼 간단한 한 줄로 표시돼요. 열면 각 단계의 종류와 횟수를 한 번씩 볼 수 있어요. 예를 들면 “example.com에서 브라우저 사용 · 7”이라고 표시돼요. 사이트 이름은 표시하지만 주소나 명령어, 파일 이름은 표시하지 않아요.

질문하려고 멈춘 경우에도 “질문함: 오늘 보낼까요, 월요일에 보낼까요?”처럼 간단한 한 줄로 표시돼요. 그 아래에는 답변만 표시돼요.

## 무엇을 물어볼 수 있나요?

메시지를 쓰기 전에 이 할 일을 바탕으로 최대 세 개의 제안이 표시될 수 있어요. 예를 들면 “대신 화요일 오전 10시를 제안해요”라고 나와요. 제안을 탭하면 메시지 입력란에 추가돼요. 그대로 보내거나 수정할 수 있어요. 적절한 제안이 없으면 표시되지 않아요.

- 대화 내용, 사람 또는 배경에 관해 물어보려면 “지난번에 뭐라고 했나요?”라고 입력해요.
- 초안을 수정하려면 “더 짧게 써 줘요” 또는 “새 날짜를 언급해 줘요”라고 입력해요.

질문에는 답변만 하고 초안은 그대로 둬요. 보내기는 할 일의 버튼으로만 할 수 있어요. 초안을 작성한 답변에서 바로 초안을 보내지는 않아요. 문서 정리처럼 다른 사람에게 전달되지 않는 수정은 추가 확인 없이 바로 적용돼요. 요청한 범위를 벗어나는 작업은 확인을 기다려요. 단계가 여러 개인 할 일은 모든 단계가 완료될 때까지 열려 있어요.

컴퓨터에서는 Enter 또는 Ctrl+Enter (Mac에서는 Cmd+Enter)를 누르면 전송되고, Shift+Enter를 누르면 새 줄이 시작돼요. 휴대전화에서는 전송 버튼을 사용해요.

## 잘못된 내용 바로잡기

채팅에서 “그 사람은 CEO가 아니에요” 또는 “회사를 그만뒀어요”처럼 알려 주세요. 원본의 직책, 회사, 직함, 프로젝트 단계, 할 일의 프로젝트 또는 학습한 규칙을 수정해요. “수정함: Sam의 직책은 영업 총괄이에요. 이메일 서명에서 확인했어요”처럼 변경 내용과 함께 **실행 취소**가 표시돼요. 실행 취소를 누르면 이전 값으로 되돌아가요. 단, 그 값이 이후에 변경된 경우에는 되돌리지 않아요.

잘못된 값을 바탕으로 만든 다른 초안은 하나씩 다시 작성돼요. 해당 초안의 채팅에는 **수정 후 초안을 다시 작성하는 중**이라고 표시돼요. 직접 수정하거나 승인한 초안과 발송 중인 초안은 그대로 유지돼요. 답변에는 각 초안의 개수가 표시돼요.

GBrain 페이지에서는 The Machine의 섹션만 변경돼요. 직접 작성한 내용은 그대로 유지돼요. 내용의 출처를 파악할 수 없으면 메모를 바탕으로 학습해요.

## 모델과 사고 수준

메시지 입력란 아래에 “GPT-6.2 Sol”, “낮은 사고 수준”처럼 모델과 사고 수준이 표시돼요. 둘 중 하나를 탭하면 이 채팅에서만 사용할 설정을 선택할 수 있어요. 새 채팅에는 **설정**의 **모델**에서 선택한 항목이 적용돼요([모델](model.md) 참고).

모델 메뉴 아래에 있는 **빠름**을 사용하면 할 일 채팅의 응답 속도가 빨라져요. 비용은 약 두 배예요. (요금제 사용량도 두 배로 늘어요.) 이 설정은 모든 할 일 채팅에서 보내는 메시지와 **실행**에 적용되며, 백그라운드 작업에는 적용되지 않아요. 기본적으로 꺼져 있고, 지원하지 않는 모델에서는 흐리게 표시돼요.

## 답변 중지

답변을 작성하는 동안 전송 버튼이 **중지**로 바뀌어요. 중지를 누르면 바로 멈추고, 지금까지 작성된 내용은 **중지됨**으로 표시돼요. 새 메시지를 작성해 계속하거나 **다시 시도**를 탭해요.

## 파일 추가

클립을 탭하거나 스크린샷을 붙여 넣거나, 파일을 채팅에 끌어다 놓아요. 각 파일은 메시지 입력란 위에 표시되고, ×를 누르면 삭제돼요. 파일만 첨부해 메시지를 보낼 수도 있어요.

- 최대 5MB인 이미지(PNG, JPEG, GIF, WebP)는 이미지로 모델에 전달돼요.
- 최대 10MB인 PDF, 텍스트 파일, 스프레드시트(CSV), Office 파일은 The Machine이 읽고 초안에 첨부할 수 있어요.
- 메시지마다 파일을 최대 5개 첨부할 수 있어요.

파일은 메시지처럼 암호화되어 내 Machine에 보관돼요. 추가했지만 보내지 않은 파일은 하루 후에 삭제돼요. 새 할 일에도 파일을 첨부할 수 있어요. **새 할 일**에서 추가하면 돼요([직접 만들기](cards.md#make-one-yourself) 참고).
