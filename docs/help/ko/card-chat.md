## 열기

할 일에서 **채팅**을 누르거나 사이드바 목록에서 할 일을 선택해요. 제목을 탭하거나 클릭하면 제목을 수정할 수 있어요.

## 채팅에 표시되는 이메일

각 이메일에는 새로 추가된 내용만 표시돼요. 인용된 이전 메시지는 **이전 메시지** 아래에 접혀 있어요. **대화 읽기**를 누르면 이메일 전문을 볼 수 있어요.

## 처리 내용

처리 중에는 메시지 입력란 위에 **처리 중이에요…**가 표시되고, 채팅에는 입력 중 표시가 나타나요. 브라우저를 사용할 때는 페이지의 작은 미리 보기도 표시돼요.

실행할 때마다 처리 내용이 "12개 항목 확인"처럼 진행 상황을 세는 간단한 한 줄로 표시돼요. 이 줄을 열면 각 단계 유형과 실행 횟수가 한 번씩 표시돼요. 예: "example.com에서 브라우저 사용 · 7회". 사이트 이름만 표시하고 주소, 명령어 또는 파일은 표시하지 않아요.

Claude Code를 사용하면 처리 중에는 단계가 채팅에 표시되지 않아요. 대신 입력 중 표시 위에 "이메일 읽는 중"처럼 최신 단계가 표시되고, 메시지 입력란 위에는 아무것도 표시되지 않아요.

확인할 내용이 있어 처리를 멈췄을 때도 "질문: 오늘 보낼까요, 월요일에 보낼까요?"처럼 간단한 한 줄로 표시돼요. 그 아래에는 답변만 표시돼요.

## 무엇을 요청할 수 있나요?

메시지를 입력하기 전에 이 할 일에 맞는 제안이 최대 3개까지 표시될 수 있어요. 예: "대신 화요일 오전 10시를 제안해 줘". 제안을 탭하면 메시지 입력란에 들어가고, 그대로 보내거나 수정할 수 있어요. 적합한 제안이 없으면 표시되지 않아요.

- 대화 내용, 관련 인물 또는 배경에 관해 질문하려면: "지난번에 무슨 얘기를 했어?"
- 초안을 수정하려면: "더 짧게 해 줘" 또는 "새 날짜를 언급해 줘".

질문에는 답변만 하고 초안은 그대로 둬요. 전송은 할 일의 버튼에서만 할 수 있어요. 채팅은 초안을 작성한 답변과 함께 초안을 보내지 않아요. 문서 정리처럼 다른 사람에게 전달되지 않는 수정 요청은 추가 확인 없이 바로 처리돼요. 요청한 범위를 벗어나는 작업은 확인을 기다려요. 단계가 여러 개인 할 일은 모든 단계가 완료될 때까지 열려 있어요.

컴퓨터에서는 Enter 또는 Ctrl+Enter(Mac에서는 Cmd+Enter)를 눌러 보내고, Shift+Enter를 눌러 줄을 바꿔요. 휴대폰에서는 보내기 버튼을 사용해요.

## 잘못된 내용 수정하기

채팅에 "그 사람은 CEO가 아니야" 또는 "회사를 그만뒀어"처럼 알려 주세요. The Machine은 원본 정보를 수정해요. 예를 들어 직책, 회사, 제목, 프로젝트 단계, 할 일의 프로젝트 또는 학습한 규칙을 수정해요. "수정됨: Sam의 직책은 영업 총괄이에요. 이메일 서명에서 확인했어요"처럼 변경 내용이 표시되고, **실행 취소**도 함께 표시돼요. 실행 취소를 누르면 이전 값으로 되돌아가요. 단, 그 사이 값이 바뀌었다면 되돌리지 않아요.

잘못된 값을 바탕으로 만든 다른 초안은 한 번에 하나씩 다시 작성해요. 해당 초안의 채팅에는 **수정 후 초안을 다시 작성하는 중**이라고 표시돼요. 직접 수정하거나 승인한 초안과 전송 중인 초안은 그대로 유지돼요. 답변에는 각 유형의 초안이 몇 개인지도 표시돼요.

GBrain 페이지에서는 The Machine이 작성한 섹션만 변경돼요. 직접 작성한 내용은 그대로 유지돼요. 정보의 출처를 확인할 수 없으면 메모를 바탕으로 학습해요.

## 모델과 사고 수준

메시지 입력란 아래에 "GPT-6.2 Sol", "낮은 사고 수준"처럼 모델과 사고 수준이 표시돼요. 둘 중 하나를 탭하면 이 채팅에서만 사용할 항목을 선택할 수 있어요. 새 채팅에는 **설정**의 **모델**에서 지정한 항목이 적용돼요([모델](model.md) 참고).

모델 메뉴 아래쪽에 있는 **빠름**을 켜면 할 일 채팅의 응답 속도가 빨라져요. 비용은 약 2배가 들거나 요금제 사용량이 2배가 돼요. 보내는 메시지와 실행에 적용되며, 모든 할 일 채팅에서 사용할 수 있어요. 백그라운드 작업에는 적용되지 않아요. 기본적으로 꺼져 있으며, 지원하지 않는 모델에서는 비활성화돼요.

## 답변 중지하기

답변을 작성하는 동안 보내기 버튼이 **중지**로 바뀌어요. 중지를 누르면 작성이 바로 끝나고, 지금까지 작성된 내용은 **중지됨**으로 표시돼요. 새 메시지를 작성해 이어가거나 **다시 시도**를 탭해요.

## 파일 추가하기

클립 아이콘을 탭하거나, 스크린샷을 붙여 넣거나, 파일을 채팅에 끌어다 놓으세요. 각 파일은 메시지 입력란 위에 표시되고, ×를 누르면 제거돼요. 파일만 첨부해 메시지를 보낼 수도 있어요.

- 이미지(PNG, JPEG, GIF, WebP)는 최대 5MB까지 모델에 이미지로 전달돼요.
- PDF, 텍스트 파일, 스프레드시트(CSV), Office 파일은 최대 10MB까지 추가할 수 있어요. The Machine이 읽고 초안에 첨부할 수 있어요.
- 메시지 하나에 파일을 최대 5개까지 첨부할 수 있어요.

파일은 메시지처럼 암호화되어 내 Machine에 저장돼요. 추가했지만 보내지 않은 파일은 하루가 지나면 삭제돼요. **새 할 일**을 만들 때도 파일을 첨부할 수 있어요([직접 만들기](cards.md#make-one-yourself) 참고).
