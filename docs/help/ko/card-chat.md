## 열기

휴대전화에서는 할 일 제목을 탭하세요. 컴퓨터에서는 **채팅에서 보기 ›** 또는 할 일의 채팅 링크를 누르세요. 컴퓨터에서 제목을 클릭하면 할 일 이름이 바뀌어요.

## 채팅에 표시되는 이메일

이메일에는 새로 추가된 내용만 표시돼요. 인용된 이전 메시지는 **이전 메시지** 아래에 접혀 있어요. **대화 읽기**를 누르면 이메일 전체를 볼 수 있어요.

## 작업 내역

메시지를 처리하는 동안에는 할 일을 준비할 때처럼 입력 표시 위에 최신 단계가 표시돼요. 예를 들면 "메일 읽는 중"과 같이 표시돼요. 브라우저를 사용하면 페이지 미리보기도 표시돼요.

완료된 작업은 "12개 항목 확인"처럼 한 줄로 간단히 표시돼요. 열면 단계별 종류와 실행 횟수를 확인할 수 있어요. 예: "example.com에서 브라우저 사용 · 7회". 사이트 이름만 표시하고 주소, 명령어 또는 파일 이름은 표시하지 않아요.

질문을 하려고 멈췄을 때도 "질문: 오늘 보낼까요, 월요일에 보낼까요?"처럼 한 줄로 표시돼요. 그 아래에는 답변만 표시돼요.

## 질문하기

메시지를 쓰기 전에 할 일과 관련된 제안이 최대 3개 표시될 수 있어요. 예: "화요일 오전 10시를 대신 제안". 하나를 탭하면 메시지 입력란에 들어가며, 그대로 보내거나 수정할 수 있어요. 적절한 제안이 없으면 표시되지 않아요.

- 대화 내용, 사람 또는 배경에 관해: "지난번에 뭐라고 했어요?"
- 초안을 변경하려면: "더 짧게 써 줘" 또는 "새 날짜를 언급해 줘".

질문에 답해도 초안은 그대로 유지돼요. 전송은 할 일의 버튼에서 진행해요. 채팅에서는 초안을 작성한 답변과 함께 초안을 전송하지 않아요. 문서 정리처럼 다른 사람에게 영향을 주지 않는 변경은 추가 확인 없이 바로 적용돼요. 요청한 내용 외의 작업은 확인을 받을 때까지 기다려요. 단계가 여러 개인 할 일은 모든 단계가 완료될 때까지 열려 있어요.

컴퓨터에서는 Enter 또는 Ctrl+Enter(Mac에서는 Cmd+Enter)를 눌러 보내고, Shift+Enter를 눌러 줄을 바꿔요. 휴대전화에서는 전송 버튼을 사용하세요.

## 문제가 있을 때

채팅에 "그 사람은 CEO가 아니에요" 또는 "회사를 떠났어요"처럼 알려 주세요. The Machine은 출처에서 내용을 수정해요. 역할, 회사, 직함, 프로젝트 단계, 할 일의 프로젝트 또는 학습한 규칙을 수정할 수 있어요. 변경 내용은 "수정 완료: Sam의 이메일 서명에 따라 역할을 영업 총괄로 변경했어요"처럼 표시되며, **실행 취소**도 함께 표시돼요. 실행 취소를 누르면 이전 값으로 돌아가요. 단, 그사이에 값이 변경된 경우에는 되돌리지 않아요.

잘못된 값을 바탕으로 작성된 다른 초안은 하나씩 다시 작성돼요. 해당 채팅에는 **수정 후 초안을 다시 작성하는 중**이라고 표시돼요. 직접 수정하거나 승인한 초안과 발송 중인 초안은 그대로 유지돼요. 답변에 각 초안이 몇 개인지 표시돼요.

GBrain 페이지에서는 The Machine이 작성한 섹션만 변경돼요. 직접 작성한 내용은 그대로 유지돼요. 내용의 출처를 확인할 수 없으면 메모를 바탕으로 학습해요.

## 모델 및 사고 수준

메시지 입력란 아래에 "GPT-6.2 Sol", "낮은 사고 수준"처럼 모델과 사고 수준이 표시돼요. 둘 중 하나를 탭하면 이 채팅에서만 사용할 다른 항목을 선택할 수 있어요. 새 채팅에는 **설정**의 **모델**에서 지정한 항목이 사용돼요([모델](model.md) 참고).

모델 메뉴 아래쪽의 **빠름**을 켜면 할 일 채팅에서 더 빠르게 답변해요. 비용은 약 두 배가 들거나 요금제 사용량이 두 배로 늘어나요. 이 기능은 모든 할 일 채팅에서 보내는 메시지와 실행에 적용되며, 백그라운드 작업에는 적용되지 않아요. 기본적으로 꺼져 있고, 지원하지 않는 모델에서는 비활성화돼요.

## 답변 중지하기

답변을 작성하는 동안 전송 버튼이 **중지**로 바뀌어요. **중지**를 누르면 답변 작성이 즉시 끝나고 지금까지 작성된 내용이 **중지됨**으로 표시돼요. 계속하려면 새 메시지를 작성하거나 **다시 시도**를 탭하세요.

## 파일 추가

클립을 탭하거나, 스크린샷을 붙여 넣거나, 파일을 채팅에 끌어다 놓으세요. 파일은 메시지 입력란 위에 표시되고, ×를 누르면 삭제돼요. 파일만 보내는 메시지도 작성할 수 있어요.

- 최대 5MB의 이미지(PNG, JPEG, GIF, WebP)는 이미지로 모델에 전달돼요.
- 최대 10MB의 PDF, 텍스트 파일, 스프레드시트(CSV), Office 파일은 The Machine이 읽고 초안에 첨부할 수 있어요.
- 메시지 하나에 파일을 최대 5개까지 첨부할 수 있어요.

파일은 메시지와 마찬가지로 암호화되어 내 Machine에 보관돼요. 추가했지만 보내지 않은 파일은 하루 뒤 삭제돼요. **새 할 일**에서도 새 할 일에 파일을 첨부할 수 있어요([직접 만들기](cards.md#make-one-yourself) 참고).
