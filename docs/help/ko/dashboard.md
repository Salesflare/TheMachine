## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 다가오는 한 주의 회의, 마감이 있는 할 일, 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 Machine이 정기적으로 처리하는 작업이에요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. 각각의 페이지는 사이드바에서 열 수 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 팀, 가족, 친구가 있다면 여기서 확인해요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일이 어떻게 진행되는지, 무엇을 배웠는지 확인해요.
- **연결**: 연결된 소스와 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 위쪽의 **검색 또는 질문**으로 할 일, 사람, 메시지 등을 찾을 수 있어요. 바로 아래에는 **새 할 일**이 있어요. 사이드바 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인** 아래에 표시되므로, 개수가 위쪽에 표시된 수와 같아요. 항목을 누르면 열려요.

할 일 메뉴를 열려면 항목에 마우스를 올리고 **⋯**를 클릭하거나, 마우스 오른쪽 버튼을 누르거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택하고 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**, **열기** 외에도 할 일마다 **완료로 표시**, **미루기**, **필요 없음**이 있고, 각 작업을 **실행 취소**할 수 있어요.

**브라우저**에는 Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**를 누르거나 사이트에 로그인해야 할 때 **브라우저 열기**를 눌러도 같은 위치에 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 원래대로 돌아가요.

할 일에서 브라우저를 사용하는 동안 위쪽에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 더 이상 클릭하거나 입력하거나 전송하지 않고, 할 일의 채팅에 "브라우저에서 중지됨"이라고 표시돼요.

실행 중인 작업이 여러 개라면 현재 앞에 표시된 작업이 중지돼요. 계속하려면 할 일의 채팅에 메시지를 쓰거나 **다시 시도**를 누르세요.

할 일이 많으면 사이드바 전체가 한 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면을 가득 채우고, 입력 중에도 버튼을 항상 누를 수 있어요.

## 더 다양하게 활용하기

할 일 탭 위쪽에는 작은 할 일이 있어요. 휴대폰 앱, 데스크톱 앱, 알림, WhatsApp, 다른 계정, 추가 연결처럼 The Machine을 더 유용하게 만드는 항목을 보여줘요. 각 행에는 해당 단계를 위한 버튼이 하나씩 있고, 단계를 마치면 목록에서 사라져 할 일에는 남은 항목만 표시돼요. 한 번에 최대 다섯 개 행이 표시되고, 아직 진행하지 않은 단계가 먼저 나와요. 따라서 GitHub처럼 이메일에서 제안된 도구는 앞선 단계를 마친 뒤에 행으로 표시돼요.

행은 관련 있는 곳에만 표시돼요. 데스크톱 앱이 설치되지 않은 컴퓨터에서는 Chromebook처럼 브라우저에서 대시보드를 설치하도록 안내해요. 행의 ×를 누르면 모든 기기에서 해당 행이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "남은 단계 2개 · 계속하기"처럼 조용한 한 줄로 접혀요. 눌러서 할 일을 열고, 화살표를 누르면 다시 접혀요.

처음 2주 동안은 새 할 일이 하루에 하나 이하인 날에 이유와 함께 제안 하나가 할 일 맨 앞에 표시될 수 있어요. 예를 들면 "WhatsApp을 연결할까요? 이메일 5개에서 언급됐어요." 또는 "WhatsApp을 다시 시도할까요? 코드가 만료됐어요."처럼 표시돼요. 접힌 상태에서는 제안과 버튼, ×만 보여요. 이 제안은 해당 단계의 기본 행을 대신해요. 첫 화면 안내의 마지막에 다음 단계가 표시되는 동안에는 제안이 기다려요.

제안은 The Machine이 이미 알고 있는 내용만 사용해요. WhatsApp 링크나 사람들에게서 받은 메일에 언급된 WhatsApp, 연결된 메일함에 포함되지 않은 내 주소, Slack 또는 Teams 회의에서 온 메일, 완료되지 않은 연결이 해당돼요. 메시지의 내용이나 보낸 사람은 표시하지 않고, 개수만 표시해요. 한 번에 하나씩, 하루 최대 하나만 표시되며 이메일이나 알림으로 보내지 않아요. 제안의 ×를 누르면 다시 표시되지 않아요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 행을 다시 표시할 수 있어요. 할 일 전체를 다시 표시하려면 **설정**에서 **일반**, **초기 설정 할 일**을 선택하세요. **설정**의 **일반**에 있는 **이 기기**에도 같은 설정이 있고, **설정**의 **앱**에는 항상 휴대폰 앱이 표시돼요. 컴퓨터에서는 데스크톱 앱도 표시돼요.

## 새 버전

대시보드의 새 버전은 사용 중에 새로고침되지 않아요. 앱을 열거나 창을 몇 분 동안 백그라운드에 두거나 사용하지 않을 때 불러와요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 방해하지 않아요. 위쪽의 **업데이트 준비됨**을 누르면 바로 불러와요.

큰 기능이나 개선 사항이 출시되면 **새로운 기능** 안내가 표시돼요. 하루에 최대 한 번 표시돼요. **뒤로**와 **다음**을 누르거나 스와이프해서 내용을 살펴보세요. 안내에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 닫혀요. 진행 중인 작업을 방해하지 않으며, 닫으면 모든 기기에서 사라져요. 사용을 시작한 뒤 출시된 기능만 표시돼요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 눌러 검색을 열고, 휴대폰에서는 검색 아이콘을 누르세요. 두 글자 이상 입력하면 **메시지**에 Machine이 읽은 내용 전체에서 의미나 단어가 가장 잘 맞는 결과가 표시돼요. 오래된 [기록](history.md)은 단어로 검색돼요.

검색창에 질문을 입력할 수도 있어요. 비어 있는 검색창에서 제안하는 질문처럼, 내 메시지를 바탕으로 짧은 답변을 받을 수 있어요([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 모든 계정 또는 한 계정의 전체 결과가 열려요. 각 결과는 내용을 읽을 수 있는 화면에서 열리고, 원본으로 이동하는 링크가 함께 표시돼요. 검색어가 없으면 최신 메시지가 표시돼요.

검색 결과에는 가장 잘 맞는 항목이 먼저 표시돼요. 휴대폰에서 전체 메시지의 미리보기를 보면 해당 메시지가 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 맨 위에 짧은 답변과 출처 메시지가 표시돼요. 메시지에 답이 없으면 답변이 표시되지 않아요.

## 배운 점

배운 점에서는 The Machine이 사용자에게서 배운 내용과 할 일이 얼마나 잘 처리되는지 확인할 수 있어요. 내용이 없는 탭은 숨겨져요.

- **배운 점**: 메모를 바탕으로 한 글쓰기 방식, 사실, 선호하는 작업 방식을 확인해요. 원하는 표현으로 직접 **수정**하고 더 이상 사실이 아닌 내용은 **삭제**할 수 있어요. 채팅에 무언가를 잊으라고 요청할 수도 있어요("이사한 것 잊어줘"). 명확하게 일치하는 사실이 하나 있으면 삭제되고, **설정**의 **활동**과 **변경사항**에서 **실행 취소**할 수 있어요. 일치하는 내용이 여러 개면 채팅에서 어느 것인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우, 할 일의 채팅에 **배운 점에 저장했어요**라고 표시되고 **수정**과 **실행 취소**가 제공돼요.
- 사실에는 **임시**, **약속**, **선호 항목** 유형을 지정하고, 해당 내용이 유지되는 시점을 **까지**로 설정할 수 있어요. 임시 사실은 몇 주, 선호 항목과 약속은 몇 달, 다른 사실은 1년이 지나면 사라져요. 설정한 날짜가 지났거나 새 메시지에서 더 이상 유효하지 않다는 점이 확인되면 사실이 **종료됨**으로 이동하고, **복원**을 누르면 다시 활성화돼요.
- **사실**에는 나와 내 작업 방식에 관한 일반적인 내용이 있어요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알려진 정보**에 저장되며, 여기서 수정할 수 있어요. 이름 전체가 포함된 사실은 저장할 때 해당 페이지로 이동하고, 할 일의 채팅에 Graph의 해당 항목에 **추가됨**이라고 표시돼요. **사실** 아래의 조용한 한 줄에는 Graph 페이지에 저장된 사실의 수가 표시돼요. 누르면 각 페이지로 이동해요. 내가 작성한 메시지에서 나온 사실에는 출처가 된 문구가 따옴표로 표시돼요.
- 누군가의 전화번호나 이메일 주소를 추가하면 사실이 아니라 Graph의 해당 페이지에 저장돼요. 번호가 이미 한 레코드에 있고 이름이 같은 다른 레코드가 하나 더 있으면 두 레코드가 병합돼요. 할 일의 채팅에 **에 추가됨**과 이름이 표시되고, **실행 취소**를 사용할 수 있어요. 누구의 정보인지 확실하지 않으면 사실로 남아요.
- 사용하지 않는다는 이유로 삭제되는 내용은 없어요. 각 할 일에는 관련성이 가장 높은 사실이 제공되고, 최근 정보일수록 더 중요하게 반영돼요. 따라서 자주 필요하지 않은 사실도 다른 내용을 방해하지 않고 보관돼요. 종료된 사실도 관련 할 일이나 채팅에서는 과거 기록으로만 활용돼요. 현재 상태로 취급되지는 않아요.
- 메모에 이미 배운 내용을 다른 말로 적으면 기존 내용을 바꿔 중복 표시되지 않아요. **병합 실행 취소**를 누르면 이전 표현을 복원해요. 직접 수정한 내용은 바뀌지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? 메모 파일(`MEMORY.md`, `USER.md`)에서 보관할 만한 문장이 맨 위에 표시되고, 각 문장에는 출처 파일이 함께 표시돼요. 보관할 항목을 선택한 다음 **선택 항목 유지**를 누르세요. 다른 내용과 마찬가지로 사실이나 규칙으로 저장돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 나에 관한 사실은 **사실**에 남아요. **나머지 무시**를 누르면 해당 항목은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 알고 있는 나에 관한 정보를 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 누른 다음, 해당 AI에 보내고 답변을 붙여 넣으세요. **검토** 화면에서 각 문장을 보관하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 문장은 건너뛰고, 기존 사실과 다른 문장은 해당 사실 옆에 표시해 어느 쪽을 유지할지 선택할 수 있어요. 비밀번호, 코드, 키, 카드 번호와 계정 번호는 표시되기 전에 제외돼요. 권한을 부여하려는 문장도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한으로 취급되지 않아요. 각 항목에는 출처와 날짜가 표시되고 **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일과 첫 화면 안내를 읽는 동안에도 사용할 수 있어요.
- **변경사항**: 수정, 무시, 채팅에서 반영된 내용이 표시되고 각 항목에서 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대한 선택을 시간순으로 확인해요.
- **공유됨**: The Machine 팀과 공유할 배운 점과, 확인이 필요한 투표가 있으면 여기에 표시돼요. [배운 점 공유](share-learnings.md)를 참고하세요.
- **진행 상황**: 최근 30일간의 수치 네 가지를 확인해요. 높을수록 좋아요. 처리하거나 무시한 할 일을 3개 결정한 뒤부터 수치가 표시돼요. 그전에는 지금까지 결정한 할 일 수가 표시돼요.
  - **도움 됨**: 결정한 할 일 중 무시하지 않고 실행(**실행**, 전송 또는 완료)한 비율이에요.
  - **완료**: **실행**으로 시작해 종료된 할 일 중 완료된 비율이에요. 단계가 전송됐거나, 직접 완료로 표시했거나, 자동으로 완료 처리된 경우를 말해요. 무시되거나 만료된 항목은 미완료로 계산돼요. 아직 열려 있는 항목은 계산에 포함되지 않고 **아직 열림**으로 표시돼요.
  - **첫 시도**: 완료된 항목 중 **실행** 후 수정할 필요가 없었던 비율이에요.
  - **완료**와 **첫 시도**는 할 일이 3개 이상일 때부터 수치가 표시돼요.
  - **그대로 전송**: 전송한 초안 중 수정하거나 먼저 **수정 요청**을 하지 않고 보낸 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 차트에는 처음 2주 동안은 하루 단위로, 이후에는 주 단위로 막대가 표시되며 최대 8주까지 보여줘요.
  - **출처별 도움 됨**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **Android 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 할 일 수예요.
  - **놓친 할 일**: The Machine은 일주일에 한 번 할 일로 만들어지지 않은 메시지를 일부 확인하고, 할 일이 필요했을 만한 메시지 수를 추정해요. 찾아낸 항목이 목록에 표시돼요. **열기** 또는 메시지 자체를 누르면 메시지를 확인할 수 있고, **실제 누락** 또는 **놓친 항목이 아니에요**를 눌러 판단이 맞았는지 알려줄 수 있어요. **실제 누락**을 누르면 할 일도 추가돼요. **실행 취소**할 수 있고, **할 일 열기**를 누르면 해당 할 일이 열려요. The Machine은 이 내용을 바탕으로 배우므로 이후에는 비슷한 메시지를 찾아낼 수 있어요. 답변은 수치에 즉시 반영되고 내 Machine에 저장돼요. 몇 개만 남으면 백분율 대신 **적음**이라고 표시돼요. 첫 번째 주간 확인 후부터 표시돼요.
