## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 예정된 한 주의 일정과 마감일이 있는 할 일, 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 내 Machine이 정기적으로 처리하는 작업을 확인해요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. 각 항목에는 사이드바에서 열 수 있는 페이지가 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에서 팀, 가족, 친구를 확인해요. Fleet이 있을 때 표시돼요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일의 진행 상황과 배운 내용을 확인해요.
- **연결**: 연결된 소스와 각 소스의 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 위쪽의 **검색 또는 질문**으로 할 일, 사람, 메시지 등을 찾을 수 있고, 바로 아래에서 **새 할 일**을 만들 수 있어요. 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 마찬가지로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인**에 표시되므로, 숫자는 페이지 상단의 숫자와 같아요. 할 일을 탭하면 열려요.

할 일 메뉴를 열려면 마우스를 올린 뒤 **⋯**를 클릭하거나, 마우스 오른쪽 버튼을 클릭해요. 휴대폰에서는 길게 누르면 돼요. 키보드에서는 할 일에 포커스를 둔 채 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**, **열기**와 할 일별 **완료**, **미루기**, **필요 없음**이 있으며, 각 항목은 **실행 취소**할 수 있어요.

**브라우저**에는 내 Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**와 사이트에 로그인이 필요할 때 표시되는 **브라우저 열기**도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체에 표시돼요. 다시 누르면 돌아가요.

할 일에서 브라우저를 사용하는 동안에는 상단에 **중지**가 표시돼요. 한 번 누르면 실행이 바로 끝나요. 더 이상 클릭하거나 입력하거나 전송하지 않고, 할 일의 채팅에 "브라우저에서 중지됨"이라고 표시돼요.

실행이 여러 개라면 앞에 표시된 실행이 중지돼요. 계속하려면 할 일의 채팅에 내용을 입력하거나 **다시 시도**를 누르세요.

할 일이 많아 공간이 부족하면 사이드바 전체가 한 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면 전체에 표시되고, 입력 중에도 버튼을 항상 누를 수 있어요.

## 더 활용하기

할 일 페이지 상단의 작은 할 일에는 내 Machine을 더 유용하게 만드는 항목이 표시돼요. 휴대폰 앱, 알림, WhatsApp, 이 컴퓨터의 앱, 다른 계정, 추가 연결 등이 있어요. 각 항목에는 해당 단계를 진행하는 버튼이 하나씩 있고, 완료하면 목록에서 사라져 남은 항목만 표시돼요. 최대 다섯 개까지 표시하며, 아직 완료하지 않은 단계가 먼저 나와요. 따라서 메일에서 GitHub 같은 도구를 제안하면 앞선 단계가 완료된 뒤 목록에 표시돼요.

각 항목은 필요한 곳에만 표시돼요. 항목 옆의 ×를 누르면 모든 기기에서 해당 항목이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "2단계 남음 · 계속하기"처럼 한 줄로 접혀 표시돼요. 탭하면 할 일이 열리고, 화살표를 탭하면 다시 접혀요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 항목을 다시 표시할 수 있어요. 할 일 전체를 다시 표시하려면 **설정**, **일반**, **초기 설정 할 일**을 이용하세요. **설정**, **일반**, **이 기기**에도 같은 설정이 있고, **설정**, **앱**에는 항상 휴대폰 앱이 표시돼요.

## 새 버전

대시보드 새 버전은 사용 중에 새로고침되지 않아요. 앱을 열거나 창이 몇 분 동안 백그라운드에 있거나 유휴 상태였을 때 불러와요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있을 때는 방해하지 않아요. 상단의 **업데이트 준비됨**을 누르면 바로 불러올 수 있어요.

주요 기능이나 개선 사항이 출시되면 간단한 **새 소식**으로 알려 드려요. 하루에 한 번까지만 표시돼요. **뒤로**와 **다음**을 누르거나 스와이프해 내용을 살펴보세요. 소식에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 닫혀요. 진행 중인 작업 위에는 표시되지 않고, 닫으면 모든 기기에서 사라져요. 사용을 시작한 뒤 출시된 내용만 표시돼요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`를 누르거나, 휴대폰에서 검색 아이콘을 눌러 검색을 열어요. 두 글자 이상 입력하면 **메시지**에 내 Machine이 읽은 모든 내용 중 가장 잘 맞는 결과가 의미나 단어 기준으로 표시돼요. 오래된 [기록](history.md)은 단어 기준으로 검색돼요.

여기에서 질문도 할 수 있어요. 검색창이 비어 있을 때 제안되는 질문을 입력하면 내 메시지에서 간단한 답을 찾아 줘요 ([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 한 계정의 결과 목록이 열려요. 결과를 누르면 내용을 읽을 수 있는 화면이 열리고, 원본으로 이동하는 링크도 있어요. 검색어가 없으면 최신 메시지가 표시돼요.

검색 결과에는 가장 관련성이 높은 항목이 먼저 표시돼요. 전체 내용이 있는 메시지의 휴대폰 미리보기는 해당 메시지로 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 맨 위에 간단한 답과 출처 메시지가 표시돼요. 메시지에 답이 없으면 아무 답도 표시되지 않아요.

## 배운 점

배운 점에는 내 Machine이 나에게서 배운 내용과 할 일의 효과가 표시돼요. 내용이 없는 탭은 숨겨져요.

- **배운 내용**: 메모를 통해 배운 글쓰기 방식, 사실, 선호하는 처리 방식을 확인해요. 원하는 내용으로 직접 **수정**하고, 더 이상 사실이 아닌 내용은 **삭제**할 수 있어요. 채팅에 잊어 달라고 요청할 수도 있어요("이사한 걸 잊어 줘"). 사실 하나가 분명하게 일치하면 해당 내용이 삭제되고, **설정**, **활동**, **변경사항**에서 **실행 취소**할 수 있어요. 여러 내용이 일치하면 채팅에서 어느 내용인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우, 할 일의 채팅에 **배운 내용에 저장했어요**라고 표시되며 **수정**과 **실행 취소** 옵션이 있어요.
- 사실에는 **임시**, **약속**, **선호 항목** 유형이 있고, 적용 기간은 **까지**로 표시돼요. 임시 사실은 몇 주 후에 사라지고, 선호 항목과 약속은 몇 달 후에 사라져요. 그 외 사실은 1년 후에 사라져요. 날짜가 지나거나 새 메시지에서 더 이상 유효하지 않다는 점이 확인되면 사실은 **종료됨**으로 이동하고, **복원**을 누르면 되돌릴 수 있어요.
- **사실**에는 나와 내 업무 방식에 관한 일반적인 사실이 있어요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알고 있는 내용**에 저장돼요. 여기서 수정할 수 있어요. 전체 이름을 언급하는 사실은 저장할 때 해당 페이지로 이동하며, 할 일의 채팅에 Graph의 해당 페이지에 **저장했어요**라고 표시돼요. **사실** 아래에는 Graph 페이지에 저장된 사실의 개수가 한 줄로 표시돼요. 누르면 각 페이지로 이동해요. 직접 작성한 메시지에서 가져온 사실에는 해당 내용이 따옴표와 함께 표시돼요.
- 다른 사람의 전화번호나 이메일 주소를 입력하면 사실이 아니라 Graph의 해당 페이지에 추가돼요. 전화번호가 이미 한 항목에 있고 다른 항목의 이름이 같으면 두 항목이 병합돼요. 할 일의 채팅에 **추가됨**과 이름이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 분명하지 않으면 사실로 남아요.
- 사용하지 않는다는 이유로 삭제되는 내용은 없어요. 각 할 일에는 가장 관련성이 높은 사실이 포함되고, 최근에 추가된 사실일수록 더 중요하게 반영돼요. 따라서 자주 필요하지 않은 사실도 다른 내용을 밀어내지 않고 유지돼요. 종료된 사실도 관련된 할 일이나 채팅에서는 참고할 수 있지만, 현재 상황이 아니라 과거 기록으로만 사용돼요.
- 이미 배운 내용을 다른 말로 적은 메모는 기존 내용을 대체해 중복되지 않게 해요. **병합 실행 취소**를 누르면 이전 표현이 복원돼요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? 보관할 만한 메모의 내용(`MEMORY.md`, `USER.md`)이 맨 위에 표시되고, 각 내용에는 출처 파일이 함께 표시돼요. 보관할 항목을 선택한 다음 **선택 항목 유지**를 누르면 다른 내용과 마찬가지로 사실이나 규칙으로 저장돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동해요. 생일은 생일 루틴에도 추가돼요. 나에 관한 내용은 **사실**에 남아요. **나머지 무시**를 누르면 나머지 항목은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 알고 있는 내 정보를 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 눌러 해당 AI에 보낸 다음, 답변을 붙여 넣으세요. **검토** 화면에서 각 항목을 보관하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 내용은 건너뛰고, 기존 사실과 다른 내용은 비교할 수 있도록 나란히 표시돼요. 어느 내용을 유지할지 선택하세요. 비밀번호, 코드, 키, 카드 번호, 계좌 번호는 표시 전에 제외돼요. 권한을 부여하려는 내용도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한으로 사용되지 않아요. 각 사실에는 출처와 날짜가 표시되고 **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일에서도 사용할 수 있고, 첫 확인이 진행되는 동안에도 사용할 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 반영된 내용이 표시되며, 각 항목을 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대해 내린 선택이 시간순으로 표시돼요.
- **공유됨**: The Machine 팀과 공유할 배운 내용과 참여할 수 있는 투표가 표시돼요. [배운 점 공유하기](share-learnings.md)를 참고하세요.
- **진행 상황**: 최근 30일을 기준으로 한 네 가지 수치가 표시돼요. 수치가 높을수록 좋아요. 결정한 할 일(실행하거나 무시한 할 일)이 3개가 되면 수치가 표시되기 시작해요. 그 전에는 지금까지 결정한 할 일의 개수가 표시돼요.
  - **가치**: 결정한 할 일 중 무시하는 대신 실행한 할 일(**실행**, 전송 또는 완료)의 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 이후 수정이 필요하지 않았던 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속 진행하거나 다시 시도해 달라고 요청하지 않아도 완료된 비율이에요.
  - **그대로 전송**: 전송한 초안 중 먼저 수정하거나 **수정 요청**을 하지 않고 보낸 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 차트는 처음 2주 동안 일별 막대로 표시되고, 이후에는 최대 8주까지 주별 막대로 표시돼요.
  - **출처별 가치**: 출처별로 실행한 할 일의 수를 보여 줘요. 예를 들면 **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **전화 알림**, **The Machine 자체**(오류 같은 문제)가 있어요.
  - **놓친 할 일**: 일주일에 한 번, The Machine이 할 일로 만들어지지 않은 메시지 일부를 확인해 할 일이 필요했을 가능성을 추정해요. 확인된 메시지가 목록에 표시돼요. **열기** 또는 메시지 내용을 누르면 메시지가 열리고, **실제 누락** 또는 **놓친 항목이 아니에요**를 눌러 판단이 맞았는지 알려 줄 수 있어요. **실제 누락**을 누르면 할 일도 추가돼요. **실행 취소**할 수 있고, **할 일 열기**를 누르면 해당 할 일이 열려요. The Machine은 이 응답을 바탕으로 배워 이후 비슷한 메시지를 찾아내요. 응답은 수치에 바로 반영되고 내 Machine에 저장돼요. 남은 항목이 몇 개뿐이면 비율 대신 **적음**이라고 표시돼요. 첫 주간 확인이 끝난 뒤 표시돼요.
