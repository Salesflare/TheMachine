## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 다가오는 한 주의 회의, 마감이 있는 할 일과 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 속한 팀, 가족, 친구를 확인해요. Fleet이 있으면 표시돼요. [Fleet](fleet.md)를 참고하세요.
- **학습**: 할 일이 어떻게 진행되고 있는지, 무엇을 배웠는지 확인해요.
- **연결**: 연결된 소스와 각 소스의 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 위쪽의 **검색**으로 할 일, 사람, 메시지 등을 찾아요. **브라우저**, **도움말**, **설정**은 아래쪽에 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **나를 위한**에 표시되므로, 할 일 개수는 맨 위에 표시되는 개수와 같아요. 항목을 눌러 열어요.

할 일 메뉴를 열려면 항목에 마우스를 올리고 **⋯**를 클릭하거나, 마우스 오른쪽 버튼을 누르거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택한 뒤 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**와 **열기** 외에도 할 일마다 **완료**, **미루기**, **필요 없음**이 있고, 각 작업을 **실행 취소**할 수 있어요.

**브라우저**에는 The Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**를 누르거나 사이트에 로그인해야 할 때 **브라우저 열기**를 눌러도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 돌아가요.

할 일에서 브라우저를 사용하는 동안에는 위쪽에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 더는 클릭하거나 입력하거나 전송하지 않고, 할 일 채팅에 “브라우저에서 중지했어요”라고 표시돼요.

실행 중인 작업이 여러 개면, 현재 진행 중인 작업이 중지돼요. 계속하려면 할 일 채팅에 메시지를 쓰거나 **다시 시도**를 누르세요.

할 일이 많아 한 화면에 다 보이지 않으면 사이드바 전체가 하나의 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면 전체에 표시돼요. 입력하는 동안에도 버튼을 항상 누를 수 있어요.

## 더 다양하게 활용하기

할 일 탭 맨 위의 작은 할 일에는 The Machine을 더 유용하게 만드는 방법이 표시돼요. 휴대폰 앱, 알림, WhatsApp, 이 컴퓨터의 앱, 다른 계정, 추가 연결 등이 있어요. 각 행에는 해당 단계를 위한 버튼이 하나씩 있고, 단계를 완료하면 목록에서 사라져 남은 할 일만 표시돼요. 행은 최대 다섯 개까지 표시하고, 아직 완료하지 않은 단계를 먼저 보여줘요. 따라서 메일에서 추천한 GitHub 같은 도구도 앞선 단계를 완료한 뒤에 행으로 표시돼요.

각 행은 해당하는 경우에만 표시돼요. 행의 ×를 누르면 모든 기기에서 해당 행이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **나를 위한** 위에 “2단계 남음 · 계속하기”처럼 한 줄로 접혀 표시돼요. 눌러서 할 일을 열고, 화살표를 눌러 다시 접어요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 행을 다시 표시할 수 있어요. 할 일 전체를 다시 표시하려면 **설정**, **일반**, **초기 설정 할 일**로 이동하세요. **설정**, **일반**, **이 기기**에도 같은 설정이 있고, **설정**, **앱**에는 휴대폰 앱이 항상 표시돼요.

## 새 버전

대시보드를 사용하는 동안에는 새 버전이 새로고침되지 않아요. 앱을 열 때나 창이 백그라운드에 있거나 몇 분 동안 사용하지 않았을 때 새 버전이 로드돼요. 저장하지 않은 텍스트나 열린 대화상자를 방해하지 않아요. 위쪽의 **업데이트 준비됨**을 누르면 바로 로드돼요.

주요 기능이나 개선 사항이 출시되면 작은 **새로운 기능** 안내로 알려드려요. 하루에 한 번까지만 표시돼요. **뒤로**와 **다음**을 누르거나 화면을 밀어 안내를 살펴보세요. 안내에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 안내가 닫혀요. 진행 중인 작업 위에는 표시되지 않고, 한 번 닫으면 모든 기기에서 사라져요. 시작한 뒤 출시된 내용만 볼 수 있어요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 눌러 검색을 열고, 휴대폰에서는 검색 아이콘을 누르세요. 두 글자 이상 입력하면 **메시지**에 The Machine이 읽은 모든 내용 중 가장 관련 있는 결과가 표시돼요. 단어나 의미를 기준으로 검색해요. 오래된 [기록](history.md)은 단어로 검색돼요.

여기서 질문을 할 수도 있어요. 빈 검색창에 표시되는 질문처럼 입력하면 내 메시지에서 짧은 답변을 찾아줘요([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 계정 하나의 결과 목록이 열려요. 각 결과를 누르면 리더에서 열리고, 출처로 이동하는 링크가 표시돼요. 검색어가 없으면 최신 메시지가 표시돼요.

검색 결과는 가장 관련 있는 항목이 먼저 표시돼요. 메시지 전체를 볼 수 있는 경우 휴대폰 미리보기는 해당 메시지로 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 위쪽에 짧은 답변과 출처 메시지가 표시돼요. 메시지에서 답을 찾을 수 없으면 답변이 표시되지 않아요.

## 학습

학습에는 The Machine이 배운 내용과 할 일의 성과가 표시돼요. 내용이 없는 탭은 숨겨져요.

- **배운 점**: 메모에서 파악한 글쓰기 방식, 사실, 선호하는 작업 방식을 확인해요. 원하는 말로 직접 **수정**하고, 더 이상 맞지 않는 내용은 **삭제**할 수 있어요. 채팅에 잊어 달라고 요청할 수도 있어요(“내가 이사했다는 걸 잊어”). 사실 하나가 분명하게 일치하면 삭제되고, **설정**, **활동**, **변경사항**에서 **실행 취소**할 수 있어요. 여러 사실이 일치하면 채팅에서 어떤 사실인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우 할 일 채팅에 **배운 내용에 저장했어요**가 표시되며, **수정**과 **실행 취소**를 할 수 있어요.
- 사실은 **임시**, **약속**, **선호 항목**으로 표시할 수 있고, 적용 기간은 **까지**에 설정해요. 임시 사실은 몇 주, 선호 항목과 약속은 몇 달, 그 밖의 사실은 1년이 지나면 희미해져요. 설정한 날짜가 지나거나 새 메시지를 통해 더 이상 유효하지 않다는 점이 확인되면 사실은 **종료됨**으로 이동해요. 여기서 **복원**할 수 있어요.
- **사실**에는 일반적인 사실, 즉 나와 작업 방식에 관한 내용이 표시돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알고 있는 정보**에 저장돼요. 여기서 수정할 수 있어요. 사람, 조직, 프로젝트의 전체 이름이 포함된 사실은 저장될 때 해당 페이지로 이동하고, 할 일 채팅에는 해당 이름이 **Graph에 추가됨**으로 표시돼요. **사실** 아래에는 Graph 페이지에 저장된 사실의 개수를 한 줄로 표시해요. 누르면 각 페이지로 이동해요.
- 다른 사람의 전화번호나 이메일 주소를 추가하면 사실이 아니라 Graph의 해당 페이지에 저장돼요. 한 기록에 이미 번호가 있고, 다른 기록에 이름이 같으면 두 기록이 병합돼요. 할 일 채팅에는 이름과 함께 **에 추가됨**이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 분명하지 않으면 사실로 남아요.
- 목록은 가득 차지 않아요. 목록이 길어지면 3주 동안 사용하지 않은 사실과 규칙은 **따로 보관**으로 이동해요. 여기서 **복원**할 수 있어요. 수정하거나 복원한 항목은 그대로 남아요. 따로 보관된 사실도 관련된 할 일이나 채팅에서 도움이 되고, 종료된 사실은 과거 기록으로만 활용되며 현재 상황을 나타내는 데는 쓰이지 않아요.
- 메모에서 이미 배운 내용을 다른 말로 설명하면 기존 내용을 대체하므로 같은 내용이 중복 표시되지 않아요. **병합 실행 취소**를 누르면 이전 표현이 복원돼요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? OpenClaw 메모 파일(`MEMORY.md`, `USER.md`)에서 보관할 만한 내용이 맨 위에 표시되고, 각 항목에는 출처 파일이 표시돼요. 보관할 항목을 선택한 다음 **선택 항목 유지**를 누르세요. 다른 내용과 마찬가지로 사실이나 규칙으로 저장돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고(생일은 생일 루틴에도 추가돼요), 나에 관한 사실은 사실에 남아요. **나머지 무시**를 누르면 해당 내용은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **변경사항**: 수정, 무시, 채팅을 통해 새로 파악한 내용을 확인하고 각각 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대해 내린 선택을 시간순으로 보여줘요.
- **공유됨**: The Machine 팀과 공유할 학습 내용과 투표할 항목이 있으면 표시돼요. [학습 내용 공유](share-learnings.md)를 참고하세요.
- **진행 상황**: 최근 30일 동안의 수치 네 가지를 보여줘요. 수치가 높을수록 좋아요. 할 일을 3개 이상 결정한 뒤(실행하거나 무시한 경우)부터 수치가 표시돼요. 그전에는 지금까지 결정한 할 일의 개수를 보여줘요.
  - **가치**: 결정한 할 일 중 무시하지 않고 실행한(**실행**, 전송 또는 완료) 할 일의 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 이후 수정이 필요하지 않았던 할 일의 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속 진행하거나 다시 시도해 달라고 요청하지 않아도 끝난 할 일의 비율이에요.
  - **그대로 전송**: 초안 중 수정하거나 먼저 **수정 요청**을 하지 않고 전송한 초안의 비율이에요.
  - 각 수치는 이전 30일과 비교해요. 차트에는 첫 2주 동안은 하루에 하나씩, 그 뒤로는 최대 8주까지 주마다 막대 하나가 표시돼요.
  - **출처별 가치**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **전화 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 할 일의 수를 보여줘요.
  - **놓친 할 일**: The Machine은 일주일에 한 번, 할 일로 이어지지 않은 메시지 일부를 확인하고 할 일이 필요했을 가능성을 추정해요. 발견한 메시지가 목록에 표시돼요. **열기** 또는 메시지 줄 자체를 누르면 메시지를 확인할 수 있고, **실제 누락** 또는 **놓친 항목이 아니에요**를 눌러 판단이 맞았는지 알려줄 수 있어요. **실제 누락**을 선택하면 할 일도 추가돼요. **실행 취소**할 수 있고(**할 일 열기**를 누르면 해당 할 일로 이동해요), The Machine은 이를 바탕으로 다음부터 비슷한 메시지를 찾아내요. 답변은 추정의 정확도를 높이는 데 사용되며 The Machine에 저장돼요. 첫 주간 확인이 끝난 뒤부터 표시돼요.
