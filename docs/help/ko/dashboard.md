## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 다가오는 한 주의 회의, 마감이 있는 할 일과 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 Machine이 정기적으로 하는 작업을 확인해요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. 각 항목은 사이드바에서 별도 페이지로 볼 수 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 참여하면 팀원, 가족, 친구를 확인할 수 있어요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일이 얼마나 잘 처리되는지, Machine이 무엇을 배웠는지 확인해요.
- **연결**: 연결된 출처와 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 맨 위의 **검색 또는 질문**에서 할 일, 사람, 메시지 등을 찾을 수 있어요. 바로 아래에는 **새 할 일**이 있어요. 사이드바 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인**에 표시되므로, 위쪽에 보이는 개수와 같아요. 항목을 탭하면 열려요.

할 일 메뉴를 열려면 항목 위에 마우스를 올리고 **⋯**를 클릭하거나, 마우스 오른쪽 버튼을 클릭하거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택한 뒤 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**, **열기**와 함께 할 일별 **완료로 표시**, **미루기**, **필요 없음**이 있고, 각각 **실행 취소**할 수 있어요.

**브라우저**에는 Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**나 사이트에 로그인해야 할 때 표시되는 **브라우저 열기**도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 돌아가요.

할 일에서 브라우저를 사용하는 동안에는 위쪽에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 더는 클릭하거나 입력하거나 전송하지 않으며, 할 일 채팅에 "브라우저에서 중지됨"이라고 표시돼요.

실행 중인 작업이 여러 개라면 가장 앞에 있는 작업이 중지돼요. 계속하려면 할 일 채팅에 메시지를 쓰거나 **다시 시도**를 누르세요.

할 일이 많아 화면에 다 표시되지 않으면 사이드바 전체가 하나의 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면 전체에 표시돼요. 입력 중에도 버튼을 항상 누를 수 있어요.

## 더 활용하기

할 일 상단의 작은 할 일에는 The Machine을 더 유용하게 만드는 항목이 표시돼요. 휴대폰 앱, 데스크톱 앱, 알림, WhatsApp, 다른 계정, 추가 연결 등이 여기에 포함돼요. 각 행에는 해당 단계를 위한 버튼 하나가 있고, 완료하면 목록에서 사라져 남은 항목만 표시돼요. 한 번에 최대 다섯 행까지 표시되며, 아직 완료하지 않은 단계가 먼저 나와요. 따라서 메일에서 제안한 GitHub 같은 도구도 이전 단계를 마치면 행에 표시돼요.

필요한 곳에만 행이 표시돼요. Chromebook처럼 데스크톱 앱이 없는 컴퓨터에서는 브라우저에서 대시보드를 설치하라는 안내가 표시돼요. 행의 ×를 누르면 모든 기기에서 해당 행이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "2단계 남음 · 계속하기"처럼 조용한 한 줄로 접혀요. 탭하면 할 일이 열리고, 화살표를 누르면 다시 접혀요.

처음 2주 동안, 새 할 일이 하루에 최대 하나인 날에는 이유가 포함된 제안 하나가 할 일 맨 앞에 표시될 수 있어요. 예를 들면 "WhatsApp에 연결할까요? 이메일 5개에서 언급됐어요." 또는 "WhatsApp을 다시 시도할까요? 코드가 만료됐어요."처럼요. 접힌 상태에서는 제안, 버튼, ×만 표시돼요. 해당 단계의 일반 행 대신 표시돼요. 첫 안내가 자체적인 다음 단계를 제공하는 동안에는 이 제안이 표시되지 않고 기다려요.

제안은 The Machine이 이미 가지고 있는 정보에서만 나와요. WhatsApp 링크나 사람이 보낸 메일에 나온 WhatsApp 언급, 연결된 메일함에 들어오지 않는 본인 주소, Slack이나 Teams 회의의 메일, 완료되지 않은 연결 등이 해당돼요. 메시지 내용이나 보낸 사람은 표시하지 않고, 개수만 표시해요. 한 번에 하나씩, 하루에 새 제안은 최대 하나만 표시돼요. 이메일이나 알림으로는 보내지 않아요. ×를 누르면 영구적으로 닫혀요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 행을 다시 표시할 수 있어요. 할 일 전체를 다시 표시하려면 **설정**, **일반**, **초기 설정 할 일**로 이동하세요. **설정**, **일반**, **이 기기**에도 같은 옵션이 있어요. **설정**, **앱**에는 항상 휴대폰 앱이 표시되고, 컴퓨터에서는 데스크톱 앱도 표시돼요.

## 새 버전

대시보드를 사용하는 동안에는 새 버전이 자동으로 새로고침되지 않아요. 앱을 열 때, 또는 창을 몇 분간 백그라운드에 두거나 사용하지 않았을 때 로드돼요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 새로고침되지 않아요. 위쪽에 표시되는 **업데이트 준비됨**을 누르면 바로 로드돼요.

주요 기능이나 개선 사항이 출시되면 작은 **새로운 기능** 안내가 표시돼요. 하루에 한 번까지만 표시돼요. **뒤로**와 **다음**을 누르거나 스와이프해 안내를 살펴보세요. 안내의 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 닫혀요. 진행 중인 작업 위에는 표시되지 않으며, 닫으면 모든 기기에서 사라져요. 사용을 시작한 뒤 출시된 항목만 볼 수 있어요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 눌러 검색을 열어요. 휴대폰에서는 검색 아이콘을 누르세요. 두 글자 이상 입력하면 **메시지**에 Machine이 읽은 모든 내용에서 의미나 단어가 가장 잘 맞는 결과가 표시돼요. 이전 [기록](history.md)은 단어로 검색돼요.

여기서 질문도 할 수 있어요. 검색창이 비어 있을 때 표시되는 질문 예시를 눌러도 돼요. 내 메시지를 바탕으로 짧게 답해요([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 선택한 계정의 결과 목록이 열려요. 각 결과는 읽기 화면에서 열리고, 원본으로 이동하는 링크가 표시돼요. 검색어가 없으면 최신 메시지가 표시돼요.

검색 결과에서는 가장 잘 맞는 항목이 먼저 표시돼요. 메시지 전체가 표시되는 휴대폰 미리보기는 해당 메시지로 한 번만 표시돼요. 모든 계정에 대한 질문에는 맨 위에 짧은 답변과 답변의 출처가 된 메시지가 표시돼요. 메시지에 답이 없으면 아무 답도 표시되지 않아요.

## 배운 점

배운 점에서는 The Machine이 사용자에게서 배운 내용과 할 일이 얼마나 잘 처리되는지 확인할 수 있어요. 내용이 없는 탭은 숨겨져요.

- **내가 배운 점**: 메시지에서 파악한 프로필(역할, 말투, 언어, 중요하게 여기는 것), 글쓰기 방식, 사실, 메모에서 파악한 선호하는 작업 방식을 확인해요. 원하는 내용을 직접 작성해 **수정**하고, 더는 사실이 아닌 내용은 **삭제**하세요. 프로필은 `USER.md`에 있어요. 수정하면 해당 줄만 바뀌며, 그곳에서 직접 수정한 줄은 바뀌지 않아요. 채팅에 잊어 달라고 요청할 수도 있어요("이사했다는 사실을 잊어 줘"). 사실 하나가 명확하게 일치하면 삭제되고, **설정**, **활동**, **변경사항**에서 **실행 취소**할 수 있어요. 여러 사실이 일치하면 채팅에서 어떤 사실인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우 할 일 채팅에 **배운 점에 저장했어요**가 표시되고, **수정**과 **실행 취소**를 할 수 있어요.
- 사실에는 **임시**, **약속**, **선호 항목** 유형을 지정할 수 있고, 적용 기간을 **까지**로 설정할 수 있어요. 임시 사실은 몇 주, 선호 항목과 약속은 몇 달, 그 밖의 사실은 1년이 지나면 사라져요. 설정한 날짜가 지나거나 새 메시지를 통해 더는 유효하지 않다는 점이 확인되면 사실이 **종료됨**으로 이동해요. **복원**을 누르면 다시 사용할 수 있어요.
- **사실**에는 일반적인 사실, 즉 본인과 작업 방식에 관한 내용이 표시돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알려진 정보**에 표시되며, 여기서 수정할 수 있어요. 이름 전체를 지정한 사실은 저장할 때 해당 페이지로 이동하고, 할 일 채팅에 해당 이름과 함께 **Graph에 추가됨**이라고 표시돼요. **사실** 아래의 조용한 한 줄에는 Graph 페이지에 저장된 사실의 개수가 표시돼요. 이 줄을 열면 각 페이지로 이동할 수 있어요. 본인이 보낸 메시지에서 가져온 사실에는 출처가 된 문구가 따옴표로 표시돼요.
- 다른 사람의 전화번호나 이메일 주소를 알려 주면 사실이 아니라 Graph의 해당 페이지에 추가돼요. 번호가 이미 한 기록에 있고 다른 기록에 같은 이름이 있으면 두 기록이 병합돼요. 할 일 채팅에 이름과 함께 **에 추가됨**이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 분명하지 않으면 사실로 남아요.
- 사용하지 않는다는 이유로 삭제되는 내용은 없어요. 각 할 일에는 관련성이 가장 높은 사실이 제공되고, 최근 사실일수록 더 중요하게 반영돼요. 따라서 드물게 필요한 사실도 다른 내용을 방해하지 않고 보관돼요. 종료된 사실도 해당 내용에 관한 할 일이나 채팅에서는 참고할 수 있지만, 과거 정보로만 사용하고 현재 상황으로 취급하지 않아요.
- 이미 배운 내용을 다른 말로 표현한 메모는 기존 내용을 대체하므로 같은 내용이 두 번 표시되지 않아요. **병합 실행 취소**를 누르면 이전 문구가 복원돼요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? 보관할 만한 메모 내용(`MEMORY.md`, `USER.md`)이 출처 파일과 함께 위쪽에 표시돼요. 보관할 항목을 선택한 다음 **선택 항목 유지**를 누르세요. 다른 항목과 마찬가지로 사실이나 규칙으로 추가돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 본인에 관한 사실은 사실에 남아요. **나머지 무시**를 누르면 나머지 항목은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 알고 있는 본인 정보를 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 누른 다음 해당 AI에 보내고 답변을 붙여 넣으세요. **검토**에서 각 줄을 보관하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 내용은 건너뛰고, 사실과 다른 내용은 해당 사실 옆에 표시되므로 어떤 내용을 유지할지 선택할 수 있어요. 비밀번호, 코드, 키, 카드 번호나 계좌 번호는 표시하기 전에 제외돼요. 권한을 부여하려는 문장도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한이 아니에요. 각 항목에는 출처와 날짜가 표시되고 **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일에서도 가져올 수 있고, 첫 안내를 읽는 동안에도 가져올 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 반영된 내용이 각각 **실행 취소**와 함께 표시돼요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 내린 결정을 시간순으로 보여 줘요.
- **공유됨**: The Machine 팀과 공유할 배운 점과, 참여할 투표가 있을 때는 해당 투표가 표시돼요. [배운 점 공유하기](share-learnings.md)를 참고하세요.
- **진행 상황**: 최근 30일을 기준으로 한 네 가지 수치를 보여 줘요. 수치가 높을수록 좋아요. 결정한 할 일(실행하거나 무시한 할 일)이 3개가 되면 집계가 시작돼요. 그전에는 지금까지 결정한 할 일의 개수를 보여 줘요.
  - **도움 됨**: 결정한 할 일 중 무시하지 않고 실행한(**실행**, 전송 또는 완료) 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 종료된 항목에서 완료된 비율이에요. 단계가 목록에서 사라졌거나, 직접 완료로 표시했거나, 완료 상태로 자동 종료된 경우예요. 무시했거나 만료된 할 일은 미완료로 계산돼요. 아직 열린 항목은 집계하지 않고 **아직 열림**으로 표시돼요.
  - **첫 시도**: 완료된 할 일 중 **실행**한 뒤 수정할 필요가 없었던 비율이에요.
  - **완료**와 **첫 시도**는 할 일이 3개 이상일 때부터 수치를 표시해요.
  - **그대로 전송**: 보낸 초안 중 수정하거나 먼저 **수정 요청**을 하지 않고 전송한 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 차트는 처음 2주 동안은 날짜별로, 이후에는 주별로 최대 8주까지 막대를 표시해요.
  - **출처별 도움 됨**: 출처별로 실행한 할 일의 수를 보여 줘요. 예를 들면 **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **Android 알림**, 오류 같은 문제를 포함하는 **The Machine 자체**가 있어요.
  - **놓친 할 일**: 일주일에 한 번 The Machine이 할 일로 등록되지 않은 메시지 일부를 확인하고, 할 일이 필요했을 가능성이 얼마나 되는지 추정해요. 발견한 메시지가 목록에 표시돼요. **열기** 또는 메시지 자체를 누르면 메시지를 확인할 수 있고, **실제 누락** 또는 **놓친 항목이 아니에요**를 선택해 판단이 맞았는지 알려 줄 수 있어요. **실제 누락**을 선택하면 할 일도 추가돼요. **실행 취소**할 수 있고, **할 일 열기**를 누르면 해당 할 일로 이동해요. The Machine은 이 내용을 학습해 다음부터 비슷한 메시지를 찾아내요. 답변은 수치에 바로 반영되고 내 Machine에 저장돼요. 몇 개만 남으면 백분율 대신 **적음**이라고 표시돼요. 첫 주간 확인이 끝난 뒤 표시돼요.
