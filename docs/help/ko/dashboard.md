## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 앞으로 한 주 동안의 회의, 마감이 있는 할 일과 약속을 보여 줘요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 Machine이 일정한 주기로 처리하는 작업이에요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 보여 줘요. 각 항목은 사이드바에서 자체 페이지로 확인할 수 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 팀, 가족, 친구가 있다면 여기서 확인할 수 있어요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일이 어떻게 처리되는지, 무엇을 배웠는지 확인해요.
- **연결**: 연결된 출처와 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 위쪽의 **검색 또는 질문**에서 할 일, 사람, 메시지 등을 찾을 수 있어요. 바로 아래에는 **새 할 일**이 있어요. 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인** 아래에 표시되므로, 개수가 위쪽에 표시되는 수와 같아요. 항목을 눌러 열어 보세요.

할 일 메뉴를 열려면 항목 위에 마우스를 올린 뒤 **⋯**을 클릭하거나, 마우스 오른쪽 버튼을 클릭하거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택한 뒤 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**와 **열기** 외에도 할 일별 **완료로 표시**, **미루기**, **필요 없음**이 있으며, 각 작업은 **실행 취소**할 수 있어요.

**브라우저**에는 내 Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**와 사이트에 로그인해야 할 때 표시되는 **브라우저 열기**도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 화면 전체를 차지하며, X를 누르면 이전 화면으로 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 원래대로 돌아가요.

할 일에서 브라우저를 사용 중이면 위쪽에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 더 이상 클릭하거나 입력하거나 전송하지 않고, 할 일 채팅에 "브라우저에서 중지됨"이라고 표시돼요.

실행이 여러 개라면 앞에 표시된 실행이 중지돼요. 계속하려면 할 일 채팅에 내용을 입력하거나 **다시 시도**를 누르세요.

할 일이 화면에 다 표시되지 않으면 사이드바 전체가 하나의 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면 전체에 표시돼요. 입력 중에도 버튼을 항상 누를 수 있어요.

## 더 유용하게 활용하기

할 일 탭 위쪽의 작은 할 일에는 The Machine을 더 유용하게 쓰는 방법이 표시돼요. 휴대폰 앱, 알림, WhatsApp, 이 컴퓨터의 앱, 다른 계정, 추가 연결 등이 있어요. 각 항목에는 해당 단계를 진행하는 버튼이 하나씩 있고, 완료하면 목록에서 사라져요. 따라서 할 일에는 남은 항목만 표시돼요. 한 번에 최대 5개 항목이 표시되며, 아직 완료하지 않은 단계가 먼저 나와요. 따라서 메일에서 제안하는 GitHub 같은 도구도 앞선 단계를 완료하면 목록에 표시돼요.

항목은 해당되는 경우에만 표시돼요. 항목의 ×를 누르면 모든 기기에서 해당 항목이 닫혀요. 위쪽의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 이 할 일은 **내 확인** 위쪽에 "단계 2개 남음 · 계속하기"처럼 한 줄로 접혀 표시돼요. 눌러서 할 일을 열고, 화살표를 눌러 다시 접을 수 있어요.

처음 2주 동안, 새 할 일이 하루에 하나 이하인 날에는 이유와 함께 제안 하나가 할 일 맨 위에 표시될 수 있어요. 예를 들면 "WhatsApp을 연결할까요? 이메일 5개에서 언급됐어요." 또는 "WhatsApp을 다시 사용해 볼까요? 코드가 만료됐어요."처럼 표시돼요. 접혀 있을 때는 버튼과 ×가 포함된 제안만 보여요. 이 제안은 해당 단계의 기본 항목을 대신해요. 첫 화면 살펴보기가 끝나면서 다음 단계를 안내하는 동안에는 제안이 표시되지 않아요.

제안은 The Machine에 이미 있는 정보에서만 만들어져요. WhatsApp으로 연결되는 링크나 메일에서 WhatsApp을 언급한 내용, 연결된 메일함에 포함되지 않은 내 주소, Slack 또는 Teams 회의에서 온 메일, 완료되지 않은 연결이 해당돼요. 메시지에 적힌 내용이나 보낸 사람은 표시하지 않고, 개수만 표시해요. 한 번에 하나씩만 표시하고, 하루에 새로운 제안은 최대 하나예요. 이메일이나 알림으로는 보내지 않아요. 제안의 ×를 누르면 다시 표시되지 않아요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 항목이 다시 표시돼요. 할 일 전체를 다시 표시하려면 **설정**에서 **일반**, **초기 설정 할 일**을 선택하세요. **설정**의 **일반**에서 **이 기기**를 선택하면 같은 설정을 확인할 수 있고, **설정**의 **앱**에는 휴대폰 앱이 항상 표시돼요.

## 새 버전

대시보드의 새 버전은 사용 중에 새로고침되지 않아요. 앱을 열 때나 창을 몇 분 동안 백그라운드에 두거나 사용하지 않았을 때 적용돼요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 적용되지 않아요. 위쪽의 **업데이트 준비됨**을 누르면 바로 적용돼요.

주요 기능이나 개선 사항이 출시되면 간단한 **새 소식**으로 알려 드려요. 하루에 한 번까지만 표시돼요. **뒤로**와 **다음**을 누르거나 밀어서 내용을 살펴보세요. 안내에 포함된 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 닫혀요. 진행 중인 작업을 가리지 않으며, 한 번 닫으면 모든 기기에서 사라져요. 사용을 시작한 뒤 출시된 내용만 표시돼요.

## 메시지

Mac에서는 `⌘K`를, Windows와 Linux에서는 `Ctrl K`을 누르거나 휴대폰에서 검색 아이콘을 눌러 검색을 열어요. 두 글자 이상 입력하면 **메시지**에 내 Machine이 읽은 내용 중 가장 잘 맞는 메시지가 표시돼요. 의미나 단어를 기준으로 찾아요. 오래된 [기록](history.md)은 단어를 기준으로 검색돼요.

검색창에서 질문할 수도 있어요. 검색창이 비어 있을 때 제안되는 질문처럼, 내 메시지를 바탕으로 간단한 답변을 받을 수 있어요([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 선택한 계정의 결과 목록이 열려요. 결과를 누르면 출처 링크가 포함된 보기 화면이 열려요. 검색창이 비어 있으면 최신 메시지가 표시돼요.

검색 결과에는 가장 잘 맞는 항목이 먼저 표시돼요. 전체 내용이 있는 메시지의 휴대폰 미리보기는 해당 메시지로 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 위쪽에 간단한 답변과 출처 메시지가 표시돼요. 메시지에 답이 없으면 아무 답도 표시되지 않아요.

## 배운 점

배운 점에서는 The Machine이 나에게서 배운 내용과 할 일이 얼마나 잘 처리되는지 확인할 수 있어요. 내용이 없는 탭은 숨겨져요.

- **내가 배운 점**: 메모에서 파악한 글쓰기 방식, 사실, 선호하는 처리 방식을 보여 줘요. 원하는 표현으로 **수정**하거나 더 이상 맞지 않는 내용을 **삭제**할 수 있어요. 채팅에 "이사했다는 사실을 잊어 줘"처럼 요청해도 내용을 잊게 할 수 있어요. 명확히 일치하는 사실이 하나 있으면 삭제되고, **설정**의 **활동**과 **변경사항**에서 **실행 취소**할 수 있어요. 일치하는 사실이 여러 개면 채팅에서 어떤 사실인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우 할 일 채팅에 **배운 점에 저장했어요**라고 표시되고, **수정**하거나 **실행 취소**할 수 있어요.
- 사실은 **임시**, **약속**, **선호 항목**으로 지정할 수 있고, 유효 기간은 **까지**에 표시돼요. 임시 사실은 몇 주, 선호 항목과 약속은 몇 달, 그 외 사실은 1년이 지나면 사라져요. 날짜가 지났거나 새 메시지를 통해 더 이상 유효하지 않은 것으로 확인되면 사실은 **종료됨**으로 이동해요. **복원**을 누르면 다시 사용할 수 있어요.
- **사실**에는 일반적인 사실, 즉 나와 일하는 방식에 관한 내용이 표시돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알려진 내용**에서 확인하고 수정할 수 있어요. 이름 전체가 적힌 사실을 저장하면 해당 페이지로 이동하고, 할 일 채팅에 **Graph에서** 해당 항목에 **추가됨**이라고 표시돼요. **사실** 아래에는 Graph 페이지에 저장된 사실의 개수를 한 줄로 표시해요. 누르면 각 페이지로 이동할 수 있어요. 내가 보낸 메시지에서 가져온 사실에는 출처가 된 문구가 따옴표로 표시돼요.
- 다른 사람의 전화번호나 이메일 주소를 알려 주면 사실이 아니라 Graph의 해당 페이지에 추가돼요. 번호가 이미 한 항목에 있고, 다른 항목의 이름이 같으면 두 항목이 병합돼요. 할 일 채팅에 **에 추가됨**과 해당 이름이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 확실하지 않으면 사실로 남아요.
- 사용하지 않는다는 이유만으로 삭제되는 내용은 없어요. 각 할 일에는 관련성이 가장 높은 사실이 전달되고, 최근 사실일수록 더 중요하게 반영돼요. 따라서 자주 필요하지 않은 사실도 다른 내용에 방해되지 않고 보관돼요. 종료된 사실도 관련 할 일이나 채팅에서는 참고할 수 있지만, 과거 기록으로만 사용되고 현재 상황으로 취급되지는 않아요.
- 이미 배운 내용을 다른 말로 표현한 메모는 기존 내용을 대체하므로 같은 내용이 중복 표시되지 않아요. **병합 실행 취소**를 누르면 이전 표현이 복원돼요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? 보관할 만한 OpenClaw 메모의 항목(`MEMORY.md`, `USER.md`)이 원본 파일과 함께 위쪽에 표시돼요. 보관할 항목을 선택한 뒤 **선택 항목 유지**를 누르세요. 다른 내용과 마찬가지로 사실이나 규칙으로 추가돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 나에 관한 사실은 **사실**에 남아요. **나머지 무시**를 누르면 나머지 항목은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 만한 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 나에 대해 알고 있는 내용을 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 눌러 해당 서비스에 보낸 다음, 답변을 붙여 넣으세요. **검토** 화면에서 각 항목을 보관하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 내용은 건너뛰고, 기존 사실과 다른 항목은 해당 사실 옆에 표시되므로 어느 쪽을 유지할지 선택할 수 있어요. 비밀번호, 코드, 키, 카드 번호와 계좌 번호는 표시되기 전에 제외돼요. 권한을 부여하려는 항목도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한으로 취급되지 않아요. 각 항목에는 출처와 날짜가 표시되고, **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일에서도 가져올 수 있으며, 첫 화면을 살펴보는 중에도 가져올 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 반영된 내용이 표시되며, 각 항목을 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대한 선택을 시간순으로 보여 줘요.
- **공유됨**: The Machine 팀과 공유할 배운 점과, 나를 기다리는 투표가 있으면 표시돼요. [배운 점 공유하기](share-learnings.md)를 참고하세요.
- **진행 상황**: 지난 30일간의 수치 4개를 보여 줘요. 수치가 높을수록 좋아요. 결정한 할 일(실행했거나 무시한 항목)이 3개가 되면 수치가 표시되기 시작해요. 그전에는 지금까지 결정한 할 일의 개수를 보여 줘요.
  - **도움 됨**: 결정한 할 일 중 무시하지 않고 실행한(**실행**, 전송 또는 완료) 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 나중에 수정할 필요가 없었던 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속 진행하거나 다시 시도해 달라고 요청하지 않아도 끝난 비율이에요.
  - **그대로 전송**: 보낸 초안 중 수정하거나 먼저 **수정 요청**하지 않고 그대로 전송한 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 그래프에는 처음 2주 동안은 일별 막대가, 이후에는 주별 막대가 최대 8주까지 표시돼요.
  - **출처별 도움 됨**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **휴대폰 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 할 일의 수를 보여 줘요.
  - **놓친 할 일**: The Machine은 일주일에 한 번, 할 일로 이어지지 않은 메시지 일부를 확인해 할 일이 필요했을 가능성을 추정해요. 확인한 메시지를 목록으로 보여 줘요. **열기** 또는 메시지 자체를 누르면 메시지를 볼 수 있고, **실제 누락** 또는 **놓친 항목이 아니에요**를 눌러 판단이 맞았는지 알려 줄 수 있어요. **실제 누락**을 누르면 할 일도 추가돼요. **실행 취소**할 수 있고, **할 일 열기**를 누르면 해당 할 일로 이동해요. The Machine은 이 결과를 바탕으로 배우므로, 그다음부터 비슷한 메시지를 찾아내요. 답변은 수치에 즉시 반영되고 내 Machine에 저장돼요. 남은 항목이 몇 개뿐이면 백분율 대신 **적음**이라고 표시돼요. 첫 주간 확인이 끝난 뒤부터 표시돼요.
