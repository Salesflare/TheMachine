## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 예정된 회의와 마감일이 있는 할 일, 약속을 한 주 단위로 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 Machine이 주기적으로 하는 작업을 확인해요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. 각 항목은 사이드바에 자체 페이지가 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 함께 있는 팀, 가족, 친구를 확인해요. Fleet이 있을 때 표시돼요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일이 어떻게 진행되는지, Machine이 무엇을 배웠는지 확인해요.
- **연결**: 연결된 소스와 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 맨 위의 **검색 또는 질문**으로 할 일, 사람, 메시지 등을 찾을 수 있어요. 바로 아래에는 **새 할 일**이 있어요. **브라우저**, **도움말**, **설정**은 맨 아래에 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인**에 표시되므로 개수가 상단에 표시된 숫자와 같아요. 항목을 눌러 열어 보세요.

할 일 메뉴를 열려면 마우스를 올린 뒤 **⋯**를 클릭하거나, 마우스 오른쪽 버튼을 클릭하거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택한 뒤 `Shift F10`을 누르세요. 메뉴에서 **이름 바꾸기**, **열기**뿐 아니라 할 일에 맞는 **완료**, **미루기**, **필요 없음**을 선택할 수 있고, 각 작업을 **실행 취소**할 수도 있어요.

**브라우저**에는 Machine 자체 브라우저가 표시돼요. LinkedIn 같은 사이트를 이용할 때 사용하는 브라우저예요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일에서 **브라우저에서 보기**를 누르거나 사이트에 로그인해야 할 때 **브라우저 열기**를 눌러도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 원래대로 돌아가요.

브라우저를 사용하는 중인 할 일에는 상단에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 더 이상 클릭하거나 입력하거나 전송하지 않고, 할 일의 채팅에는 "브라우저에서 중지됨"이라고 표시돼요.

실행 중인 작업이 여러 개라면 앞에 표시된 작업이 중지돼요. 계속하려면 할 일의 채팅에 메시지를 쓰거나 **다시 시도**를 누르세요.

할 일이 화면에 다 들어가지 않으면 사이드바 전체가 한 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 화면 전체에 표시돼요. 입력 중에도 버튼을 언제든 누를 수 있어요.

## 더 활용하기

할 일 탭 맨 위에 있는 작은 할 일에는 Machine을 더 유용하게 만드는 항목이 표시돼요. 휴대폰 앱, 알림, WhatsApp, 이 컴퓨터의 앱, 다른 계정, 추가 연결 등이 있어요. 각 행에는 해당 단계를 진행하는 버튼이 하나 있고, 완료하면 목록에서 사라져 남은 항목만 표시돼요. 한 번에 최대 다섯 개의 행이 표시되며, 아직 완료하지 않은 단계가 먼저 나와요. 따라서 메일에서 GitHub 같은 도구를 제안한 경우에도 앞 단계가 완료된 후에야 해당 행이 표시돼요.

각 행은 해당하는 곳에만 표시돼요. 행의 ×를 누르면 모든 기기에서 해당 행이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "2단계 남음 · 계속하기"처럼 한 줄로 접혀 조용히 표시돼요. 눌러서 할 일을 열고, 화살표를 눌러 다시 접으세요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 행이 다시 표시돼요. 할 일 전체를 다시 표시하려면 **설정**에서 **일반**, **초기 설정 할 일**을 선택하세요. **설정**의 **일반** 아래에 있는 **이 기기**에도 같은 설정이 있고, **설정**의 **앱**에는 휴대폰 앱이 항상 표시돼요.

## 새 버전

대시보드를 사용하는 도중에는 새 버전이 다시 로드되지 않아요. 앱을 열거나 창이 백그라운드에 있거나 몇 분 동안 유휴 상태였을 때 로드돼요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 업데이트가 끼어들지 않아요. 상단의 **업데이트 준비됨**을 누르면 바로 업데이트돼요.

주요 기능이나 개선 사항이 출시되면 **새로운 기능** 메모가 표시돼요. 하루에 한 번까지만 표시돼요. **뒤로**와 **다음**을 누르거나 화면을 밀어 내용을 살펴보세요. 메모에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 메모가 닫혀요. 진행 중인 작업 위에는 표시되지 않고, 닫으면 모든 기기에서 사라져요. 사용을 시작한 뒤 출시된 내용만 볼 수 있어요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 눌러 검색을 열고, 휴대폰에서는 검색 아이콘을 누르세요. 두 글자 이상 입력하면 **메시지**에 Machine이 읽은 내용 중 의미나 단어가 가장 잘 맞는 결과가 표시돼요. 이전 [기록](history.md)은 단어로 검색돼요.

검색창에 질문을 입력할 수도 있어요. 입력하지 않은 검색창에 표시되는 질문처럼, 내 메시지를 바탕으로 짧은 답변을 받을 수 있어요 ([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 한 계정의 검색 결과가 열려요. 결과를 누르면 메시지를 읽을 수 있는 화면이 열리고, 원문으로 이동하는 링크가 표시돼요. 검색어를 입력하지 않으면 최신 메시지가 표시돼요.

검색하면 가장 잘 맞는 결과가 먼저 표시돼요. 메시지 전체를 미리 볼 수 있는 휴대폰에서는 해당 메시지가 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 위쪽에 짧은 답변과 출처 메시지가 표시돼요. 메시지에 답이 없으면 답변이 표시되지 않아요.

## 배운 점

배운 점에는 Machine이 사용자에게서 배운 내용과 할 일이 얼마나 잘 처리되는지 표시돼요. 내용이 없는 탭은 숨겨져요.

- **내가 배운 내용**: 메모에서 파악한 글쓰기 방식, 사실, 선호하는 작업 방식을 확인해요. 원하는 내용은 직접 작성해 **수정**하고, 더 이상 사실이 아닌 내용은 **삭제**할 수 있어요. 채팅에 잊어 달라고 요청할 수도 있어요("이사한 사실을 잊어 줘"). 일치하는 사실이 명확하면 삭제되고, **설정**의 **활동**과 **변경사항**에서 **실행 취소**할 수 있어요. 여러 사실이 일치하면 채팅에서 어느 사실인지 물어봐요. 메모에서 사실이나 규칙을 파악하면 할 일의 채팅에 **배운 내용에 저장했어요**와 함께 **수정**, **실행 취소**가 표시돼요.
- 사실에는 **임시**, **약속**, **선호 항목** 유형을 지정하고, 언제까지 유효한지 **까지** 설정할 수 있어요. 임시 사실은 몇 주 후, 선호 항목과 약속은 몇 달 후, 그 외 사실은 1년 후에 흐려져요. 유효 기간이 지났거나 새 메시지에서 더 이상 유효하지 않다는 점이 확인되면 사실이 **종료됨**으로 이동해요. **복원**을 누르면 되돌릴 수 있어요.
- **사실**에는 일반적인 사실이 저장돼요. 나에 관한 사실과 일하는 방식에 관한 사실이 여기에 포함돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알려진 정보**에 저장되며, 여기서 수정할 수 있어요. 전체 이름이 명시된 사실을 저장하면 해당 페이지로 이동하고, 할 일의 채팅에 **Graph의** 해당 페이지에 **추가됨**이라고 표시돼요. Graph 페이지에 저장된 사실의 개수는 **사실** 아래에 한 줄로 표시돼요. 누르면 해당 페이지로 이동할 수 있어요. 내 메시지에서 가져온 사실에는 출처가 된 문구가 따옴표로 표시돼요.
- 누군가의 전화번호나 이메일 주소를 입력하면 사실이 아니라 Graph의 해당 페이지에 저장돼요. 한 기록에 이미 있는 번호와 이름이 같은 다른 기록이 있으면 두 기록이 병합돼요. 할 일의 채팅에 **추가됨**과 이름이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 명확하지 않으면 사실로 남아요.
- 목록은 계속 늘어나지 않아요. 길어지면 3주 동안 사용하지 않은 사실과 규칙이 **따로 보관**으로 이동하고, **복원**을 눌러 되돌릴 수 있어요. 직접 수정하거나 복원한 항목은 그대로 남아요. 따로 보관된 사실도 관련된 할 일이나 채팅에서는 참고해요. 종료된 사실은 과거 기록으로만 참고하고, 현재 상태처럼 사용하지는 않아요.
- 다른 말로 이미 배운 내용을 다시 설명하는 메모는 기존 내용을 대체하므로 같은 내용이 두 번 표시되지 않아요. **병합 실행 취소**를 누르면 이전 표현을 복원할 수 있어요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? OpenClaw 메모에서 보존할 만한 내용이 있으면 (`MEMORY.md`, `USER.md`) 출처 파일과 함께 위에 표시돼요. 보존할 항목을 선택한 다음 **선택 항목 유지**를 누르세요. 다른 사실이나 규칙과 마찬가지로 저장돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 나에 관한 사실은 **사실**에 남아요. **나머지 무시**를 누르면 나머지 항목은 다시 표시되지 않아요. 파일은 변경되지 않고, 보존할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 나에 관해 알고 있는 내용을 가져와요. 어시스턴트를 선택하고 **프롬프트 복사**를 누른 다음, 해당 AI에 보내고 답변을 붙여 넣으세요. **검토**에서 각 항목을 유지하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 내용은 건너뛰고, 기존 사실과 다른 항목은 해당 사실 옆에 표시돼요. 어느 쪽을 유지할지 선택하세요. 비밀번호, 코드, 키, 카드 번호, 계좌 번호는 표시되기 전에 제외돼요. 권한을 부여하려는 내용도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한이 아니에요. 각 항목에는 출처와 날짜가 표시되고, **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일과 첫 확인 중에도 사용할 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 파악한 내용이 표시되고, 각 항목을 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 관해 내린 선택을 시간순으로 확인해요.
- **공유됨**: The Machine 팀과 공유할 배운 점과 내 응답을 기다리는 투표가 있으면 표시돼요. [배운 점 공유하기](share-learnings.md)를 참고하세요.
- **진행 상황**: 지난 30일을 기준으로 한 네 가지 수치를 확인해요. 수치가 높을수록 좋아요. 결정한 할 일(실행하거나 무시한 항목)이 3개가 되면 수치가 표시되기 시작해요. 그 전에는 지금까지 결정한 할 일의 개수가 표시돼요.
  - **가치**: 결정한 할 일 중 무시하지 않고 실행한 항목(**실행**, 전송 또는 완료)의 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 나중에 수정하지 않아도 된 항목의 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속 진행하거나 다시 시도해 달라고 요청하지 않아도 완료된 항목의 비율이에요.
  - **그대로 전송**: 초안 중 수정하거나 먼저 **수정 요청**을 하지 않고 전송한 항목의 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 차트에는 처음 2주 동안은 하루마다 막대가 표시되고, 이후에는 최대 8주까지 한 주마다 막대가 표시돼요.
  - **출처별 가치**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **전화 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 항목의 수를 확인해요.
