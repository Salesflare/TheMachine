## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 다음 주의 회의, 마감이 다가오는 할 일과 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 정해진 주기로 Machine이 처리하는 작업이에요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 나오는 사람, 조직, 프로젝트를 보여줘요. 사이드바에서 각각의 페이지를 열 수 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에서 팀원, 가족, 친구와 함께할 수 있어요. Fleet이 있어야 표시돼요. [Fleet](fleet.md)을 참고하세요.
- **배운 점**: 할 일이 어떻게 진행되는지와 Machine이 배운 내용을 확인해요.
- **연결**: 연결된 출처와 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 맨 위의 **검색 또는 질문**에서 할 일, 사람, 메시지 등을 찾을 수 있어요. 바로 아래에는 **새 할 일**이 있어요. 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인**에 표시되므로, 개수는 맨 위에 표시된 숫자와 같아요. 하나를 눌러 열어 보세요.

할 일 메뉴를 열려면 할 일에 마우스를 올리고 **⋯**를 클릭하거나, 오른쪽 클릭하거나, 휴대폰에서 길게 누르세요. 키보드에서는 할 일에 포커스를 둔 뒤 `Shift F10`을 누르세요. 메뉴에는 **이름 바꾸기**와 **열기** 외에도 해당 할 일의 **완료로 표시**, **미루기**, **필요 없음**이 있으며, 각각 **실행 취소**할 수 있어요.

**브라우저**에는 Machine이 LinkedIn 같은 사이트를 이용할 때 쓰는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**를 누르거나, 사이트에 로그인해야 할 때 **브라우저 열기**를 눌러도 같은 방식으로 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체를 차지해요. 다시 누르면 돌아가요.

할 일에서 브라우저를 사용하는 동안에는 맨 위에 **중지**가 표시돼요. 한 번 누르면 실행이 즉시 끝나요. 이후에는 아무것도 클릭하거나 입력하거나 보내지 않으며, 할 일의 채팅에는 "브라우저에서 중지됨"이라고 표시돼요.

실행 중인 작업이 여러 개면 현재 진행 중인 작업이 중지돼요. 계속하려면 할 일의 채팅에 내용을 입력하거나 **다시 시도**를 누르세요.

할 일이 많아 화면에 다 표시되지 않으면 사이드바 전체가 한 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 전체 화면으로 열려요. 입력 중에도 버튼을 언제든 누를 수 있어요.

## 더 유용하게 활용하기

할 일 탭 맨 위의 작은 할 일에는 Machine을 더 유용하게 만드는 항목이 표시돼요. 휴대폰 앱, 데스크톱 앱, 알림, WhatsApp, 다른 계정, 추가 연결 등이 있어요. 각 항목에는 해당 단계를 진행하는 버튼이 하나씩 있고, 완료하면 목록에서 사라져 할 일에는 남은 항목만 표시돼요. 한 번에 최대 다섯 개 항목이 표시되고, 진행하지 않은 항목이 먼저 나와요. 따라서 메일에서 추천한 GitHub 같은 도구는 앞선 단계를 완료한 뒤에 표시돼요.

해당되는 기기에서만 항목이 표시돼요. Chromebook처럼 데스크톱 앱이 없는 컴퓨터에서는 대신 브라우저에서 대시보드를 설치하도록 안내해요. 항목 옆의 ×를 누르면 모든 기기에서 해당 항목이 닫혀요. 맨 위의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "2단계 남음 · 계속하기"처럼 간단한 한 줄로 접혀 표시돼요. 눌러서 할 일을 열고, 화살표를 누르면 다시 접혀요.

처음 2주 동안은 새 할 일이 하루에 한 개 이하인 날에, 이유가 포함된 제안 하나가 할 일 맨 위에 표시될 수 있어요. 예: "WhatsApp을 연결할까요? 이메일 5개에서 언급됐어요." 또는 "WhatsApp을 다시 시도할까요? 코드가 만료됐어요." 접힌 상태에서는 제안과 버튼, ×만 표시돼요. 해당 단계의 기본 항목 대신 제안이 표시돼요. 첫 화면을 살펴보는 과정에서 마지막 안내가 자체 다음 단계를 보여주는 동안에는 제안이 표시되지 않아요.

제안은 Machine이 이미 확인한 내용만 바탕으로 해요. WhatsApp 링크나 메일에 나온 언급, 연결된 메일함에 없는 내 주소, Slack이나 Teams 회의에서 온 메일, 완료되지 않은 연결 등이 해당돼요. 메시지 내용이나 보낸 사람은 보여주지 않고, 최대 개수만 표시해요. 제안은 한 번에 하나씩만, 하루에 새로 최대 하나만 표시돼요. 이메일이나 알림으로는 보내지 않아요. ×를 누르면 다시 표시되지 않아요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 항목이 다시 표시돼요. 할 일 전체를 다시 표시하려면 **설정**에서 **일반**, **초기 설정 할 일**을 선택하세요. **설정**의 **일반**에서 **이 기기**를 선택해도 같은 설정을 이용할 수 있어요. **설정**의 **앱**에는 항상 휴대폰 앱이 표시되고, 컴퓨터에서는 데스크톱 앱도 표시돼요.

## 새 버전

대시보드의 새 버전은 사용 중에 새로고침되지 않아요. 앱을 열거나 창을 몇 분 동안 백그라운드에 두거나 사용하지 않으면 새 버전이 적용돼요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 적용되지 않아요. 맨 위의 **업데이트 준비됨**을 누르면 바로 적용할 수 있어요.

주요 기능이나 개선 사항이 출시되면 작은 **새로운 기능** 안내로 알려드려요. 하루에 최대 한 번 표시돼요. **뒤로**와 **다음**을 누르거나 스와이프해서 살펴보세요. 안내에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 안내가 닫혀요. 진행 중인 작업을 방해하지 않으며, 닫으면 모든 기기에서 사라져요. 시작한 뒤 출시된 기능만 표시돼요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 누르거나 휴대폰에서 검색 아이콘을 눌러 검색을 열어요. 두 글자 이상 입력하면 **메시지**에 Machine이 읽은 내용 중 의미나 단어가 가장 잘 맞는 결과가 표시돼요. 이전 [기록](history.md)은 단어로 검색돼요.

여기에서 질문할 수도 있어요. 검색창이 비어 있을 때 제안하는 질문처럼, 내 메시지에서 짧은 답변을 찾아줘요([키보드와 명령 팔레트](keyboard.md)).

**모든 결과 보기**를 누르면 전체 계정 또는 하나의 계정에서 찾은 결과를 볼 수 있어요. 각 결과는 원본으로 연결되는 링크가 포함된 읽기 화면으로 열려요. 검색창이 비어 있으면 최신 메시지가 표시돼요.

검색하면 가장 잘 맞는 결과가 먼저 표시돼요. 메시지 전체가 있는 휴대폰 미리보기는 해당 메시지 하나만 표시해요. 모든 계정을 대상으로 질문하면 맨 위에 짧은 답변과 출처 메시지가 표시돼요. 메시지에 답이 없으면 답변을 표시하지 않아요.

## 배운 점

배운 점에서는 Machine이 나에게서 배운 내용과 할 일이 얼마나 잘 진행되는지 확인할 수 있어요. 내용이 없는 탭은 숨겨져요.

- **내가 배운 점**: 메모에서 파악한 글쓰기 방식, 사실, 선호하는 처리 방식을 보여줘요. 내용을 직접 작성해 **수정**하거나 더 이상 사실이 아닌 내용을 **삭제**할 수 있어요. 채팅에 잊어 달라고 요청할 수도 있어요("이사했다는 사실을 잊어줘"). 사실 하나가 분명하게 일치하면 해당 내용이 삭제되고, **설정**의 **활동**과 **변경사항**에서 **실행 취소**할 수 있어요. 여러 내용이 일치하면 채팅에서 어떤 내용인지 물어봐요. 메모에서 사실이나 규칙을 배운 경우 할 일의 채팅에 **배운 점에 저장했어요**가 표시되고, **수정**과 **실행 취소**를 할 수 있어요.
- 사실은 **임시**, **약속**, **선호 항목**으로 설정할 수 있고, 해당 사실이 유효한 기간은 **까지**로 지정할 수 있어요. 임시 사실은 몇 주, 선호 항목과 약속은 몇 달, 그 외 사실은 1년이 지나면 희미해져요. 날짜가 지났거나 새 메시지에서 더 이상 유효하지 않은 것으로 확인되면 **종료됨**으로 이동하며, **복원**을 누르면 되돌릴 수 있어요.
- **사실**에는 일반적인 사실, 즉 나와 일하는 방식에 관한 내용이 표시돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에서 **알려진 정보** 아래에 표시되고, 그곳에서 수정할 수 있어요. 전체 이름으로 지칭한 사실은 저장될 때 해당 페이지로 이동하며, 할 일의 채팅에는 해당 대상 이름과 함께 **Graph에 저장했어요**가 표시돼요. **사실** 아래에는 Graph 페이지에 저장된 사실의 개수를 한 줄로 표시해요. 그 줄을 열면 각 페이지로 이동할 수 있어요. 내가 보낸 메시지에서 가져온 사실에는 원문이 따옴표로 표시돼요.
- 누군가의 전화번호나 이메일 주소를 알려주면 사실에 추가하는 대신 Graph의 해당 페이지에 추가해요. 이미 한 기록에 번호가 있고, 같은 이름을 가진 다른 기록이 있으면 두 기록을 병합해요. 할 일의 채팅에는 이름과 함께 **에 추가됨**이 표시되고, **실행 취소**할 수 있어요. 누구의 정보인지 확실하지 않으면 사실로 남아요.
- 사용하지 않았다는 이유로 삭제되는 내용은 없어요. 각 할 일에는 가장 관련 있는 사실이 제공되고, 새로 추가된 사실일수록 더 중요하게 반영돼요. 자주 필요하지 않은 사실도 다른 내용을 밀어내지 않고 남아 있어요. 종료된 사실도 할 일이나 채팅에서 관련 내용이 다뤄질 때 참고할 수 있지만, 과거 기록으로만 사용되며 현재 상황처럼 취급되지 않아요.
- 다른 말로 이미 배운 내용을 담은 메모는 기존 내용을 대체해 중복을 방지해요. **병합 실행 취소**를 누르면 기존 표현을 복원할 수 있어요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용한 적이 있나요? 메모 파일(`MEMORY.md`, `USER.md`)에서 보관할 만한 줄을 파일 이름과 함께 맨 위에 표시해요. 남길 내용을 선택하고 **선택 항목 유지**를 누르면 다른 내용과 마찬가지로 사실이나 규칙이 돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 나에 관한 사실은 사실에 남아요. **나머지 무시**를 누르면 해당 내용은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude, Gemini가 알고 있는 나에 관한 정보를 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 눌러 해당 서비스에 보내세요. 답변을 복사해 다시 붙여 넣으면 돼요. **검토** 화면에서 각 줄을 남기거나, 수정하거나, 선택 해제할 수 있어요. 이미 알려준 내용은 건너뛰고, 사실과 다른 내용은 기존 사실 옆에 표시해 어느 쪽을 남길지 선택할 수 있어요. 비밀번호, 코드, 키, 카드 번호나 계좌 번호는 표시되기 전에 제외돼요. 권한을 부여하려는 줄도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한이 되지는 않아요. 각 내용에는 출처와 날짜가 표시되고, **직접 수정할 때까지 참고 정보로만 사용돼요**로 표시돼요. 초기 설정 할 일에서도 가져올 수 있으며, 첫 화면을 살펴보는 동안에도 가져올 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 반영된 내용이 각각 **실행 취소**와 함께 표시돼요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대한 선택을 시간순으로 보여줘요.
- **공유됨**: Machine 팀과 공유할 배운 점과 아직 투표하지 않은 항목을 보여줘요. 해당 내용이 있을 때만 표시돼요. [배운 점 공유하기](share-learnings.md)를 참고하세요.
- **진행 상황**: 지난 30일을 기준으로 네 가지 수치를 보여줘요. 수치가 높을수록 좋아요. 결정한 할 일이 3개가 된 뒤부터 수치를 확인할 수 있어요. 그전에는 지금까지 결정한 할 일의 개수가 표시돼요.
  - **도움 됨**: 결정한 할 일 중 무시하지 않고 실행한(**실행**, 전송 또는 완료) 항목의 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 이후에 수정하지 않아도 됐던 항목의 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속하거나 다시 시도해 달라고 요청하지 않아도 완료된 항목의 비율이에요.
  - **그대로 전송**: 초안을 전송한 항목 중 수정하거나 먼저 **수정 요청**하지 않고 전송한 항목의 비율이에요.
  - 각 수치는 이전 30일과 비교해요. 그래프에는 첫 2주 동안은 날짜별 막대가 표시되고, 그다음부터는 주별 막대가 최대 8주까지 표시돼요.
  - **출처별 도움 됨**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **Android 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 항목의 개수를 보여줘요.
  - **놓친 할 일**: Machine은 일주일에 한 번 할 일로 이어지지 않은 메시지 일부를 확인하고, 할 일이 필요했을 가능성이 높은 메시지 수를 추정해요. 찾은 메시지가 목록에 표시돼요. **열기**를 누르거나 해당 줄을 누르면 메시지를 볼 수 있고, **실제 누락** 또는 **놓친 항목이 아니에요**를 선택해 판단이 맞았는지 알려줄 수 있어요. **실제 누락**을 선택하면 할 일도 추가돼요. **실행 취소**할 수 있고, **할 일 열기**를 누르면 해당 할 일로 이동해요. Machine은 이 답변을 바탕으로 이후 비슷한 메시지도 찾아내요. 답변은 수치에 즉시 반영되며 내 Machine에 저장돼요. 남은 항목이 두 개 정도뿐이면 백분율 대신 **적음**으로 표시돼요. 첫 번째 주간 확인 이후에 표시돼요.
