## 탭

- **할 일**: 할 일과 약속을 확인해요. [할 일](cards.md)을 참고하세요.
- **캘린더**: 앞으로 한 주 동안의 회의, 마감이 다가오는 할 일과 약속을 확인해요. [캘린더](calendar.md)를 참고하세요.
- **루틴**: 월요일 요약처럼 정해진 주기로 Machine이 하는 작업이에요. [루틴](routines.md)을 참고하세요.
- **Graph**: 메시지에 등장하는 사람, 조직, 프로젝트를 확인해요. 각 항목은 사이드바에서 개별 페이지로 볼 수 있어요. [Graph](graph.md)를 참고하세요.
- **Fleet**: The Machine Network에 연결된 팀, 가족, 친구를 확인해요. 연결된 사람이 있을 때 표시돼요. [Fleet](fleet.md)를 참고하세요.
- **배운 점**: 할 일이 어떻게 처리되고 있는지, 무엇을 배웠는지 확인해요.
- **연결**: 연결한 출처와 각 출처의 상태를 확인해요. [연결](connections.md)을 참고하세요.

사이드바 위쪽의 **검색 또는 질문**으로 할 일, 사람, 메시지 등을 찾을 수 있고, 바로 아래에서 **새 할 일**을 만들 수 있어요. 아래쪽에는 **브라우저**, **도움말**, **설정**이 있어요. 휴대폰에서는 상단 바의 메뉴 버튼을 눌러 사이드바를 열어요.

사이드바에는 페이지와 같은 방식으로 할 일이 표시돼요. Fleet에서 온 요청도 **내 확인**에 표시되므로, 개수가 맨 위에 표시된 개수와 같아요. 항목을 탭하면 열려요.

할 일 메뉴를 열려면 항목에 마우스를 올린 뒤 **⋯**을 클릭하거나, 마우스 오른쪽 버튼을 클릭하거나, 휴대폰에서 길게 누르세요. 키보드에서는 항목을 선택하고 `Shift F10`을 누르세요. 메뉴에서 **이름 바꾸기**, **열기**와 함께 할 일별 **완료**, **미루기**, **필요 없음**을 선택할 수 있고, 각각 **실행 취소**도 할 수 있어요.

**브라우저**에는 Machine이 LinkedIn 같은 사이트에서 사용하는 자체 브라우저가 표시돼요. 컴퓨터에서는 사이드바 옆에 열려요. 할 일의 **브라우저에서 보기**와 사이트에 로그인해야 할 때 표시되는 **브라우저 열기**도 같은 위치에 열려요. 휴대폰 브라우저에서는 새 탭으로 열려요. 휴대폰 앱이나 홈 화면에 추가한 대시보드에서는 전체 화면으로 열리고, X를 누르면 돌아가요.

**전체 크기**를 누르면 브라우저가 창 전체에 표시돼요. 다시 누르면 원래 크기로 돌아가요.

할 일에서 브라우저를 사용하는 동안에는 위쪽에 **중지**가 표시돼요. 한 번 누르면 작업이 즉시 중단돼요. 더 이상 클릭하거나 입력하거나 전송하지 않고, 할 일의 채팅에 "브라우저에서 중지됨"이라고 표시돼요.

여러 작업이 실행 중이라면 가장 앞에 있는 작업이 중단돼요. 계속하려면 할 일의 채팅에 메시지를 쓰거나 **다시 시도**를 누르세요.

할 일이 많아 한 화면에 다 표시되지 않으면 사이드바 전체가 한 열로 스크롤돼요.

휴대폰에서는 **이 이메일을 보낼까요?** 같은 대화상자가 전체 화면에 표시되고, 입력 중에도 버튼이 항상 보여요.

## 더 활용하기

할 일 상단에는 Machine을 더 유용하게 만드는 방법을 안내하는 작은 할 일이 있어요. 휴대폰 앱, 알림, WhatsApp, 이 컴퓨터의 앱, 다른 계정, 추가 연결 등이 표시돼요. 각 행에는 해당 설정을 위한 버튼이 하나씩 있고, 완료하면 목록에서 사라져요. 따라서 남은 항목만 표시돼요. 한 번에 최대 다섯 개까지 표시되며, 아직 완료하지 않은 항목이 먼저 나와요. 따라서 메일에서 추천한 GitHub 같은 도구도 앞선 단계가 완료되면 목록에 표시돼요.

각 행은 표시할 수 있는 곳에만 나타나요. 행 옆의 ×를 누르면 모든 기기에서 해당 항목이 닫혀요. 위쪽의 ×를 누르면 할 일 전체가 닫혀요.

첫날이 지나면 **내 확인** 위에 "2단계 남음 · 계속하기"처럼 한 줄로 접혀서 표시돼요. 누르면 할 일이 열리고, 화살표를 누르면 다시 접혀요.

**실행 취소** 또는 **숨긴 항목 1개 표시**를 누르면 행을 다시 표시할 수 있어요. 할 일 전체를 다시 표시하려면 **설정**, **일반**, **초기 설정 할 일**로 이동하세요. **설정**, **일반**, **이 기기**에도 같은 설정이 있고, **설정**, **앱**에는 휴대폰 앱이 항상 표시돼요.

## 새 버전

대시보드를 사용하는 중에는 새 버전이 자동으로 다시 로드되지 않아요. 앱을 열 때나 창이 몇 분 동안 백그라운드에 있거나 유휴 상태였을 때 로드돼요. 저장하지 않은 텍스트가 있거나 대화상자가 열려 있으면 업데이트를 방해하지 않아요. 위쪽의 **업데이트 준비됨**을 누르면 바로 로드돼요.

새로운 기능이나 개선 사항이 출시되면 작은 **새로운 기능** 안내가 표시돼요. 하루에 최대 한 번만 표시돼요. **뒤로**와 **다음**을 누르거나 스와이프해 살펴보세요. 안내에 있는 버튼을 누르면 해당 기능이 열려요. **완료** 또는 **×**를 누르면 안내가 닫혀요. 진행 중인 작업 위에는 표시되지 않고, 한 번 닫으면 모든 기기에서 사라져요. 시작한 뒤 출시된 내용만 볼 수 있어요.

## 메시지

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`을 누르거나, 휴대폰에서 검색 아이콘을 눌러 검색을 여세요. 두 글자 이상 입력하면 **메시지**에 Machine이 읽은 내용 중 의미나 단어가 가장 잘 맞는 결과가 표시돼요. 오래된 [기록](history.md)은 단어로 검색돼요.

검색창에 질문을 입력해도 돼요. 검색창이 비어 있을 때 제안되는 질문처럼, 내 메시지를 바탕으로 짧은 답변을 받을 수 있어요 ([키보드와 명령 팔레트](keyboard.md)).

**결과 모두 보기**를 누르면 전체 계정 또는 한 계정의 결과 목록이 열려요. 결과를 누르면 원본 링크가 포함된 읽기 화면이 열려요. 검색어가 없으면 최신 메시지가 표시돼요.

검색 결과에는 가장 잘 맞는 항목이 먼저 표시돼요. 휴대폰에서 메시지 미리보기를 전체 메시지로 열면 해당 메시지가 한 번만 표시돼요. 모든 계정을 대상으로 질문하면 위쪽에 짧은 답변과 출처 메시지가 표시돼요. 메시지에서 답을 찾을 수 없으면 답변이 표시되지 않아요.

## 배운 점

배운 점에서는 Machine이 사용자에게서 배운 내용과 할 일의 처리 결과를 확인할 수 있어요. 비어 있는 탭은 숨겨져요.

- **내가 배운 점**: 메모에서 배운 글쓰기 방식, 사실, 선호하는 처리 방식을 확인해요. 내용을 직접 표현한 말로 **수정**하거나 더 이상 맞지 않는 내용을 **삭제**할 수 있어요. 채팅에 잊어 달라고 요청할 수도 있어요("이사한 사실을 잊어 줘"). 일치하는 사실이 하나면 삭제되고, **설정**, **활동**, **변경사항**에서 **실행 취소**할 수 있어요. 여러 사실이 일치하면 채팅에서 어떤 사실인지 물어봐요. 메모에서 사실이나 규칙을 배우면 할 일의 채팅에 **배운 내용에 저장했어요**가 표시되고, **수정**하거나 **실행 취소**할 수 있어요.
- 사실은 **임시**, **약속**, **선호 항목**으로 지정할 수 있고, 해당 사실이 적용되는 시점을 **까지**로 설정할 수 있어요. 임시 사실은 몇 주 후, 선호 항목과 약속은 몇 달 후, 그 밖의 사실은 1년 후에 사라져요. 설정한 날짜가 지났거나 최신 메시지에서 더 이상 사실이 아님이 확인되면 **종료됨**으로 이동하고, **복원**할 수 있어요.
- **사실**에는 일반적인 사실, 즉 사용자와 일하는 방식에 관한 내용이 표시돼요. 사람, 조직, 프로젝트에 관한 사실은 Graph의 해당 페이지에 있는 **알려진 정보**에 저장되며, 그곳에서 수정할 수 있어요. 전체 이름으로 특정 대상을 가리키는 사실은 저장 시 해당 페이지로 이동하고, 할 일의 채팅에는 **Graph**의 해당 대상 이름 아래에 **에 추가됨**이 표시돼요. **사실** 아래 한 줄에 Graph 페이지에 저장된 사실의 개수가 표시돼요. 누르면 각 페이지로 이동할 수 있어요. 직접 작성한 메시지에서 가져온 사실에는 출처 문구가 따옴표로 표시돼요.
- 다른 사람의 전화번호나 이메일 주소를 입력하면 사실이 아니라 Graph의 해당 사람 페이지에 저장돼요. 한 기록에 이미 전화번호가 있고, 다른 기록에 같은 이름이 있으면 두 기록이 병합돼요. 할 일의 채팅에는 해당 사람 이름과 함께 **에 추가됨**, **실행 취소**가 표시돼요. 누구의 정보인지 확실하지 않으면 사실로 남아요.
- 목록에는 항목 수 제한이 없어요. 목록이 길어지면 3주 동안 사용하지 않은 사실과 규칙이 **따로 보관**으로 이동하고, **복원**할 수 있어요. 직접 수정하거나 복원한 항목은 그대로 남고, 다른 AI에서 가져온 항목은 직접 작성한 항목보다 먼저 표시돼요. 따로 보관된 사실도 할 일이나 채팅에서 관련 내용을 다룰 때 참고해요. 종료된 사실은 이전 기록으로만 참고하고 현재 상황으로는 사용하지 않아요.
- 이미 배운 내용을 다른 말로 표현한 메모는 기존 내용을 대체하므로 같은 내용이 중복 표시되지 않아요. **병합 실행 취소**를 누르면 이전 표현을 복원할 수 있어요. 직접 수정한 내용은 대체되지 않아요.
- **가져오기**: OpenClaw를 사용해 본 적이 있나요? 보관할 만한 OpenClaw 메모의 문구(`MEMORY.md`, `USER.md`)가 출처 파일명과 함께 맨 위에 표시돼요. 보관할 항목을 선택한 뒤 **선택 항목 유지**를 누르세요. 다른 사실이나 규칙처럼 저장돼요. Graph에 있는 사람에 관한 사실은 해당 페이지로 이동하고, 생일은 생일 루틴에도 추가돼요. 사용자에 관한 사실은 사실에 저장돼요. **나머지 무시**를 누르면 해당 내용은 다시 표시되지 않아요. 파일은 변경되지 않으며, 보관할 내용이 없으면 아무것도 표시되지 않아요.
- **다른 AI에서 가져오기**: ChatGPT, Claude 또는 Gemini가 알고 있는 사용자 정보를 가져올 수 있어요. 어시스턴트를 선택하고 **프롬프트 복사**를 누른 다음, 해당 AI에 보내고 답변을 붙여 넣으세요. **검토** 화면에서 각 항목을 보관하거나 수정하거나 선택 해제할 수 있어요. 이미 알려 준 내용은 건너뛰고, 기존 사실과 다른 내용은 나란히 표시되므로 어느 쪽을 유지할지 선택할 수 있어요. 비밀번호, 코드, 키, 카드 번호, 계좌 번호는 표시되기 전에 제외돼요. 권한을 부여하려는 문구도 제외돼요. 가져온 사실은 참고 정보일 뿐, 권한으로 사용되지 않아요. 각 항목에는 출처와 날짜가 표시되고 **직접 수정할 때까지 참고 정보로만 사용돼요**라고 표시돼요. 초기 설정 할 일에서도 가져올 수 있고, 첫 확인을 진행하는 동안에도 가져올 수 있어요.
- **변경사항**: 수정, 무시, 채팅을 통해 배운 내용이 표시되며 각 항목을 **실행 취소**할 수 있어요. [글쓰기](writing.md#it-keeps-learning)를 참고하세요.
- **결정**: 할 일에 대한 선택 기록을 시간순으로 보여 줘요.
- **공유됨**: The Machine 팀과 공유할 배운 내용과 검토를 기다리는 투표가 표시돼요. 항목이 있을 때만 표시돼요. [배운 내용 공유](share-learnings.md)를 참고하세요.
- **진행 상황**: 최근 30일의 수치를 네 가지로 보여 줘요. 높을수록 좋아요. 결정한 할 일(실행하거나 무시한 할 일)이 3개 쌓인 뒤부터 표시돼요. 그전에는 지금까지 결정한 할 일의 개수를 보여 줘요.
  - **가치**: 결정한 할 일 중 무시하지 않고 실행한(**실행**, 전송 또는 완료) 비율이에요.
  - **첫 시도**: **실행**으로 시작한 할 일 중 나중에 수정할 필요가 없었던 비율이에요.
  - **완료**: **실행**으로 시작한 할 일 중 계속 진행하거나 다시 시도해 달라고 요청하지 않아도 완료된 비율이에요.
  - **그대로 전송**: 전송한 초안 중 수정하거나 먼저 **수정 요청**을 하지 않고 그대로 보낸 비율이에요.
  - 각 수치는 이전 30일과 비교돼요. 차트에는 처음 2주 동안은 날짜별 막대가, 그다음에는 주별 막대가 최대 8주까지 표시돼요.
  - **출처별 가치**: **이메일**, **직접 추가했어요**(**새 할 일**에서 추가), **전화 알림**, **The Machine 자체**(오류 같은 문제) 등 출처별로 실행한 할 일의 수예요.
