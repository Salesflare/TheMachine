The Machine이 익히는 모든 내용은 사용자 소유예요. 메시지, 할 일, 초안, Graph, 기억, 스킬까지 전부 다른 The Machine으로 옮기거나 사본으로 보관할 수 있어요.

## 내보내기

직접 운영하는 컴퓨터에서:

1. **설정** › **일반** › **내보내기**에서 전체 항목 옆에 있는 **내보내기**를 누르세요.
2. 원하면 암호 문구를 설정하세요. 설정하지 않으면 내보내기 코드가 표시돼요. 코드를 적어 두세요. 가져올 때 필요해요.
3. 원하면 **키와 토큰 포함**을 켜세요. 암호 문구가 필요해요. 켜 두면 연결된 소스를 다시 연결하지 않아도 돼요.
4. **내보내기 시작**을 누른 다음 **다운로드**를 누르세요. 파일은 24시간 후 삭제되며, **삭제**를 누르면 바로 삭제돼요.

호스팅 환경에서는 전체 항목 옆의 **내보내기**를 누르면 계정 페이지가 열려요. **모두 내보내기**를 누른 다음 **다운로드**를 누르세요. The Machine은 24시간 후 파일을 삭제하며, **지금 삭제**를 누르면 바로 삭제돼요.

파일은 항상 암호화돼요. 설정에서 파일에 포함된 항목과 포함되지 않은 항목을 확인할 수 있어요. 호스팅 로그인으로 연결한 Google 및 Microsoft 계정은 새 환경에서 다시 로그인해야 해요.

## 가져오기

1. **설정** › **일반** › **내보내기**에서 가져오기 옆의 **파일 선택**을 누르고 내보내기 파일을 선택하세요.
2. 암호 문구나 내보내기 코드를 입력하고 **열기**를 누르세요. 먼저 파일 전체를 검사해요.
3. 호스팅 환경: **지금 가져오기**를 누르세요. 직접 운영하는 컴퓨터: **이 내보내기 파일로 바꾸기**를 누른 다음 **바꾸기**를 누르세요. 몇 분 안에 The Machine이 해당 파일로 다시 시작되고, 설정에 **가져옴**이라고 표시돼요.

가져오기를 하면 현재 내용을 먼저 복사본으로 보관한 다음 바꿔요. 아무것도 자동으로 전송되지 않아요. 대기 중인 전송은 직접 처리할 때까지 기다려요.

컴퓨터에서 설정을 통해 The Machine을 다시 시작할 수 없으면, 대신 실행할 명령어가 표시돼요.

새 컴퓨터에서는 먼저 [The Machine 설치](self-hosted-setup.md)를 진행하세요. 호스팅 요금제가 더 이상 필요하지 않다면 취소하세요. [취소 또는 삭제](cancel-and-delete.md)를 참고하세요.
