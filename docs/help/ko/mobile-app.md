모바일 앱을 열면 웹에서와 같은 계정으로 로그인된 대시보드가 표시돼요. iPhone과 iPad에서는 [App Store](https://apps.apple.com/app/id6829875215)에서, Android에서는 [Google Play](https://play.google.com/store/apps/details?id=computer.themachine.app)에서 받을 수 있어요.

할 일 맨 위에 있는 **The Machine 더 알차게 사용하기** 할 일에서 앱을 추천해요. 휴대전화 브라우저에서는 **받기**를 누르면 스토어가 열려요. 데스크톱 사이트 표시로 설정한 휴대전화에서는 두 스토어 링크가 모두 표시돼요. 컴퓨터에서는 휴대전화로 스캔할 QR 코드와 두 스토어 링크가 표시돼요.

휴대전화에서 [themachine.computer/app](https://themachine.computer/app)을 열면 해당 스토어로 이동해요. **설정**의 **앱** 맨 위에 두 스토어가 표시되고, 휴대전화에서는 해당 휴대전화의 스토어만 표시돼요. 컴퓨터에서는 **컴퓨터**를 눌러 대시보드를 앱으로 설치할 수 있어요. [앱 설치하기](phone-app.md)를 참고하세요.

## 연결하기

호스팅된 Machine에서는 계정으로 앱에 로그인해요. 자체 호스팅 Machine에서는 컴퓨터에서 **설정**의 **앱**을 여세요. 스토어 아래의 **Network에 없나요?**를 누르면 코드가 표시돼요. 앱을 설치한 다음 휴대전화 카메라로 코드를 스캔하거나, 앱에 코드 아래 표시된 주소를 입력하세요. 연결하기 전에 앱에서 확인을 요청하며, 계속해서 해당 Machine의 로그인이 필요해요.

## 알림

앱을 처음 열면 알림을 허용할지 물어봐요. 알림을 탭하면 해당 내용이 열려요. 할 일 알림은 해당 채팅을, 아침 알림은 **캘린더**의 오늘을, 팀 브리핑 알림은 할 일을, Fleet 질문 알림은 해당 할 일을 열어요. Apple, Google 또는 The Machine의 서비스에는 할 일의 텍스트가 전달되지 않아요. "할 일이 있어요" 같은 고정 문구만 전달돼요.

그다음 앱에서 해당 Machine에 할 일의 제목과 다음 단계를 요청해요. 예를 들어 "샘에게 답장하기"와 "샘에게 보내기: 화요일 10:00 괜찮아요"가 표시돼요. 아침 알림에는 대기 중인 일과 첫 회의 시간이, 팀 브리핑에는 첫 번째 항목들이, Fleet 업데이트에는 발생한 내용이 표시돼요. 해당 Machine에 연결할 수 없으면 고정 문구가 계속 표시돼요. Android에서는 "할 일 2개가 있어요"처럼 대기 중인 할 일의 개수를 알려줘요.

알림에는 **미루기**(내일까지)와 **완료**가 표시되고, 아직 시작하지 않은 할 일에는 **실행**도 표시돼요. 휴대전화 잠금을 해제하면 앱을 열지 않고도 사용할 수 있어요. 보내기와 마지막 단계는 항상 앱에서 열려요. 할 일마다 알림은 하나만 표시돼요. "준비 중"은 "준비됨"으로 바뀌고, 여기서든 다른 곳에서든 할 일을 완료하거나 미루면 알림이 사라져요.

확인한 단계가 처리되면 알림에 **완료**와 처리된 내용이 표시돼요. 할 일에서 **알겠어요**를 탭할 때까지 표시되며, iPhone에서는 다음에 앱을 열 때까지 알림이 남아 있을 수 있어요.

**설정**의 **보안**에서 **알림 텍스트**를 끄면 고정 문구만 표시돼요. 잠금 화면에서 알림 내용을 숨기도록 설정한 경우에도 마찬가지예요. 표시할 내용이 없으면 "탭해서 열기"가 표시될 수 있어요. 알림이 도착했을 때 휴대전화가 해당 Machine에 연결되지 않으면, 다시 온라인 상태가 된 후 세부 정보가 표시돼요.

웹 푸시와 같은 규칙이 적용돼요. [알림](notifications.md)에서 종류별로 선택한 설정과 [근무 시간](work-hours.md)이 적용되고, 대시보드를 사용 중일 때는 알림이 오지 않아요.

앱이 설치된 각 휴대전화는 **설정**의 **알림**에 **앱이 설치된 휴대전화**로 표시돼요. **삭제**하면 해당 휴대전화의 알림이 중지돼요. 자체 호스팅 Machine에서 알림을 받으려면 The Machine Network가 필요해요. 앱은 The Machine Network 없이도 사용할 수 있어요.

## The Machine에 공유하기

어떤 앱에서든 공유를 탭하고 The Machine을 선택하세요. 공유한 텍스트, 링크 또는 파일이 들어 있는 **새 할 일**이 열려요. 내용을 확인하고, 원하면 날짜를 추가한 다음 할 일을 추가하세요. 직접 추가하기 전에는 아무것도 추가되지 않아요.

청구서나 편지처럼 파일만 있어도 돼요. 해당 Machine에서 PDF의 텍스트를 읽고 할 일의 내용, 다음 단계와 날짜를 입력해요. 파일은 해당 Machine으로 바로 전송되며, 그곳에 보관돼요.

Android에서는 앱으로 설치한 대시보드도 공유 항목을 받을 수 있어요. 공유 시트에서 같은 방식으로 선택하세요.

요금제와 결제 정보는 앱에 표시되지 않아요. 계정을 삭제할 수 있도록 **설정**에 **계정 열기**가 계속 표시돼요.
