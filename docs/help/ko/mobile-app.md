모바일 앱을 열면 웹에서처럼 로그인된 내 대시보드가 보여요. iPhone과 iPad에서는 [App Store](https://apps.apple.com/app/id6829875215), Android에서는 [Google Play](https://play.google.com/store/apps/details?id=computer.themachine.app)에서 다운로드하세요.

할 일 목록 맨 위에 있는 **The Machine 더 알차게 사용하기** 할 일이 앱을 사용해 보라고 안내해요. 휴대폰 브라우저에서 **받기**를 누르면 앱 스토어가 열려요. 데스크톱 사이트를 표시하도록 설정한 휴대폰에서는 두 앱 스토어 링크가 모두 보여요. 컴퓨터에서는 휴대폰으로 스캔할 수 있는 QR 코드와 두 앱 스토어 링크가 표시돼요.

어떤 휴대폰에서든 [themachine.computer/app](https://themachine.computer/app)을 열면 해당 앱 스토어로 이동해요. **설정**의 **앱** 맨 위에는 두 앱 스토어가 표시되고, 휴대폰에서는 해당 휴대폰의 앱 스토어만 표시돼요. 컴퓨터에서는 Windows, Mac, Linux용 데스크톱 앱도 확인할 수 있어요. 자세한 내용은 [데스크톱 앱](desktop-app.md)을 참고하세요.

## 연결하기

호스팅된 Machine에서는 앱이 계정으로 로그인해요. 자체 호스팅 Machine에서는 컴퓨터에서 **설정**의 **앱**을 여세요. 앱 스토어 아래에 있는 **Network에 없나요?**에 코드가 표시돼요. 앱을 설치한 다음 휴대폰 카메라로 코드를 스캔하거나, 코드 아래에 표시된 주소를 앱에 입력하세요. 앱에서 연결 여부를 확인하며, 내 Machine에 설정된 로그인 방식도 그대로 적용돼요.

**연결**에서 서비스(Shortcut, Notion, Slack, Zoom 등)의 **다음으로 로그인**을 누르면 휴대폰의 로그인 창이 열려요. 로그인을 마치면 앱으로 돌아오고, 새 연결이 **연결**에 자동으로 표시돼요.

앱이 내 Machine에 연결할 수 없으면 그 사실을 알리고 자동으로 다시 시도해요. Mac에서는 잠자기 후 창을 다시 열었을 때 비어 있으면 페이지도 자동으로 다시 열려요. 입력하던 채팅 메시지도 그대로 돌아와요. 키보드가 연결된 Mac이나 iPad에서는 Cmd+R을 눌러 페이지를 다시 불러올 수 있어요.

## 알림

앱을 처음 열면 알림을 허용할지 물어봐요. 알림을 탭하면 관련 화면이 열려요. 할 일 알림을 탭하면 목록에서 해당 할 일이 강조 표시되고, 아침 알림을 탭하면 오늘의 **캘린더**가 열려요. 팀 브리프 알림을 탭하면 할 일 목록이 열리고, Fleet 질문 알림을 탭하면 해당 할 일이 열려요. 할 일의 내용은 Apple, Google 또는 The Machine의 서비스를 거치지 않아요. 이 서비스들은 "처리할 할 일이 있어요" 같은 고정 문구만 전달해요.

그런 다음 앱이 내 Machine에서 할 일의 제목과 다음 단계를 가져와요. 예를 들면 "Sam에게 답장하기"라는 제목과 "Sam에게 보내기: 화요일 오전 10시 괜찮아요"라는 다음 단계가 표시돼요. 아침 알림에는 남은 할 일과 첫 회의 시간, 팀 브리프에는 첫 번째 항목들, Fleet 업데이트에는 발생한 일이 표시돼요. 내 Machine에 연결할 수 없으면 고정 문구만 표시돼요. Android에서는 "처리할 할 일이 2개 있어요"처럼 남은 할 일 수도 표시해요.

알림에는 **미루기**(내일까지)와 **완료로 표시**가 있고, 아직 시작하지 않은 할 일에는 **실행**도 표시돼요. 휴대폰 잠금을 해제하면 앱을 열지 않고도 이 작업을 할 수 있어요. 전송과 마지막 단계는 항상 앱에서 열려요. 할 일마다 알림은 하나만 표시돼요. "준비 중"은 "준비됨"으로 바뀌고, 여기에서든 다른 곳에서든 할 일을 완료하거나 미루면 알림이 사라져요.

확인한 단계가 완료되면 알림에 **완료**와 처리 결과가 표시돼요. 할 일 화면에서 **알겠어요**를 누르면 알림이 사라져요. iPhone에서는 앱을 다음에 열 때까지 그대로 둘 수 있어요.

**설정**의 **보안**에서 **알림 텍스트**를 끄면 고정 문구만 표시돼요. 잠금 화면에서 알림 내용을 숨기도록 설정한 경우에도 마찬가지예요. 표시할 내용이 없으면 "탭하여 열기"라고 표시될 수 있어요. 알림이 도착했을 때 휴대폰이 내 Machine에 연결되지 않으면, 다시 온라인 상태가 된 뒤 알림 세부 정보가 표시돼요.

알림은 웹 푸시와 같은 규칙을 따라요. [알림](notifications.md)에서 종류별로 설정한 항목과 [근무 시간](work-hours.md)이 적용되고, 대시보드를 사용 중일 때는 알림이 오지 않아요.

앱이 설치된 휴대폰은 각각 **설정**의 **알림**에 **앱이 설치된 휴대폰**으로 표시돼요. **삭제**를 누르면 해당 휴대폰의 알림이 중지돼요. 자체 호스팅 Machine에서 알림을 받으려면 The Machine Network가 필요해요. 앱은 The Machine Network 없이도 사용할 수 있어요.

## The Machine으로 공유하기

어떤 앱에서든 공유를 탭하고 The Machine을 선택하세요. 공유한 텍스트, 링크 또는 파일이 들어 있는 **새 할 일**이 열려요. 내용을 확인하고, 원한다면 날짜를 추가한 다음 저장하세요. 직접 저장하기 전에는 아무것도 추가되지 않아요.

청구서나 편지처럼 파일만 공유해도 돼요. 내 Machine이 PDF의 텍스트를 읽고 할 일의 내용을 채워요. 어떤 파일인지, 다음 단계와 날짜가 입력돼요. 파일은 내 Machine으로 바로 전송되어 그곳에 보관돼요.

Android에서 앱으로 설치한 대시보드에서도 공유할 수 있어요. 공유 메뉴에서 같은 방법으로 대시보드를 선택하세요.

요금제와 결제 정보는 앱에 표시되지 않아요. 계정을 삭제할 수 있도록 **설정**의 **계정 열기**는 계속 표시돼요.
