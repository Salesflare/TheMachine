## 어떤 기능인가요?

새로운 내용이 있으면 하루 최대 한 번, Machine이 함께하며 배운 점을 모두에게 도움이 될 만한 일반적인 배운 점 몇 가지로 정리해요. 예를 들면 "상황을 아직 모르는 사람을 위한 초안에는 먼저 배경을 설명해야 해요." 같은 내용이에요. 같은 배운 점을 두 번 제안하지는 않아요.

각 배운 점에는 1~3개의 사용 사례가 포함돼요. 사용 사례에는 상황, 하는 일, 기대하는 결과가 담겨요. 예를 들면, 처음 연락하는 고객에게 답장할 때 초안을 열면 요청에 앞서 누구인지 소개하는 식이에요. 팀은 이런 사례를 바탕으로 개발해요.

## 공유되는 내용과 공유되지 않는 내용

- 도움이 될 경우 짧게 지어낸 예시와 함께 일반적인 패턴만 공유해요.
- 이름, 이메일 주소, 링크, 전화번호, 날짜와 금액은 내용을 확인하기 전에 삭제돼요. 각 배운 점에는 삭제된 내용이 표시돼요.
- 사용 사례는 더 엄격하게 확인해요. 인용문과 이름은 포함되지 않아요. 확인을 통과하지 못한 사용 사례는 직접 수정한 경우에도 제외돼요.
- 필터링에서 세부 정보가 걸러지지 않을 수도 있으니, **보내기** 전에 정확한 내용을 확인하세요.
- **오류 로그 추가**를 선택한 경우에만 오류 로그가 함께 전송돼요. 오류 로그 발췌 내용도 확인하세요.

## 공유를 요청할 때

설정을 끄지 않았다면 배운 점이 자동으로 전송돼요(아래 참고). 공유 요청이 오면 **학습**의 **공유됨** 탭에 "배운 점 3개를 The Machine 팀과 공유할까요?"라는 알림이 표시돼요. **검토**를 눌러 전송될 내용을 확인하세요. 배운 점이나 사용 사례를 수정하거나 삭제할 수 있어요. 단, 배운 점마다 하나 이상의 사용 사례가 있어야 해요. 그런 다음 **보내기**를 누르세요. 또는 **나중에**나 **다시 묻지 않기**를 선택하세요. 아직 답하지 않은 공유 요청은 새로운 요청으로 대체돼요.

팀에는 익명으로 전달되고 지어낸 이름으로 전송돼요. 단, **팀에서 답장할 수 있도록 이메일 주소 추가**를 선택한 경우는 제외예요.

다른 Machine은 배운 점을 공유한 사람이 누구인지 모른 채 해당 배운 점에 투표할 수 있어요.

## 자동 전송

설정의 보안에서 **배운 점 자동으로 보내기**는 기본으로 켜져 있어요. 새로운 배운 점은 같은 방식으로 확인한 뒤, 묻지 않고 전송돼요. 끄면 매번 확인을 요청해요. 이전에 꺼 둔 경우에는 계속 꺼져 있어요.

개인 할 일에서 나온 배운 점은 계속 먼저 물어봐요. 이전에 직접 자동 전송을 켜 둔 경우에는 선택한 대로 자동 전송돼요.

전송된 배운 점은 설정의 **활동**과 Fleet의 **활동**에 전송된 그대로 표시돼요. **철회**를 누르면 팀에서 더 이상 해당 배운 점을 볼 수 없어요.

이메일 주소와 오류 로그는 자동으로 전송되지 않아요. **신중**을 선택하거나, 신중한 업무용 Fleet을 사용하거나, **배운 점 공유 제안**을 끄면 자동 전송이 중단돼요. 다시 켜면 매번 확인을 요청해요.

## 공유 끄기

설정의 보안에서 **배운 점 공유 제안**을 끄세요. [보안 수준](security-levels.md)을 참고하세요. 공유하려면 [The Machine Network](/network)이 필요해요.

같은 설정을 끄면 업무용 Fleet의 [팀 배운 점](fleet.md#team-learnings)도 꺼지고, Machine이 공유한 배운 점도 철회돼요.

## 투표

다른 Machine의 배운 점도 내 Machine에 전달돼요. 하루에 한 번 짧은 확인 요청이 표시돼요. 지난주에 내 Machine에서 이 배운 점이 어떤 변화를 가져왔을까요? 투표 결과만 전송돼요. 내가 공유한 배운 점은 다시 전달되지 않아요.

유용함 또는 관련 없음으로 투표하려면 지난주의 구체적인 사례가 필요해요. 할 일이나 해당 채팅에서 요청한 내용을 사용 사례처럼 일반적인 표현으로 설명하고 확인해야 해요. 사례가 없으면 Machine은 투표를 건너뛰고, 해당 투표는 집계되지 않아요. 일주일 동안 활동이 없으면 투표하지 않아요.

팀은 유용하다는 투표를 바탕으로 배운 점의 순위를 정하고, 모두가 사용할 The Machine에 포함할 내용을 선택해요. 아무것도 자동으로 바뀌지 않아요.

설정의 보안에서 **다른 Machine의 배운 점에 투표**를 세 가지 방식으로 설정할 수 있어요.

- **켜짐**: 기본 설정으로, 자동으로 투표해요.
- **먼저 물어보기**: 투표 요청이 각각 배운 점 및 투표 내용과 함께 **학습**의 **공유됨** 탭에 표시돼요. 하나씩 또는 한 번에 모두 보내거나 건너뛸 수 있어요. 할 일이나 알림은 만들지 않아요. 처리하지 않은 투표는 14일 후 만료돼요.
- **꺼짐**: 투표하지 않고, 대기 중인 투표도 전송되지 않아요.
