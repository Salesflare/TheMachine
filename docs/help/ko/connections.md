## 상태 확인하기

**연결** 탭에는 소스가 종류별로 표시되고, 구분선 아래에는 **로그인 세션**과 **확인**이 표시돼요. 휴대전화에서는 종류를 눌러 열고 **연결**을 눌러 돌아가세요. 확인이 필요한 소스가 있는 종류가 먼저 열려요. 각 소스는 한 줄로 표시돼요. 연결 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결 중, 도움이 필요함)와 최근에 가져온 항목을 확인할 수 있어요. 소스를 누르면 카드와 **세부 정보**가 열려요.

나중에 동기화하면서 누락된 항목을 가져온 실패는 회색으로 표시돼요. 가장 최근 동기화도 실패한 경우에만 문제로 표시되며, 다시 시도하는 시점도 함께 보여요.

항목 수에는 [기록](history.md)을 포함해 지금까지 가져온 전체 항목, 지난 24시간 동안 가져온 항목, 아직 확인하지 않은 항목이 표시돼요. 캘린더에는 일정 수가 표시돼요.

각 소스는 서비스에서 사용하는 계정 이름으로 표시돼요. 이메일 주소, X 프로필, Slack 워크스페이스, Signal 또는 Telegram 계정 이름 등이 여기에 해당해요. 이름 아래에는 **업무** 또는 **개인**이 먼저 표시되고, 이름에 이미 포함되지 않은 경우 주소나 핸들도 함께 표시돼요. 같은 종류의 소스 이름이 같으면 Slack이나 X처럼 둘을 구분하는 정보도 표시돼요. 예를 들면 워크스페이스 주소가 표시돼요.

각 소스에는 가져오는 항목이 한 줄로 표시돼요. 작업을 수행할 수 있는 소스라면 **보내기**를 누르거나 승인한 후에만 작업한다고도 알려줘요.

## 소스 추가하기

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없다면 목록 아래에서 선택할 수도 있어요. 마지막에는 여러 용도로 쓸 수 있는 항목이 있어요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 표시돼요. Exchange Server는 회의를 가져오므로 캘린더 아래에 있어요.

Machine에서 소스를 추가할 만한 이유가 발견되면 **추천 항목**이 **연결** 위에 표시되고, 추천 이유도 한 줄로 안내돼요. 예를 들면 Stripe에서 온 메일, 캘린더의 Zoom 회의, Google Docs로 연결되는 메시지, 또는 완료되지 않은 설정 등이 있어요. 해당 소스는 원래 속한 그룹에도 **추천됨**으로 표시돼요. 추천 항목은 Machine에서만 확인하며, 외부로 전송되지 않아요. 이미 연결된 소스는 추천 항목으로 표시되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅 아래에서는 채팅용으로, 회의 아래에서는 회의 메모용 **Teams 회의**로 표시돼요. 둘 다 같은 Microsoft 로그인 정보를 사용하므로 하나를 연결하면 다른 하나도 연결돼요.

이미 연결한 소스는 계정 정보와 함께 목록에 표시돼요. 해당 소스를 선택하면 옆에 다른 계정을 추가할 수 있어요. 양식에 추가 계정임이 표시되고 기존 계정으로 연결되는 링크도 제공돼요.

필요한 정보(키, 주소 등)를 입력하고 회사 계정이면 **업무**, 개인 계정이면 **개인**을 선택한 다음 **연결**을 누르세요. 단, 메일과 캘린더는 주소만으로 구분할 수 없는 경우에만 선택을 요청해요. LinkedIn이나 X 같은 사이트는 Machine의 브라우저에서 로그인 페이지를 열어요. 로그인하면 자동으로 다음 단계로 넘어가요. GitHub, WhatsApp, Codex에서는 입력할 코드를 보여주고, Telegram 채팅과 Signal 채팅에서는 스캔할 QR 코드를 보여줘요.

**취소**를 누르면 추가 작업이 중단돼요. 완료하기 전에 나갔더라도 어떤 기기에서든 다시 **연결**을 열면 같은 단계부터 이어서 진행할 수 있어요. 연결되면 Machine이 바로 소스를 읽기 시작하고 첫 동기화 상태를 보여줘요.

호스팅형 Machine에서는 자체 로그인을 사용하는 소스에 여기서 바로 로그인할 수 있어요. Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello가 여기에 해당해요.

**업무** 또는 **개인**을 선택하고 **Google로 로그인**처럼 해당 로그인 버튼을 누르세요. 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대전화의 인증 코드도 여기 표시돼요.

개인 컴퓨터에서는 Machine을 계정에 연결한 뒤 같은 소스에 로그인할 수 있어요. 처음에는 **이 Machine 연결**을 누르세요. 일부 소스는 자체 앱이나 키를 사용하는 다른 방법도 제공해요.

소스에서 **다시 연결**을 누르거나 **확인 필요**에서 해당 소스를 선택하면 같은 양식이 열려요. 개인 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 같은 작업을 할 수 있어요.

## 업무용 또는 개인용

각 소스는 업무용(이름을 지정한 회사) 또는 개인용으로 분류돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 Machine이 주소를 바탕으로 분류했다는 뜻이에요. 업무용 할 일은 업무일에 진행돼요.

Google과 Microsoft의 메일 및 캘린더는 주소로 구분할 수 있을 때 자동으로 분류돼요. Gmail이나 Outlook.com 같은 메일 서비스 주소는 개인용이고, 팀 도메인은 업무용이에요. 구분할 수 없으면 로그인 직후 한 번 물어봐요. **변경**을 누르면 직접 설정할 수 있어요. 나중에 메일에서 다른 용도라는 점이 확인되면 **The Machine 더 알차게 사용하기** 할 일에서 변경할지 한 번 물어봐요.

## 기능

소스는 신호를 가져와서 할 일로 만들거나, 할 일과 관련된 작업(문서 읽기, 승인 후 보내기, 답장하기 또는 변경하기)을 수행하거나, 두 가지 모두를 할 수 있어요. 둘 다 지원하는 소스의 **세부 정보**에는 각각 **신호를 가져와요**와 **작업 수행 가능** 스위치가 있어요. 하나는 항상 켜져 있어요. 둘 다 중단하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 있어요.

**신호를 가져와요**를 끄면 동기화되지 않아요. **작업 수행 가능**을 끄면 Machine은 해당 소스를 사용해 어떤 내용도 읽거나 초안으로 작성하거나 변경하지 않아요.

## 소스 삭제하기

소스를 열고 **세부 정보**를 선택한 다음 **연결 해제**를 누르세요. 소스 읽기가 중단돼요. 이미 가져온 항목은 그대로 남아요. 호스팅형 Machine에서 설정 페이지가 로그인을 관리하는 소스(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시돼요. 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 지난 30일 동안 삭제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 삭제 시점이 표시돼요. 서비스에서 연결 해제를 확인할 때까지 대기 중으로 표시되고 계속 다시 시도해요. Google 계정은 Google Meet 또는 Docs에서 별도의 로그인을 사용했더라도 한 번만 표시돼요. 각 계정은 해당하는 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 저장한 로그인은 **로그인 세션**에 표시돼요. 사이트에서 Machine의 로그아웃이 감지되면 한 번 눌러 다시 로그인할 수 있어요. 비밀번호는 Machine에 암호화된 상태로 저장돼요. 항목을 삭제하려면 **잊기**를 누르세요.

## 확인

**확인**에는 Machine이 가져온 항목을 확인한 기록과 각 확인에서 발견한 내용이 표시돼요. [새 할 일이 없어요](reviews-paused.md)를 참고하세요.

이 섹션의 각 연결에는 별도의 도움말이 있어요. 어떤 내용을 가져오고 무엇을 보낼 수 있는지 확인할 수 있어요.
