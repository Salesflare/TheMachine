## 상태 확인

**연결** 탭에는 소스가 종류별로 표시되고, 구분선 아래에는 **로그인 세션**과 **확인**이 표시돼요. 휴대전화에서는 종류를 눌러 열고 **연결**을 눌러 돌아가세요. 확인이 필요한 소스가 있는 종류가 먼저 열려요. 소스는 행으로 표시되며, 상태(연결됨, 첫 동기화 대기 중, 자동 재연결 중, 직접 확인 필요)와 최근에 가져온 항목을 볼 수 있어요. 소스를 누르면 카드와 **세부 정보**가 표시돼요.

나중에 동기화가 성공해 이전 실패를 만회한 경우에는 실패가 회색으로 표시돼요. 가장 최근 동기화가 실패한 경우에만 문제로 표시되며, 다음 시도 시점도 함께 나와요.

가져온 전체 항목 수와 [기록](history.md), 지난 24시간 동안 가져온 항목 수, 아직 확인하지 않은 항목 수가 표시돼요. 캘린더에는 일정 수가 표시돼요.

소스 이름은 서비스에서 사용하는 계정 이름을 따와요. 이메일 주소, X 프로필, Slack 워크스페이스, 또는 Signal이나 Telegram 계정의 소유자 이름이 표시돼요. 이름 아래에는 **업무** 또는 **개인**이 먼저 표시되고, 이름만으로 알 수 없는 경우 주소나 사용자 이름도 표시돼요. 같은 종류에 이름이 같은 소스가 두 개 있으면 Slack이나 X 계정, 또는 워크스페이스 주소처럼 서로 구별할 수 있는 정보도 표시돼요.

각 소스에는 어떤 항목을 가져오는지 한 줄로 표시돼요. 작업을 수행할 수 있는 소스라면 **보내기**를 누르거나 승인한 뒤에만 작업을 수행한다는 점도 표시돼요.

## 소스 추가하기

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없으면 목록 아래에서 선택할 수도 있어요. 기타 항목은 목록 마지막에 있어요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의 정보를 읽으므로 캘린더에 있어요.

Machine에서 소스를 추천할 이유를 찾으면 **추천 항목**이 **연결** 위에 표시되고, 그 이유도 한 줄로 나와요. 예를 들면 Stripe에서 온 메일, 캘린더의 Zoom 회의, Google Docs 링크가 포함된 메시지, 또는 완료되지 않은 설정이에요. 해당 소스는 원래 그룹에도 **추천됨**으로 표시돼요. 추천 여부는 내 Machine에서 계산되며, 외부로 전송되지 않아요. 이미 연결된 소스는 추천되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅의 Teams 채팅과 회의의 **Teams 회의**예요. 둘 다 같은 Microsoft 로그인 정보를 사용하므로 한쪽을 연결하면 다른 쪽도 연결돼요.

이미 연결한 소스는 계정과 함께 목록에 표시돼요. 소스를 선택하면 기존 소스 옆에 하나 더 추가할 수 있어요. 양식에도 이 내용이 표시되며, 기존 소스 링크도 나와요.

필요한 정보(키, 주소 등)를 입력하고, 회사를 지정해 **업무**로 설정하거나 **개인**으로 설정한 뒤 **연결**을 누르세요. LinkedIn이나 X 같은 사이트는 내 Machine 브라우저에서 로그인 페이지를 열어요. 로그인하면 자동으로 다음 단계로 진행돼요. GitHub, WhatsApp, Codex에서는 입력할 코드를 표시하고, Telegram 채팅과 Signal 채팅에서는 스캔할 QR 코드를 표시해요.

**취소**를 누르면 추가가 중단돼요. 완료하기 전에 나왔나요? 어떤 기기에서든 **연결**을 다시 열면 같은 단계부터 시작해요. 연결되면 Machine이 바로 데이터를 읽기 시작하고 첫 동기화 상태를 표시해요.

호스팅된 Machine에서는 Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello처럼 별도 로그인이 필요한 소스에 여기서 로그인해요.

**업무** 또는 **개인**을 선택하고 **Google로 로그인** 같은 로그인 버튼을 누르세요. 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대전화의 코드도 여기서 확인할 수 있어요.

내 컴퓨터에서는 Machine을 계정과 페어링하면 같은 소스에 로그인할 수 있어요. 처음에는 **이 Machine 연결**을 누르세요. 일부 소스에는 자체 앱이나 키를 사용하는 다른 방법도 있어요.

소스에서 **다시 연결**을 누르거나 **확인 필요**에서 소스를 선택하면 같은 양식이 열려요. 내 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 돼요.

## 업무용 또는 개인용

각 소스는 지정한 회사의 업무용이거나 개인용으로 분류돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 Machine이 주소를 보고 분류했다는 뜻이에요. 업무용 할 일은 업무일에 처리돼요.

Google과 Microsoft의 이메일과 캘린더는 주소만으로 분류할 수 있으면 주소를 기준으로 설정해요. Gmail이나 Outlook.com 같은 메일 서비스는 개인용이고, 팀 도메인은 업무용이에요. 주소만으로 알 수 없으면 로그인 직후 한 번 물어봐요. **변경**을 누르면 직접 설정할 수 있어요. 나중에 이메일에서 다른 분류가 확인되면 **The Machine 더 알차게 사용하기** 할 일에서 한 번 변경 여부를 물어봐요.

## 기능

소스는 신호를 가져와 할 일로 만들거나, 할 일을 대신 처리할 수 있어요. 예를 들면 문서를 읽거나, 승인 후 메시지를 보내고 답장하거나 내용을 변경해요. 둘 다 할 수도 있어요. 두 기능을 모두 지원하는 소스의 **세부 정보**에는 각각 전환 버튼이 있어요. **신호를 가져와요**와 **작업 수행 가능**이에요. 둘 중 하나는 항상 켜져 있어요. 둘 다 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 있어요.

**신호를 가져와요**를 끄면 동기화되지 않아요. **작업 수행 가능**을 끄면 Machine이 해당 소스에서 내용을 읽거나, 초안을 작성하거나, 변경하는 일이 없어요.

## 소스 연결 해제

소스를 열고 **세부 정보**에서 **연결 해제**를 누르세요. 데이터 읽기가 중단돼요. 이미 가져온 항목은 그대로 남아요. 호스팅된 Machine에서 설정 페이지에 로그인 정보가 저장된 소스(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시되며, 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 지난 30일 동안 연결을 해제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 연결 해제 시점이 표시돼요. 서비스에서 연결 해제를 확인할 때까지 대기 중으로 표시되고 계속 다시 시도해요. Google 계정은 한 번만 표시되며, Google Meet이나 Docs에 별도 로그인이 있었던 경우도 마찬가지예요. 각 계정은 해당 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 그러면 **로그인 세션**에 로그인 정보가 표시되고, 사이트에서 Machine의 로그아웃을 처리해도 한 번만 눌러 다시 로그인할 수 있어요. 비밀번호는 Machine에 암호화되어 저장돼요. **잊기**를 누르면 로그인 정보가 삭제돼요.

사이트마다 **업무**용과 **개인**용처럼 여러 계정을 저장할 수 있어요. **다른 이름으로 저장**은 할 일에 설정된 계정 유형을 기본으로 사용하고, **다른 이름…**을 선택하면 원하는 이름을 지정할 수 있어요. 할 일은 적절한 계정으로 로그인해요. 어떤 계정인지 확실하지 않으면 대화상자에서 한 번 물어보고, 해당 할 일에 사용할 계정을 기억해요.

**로그인 세션**에는 사이트가 한 번씩 표시되고, 그 아래에 계정이 나열돼요. 계정 기능이 추가되기 전에 저장한 로그인 정보는 여기서 유형을 선택할 때까지 **기본**으로 표시돼요.

**가져오기**를 사용하면 비밀번호 관리자에서 로그인 정보를 가져올 수 있어요. 1Password, LastPass, Bitwarden, Chrome에서 내보낸 CSV 파일을 사용하거나, 이 컴퓨터에서 로그인한 상태라면 1Password와 LastPass의 명령줄 도구에서 바로 가져올 수 있어요. 유지할 로그인 정보는 직접 선택하세요. Machine은 비밀번호 관리자에 로그인하지 않으며 마스터 비밀번호도 요구하지 않아요. 가져오기가 끝나면 내보내기 파일을 삭제하세요.

저장된 로그인 정보는 해당 웹 주소에만 사용돼요. 사이트, `https`, 포트가 모두 같아야 해요. 비슷한 주소나 다른 하위 도메인에는 사용되지 않아요.

## 확인

**확인**에는 Machine이 가져온 내용을 어떻게 읽는지 표시돼요. 최근에 확인한 내용과 각 확인에서 발견한 항목을 볼 수 있어요. [새 할 일이 없어요](reviews-paused.md)를 참고하세요.

이 섹션에는 연결별 문서가 있어요. 각 문서에서 읽어 오는 항목과 보낼 수 있는 항목을 확인할 수 있어요.
