## 상태

**연결** 탭에는 종류별로 소스가 표시되고, 구분선 아래에는 **로그인 세션**과 **확인**이 표시돼요. 휴대폰에서는 종류를 눌러 열고, **연결**을 눌러 돌아가세요. 확인이 필요한 소스가 있는 종류가 먼저 열려요. 각 소스는 한 줄로 표시돼요. 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결하는 중, 확인 필요)와 최근에 가져온 내용이 나와요. 소스를 누르면 카드와 **세부 정보**가 열려요.

나중 동기화에서 보완된 동기화 실패는 회색으로 표시돼요. 가장 최근에도 실패한 경우에만 문제로 표시되고, 다시 시도할 시간도 나와요.

소스가 가져온 전체 항목 수에는 [기록](history.md)도 포함돼요. 지난 24시간 동안 가져온 항목 수와 아직 확인하지 않은 항목 수도 표시돼요. 캘린더에는 일정 수가 표시돼요.

각 소스의 이름은 해당 계정 이름을 사용해요. 서비스에서 지정한 이름으로, 이메일 주소나 X 프로필, Slack 워크스페이스, Signal 또는 Telegram 계정 소유자 이름이 표시돼요. 이름 아래에는 먼저 **업무** 또는 **개인**이 표시되고, 이름만으로 알 수 없는 경우 주소나 핸들도 함께 표시돼요. 같은 종류의 소스 이름이 같으면 Slack이나 X처럼 구분에 필요한 정보도 표시돼요. 예를 들어 워크스페이스 주소가 표시돼요.

각 소스에는 가져오는 내용을 한 줄로 설명해요. 작업을 수행할 수 있는 소스라면 **보내기**를 누르거나 승인한 뒤에만 작업한다고도 표시돼요.

## 추가

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없으면 목록 아래에서 선택할 수 있어요. 마지막에는 여러 서비스를 포괄하는 옵션이 표시돼요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의 내용을 읽으므로 캘린더 아래에 있어요.

내 Machine에서 소스를 추가할 만한 이유를 찾으면 **연결** 위에 **추천 항목**이 표시돼요. 추천 이유도 한 줄로 나와요. 예를 들어 Stripe에서 받은 메일, 캘린더에 있는 Zoom 회의, Google Docs 링크가 포함된 메시지, 완료되지 않은 설정 등이 있어요. 해당 소스는 원래 종류에도 **추천됨**으로 표시돼요. 추천 항목은 내 Machine에서 계산하며, 정보가 외부로 전송되지 않아요. 이미 연결된 소스는 추천되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅 아래에는 채팅용으로, 회의 아래에는 회의록용 **Teams 회의**로 표시돼요. 두 가지 모두 같은 Microsoft 로그인 정보를 사용하므로 한쪽을 연결하면 다른 쪽도 연결돼요.

이미 연결한 소스는 목록에 계정 정보와 함께 표시돼요. 해당 소스를 선택하면 옆에 계정을 하나 더 추가할 수 있어요. 양식에 계정을 추가한다는 안내와 기존 계정 링크가 표시돼요.

필요한 정보(키, 주소 등)를 입력하고 회사 계정이면 **업무**, 개인 계정이면 **개인**을 선택한 다음 **연결**을 누르세요. 메일과 캘린더는 주소만으로 구분되지 않을 때만 선택을 요청해요. LinkedIn이나 X 같은 사이트는 내 Machine의 브라우저에서 로그인 화면을 열어요. 로그인하면 자동으로 다음 단계로 진행돼요. GitHub, WhatsApp, Codex는 입력할 코드를 표시하고, Telegram 채팅과 Signal 채팅은 스캔할 QR 코드를 표시해요.

**취소**를 누르면 추가가 중단돼요. 완료하기 전에 나갔더라도 어느 기기에서든 **연결**을 다시 열면 중단한 단계부터 이어서 진행돼요. 연결되면 내 Machine이 바로 읽기 시작하고 첫 동기화 상태를 표시해요.

호스팅된 Machine에서는 자체 로그인 정보를 사용하는 소스를 여기서 로그인할 수 있어요. Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello가 해당돼요.

**업무** 또는 **개인**을 선택하고 **Google로 로그인** 같은 로그인 버튼을 누르세요. 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대폰도 여기에서 코드를 표시해요.

내 컴퓨터에서는 Machine을 계정에 연결한 후 같은 소스에 로그인할 수 있어요. 처음에는 **이 Machine 연결**을 누르세요. 일부 소스는 직접 만든 앱이나 키 같은 다른 방법도 지원해요.

소스에서 **다시 연결**을 누르거나 **확인 필요** 목록을 열면 같은 양식이 열려요. 내 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 돼요.

## 업무용 또는 개인용

각 소스는 회사 이름을 지정한 업무용이거나 개인용이에요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 내 Machine이 주소를 바탕으로 구분했다는 뜻이에요. 업무용 할 일은 업무일에 처리돼요.

Google과 Microsoft의 메일 및 캘린더는 주소로 구분할 수 있으면 주소를 기준으로 분류해요. Gmail이나 Outlook.com 같은 메일 서비스는 개인용이고, 팀 도메인은 업무용이에요. 구분할 수 없으면 로그인 직후 한 번 물어봐요. **변경**을 눌러 직접 설정할 수도 있어요. 나중에 메일에서 다른 용도라는 점이 확인되면 **The Machine 더 알차게 사용하기** 할 일에서 변경할지 한 번 물어봐요.

## 기능

소스는 신호를 가져올 수도 있고(가져온 내용이 할 일이 돼요), 할 일에 필요한 작업을 수행할 수도 있어요(문서 읽기, 또는 승인 후 보내기, 답장하기, 내용 변경하기). 둘 다 할 수 있는 소스에는 **세부 정보**에 각각 **신호를 가져와요**와 **작업 수행 가능** 설정이 있어요. 둘 중 하나는 항상 켜져 있어요. 둘 다 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 있어요.

**신호를 가져와요**를 끄면 동기화하지 않아요. **작업 수행 가능**을 끄면 내 Machine이 해당 소스로 내용을 읽거나, 초안을 작성하거나, 변경하는 일이 없어요.

## 소스 삭제

소스를 열고 **세부 정보**에서 **연결 해제**를 누르세요. 더 이상 내용을 읽지 않아요. 이미 가져온 내용은 그대로 남아요. 호스팅된 Machine에서 설정 페이지가 로그인 정보를 관리하는 소스(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시돼요. 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 최근 30일 동안 삭제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 삭제한 시각이 표시돼요. 서비스에서 확인이 완료될 때까지 대기 중으로 표시되고 계속 다시 시도해요. Google 계정은 한 번만 표시돼요. Google Meet이나 Docs에 별도 로그인 정보가 있었던 경우에도 마찬가지예요. 각 계정은 해당 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 그러면 **로그인 세션**에 표시돼요. 사이트에서 내 Machine의 로그아웃을 처리하면 한 번 눌러 다시 로그인할 수 있어요. 비밀번호는 내 Machine에 암호화된 상태로 저장돼요. **잊기**를 누르면 삭제돼요.

사이트 하나에 **업무**와 **개인**처럼 여러 계정을 저장할 수 있어요. **다른 이름으로 저장**은 할 일에 지정된 용도로 시작하고, **다른 이름…**을 누르면 직접 이름을 지정할 수 있어요. 할 일은 알맞은 계정으로 로그인해요. 알맞은 계정을 구분할 수 없으면 대화상자에서 한 번 물어보고 해당 할 일에 저장해요.

**로그인 세션**에는 사이트가 한 번씩 표시되고, 그 아래에 계정이 나열돼요. 사용자 이름과 용도를 보여 주는 메뉴가 있어요. 언제든 메뉴에서 용도를 변경할 수 있어요. 계정 기능이 추가되기 전에 저장한 로그인에는 용도를 선택할 때까지 **업무 또는 개인용인가요?**가 표시돼요. 용도를 변경하면 해당 로그인을 사용하던 할 일에서 다시 계정을 선택해요.

**가져오기**를 사용하면 비밀번호 관리자에서 로그인을 가져올 수 있어요. 1Password, LastPass, Bitwarden, Chrome에서 내보낸 CSV 파일을 사용하거나, 이 컴퓨터에서 로그인한 상태라면 명령줄 도구를 통해 1Password와 LastPass에서 바로 가져올 수 있어요. 보관할 항목을 선택하면 돼요. 내 Machine은 비밀번호 관리자에 로그인하지 않으며 마스터 비밀번호를 요청하지도 않아요. 가져오기를 마치면 내보낸 파일을 삭제하세요.

저장된 로그인은 해당 웹 주소에만 사용돼요. 같은 사이트, `https`, 포트가 일치해야 해요. 비슷하게 보이는 다른 주소나 다른 하위 도메인에서는 사용할 수 없어요.

## 확인

**확인**에는 내 Machine이 가져온 내용을 확인한 기록과 각 확인에서 찾은 내용이 표시돼요. [새 할 일이 없어요](reviews-paused.md)를 참고하세요.

이 섹션의 각 연결에는 어떤 내용을 읽고 무엇을 보낼 수 있는지 설명하는 문서가 있어요.
