## 상태 확인

**연결** 탭에는 종류별로 소스가 표시되고, 구분선 아래에 **로그인 세션**과 **확인**이 표시돼요. 휴대전화에서는 종류를 탭해 열고, **연결**을 탭해 돌아가세요. 확인이 필요한 소스가 있는 종류가 먼저 열려요. 각 소스는 한 줄로 표시돼요. 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결 중, 확인 필요)와 최근에 가져온 항목을 볼 수 있어요. 소스를 탭하면 카드와 **세부 정보**가 표시돼요.

이후 동기화에서 만회한 동기화 실패는 회색으로 표시돼요. 가장 최근에도 실패한 경우에만 문제로 표시되며, 다음 시도 시점도 함께 표시돼요.

항목 수에는 가져온 모든 항목과 [기록](history.md), 지난 24시간 동안 가져온 항목, 아직 확인하지 않은 항목이 표시돼요. 캘린더에는 일정 수가 표시돼요.

각 소스의 이름은 서비스에서 사용하는 계정 이름을 따르며, 이메일 주소, X 프로필, Slack 워크스페이스, Signal 또는 Telegram 계정 소유자 이름 등이 표시돼요. 이름 아래에는 먼저 **업무** 또는 **개인**이 표시되고, 이름에 이미 포함돼 있지 않으면 주소나 사용자 이름도 표시돼요. 같은 종류의 소스 두 개의 이름이 같으면 Slack이나 X처럼 구분에 도움이 되는 정보 또는 워크스페이스 주소도 표시돼요.

각 소스에는 어떤 항목을 가져오는지 한 줄로 표시돼요. 작업을 수행할 수 있는 소스라면 **보내기**를 누르거나 확인을 받아야만 작업한다는 설명도 표시돼요.

## 소스 추가

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없다면 목록 아래에서 선택할 수 있어요. 모든 경우에 사용할 수 있는 옵션은 목록 끝에 표시돼요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의 내용을 읽으므로 캘린더 아래에 있어요.

Machine에서 소스를 추가할 이유를 찾으면 **추천 항목**이 **연결** 위에 표시되고, 추천 이유도 한 줄로 알려줘요. Stripe에서 온 메일, 캘린더의 Zoom 회의, Google Docs로 연결되는 메시지, 완료되지 않은 설정 등이 표시될 수 있어요. 해당 소스는 원래 그룹에도 **추천됨**으로 표시돼요. 이 항목은 내 Machine에서만 확인하며 외부로 전송되지 않아요. 이미 연결된 소스는 추천되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅에는 채팅용으로, 회의에는 회의 메모용 **Teams 회의**로 표시돼요. 둘 다 같은 Microsoft 로그인 정보를 사용하므로 하나를 연결하면 다른 하나도 연결돼요.

이미 연결한 소스는 목록에 계정 정보와 함께 표시돼요. 해당 소스를 선택하면 옆에 다른 계정을 추가할 수 있어요. 양식에 이를 안내하고 기존 계정으로 연결되는 링크도 표시돼요.

필요한 정보(키, 주소 등)를 입력하고 **업무**와 회사 이름 또는 **개인**을 선택한 뒤 **연결**을 누르세요. 이메일과 캘린더는 주소만으로 구분할 수 없는 경우에만 선택하라고 요청해요. LinkedIn이나 X 같은 사이트는 내 Machine의 브라우저에서 로그인 화면을 열어요. 로그인하면 자동으로 다음 단계로 진행돼요. GitHub, WhatsApp, Codex에는 입력할 코드가 표시되고, Telegram 채팅과 Signal 채팅에는 스캔할 QR 코드가 표시돼요.

**취소**를 누르면 추가가 중단돼요. 완료하기 전에 나갔더라도 어떤 기기에서든 **연결**을 다시 열면 같은 단계부터 이어서 진행돼요. 연결되면 내 Machine이 바로 읽기를 시작하고 첫 동기화 상태를 표시해요.

호스팅된 Machine에서는 별도의 로그인이 필요한 소스에 여기서 로그인할 수 있어요. Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello가 해당돼요.

**업무** 또는 **개인**을 선택한 다음 **Google로 로그인** 같은 로그인 버튼을 누르세요. 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대전화의 코드도 여기 표시돼요.

내 컴퓨터에서 사용하는 경우에는 Machine을 계정에 연결한 후 같은 소스에 로그인할 수 있어요. 처음에는 **이 Machine 연결**을 누르세요. 일부 소스는 자체 앱이나 키를 사용하는 다른 방법도 제공해요.

소스의 **다시 연결**이나 **확인 필요**를 누르면 같은 양식이 열려요. 내 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 돼요.

## 업무 또는 개인

각 소스는 업무(지정한 회사용) 또는 개인용으로 분류돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 내 Machine이 주소를 보고 분류했다는 뜻이에요. 업무용 할 일은 업무일이 될 때까지 기다려요.

Google 및 Microsoft의 이메일과 캘린더는 주소로 구분할 수 있으면 자동 분류돼요. Gmail이나 Outlook.com 같은 이메일 제공업체는 개인용이고, 팀 도메인은 업무용이에요. 명확하지 않으면 로그인 직후 한 번 물어봐요. **변경**을 누르면 직접 설정할 수 있어요. 나중에 이메일 내용에서 다른 용도라고 판단되면 **The Machine 더 알차게 사용하기** 할 일에서 변경할지 한 번 물어봐요.

## 권한

소스는 신호를 가져와 할 일로 만들거나, 할 일을 위해 작업(문서 읽기, 확인 후 보내기, 답장하기 또는 변경하기)을 하거나, 둘 다 할 수 있어요. 두 기능을 모두 지원하는 소스에는 **세부 정보**에 각각의 스위치가 있어요. **신호를 가져와요**와 **작업 수행 가능**이에요. 스위치 하나는 항상 켜져 있어요. 두 기능을 모두 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 표시돼요.

**신호를 가져와요**를 끄면 동기화하지 않아요. **작업 수행 가능**을 끄면 내 Machine은 해당 소스로 어떤 내용도 읽거나 초안을 작성하거나 변경하지 않아요.

## 소스 삭제

소스를 열고 **세부 정보**를 선택한 다음 **연결 해제**를 누르세요. 더 이상 내용을 읽지 않아요. 이미 가져온 항목은 그대로 유지돼요. 호스팅된 Machine에서 설정 페이지에 로그인 정보가 저장된 소스(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시돼요. 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 지난 30일 동안 연결을 해제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 연결 해제 시점이 표시돼요. 서비스에서 확인해 줄 때까지는 대기 중으로 표시되고 계속 다시 시도해요. Google 계정은 한 번만 표시돼요. Google Meet 또는 Docs에서 별도의 로그인 정보를 사용한 경우도 마찬가지예요. 각 계정은 해당 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 그러면 **로그인 세션**에 표시되고, 사이트에서 내 Machine의 로그아웃을 처리하면 한 번 탭해 다시 로그인할 수 있어요. 비밀번호는 내 Machine에 암호화되어 저장돼요. **잊기**를 누르면 삭제돼요.

사이트에 **업무**와 **개인**처럼 여러 계정을 저장할 수 있어요. **다른 이름으로 저장**은 할 일에 설정된 용도를 기본으로 사용하고, **다른 이름…**을 선택하면 원하는 이름을 지정할 수 있어요. 할 일은 용도에 맞는 계정으로 로그인해요. 어떤 계정인지 명확하지 않으면 대화상자에서 한 번 물어보고 해당 할 일에 사용할 계정을 기억해요.

**로그인 세션**에는 사이트가 한 번씩 표시되고, 그 아래에 각 계정이 표시돼요. 계정의 사용자 이름과 용도를 보여 주는 메뉴가 있어요. 언제든 메뉴에서 용도를 변경할 수 있어요. 계정 구분 기능이 추가되기 전에 저장한 로그인에는 용도를 선택할 때까지 **업무 또는 개인용인가요?**가 표시돼요. 로그인 정보를 사용한 할 일은 용도를 변경하면 다시 선택해요.

**가져오기**를 사용하면 비밀번호 관리자에서 로그인 정보를 가져올 수 있어요. 하나를 선택하세요.

- **LastPass**, **Bitwarden** 또는 **Google 비밀번호 관리자**: 내 Machine의 브라우저에서 내보내기 페이지가 열려요. 로그인하면 내 Machine이 내보내기를 진행해요. 마스터 비밀번호 입력처럼 직접 해야 할 일이 한 줄로 표시돼요. 휴대전화에서는 입력할 위치가 확대돼요. 페이지가 예상과 다르게 표시되면 직접 완료하는 방법이 대신 표시돼요. 내 Machine이 파일을 가져와 한 번 읽은 다음 삭제해요.
- **1Password**: 컴퓨터의 1Password 앱에서 CSV를 내보낸 다음 해당 파일을 선택하세요. 1Password의 `op`에 내 Machine에서 로그인되어 있으면 해당 위치에서 읽어 와요. LastPass의 `lpass`도 마찬가지예요.
- **내보낸 파일에서**: 1Password, LastPass, Bitwarden 또는 Chrome에서 내보낸 CSV를 선택하세요. 사용을 마치면 파일을 삭제하세요.

그런 다음 보관할 계정을 선택하세요. 내 Machine은 비밀번호 관리자에 대신 로그인하거나, 마스터 비밀번호를 입력하거나 읽지 않아요. 페이지를 어시스턴트에게 보여 주지도 않아요. 페이지에 비밀번호를 직접 입력해야 해요.

저장된 로그인은 같은 사이트 주소, `https`, 포트에서만 사용할 수 있어요. 비슷해 보이는 다른 주소나 다른 하위 도메인에서는 사용할 수 없어요.

## 확인

**확인**에는 내 Machine이 가져온 내용을 확인하는 방식이 표시돼요. 최근 확인 내역과 각 확인에서 찾은 내용을 볼 수 있어요. [새 할 일이 없는 경우](reviews-paused.md)를 참고하세요.

이 섹션의 연결 항목마다 읽는 내용과 보낼 수 있는 내용을 설명하는 문서가 있어요.
