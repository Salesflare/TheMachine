## 연결 상태 확인하기

**연결** 탭에는 소스가 종류별로 표시되고, 구분선 아래에는 **로그인 세션**과 **확인**이 표시돼요. 휴대전화에서는 종류를 눌러 열고, **연결**을 눌러 돌아가세요. 확인이 필요한 소스가 있는 종류가 먼저 열려요. 각 소스는 한 줄로 표시돼요. 연결 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결 중, 확인 필요)와 최근에 가져온 내용을 확인할 수 있어요. 소스를 누르면 카드와 **세부 정보**가 표시돼요.

나중에 동기화가 성공해 만회한 실패 기록은 회색으로 표시돼요. 가장 최근에도 실패한 경우에만 문제로 표시되며, 다음 시도 시점도 함께 표시돼요.

소스의 횟수에는 가져온 전체 항목과 [기록](history.md), 지난 24시간 동안 가져온 항목, 아직 확인하지 않은 항목이 표시돼요. 캘린더에는 일정 수가 표시돼요.

각 소스의 이름은 서비스에서 정한 계정 이름을 따라요. 주소, X 프로필, Slack 워크스페이스, 또는 Signal이나 Telegram 계정 소유자 이름 등이 표시돼요. 이름 아래에는 먼저 **업무** 또는 **개인**이 표시되고, 이름에 주소나 핸들이 포함되지 않은 경우 함께 표시돼요. 같은 종류에 이름이 같은 소스가 두 개 있으면 Slack이나 X처럼 구분할 수 있는 정보나 워크스페이스 주소도 표시돼요.

각 소스에는 어떤 정보를 가져오는지 한 줄로 표시돼요. 작업을 수행할 수 있는 소스라면 **보내기**를 누르거나 승인한 뒤에만 작업한다는 내용도 표시돼요.

## 소스 추가하기

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없다면 목록 아래에서 선택할 수도 있어요. 모든 항목을 아우르는 옵션은 목록 마지막에 있어요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의 정보를 읽기 때문에 캘린더 아래에 표시돼요.

내 Machine에서 소스를 연결할 이유가 발견되면 **추천 항목**이 **연결** 맨 위에 표시되고, 추천 이유가 한 줄로 안내돼요. 예를 들어 Stripe에서 온 메일, 캘린더에 있는 Zoom 회의, Google Docs로 연결되는 메시지, 또는 완료되지 않은 설정 등이 표시돼요. 해당 소스는 원래 그룹에도 **추천됨** 표시와 함께 계속 나타나요. 이 항목은 내 Machine에서 계산되며, 외부로 전송되지 않아요. 이미 연결된 소스는 추천되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅은 **채팅** 아래에, 회의록은 **회의** 아래의 **Teams 회의**에 표시돼요. 두 항목 모두 같은 Microsoft 로그인 정보를 사용하므로 하나를 연결하면 다른 하나도 연결돼요.

이미 연결한 소스는 계정 정보와 함께 목록에 표시돼요. 이를 선택하면 옆에 다른 계정을 추가할 수 있어요. 양식에 다른 계정을 추가한다고 표시되고, 기존 계정으로 연결되는 링크도 제공돼요.

필요한 정보(키, 주소 등)를 입력하고, 회사 계정이면 **업무**, 개인 계정이면 **개인**을 선택한 다음(**이메일**과 캘린더는 주소만으로 구분되지 않는 경우에만 물어봐요) **연결**을 누르세요. LinkedIn이나 X 같은 사이트는 내 Machine의 브라우저에서 로그인 화면을 열어요. 로그인하면 자동으로 다음 단계로 넘어가요. GitHub, WhatsApp, Codex는 입력할 코드를 표시하고, Telegram 채팅과 Signal 채팅은 스캔할 QR 코드를 표시해요.

**취소**를 누르면 추가가 중단돼요. 완료하기 전에 나가도 괜찮아요. 어느 기기에서든 **연결**을 다시 열면 같은 단계부터 이어서 진행돼요. 연결되면 내 Machine이 바로 읽기를 시작하고 첫 동기화 상태를 표시해요.

호스팅된 Machine에서는 자체 로그인이 필요한 소스에 여기서 바로 로그인할 수 있어요. Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello가 해당돼요.

**업무** 또는 **개인**을 선택하고 **Google로 로그인** 같은 로그인 버튼을 누르세요. 이 양식으로 돌아오면 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대전화도 여기서 코드를 표시해요.

내 컴퓨터에서 같은 소스에 로그인하려면 먼저 내 Machine을 계정에 연결해야 해요. 처음에는 **이 Machine 연결**을 누르세요. 일부 소스는 자체 앱이나 키 같은 다른 방법도 제공해요.

소스에서 **다시 연결**을 누르거나 **확인 필요**에서 선택하면 같은 양식이 열려요. 내 컴퓨터에서는 터미널에서 `assistant connect` 명령을 실행해도 돼요.

## 업무용 또는 개인용

각 소스는 업무용(이름을 지정한 회사 계정) 또는 개인용으로 구분돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 내 Machine이 주소를 바탕으로 구분했다는 뜻이에요. 업무 할 일은 근무일이 될 때까지 기다려요.

Google 및 Microsoft의 이메일과 캘린더는 주소만으로 구분할 수 있으면 주소를 기준으로 설정돼요. Gmail이나 Outlook.com 같은 메일 서비스는 개인용이고, 팀 도메인은 업무용이에요. 구분할 수 없으면 로그인 직후 한 번 물어봐요. **변경**을 누르면 직접 설정할 수 있어요. 나중에 메일에서 다른 용도인 것으로 확인되면 **The Machine 더 알차게 사용하기** 할 일에서 변경할지 한 번 물어봐요.

## 기능

소스는 신호를 가져오거나(가져온 내용이 할 일이 돼요), 할 일을 위해 작업하거나(문서 읽기, 또는 승인 후 보내기, 답장하기, 내용 변경하기), 두 가지를 모두 할 수 있어요. 두 기능을 모두 지원하면 **세부 정보**에 각각 전환 버튼이 있어요. **신호 가져오기**와 **작업 수행 가능**이에요. 하나는 항상 켜져 있어요. 둘 다 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 표시돼요.

**신호 가져오기**를 끄면 동기화하지 않아요. **작업 수행 가능**을 끄면 내 Machine은 해당 소스로 아무것도 읽거나, 초안을 작성하거나, 변경하지 않아요.

## 소스 삭제하기

소스를 열고 **세부 정보**를 선택한 다음 **연결 해제**를 누르세요. 더 이상 정보를 읽지 않아요. 이미 가져온 내용은 그대로 남아요. 호스팅된 Machine에서 설정 페이지에 로그인 정보가 저장된 소스(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시돼요. 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 지난 30일 동안 삭제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 삭제한 시점이 표시돼요. 서비스에서 확인될 때까지 대기 중으로 표시되고 계속 시도해요. Google Meet이나 Docs에 별도 로그인이 있었더라도 Google 계정은 한 번만 표시돼요. 각 계정은 해당 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 그러면 **로그인 세션**에 로그인 정보가 표시되고, 사이트에서 내 Machine이 로그아웃되면 한 번 눌러 다시 로그인할 수 있어요. 비밀번호는 내 Machine에서 암호화된 상태로 보관돼요. 하나를 삭제하려면 **잊기**를 누르세요.

한 사이트에 **업무**와 **개인** 같은 계정을 여러 개 저장할 수 있어요. **다른 이름으로 저장**은 할 일의 용도에 맞는 이름부터 표시하고, **다른 이름…**을 선택하면 직접 이름을 정할 수 있어요. 할 일에는 용도에 맞는 계정으로 로그인해요. 용도를 구분할 수 없으면 대화상자에서 사용할 계정을 한 번 물어보고, 해당 할 일에 기억해 둬요.

**로그인 세션**에는 사이트별로 한 번씩 표시되고, 그 아래에 계정이 표시돼요. 사용자 이름과 용도를 보여 주는 메뉴가 있어요. 언제든 메뉴에서 용도를 변경할 수 있어요. 계정 기능이 생기기 전에 저장한 로그인 정보에는 용도를 선택할 때까지 **업무 또는 개인용인가요?**가 표시돼요. 로그인 정보를 사용한 할 일은 용도를 변경한 뒤 다시 계정을 선택해요.

**가져오기**를 선택하면 비밀번호 관리자에서 로그인 정보를 가져올 수 있어요. 다음 중 하나를 선택하세요.

- **LastPass**, **Bitwarden** 또는 **Google 비밀번호 관리자**: 내 Machine의 브라우저에서 해당 서비스의 내보내기 페이지가 열리고, 대화상자 안에 표시돼요. 할 일의 **실행**과 마찬가지로, 해당 페이지에 로그인하면 내 Machine이 내보내기를 진행해요. 마스터 비밀번호 입력처럼 직접 해야 할 작업이 한 줄로 안내돼요. LastPass는 내보내기를 확인하는 링크를 이메일로 보내요. 내 Machine은 한 번 내보내기를 시작하고, 연결된 메일함에 10분 안에 메일이 도착하면 링크를 직접 열어요. 그렇지 않으면 직접 확인한 뒤 다시 내보내도록 안내해요. 휴대전화에서는 입력할 위치까지 화면이 확대돼요. 페이지가 예상과 다르게 보이면 수동으로 완료하는 단계가 대신 표시돼요. 내 Machine은 파일을 가져와 한 번 읽고 삭제해요.
- **1Password**: 컴퓨터의 1Password 앱에서 CSV 파일을 내보낸 다음 해당 파일을 선택하세요. 1Password의 `op`가 내 Machine에 로그인돼 있으면 그곳에서 가져와요. LastPass의 `lpass`도 마찬가지예요.
- **내보낸 파일에서**: 1Password, LastPass, Bitwarden 또는 Chrome에서 내보낸 CSV 파일을 선택하세요. 완료되면 파일을 삭제하세요.

그런 다음 저장할 항목을 선택하세요. 내 Machine은 비밀번호 관리자에 대신 로그인하거나, 마스터 비밀번호를 입력하거나 읽지 않아요. 페이지를 어시스턴트에 보여 주지도 않아요. 비밀번호는 직접 페이지에 입력해야 해요.

저장된 로그인 정보는 해당 웹 주소에만 사용돼요. 같은 사이트, `https`, 같은 포트여야 해요. 비슷한 주소나 다른 하위 도메인에는 사용되지 않아요.

## 확인

**확인**에는 내 Machine이 가져온 정보를 확인하는 방식이 표시돼요. 최근에 확인한 내용과 각 확인에서 발견한 내용을 볼 수 있어요. [새 할 일이 없어요](reviews-paused.md)를 참고하세요.

이 섹션의 각 연결에는 별도 도움말이 있어요. 읽는 정보와 보낼 수 있는 내용을 확인할 수 있어요.
