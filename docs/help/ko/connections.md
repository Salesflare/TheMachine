## 상태 확인

**연결** 탭에는 연결 항목이 종류별로 표시되고, 각 항목 아래에 **로그인 세션**과 **확인**이 나와요. 휴대전화에서는 종류를 눌러 열고 **연결**을 눌러 돌아가세요. 확인이 필요한 연결 항목이 있는 종류가 먼저 열려요. 각 연결 항목은 한 줄로 표시돼요. 연결 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결 중, 확인 필요)와 최근에 가져온 항목을 볼 수 있어요. 연결 항목을 누르면 카드와 **세부 정보**가 열려요.

나중 동기화에서 보완된 동기화 실패는 회색으로 표시돼요. 가장 최근 동기화도 실패한 경우에만 문제로 표시되며, 다음 시도 시각도 함께 나와요.

각 연결 항목의 수에는 가져온 전체 항목과 [기록](history.md), 지난 24시간 동안 가져온 항목, 아직 확인하지 않은 항목이 표시돼요. 캘린더에는 일정 수가 표시돼요.

연결 항목의 이름은 서비스에서 사용하는 계정 이름을 따르며, 이메일 주소, X 프로필, Slack 워크스페이스, 또는 Signal이나 Telegram 계정 소유자 이름일 수 있어요. 이름 아래에는 먼저 **업무** 또는 **개인**이 표시되고, 이름에 이미 포함되어 있지 않으면 주소나 사용자 이름도 표시돼요. 같은 종류의 연결 항목 이름이 같으면 Slack이나 X처럼 구분할 수 있는 정보도 표시돼요. 예를 들어 워크스페이스 주소가 나와요.

각 연결 항목에는 한 줄로 가져오는 정보가 설명돼요. 작업을 수행할 수 있는 경우에는 **보내기**를 누르거나 승인한 뒤에만 작업한다고 표시돼요.

## 연결 항목 추가

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **하나 더 추가** 아래에서 연결 항목을 선택하세요. 아직 연결된 항목이 없으면 목록 아래에서 선택할 수 있어요. 마지막에는 기타 항목이 표시돼요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의를 가져오므로 캘린더 아래에 있어요.

내 Machine에서 연결 항목을 추천할 이유가 있으면 **연결** 위에 **추천 항목**이 표시되고, 추천 이유도 한 줄로 나와요. Stripe에서 온 메일, 캘린더에 있는 Zoom 회의, Google Docs 링크가 포함된 메시지, 완료되지 않은 설정 등이 이유일 수 있어요. 해당 연결 항목은 원래 그룹에도 **추천됨**으로 표시돼요. 이 항목은 내 Machine에서 확인하며, 외부로 전송되지 않아요. 이미 연결된 항목은 추천되지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅 아래에는 채팅 항목으로, 회의 아래에는 회의록을 위한 **Teams 회의**로 표시돼요. 두 항목은 같은 Microsoft 로그인 정보를 사용하므로 하나를 연결하면 다른 항목도 연결돼요.

이미 연결한 항목은 목록에 계정 정보와 함께 표시돼요. 이 항목을 선택하면 옆에 계정을 하나 더 추가할 수 있어요. 양식에 계정을 추가하는 항목이라고 표시되고, 기존 계정으로 연결되는 링크도 나와요.

필요한 정보(키, 주소 등)를 입력하고 회사 계정은 **업무**, 개인 계정은 **개인**을 선택한 다음 **연결**을 누르세요. 이메일과 캘린더는 주소만으로 구분되지 않는 경우에만 선택을 요청해요. LinkedIn이나 X 같은 사이트는 내 Machine의 브라우저에서 로그인 화면을 열고, 로그인하면 자동으로 다음 단계로 넘어가요. GitHub, WhatsApp, Codex는 입력할 코드를 표시하고, Telegram 채팅과 Signal 채팅은 스캔할 QR 코드를 표시해요.

**취소**를 누르면 연결 추가가 중단돼요. 완료하기 전에 나갔더라도 어떤 기기에서든 **연결**을 다시 열면 같은 단계부터 이어서 진행할 수 있어요. 연결되면 내 Machine이 바로 읽기를 시작하고 첫 동기화 상태를 보여줘요.

호스팅된 Machine에서는 별도 로그인이 필요한 연결 항목을 여기서 바로 로그인할 수 있어요. Google, Microsoft(Outlook, OneDrive, Teams), Google Meet, Google Docs, Slack, Zoom, Stripe, Intercom, Salesforce, Trello가 해당돼요.

**업무** 또는 **개인**을 선택하고 **Google로 로그인** 같은 로그인 버튼을 누르세요. 다시 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대전화는 여기에서 코드도 표시해요.

내 컴퓨터에서는 Machine을 계정에 연결한 뒤 같은 연결 항목에 로그인할 수 있어요. 처음에는 **이 Machine 연결**을 누르세요. 일부 항목은 자체 앱이나 키를 사용하는 다른 방법도 있어요.

연결 항목이나 **확인 필요**에서 **다시 연결**을 누르면 같은 양식이 열려요. 내 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 돼요.

## 업무용 또는 개인용

각 연결 항목은 업무용(회사 이름 포함) 또는 개인용으로 분류돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 내 Machine이 주소를 보고 분류했다는 뜻이에요. 업무용 할 일은 업무일에 처리돼요.

Google과 Microsoft의 이메일 및 캘린더는 주소로 분류할 수 있는 경우 자동으로 분류해요. Gmail이나 Outlook.com 같은 메일 서비스는 개인용이고, 회사 도메인은 업무용이에요. 명확하지 않으면 로그인 직후 한 번 물어봐요. **변경**을 눌러 직접 설정할 수 있어요. 나중에 메일을 확인했을 때 다른 분류가 맞는 것으로 보이면 **The Machine 더 알차게 사용하기** 할 일에서 변경할지 한 번 물어봐요.

## 기능

연결 항목은 신호를 가져올 수 있고(가져온 내용이 할 일이 돼요), 할 일을 위해 작업을 수행할 수도 있어요(문서를 읽거나, 승인 후 보내고 답장하거나 내용을 변경해요). 두 기능을 모두 지원하면 **세부 정보**에 **신호를 가져와요**와 **작업 수행 가능** 스위치가 각각 표시돼요. 둘 중 하나는 항상 켜져 있어요. 두 기능을 모두 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행 가능**만 있어요.

**신호를 가져와요**를 끄면 동기화되지 않아요. **작업 수행 가능**을 끄면 내 Machine은 해당 연결 항목에서 내용을 읽거나 초안을 작성하거나 변경하지 않아요.

## 연결 항목 삭제

연결 항목을 열고 **세부 정보**를 선택한 다음 **연결 해제**를 누르세요. 읽기가 중지돼요. 이미 가져온 항목은 그대로 유지돼요. 호스팅된 Machine에서 설정 페이지가 로그인 정보를 관리하는 연결 항목(Google, Microsoft, Google Meet, Slack, Zoom, Stripe, Salesforce)에는 **연결 해제 ↗**가 표시돼요. 누르면 설정 페이지가 열려요.

**최근 연결 해제됨**에는 지난 30일 동안 삭제한 Google, Microsoft, Zoom, Slack, Stripe, Salesforce 계정과 삭제 시점이 표시돼요. 서비스에서 확인이 끝날 때까지 대기 중으로 표시되고 계속 다시 시도해요. Google 계정은 한 번만 표시돼요. Google Meet이나 Docs에 별도 로그인이 있었던 경우에도 마찬가지예요. 각 계정은 해당 종류 아래에 표시돼요. Google 또는 Microsoft 계정은 **이메일** 아래에, Slack은 **채팅** 아래에 표시돼요.

## 저장된 로그인

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에도 사용할 수 있게 저장**을 선택하세요. 그러면 **로그인 세션**에 표시되고, 사이트에서 내 Machine의 로그아웃이 처리되면 한 번 눌러 다시 로그인할 수 있어요. 비밀번호는 내 Machine에 암호화되어 저장돼요. **잊기**를 누르면 저장된 로그인을 삭제할 수 있어요.

사이트마다 **업무**와 **개인**처럼 여러 계정을 사용할 수 있어요. **다른 이름으로 저장**은 할 일에 맞는 분류로 시작하고, **다른 이름…**을 선택하면 원하는 이름을 지정할 수 있어요. 할 일에는 알맞은 계정으로 로그인해요. 알맞은 계정이 명확하지 않으면 대화상자에서 한 번 물어보고 해당 할 일에 기억해 둬요.

**로그인 세션**에는 사이트마다 한 번씩 표시되고, 그 아래에 계정이 나와요. 계정에는 사용자 이름과 분류를 보여주는 메뉴가 있어요. 언제든 메뉴에서 분류를 변경할 수 있어요. 계정 분류를 설정하기 전에 저장한 로그인은 분류를 선택할 때까지 **업무 또는 개인용인가요?**로 표시돼요. 로그인 정보를 사용한 할 일은 분류를 변경한 뒤 다시 계정을 선택해요.

**가져오기**를 사용하면 비밀번호 관리자에서 로그인 정보를 가져올 수 있어요. 하나를 선택하세요.

- **LastPass**, **Bitwarden** 또는 **Google 비밀번호 관리자**: 내 Machine의 브라우저에서 내보내기 페이지가 열려요. 로그인한 뒤 해당 페이지에서 내보내세요. 단계별 안내도 함께 표시돼요. 내 Machine이 파일을 가져와 한 번 읽은 다음 삭제해요.
- **1Password**: 컴퓨터의 1Password 앱에서 CSV를 내보낸 다음 해당 파일을 선택하세요. 내 Machine에서 1Password의 `op`에 로그인되어 있으면 대신 거기에서 읽어요. LastPass의 `lpass`도 마찬가지예요.
- **내보낸 파일에서**: 1Password, LastPass, Bitwarden 또는 Chrome에서 내보낸 CSV를 선택하세요. 작업이 끝나면 파일을 삭제하세요.

그런 다음 유지할 로그인 정보를 선택하세요. 내 Machine은 비밀번호 관리자에 대신 로그인하지 않으며 마스터 비밀번호를 묻지도 않아요. 마스터 비밀번호는 로그인 페이지에 직접 입력하세요.

저장된 로그인 정보는 해당 웹 주소에만 사용돼요. 같은 사이트, `https`, 포트가 모두 일치해야 해요. 비슷해 보이는 주소나 다른 하위 도메인에는 사용되지 않아요.

## 확인

**확인**에는 내 Machine이 가져온 내용을 어떻게 읽는지 표시돼요. 최근 확인 내역과 각 확인에서 찾은 내용을 볼 수 있어요. [새 할 일이 없음](reviews-paused.md)을 참고하세요.

각 연결 항목에 대한 별도 문서가 이 섹션에 있어요. 어떤 내용을 읽고 무엇을 보낼 수 있는지 설명해요.
