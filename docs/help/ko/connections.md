## 상태 확인

**연결** 탭에는 소스가 종류별로 표시되고, 구분선 아래에 **로그인**과 **검토**가 있어요. 휴대폰에서는 종류를 눌러 열고 **연결**을 눌러 돌아가세요. 도움이 필요한 소스가 있는 종류가 먼저 열려요. 각 소스는 한 줄로 표시되며, 상태(연결됨, 첫 동기화 대기 중, 자동으로 다시 연결 중, 도움이 필요해요)와 최근에 가져온 항목을 확인할 수 있어요. 소스를 누르면 카드와 **세부 정보**가 열려요.

나중에 동기화되어 보완된 동기화 실패는 회색으로 표시돼요. 가장 최근에도 실패한 경우에만 문제로 표시하고, 다음 시도 시각도 알려줘요.

항목 수에는 [기록](history.md)까지 포함해 가져온 모든 항목, 지난 24시간 동안 가져온 항목, 아직 확인하지 않은 항목이 표시돼요. 캘린더에는 일정 수가 표시돼요.

각 소스의 이름은 서비스에서 정한 계정 이름을 사용해요. 이메일 주소, X 프로필, Slack 워크스페이스, Signal 또는 Telegram 계정 이름 등이 표시돼요. 이름 아래에는 먼저 **업무** 또는 **개인**이 표시되고, 이름만으로 구분되지 않을 때는 주소나 핸들도 표시돼요. 같은 종류에 이름이 같은 소스가 두 개 있으면 Slack이나 X처럼 구분할 수 있는 정보나 워크스페이스 주소도 표시돼요.

각 소스에는 어떤 항목을 가져오는지 한 줄로 표시돼요. 작업도 할 수 있는 소스라면 **보내기**를 누르거나 확인한 뒤에만 작업한다고 알려줘요.

## 소스 추가

종류(**이메일**, **캘린더**, **채팅**, **회의**, **문서 및 파일**, **고객**, **프로젝트 및 코드**, **기타**)를 열고 **다른 소스 추가** 아래에서 소스를 선택하세요. 아직 연결된 소스가 없으면 목록 아래에서 선택할 수 있어요. 기타 항목은 마지막에 표시돼요. 이메일에는 **기타 이메일**, 캘린더에는 **캘린더 링크 (ICS)**와 **기타 캘린더**가 있어요. Exchange Server는 회의를 가져오므로 캘린더에 있어요.

The Machine이 소스가 필요한 이유를 파악하면 **연결** 위에 **추천 항목**이 표시되고, 이유도 한 줄로 알려줘요. Stripe에서 온 이메일, 캘린더의 Zoom 회의, Google Docs 링크가 있는 메시지, 또는 완료되지 않은 설정 등이 이유가 될 수 있어요. 해당 소스는 원래 그룹에도 **추천** 표시와 함께 나타나요. 추천 항목은 The Machine에서 계산하며, 정보가 외부로 전송되지 않아요. 이미 연결된 소스는 추천하지 않아요.

Microsoft Teams는 두 곳에 표시돼요. 채팅에는 채팅용으로, 회의에는 회의록용 **Teams 회의**로 표시돼요. 둘 다 같은 Microsoft 로그인 정보를 사용하므로 하나를 연결하면 다른 하나도 연결돼요.

이미 연결한 소스는 목록에 계정과 함께 표시돼요. 해당 소스를 선택하면 옆에 다른 계정을 추가할 수 있어요. 양식에 계정을 추가한다는 안내와 기존 계정 링크가 표시돼요.

필요한 정보(키, 주소 등)를 입력하고 **업무**와 회사 이름 또는 **개인**을 선택한 다음 **연결**을 누르세요. 이메일과 캘린더는 주소만으로 구분할 수 없을 때만 선택을 요청해요. LinkedIn이나 X 같은 사이트는 The Machine의 브라우저에서 로그인 화면을 열어요. 로그인하면 자동으로 다음 단계로 넘어가요. GitHub, WhatsApp, Codex에서는 입력할 코드를 보여주고, Telegram 채팅에서는 스캔할 QR 코드를 보여줘요.

**취소**를 누르면 추가가 중단돼요. 완료하기 전에 나갔더라도 어떤 기기에서든 **연결**을 다시 열면 같은 단계부터 이어서 진행할 수 있어요. 연결되면 The Machine이 바로 소스를 읽기 시작하고 첫 동기화 상태를 보여줘요.

호스팅 환경의 The Machine에서는 Google, Microsoft, Microsoft OneDrive, Zoom, Stripe, Intercom에 여기서 로그인할 수 있어요. **업무** 또는 **개인**을 선택하고 **로그인**을 누르세요. 이 양식으로 돌아오면 로그인 결과가 표시돼요. GitHub, WhatsApp, Codex, Telegram 채팅, Android 휴대폰도 여기서 코드를 보여줘요.

소스의 **다시 연결**이나 **도움이 필요해요**를 누르면 같은 양식이 열려요. 개인 컴퓨터에서는 터미널에서 `assistant connect`을 실행해도 돼요.

## 업무용 또는 개인용

각 소스는 업무용(회사 이름 지정) 또는 개인용으로 설정돼요. **세부 정보**에서 변경할 수 있어요. **추정됨**은 The Machine이 주소를 보고 설정했다는 뜻이에요. 업무용 할 일은 업무일에 표시돼요.

Google 및 Microsoft 이메일과 캘린더는 주소로 구분할 수 있으면 주소를 기준으로 설정돼요. Gmail이나 Outlook.com 같은 이메일 서비스는 개인용이고, 팀 도메인은 업무용이에요. 구분할 수 없으면 로그인 직후 한 번 물어봐요. **변경**을 눌러 직접 설정할 수 있어요. 나중에 이메일에서 다른 용도라고 확인되면 **The Machine 더 잘 활용하기** 할 일에서 변경할지 한 번 물어봐요.

## 기능

소스는 신호를 가져와서(가져온 내용이 할 일이 돼요), 할 일을 대신 처리할 수 있어요(문서 읽기, 또는 확인 후 보내기, 답장하기, 변경하기). 둘 다 가능한 소스는 **세부 정보**에 **신호 가져오기**와 **작업 수행** 스위치가 각각 있어요. 둘 중 하나는 항상 켜져 있어요. 둘 다 중지하려면 연결을 해제하세요. 채팅에는 **작업 수행**만 있어요.

**신호 가져오기**를 끄면 동기화하지 않아요. **작업 수행**을 끄면 The Machine은 해당 소스로 아무것도 읽거나, 초안을 작성하거나, 변경하지 않아요.

## 소스 삭제

소스를 열고 **세부 정보**를 누른 다음 **연결 해제**를 선택하세요. 더 이상 소스를 읽지 않아요. 이미 가져온 내용은 그대로 남아요. 호스팅 환경의 The Machine에서는 Google, Microsoft, Microsoft OneDrive, Zoom, Stripe에 **연결 해제 ↗**가 표시되며, 누르면 설정 페이지가 열려요.

**최근 연결 해제**에는 삭제한 Google, Microsoft, Zoom 로그인이 표시돼요. **삭제 완료**는 로그인이 모든 곳에서 삭제됐다는 뜻이에요. **대기 중**에는 이유가 표시되며, The Machine은 계속 삭제를 시도해요.

## 저장된 로그인 정보

LinkedIn이나 X 같은 사이트에 로그인할 때 **다음에 사용하도록 저장**을 선택하세요. 그러면 **로그인**에 해당 정보가 표시되고, 사이트에서 The Machine의 로그아웃을 처리해도 한 번만 누르면 다시 로그인해요. 비밀번호는 The Machine에 암호화된 상태로 저장돼요. **삭제**를 누르면 로그인 정보를 삭제해요.

## 검토

**검토**에는 The Machine이 가져온 내용을 확인한 결과가 표시돼요. 최근 검토 내역과 각 검토에서 찾은 내용을 확인할 수 있어요. [새 할 일이 없어요](reviews-paused.md)를 참고하세요.

각 연결에는 이 섹션에 별도의 문서가 있어요. 어떤 내용을 읽고 무엇을 보낼 수 있는지 확인할 수 있어요.
