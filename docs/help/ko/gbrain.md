## 사용 설정

GBrain은 이미 사용하는 사람도 있는 오픈 소스 에이전트 메모리예요. 직접 사용 설정하지 않으면 꺼져 있고, 내 컴퓨터에서 실행 중인 Machine에서만 사용할 수 있어요. 먼저 GBrain을 설치한 다음 **연결**, **기타**, **GBrain**을 열어요.

포함할 내용은 Machine이 정해요. Graph에 있는 사람과 프로젝트(원래 위치로 돌아가는 링크 포함), 그리고 일하는 방식에 관해 배운 내용이 포함돼요. 메시지 내용은 절대 포함되지 않아요. GBrain은 이 정보를 자체 AI 제공업체에 보낼 수 있어요. **동의**를 선택한 다음 **GBrain 연결**을 선택해요.

## 작동 방식

체크에서는 GBrain을 검색하고 페이지를 읽어 더 나은 할 일을 작성할 수 있어요. 페이지에 쓰지는 않아요. Machine은 각 페이지에서 알아보기 쉽게 표시된 구분자 사이에 자체 내용을 작성해요. 해당 부분을 수정하거나 삭제하면, 수정하거나 삭제한 상태 그대로 둬요. GBrain에서 사람에 관해 작성한 메모는 Graph에서 해당 사람 옆에 표시돼요.

업무 관련 사람과 회사는 **업무 관련 사람과 회사 포함**을 선택한 경우에만 포함돼요. 팀원의 Team Graph 데이터는 절대 포함되지 않아요.

## 사용 중지

다시 **GBrain**을 열고 **끄기**를 눌러요. GBrain과 페이지는 그대로 유지돼요. Machine은 GBrain과의 자체 연결과 가져온 메모만 삭제해요.
