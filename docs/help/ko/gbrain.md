## 사용 설정

GBrain은 일부 사용자가 이미 사용하는 오픈소스 에이전트 메모리예요. 직접 사용 설정하기 전까지 꺼져 있고, 내 컴퓨터의 Machine에서만 사용할 수 있어요. 먼저 GBrain을 설치한 다음 **연결**, **기타**, **GBrain**을 열어요.

무엇을 저장할지는 내 Machine이 정해요. Graph의 사람과 프로젝트, Graph로 돌아가는 링크, 그리고 일하는 방식에 관해 배운 내용이 들어가요. 메시지 내용은 저장되지 않아요. GBrain은 이 정보를 자체 AI 제공업체에 보낼 수 있어요. **동의해요**를 선택한 다음 **GBrain 연결**을 눌러요.

## 기능

확인 작업에서는 메모리를 검색하고 페이지를 읽을 수 있지만, 쓰기는 할 수 없어요. 이를 통해 더 나은 할 일을 작성해요. 각 페이지에서 내 Machine이 작성한 부분은 명확한 표시로 구분해 저장해요. 해당 부분을 수정하거나 삭제하면, 내 Machine은 수정하거나 삭제한 상태를 그대로 유지해요. GBrain에서 사람에 대해 작성한 메모는 내 Machine으로 돌아와 해당 인물의 정보와 함께 표시되므로, 확인 작업과 채팅에서 확인할 수 있어요. 메모는 내 Machine에 남아요.

**업무 연락처 및 회사 포함**을 선택한 경우에만 업무 연락처와 회사가 포함돼요. 팀원의 팀 Graph 데이터는 포함되지 않아요.

## 사용 중지

**GBrain**을 다시 열고 **끄기**를 눌러요. GBrain 메모리와 페이지는 그대로 유지돼요. 내 Machine에서는 GBrain으로 연결하는 자체 링크와 가져온 메모만 삭제돼요.
