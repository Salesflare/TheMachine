## 다른 AI가 할 수 있는 일

Claude, ChatGPT, Cursor, Codex, GBrain 및 다른 AI를 내 Machine에 연결할 수 있어요. AI는 내 할 일, 약속, 팀 브리프, Graph에 있는 사람과 회사를 읽을 수 있어요.

**읽기 및 수정** 권한을 주면 할 일이나 이메일 초안을 추가하고, Graph에 정보를 저장하거나 세부 정보, 필드, 태그를 수정하고, 사람의 요약에 내용을 추가할 수도 있어요.

변경 사항은 모두 **활동**에 표시되고 **실행 취소**할 수 있어요. AI는 기록을 병합하거나 삭제하거나 공유하지 않아요. AI가 저장한 내용에는 이름과 함께 **AI:**가 표시돼요. 내 Machine은 이 내용을 AI의 주장으로 취급하며, 지시로 여기지 않아요.

초안은 직접 읽고 **보내기**를 눌러야 전송돼요. 연결된 AI는 아무것도 보내지 않고, 대신 행동하지도 않아요.

작성할 내용이 남아 있는 초안, 언급된 파일이 실제로 첨부되지 않은 초안, 내 주소만 적힌 초안은 AI가 먼저 수정하도록 돌려보내요. AI가 같은 할 일이나 초안을 연달아 두 번 요청하면 한 번만 만들어져요.

## 연결하기

**설정**에서 **앱**을 열어요. **The Machine 앱** 아래에 **ChatGPT에 추가**와 **Claude에 추가**가 있어요. **또는 주소로 추가해요** 아래에는 공식 앱의 모든 Machine에서 사용하는 주소 `https://mcp.themachine.computer/mcp`과 **주소** `https://<your name>.mcp.themachine.computer/mcp`가 있으며, 각각 **복사**할 수 있어요.

내 컴퓨터에서 실행 중인 Machine이라면 먼저 **주소 받기** 아래의 **설정하기**를 눌러요. 계정 페이지가 열리면 같은 코드가 표시되는지 확인하고, 연결을 승인한 뒤 이름을 정해요. 재시작하지 않아도 Machine이 자동으로 연결돼요. 두 방법 모두 이 단계가 필요해요.

그러면 내 Machine이 보안 주소를 자동으로 설정해요. 몇 분 정도 걸려요.

Claude에서는 **Claude에 추가**를 누르거나 [Claude 디렉터리의 The Machine](https://claude.ai/directory/the-machine)을 열고 **연결**을 눌러요. Team 및 Enterprise에서는 관리자가 Organization settings에서 추가해야 해요.

대신 Claude에서 주소를 사용하려면 Customize, Connectors를 열고 + Add를 누른 다음 Add custom connector를 선택해요. 이름을 The Machine으로 지정하고 주소를 붙여 넣은 다음 Continue, Add를 차례로 눌러요.

ChatGPT에서는 **ChatGPT에 추가**를 누르거나 [ChatGPT의 The Machine](https://chatgpt.com/plugins/plugin_asdk_app_6ae74ac637d0819199400cd3750138b4)을 열고 Install plugin을 눌러요. Business 및 Enterprise에서는 관리자가 먼저 사용을 허용해야 할 수 있어요.

공식 앱은 호스팅된 Machine에 연결하고, 주소를 설정한 뒤에는 내 컴퓨터에서 실행 중인 Machine에도 연결해요.

비공개 주소를 사용하거나 Network에 연결되지 않은 Machine을 연결하려면 ChatGPT에서 맞춤 MCP 서버를 추가해요. chatgpt.com/plugins를 열고 +를 누른 다음 Add custom MCP server를 선택해요. 이름을 The Machine으로 지정하고 주소를 붙여 넣은 뒤 OAuth를 선택해요. 경고를 확인하고 Create as a plugin을 눌러요. 요금제나 워크스페이스에서 맞춤 MCP 서버를 허용해야 해요.

공식 앱을 사용하면 AI가 The Machine 계정으로 로그인하라고 요청해요. Machine이 여러 대라면 연결할 Machine을 선택하고, 해당 Machine의 페이지에서 승인해요. 비공개 주소를 사용하면 AI가 바로 내 Machine에 연결돼요.

Claude Code나 Cursor처럼 비공개 네트워크(Tailscale)의 기기에서 사용하는 AI도 대시보드 주소 뒤에 `/mcp`을 붙여 사용할 수 있어요. **설정**의 **계정** 아래에서 **이 Machine 연결 해제**를 누르면 내 컴퓨터에서 실행 중인 Machine을 계정에서 다시 연결 해제할 수 있어요.

내 Machine에는 어떤 AI가 요청하는지 표시돼요. 확인할 수 없으면 요청이 어디에서 왔는지 표시돼요. 직접 시작한 요청일 때만 연결해요.

AI가 할 수 있는 작업으로 **읽기** 또는 **읽기 및 수정**을 선택해요. 업무 계정과 개인 계정이 모두 있다면 AI가 볼 수 있는 범위도 선택해요. 그런 다음 권한을 유지할 기간을 **1일**, **7일**, **30일** 또는 **1년** 중에서 선택해요. **연결**을 누르거나 **취소**를 눌러 아무것도 허용하지 않고 돌아가요.

## 공식 앱 또는 비공개 주소

공식 앱을 사용하면 간편해요. 모두가 같은 주소를 사용하고, 계정에서 내 Machine을 찾아줘요. 저희 클라우드는 요청을 전달하지만 요청 내용을 저장하지 않아요.

비공개 주소를 사용하면 모든 내용이 내 Machine까지 암호화돼요. 클라우드는 요청을 전달하기만 하며 내용을 읽을 수 없어요.

어느 방법을 사용하든 권한은 내 Machine이 관리해요. 해당 Machine 페이지에서 승인한 AI만 선택한 권한으로 연결할 수 있어요. 공식 앱을 통해 연결된 AI는 **설정**의 **앱**에서 **공식 앱**으로 표시돼요.

## 볼 수 있는 내용

연결된 AI는 허용된 범위의 내용만 볼 수 있어요. 업무 범위에는 업무 계정의 할 일과 약속, 업무 관련 사람, 회사, 프로젝트, 업무 Fleet의 팀 브리프가 포함돼요. 개인 범위에는 나머지 내용이 포함돼요. **메시지**를 켜지 않으면 메시지 내용은 내 Machine에 남아요. 이 경우 AI는 보낸 사람, 제목, 날짜만 보고 할 일의 출처를 확인할 수 있어요.

팀원의 Team Graph 기록은 외부 AI에 전달되지 않아요.

## 메시지

**메시지**를 켜면 AI가 이메일, Slack, WhatsApp 및 다른 채팅을 검색하고 읽을 수 있어요. 연결하는 페이지나 나중에 **설정**의 **앱**에서 직접 켜기 전까지는 꺼져 있어요. 읽기만 가능하며, 메시지를 보내거나 삭제하거나 읽음으로 표시하지 않아요.

AI는 허용된 범위의 메시지만 읽어요. 일회용 코드와 로그인 링크, **나만**으로 설정된 보드나 프로젝트의 메시지, 내 Machine이 민감하다고 판단한 대화(거래, 인사, 법률, 건강, 금전 관련), 비공개로 설정한 대화, 삭제된 메시지는 전달되지 않아요.

메시지를 읽을 때마다 AI의 **활동**에 읽은 메시지 수와 대화 목록이 표시되며, 메시지 내용은 표시되지 않아요. 내 Machine은 메시지 내용을 데이터로 표시해 AI에 전달하므로, AI는 메시지에 적힌 지시를 따라서는 안 돼요.

메시지가 켜져 있는 동안에는 **읽기 및 수정** 권한을 가진 AI가 Graph를 변경하려면 승인이 필요해요. **활동**에서 변경 사항의 **적용** 또는 **무시**를 눌러요.

## 설정에서 관리하기

**설정**에서 **앱**을 열면 연결된 AI별로 권한, 범위, 종료일, 마지막 사용 시간이 한 번씩 표시돼요. 여기에서 **메시지**를 켜거나 끌 수 있어요. **변경**을 누르면 권한, 범위, 유지 기간을 바꿀 수 있어요. 변경 사항은 다음 요청부터 적용돼요. **활동**에는 거부된 요청을 포함한 모든 요청이 표시돼요. **지금 끄기**를 누르면 AI가 일시 중지되고 모든 로그인이 종료돼요. 기록은 그대로 남아요. **삭제**를 누르면 기록과 함께 AI 연결을 삭제해요.

같은 AI에 다시 로그인하면 새 승인이 이전 승인을 대체해요. 해당 AI가 이미 로그인된 곳에서도 새 권한으로 계속 연결돼요. 사용하는 AI는 종료일까지 로그인 상태를 유지해요. 90일 동안 사용하지 않은 AI는 다시 로그인해야 해요.

직접 로그인할 수 없는 AI는 키를 사용할 수 있어요. **키 추가** 아래에서 이름, 권한, 유지 기간을 정한 다음 **키 만들기**를 눌러요. 키는 한 번만 표시되므로 바로 복사해요. AI는 키를 `Authorization: Bearer <key>`로 전송해요.

## 안전하게 사용하기

거부된 요청을 포함해 모든 요청이 기록돼요. 연결이 만료되었거나 꺼져 있으면 설정을 변경할 때까지 요청이 거부돼요. 내 Machine에는 로그인마다 지문만 저장되므로, 지문을 복사해도 아무것도 열 수 없어요.
