## 상태 확인하기

**연결**을 열어 보세요. 각 소스의 상태를 확인할 수 있어요.

- **자동으로 다시 연결 중**: 잠시 문제가 생겼어요. 자동으로 다시 시도해요.
- **첫 동기화를 기다리는 중**: 방금 연결했어요. 몇 분 기다려 주세요.
- **다음에 다시 읽는 시간** 07:00: X와 LinkedIn은 낮에만 읽어요. 따로 할 일은 없어요.
- **도움이 필요해요**: **세부 정보**를 열어 보세요. 무엇이 잘못됐는지, 어떻게 해결하는지 확인할 수 있어요.
- **전화 연결 끊김**: Android 휴대전화가 The Machine에 연결되지 않았어요. 휴대전화에서 OpenClaw 앱을 열어 보세요.

평소보다 오래 새 항목을 가져오지 않는 소스는 연결된 상태로 표시되지 않아요. 새 항목이 들어오면 자동으로 해결돼요.

**연결**에 표시되는 개수에는 도움이 필요한 소스만 포함돼요.

## 일반적인 해결 방법

- "Google에 다시 로그인하세요"(또는 Microsoft): **다시 연결**을 한 번 누르면 Gmail, Calendar처럼 해당 계정에 연결된 모든 소스가 다시 연결돼요.
- "다시 로그인해야 해요": **다시 연결**을 누르고 로그인하세요.
- Microsoft에서 액세스를 아직 설정 중인 경우: 자동으로 다시 시도해요.
- Slack: **다시 연결**을 누르세요. Maton 키로 연결했다면 Maton에서 키와 Slack 연결을 확인하세요.
- Android: 휴대전화에서 OpenClaw 앱을 열고 알림 접근 권한을 허용하세요.

사용 중인 컴퓨터에서 `assistant doctor`을 실행하면 모든 소스를 확인하고 각 문제의 해결 방법을 알려줘요.

여전히 해결되지 않나요? [지원 받기](get-support.md)를 확인하세요.
