## 상태 확인하기

**연결**을 열어 각 연결 항목의 상태를 확인하세요.

- **자동으로 다시 연결 중**: 일시적인 문제예요. 자동으로 다시 연결을 시도해요.
- **첫 동기화를 기다리는 중**: 방금 연결했어요. 몇 분 기다려 주세요.
- **다시 읽는 시간** 07:00: X와 LinkedIn은 낮에만 데이터를 읽어요. 따로 할 일은 없어요.
- **도움이 필요해요**: **세부 정보**를 열어 보세요. 무엇이 잘못됐고 어떻게 해결해야 하는지 확인할 수 있어요.
- **휴대폰 연결 끊김**: Android 휴대전화가 내 Machine에 연결되지 않고 있어요. 휴대전화에서 OpenClaw 앱을 열어 주세요.

평소보다 오래 데이터를 가져오지 않는 연결 항목에는 **새 동기화를 기다리는 중**이라고 표시돼요. 동기화가 완료되면 자동으로 사라져요.

**연결**에 표시되는 숫자는 도움이 필요한 연결 항목만 집계해요.

## 일반적인 해결 방법

- "Google에 다시 로그인하세요"(또는 Microsoft): **다시 연결**을 한 번 누르면 Gmail과 캘린더처럼 해당 계정에 연결된 모든 항목이 복구돼요.
- "다시 로그인해야 해요": **다시 연결**을 누르고 로그인하세요.
- Microsoft에서 액세스 설정을 진행 중이에요: 자동으로 다시 시도해요.
- Slack: **다시 연결**을 누르세요. Maton 키로 연결했다면 Maton에서 키와 Slack 연결을 확인하세요.
- Android: 휴대전화에서 OpenClaw 앱을 열고 알림 접근 권한을 허용하세요.

내 컴퓨터에서 `assistant doctor` 명령을 실행하면 모든 연결 항목을 확인하고 각 문제의 해결 방법을 알려 줘요.

여전히 해결되지 않나요? [지원받기](get-support.md)를 확인하세요.
