## 상태 확인

**연결**을 열어 보세요. 각 연결 항목에 상태가 표시돼요.

- **자동으로 다시 연결 중**: 잠깐 문제가 생겼어요. 자동으로 다시 시도해요.
- **첫 동기화를 기다리는 중**: 방금 연결했어요. 몇 분 정도 기다려 주세요.
- **다시 읽는 시간** 07:00: X와 LinkedIn은 낮에만 데이터를 읽어요. 따로 할 일은 없어요.
- **아직 설정되지 않음**: 아직 여기에서 로그인하지 않았어요. **연결**을 누르세요. 1분 안에 시작돼요.
- **도움이 필요해요**: **세부 정보**를 열어 보세요. 무엇이 잘못됐는지, 어떻게 해야 하는지 확인할 수 있어요.
- **휴대폰 연결 끊김**: Android 휴대폰이 내 Machine에 연결되지 않고 있어요. 휴대폰에서 OpenClaw 앱을 열어 보세요.

평소보다 오래 데이터를 가져오지 못하면 **새 동기화를 기다리는 중**이라고 표시돼요. 동기화가 완료되면 자동으로 표시가 사라져요.

**연결**에 표시되는 숫자에는 도움이 필요한 연결 항목만 포함돼요.

## 자주 쓰는 해결 방법

- “Google에 다시 로그인하세요”(또는 Microsoft): **다시 연결** 한 번으로 Gmail, 캘린더처럼 해당 계정에 연결된 모든 항목을 다시 연결해요.
- “다시 로그인해야 해요”: **다시 연결**을 누르고 로그인하세요.
- “이 컴퓨터에 없는 프로그램이 필요해요”: 해당 컴퓨터의 터미널에서 카드에 표시된 명령어를 실행하세요. 설치할 프로그램을 알려 주거나, 위치가 바뀐 프로그램을 찾아요.
- Microsoft에서 액세스 설정을 진행 중이에요: 자동으로 다시 시도해요.
- Slack: **다시 연결**을 누르세요. Maton 키로 연결했다면 Maton에서 키와 Slack 연결을 확인하세요.
- Android: 휴대폰에서 OpenClaw 앱을 열고 알림 접근 권한을 허용하세요.

내 컴퓨터에서 `assistant doctor`을 실행하면 각 연결 항목을 확인하고 문제별 해결 방법을 알려 줘요.

아직 해결되지 않았나요? [지원받기](get-support.md)를 참고하세요.
