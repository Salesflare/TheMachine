**설정**의 **모델**에서는 **백그라운드 작업**을 처리하는 AI 모델과 ChatGPT 같은 서비스에 로그인한 상태를 확인할 수 있어요.

호스팅된 Machine에서 ChatGPT로 로그인하면 기본 모델은 GPT-6.2 Sol이에요. 같은 가격으로 GPT-6.1 Sol보다 더 빠르게 답변해요.

Claude 로그인은 로그인한 지 약 4주 후에 만료돼요. 만료 3일 전에는 **확인 필요**가 표시되고, 만료된 후에는 알림이 한 번 표시돼요. **다시 로그인**을 누르면 한 단계로 해결돼요.

개인 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅을 모델 학습에 사용할 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 항목이 숨겨져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택할 수 있어요. 로그인한 계정에서 제공하는 모델과 수준만 표시돼요.

사고 수준이 높으면 어려운 질문에 더 잘 답하지만, 속도가 느리고 요금제 사용량도 늘어나요. **사고 수준 울트라**는 가장 어려운 질문에 보조 모델을 사용하며, 사용량이 가장 많아요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래에서 모델이나 사고 수준을 누르세요. 설정을 따르려면 설정 옵션을 다시 선택하세요.

확인 작업, 프로필, 미리 준비한 초안은 각각 별도의 모델을 사용해요.

## 한도

ChatGPT나 Claude 요금제의 5시간 및 주간 한도처럼 사용 한도가 있는 요금제라면, 사용량과 한도가 초기화되는 시점을 표시해요. 확인만 하는 것으로 요금제 사용량이 늘지는 않아요.

## 직접 채팅할 여유 확보

백그라운드 작업은 직접 채팅할 여유를 남겨 둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%를 사용할 때까지 계속돼요. 그 외 작업은 하루에 일주일 사용량의 약 7분의 1을 사용해요. API 키처럼 사용 한도가 없는 로그인은 일시 중지되지 않아요.

백그라운드 작업은 GPT-6 Astra에서 실행되지 않아요. ChatGPT로 로그인했고 OpenClaw 버전이 2026.11.10보다 낮으면, 기본 모델이 GPT-6.2 Sol이어도 백그라운드 작업에는 GPT-6.1 Sol을 사용해요. 이 경우 6.2는 캐시된 지침을 재사용하지 않아 요금제 사용량이 늘어나요. OpenClaw 2026.11.10부터는 백그라운드 작업에서 다시 기본 모델을 사용해요. 채팅에는 선택한 모델이 계속 사용돼요.

확인 작업 전에 소형 모델(ChatGPT에서는 GPT-6 Luna, Claude에서는 Haiku)이 뉴스레터, 프로모션, 앱 알림 중 확인할 필요가 없는 것이 분명한 항목을 제외해요. 이렇게 하면 확인 작업에서 요금제를 덜 사용해요. 제외된 항목도 계속 검색할 수 있어요. 사람이 보낸 메시지, 청구서, 보안 알림, 로그인 코드는 항상 확인해요.

## 한도에 도달하기 전에

ChatGPT 요금제에 초기화 횟수가 남아 있다면, 백그라운드 작업이 느려질 때 할 일에 짧은 안내가 표시돼요. 5시간 한도의 약 65% 또는 주간 한도의 약 90%를 사용하면 표시돼요. 사용량과 남은 초기화 횟수를 알려줘요. **재설정 사용**을 누르고 확인하면 한도가 초기화돼요. ×를 누르면 한도가 초기화될 때까지 안내가 숨겨져요. 초기화 횟수가 남아 있지 않으면 새 안내는 표시되지 않아요.

호스팅된 Machine에서는 내 Machine의 Codex가 같은 ChatGPT 계정으로 로그인하면 내 Machine에서 초기화 횟수를 확인하고 사용할 수 있어요. 그전까지는 할 일과 설정에 **켜면 초기화돼요**가 표시돼요. 이 항목을 누르면 설정 페이지의 Codex 단계가 열려요. 여기서 ChatGPT 로그인처럼 코드를 사용해 로그인할 수 있어요.

## 한도에 도달하면

대시보드 상단에 도달한 한도와 초기화 시점이 표시돼요. 작업은 대기했다가 중단된 지점부터 다시 시작해요. 아무것도 잃지 않아요. ChatGPT 요금제에 초기화 횟수가 남아 있다면 **재설정 사용**을 눌러 한도를 초기화할 수 있어요. Codex에 로그인하지 않은 호스팅 Machine에서는 **켜면 초기화돼요**를 누르면 설정 페이지가 열려요. 그 외의 경우에는 **ChatGPT에서 초기화 내역 보기**를 누르면 ChatGPT 페이지가 열려요.

## 대체 모델 사용

내 Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있다면, 한도에 도달했을 때 대체 모델이 작업을 이어받아 기다릴 필요가 없어요. 대시보드 상단에 “ChatGPT 한도에 도달해 대체 모델을 사용하고 있어요.”라고 표시돼요. 대체 모델이 작동하지 않으면 다시 일시 중지돼요.
