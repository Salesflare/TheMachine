**설정**의 **모델**에서 **백그라운드 작업**을 처리하는 AI 모델과 ChatGPT처럼 어떤 계정으로 로그인했는지 확인할 수 있어요.

호스팅된 Machine에서 ChatGPT 계정으로 로그인하면 기본 모델은 GPT-6.2 Sol이에요. 같은 가격에 GPT-6.1 Sol보다 더 빠르게 답변해요.

호스팅된 Machine에서 Claude 계정으로 로그인하면 약 1년 동안 로그인 상태가 유지돼요. `claude auth login`을 사용하면 로그인한 지 약 4주 후에 만료돼요. 만료 3일 전에는 **확인 필요**가 표시되고 이메일도 한 통 발송돼요. 만료되면 알림이 한 번 표시되고, 아직 발송하지 않았다면 이메일도 발송돼요. **다시 로그인**을 누르면 한 단계로 해결할 수 있어요.

개인 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 안내가 숨겨져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 제공하는 모델과 사고 수준만 표시돼요.

더 깊이 사고하면 어려운 질문에 더 나은 답변을 얻을 수 있지만, 응답이 느리고 요금제 한도를 더 많이 사용해요. **사고 수준 울트라**는 가장 어려운 질문에 보조 모델을 활용하며, 한도를 가장 많이 사용해요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제 한도를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래의 모델이나 사고 수준을 탭하세요. 설정에 지정한 모델과 사고 수준을 따르려면 설정 항목을 다시 선택하세요.

확인 작업, 프로필, 미리 준비한 초안에는 각자 별도의 모델이 사용돼요.

## 사용 한도

ChatGPT나 Claude 요금제의 5시간 한도와 주간 한도처럼 요금제에 사용 한도가 있으면, 사용량과 한도가 초기화되는 시각이 표시돼요. 확인만 하는 것으로는 요금제 한도가 사용되지 않아요.

## 직접 채팅할 공간 확보

백그라운드 작업은 직접 채팅할 공간을 남겨 둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지를 확인하는 작업은 주간 한도의 약 90%를 사용할 때까지 계속되고, 그 외 작업은 하루에 일주일 한도의 약 7분의 1을 사용해요. API 키처럼 사용 한도가 없는 계정으로 로그인하면 일시 중지되지 않아요.

백그라운드 작업에는 GPT-6 Astra를 사용하지 않아요. ChatGPT 계정으로 로그인했고 OpenClaw 버전이 2026.11.10보다 낮으면, 기본 모델이 GPT-6.2 Sol이어도 백그라운드 작업에는 GPT-6.1 Sol을 사용해요. 이 환경에서는 6.2가 캐시된 지침을 재사용하지 않아 요금제 한도를 더 많이 사용하기 때문이에요. OpenClaw 2026.11.10부터는 백그라운드 작업에도 기본 모델을 다시 사용해요. 채팅에는 선택한 모델이 계속 사용돼요.

확인 작업을 시작하기 전에 소형 모델이 뉴스레터, 광고, 앱 알림처럼 확인할 필요가 없는 내용을 걸러내므로 요금제 한도를 덜 사용해요. ChatGPT에서는 GPT-6 Luna를, Claude에서는 Haiku를 사용해요. 걸러낸 내용도 검색할 수 있어요. 사람이 보낸 메시지, 청구서, 보안 알림, 로그인 코드는 항상 확인해요.

## 한도에 도달하기 전

ChatGPT 요금제에 남은 초기화 횟수가 있으면 백그라운드 작업이 느려질 때 할 일에 짧은 안내가 표시돼요. 5시간 한도의 약 65% 또는 주간 한도의 약 90%를 사용했을 때예요. 사용량과 남은 초기화 횟수가 표시돼요. **재설정 사용**을 누르면 확인 후 한도가 초기화돼요. ×를 누르면 해당 한도가 초기화될 때까지 안내가 숨겨져요. 남은 초기화 횟수가 없으면 새 안내가 표시되지 않아요.

호스팅된 Machine에서는 내 Machine의 Codex가 같은 ChatGPT 계정으로 로그인한 뒤부터 초기화 횟수를 확인하고 사용할 수 있어요. 그전까지는 할 일과 설정에 **켜면 초기화돼요**가 표시돼요. 이 버튼을 누르면 설정 페이지의 Codex 단계가 열려요. ChatGPT에 로그인할 때처럼 코드를 사용해 로그인하면 돼요.

## 한도에 도달했을 때

대시보드 상단에 도달한 한도와 초기화 시각이 표시돼요. 작업은 대기한 뒤 중단된 곳부터 다시 시작해요. 아무것도 사라지지 않아요. ChatGPT 요금제에 초기화 횟수가 남아 있으면 **재설정 사용**을 눌러 한도를 초기화할 수 있어요. Codex에 로그인하지 않은 호스팅된 Machine에서는 **켜면 초기화돼요**를 누르면 설정 페이지가 열려요. 그 외의 경우에는 **ChatGPT에서 초기화 내역 보기**를 누르면 ChatGPT 페이지가 열려요.

## 대체 모델 사용

Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있으면 한도에 도달했을 때 대신 사용되므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT 한도에 도달해 대체 모델을 사용 중이에요."라고 표시돼요. 대체 모델이 작동을 멈추면 다시 일시 중지돼요.
