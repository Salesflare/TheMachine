**설정**, **모델**에서 **백그라운드 작업**에 어떤 AI 모델을 사용하는지, ChatGPT 같은 서비스에 어떻게 로그인했는지 확인할 수 있어요.

ChatGPT 계정으로 로그인한 호스팅 Machine에서는 기본 모델이 GPT-6.2 Sol이에요. 같은 가격으로 GPT-6.1 Sol보다 더 빠르게 답변해요.

개인용 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 안내가 사라져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 제공하는 모델과 수준만 표시돼요.

사고 수준을 높이면 어려운 질문에 더 나은 답변을 얻을 수 있지만, 속도가 느리고 요금제를 더 많이 사용해요. **울트라 사고**는 가장 어려운 질문에 도우미를 함께 사용해 답변하며, 요금제를 가장 많이 사용해요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래에서 모델이나 사고 수준을 누르세요. 설정을 따르려면 **설정**을 다시 선택하세요.

확인 작업, 프로필, 미리 준비한 초안은 각각 별도의 모델을 사용해요.

## 사용 한도

ChatGPT나 Claude 요금제의 5시간 및 주간 한도처럼 요금제에 사용 한도가 있으면, 사용량과 한도가 재설정되는 시각이 표시돼요. 확인만 해도 요금제 사용량은 줄지 않아요.

## 내 채팅을 위한 여유 공간

백그라운드 작업은 내 채팅을 위한 여유 공간을 남겨 둬요. 5시간 한도의 약 65%를 사용하면 백그라운드 작업이 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속되고, 다른 작업은 하루에 주간 사용량의 약 7분의 1을 사용해요. API 키처럼 사용 한도가 없는 계정은 일시 중지되지 않아요.

백그라운드 작업은 GPT-6 Astra에서 실행되지 않아요. ChatGPT 계정으로 로그인한 경우에는 기본 모델이 GPT-6.2 Sol이어도 당분간 GPT-6.1 Sol을 사용해요. 해당 계정에서는 GPT-6.2가 캐시된 지침을 아직 재사용하지 않아 요금제를 더 많이 사용하기 때문이에요. 채팅에는 선택한 모델이 계속 사용돼요.

## 한도에 도달한 경우

대시보드 상단에 도달한 한도와 재설정 시각이 표시돼요. 작업은 대기하다가 한도가 재설정되면 중단된 부분부터 다시 시작해요. 아무것도 사라지지 않아요. ChatGPT 요금제에 한도 재설정 기능이 있으면 **재설정 사용**을 눌러 한도를 초기화하세요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 눌러 ChatGPT 페이지를 여세요.

## 대체 모델 사용

내 Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있으면, 한도에 도달했을 때 대체 모델이 이어받아 작업이 대기하지 않아요. 대시보드 상단에 “ChatGPT 한도에 도달했어요. 대체 모델을 사용하고 있어요.”라고 표시돼요. 대체 모델도 작동하지 않으면 작업이 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅 Machine에서는 설정 페이지의 내 AI에서 변경하세요. 내 컴퓨터에서 사용 중이라면 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 안내](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
