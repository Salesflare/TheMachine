**설정**에서 **모델**을 누르면 **백그라운드 작업**에 어떤 AI 모델을 사용하는지, ChatGPT처럼 어떤 방식으로 로그인했는지 확인할 수 있어요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택해요. 로그인한 계정에서 제공하는 모델과 수준만 표시돼요.

더 깊이 사고하면 어려운 질문에 더 잘 답하지만, 속도가 느리고 요금제 한도를 더 많이 사용해요. **울트라 사고**는 가장 어려운 질문에 도우미를 투입하며, 한도를 가장 많이 사용해요. 새로 설정한 Machine은 **사고 수준 낮음**으로 시작해요. 요금제 한도를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에서만 바꾸려면 메시지 입력란 아래의 모델이나 사고 수준을 눌러요. 설정을 따르려면 다시 설정 옵션을 선택해요.

점검, 프로필, 미리 준비된 초안은 각각 자체 모델을 사용해요.

## 한도

ChatGPT나 Claude 요금제의 5시간 및 주간 한도처럼 사용량 제한이 있는 요금제라면, 사용량과 한도별 초기화 시간을 확인할 수 있어요. 확인만으로는 요금제 한도를 사용하지 않아요.

## 직접 채팅할 여유 확보

백그라운드 작업은 직접 채팅할 여유를 남겨둬요. 5시간 한도의 약 65%를 사용하면 작업을 일시 중지해요. 새 메시지 확인은 주간 한도의 약 90%를 사용할 때까지 계속돼요. 다른 작업은 하루에 주간 한도의 약 7분의 1을 사용해요. API 키처럼 사용 한도가 없는 로그인은 일시 중지되지 않아요.

백그라운드 작업에는 GPT-6 Astra를 사용하지 않아요. 대신 GPT-6.1 Sol을 사용해요.

## 한도에 도달한 경우

대시보드 상단에 도달한 한도와 초기화 시간이 표시돼요. 작업은 대기한 뒤 중단된 지점부터 다시 시작돼요. 아무것도 사라지지 않아요. ChatGPT 요금제에 초기화가 포함돼 있다면 **재설정 사용**을 눌러 한도를 초기화해요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 눌러 ChatGPT 페이지를 열어요.

## 대체 모델 사용

Machine에 다른 요금제나 제공업체의 대체 모델이 설정돼 있으면 한도에 도달할 때 대체 모델로 전환되므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT limit reached, using your fallback."이라고 표시돼요. 대체 모델이 작동을 멈추면 다시 작업이 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅된 Machine에서는 설정 페이지의 Your AI에서 변경해요. 개인 컴퓨터에서는 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 가이드](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고해요.
