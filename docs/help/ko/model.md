**설정**에서 **모델**을 선택하면 **백그라운드 작업**에 어떤 AI 모델을 사용하는지, ChatGPT처럼 어떤 방식으로 로그인했는지 확인할 수 있어요.

ChatGPT로 로그인한 호스팅 Machine에서는 기본 모델로 GPT-6.2 Sol을 사용해요. 같은 가격으로 GPT-6.1 Sol보다 더 빠르게 답변해요.

개인 ChatGPT 또는 Claude 플랜은 기본적으로 채팅 내용을 학습에 사용할 수 있어요. **내 데이터로 학습하기 끄기**를 선택하면 제공업체의 해당 설정이 열리고, **완료**를 선택하면 이 안내가 숨겨져요.

## 채팅의 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 제공하는 모델과 수준만 표시돼요.

더 많이 사고하면 어려운 질문에 더 나은 답변을 얻을 수 있지만, 속도가 느려지고 플랜 한도를 더 많이 사용해요. **울트라 사고**는 가장 어려운 질문을 처리할 때 도우미를 활용하며, 한도를 가장 많이 사용해요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 플랜을 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래에서 모델이나 사고 수준을 탭하세요. 다시 설정을 따르려면 **설정**을 선택하세요.

점검, 프로필, 미리 준비된 초안은 각자 별도의 모델을 사용해요.

## 사용 한도

ChatGPT 또는 Claude 플랜의 5시간 및 주간 사용 한도처럼 플랜에 한도가 있으면, 사용량과 한도 초기화 시점을 확인할 수 있어요. 확인만 하는 것으로는 플랜 한도를 사용하지 않아요.

## 내 채팅을 위한 여유 공간

백그라운드 작업은 내 채팅을 위한 여유 공간을 남겨둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속되고, 다른 작업은 하루에 주간 한도의 약 7분의 1을 사용해요. API 키처럼 한도가 없는 로그인은 일시 중지되지 않아요.

백그라운드 작업은 GPT-6 Astra에서 실행되지 않아요. 대신 GPT-6.2 Sol을 사용하고, 6.2가 설정되어 있지 않으면 GPT-6.1 Sol을 사용해요.

## 한도에 도달하면

대시보드 상단에 도달한 한도와 초기화 시점이 표시돼요. 작업은 대기한 뒤 중단된 곳부터 다시 시작해요. 아무것도 사라지지 않아요. ChatGPT 플랜에 초기화가 있다면 **재설정 사용**을 선택해 한도를 초기화할 수 있어요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 선택해 ChatGPT 페이지를 여세요.

## 대체 모델이 있는 경우

Machine에 다른 플랜이나 제공업체의 대체 모델이 설정되어 있으면 한도에 도달했을 때 대신 사용되므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT limit reached, using your fallback."이라고 표시돼요. 대체 모델이 작동하지 않으면 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅 Machine에서는 설정 페이지의 Your AI에서 변경할 수 있어요. 개인 컴퓨터를 사용하는 경우 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 가이드](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
