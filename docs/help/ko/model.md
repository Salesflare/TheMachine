**설정**의 **모델**에서 **백그라운드 작업**을 처리하는 AI 모델과 ChatGPT 같은 로그인 방식을 확인할 수 있어요.

ChatGPT로 로그인한 호스팅 Machine의 기본 모델은 GPT-6.2 Sol이에요. 같은 가격에 GPT-6.1 Sol보다 더 빠르게 답변해요.

개인용 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅 내용이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 안내가 숨겨져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 사용할 수 있는 모델과 수준만 표시돼요.

더 많이 사고하면 어려운 질문에 더 나은 답변을 받을 수 있지만, 속도가 느리고 요금제 사용량도 늘어나요. **울트라 사고**는 가장 어려운 질문에 보조 모델을 활용하며, 사용량도 가장 많아요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제를 훨씬 적게 사용하면서 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력창 아래에서 모델이나 사고 수준을 누르세요. **설정**을 다시 선택하면 설정을 따르게 돼요.

확인 작업, 프로필, 미리 준비한 초안에는 각자 별도의 모델이 적용돼요.

## 사용량 한도

ChatGPT나 Claude 요금제의 5시간 및 주간 한도처럼 요금제에 사용량 한도가 있으면, 사용량과 한도가 초기화되는 시점이 표시돼요. 확인만 해도 요금제 사용량은 줄지 않아요.

## 내 채팅을 위한 여유 공간

백그라운드 작업은 내 채팅을 위한 여유 공간을 남겨 둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속되고, 그 밖의 작업은 하루에 주간 한도의 약 7분의 1을 사용해요. API 키처럼 사용량 제한이 없는 로그인은 일시 중지되지 않아요.

GPT-6 Astra에서는 백그라운드 작업이 실행되지 않아요. ChatGPT로 로그인하면 지금은 기본 모델이 GPT-6.2 Sol이어도 GPT-6.1 Sol을 사용해요. 해당 로그인에서는 아직 6.2가 캐시된 지침을 재사용하지 않아 요금제 사용량이 더 많아요. 채팅에는 선택한 모델이 계속 적용돼요.

## 한도에 도달하기 전

ChatGPT 요금제에 초기화 횟수가 남아 있으면, 백그라운드 작업이 느려질 때 할 일에 짧은 안내가 표시돼요. 5시간 한도의 약 65% 또는 주간 한도의 약 90%를 사용했을 때예요. 사용량과 남은 초기화 횟수가 표시돼요. **재설정 사용**을 누르고 확인하면 한도가 초기화돼요. ×를 누르면 해당 한도가 초기화될 때까지 안내가 숨겨져요. 초기화 횟수가 남아 있지 않으면 새 안내가 표시되지 않아요.

## 한도에 도달했을 때

대시보드 상단에 도달한 한도와 초기화 시점이 표시돼요. 작업은 대기하다가 중단된 지점부터 다시 진행돼요. 작업은 사라지지 않아요. ChatGPT 요금제에 초기화 횟수가 남아 있으면 **재설정 사용**을 눌러 한도를 초기화하세요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 눌러 ChatGPT 페이지를 여세요.

## 대체 모델 사용

Machine에 다른 요금제나 제공업체의 대체 모델이 있으면 한도에 도달했을 때 대신 사용하므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT 한도에 도달해 대체 모델을 사용 중이에요."라고 표시돼요. 대체 모델이 작동을 멈추면 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅 Machine에서는 설정 페이지의 내 AI에서 변경하세요. 내 컴퓨터에서 사용하는 경우 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 안내](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
