**설정**의 **모델**에서는 **백그라운드 작업**을 처리하는 AI 모델과 ChatGPT 같은 로그인 방식을 확인할 수 있어요.

개인 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅 내용이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 항목이 숨겨져요.

## 채팅의 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인 방식에서 제공하는 모델과 수준만 표시돼요.

사고 수준을 높이면 어려운 질문에 더 나은 답을 얻을 수 있지만, 응답이 느려지고 요금제를 더 많이 사용해요. **울트라 사고**는 가장 어려운 질문에 여러 도우미를 활용하며, 요금제를 가장 많이 사용해요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력창 아래에서 모델이나 사고 수준을 누르세요. **설정**을 다시 선택하면 설정에서 지정한 값을 따라요.

확인 작업, 프로필, 미리 준비한 초안은 각자 다른 모델을 사용해요.

## 한도

ChatGPT 또는 Claude 요금제의 5시간 및 주간 한도처럼 사용량 한도가 있는 요금제라면, 사용량과 한도가 초기화되는 시점을 확인할 수 있어요. 확인만 하는 것은 요금제를 사용하지 않아요.

## 직접 채팅할 여유 공간

백그라운드 작업은 직접 채팅할 여유를 남겨 둬요. 5시간 한도의 약 65%에 도달하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속돼요. 그 외 작업은 하루에 주간 한도의 약 7분의 1을 사용해요. API 키처럼 한도가 없는 로그인 방식은 일시 중지되지 않아요.

백그라운드 작업은 GPT-6 Astra에서 실행되지 않아요. 대신 GPT-6.2 Sol을 사용하고, 6.2가 설정되지 않은 경우에는 GPT-6.1 Sol을 사용해요.

## 한도에 도달한 경우

대시보드 상단에 어떤 한도에 도달했는지와 한도가 언제 초기화되는지 표시돼요. 작업은 대기했다가 중단된 지점부터 다시 시작돼요. 아무것도 사라지지 않아요. ChatGPT 요금제에서 초기화를 지원하면 **재설정 사용**을 눌러 한도를 초기화할 수 있어요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 눌러 ChatGPT 페이지를 열 수 있어요.

## 대체 모델이 있는 경우

내 Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있으면 한도에 도달했을 때 대신 사용되므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT 한도에 도달해 대체 모델을 사용하고 있어요."라고 표시돼요. 대체 모델도 작동하지 않으면 작업이 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅된 Machine에서는 설정 페이지의 **내 AI**에서 변경하세요. 개인 컴퓨터에서는 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 안내](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
