**설정**의 **모델**에서 **백그라운드 작업**에 사용할 AI 모델과 ChatGPT 같은 서비스의 로그인 방식을 확인할 수 있어요.

ChatGPT 계정으로 로그인한 호스팅 Machine에서는 기본 모델로 GPT-6.2 Sol을 사용해요. 같은 가격에 GPT-6.1 Sol보다 더 빠르게 답변해요.

개인 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅 내용이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 제공업체의 해당 설정이 열리고, **완료**를 누르면 이 안내가 숨겨져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 제공하는 모델과 수준만 표시돼요.

사고 수준이 높을수록 어려운 질문에 더 나은 답변을 제공하지만, 속도가 느리고 요금제 한도를 더 많이 사용해요. **사고 수준 울트라**는 가장 어려운 질문에 보조 모델을 사용하며, 한도를 가장 많이 사용해요. 새 Machine은 **사고 수준 낮음**으로 시작해요. 요금제 한도를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 설정을 변경하면 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래의 모델이나 사고 수준을 누르세요. 설정을 따르려면 다시 설정 항목을 선택하세요.

확인 작업, 프로필, 미리 준비한 초안에는 각각 별도의 모델이 사용돼요.

## 한도

ChatGPT 또는 Claude 요금제의 5시간 및 주간 한도처럼 사용 한도가 있는 요금제라면, 사용량과 한도가 초기화되는 시간이 표시돼요. 이 정보를 확인하는 데는 요금제 한도가 사용되지 않아요.

## 내 채팅을 위한 여유 공간

백그라운드 작업은 직접 하는 채팅을 위한 여유 공간을 남겨둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속돼요. 그 외 작업은 일주일 한도의 약 7분의 1을 하루에 사용해요. API 키처럼 사용 한도가 없는 계정은 일시 중지되지 않아요.

백그라운드 작업에는 GPT-6 Astra를 사용하지 않아요. ChatGPT 계정으로 로그인하면 현재 GPT-6.1 Sol을 사용해요. 기본 모델이 GPT-6.2 Sol인 경우에도 마찬가지예요. 해당 계정에서는 아직 6.2가 캐시된 지침을 재사용하지 않아 요금제 한도를 더 많이 사용해요. 채팅에는 선택한 모델이 계속 사용돼요.

확인 작업을 시작하기 전에 소형 모델이 불필요한 뉴스레터, 프로모션, 앱 알림을 걸러내 요금제 한도를 아껴줘요. ChatGPT에서는 GPT-6 Luna를, Claude에서는 Haiku를 사용해요. 걸러진 항목도 검색할 수 있어요. 사람이 작성한 메시지, 청구서, 보안 알림, 로그인 코드는 항상 확인해요.

## 한도에 도달하기 전에

ChatGPT 요금제에 재설정 횟수가 남아 있다면, 백그라운드 작업이 느려지기 시작할 때 할 일에 안내가 표시돼요. 5시간 한도의 약 65% 또는 주간 한도의 약 90%를 사용한 시점이에요. 안내에는 사용량과 남은 재설정 횟수가 표시돼요. **재설정 사용**을 누르고 확인하면 한도가 초기화돼요. ×를 누르면 해당 한도가 초기화될 때까지 안내가 숨겨져요. 재설정 횟수가 없으면 새 안내가 표시되지 않아요.

호스팅 Machine에서는 내 Machine의 Codex가 같은 ChatGPT 계정에 로그인한 뒤부터 재설정 횟수를 확인하고 사용할 수 있어요. 그전에는 할 일과 설정에 **켜면 초기화돼요**가 표시돼요. 이 항목을 누르면 설정 페이지의 Codex 단계가 열려요. ChatGPT에 로그인할 때처럼 코드로 로그인하면 돼요.

## 한도에 도달했을 때

대시보드 상단에 도달한 한도와 초기화 시간이 표시돼요. 작업은 대기했다가 중단된 지점부터 다시 시작해요. 아무것도 사라지지 않아요. ChatGPT 요금제에 재설정 횟수가 남아 있다면 **재설정 사용**을 눌러 한도를 초기화할 수 있어요. Codex에 로그인하지 않은 호스팅 Machine에서는 **켜면 초기화돼요**를 누르면 설정 페이지가 열려요. 그 외에는 **ChatGPT에서 초기화 내역 보기**를 누르면 ChatGPT 페이지가 열려요.

## 대체 모델 사용

내 Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있으면 한도에 도달했을 때 대신 사용되므로 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT 한도에 도달해 대체 모델을 사용하고 있어요."라고 표시돼요. 대체 모델이 작동을 멈추면 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅 Machine에서는 설정 페이지의 Your AI에서 변경하세요. 개인 컴퓨터에서 사용 중이라면 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 안내](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
