**설정**에서 **모델**을 누르면 **백그라운드 작업**에 어떤 AI 모델을 사용하는지와 ChatGPT 같은 서비스에 어떻게 로그인했는지 확인할 수 있어요.

개인 ChatGPT 또는 Claude 요금제에서는 기본적으로 채팅 내용이 학습에 사용될 수 있어요. **내 데이터로 학습하기 끄기**를 누르면 해당 서비스의 설정이 열리고, **완료**를 누르면 이 안내가 숨겨져요.

## 채팅 모델과 사고 수준

**채팅**에서 할 일 채팅과 도움말에 사용할 모델과 사고 수준을 선택하세요. 로그인한 계정에서 사용할 수 있는 모델과 수준만 표시돼요.

더 깊이 사고하면 어려운 질문에 더 나은 답변을 받을 수 있지만, 속도가 느리고 요금제를 더 많이 사용해요. **울트라 사고**는 가장 어려운 질문에 도우미를 추가로 활용하며, 요금제를 가장 많이 사용해요. 새 The Machine은 **사고 수준 낮음**으로 시작해요. 요금제를 훨씬 적게 사용하면서도 좋은 결과를 얻을 수 있어요. 변경 사항은 다음 메시지부터 적용돼요.

채팅 하나에만 적용하려면 메시지 입력란 아래에서 모델이나 사고 수준을 누르세요. 설정을 따르려면 **설정** 옵션을 다시 선택하세요.

확인 작업, 프로필, 미리 준비된 초안은 각각 별도의 모델을 사용해요.

## 한도

ChatGPT 또는 Claude 요금제의 5시간 한도와 주간 한도처럼 요금제에 사용 한도가 있다면, 얼마나 사용했는지와 한도가 언제 초기화되는지 표시돼요. 확인만 하는 것은 요금제를 사용하지 않아요.

## 직접 채팅할 여유

백그라운드 작업은 직접 채팅할 여유를 남겨둬요. 5시간 한도의 약 65%를 사용하면 일시 중지돼요. 새 메시지 확인은 주간 한도의 약 90%까지 계속되고, 다른 작업은 하루에 일주일 사용량의 약 7분의 1을 사용해요. API 키처럼 사용 한도가 없는 로그인은 일시 중지되지 않아요.

백그라운드 작업은 GPT-6 Astra에서 실행되지 않아요. 대신 GPT-6.1 Sol을 사용해요.

## 한도에 도달하면

대시보드 상단에 도달한 한도와 초기화 시간이 표시돼요. 작업은 대기한 뒤 중단된 부분부터 다시 시작해요. 아무것도 사라지지 않아요. ChatGPT 요금제에서 초기화를 제공한다면 **재설정 사용**을 눌러 한도를 초기화할 수 있어요. 그렇지 않으면 **ChatGPT에서 초기화 내역 보기**를 눌러 ChatGPT 페이지를 여세요.

## 대체 모델 사용

The Machine에 다른 요금제나 제공업체의 대체 모델이 설정되어 있다면, 한도에 도달했을 때 대체 모델이 이어받아 작업이 대기하지 않아요. 대시보드 상단에 "ChatGPT 한도에 도달해 대체 모델을 사용하고 있어요."라고 표시돼요. 대체 모델이 작동을 멈추면 다시 일시 중지돼요.

## 기본 모델 변경

기본 모델은 The Machine의 나머지 기능에서 사용하는 모델이에요. 호스팅된 The Machine에서는 설정 페이지의 Your AI에서 변경하세요. 본인 컴퓨터에서 사용하는 경우 [ChatGPT](chatgpt.md), [Mistral](mistral.md), [모델 안내서](https://github.com/Salesflare/TheMachine/blob/main/docs/models.md)를 참고하세요.
