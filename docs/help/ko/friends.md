## 친구

**Fleet** 탭의 친구 메뉴에서 상대방의 정확한 사용자 이름을 입력해 추가하세요. 친구는 아는 사람을 누가 알고 있는지 물어보고, 회의 맥락과 소개를 받을 수 있으며, 바쁜 시간대도 확인할 수 있어요. 무엇 때문에 바쁜지는 표시되지 않아요. 캘린더에 표시되지 않은 날은 알 수 없음으로 표시되고, 가능으로 표시되지 않아요. 친구는 언제든 삭제하거나 차단할 수 있어요.

## 아는 사람 찾기

**Fleet**의 **Network**에서 다음을 설정할 수 있어요.

- "내 연락처 중 누가 Machine을 사용하는지 확인"을 선택하면 아는 사람을 추천해요.
- "내 이메일 주소를 아는 사람이 나를 찾을 수 있도록 허용"을 선택하면 다른 사람이 나를 찾을 수 있어요.

두 설정은 기본적으로 켜져 있고, 보안 수준이 신중으로 설정되어 있으면 꺼져 있어요. 언제든 하나씩 끌 수 있고, 설정은 그대로 유지돼요. 로그인 이메일 주소로는 항상 나를 찾을 수 있고, 연결된 주소는 각각 **검색 가능 기준**에서 따로 설정할 수 있어요. info@처럼 여러 사람이 함께 사용하는 주소는 직접 켜기 전까지 꺼져 있어요.

이 기능을 켜면 아는 사람이 바로 할 일로 표시되고, 나중에 Network에 참여하는 사람도 할 일로 표시돼요. 각 사람에 대해 **친구**, **가족**(직장 동료는 **연결**), **나중에**, **절대 제안하지 않기**를 ⋯ 메뉴에서 선택할 수 있어요. 친구가 되면 더 이상 추천되지 않아요. **Network 나가기**를 선택하면 Network에서 나가요.

찾은 사람은 People 목록에 **Machine 있음**으로 표시돼요. 메시지를 주고받은 주소와 **수정**을 눌러 사람 정보에 추가한 주소를 확인해요. 누군가 다른 주소로 가입했다면 그 주소를 추가하세요. 찾은 사람의 페이지에서 **친구로 추가**를 누르면 연결과 같은 요청을 보내요. **가족으로 추가**는 ⋯ 메뉴에 있어요.

Machine이 없는 사람에게는 **The Machine에 초대**가 표시돼요. 이걸 누르면 평소 할 일에서와 같이 **이 이메일을 보낼까요?**에 초대 이메일이 열려요. 원하면 내용을 수정할 수 있어요. **지금 보내기**를 누르기 전에는 이메일이 전송되지 않아요. 창을 닫으면 초대가 할 일로 남아요. 이메일을 보낼 수 있는 메일함이 없다면 **복사** 또는 **이메일에서 열기**를 선택하세요.

전화번호도 포함돼요. 메시지를 보내거나 만난 사람과 나눈 WhatsApp 채팅의 전화번호와 **수정**을 눌러 추가한 번호를 확인해요. 연결된 WhatsApp 번호와 내 정보에 등록한 번호로도 나를 찾을 수 있으며, 각 번호는 **검색 가능 기준**에서 따로 설정할 수 있어요. 상대방도 나를 찾았거나 서로 친구인 경우에만 전화번호로 찾을 수 있어요. 따라서 누군가 번호를 하나씩 입력해 Machine 사용 여부를 확인할 수는 없어요.

## 다른 Machine과 일정 예약

Machine을 사용하는 사람이 "다음 주에 만나자"고 쓰면 내 Machine이 상대방의 Machine에 가능한 시간을 물어보고, 근무 시간 안에서 서로에게 맞는 시간을 찾아요. 각자 "Alex Example 만나기" 같은 할 일을 하나씩 받으며, 시간은 할 일 아래에 표시돼요. **예약하기**, **다른 시간** 또는 **필요 없음**을 누르세요. 둘 다 예약하기를 눌러야 초대가 전송돼요.

종단 간 암호화된 가능/바쁨 정보만 전송돼요. 최대 14일간의 정보가 15분 단위로 반올림되어 공유돼요. 비공개 일정도 바쁨으로 처리돼요. 서로 이메일을 주고받은 경우에만 Machine이 요청할 수 있어요. **다른 Machine이 내 Machine에 요청할 수 있는 내용**에서 **일정 예약용 가능/바쁨** 또는 **꺼짐**을 설정하고, 회의 시간, 여유 시간, 선호 시간을 정하세요. 요청은 캘린더 아래의 활동에 표시돼요.

캘린더에서 가능으로 표시된 경우에만 시간이 가능으로 처리돼요. 캘린더를 연결하지 않았거나, 하루 동안 캘린더를 읽을 수 없었거나, 30일 이후인 경우에는 내 Machine이 시간을 제안하지 않아요. 종일 일정은 바쁨으로 표시된 경우에만 바쁜 시간으로 처리되고, 가능으로 표시된 일정은 바쁜 시간으로 처리되지 않아요. 할 일에서 추가하는 종일 일정은 가능으로 표시돼요. 해당 날짜에 자리를 비우거나 다른 일정이 있으면 추가하기 전에 "바쁨"으로 표시돼요.

상대방이 Machine을 사용하지 않거나 응답하지 않으면 이메일 초안에 링크가 포함돼요. 상대방은 링크에서 내가 가능한 시간 중 하나를 선택할 수 있어요. 선택한 시간은 **예약하기**가 있는 할 일로 표시되며, 내가 누르기 전에는 예약되지 않아요.

링크에는 같은 기준에 따라 가능한 시간만 표시되고, 그 외의 내 정보는 표시되지 않아요. 회의가 예약되거나 14일이 지나면 링크가 만료돼요. 이메일에는 "시간 선택"으로 표시돼요. 페이지 아래에는 이름과 함께 "Alex의 Machine에서 가능한 시간을 찾았어요. 내 Machine도 시작해 보세요."라고 표시돼요. 이 문구를 끄려면 **예약 링크의 바닥글**을 사용하세요. 각 링크와 선택 내역은 활동에 표시돼요.

## 직접 운영하는 컴퓨터에서 Machine 사용하기

직접 운영하는 Machine에서 Network에 참여하려면 다음 단계를 따르세요.

1. Machine 대시보드에서 **설정**을 열고 **Network에 참여**를 누르세요.
2. 열린 페이지에서 로그인하거나 계정을 만든 다음 확인하세요. Machine이 자동으로 연결되므로 다시 시작할 필요가 없어요.

코드를 사용하는 방법도 계속 이용할 수 있어요. app.themachine.computer의 계정 페이지에서 **직접 호스팅하는 Machine 연결**을 누른 다음, 컴퓨터에서 `assistant fleet-pair`을 코드와 함께 실행하고 다시 시작하세요. 코드는 한 번만 사용할 수 있고, 15분 후 만료돼요.

계정당 최대 5대의 Machine을 연결할 수 있어요. 각 Machine은 해당 페이지에서 연결을 해제할 수 있어요.
