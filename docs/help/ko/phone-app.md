휴대폰이나 컴퓨터에 The Machine을 앱으로 설치하면 [근무 시간](work-hours.md)에 할 일, 결과, 미리 알림마다 알림을 받을 수 있어요. [알림](notifications.md)에서 알림을 받을 항목을 선택하세요.

할 일 목록 상단의 **The Machine 더 알차게 사용하기** 할 일에는 각 항목에 해당하는 행이 있어요: **휴대폰 앱 다운로드**([모바일 앱](mobile-app.md) 참고), **데스크톱 앱 다운로드**([데스크톱 앱](desktop-app.md) 참고), **알림 켜기**, **이 컴퓨터에 설치**. 해당 기기에 아직 없는 항목만 표시돼요. 행의 ×를 누르면 닫혀요. 같은 설정은 **설정**의 **일반** › **이 기기**에서도 찾을 수 있어요.

**이 컴퓨터에 설치**는 Chromebook처럼 데스크톱 앱이 설치되지 않은 컴퓨터에만 표시돼요.

휴대폰 앱에서 알림이 꺼져 있으면 **필요할 때 알림 받기.**가 표시돼요. **켜기**를 누르면 휴대폰에서 알림을 허용할지 묻거나 휴대폰 설정이 열려요. **×**를 누르면 7일 동안 숨겨져요.

## 컴퓨터에서 (Chrome 또는 Edge)

1. 대시보드를 열고 설정의 **앱 설치** › **일반** › **이 기기**에서 **설치**를 클릭하세요. Chromebook에서는 해당 할 일의 행에 있는 **설치**를 클릭하면 돼요.
2. The Machine이 별도 창에서 열려요. 작업 표시줄이나 Dock에 고정하세요.
3. 해당 행에서 **켜기**를 클릭하고 알림을 허용하세요. 테스트 알림이 바로 표시돼요.

## Mac에서 (Safari)

1. Safari 메뉴 막대에서 File을 선택한 다음 Add to Dock을 선택하세요.
2. Dock에서 The Machine을 열고 **켜기**를 클릭하세요.

## Firefox에서

Firefox에서는 앱으로 설치할 수 없어요. 탭에서 알림을 사용할 수 있어요. 해당 행의 **켜기**를 클릭하거나 설정에서 **알림** 옆의 종 모양 아이콘을 클릭하세요.

## iPhone 또는 iPad에서

1. Safari에서 대시보드를 여세요. iOS 16.4 이상이 필요해요.
2. 공유를 탭한 다음 홈 화면에 추가를 탭하세요.
3. 홈 화면에서 The Machine을 열고 **켜기**를 탭하세요.

알림은 홈 화면 앱에서만 사용할 수 있고 Safari 탭에서는 사용할 수 없어요.

## Android에서

1. Chrome에서 대시보드를 열고 메뉴를 연 다음 앱 설치를 탭하세요.
2. 홈 화면에서 앱을 열고 **켜기**를 탭하세요.

## 확인하거나 변경하기

**설정** › **일반** › **이 기기**에서 **알림** 옆의 종 모양 아이콘을 누르면 해당 기기에서만 알림을 켜거나 끌 수 있어요. **테스트 보내기**를 누르면 해당 기기로 테스트 알림을 보내요.

알림이 차단됐나요? 컴퓨터에서는 주소 왼쪽의 아이콘을 클릭하고 알림을 허용하세요. iPhone에서는 설정 앱을 열고 알림 › The Machine으로 이동하세요.

## 빠르게 열기

앱을 열면 내 최근 할 일이 바로 표시되고, 이어서 최신 내용으로 업데이트돼요. 이 사본은 암호화되어 기기에 최대 7일 동안 저장되고, 로그아웃하면 삭제돼요.

## 오프라인 또는 와이파이 연결이 불안정할 때

비행기나 기차에서도 대시보드를 계속 사용할 수 있어요. 화면 상단의 표시줄에 **오프라인**과 현재 화면이 마지막으로 업데이트된 시간이 표시돼요. 할 일, 할 일의 채팅, 캘린더, Graph 목록은 기기에 저장된 내용으로 열려요.

- **미루기**, **필요 없음**, **완료로 표시**, **다시 열기**, The Machine에 보내는 채팅 메시지는 **취소**할 수 있으며 기기에 대기해요. 다시 온라인 상태가 되면 자동으로 전송돼요.
- 다른 사람에게 보내는 메시지는 대기하지 않아요. 다시 온라인 상태가 되면 다시 보내세요.
- 채팅에 입력한 내용은 전송할 때까지 기기에 저장돼요. 페이지를 새로고침해도 유지돼요.
- 앱이 자동으로 계속 다시 시도해요. **지금 시도**를 누르면 바로 시도해요.
- 내 Machine에는 Tailscale을 통해 연결해요. 휴대폰에서는 백그라운드에서 Tailscale이 꺼질 수 있어요. 이 방식으로 내 Machine에 연결할 수 없으면 표시줄에 **이 기기에서 Tailscale이 꺼져 있을 수 있어요**라고 표시돼요. 휴대폰에서 **Tailscale 열기**를 누르면 Tailscale 앱이나 앱 스토어 페이지가 열려 다시 켤 수 있어요.
- Machine이 바쁘면 응답하는 데 시간이 걸릴 수 있어요. 그러면 앱에 **내 Machine의 응답이 느려요**라고 표시되고 현재 화면이 유지돼요. 오프라인 상태라는 뜻은 아니에요.

## 기기 추가하기

각 기기에서 같은 방법으로 로그인하세요. 호스팅된 Machine에서는 기기마다 패스키를 설정하면 더 빠르게 로그인할 수 있어요. **설정** › **계정**에서 로그인 옆의 **관리**를 누르세요.

Android 휴대폰의 알림을 정보 소스로 읽는 방법은 [Android 알림](android.md)을 참고하세요.
