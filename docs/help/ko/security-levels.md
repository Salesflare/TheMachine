## 두 가지 수준

**설정**에서 **보안**을 열어요.

- **표준**: 현재 기본 설정이에요. 달라지는 점은 없어요.
- **신중**: 휴대폰에 표시되는 정보와 보관되는 정보를 줄이고 싶을 때 선택하는 더 엄격한 설정이에요.

수준은 시작점이에요. 설정을 하나라도 바꾸면 수준이 **맞춤**으로 표시돼요. 수준을 다시 선택하면 설정이 초기화돼요.

## 신중을 선택하면 달라지는 점

- **알림 텍스트**가 꺼져요. 알림에는 “새 할 일”이나 “준비됨”이라고 표시되고, 할 일 내용은 표시되지 않아요.
- **로그인 정보 저장 제안**이 꺼져요. 저장된 로그인은 **저장된 로그인 모두 잊기**를 누를 때까지 유지돼요.
- **업무 연락처 검색**, **배운 점 공유 제안**, **요청된 도움 내용 공유**가 꺼져요.
- **내 연락처 중 Machine이 있는 사람 확인**과 **내 이메일을 아는 사람이 나를 찾도록 허용**이 꺼져요.
- **실행 세부 정보 90일간 보관**이 꺼져요. 실행 세부 정보는 30일간 보관돼요.
- **다른 Machine이 내 Machine에 요청할 수 있는 내용**이 **꺼짐**으로 설정돼요. 다른 Machine과 일정을 조율할 수 없어요. [친구와 Network](friends.md#scheduling-with-other-machines)를 참고하세요.
- 가족 Fleet에서는 한가한 시간이나 바쁜 시간을 확인하기 전에 먼저 허락을 구해요. 친구와는 회의 맥락 공유 요청을 거절해요.

## 업무 Fleet의 수준

Fleet 소유자나 관리자가 Fleet 설정에서 수준을 선택해요. **설정** › **계정**에서 **Fleet**을 누르면 돼요. Fleet의 모든 구성원에게 선택한 수준이 적용돼요. 신중으로 설정하면 다음과 같이 바뀌어요.

- 팀원에게 보내는 답변은 먼저 확인을 받아요. 이름은 표시되지 않으며, 업무 계정에 있는 사람에 대해서만 답변해요.
- 소개와 인계도 먼저 확인을 받아요.
- 팀 Graph는 고객 이메일을 첨부 파일 없이 공유해요.
- 업무 할 일 알림에는 텍스트가 표시되지 않아요.
- 업무 연락처를 검색하지 않아요.
- 직접 허용하지 않은 경우, 내 Machine은 Network에서 연락처를 확인하지 않고 이메일로 나를 찾을 수 있게 하지도 않아요.
- 모든 구성원은 7일마다 다시 로그인해야 해요.
- 초대 링크는 초대장을 받은 이메일 주소로만 사용할 수 있어요.

구성원은 Fleet보다 더 엄격하게 설정할 수 있지만, 더 느슨하게 설정할 수는 없어요. 개인 설정은 유지되며, Fleet이 표준으로 돌아가면 다시 적용돼요.

## 두 수준에 공통인 점

확인 없이 전송되는 내용은 없어요. 초안을 확인한 뒤 **보내기**를 눌러요. 실행과 코딩 에이전트는 두 수준에서 똑같이 작동해요. 로그인할 때는 항상 인증 앱 코드나 패스키가 필요해요.
