## 두 가지 수준

**설정**에서 **보안**을 열어요.

- **표준**: 현재 기본값이에요. 바뀌는 내용은 없어요.
- **신중**: 휴대폰에 표시되는 정보와 보관되는 정보를 줄이고 싶을 때 선택하는 더 엄격한 설정이에요.

수준을 선택하면 기본 설정이 적용돼요. 이후 설정을 하나라도 변경하면 수준이 **맞춤**으로 표시돼요. 수준을 다시 선택하면 설정이 초기화돼요.

## 신중을 선택하면 달라지는 점

- **알림 텍스트** 끔: 알림에는 할 일의 내용 대신 "새 할 일" 또는 "준비됨"이라고 표시돼요.
- **로그인 정보 저장 제안** 끔. 저장해 둔 로그인 사이트는 **저장된 로그인 모두 잊기**를 누를 때까지 유지돼요.
- **업무 연락처 검색**, **배운 점 공유 제안**, **요청된 도움 내용 공유** 끔.
- **내 연락처 중 Machine이 있는 사람 확인** 및 **내 이메일을 아는 사람이 나를 찾도록 허용** 끔.
- **실행 세부 정보 90일간 보관** 끔: 세부 정보는 30일간 보관돼요.
- 가족에서는 가능한 시간 정보를 먼저 물어봐요. 친구와는 회의 맥락 공유를 거절해요.

## Work Fleet의 수준

Fleet 소유자나 관리자가 Fleet 설정에서 수준을 선택해요. **설정** › **계정**에서 **Fleet**를 눌러요. Fleet의 모든 구성원에게 선택한 수준이 적용돼요. 신중을 선택하면 다음과 같이 달라져요.

- 팀원에게 보내는 답변은 승인할 때까지 대기하고, 이름은 표시하지 않으며, 업무 계정에 있는 사람에 관한 내용만 다뤄요.
- 소개와 인계도 승인할 때까지 대기해요.
- 팀의 Graph에서는 고객 이메일을 첨부 파일 없이 공유해요.
- 업무 할 일 알림에는 텍스트가 표시되지 않아요.
- 업무 연락처를 검색하지 않아요.
- 직접 켜지 않는 한 The Machine은 Network에서 연락처를 확인하거나 이메일로 검색 가능하게 만들지 않아요.
- 모든 구성원은 7일마다 다시 로그인해요.
- 초대 링크는 해당 링크를 받은 이메일 주소로만 사용할 수 있어요.

구성원은 Fleet보다 더 엄격한 설정을 선택할 수 있지만, 더 느슨한 설정은 선택할 수 없어요. 구성원이 직접 선택한 설정은 유지되며 Fleet이 표준으로 돌아가면 다시 적용돼요.

## 두 수준에 공통으로 적용되는 점

승인 없이 전송되는 내용은 없어요. 각 초안을 확인하고 보내기를 눌러요. 실행과 코딩 에이전트는 똑같이 작동해요. 로그인할 때는 항상 인증 앱 코드나 패스키가 필요해요.
