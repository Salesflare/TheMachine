## 읽어 오는 정보

Salesflare의 계정, 연락처, 거래 정보와 각 계정의 피드를 읽어요. 피드에는 내가 포함되지 않은 동료의 이메일과 메모가 있는 회의가 포함돼요.

## 변경할 수 있는 정보

없어요. (내 컴퓨터에서는 `join_pipelines` 설정으로 선택한 파이프라인의 계정에 나를 추가할 수 있어요. 기본적으로 꺼져 있어요.)

## 연결하기

1. Salesflare에서 [설정, API 키](https://app.salesflare.com/#/settings/apikeys)를 열고 키를 만들어요.
2. 내 호스팅 Machine을 사용하는 경우: app.themachine.computer/setup에서 설정 페이지를 열고 **추가 소스**로 이동한 다음 Salesflare CRM을 열어요. 키를 붙여 넣고 **연결**을 눌러요.
3. 대시보드에서 **연결**, **고객**, Salesflare CRM을 차례로 열어요. 키를 붙여 넣고 **연결**을 눌러요. 그러면 카드에 진행 상황이 표시돼요.

## 동기화 세부 정보

**연결**, **고객**에서 Salesflare의 진행 상황을 확인할 수 있어요. 이번에 읽은 계정 수와 Salesflare가 너무 느려서 건너뛴 계정 수가 표시돼요. 동기화가 몇 시간 동안 계속되면 중단된 상태일 수 있어요.

타일에는 열 수 있었던 계정 수와 가져온 이메일 및 회의 수가 표시돼요. API 키로 열 수 있는 계정이 하나도 없으면 카드에 **도움이 필요해요**가 표시돼요. 해당 계정을 볼 수 있는 사용자의 키를 사용하세요. Salesflare에서 시간 초과가 반복되지만 재시도할 때마다 동기화에 성공하면 Salesflare가 **가끔 느려요**라고 표시돼요.

Salesflare에서 팀의 API 키에 대한 피드 액세스를 켜지 않은 경우 카드에 해당 내용이 표시돼요. Salesflare 지원팀에서 액세스를 켜기 전까지 이메일과 회의가 들어오지 않아요. 첫날에는 10분마다, 이후에는 약 1시간마다 다시 확인하고, 액세스가 가능해지면 자동으로 동기화를 계속해요.

- **중지**: **시작**을 누를 때까지 새 데이터가 들어오지 않아요. 중지한 지점부터 계속 진행해요.
- **동기화 다시 시작**: 처음부터 다시 시작해 지난주 데이터를 다시 읽어요. 이미 가져온 데이터는 사라지지 않아요.
- **API 키**: Salesflare의 API 키 페이지를 열어 새 키를 만들어요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 Salesflare, **세부 정보**, **연결 해제**를 차례로 눌러요. 이미 가져온 데이터는 그대로 남아요.
- 내 호스팅 Machine을 사용하는 경우 설정 페이지에서 옆에 있는 **삭제**를 눌러도 돼요.

## Salesflare에서 키 취소하기

Salesflare의 설정, API 키에서 API 키를 삭제하세요.
