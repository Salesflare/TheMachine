## 읽는 데이터

Salesflare의 계정, 연락처, 거래와 각 계정의 피드를 읽어요. 피드에는 내가 포함되지 않은 동료의 이메일과 메모가 있는 회의가 있어요.

## 변경할 수 있는 항목

없어요. (개인 컴퓨터에서는 `join_pipelines` 설정으로 선택한 파이프라인의 계정에 연결된 사용자를 추가할 수 있어요. 기본적으로 꺼져 있어요.)

## 연결하기

1. Salesflare에서 [설정, API 키](https://app.salesflare.com/#/settings/apikeys)를 열고 키를 만들어요.
2. 호스팅된 Machine에서는 app.themachine.computer/setup에서 설정 페이지를 열고 **더 많은 소스**로 이동해 Salesflare CRM을 연 다음, 키를 붙여 넣고 **연결**을 눌러요.
3. 대시보드에서 **연결**, **고객**, Salesflare CRM으로 이동해 키를 붙여 넣고 **연결**을 눌러요. 그러면 읽은 계정 수가 표시돼요.

## 동기화 세부 정보

**연결**, **기타 소스**에서 Salesflare 동기화 진행 상황을 확인할 수 있어요. 이번에 읽은 계정 수와 Salesflare가 너무 느려서 건너뛴 계정 수가 표시돼요. 동기화가 몇 시간 동안 진행되면 멈췄을 수 있다는 메시지가 표시돼요.

타일에는 열 수 있었던 계정 수와 가져온 이메일 및 회의 수가 표시돼요. API 키로 열 수 있는 계정이 하나도 없으면 카드에 **도움이 필요해요**라고 표시돼요. 해당 계정을 볼 수 있는 사용자의 키를 사용하세요. Salesflare에서 계속 시간 초과가 발생하지만 재시도할 때마다 완료되면 **때때로 느려요**라고 표시돼요.

Salesflare에서 팀의 API 키에 피드 접근 권한을 사용 설정하지 않았다면 카드에 안내가 표시돼요. Salesflare 지원팀에서 사용 설정하기 전까지 이메일이나 회의가 들어오지 않아요. 첫날에는 10분마다, 이후에는 약 1시간마다 다시 확인하고, 작동하면 자동으로 계속 진행돼요.

- **중지**: **시작**을 누를 때까지 새 데이터가 들어오지 않아요. 중지한 지점부터 다시 진행돼요.
- **동기화 다시 시작**: 처음부터 다시 시작해 지난주 데이터를 다시 읽어요. 이미 가져온 데이터는 사라지지 않아요.
- **API 키**: 새 키를 만들 수 있도록 Salesflare의 API 키 페이지를 열어요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 Salesflare, **세부 정보**, **연결 해제**를 차례로 선택해요. 이미 가져온 데이터는 유지돼요.
- 호스팅된 Machine에서는 설정 페이지에서 Salesflare 옆의 **삭제**를 눌러도 돼요.

## Salesflare에서 키 취소하기

Salesflare의 설정, API 키에서 API 키를 삭제하세요.
