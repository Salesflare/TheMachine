## 읽어 오는 정보

Salesflare의 계정, 연락처, 거래 정보와 각 계정의 피드예요. 피드에는 내가 참조에 포함되지 않은 동료의 이메일과 메모가 있는 회의가 포함돼요.

## 변경할 수 있는 정보

없어요. (내 컴퓨터에서는 `join_pipelines` 설정을 사용하면 선택한 파이프라인의 계정에 나를 추가할 수 있어요. 기본적으로 꺼져 있어요.)

## 연결하기

1. Salesflare에서 [설정, API 키](https://app.salesflare.com/#/settings/apikeys)를 열고 키를 만들어요.
2. 호스팅된 Machine에서는 설정 페이지(app.themachine.computer/setup)를 열고 **추가 소스**로 이동해 Salesflare CRM을 연 다음, 키를 붙여 넣고 **연결**을 눌러요.
3. 대시보드에서 **연결**, **고객**, Salesflare CRM을 차례로 열고 키를 붙여 넣은 다음 **연결**을 눌러요. 그러면 카드에 동기화 진행 상황이 표시돼요.

## 동기화 세부 정보

**연결**, **고객**에서 Salesflare의 동기화 진행 상황을 확인할 수 있어요. 이번 회차에 확인한 계정, Salesflare가 너무 느려 건너뛴 계정, API 키로 열 수 없는 계정(**액세스할 수 없음**)이 표시돼요. 동기화가 몇 시간 동안 진행 중이면 멈췄을 수 있다는 뜻이에요.

타일에는 이번 주에 읽은 계정 수와 가져온 이메일 및 회의 수가 표시돼요.

액세스할 수 없는 계정이 몇 개 있어도 따로 조치할 필요는 없어요. 나머지 정보는 평소처럼 가져와요. API 키로 열 수 있는 계정이 하나도 없으면 카드에 **도움이 필요해요**라고 표시돼요. 해당 계정을 볼 수 있는 사용자의 키를 사용해 주세요. 새 키를 사용하면 처음부터 다시 시작해 지난 일주일의 정보를 읽어요. Salesflare의 응답 시간 초과가 계속 발생하지만 재시도할 때마다 연결에 성공하면 Salesflare가 **가끔 느려요**라고 표시돼요.

Salesflare에서 팀의 API 키에 대한 피드 액세스를 사용 설정하지 않은 경우 카드에 해당 내용이 표시돼요. Salesflare 지원팀에서 사용 설정할 때까지 이메일이나 회의 정보를 가져오지 않아요. 첫날에는 10분마다, 그다음부터는 약 1시간마다 다시 확인하며, 액세스가 가능해지면 자동으로 계속 진행해요.

- **중지**: **시작하기**를 누를 때까지 새 정보를 가져오지 않아요. 중지한 지점부터 다시 진행해요.
- **동기화 다시 시작**: 처음부터 다시 시작해 지난 일주일의 정보를 읽어요. 이미 가져온 정보는 사라지지 않아요.
- **API 키**: 새 키를 만들 수 있도록 Salesflare의 API 키 페이지를 열어요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 Salesflare, **세부 정보**, **연결 해제**를 차례로 눌러요. 이미 가져온 정보는 그대로 남아요.
- 호스팅된 Machine에서는 설정 페이지에서 Salesflare 옆의 **삭제**를 눌러도 돼요.

## Salesflare에서 액세스 권한 취소하기

Salesflare의 설정, API 키에서 API 키를 삭제해요.
