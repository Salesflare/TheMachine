할 일은 확인 기능에서 만들어져요. The Machine은 지난 15분 정도 동안 들어온 내용을 살펴봐요.

## 가입한 직후

새 호스팅 Machine에서는 AI와 메일을 연결하면 확인 기능이 자동으로 시작돼요. The Machine이 메일을 읽는 동안 할 일에는 "메일을 읽고 있어요. 몇 분 후 첫 할 일이 생겨요."라고 표시돼요. 메일 양을 파악하면 대략 얼마나 걸릴지 알려줘요. 예를 들어 "첫 할 일이 약 10분 후에 생겨요."라고 표시돼요. 필요한 단계가 남아 있으면 **확인 필요**에 **메일 연결**처럼 해야 할 일이 표시되고 해당 단계로 가는 링크가 제공돼요.

메일을 읽는 동안 할 일에는 진행 상황("메시지 132개 중 20개를 읽었어요. 다음 40개를 읽는 중…")과 확인한 사람 및 조직 몇 곳, 그리고 첫 할 일이 생기는 즉시 해당 항목이 표시돼요. 숫자는 읽기를 마친 메시지 수예요. 다음 메시지를 읽는 동안 진행 막대는 계속 움직여요. 이름은 직접 받은 메일에서 가져오며, 다른 사람에게는 보이지 않아요.

처음 살펴본 결과 할 일이 없으면, 무엇을 읽었는지 알려주고 자주 메일을 보내는 서비스를 연결하거나 이번 주에 달라진 점을 물어보는 등의 다음 단계를 제안해요.

## 확인 기능이 꺼져 있어요

할 일 화면 상단에 "확인 기능이 꺼져 있어 아직 할 일이 없어요."라고 표시돼요. 호스팅 Machine에서는 **확인 기능 켜기**를 누르세요. 직접 사용하는 컴퓨터에서는 `./install.sh --activate`을 실행하세요.

## 모델 사용량 한도

직접 채팅할 수 있도록 확인 기능은 AI 요금제의 5시간 한도 중 약 65%, 주간 한도 중 90%에 도달하면 일시 중지돼요. 다른 요금제의 백업 모델을 사용하면 확인 기능은 대기하지 않아요. 자세한 내용은 [모델](model.md)을 참고하세요.

확인 기능이 대기 중이면 대시보드 상단에 대기 종료 시각이 표시돼요. 예를 들어 "ChatGPT 주간 사용량을 아끼기 위해 07:15까지 확인 기능이 대기해요."라고 표시돼요. **지금 확인**을 누르면 바로 확인을 시작해요. **설정**의 **모델**에서 한도를 확인할 수 있어요.

놓치는 내용은 없어요. 확인이 가능해지는 대로 들어온 내용을 확인해요.

## 밤 시간

00:00부터 06:30까지 확인 기능이 일시 중지되고 새 메시지는 대기해요. 오전 6:30에 대기 중인 메시지를 한꺼번에 확인한 뒤 아침 요약을 보내요. **확인**에는 "밤 시간에는 일시 중지돼요. 06:30에 확인을 이어가요."라고 표시돼요. 앱을 사용하거나 채팅에 메시지를 쓰거나 할 일을 누르면 확인 기능이 다시 실행돼요. 한 시간 동안 자리를 비우면 다시 일시 중지돼요. **지금 확인**을 누르면 바로 확인해요.

## 실행에 실패했어요

**연결**의 **확인** 아래에 있는 **최근 실행**에서 실행 내역을 확인할 수 있어요. 실패한 실행은 자동으로 다시 시도해요.

## 따로 보관

확인 기능이 메시지를 두 번 미루면 해당 메시지는 따로 보관돼요. **연결**의 **확인**에서 따로 보관된 메시지 수를 확인할 수 있고, **따로 보관**에서 메시지 목록을 볼 수 있어요. 메시지를 보낸 사람이거나 아는 사람 또는 고객이라면, 메시지가 들어온 지 약 3일 후에 한 번 더 확인해요. 이때 할 일로 만들거나 종료해요. 필요 없다고 표시했거나 미룬 항목은 그대로 유지돼요.
