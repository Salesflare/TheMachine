할 일은 확인 작업에서 생겨요. Machine이 약 15분 동안 새로 들어온 내용을 확인해요.

## 가입 직후

새 호스팅 Machine에서는 AI와 메일을 연결하면 확인 작업이 자동으로 시작돼요. Machine이 메일을 읽는 동안 할 일에 "메일을 읽고 있어요. 몇 분 후 첫 할 일이 생겨요."라고 표시돼요. 메일 양을 파악하면 "약 10분 후 첫 할 일이 생겨요."처럼 예상 시간을 알려줘요. 필요한 단계가 빠져 있으면 **확인 필요**에 **메일 연결**처럼 해야 할 일이 표시되고, 해당 단계로 가는 링크도 제공돼요.

메일을 읽는 동안 할 일에는 진행 상황("메시지 132개 중 20개를 읽었어요. 다음 40개를 읽는 중…"), 확인한 사람과 조직 몇 곳, 그리고 준비되는 대로 첫 할 일이 표시돼요. 숫자는 읽기를 마친 메시지 수를 나타내고, 다음 메시지를 읽는 동안 진행 막대는 계속 움직여요. 이름은 메일에서 가져오며, 나만 볼 수 있어요.

처음 확인한 결과 할 일이 없으면, 무엇을 읽었는지 알려주고 자주 메일을 보내는 서비스를 연결하거나 이번 주에 달라진 점을 물어보는 등의 다음 단계를 제안해요.

## 확인 기능이 꺼져 있어요

할 일 화면 상단에 "확인 기능이 꺼져 있어 아직 할 일이 들어오지 않아요."라고 표시돼요. 호스팅 Machine에서는 **확인 기능 켜기**를 눌러요. 내 컴퓨터에서는 `./install.sh --activate`을 실행해요.

## 모델 사용량 한도

내 채팅을 위한 여유를 남겨두기 위해 확인 작업은 AI 요금제의 5시간 한도의 약 65%, 주간 한도의 90%에 도달하면 일시 중지돼요. 다른 요금제의 백업 모델이 있으면 확인 작업은 기다리지 않아요. 자세한 내용은 [모델](model.md)을 참고하세요.

확인 작업이 대기 중이면 대시보드 상단에 "ChatGPT 주간 한도를 아끼기 위해 07:15까지 확인 작업이 대기해요."처럼 대기 종료 시간이 표시돼요. **지금 확인**을 누르면 바로 확인 작업을 시작해요. **설정**의 **모델**에서 한도를 확인할 수 있어요.

놓치는 내용은 없어요. 가능한 시점에 새로 들어온 내용을 확인해요. 오래 기다린 경우 사람에게서 온 최근 메시지를 먼저 확인하고, 각 확인 작업 중 일부는 가장 오래된 메시지를 처리해요.

확인을 따라잡을 때까지 새 할 일에는 초안이 없어요. 요금제 사용량을 메시지 확인에 먼저 쓰기 위해서예요. 초안은 나중에 생기며, 긴급한 할 일은 기다리지 않아요. 지금 초안을 만들려면 **실행**을 눌러요.

## 밤 시간

00:00부터 06:30까지 확인 작업이 일시 중지되고 새 메시지는 대기해요. 06:30에 메시지를 한꺼번에 확인한 뒤 아침 요약을 만들어요. **확인**에 "밤 시간에는 일시 중지돼요. 06:30에 따라잡아요."라고 표시돼요. 앱을 사용하거나, 채팅에 글을 쓰거나, 할 일을 누르면 다시 확인 작업이 시작돼요. 한 시간 동안 자리를 비우지 않을 때까지 계속돼요. **지금 확인**을 누르면 바로 확인해요.

## 실행 실패

**연결**의 **확인** 아래 **최근 실행**에서 각 실행 내역을 볼 수 있어요. 실패한 실행은 자동으로 다시 시도해요. 예를 들어 로그인이 만료돼 AI가 응답을 멈추면 **설정**의 **모델**에서 다시 로그인하세요. 확인 작업은 바로 다시 시작돼요.

AI 요금제 사용량 한도에 도달해 중지된 실행에는 **AI 사용량 한도에 도달했어요.**라고 표시되고, 한도가 풀리는 시간도 안내돼요. 이 경우에는 실패가 아니라 일시 중지된 거예요. 메시지는 대기했다가 한도가 초기화된 뒤 확인돼요. [오류 보고서](error-reports.md)에는 아무것도 전송되지 않아요.

## 따로 보관

확인 작업에서 메시지를 두 번 미루면 따로 보관돼요. **연결**의 **확인**에 따로 보관된 메시지 수가 표시되고, **따로 보관**에서 메시지 목록을 볼 수 있어요.

AI가 정상적으로 작동하는데 특정 메시지 때문에 확인 작업이 매번 실패하면, 나머지 내용을 확인할 수 있도록 해당 메시지도 같은 방식으로 따로 보관돼요.

나에게 연락한 사람, 아는 사람 또는 고객이 보낸 메시지는 들어온 지 약 3일 후 한 번 더 확인해요. 이 확인에서 할 일을 만들거나 메시지를 닫아요. 무시하거나 미룬 메시지는 그대로 유지돼요.
