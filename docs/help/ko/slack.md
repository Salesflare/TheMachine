## 읽는 내용

멤버로 참여 중인 대화, 즉 채널, 비공개 채널, 다이렉트 메시지, 그룹 메시지를 읽어요. 연결할 때는 최근 7일간의 메시지를 읽고, 그다음부터는 새 메시지를 모두 읽어요. 채널에 직접 참여하거나 대화를 직접 열지는 않아요. 조용한 채널은 하루에 한 번 정도 읽고, 할 일에 최신 메시지가 필요하면 The Machine이 바로 읽어요.

약 1년 치의 이전 메시지는 [기록](history.md)으로 나중에 조금씩 가져와요.

사람은 이름으로, 앱은 앱 이름으로 표시하고 Slack ID는 표시하지 않아요. Slack 계정이 삭제된 사람은 이전 Slack 사용자로 표시돼요.

## 보낼 수 있는 내용

한 사람에게 회원님을 대신해 다이렉트 메시지를 보내요. 할 일에서 승인한 뒤에만 보내요. 할 일이 시작된 Slack 메시지에 답장하면 그 메시지의 스레드에 답장이 올라가요. 다이렉트 메시지나 채널에서도 마찬가지예요. 초안에는 **스레드에서**라고 표시돼요. 채널에 새 게시물을 작성하지는 않아요.

## 보관하는 내용

읽은 내용은 직접 삭제하거나 The Machine을 삭제할 때까지 The Machine에 보관돼요. 호스팅 서비스에는 메시지 사본이나 Slack 로그인 정보가 저장되지 않고, Slack 데이터를 사용해 AI 모델을 학습시키지도 않아요. The Machine은 AI를 사용하므로 잘못된 내용을 만들 수 있어요. 그래서 메시지를 보내기 전에 항상 확인할 수 있어요.

## 연결하기

1. **연결**, **채팅**, **Slack**을 차례로 선택한 다음 **Sign in with Slack**을 선택하고 Slack에서 권한을 허용해요. 내 컴퓨터에서 사용하려면 먼저 themachine.computer에서 계정과 페어링해요.
2. 새 메시지와 다이렉트 메시지를 먼저 가져와요. Slack에서는 앱이 대화를 1분에 한 번 정도만 읽을 수 있어 이전 메시지를 가져오는 데 몇 시간이 걸릴 수 있어요.

또는 Maton API 키를 사용할 수 있어요. maton.ai에 로그인하고 Slack을 연결한 다음, 홈에서 Maton API 키를 복사해요. 그런 다음 Slack 아래의 **또는 Maton API 키를 사용해요**를 열어 키를 붙여넣거나, 내 컴퓨터에서 `assistant connect slack` 명령을 실행해요. Maton을 통해 연결한 Slack은 기존 방식대로 계속 작동해요.

## 연결 해제하기

- 대시보드에서 **연결**을 선택하고 Slack을 연 다음 **세부 정보**, **연결 해제**를 선택해요. 이미 가져온 내용은 그대로 남아요.
- 내 호스팅 Machine에서는 설정 페이지에서 Slack 옆의 **삭제**를 눌러도 돼요.

## Slack에서 제거하기

Slack으로 로그인한 경우 Slack에서 워크스페이스의 앱 관리 페이지를 열고 The Machine을 제거해요. 즉시 메시지 읽기를 중단하고 다시 로그인하라는 메시지가 표시돼요. 이미 가져온 내용은 그대로 남아요. Maton을 통해 연결한 경우 Maton에서 Slack 연결을 삭제하고 제공한 Maton API 키를 삭제해요. Slack 관리자는 앱 관리에서 워크스페이스의 두 앱 중 하나를 제거할 수도 있어요.
