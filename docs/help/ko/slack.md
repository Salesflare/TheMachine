## 읽는 내용

참여 중인 대화인 채널, 비공개 채널, 다이렉트 메시지, 그룹 메시지를 읽어요. 연결할 때는 최근 7일간의 메시지를 읽고, 그 후에는 새로 온 메시지를 모두 읽어요. 채널에 참여하거나 대화를 여는 일은 없어요. 활동이 뜸한 채널은 하루에 한 번 정도 읽고, 할 일에 최신 메시지가 필요하면 The Machine이 바로 읽어요.

약 1년 치 이전 메시지는 나중에 [기록](history.md)으로 조금씩 가져와요.

사람은 이름으로, 앱은 앱 이름으로 표시해요. Slack ID는 표시하지 않아요. Slack 계정이 삭제된 사람은 이전 Slack 사용자로 표시해요.

## 보낼 수 있는 내용

할 일에서 승인한 후에만, 본인을 대신해 한 사람에게 다이렉트 메시지를 보내요. 할 일이 시작된 Slack 메시지에 답장하면 해당 메시지의 스레드에 답장이 올라가요. 다이렉트 메시지나 채널 어디에서든 마찬가지예요. 초안에는 **스레드에서**라고 표시돼요. 채널에 새 게시물을 올리지는 않아요.

## 연결하기

1. **연결**, **채팅**, **Slack**, **Slack으로 로그인**을 차례로 누른 다음 Slack에서 허용해요. 개인 컴퓨터에서는 먼저 themachine.computer에서 계정과 페어링해요.
2. 새 메시지와 다이렉트 메시지를 먼저 가져와요. Slack에서는 앱이 대화를 1분에 한 번 정도만 읽을 수 있어서, 이전 메시지는 몇 시간에 걸쳐 채워져요.

Maton API 키를 사용할 수도 있어요. maton.ai에 로그인하고 Slack을 연결한 다음, 홈에서 Maton API 키를 복사해요. 그런 다음 Slack 아래의 **또는 Maton API 키 사용**을 열어 키를 붙여 넣거나, 개인 컴퓨터에서 `assistant connect slack`을 실행해요. Maton을 통해 연결한 Slack은 계속 기존처럼 작동해요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 Slack, **세부 정보**, **연결 해제**를 차례로 선택해요. 이미 가져온 내용은 그대로 남아요.
- 호스팅 환경의 Machine에서는 설정 페이지에서 Slack 옆의 **삭제**를 눌러도 돼요.

## Slack에서 앱 삭제하기

Slack으로 로그인했다면 Slack에서 워크스페이스의 앱 관리 페이지를 열고 The Machine을 삭제해요. Maton을 이용했다면 Maton에서 Slack 연결을 삭제하고 제공한 Maton API 키도 삭제해요. Slack 관리자는 앱 관리에서 워크스페이스의 두 앱 중 어느 것이든 삭제할 수 있어요.
