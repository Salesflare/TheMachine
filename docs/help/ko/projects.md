The Machine은 메시지 내용을 바탕으로 프로젝트 이름을 정해요. 관련 있어 보이는 메시지는 "관련 있을 가능성이 높음"으로 표시돼요. 프로젝트 이름을 다른 프로젝트와 똑같이 바꾸면 두 프로젝트가 합쳐져요. CRM의 거래처럼 직접 관리할 수도 있어요.

## 프로젝트 추가

보드 상단의 **새 프로젝트**, 단계 아래의 **+ 추가**, 목록 상단의 **새 프로젝트**, 휴대폰 상단 바의 **+**, 또는 사람이나 조직 페이지에서 추가할 수 있어요.

이름, 보드와 단계, 조직(Graph에서 검색하거나 새 조직 **추가**), 금액, 예상 종료일, 사람, 메모를 입력해요. Graph에 이름이 비슷한 프로젝트가 있으면 먼저 표시돼요.

## 프로젝트 수정, 수주 또는 분실

- 프로젝트 페이지의 **수정** 또는 보드에서 프로젝트의 **⋯** 메뉴에 있는 **수정**을 선택하거나 E 키를 누르면 위 항목을 모두 바꿀 수 있어요.
- 거래인 경우, 이유와 함께 **수주** 또는 **분실**로 표시할 수 있어요. 거래란 금액이나 예상 종료일이 있는 프로젝트, 또는 그런 프로젝트가 있는 보드의 프로젝트를 말해요. 수주한 프로젝트는 보드의 마지막 단계로 이동하고, 분실한 프로젝트는 중단 또는 거절 단계로 이동해요. 그 외 프로젝트는 **완료**로 끝나요. **다시 열기**를 누르면 취소돼요.
- **보관**하면 보드와 목록에서 사라져요. 관련 메시지가 새로 오면 다시 표시돼요.
- **삭제**하면 완전히 삭제돼요. 메시지와 사람은 그대로 남아요.

## 설명

프로젝트 이름 아래에 표시되는 한두 문장으로, 프로젝트 내용과 진행 상황을 알려줘요. The Machine은 프로젝트의 메시지, 할 일, 약속, 사실, 단계를 바탕으로 설명을 작성하고 새 메시지, 단계 변경, 수주 또는 분실처럼 변경 사항이 생기면 업데이트해요. 아직 구체적으로 쓸 내용이 없으면 표시하지 않아요.

프로젝트의 **수정**에서 **설명**을 바꿀 수 있어요. 직접 수정하면 설명은 직접 관리하게 돼요. "직접 수정함"이라고 표시되고, The Machine은 설명을 건드리지 않아요. 설명 아래 또는 **수정**에서 **최신 상태로 유지**를 선택하면 다시 The Machine이 관리해요. 설명을 비워서 저장하면 표시되지 않아요.

공유 Work 프로젝트에서는 설명의 근거가 된 내용이 모두 팀에도 공유된 경우에만 팀에서 설명을 볼 수 있어요. 직접 수정한 내용은 본인에게만 보여요.

## 프로젝트 이동

프로젝트를 다른 단계로 드래그해 옮기거나, 휴대폰에서 **⋯** 메뉴의 **다음으로 이동**을 사용해요. 이후 더 최근 메시지로 프로젝트가 이동하기 전까지는 직접 옮긴 단계가 유지돼요.

보드 상단의 **단계**에서 보드별로 표시할 단계만 선택할 수 있어요. **지우기**를 누르면 모든 단계가 다시 표시돼요.

단계 아래에 "답장이 10일 넘게 없는 프로젝트 4개"라고 표시되면 눌러서 보드와 목록에 해당 프로젝트만 표시할 수 있어요. 다시 누르면 전체 프로젝트가 표시돼요.

## 프로젝트 나누기

프로젝트에 여러 내용이 포함된 경우 **⋯** 메뉴에서 **분할하기…**를 선택하면 The Machine이 새 프로젝트를 2~4개 만들어요. 각 프로젝트에는 이름, 내용 한 줄, 해당 프로젝트에 포함될 대화, 할 일, 사람이 표시돼요. 아직 아무것도 변경되지 않으니 이름을 바꾸고, 항목을 다른 프로젝트로 옮기거나, 그대로 두거나, 프로젝트에서 제외한 다음 확인해요.

새 프로젝트는 원래 프로젝트와 같은 보드 및 단계에 추가되고, 같은 사람과 공유돼요. 공유 대상이 더 늘어나지는 않아요. 분할 후 페이지에는 분할된 프로젝트가 표시되고, **실행 취소**를 누르면 모든 내용이 원래대로 돌아가요.

## 프로젝트의 할 일

할 일은 프로젝트 하나에 연결할 수 있어요. 대화나 관련 인물이 진행 중인 프로젝트 하나에만 속하면 The Machine이 해당 프로젝트를 선택하고, 할 일 제목 아래에 프로젝트 이름을 표시해요. 할 일의 **세부 정보**에서 **프로젝트**를 선택하거나 명령 메뉴(Ctrl K)에서 **프로젝트에 추가**를 선택하면 프로젝트를 바꾸거나 연결을 해제할 수 있어요. 직접 선택한 내용은 그대로 유지돼요.

프로젝트 페이지의 **할 일**에는 해당 프로젝트의 할 일이 표시되며, 진행 중인 할 일이 먼저 보여요. 보드에는 진행 중인 할 일의 개수가 표시돼요. 할 일을 공유 프로젝트에 연결해도 추가로 공유되는 내용은 없어요. 팀에는 공유 메시지에서 비롯된 내용만 보여요.

일주일에 한 번, The Machine은 조용해진 프로젝트를 찾아요. 10일 이상 새로운 내용이 없고, 진행 중인 할 일도 없으며, 약속한 내용도 없는 프로젝트예요. 최대 3개 프로젝트에 "서명된 주문서를 Sam에게 보내기"처럼 구체적인 다음 단계를 할 일로 추가하고, 해당 할 일을 이어갈 메시지에 연결해요. 명확한 다음 단계가 없으면 할 일을 추가하지 않아요. 할 일을 무시하면 해당 프로젝트는 4주 동안 다시 추천되지 않아요.

## 프로젝트의 조직

프로젝트 하나에 조직 하나를 연결할 수 있어요. 연결된 조직은 프로젝트 페이지, 목록, 보드에 링크와 함께 표시돼요.

직접 조직을 선택하지 않았다면 The Machine은 프로젝트에 포함된 사람과 메시지를 바탕으로 조직을 지정하고, 동료는 제외해요. 상대편 조직이 명확한 경우에만 지정해요. Gmail 같은 개인 이메일은 해당하지 않고, 여러 회사가 관련된 프로젝트에는 조직을 지정하지 않아요. 이때 프로젝트 양식에는 "관련 인물에서 가져옴"이라고 표시돼요.

그런 다음 프로젝트 내용과 대조해 확인해요. 프로젝트에 참여한 사람의 직장일 뿐인 조직(예: 콘서트 프로젝트에 참여한 친구의 고용주)은 연결이 해제돼요.

**수정**에서 직접 선택한 조직은 프로젝트에서 조직을 해제한 경우에도 계속 유지돼요. **다음과 같은 조직…**을 선택하면 해당 조직의 프로젝트를 함께 이동하고, **분리**를 선택하면 다시 나눠요.

## 보드

CRM의 영업 파이프라인처럼 같은 종류의 프로젝트를 단계별로 관리해요. 보드의 **⋯** 메뉴에서 **보드 수정**(이름, 단계, 포함할 프로젝트), **이 보드에서 열기**, **새 보드**를 선택할 수 있어요.

확인 기능은 조건에 맞는 프로젝트를 계속 추가하고 단계를 지정해요. 판단하기 어려운 경우 보드에 "여기에 포함될 수 있는 프로젝트 2개"라고 표시돼요. **추가** 또는 **제외**를 선택해요. 몇 개를 선택하거나 **모두 선택**하면 한 번에 처리할 수 있어요. 마음이 바뀌면 바로 **실행 취소**를 선택해요. 여러 상대방을 한데 묶은 프로젝트를 추가하면 상대방마다 프로젝트 하나씩으로 나뉘어요.

새 보드를 만들거나 추천 보드를 저장하면 전체 기록을 한 번 살펴봐요. 조건에 맞는 조직마다 프로젝트 하나를 만들고 각 프로젝트를 단계에 배치해요. 처리 중에는 헤더에 "기록을 살펴보는 중…"이라고 표시되고, 완료되면 추가한 프로젝트 수와 확인이 필요한 프로젝트 수가 표시돼요. 나만 보는 보드에서는 찾은 내용도 본인에게만 보여요.

보드의 **⋯** 메뉴에서 **후속 연락…**을 설정하면 상대방이 답장하지 않을 때 자동으로 후속 연락을 해요. [후속 연락](follow-ups.md)을 참고하세요.

## 완료 조건

보드에 포함됐는지와 관계없이 프로젝트의 **수정**에서 **완료 조건**을 설정해, 완료 기준을 쉬운 말로 설명하고 근거를 선택할 수 있어요. 근거는 **실시간 페이지**(The Machine이 상대방의 메시지에 있는 링크를 열어 해당 페이지에 연결된 내용이 있는지 확인해요) 또는 **상대방 메시지**예요. 파트너 등록 프로젝트에는 확인할 근거가 추천돼요.

근거가 확인된 프로젝트만 해당 근거가 연결된 프로젝트 페이지와 함께 마지막 단계로 이동해요. 보드에 없는 프로젝트는 대신 완료로 표시되고, **⋯** 메뉴의 최근 변경 사항에서 **실행 취소**를 선택할 수 있어요.

나중에 **완료 조건**을 바꾸면 완료된 프로젝트의 근거가 더 이상 조건에 맞지 않을 때 다시 열려요. 연결된 할 일도 새 조건을 따르게 돼요. 직접 **완료** 또는 **수주**로 표시해도 돼요. 페이지에는 진행을 막는 내용(10일 넘게 답장이 없음, 기한이 지난 약속)도 표시되고, 할 일이 없으면 해당 내용에 대한 할 일이 추가돼요. 확인은 새 메시지가 없더라도 매일 업무일에 진행돼요. 직접 확인하지 않는 한 아무것도 전송되지 않아요.

## 파이프라인

보드 상단의 **파이프라인**에는 진행 중인 프로젝트의 금액 합계가 단계별로 표시되고, 종료 예정일을 기준으로 월별 종료 예상 금액도 표시돼요. 수주, 분실, 중단된 프로젝트는 진행 중인 프로젝트에 포함되지 않아요. 이번 달 수주 금액은 따로 표시돼요.

금액은 The Machine의 통화를 다른 통화로 설정하지 않았다면 유로로 표시돼요. 필터에서 **소유자**를 선택하면 본인 프로젝트만 계산돼요.

## 팀원의 보드

**팀**에서 팀원이 공유한 보드를 확인할 수 있어요. 본인 프로젝트가 가장 많이 포함된 보드가 먼저 표시돼요. 헤더에는 보드 소유자와 공유 대상이 표시돼요. 전체 팀과 공유한 경우 "Ada의 보드, 팀과 공유됨", 선택한 팀원과만 공유한 경우 "Ada님이 이 보드를 공유했어요"라고 표시돼요.

프로젝트마다 마지막으로 진행된 내용과 날짜가 표시돼요. 팀과 공유된 내용 중 가장 최근 내용 또는 그보다 나중에 이루어진 단계 이동이 표시돼요. 여러 팀원의 프로젝트가 있는 보드에서는 해당 줄 끝에 누구의 내용인지 표시돼요("Ada님이 작성").

팀원의 보드에는 팀원이 보는 것보다 프로젝트가 적을 수 있어요. 비공개로 둔 프로젝트나 개인 대화가 포함된 프로젝트는 팀원의 Machine 밖으로 나가지 않아요. 개인으로 분류된 사람은 공유되는 프로젝트에서 제외돼요. 본인 보드의 헤더에는 "팀과 공유됨"과 본인에게만 표시되는 프로젝트 수가 나오고, 해당 프로젝트에는 자물쇠가 표시돼요.

**내 담당**, **내 조치가 필요해요**, **전체**를 선택하면 공유 보드와 해당 보드가 포함된 팀의 프로젝트 목록에 표시할 내용을 정할 수 있어요. 내 담당에는 본인이 참여한 대화, 소유한 프로젝트, 또는 본인 할 일이 관련된 프로젝트가 표시돼요. 내 조치가 필요해요에는 진행 중인 할 일이 있거나 가장 최근 메시지를 본인이 받은 프로젝트가 표시돼요.

프로젝트는 소유자의 보드와 같은 모습과 순서로 표시돼요. 조직, 해당 단계에 머문 날짜 수, 다음 단계, "답장 없음: N일"이 표시돼요. 소유자에게만 남아 있는 메시지에서 나온 다음 단계나 이유는 표시되지 않아요. 나머지 단계 내용은 **N개 더 보기**를 선택하면 펼쳐져요. 이 중 어느 것도 공유 설정을 바꾸지 않아요.

어떤 보드에서든 보드 이름과 같은 이름의 프로젝트는 보드 이름 없이 표시돼요("Listings: Acme"는 Listings 보드에서 "Acme"로 표시돼요).
