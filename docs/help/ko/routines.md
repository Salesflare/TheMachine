## 루틴 만들기

사이드바에서 **루틴**을 열고 한 줄로 할 일과 시점을 말해 주세요. 예를 들어 "매주 월요일 9시에 진행 중인 거래를 요약해 줘" 또는 "평일 아침마다 아직 답장하지 않은 이메일을 목록으로 보여 줘"라고 입력한 다음 **추가**를 누르세요.

시점을 지정하지 않으면 8:00에 실행돼요. 시각은 Machine의 시간대를 기준으로 해요. 처음 실행할 때 짧은 이름이 정해져요.

**추가**를 누르면 먼저 테스트 실행이 진행돼요. 결과를 확인한 뒤 유지할 수 있어요. 이때는 아무것도 전송하거나 저장하지 않아요. 다음으로 **추가**를 누르면 정해진 일정에 따라 실행되고, **변경**을 누르면 다른 문구나 새 이름을 시도하고, **취소**를 누르면 루틴을 삭제해요.

## 템플릿

루틴 페이지 아래쪽의 **템플릿**에서 **추가**를 누르면 미리 만들어진 루틴이 켜져요. 바로 한 번 실행된 다음 매일 아침 7:30에 실행돼요. 스팸 정리는 매시간, 중고 물품 찾기는 3시간마다, 구독 및 체험은 한 달에 한 번 실행돼요. 템플릿 카드에는 다른 루틴처럼 실행 내용이 표시되고, **수정**을 누르면 내용이나 이름을 바꿀 수 있어요.

뉴스레터가 많이 들어오고 뉴스레터 정리가 꺼져 있으면, 할 일 위에 새로 받은 뉴스레터 수와 처리 방법을 보여 주는 안내가 나타나요. 일주일 동안 5명 이상의 발신자에게서 25개 이상 받은 경우예요. 여기서 **켜기** 또는 **아니요, 괜찮아요**를 선택할 수 있어요.

일주일 동안 직접 스팸으로 옮긴 이메일이 5개 이상이면 스팸 정리도 같은 방식으로 안내돼요. **켜기**를 누르면 여기서 **추가**를 누를 때처럼 템플릿이 추가돼요. **아니요, 괜찮아요**를 누르면 다시 제안하지 않아요. 이전에 사용한 템플릿은 다시 제안하지 않아요.

**뉴스레터 정리**는 업무와 개인 영역별로 할 일 하나를 만들어요. 지난 하루 동안 받은 뉴스레터가 표시되고, 각 이메일마다 **유지** 또는 **구독 취소**를 선택할 수 있어요. 구독 취소는 목록의 원클릭 링크를 사용하거나, 메일 전송이 켜져 있으면 내 주소에서 구독 취소 이메일을 보내요. 그 외에는 Machine이 자체 브라우저에서 목록 페이지를 열어 구독을 취소해요. 페이지에서 로그인이 필요하거나, 보안 문자를 입력하거나, 선택해야 할 항목이 있으면 직접 처리해야 해요. 해당 행에 이유와 함께 **수신 거부 페이지 열기**가 표시돼요.

영수증, 주문 내역, 결제 알림은 제외돼요. Google Group 같은 그룹 주소로 온 이메일은 작성자 이름 아래 표시되며, 그룹 구독을 취소하지 않아요. 발신자가 직접 제공하는 구독 취소 방법이 없으면 해당 행에 **직접 구독 취소**가 표시돼요.

**스팸 정리**는 알 수 없는 발신자가 보낸 스팸처럼 보이는 이메일을 영역별로 모아 할 일 하나를 만들어요. 각 이메일마다 **스팸** 또는 **스팸 아님**을 선택할 수 있어요. Outlook에서는 스팸이 정크 메일로 이동하고, Gmail에서는 스팸으로 표시돼요. 매시간 확인하므로 보통 스팸이 들어오면 바로 표시돼요. 할 일이 열려 있는 동안 새 스팸이 들어오면 같은 할 일에 추가돼요.

호스팅된 Machine처럼 읽기 전용으로 연결된 Gmail에서는 이메일을 스팸으로 이동할 수 없어요. 이 경우 **스팸**을 누르면 Gmail에서 스팸으로 표시할 수 있는 링크가 제공되고, Machine은 해당 발신자를 스팸으로 기억해요. 메일 계정이 연결되어 있지 않으면 템플릿에서 **추가** 대신 **메일 연결**이 표시돼요.

알 수 없는 발신자란 한 번도 이메일을 주고받지 않은 발신자를 뜻해요. 제목에 “Re:”가 있어도 내가 참여한 대화만 대화로 간주해요. 할 일에서든 메일함에서든 스팸으로 표시한 발신자의 이메일이 다시 도착하면 다음 할 일에 **이전에 스팸으로 표시했어요**라고 표시돼요. 직접 스팸으로 옮긴 이메일도 비슷한 이메일을 찾아내는 데 도움이 돼요.

할 일에서 확인하기 전까지는 아무것도 바뀌지 않아요. 발신자를 눌러 이메일을 먼저 읽어도 읽지 않은 상태로 유지되고 아무것도 바뀌지 않아요. 스팸 정리에서는 웹에서 가져오는 이미지가 로드되지 않으므로 발신자가 이메일이 열렸다는 사실을 알 수 없어요. 이미 결정한 발신자에 대해서는 다시 묻지 않아요. 뉴스레터나 스팸이 없는 날에는 할 일이 만들어지지 않으며, 이 할 일은 알림을 보내지 않아요.

모든 발신자에 대해 결정을 내리면 할 일에 완료되었다고 표시되고 **완료**가 나타나요.

**일일 요약**은 하루에 한 번, 시간을 들여 볼 만한 뉴스레터 몇 개를 할 일 하나로 모아 줘요. 각 항목에는 나에게 중요한 이유가 한 줄로 표시돼요. 항목을 눌러 이메일을 읽거나 **메일에서 열기**를 사용하세요. 뉴스레터만 포함돼요. 사람에게서 온 이메일, 영수증, 구독을 취소한 발신자의 이메일은 포함되지 않으며, 이미 읽은 이메일도 포함되지 않아요. 눈에 띄는 항목이 없으면 할 일이 만들어지지 않아요.

열어 보거나 별표 표시하거나 읽지 않은 채 보관한 항목, 그리고 각 추천 항목에서 **이런 항목 더 보기** 또는 **이런 항목 줄이기**를 선택한 내역을 바탕으로 관심사를 파악해요. 추천 주제는 루틴 카드의 **더 많은**과 **줄이기** 아래에 표시돼요. ×를 눌러 주제를 삭제하거나 직접 추가할 수 있어요. 점선으로 표시된 주제는 Machine이 알아낸 항목이에요. 새 요약이 만들어지면 열려 있는 요약을 대체하며, 알림은 보내지 않아요.

각각의 새 뉴스레터에서 발신자, 제목, 앞부분만 읽고, 매일 정해진 한도 내에서 AI에게 뉴스레터에 대한 짧은 질문 하나를 해요. 비용을 낮게 유지하기 위해서예요. **시점 변경**을 누르면 실행 시각을 설정할 수 있어요. 실행 내용을 바꾸면 다른 루틴처럼 내가 지정한 내용으로 실행돼요.

**생일**은 오늘 생일인 가까운 지인마다 할 일 하나를 만들어요. 친구, 가족, 자주 연락하는 사람처럼 직접 이메일을 주고받는 사람이 대상이에요. 평소 대화하는 곳에 해당 언어로 작성한 짧은 인사말 초안이 함께 제공돼요. 예를 들어 WhatsApp 채팅이나 이메일 대화에 초안이 만들어져요. 직접 보내기 전까지는 전송되지 않아요. 생일인 사람이 없는 날에는 할 일이 만들어지지 않아요.

생일 정보는 캘린더에서 가져와요. Google의 생일 일정과 생일 캘린더는 동기화되지 않았더라도 매일 아침 확인하고, Outlook의 생일 캘린더도 확인해요. 자체 호스팅 Machine에서는 Google 연락처와 Graph에 있는 사람의 Birthday라는 날짜 필드도 확인해요. 어디에도 생일 정보가 없으면 결과에 **아직 생일 정보가 없어요**라고 표시하고, 정보를 추가하는 방법을 안내해요.

**Facebook에서 생일 가져오기**: 생일을 켜면 할 일에서 Facebook의 생일 페이지를 읽을지 물어봐요. **가져오기**를 누르면 Machine이 자체 브라우저에서 해당 페이지를 열고, 모든 달의 내용이 로드될 때까지 스크롤한 뒤 친구의 이름과 생일을 읽어요. 찾은 생일 수와 Graph에서 이름과 성이 일치한 사람을 보여 줘요. 같은 이름을 가진 사람이 여러 명이면 건너뛰고 목록에 표시해요.

**저장**을 눌러야 각 사람의 페이지에 생일 정보가 저장돼요. 사진이 없는 사람에게는 Facebook 프로필 사진도 저장돼요. 직접 설정한 생일이나 사진은 그대로 유지되고, 이미 사진이 있는 사람의 사진은 바뀌지 않아요. Facebook에는 아무것도 기록되지 않아요.

자동으로 다시 읽지는 않아요. 할 일에서 **다시 가져오기**를 눌러야 해요. 브라우저에서 Facebook에 로그인한 상태여야 해요. 로그인하지 않았다면 할 일에서 **Facebook에 로그인**을 누르고 로그인하세요. 로그인하면 페이지를 자동으로 읽어요. Machine이 대신 로그인하지는 않아요.

Graph에 등록되지 않은 친구도 수와 이름 일부가 표시돼요. **…을 개인 연락처로 추가**를 누르면 저장한 뒤에도 친구를 한꺼번에 추가할 수 있어요. 이름과 생일이 저장되며, Work Fleet과는 공유되지 않아요. Graph에 이미 같은 이름을 가진 사람이 있거나 영구 삭제한 사람이 같은 이름을 갖고 있으면 건너뛰어요. 생일 알림은 여전히 직접 연락하는 사람에게만 제공돼요.

할 일에서 **실행 취소**를 누르면 가져온 사람만 정확히 삭제돼요. **다시 가져오기**를 한 뒤에도 마찬가지예요.

**구독 및 체험**은 한 달에 한 번 영수증, 청구서, 갱신 알림을 확인하고 구독 정보를 할 일 하나에 모아요. 각 구독의 비용, 다음 결제일, 체험 종료나 가격 인상 여부가 표시돼요. 확실한 구독만 목록에 표시돼요. 찾은 항목이 없으면 할 일이 만들어지지 않아요.

각 항목마다 **유지** 또는 **취소하기**를 선택하세요. 유지한 구독은 가격이 바뀌지 않는 한 다시 묻지 않아요. **취소하기**를 누르면 취소 페이지를 열거나 취소 요청 초안을 만들어요. 직접 보내기 전까지는 전송되지 않아요. 실행 사이에는 매일 확인하며, 체험이나 구독 결제가 7일 이내로 다가오면 할 일을 만들어요.

**연락 유지**는 가까운 사람에게 연락할 만한 실제 이유가 있을 때 가끔 알려 줘요. 카드의 짧은 목록에서 직접 양방향으로 몇 달간 연락을 주고받은 사람을 선택하세요. ×를 눌러 사람을 삭제할 수 있어요.

평소보다 훨씬 오래 연락하지 않았고 전할 만한 구체적인 내용이 있을 때만 알림을 보내요. 예를 들어 그 사람이 전한 소식, 아직 지키지 않은 약속, 답하지 않은 메시지가 있을 때예요. 이유와 함께 할 일 하나를 만들고, 평소 대화하는 곳에 해당 언어로 짧은 메시지 초안을 작성해요. 직접 보내기 전까지는 전송되지 않아요. 전할 내용이 없으면 할 일이 만들어지지 않아요.

일주일에 최대 두 번, 한 사람에게는 한 달에 한 번만 알림을 보내며 최근에 연락한 사람에게는 보내지 않아요. 알림에서 **필요 없음**을 누르면 해당 사람에게 다시 알리기까지 더 오래 기다려요. 누를 때마다 기다리는 기간이 길어져요. 알림은 보내지 않으며 Personal에만 남아요. Work Fleet과는 공유되지 않아요.

**중고 물품 찾기**는 Marktplaats, Vinted, eBay 또는 Facebook Marketplace 같은 중고 거래 사이트에서 검색을 추적해요. 원하는 필터를 설정해 사이트에서 검색한 다음, 검색 결과 주소를 복사해 **추가**를 누른 뒤 붙여 넣으세요. 원하면 "300 미만, 30km 이내, ‘부품용’ 제외"처럼 원하는 필터를 직접 추가할 수도 있어요. 검색마다 별도의 루틴이므로 다른 검색을 추가하려면 다시 추가하세요.

3시간마다 Machine의 자체 브라우저에서 검색을 열어 아직 보지 않은 매물을 찾아요. 가격, 거리, 제외한 단어는 먼저 간단한 코드로 확인해요.

조건에 맞는 새 매물은 하나씩 열어 AI가 사진과 설명을 바탕으로 상태를 판단하고, 판매자의 리뷰, 평점, 계정 생성 시점을 바탕으로 판매자를 평가해요. 괜찮은 매물은 사진, 제목, 가격, 한 줄 평가와 함께 할 일 하나에 모여요. 매물을 누르면 Machine의 브라우저에서 해당 페이지가 열려요.

할 일이 열려 있는 동안 새 매물이 발견되면 맨 위에 추가되고, 매물 수가 늘어나며 다시 알림을 보내요. 괜찮은 거래는 금방 끝날 수 있기 때문이에요. 완료하면 다음에 찾은 매물은 새 할 일에 담겨요. 괜찮은 매물이 없는 실행은 아무것도 바꾸지 않아요.

부담을 줄이고 비용을 낮게 유지해요. 실행마다 검색은 한 번만 읽고, 매물은 최대 6개까지 열어 보며, 매물 사이에 잠시 기다려요. 모든 검색을 통틀어 하루에 최대 40개까지 확인해요. 각 확인은 AI에게 사진 한 장과 함께 짧은 질문 하나를 하는 방식이에요. 처음 실행할 때는 최신 매물 몇 개를 확인하고 나머지는 이미 본 것으로 처리하므로, 다음 실행부터 새 매물만 확인해요.

사이트에서 로그인을 요청하거나, 로봇 확인을 표시하거나, 읽기를 차단하면 할 일에 안내가 표시되고 **열기**를 눌러 Machine의 브라우저에서 확인할 수 있어요. 직접 로그인하거나 확인 절차를 완료하면 다음 실행 때 다시 읽어요. Machine은 대신 로그인하거나 확인 절차를 해결하지 않으며, 판매자에게 연락하거나 입찰하거나 구매하지도 않아요.

루틴 카드에서 **검색 조건 변경**을 누르면 주소나 필터를 새로 설정할 수 있고, **시점 변경**을 누르면 "6시간마다"처럼 일정을 바꿀 수 있어요.

템플릿의 루틴은 템플릿 내용을 그대로 유지하는 동안 내 AI 요금제를 사용하지 않고 자체 코드로 실행돼요. 스팸 정리는 먼저 새 이메일 중 알 수 없는 발신자가 보낸 이메일을 코드로 골라내고, 해당 이메일이 있을 때만 AI에게 짧은 질문 하나를 해요. 연락 유지는 선택된 한두 사람에 대해서만 질문해요. 이름을 바꿔도 이 방식은 유지돼요. 내용을 바꾸면 다른 루틴처럼 내가 지정한 내용으로 실행돼요.

뉴스레터 정리와 스팸 정리는 계속 이메일별 선택 항목이 있는 동일한 할 일로 처리돼요. 생일 내용을 수정하면 결과와 초안이 최대 하나만 제공되며, 사람마다 할 일이 따로 만들어지지 않아요. **수정**에서 **템플릿으로 돌아가기**를 누르면 원래 템플릿 내용으로 되돌아가요.

## 루틴 작동 방식

설정한 시각에 Machine은 메시지, 일정, Graph처럼 필요한 내용을 읽고 결과를 루틴 페이지에 표시해요. 결과는 **준비 완료**, **새로운 항목이 없어요**(이유 포함) 또는 **작동하지 않았어요**(이유 포함)로 표시돼요. 결과 없이 끝난 실행은 완료가 아니라 실패한 실행으로 처리돼요.

루틴은 읽기만 해요. 메시지, 웹페이지, GitHub, 브라우저의 X 같은 사이트를 읽어요. 전송, 답장, 게시를 하거나 무엇이든 변경하지 않아요. 메일을 변경하는 것은 템플릿뿐이며, 할 일에서 직접 확인한 항목만 변경해요.

루틴 작업이 게시물이나 메시지 작성으로 끝나는 경우, 해당 단계까지 실행한 뒤 **X에 게시할 내용:** 같은 형식으로 초안을 보여 줘요. 실제 실행 후에는 승인할 수 있도록 할 일로 제공되고, 테스트 실행에서는 결과만 표시돼요. 이름에는 작업 내용과 게시 위치가 표시되고, 버튼에는 **게시하기**처럼 실행할 단계가 표시돼요. 아래의 **루틴에서 가져옴**을 누르면 루틴을 열 수 있어요.

할 일은 게시물을 보낼 계정 영역에 표시돼요. 예를 들어 회사의 X 계정으로 게시하는 경우 업무 영역에 표시되므로 다른 영역으로 옮기라는 안내가 나오지 않아요.

루틴은 실행 내용에 맞는 사용 설정된 [스킬](skills.md)을 선택해 따를 수 있어요. 해당하는 스킬만 전체 내용을 읽어요. 사용한 스킬은 결과의 **사용한 항목:** 아래에 표시돼요. 스킬이 루틴을 통해 무언가를 보내거나 변경하는 일은 없어요.

루틴은 제안 아래의 **루틴**에 표시돼요. 긴 결과는 짧은 미리보기로 접혀요. **더 보기**를 누르거나 결과를 탭하면 전체 내용을 볼 수 있어요.

각 실행은 이전 결과를 알고 있으므로 그 이후에 바뀐 점을 알려 줄 수 있어요.

실행이 잘 끝나면 Machine이 매번 같은 방식으로 읽는 작업을 위한 레시피를 직접 만들 수 있어요. 예를 들면 확인할 이메일이나 GitHub 변경 사항을 지정하는 식이에요. 다음 실행부터는 먼저 간단한 코드로 해당 내용을 읽고, AI는 중요한 항목을 골라 작성하는 데만 사용되므로 토큰을 줄일 수 있어요. 레시피는 읽기만 해요. 작동하지 않으면 실행이 자동으로 읽기를 진행해 문제를 해결해요. ⋯ 메뉴의 **고급: 스크립트 단계** 아래에 표시돼요.

## 놓친 날

Machine이 꺼져 있거나 바빠서 실행을 놓쳐도 실행이 쌓이지 않아요. 가장 최근 실행 하나만 한 번 진행돼요. 재시작한 뒤에도 날짜별로 한 번씩만 실행돼요.

루틴은 한 번에 하나씩 실행되고, 백그라운드 작업과 마찬가지로 AI 요금제 사용량이 부족하면 기다려요. **지금 실행**을 누르면 바로 실행돼요. 결과가 준비되면 카드에 표시돼요.

## 변경 또는 중지

루틴의 ⋯ 메뉴에서 설정할 수 있어요. **수정**을 누르면 이름과 실행 내용을 바꿀 수 있어요. 실행 일정과 이전 결과는 그대로 유지돼요. **시점 변경**을 누르면 "평일마다 8시에"처럼 원하는 말로 일정을 설정할 수 있어요. 두 설정 모두 **저장**과 **취소** 버튼이 있어요. 컴퓨터에서는 Esc 키를 누르거나 바깥을 클릭해도 취소돼요.

**수정**에서 **사용해 보기**를 누르면 새 내용으로 한 번 실행하고 결과를 표시해요. **저장**하기 전까지 루틴은 기존 설정을 유지해요.

**일시 정지**를 누르면 카드에서 **재개**할 때까지 실행이 멈춰요. 일시 정지된 루틴은 루틴 아래의 **일시 정지됨**에 표시되며, 일시 정지 중 놓친 실행은 나중에 진행되지 않아요. **중지**를 누르면 루틴이 완전히 종료돼요.

일시 정지된 루틴을 포함해 최대 20개까지 만들 수 있어요. 새 루틴을 추가하려면 기존 루틴을 중지하세요.

루틴의 할 일에서 **수정 요청**을 사용하거나 채팅에 모든 실행에 적용할 내용을 적으면, 예를 들어 "이모지를 절대 사용하지 마"라고 적으면 할 일과 채팅의 답변 아래에 **루틴도 변경**이 표시돼요. 루틴 내용 중 바뀌는 부분을 보여 주며, **변경**을 눌러야 루틴이 변경돼요. **그대로 유지**를 누르면 변경하지 않아요. 현재 초안만 수정하는 경우에는 이 옵션이 표시되지 않아요.

## 고급: 스크립트 단계

스크립트는 없어도 돼요. 루틴이 할 일을 평소 말로 설명하면 Machine이 나머지를 처리해요.

고급 사용자는 Machine에서 직접 명령을 실행하는 루틴도 만들 수 있어요. ⋯ 메뉴에서 **고급: 스크립트 단계**를 선택하세요. 루틴에 스크립트 단계가 있을 때만 **수정**을 눌러 확인할 수 있어요. **데이터 가져오기**를 누르면 먼저 명령을 실행해요. 명령은 지정된 폴더에서 실행되고, 폴더를 지정하지 않으면 홈 폴더에서 실행돼요. 실행 시간은 설정한 초를 넘지 않아요. 명령이 출력한 내용은 루틴이 처리할 수 있도록 전달돼요. 실행 내용이 비어 있으면 출력 결과가 그대로 표시돼요.

**확인**은 실행 후 결과를 입력으로 받아요. 오류로 종료되면 확인 단계에서 반환한 내용과 함께 **작동하지 않았어요**가 표시돼요. 데이터 가져오기 명령이 실패해도 같은 방식으로 표시돼요.

명령은 셸 없이 한 줄씩 실행돼요. 파이프나 변수는 사용할 수 없어요. 스크립트 단계는 직접 설정하는 것으로, 대시보드에만 설정돼요. 테스트 실행과 **사용해 보기**에서도 데이터 가져오기가 실행되며, 실행된다는 안내가 표시돼요. 그래도 아무것도 보내거나 저장하지 않아요. 루틴은 아무것도 보내지 않으므로 스크립트 단계는 읽기만 해야 해요.

## OpenClaw 작업에서 가져오기

이전에 OpenClaw에서 예약 작업을 만든 적이 있으면 Machine이 해당 작업을 읽고, 적합한 작업을 **추천됨** 아래의 루틴으로 제안해요. 기존 작업은 변경하지 않아요. 각 작업은 한 번 실행되므로 실제 결과도 확인할 수 있어요.

작업에 대한 수정 사항은 유지하고, 작업에서 전송하거나 게시한 내용은 제외해요. 스크립트를 실행했거나 스크립트 작업에서 수집한 내용을 읽는 작업은 스크립트를 데이터 가져오기로 가져와요. **추가**를 누르면 루틴으로 만들고, **아니요, 괜찮아요**를 누르면 해당 작업을 다시 제안하지 않아요. 무언가를 하도록 알려 주는 작업은 할 일 페이지에서 반복 할 일로 제안돼요.

제안을 추가하기 전에 ⋯ 메뉴에서 **수정**과 **시점 변경**을 사용해 다른 루틴처럼 내용을 바꿀 수 있어요. **다시 실행**을 누르면 현재 내용으로 실행해 최신 결과를 확인할 수 있어요. 예를 들어 조용했던 주말이 지난 뒤에 실행할 수 있어요. 읽기만 하고 탭할 때마다 한 번씩 실행되며, 새 결과가 이전 결과를 대체해요.

제안은 한 번에 최대 3개까지 표시돼요. 루틴이 일주일 동안 문제없이 실행되면 **기존 OpenClaw 작업을 끌까요?**라고 물어봐요. **끄기**를 눌러야 기존 작업이 꺼지고, OpenClaw에서 다시 켤 수 있어요. **유지**를 누르면 두 작업 모두 계속 실행돼요.

## 내가 하는 작업에서 찾기

OpenClaw를 사용하지 않아도 Machine은 반복해서 하는 작업을 찾아 **추천됨** 아래의 루틴으로 제안해요. 다음과 같은 작업을 살펴봐요.

- 같은 요청을 연달아 세 번 이상 한 경우. 예: 매주 월요일마다 "열린 지원 티켓 요약해 줘"라고 요청하는 경우
- 주기적으로 보내는 이메일. 예: 팀에 매주 보내는 보고서
- 매주 계속 들어오는 뉴스레터와 업데이트 이메일
- 다른 사람들도 매주 글을 올리는 활발한 Slack 채널
- 같은 사람에게 이메일을 하나씩 전달하는 경우. 예: 학교와 동아리 이메일을 파트너에게 보내는 경우. 주간 요약을 보내면 매번 전달하지 않아도 돼요.
- 같은 요청에 주기적으로 답하는 경우. 예: 매달 같은 사람의 요청을 승인하는 경우

제안마다 확인한 내용을 표시해요. 예를 들어 "연달아 4번 요청함" 또는 "3주 동안 Sam에게 이메일 6개 전달함"이라고 표시돼요. 한 번 실행해 실제 결과도 보여 줘요. 팀 업무 요약, 주간 통화 전 브리핑, 지원 또는 개발 요약, 주요 수치 현황, 받은 뉴스레터 요약 등을 생각해 볼 수 있어요.

나에게만 해당하고 분명히 유용한 항목만 제안해요. 예를 들어 뉴스 요약은 내가 구독한 뉴스레터만 대상으로 하며 일반적인 뉴스 요약은 제안하지 않아요. 적합한 작업이 없으면 제안하지 않아요.

하루에 한 번까지만 확인하고, 알림 없이 일주일에 새 제안 하나까지만 보여 줘요. **아니요, 괜찮아요**를 누르면 해당 제안은 다시 표시되지 않아요. 전달한 이메일과 답장은 보낸 계정에 남으므로 업무와 개인 영역이 섞이지 않아요. 모든 내용은 Machine에만 남아요. 주기적으로 완료하는 할 일은 대신 반복 할 일로 제안돼요.

## 루틴과 반복 할 일

[반복 할 일](recurring.md)은 무언가를 하도록 알려 줘요. 루틴은 Machine이 알아서 작업을 하고 결과를 보여 줘요. "매달 1일에 월세 내기"에는 반복 할 일을, "매주 금요일에 조용해진 거래를 알려 줘"에는 루틴을 사용하세요.
