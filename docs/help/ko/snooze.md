## 할 일 미루기

할 일에서 **미루기**를 누르세요. 메뉴에 2시간 후, 내일, 일주일 후처럼 몇 가지 시간이 표시돼요. 다른 시간으로 미루려면 **날짜 선택**과 **시간**을 선택한 다음 **시간 저장**을 누르세요. 실수로 미뤘나요? 메시지에서 **실행 취소**를 누르면 바로 되돌릴 수 있어요.

하루 이상 미룬 할 일은 "미룬 할 일이 표시되는 시간"에 다시 표시되고, 업무 관련 할 일은 근무일까지 기다려요. [근무 시간](work-hours.md)에서 두 항목을 설정하세요.

또는 **수정 요청**에 "다음 주 화요일에 이 할 일을 다시 알려줘"처럼 입력하세요.

## 다시 표시될 때

알림이 켜져 있는 각 기기와 Telegram을 사용하는 경우 Telegram으로 알림이 와요. [알림](notifications.md)에서 **알림**을 허용해야 해요. 미루기 메시지에 어디에 표시되는지 안내돼요. 알림을 받을 곳이 하나도 없다면 대시보드에 다시 표시되고, 바로 옆에 **알림 켜기**가 표시돼요. iPhone과 iPad에서 알림을 받으려면 [모바일 앱 다운로드](mobile-app.md)를 이용하세요.

The Machine이 이미 완료한 할 일은 이전 상태로 다시 표시돼요. 미뤄 둔 동안 새 내용이 들어온 경우에만 다시 작업해요.

## 미뤄 둔 동안

할 일은 **나중에 다시 돌아와요** 아래에 표시되고, [캘린더](calendar.md)에서 해당 날짜에도 표시돼요. **미루기 해제**를 누르면 지금 다시 표시되고, **시간 변경**을 선택하면 다른 시간으로 미뤄져요.

Outlook에서는 할 일이 다시 표시될 때까지 이메일 대화가 미룬 편지함으로 이동해요. [Microsoft](microsoft.md)를 참고하세요.
