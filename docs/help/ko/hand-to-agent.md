## 할 일 넘기기

1. 할 일에서 **…**을 열고 **넘기기…**를 누른 다음 **Codex** 또는 **Claude Code**를 선택해요. 설정한 도구만 표시돼요.
2. 요약과 전달할 내용을 확인하고, 원하면 메모를 추가한 다음 **넘기기**를 눌러요. **전체 작업 보기**에서 전체 요청 내용을 확인할 수 있어요.

할 일에 진행 중이라고 표시된 다음, **수행한 작업**과 **변경 사항 보기**를 통해 결과를 확인할 수 있어요. **수정 요청**을 누르면 변경할 내용을 전달해요. **…**에서 **넘기기…**를 누르면 다시 시작해요. **숨기기**를 누르면 결과가 숨겨져요. 멈춘 할 일을 넘기면 작업이 진행되는 동안 **멈춤** 대신 **작업 중…**이 표시돼요.

작업이 대신 무언가를 전송하는 일은 없어요. 게시나 배포 단계가 남으면 할 일에서 **실행**을 눌러 해당 단계를 진행해요. 작업이 작성한 답장은 직접 보내도록 초안으로 남아요.

## Codex 앱에서

- 작업이 끝나면 **Codex에서 열기**를 눌러 Codex 앱에서 작업 스레드를 열 수 있어요.
- **수정 요청**을 누르면 같은 Codex 대화에서 이어지고, 할 일도 그 대화를 따라가요.
- 진행이 30분 동안 없거나 총 6시간이 지나면 작업이 중단돼요. 다시 시작해도 작업은 중단되지 않아요.

## 설정하기

**설정**의 **모델**에서 **Codex 및 Claude Code** 항목을 확인해요.

- **Codex**: 실행 위치예요. 내 Machine이나 컴퓨터에서 실행하는 경우 여기서 더 설정할 필요가 없어요. **변경**을 누르면 설정 페이지가 열려요.
- **Codex 클라우드**: Codex에서 확인한 환경 ID와, 원하는 경우 시작할 **브랜치**를 입력해요.
- **Claude Code**: Claude Code 세션 링크예요.

Claude는 The Machine 커넥터를 통해 결과를 보내요. claude.ai에서 한 번만 설정하면 돼요. 세션 아래에 표시된 주소를 사용해 **설정**, **커넥터**, **사용자 지정 커넥터 추가**로 이동해요.

## Codex 실행 위치

호스팅된 Machine에서는 설정 페이지의 **언제든 더 추가** 아래에 있는 **Codex**에서 실행 위치를 선택해요.

- **내 Machine에서**(기본값): **Codex 연결**을 누르고 OpenAI에 표시되는 코드를 입력해요. 모델과 같은 ChatGPT 요금제를 사용하고, 작업은 내 Machine에서 실행돼요. 터미널은 필요하지 않아요. 같은 ChatGPT 계정으로 로그인하면 내 Machine에서 사용량 한도 초기화 정보도 확인하고 활용할 수 있어요.
- **다른 방법**, **내 컴퓨터에서**: Codex에 로그인한 내 컴퓨터에서 작업이 실행돼요. 암호화되어 전송되며 해당 컴퓨터에서만 사용할 수 있어요. 그 컴퓨터에 The Machine을 설치하고, 계정 페이지에서 페어링한 다음 `codex login`을 실행하고 The Machine을 계속 켜 둬요. 결과는 할 일에 돌아와요. 컴퓨터가 꺼져 있으면 작업은 대기해요.
- **다른 방법**, **Codex 클라우드**: OpenAI 클라우드에서 작업이 실행돼요. **Codex 연결**을 누르면 모델과 같은 ChatGPT 요금제를 사용해요. OpenAI에서 Codex용 코드를 하나 더 요청해요. 그런 다음 설정에서 Codex 클라우드 환경을 입력해요.

대시보드에서 로그인할 수도 있어요. **연결**에서 **프로젝트 및 코드**, **Codex**, **코드 받기**를 차례로 선택해요. 자체 호스팅 Machine에서는 같은 로그인을 직접 진행해요.

호스팅된 Machine에서는 GitHub 또는 Codex를 연결하면 설정에 **Codex 및 Claude Code**가 표시돼요. 개발자라면 [에이전트 가이드](https://github.com/Salesflare/TheMachine/blob/main/docs/agents.md)를 참고하세요.
