## 할 일을 넘기기

1. 할 일에서 **…**를 연 다음 **넘기기…**를 선택하고 **Codex** 또는 **Claude Code**를 골라요. 설정한 도구만 표시돼요.
2. 요약과 전달할 내용을 확인하고, 원하면 메모를 추가한 다음 **넘기기**를 눌러요. **전체 작업 보기**를 누르면 전체 요청 내용을 볼 수 있어요.

할 일에 작업 중 상태가 표시된 다음 결과가 표시되고, **수행한 작업**과 **변경 사항 보기**를 확인할 수 있어요. **수정 요청**을 누르면 바꿀 내용을 전달해요. **…**에서 **넘기기…**를 선택하면 처음부터 다시 시작해요. **숨기기**를 누르면 결과가 사라져요. 멈춘 할 일을 넘기면 작업이 진행되는 동안 **멈춤** 대신 **작업 중…**이 표시돼요.

작업이 대신 무언가를 전송하는 일은 없어요. 게시 또는 배포 단계를 직접 해야 하는 경우, 할 일에서 **실행**을 누르면 해당 단계를 진행해요. 작성된 답장은 직접 보내도록 초안으로 남아요.

## Codex 앱에서

- 작업이 끝나면 **Codex에서 열기**를 눌러 Codex 앱에서 작업 대화를 열 수 있어요.
- **수정 요청**을 누르면 같은 Codex 대화에서 작업이 이어지고, 할 일에도 반영돼요.
- 진행이 30분 동안 없거나 총 6시간이 지나면 작업이 중단돼요. 다시 시작해도 작업은 중단되지 않아요.

## 설정하기

**설정**의 **모델**에서 **Codex 및 Claude Code** 항목을 확인해요.

- **Codex**: 실행 위치예요. The Machine 또는 컴퓨터에서 실행하는 경우 여기서 더 설정할 필요가 없어요. **변경**을 누르면 설정 페이지가 열려요.
- **Codex 클라우드**: Codex에서 확인할 수 있는 환경 ID예요. 선택 사항으로 시작할 **브랜치**를 지정할 수도 있어요.
- **Claude Code**: Claude Code 세션 링크예요.

Claude는 The Machine 커넥터를 통해 결과를 돌려보내요. claude.ai에서 한 번 추가해 주세요. 설정에서 커넥터로 이동해 맞춤 커넥터 추가를 선택한 다음 세션 아래에 표시된 주소를 입력하면 돼요.

## Codex 실행 위치

호스팅된 Machine에서는 설정 페이지의 **언제든 더 추가** 아래에서 **Codex**를 선택해요.

- **The Machine에서**(기본값): **Codex 연결**을 누르고 OpenAI에 표시되는 코드를 입력해요. 모델과 같은 ChatGPT 요금제를 사용하고, 작업은 The Machine에서 실행돼요. 터미널은 필요하지 않아요.
- **다른 방법**, **내 컴퓨터에서**: 작업은 Codex에 로그인한 내 컴퓨터에서 실행돼요. 해당 컴퓨터에서만 사용할 수 있도록 암호화되어 전송돼요. 그곳에 The Machine을 설치하고 계정 페이지에서 연결한 다음 `codex login`을 실행하고 The Machine을 켜 두세요. 결과는 할 일에 표시돼요. 컴퓨터가 꺼져 있으면 작업은 대기해요.
- **다른 방법**, **Codex 클라우드**: 작업은 OpenAI 클라우드에서 실행돼요. **Codex 연결**을 누르세요. 모델과 같은 ChatGPT 요금제를 사용하고, OpenAI에서 Codex용 코드를 하나 더 요청해요. 그런 다음 설정에서 Codex 클라우드 환경을 입력해요.

대시보드에서 로그인할 수도 있어요. **연결**, **프로젝트 및 코드**, **Codex**, **코드 받기** 순으로 선택해요. 자체 호스팅하는 Machine에서는 같은 로그인 절차를 직접 진행해요.

호스팅된 Machine에서는 GitHub 또는 Codex를 연결하면 설정에 **Codex 및 Claude Code**가 표시돼요. 개발자라면 [에이전트 가이드](https://github.com/Salesflare/TheMachine/blob/main/docs/agents.md)를 참고하세요.
