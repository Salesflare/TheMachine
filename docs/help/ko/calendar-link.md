## 읽어오는 정보

링크에 연결된 캘린더의 일정과 반복 일정, 시간대 정보를 읽어와요. 지난 일주일과 다음 한 달의 일정을 가져온 뒤 변경 사항을 반영해요. 일정은 Calendar와 회의 준비에 표시돼요.

링크는 읽기 전용이라 일정을 변경하지 않아요. 최대 15분마다 링크를 확인해요. Proton에 따르면 링크에 변경 사항이 반영되기까지 몇 시간이 걸릴 수 있어요.

## Proton Calendar 연결

Proton Calendar는 앱에서 연결할 다른 방법이 없어서 공유 링크를 사용해요.

1. 웹에서 calendar.proton.me로 Proton Calendar를 열어요. 휴대폰 앱에서는 공유 링크를 만들 수 없어요.
2. "설정", "모든 설정", "캘린더"로 이동한 다음 캘린더를 선택해요.
3. "누구나와 공유"에서 "링크 만들기"를 누르고 "전체 보기"를 선택해요. 제한된 보기는 바쁜 시간만 표시해요.
4. "링크 복사"를 눌러요.
5. 대시보드에서 **연결**을 연 다음 **캘린더**를 선택하고 **Proton Calendar**를 골라 링크를 붙여넣은 뒤 **연결**을 눌러요.

## 다른 캘린더 링크 연결

**캘린더 링크(ICS)**를 선택하고 링크를 붙여넣어요. iCloud 공개 캘린더, Outlook 게시 캘린더, 자녀의 학교 캘린더처럼 .ics로 끝나는 https 또는 webcal 주소를 사용할 수 있어요.

## 링크 비공개로 유지하기

링크가 있는 사람은 누구나 캘린더를 볼 수 있어요. The Machine은 링크를 비밀번호처럼 취급해요. 로그나 화면에 표시하지 않아요. 연결을 중지하려면 링크를 만든 곳에서 링크를 삭제한 다음 여기서 **연결 해제**를 눌러요.

## 연결이 중단되는 경우

- **캘린더 링크가 작동하지 않아요**: 링크가 삭제되었거나 변경되었어요. 새 링크를 만든 다음 다시 연결해요.
- **캘린더 서버에 연결할 수 없어요**: 자동으로 다시 시도해요.
