## 읽는 항목

Shortcut 워크스페이스에서 상태가 바뀌는 스토리와 담당자, 마감일을 읽어요.

## 할 수 있는 작업

아무 작업도 할 수 없어요. Shortcut 토큰으로 더 많은 작업을 할 수 있어도 읽기만 해요.

## 연결하기

1. 호스팅된 Machine에서는 app.themachine.computer/setup에서 설정 페이지를 열고, **더 많은 소스**로 이동해 Shortcut을 열어요. 개인 컴퓨터에서는 **연결**, **프로젝트 및 코드**, Shortcut을 선택하거나 `assistant connect shortcut`을 입력해요.
2. **토큰 받기**를 눌러요. Shortcut의 API 토큰 페이지가 새 탭에서 열려요. 토큰을 만든 다음 복사해요.
3. 토큰을 붙여 넣고 **연결**을 눌러요. 토큰을 바로 확인하고, 어떤 계정으로 어떤 워크스페이스에 연결됐는지 보여줘요.

Shortcut 워크스페이스가 여러 개인가요? 토큰은 한 워크스페이스에만 연결되므로, 먼저 Shortcut에서 해당 워크스페이스로 전환해요.

## 연결 해제하기

- 대시보드에서 **연결**을 선택하고 Shortcut을 연 다음 **세부 정보**, **연결 해제**를 선택해요. 이미 가져온 내용은 그대로 남아요.
- 호스팅된 Machine에서는 설정 페이지에서 Shortcut 옆의 **삭제**를 눌러도 돼요.

## Shortcut에서 토큰 취소하기

같은 API 토큰 페이지에서 토큰을 삭제해요.
