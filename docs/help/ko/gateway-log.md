## 읽는 내용

내 Machine 자체 로그예요. 실패한 실행, 거부된 인계, 전송되지 않은 Telegram 메시지, The Machine 자체 오류가 포함돼요. 수정이 필요하면 할 일로 알려 줘요. 내 컴퓨터에서는 **마지막 업데이트 설치 마무리하기**도 포함돼요. 업데이트의 한 부분은 밤에 짧게 재시작해야 하는데, 며칠 밤 동안 재시작하지 못했어요. 채팅에서 요청하면 The Machine이 마무리해요. 해당 부분이 설치되면 할 일은 자동으로 닫혀요.

## 업데이트에서 보류한 수정 사항

The Machine이 업데이트될 때 자체 수정 사항이 새 버전과 맞지 않으면, 업데이트는 해당 수정 사항을 보류하고 계속 진행해요. 그래서 내 Machine은 이전 버전에 머무르지 않아요. 할 일 **업데이트에서 보류한 수정 사항 다시 실행**에 수정 사항이 표시돼요.

**다시 실행**하면 내 Machine이 새 버전에서 수정 사항을 다시 만들어요. 자체 수정 사항을 적용할 때와 마찬가지로 변경 내용을 확인하고 **수정 병합**을 탭해요. 병합되면 이전 사본은 삭제돼요. 또는 할 일을 닫아도 돼요.

## 업데이트에서 보존한 파일

새 버전에 직접 추가한 파일과 이름이 같은 파일이 있으면, 업데이트는 직접 추가한 파일의 이름을 바꾸고 덮어쓰지 않은 채 계속 진행해요. 할 일에는 보존된 파일 수와 각 파일의 이전 이름과 새 이름이 표시돼요. 확인한 뒤 닫으세요.

## 할 수 있는 일

아무것도 없어요. 내 Machine의 로그만 읽어요.

## 연결하기

- 호스팅된 Machine에서는 설정 페이지의 **소스 더 보기** 아래에 Machine 상태로 표시돼요. Machine마다 하나씩 있어요.
- 내 컴퓨터에서는 **연결**, **기타**에서 Machine 상태를 선택하세요. 또는 `assistant connect gateway` 명령을 실행하세요.

## 삭제하기

- 대시보드에서 **연결**을 선택하고, 해당 항목을 연 다음 **세부 정보**에서 **연결 해제**를 선택하세요.
- 호스팅된 Machine에서는 설정 페이지에서 해당 항목 옆의 **삭제**를 눌러도 돼요.

다른 곳에서는 제거할 필요가 없어요.
