## 읽는 항목

Machine 자체 로그를 읽어요. 실패한 실행, 거부된 인계, 전송되지 않은 Telegram 메시지, The Machine 자체 오류가 포함돼요. 수정이 필요한 항목은 할 일로 알려줘요.

## 업데이트에서 보류한 수정 사항

The Machine이 업데이트될 때 자체 수정 사항이 새 버전과 맞지 않으면, 업데이트는 해당 수정 사항을 보류하고 계속 진행해요. 따라서 Machine은 이전 버전에 머무르지 않아요. 할 일인 **업데이트에서 보류한 수정 사항 다시 실행**에 수정 사항의 이름이 표시돼요.

**다시 실행**을 누르면 Machine이 새 버전에 맞게 수정 사항을 다시 만들어요. 다른 자체 수정 사항과 마찬가지로 변경 내용을 확인한 다음 **수정 사항 병합**을 눌러요. 병합하면 이전 복사본은 삭제돼요. 또는 할 일을 닫아도 돼요.

## 업데이트가 보존한 직접 추가한 파일

새 버전에 직접 추가한 파일과 이름이 같은 파일이 있으면, 업데이트는 직접 추가한 파일의 이름을 바꾸고 덮어쓰지 않은 채 계속 진행해요. 할 일에 보존된 파일 수와 각 파일의 이전 이름 및 새 이름이 표시돼요. 파일을 확인한 다음 할 일을 닫아 주세요.

## 할 수 있는 작업

아무것도 하지 않아요. 내 Machine의 로그를 읽기만 해요.

## 연결하기

- 호스팅된 Machine에서는 설정 페이지의 **More sources** 아래에서 Machine health를 찾을 수 있어요. Machine마다 하나씩 있어요.
- 내 컴퓨터에서는 `assistant connect gateway`을 실행해요.

## 삭제하기

- 대시보드에서 **연결**을 열고 **세부 정보**를 선택한 다음 **연결 해제**를 눌러요.
- 호스팅된 Machine에서는 설정 페이지에서 옆에 있는 **삭제**를 눌러도 돼요.

다른 곳에서 제거할 항목은 없어요.
