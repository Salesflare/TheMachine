## 표시되는 내용

**설정**에서 **활동**을 열어 보세요. 각 항목에는 The Machine이 처리한 작업 하나가 날짜별 최신순으로 표시돼요.

- 어떤 작업을 했고 어떻게 끝났는지: 전송, 거부, 실패 또는 실행 취소
- 작업한 시간, 사용한 계정이나 앱, [작업을 허용한 항목](activity.md#what-allowed-it)
- 연결된 할 일 링크. 해당하는 경우에만 표시돼요.
- ChatGPT나 Claude처럼 연결한 AI의 경우, The Machine 자체와 구분할 수 있도록 이름 뒤에 **(연결된 AI)**가 표시돼요.

메시지와 답장, 문서 및 캘린더 변경, 웹에서 한 작업, 병합한 수정 사항, 코딩 에이전트, Fleet 질문과 답변, The Machine 팀에 보낸 배운 점, 스킬, Graph 가져오기, 채팅에서 잊어 달라고 요청한 사실(**실행 취소** 가능), 추가하거나 삭제한 연결, [지원 액세스](get-support.md#support-access)를 통해 저희 팀이 조회한 기록이 모두 표시돼요. 거부된 조회 기록도 포함돼요.

## 작업을 허용한 항목

메시지, 문서나 캘린더 변경, 웹에서 한 작업, 병합한 수정 사항에는 작업 당시 무엇이 허용했는지 표시돼요.

- **할 일에서 승인됨** 또는 **Telegram에서 승인됨**: 보내기, 확인 또는 병합을 탭한 기록
- **음성으로 승인됨**: Talk에서 승인한 기록
- **실행을 탭함**: 할 일에서 **실행**을 탭한 기록
- **채팅에서 요청함**: 채팅으로 요청한 내용과 메시지 첫 부분이 인용문으로 표시돼요. 인용문은 해당 문구가 메시지에 남아 있는 동안에만 보여요.
- **후속 연락, 자동 전송**, **작은 수정 사항, 자동으로 병합됨**, **자동으로 만든 새 비공개 문서** 또는 **미리 자동으로 준비됨**: 설정 또는 The Machine 자체 규칙에 따른 작업
- **승인 기록 없음**: 승인 기록이 없어요. 누락된 경로를 찾을 수 있도록 [오류 보고서](error-reports.md)에도 기록돼요.

웹에서 한 작업에는 페이지에서 클릭하거나 입력한 할 일 실행도 표시되며, 해당 실행을 허용한 항목도 확인할 수 있어요.

기록이 남기기 시작되기 전에 생성된 이전 항목에는 **승인 후**처럼 예전 문구가 계속 표시돼요.

## 필터링

목록 맨 위에서 **메시지** 또는 **Fleet**처럼 종류를 선택하세요. **거부되었거나 차단됨**을 선택하면 진행되지 않은 작업과 그 이유만 표시돼요. **더 보기**를 누르면 더 오래된 항목이 표시돼요.

## 다른 위치

할 일의 채팅에는 작업 내역이 계속 표시되고, 활동에서 해당 채팅으로 이동할 수 있어요. Fleet의 **활동**에는 Fleet과 배운 점에 관한 같은 항목이 표시되며, 배운 점을 **철회**할 수 있어요. 설정에서 **보안**을 열고 **활동에서 각 조회 기록 보기**를 누르면 저희 팀의 조회 기록을 확인할 수 있어요.

활동에는 발생한 일만 표시돼요. The Machine이 할 수 있는 작업에는 영향을 주지 않아요.
