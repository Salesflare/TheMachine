## 표시되는 항목

**설정**에서 **활동**을 열어요. 날짜별로 The Machine이 처리한 항목이 최신순으로 표시돼요.

- 처리한 내용과 결과: 전송, 거부, 실패 또는 실행 취소. [나중에 전송하는](send-later.md) 메시지라면 예약, 수정 또는 취소한 시점도 표시돼요.
- 처리한 시점, 사용한 계정이나 앱, 그리고 [처리를 허용한 항목](activity.md#what-allowed-it)
- 해당하는 경우 연결된 할 일
- ChatGPT나 Claude처럼 연결한 AI는 이름 뒤에 **(연결된 AI)**가 표시돼 The Machine 자체와 구분할 수 있어요.

메시지와 답장, 문서 및 캘린더 변경, 웹 작업, 병합한 수정 사항, 코딩 에이전트, Fleet 질문과 답변, The Machine 팀에 전송한 배운 점, 스킬, Graph 가져오기, 채팅에서 잊어 달라고 요청한 사실(**실행 취소** 포함), 추가하거나 삭제한 연결이 목록에 표시돼요. [지원 액세스](get-support.md#support-access)를 통해 팀에서 조회한 기록도 거부된 조회를 포함해 모두 표시돼요.

## 처리 허용 항목

메시지, 문서 또는 캘린더 변경, 웹 작업, 병합한 수정 사항에는 실행 당시 허용한 항목이 표시돼요.

- **할 일에서 승인됨** 또는 **Telegram에서 승인됨**: 보내기, 확인 또는 병합을 탭해 승인한 경우
- **음성으로 승인됨**: Talk에서 예라고 답한 경우
- **실행을 탭함**: 할 일에서 실행을 탭한 경우
- **채팅에서 요청함**: 채팅으로 요청한 경우예요. 메시지의 앞부분이 따옴표 안에 표시돼요. 해당 문구가 내 메시지에 남아 있는 동안에만 인용문이 표시돼요.
- **후속 연락, 자동 전송**, **작은 수정 사항, 자동으로 병합됨**, **자동으로 만든 새 비공개 문서** 또는 **미리 자동으로 준비됨**: 내 설정이나 The Machine의 자체 규칙에 따른 경우
- **승인 기록 없음**: 승인 기록이 없는 경우예요. 이 항목은 [오류 보고서](error-reports.md)에도 표시돼 놓친 경로를 찾을 수 있어요.

웹 작업에는 페이지에서 클릭하거나 입력한 할 일의 실행 기록과 해당 실행을 허용한 항목도 표시돼요. 미루기 후에도 계속 진행되는 작업에는 미루기 전에 허용한 항목이 그대로 표시돼요.

기록 기능이 생기기 전에 발생한 항목에는 **승인 후**처럼 당시 사용하던 문구가 표시돼요.

## 필터링

목록 맨 위에서 **메시지**나 **Fleet**처럼 유형을 선택해요. **거부되었거나 차단됨**을 선택하면 실행되지 않은 항목과 그 이유만 표시돼요. **더 보기**를 선택하면 이전 항목을 불러와요.

## 다른 위치

할 일의 채팅에는 해당 작업의 기록이 계속 남고, 활동에서 그 기록으로 이동할 수 있어요. Fleet의 **활동**에는 Fleet과 배운 점에 관한 같은 항목이 표시되고, 배운 점은 **철회**할 수 있어요. 설정의 **보안**에서 **활동에서 각 조회 기록 보기**를 열면 팀의 조회 기록을 확인할 수 있어요.

활동에는 발생한 일만 표시돼요. The Machine이 할 수 있는 일을 바꾸지는 않아요.
