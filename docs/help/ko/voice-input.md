## 타이핑 대신 말하기

메시지 입력란에서 마이크를 누르세요. 할 일의 채팅, **새 할 일**, **도움말** 또는 초안을 수정하는 입력란에서 사용할 수 있어요. 말한 다음 체크 표시를 누르세요. 또는 말하는 동안 마이크를 누르고 있다가 끝나면 손을 떼세요.

음성을 듣는 동안 입력란에 타이머와 지금까지 인식한 내용이 표시돼요. 아무것도 저장하지 않고 중지하려면 X 표시를 누르세요. 녹음은 2분이 지나면 자동으로 중지돼요.

텍스트는 커서가 있던 위치의 입력란에 표시돼요. 아무것도 전송되지 않으니 내용을 읽고 원하는 대로 수정한 다음 직접 보내세요.

## 음성 처리 방식

**설정**의 **일반**에서 **음성 입력** 방식을 선택하세요. 현재 사용 중인 방식은 그 아래에 표시돼요.

- **자동** (기본값): The Machine에서 OpenAI를 사용 중이면 OpenAI가 음성을 텍스트로 변환해요. OpenAI 키를 사용하거나 오디오를 지원하는 ChatGPT 요금제를 이용하는 경우예요. 그렇지 않으면 The Machine이 직접 변환하며 녹음이 외부로 전송되지 않아요.
- **이 Machine에서**: OpenAI를 설정했더라도 항상 The Machine에서 처리해요.
- **OpenAI 사용**: 항상 OpenAI에서 처리해요.

텍스트 변환이 끝나면 녹음은 바로 삭제돼요.

## 준비하기

The Machine이 직접 음성을 텍스트로 변환하려면 먼저 음성 모델(150~500 MB)을 다운로드해야 해요. 다운로드는 백그라운드에서 조용할 때 진행돼요. 다운로드 중에는 설정에 **준비 중 (백그라운드에서)**이라고 표시돼요. OpenAI를 사용 중이면 이 다운로드를 건너뛰어요.

다운로드가 끝나기 전에는 **자동**을 선택해도 브라우저에 음성 인식 기능이 있으면 브라우저의 기능을 사용해요. 이 경우 입력란 아래에 안내가 표시돼요. 일부 브라우저는 음성을 브라우저 제작사로 전송해요. **이 Machine에서**를 선택하면 녹음은 준비가 끝날 때까지 대기하며, 입력란에 "음성 기능 준비 중…"과 남은 시간이 표시돼요.

## 설정

- **텍스트로 변환됨**: **자동**, **이 Machine에서** 또는 **OpenAI 사용**.
- **정확도** (The Machine에서 처리할 때만): 대부분의 언어에서는 **더 정확하게**가 가장 적합해요. **더 빠름**은 처리가 빠르지만 실수가 더 많으며, Standard Machine의 기본값이에요.
- **언어**: **감지**는 모든 앱 언어에서 사용할 수 있어요. 언어를 직접 선택하면 조금 더 빨라요.

대신 The Machine과 소리 내어 실시간으로 대화하려면 [실시간 대화](talk-live.md)를 참고하세요.

## 작동하지 않을 때

- **마이크가 차단됨**: 브라우저 설정에서 이 사이트의 마이크 사용을 허용하세요. 휴대폰 앱에서는 앱 권한에서 허용할 수 있어요.
- **마이크를 찾을 수 없음**: 마이크를 연결한 다음 다시 시도하세요.
- **The Machine에 연결할 수 없음**: 녹음은 보관되며 The Machine이 다시 연결되면 텍스트로 변환돼요. 더 빨리 시도하려면 **지금 시도**를 누르세요.
- **음성을 인식하지 못함**: 마이크에 더 가까이 대고 말하거나 조금 더 오래 말해 보세요.
