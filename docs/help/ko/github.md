## 읽는 항목

GitHub 알림에서 검토 요청, 멘션, 할당, 답글, 실패한 CI 실행을 확인해요. 알림을 읽음으로 표시하지는 않아요.

## 할 수 있는 작업

읽기만 할 때는 GitHub에서 아무것도 변경하지 않아요. 할 일에 이슈 등록 같은 GitHub 단계가 포함되면, 할 일에 그 내용이 표시되고 **확인**을 누른 뒤에만 단계가 실행돼요. 채팅에서 해당 작업을 정확히 요청한 경우에도 실행돼요. 스크린샷은 Machine 브라우저를 통해 가져와요. GitHub가 연결되어 있지 않으면 할 일에 브라우저를 사용한다고 표시되고 **GitHub 연결**이 보여요.

## 연결하기

호스팅된 Machine에서:

1. **연결**을 연 다음 **프로젝트 및 코드**를 열고 GitHub를 선택해요.
2. **업무용** 또는 **개인용**을 선택하고 **GitHub로 로그인**을 눌러요.
3. **GitHub 열기 ↗**를 누르고 표시된 코드를 입력한 다음 권한을 허용해요. 자동으로 연결돼요.

app.themachine.computer/setup의 설정 페이지에서도 **더 많은 소스** 아래에서 같은 방식으로 로그인할 수 있어요.

개인 컴퓨터에서:

1. **연결**을 연 다음 **프로젝트 및 코드**를 열고 GitHub를 선택해요.
2. 회사와 함께 **업무용**을 선택하거나 **개인용**을 선택하고 **연결**을 눌러요.
3. 요청이 표시되면 **GitHub 열기 ↗**를 누르고 코드를 입력한 다음 권한을 허용해요. 자동으로 연결돼요.

또는 `assistant connect github`을 실행한 다음 GitHub 로그인을 확인해요.

## 연결 해제

- **연결**을 열고 GitHub, **세부 정보**, **연결 해제**를 차례로 선택해요. 그러면 알림을 더 이상 읽지 않아요. 이미 가져온 내용은 그대로 남아요.
- 호스팅된 Machine에서는 설정 페이지에서 GitHub 옆의 **삭제**를 눌러도 돼요.

## GitHub에서 앱 삭제

GitHub에서 설정, 애플리케이션, 승인된 OAuth 앱을 열고 GitHub CLI의 액세스를 취소해요. 개인 컴퓨터에서는 `gh auth logout`를 실행해도 로그아웃돼요.
