## 대화 시작하기

할 일의 채팅에서 마이크 옆의 파형을 누르고, 요청이 표시되면 마이크 사용을 허용해요. 표시줄에 **실시간**이 표시되면 통화하듯 말해 보세요. The Machine이 소리 내어 답해요. 답변 중에 말하면 대화를 끊고 말할 수 있어요.

The Machine은 이 할 일의 메시지, 초안, 채팅을 알고 있고 다른 할 일도 찾아볼 수 있어요. “완료로 표시해 줘”, “내일 9시까지 미뤄 줘”, “필요 없음”이라고 말하면 요청을 실행해요. 바로 이어서 “아니, 그건 아니야”라고 말하면 실행을 되돌려요. 시간은 [근무 시간](work-hours.md)에 설정된 시간대를 따라요.

앱 언어와 브라우저에 표시된 언어를 알아들어요. 기침, 소음, 다른 언어에는 답하지 않고 대화 내용에도 포함하지 않아요.

표시줄에는 **음소거**와 **종료**가 있어요. 작별 인사를 하면 대화가 자동으로 끝나요. 대화는 최대 10분 동안 할 수 있고, 마지막 1분에는 카운트다운이 표시돼요. 계속하려면 다시 시작해요.

## 모든 할 일에 대해 대화하기

사이드바에서 **대화**를 누르세요. 휴대폰에서는 메뉴에서 찾을 수 있어요. The Machine이 대기 중인 할 일의 수를 알려준 다음 **나를 위한**에 있는 할 일을 가장 급한 순서대로 하나씩 살펴봐요. **준비 중…**으로 표시된 할 일이 준비되면 알려줘요.

대화에는 별도의 페이지가 있어요. 진행 중인 할 일이 페이지 맨 위에 표시되고, 초안과 **채팅 열기**도 함께 보여요.

초안을 읽거나, 수정하거나, 미루거나, 완료로 표시하거나, 다음 할 일로 넘어가 달라고 요청할 수 있어요. 할 일에 대해 말한 내용은 해당 할 일의 채팅에 남아요. 새 할 일은 대화가 잠시 멈췄을 때 알려줘요. “... 할 일 추가해 줘”라고 말하면 하던 위치를 벗어나지 않고 할 일을 추가할 수 있어요.

사람, 조직, 프로젝트, 회의 또는 약속에 대해 물어보면 찾아서 보여줘요. **완료 / 무시**에 있는 할 일을 포함해, 할 일을 무시하거나 이름을 바꾸거나 다시 열 수도 있어요. 그 외의 질문은 새 할 일의 채팅에 전달해 답을 알려줘요.

이전에 나눈 대화도 기억해요. “오프사이트에 대해 어떤 결정을 내렸지?”라고 물으면 결정한 내용과 말한 시점을 알려줘요. 이 기능은 사이드바의 **대화**에서만 사용할 수 있어요.

그동안 다른 페이지를 열어도 괜찮아요. 표시줄은 화면 아래에 계속 표시되고, **대화**를 누르면 돌아올 수 있어요. 대화는 최대 30분 동안 할 수 있어요. 컴퓨터와 Android에서는 백그라운드에서도 계속되지만, iPhone에서는 앱이 화면에서 사라지면 중단돼요.

## 요청하고 동의한 뒤 보내기

“목요일에 괜찮다고 답장 써 줘”처럼 요청하면, The Machine이 직접 입력한 것처럼 할 일의 채팅에 전달해요. 채팅에는 평소와 같은 규칙이 적용돼요.

채팅에서 가게 영업시간 같은 정보도 찾아볼 수 있어요. **처리 중이에요…**가 표시되는 동안 계속 대화할 수 있어요. 답을 찾으면 The Machine이 결과와 출처를 알려줘요.

초안을 보내려면 보내 달라고 말하세요. The Machine이 받는 사람, 제목, 내용을 소리 내어 읽고 “이 답장을 Sam에게 이메일로 보낼까요?”처럼 물어봐요. 휴대폰이 주머니에 있어도 사용할 수 있어요. “응, 보내”처럼 분명히 동의하면 초안이 전송돼요.

- 읽어 준 초안 그대로 전송해요. 초안이 바뀌면 다시 읽고 확인을 요청해요. 3분 안에 답하지 않으면 확인 요청이 만료돼요.
- 분명한 동의가 아니면 아무것도 보내지 않아요.
- 이미 보거나 들은 초안은 다시 읽지 않아요. “Pat에게 보낼까요?”처럼 확인만 요청해요.
- “준비된 것 전부 보내”라고 말하면 받는 사람을 한 번에 모두 알려주고 확인을 요청해요. 한 번 동의하면 전부 전송돼요.
- 동의한 뒤에는 대화에 카운트다운과 함께 **실행 취소**가 표시돼요. 누르거나 “취소” 또는 “잠깐”이라고 말하세요.
- 전송이 완료되면 대화에 “전송했어요.”라고 표시되고, 할 일에는 전송 시간과 함께 **받는 사람**이 표시돼요. 전송에 실패하면 이유를 알려줘요. 언제든 “전송됐어?”라고 물어보면 추측하지 않고 확인해요.

**승인**을 눌러도 돼요.

“실행해 줘”라고 말하면 **실행**처럼 The Machine이 할 일을 시작해요. “버그 신고해 줘”라고 말하면 도움말의 **버그 신고**처럼 버그 신고를 보내요.

## 음성 선택하기

**설정**의 **일반**에서 **음성 입력** 아래에 있는 **음성**을 선택하고 재생을 눌러 들어 보세요. 기본 음성은 **Cedar**예요. ChatGPT의 Cove 음성은 사용할 수 없어요.

## 필요한 항목

실시간 대화에는 OpenAI 음성이 사용되므로 The Machine에 다음 중 하나가 필요해요.

- ChatGPT 로그인: 지원되는 요금제에 포함돼요.
- OpenAI API 키: OpenAI에서 사용 분당 요금을 부과하며, 표시줄에 요금이 표시돼요. 둘 다 있으면 The Machine은 API 키를 사용해요.

**설정**의 **일반**에서 **음성 입력**을 열면 실시간 대화를 사용할 수 있는지 확인할 수 있어요. OpenAI를 사용할 수 없으면 파형이 표시되지 않아요. 오디오는 브라우저에서 OpenAI로 바로 전송돼요.

## 작동하지 않을 때

- **마이크가 차단됨**: 브라우저 설정에서 이 사이트의 마이크 사용을 허용해요.
- **실시간 대화를 시작할 수 없음**: ChatGPT 로그인 또는 OpenAI API 키를 확인한 뒤 다시 시도해요.
- **실시간 대화 연결이 끊김**: 다시 시작해요. 말한 내용은 채팅에 남아 있어요.
- 말을 알아듣지 못한다고 표시됨: 마이크를 확인하거나 채팅에 입력해요.
