## 대화 시작하기

할 일의 채팅에서 마이크 옆의 파형을 누르고, 메시지가 표시되면 마이크 사용을 허용해요. 표시줄에 **실시간**이 나타나면 통화하듯 말해요. The Machine이 소리 내어 답해요. 말하는 도중에 끼어들어도 돼요.

이 할 일의 메시지, 초안, 채팅 내용을 알고 있고, 다른 할 일도 찾아볼 수 있어요. "완료로 표시해", "내일 9시까지 미뤄" 또는 "필요 없음"이라고 말하면 그대로 실행해요. 바로 이어서 "아니, 그건 아니야"라고 말하면 취소해요. 시간대는 [근무 시간](work-hours.md)을 따라요.

앱 언어와 브라우저에 설정된 언어를 인식해요. 기침 소리, 잡음, 다른 언어는 답변하지 않고 녹취록에도 포함하지 않아요.

표시줄에 **음소거**와 **종료**가 있어요. 인사하면 대화가 자동으로 끝나요. 대화는 최대 10분 동안 이어지며, 마지막 1분에는 카운트다운이 표시돼요. 다시 시작하면 계속할 수 있어요.

## 모든 할 일과 대화하기

사이드바에서 **대화**를 눌러요. 휴대폰에서는 메뉴에서 찾을 수 있어요. The Machine이 대기 중인 할 일의 개수를 알려주고 **내 확인**에 있는 할 일을 목록에 표시된 순서대로 하나씩 처리해요. **준비 중…**인 할 일이 준비되면 알려줘요.

대화 전용 페이지가 열려요. 현재 할 일이 맨 위에 표시되고, 초안과 **채팅 열기**가 함께 보여요.

초안을 읽거나 수정하고, 미루거나 완료로 표시하거나 다음 할 일로 넘어가 달라고 요청해요. 할 일에 관해 말한 내용은 해당 할 일의 채팅에 기록돼요. 잠시 멈추면 새 할 일을 알려줘요. "...할 일 추가해"라고 말하면 현재 위치를 잃지 않고 할 일을 추가할 수 있어요.

사람, 조직, 프로젝트, 회의 또는 약속에 관해 물어보면 찾아서 보여줘요. **완료 / 무시**에 있는 할 일도 무시하거나, 이름을 바꾸거나, 다시 열 수 있어요. 그 밖의 요청은 새 할 일의 채팅으로 전달하고 답변을 알려줘요.

이전 대화 내용을 기억해요. "오프사이트에 대해 어떻게 결정했지?"라고 물어보면 결정 내용과 말한 시점을 알려줘요. 이 기능은 사이드바의 대화에서만 사용할 수 있어요.

그동안 다른 페이지를 이용해도 돼요. 표시줄은 화면 아래에 계속 표시되고, **대화**를 누르면 다시 돌아와요. 이 대화는 최대 30분 동안 이어져요. 컴퓨터와 Android에서는 백그라운드에서도 계속돼요. iPhone에서는 앱이 화면에서 사라지면 대화가 중단돼요.

## 요청하고 동의한 뒤 보내기

"목요일에 괜찮다고 답장 써 줘"처럼 요청하면 The Machine이 직접 입력한 것처럼 할 일의 채팅에 내용을 전달해요. 채팅은 평소 규칙을 따라요.

채팅에서 매장의 영업시간 같은 정보도 찾아볼 수 있어요. **처리 중이에요…**가 표시되는 동안에도 계속 말할 수 있어요. 답변이 준비되면 The Machine이 답변과 출처를 알려줘요.

초안을 보내려면 보내 달라고 말해요. The Machine이 받는 사람, 제목, 내용을 소리 내어 읽고 "이 답장을 Sam에게 이메일로 보낼까요?"처럼 물어봐요. 휴대폰을 주머니에 넣은 상태에서도 사용할 수 있어요. "응, 보내"처럼 명확하게 동의하면 초안을 보내요.

- 읽어 준 초안 그대로 보내요. 초안이 바뀌면 다시 읽고 확인을 요청해요. 3분 안에 답하지 않으면 요청이 만료돼요.
- 명확하게 동의하지 않으면 아무것도 보내지 않아요.
- 이미 보거나 들은 초안은 다시 읽지 않고 "Pat에게 보낼까요?"처럼 확인만 요청해요.
- "준비된 항목 모두 보내"라고 말하면 한 번에 모두에게 보낼지 물어봐요. 한 번 동의하면 모두 보내요.
- 동의한 뒤에는 대화에 카운트다운과 함께 **실행 취소**가 표시돼요. 누르거나 "취소해" 또는 "잠깐"이라고 말해요.
- 보내고 나면 대화에 "보냈어요."라고 표시되고, 할 일에는 보낸 시간과 함께 해당 사람의 이름이 **받는 사람**으로 표시돼요. 보내기에 실패하면 이유를 알려줘요. 언제든 "보냈어?"라고 물어보면 추측하지 않고 확인해요.

**승인**을 눌러도 돼요.

"실행해"라고 말하면 **실행**처럼 해당 할 일에서 The Machine을 시작해요. "버그 신고해"라고 말하면 도움말의 **버그 신고**처럼 버그 신고를 보내요.

## 음성 선택하기

**설정**의 **일반**에서 **음성 입력** 아래에 있는 **음성**을 선택하고 재생 버튼을 눌러 들어 보세요. 기본 음성은 **Cedar**예요. ChatGPT의 Cove 음성은 사용할 수 없어요.

## 필요한 항목

실시간 대화는 OpenAI 음성을 사용하므로, 내 Machine에 다음 중 하나가 필요해요.

- ChatGPT 로그인: 해당 기능을 제공하는 요금제에 포함돼요.
- OpenAI API 키: OpenAI에서 사용한 분 단위로 요금을 청구하며, 표시줄에 요금이 표시돼요. 둘 다 있으면 내 Machine은 API 키를 사용해요.

**설정**, **일반**, **음성 입력**에서 실시간 대화 사용 준비 여부를 확인할 수 있어요. OpenAI를 사용할 수 없으면 파형이 표시되지 않아요. 오디오는 브라우저에서 OpenAI로 바로 전송돼요.

## 작동하지 않을 때

- **마이크가 차단됨**: 브라우저 설정에서 이 사이트의 마이크 사용을 허용해요.
- **실시간 대화를 시작할 수 없음**: ChatGPT 로그인 또는 OpenAI 키를 확인하고 다시 시도해요.
- **실시간 대화 연결이 끊김**: 다시 시작해요. 말한 내용은 채팅에 남아 있어요.
- 말한 내용을 알아들을 수 없다는 안내가 표시돼요: 마이크를 확인하거나 채팅에 입력해요.
