상단에서 **도움말**을 **설정** 옆에서 누르고, “할 일을 어떻게 미루나요?”처럼 편하게 질문해 보세요. Enter를 누르면 질문을 보내고, Shift+Enter를 누르면 줄을 바꿔요. 앱 언어나 질문을 작성한 언어로 답변해요. 도움말 페이지 링크를 누르면 같은 언어로 패널에서 바로 열려요.

## 답변을 찾는 곳

질문과 관련된 도움말 페이지를 확인하고, 페이지에서 다루지 않는 내용은 앱 코드를 살펴봐요. 답변마다 참고한 페이지의 링크가 포함돼요.

짧고 별도의 채팅으로 The Machine 자체 모델을 사용해요. 메시지 입력란 아래에서 이 도움말 채팅에 사용할 다른 모델이나 사고 수준을 선택할 수 있어요([모델](model.md) 참고). 질문과 관련 페이지만 전송돼요. 메시지, 사람, 설정은 전송되지 않아요.

수준에 맞춰 답변해요. 대부분의 사람에게는 쉬운 말로, 기술적인 질문에는 더 자세히 설명해요. 설정, 역할, 질문하는 방식으로 수준을 추측하고, 추측한 내용만 전송돼요.

먼저 The Machine에 이미 있는 기능을 안내하고, 기본 기능으로 해결할 수 없을 때만 스킬을 제안해요. [내 방식에 맞게 설정하기](personalize.md)를 참고하세요.

## 팀에서 확인하는 내용

도움말을 개선하기 위해 질문마다 “할 일을 미루기”처럼 질문 주제를 나타내는 몇 가지 단어를 The Machine에서 세요. 질문이나 답변은 물론 이름, 주소, 숫자도 보내지 않아요. 도움말 페이지에 있는 단어만 사용해요. 하루에 한 번, 이 단어의 집계 결과가 계정 정보 없이 The Machine 팀으로 전송돼요.

전송을 중단하려면 **설정**의 **보안**에서 **The Machine 팀** 아래에 있는 **요청된 도움 내용 공유**를 끄거나 **신중** [보안 수준](security-levels.md)을 선택하세요. [The Machine Network](/network)가 필요해요. 아직 전송되지 않은 내용은 삭제돼요.

## 할 수 없는 작업

도움말은 질문에 답해요. 데이터를 볼 수 없고 아무것도 변경하지 않아요. 대신 어디를 눌러야 하는지 알려줘요.

설명한 내용이 사용법 질문이 아니라 오류처럼 들리면 답변 끝에 **이 버그 신고**가 표시돼요. 이를 누르면 **버그 신고**가 열리고, 무엇을 했는지, 무엇을 예상했는지, 어떤 일이 있었는지 간단히 정리한 내용과 지원 보고서 항목이 선택된 상태로 표시돼요. 원하는 대로 내용을 수정할 수 있어요. **보내기**를 누르기 전까지는 아무것도 전송되지 않아요.

같은 패널에서 **버그 신고** 탭을 직접 열 수도 있어요. [지원 받기](get-support.md#report-a-bug)를 참고하세요.
