사이드바 하단의 **도움말**을 누르고 "할 일을 어떻게 미루나요?"처럼 편하게 질문하세요. Enter 키를 누르면 질문이 전송되고, Shift+Enter를 누르면 줄이 바뀌어요. 도움말은 앱 언어로 답하거나, 질문에 사용한 언어로 답해요. 도움말 페이지 링크를 누르면 같은 패널에서 해당 언어로 페이지가 열려요.

## 답변은 어디서 가져오나요

도움말은 질문에 맞는 도움말 페이지를 참고하고, 페이지에서 다루지 않는 내용은 앱 코드를 살펴봐요. 답변마다 참고한 페이지 링크가 포함돼요.

도움말 채팅은 내 Machine 자체 모델에서 별도의 짧은 채팅으로 실행돼요. 메시지 입력란 아래에서 이 도움말 채팅에 사용할 다른 모델이나 사고 수준을 선택할 수 있어요([모델](model.md) 참고). 질문과 관련된 페이지 외에는 아무것도 전달되지 않아요. 메시지, 사람 정보, 설정은 포함되지 않아요.

대부분의 사람에게는 쉬운 말로, 기술적인 질문에는 더 자세히 답해요. 설정, 역할, 질문하는 방식을 바탕으로 어느 정도 설명이 필요한지 추측해요. 전달되는 건 그 추측뿐이에요.

먼저 The Machine에 이미 있는 기능을 안내하고, 기본 기능으로 해결할 수 없는 경우에만 스킬을 제안해요. [나에게 맞게 설정하기](personalize.md)를 참고하세요.

## 팀에 표시되는 내용

도움말을 개선하기 위해 내 Machine은 각 질문의 주제와 관련된 몇 개의 단어를 집계해요. 예를 들면 "할 일을 미루기" 같은 단어예요. 질문이나 답변은 집계하지 않으며, 이름, 주소, 숫자도 포함하지 않아요. 도움말 페이지에 있는 단어만 집계해요. 하루에 한 번 계정 정보 없이 집계 결과를 The Machine 팀에 보내요.

집계를 중지하려면 **설정**의 **보안**에서 **The Machine 팀** 아래에 있는 **요청된 도움 내용 공유**를 끄거나 **신중** [보안 수준](security-levels.md)을 선택하세요. [The Machine Network](/network)가 필요해요. 아직 전송되지 않은 내용은 삭제돼요.

## 도움말이 할 수 없는 일

도움말은 질문에 답해요. 데이터는 볼 수 없고 아무것도 변경하지 않아요. 대신 어디를 눌러야 하는지 알려 줘요.

설명한 내용이 사용법 질문이 아니라 오류처럼 보이면 답변 끝에 **이 버그 신고**가 표시돼요. 누르면 **버그 신고**가 열리고, 한 일과 예상한 결과, 실제로 발생한 일을 간단히 정리한 내용과 지원 보고서 체크 항목이 표시돼요. 원하는 대로 내용을 수정할 수 있어요. **보내기**를 누르기 전에는 아무것도 전송되지 않아요.

**버그 신고**는 같은 패널의 별도 탭으로도 표시돼요. [지원받기](get-support.md#report-a-bug)를 참고하세요.
