**도움말**을 사이드바 아래쪽에서 **설정** 위에 있는 탭하고, "할 일을 어떻게 미루나요?"처럼 원하는 말로 질문하세요. Enter를 누르면 질문을 보내고, Shift+Enter를 누르면 줄을 바꿔요. 도움말은 앱 언어나 질문을 작성한 언어로 답변해요. 도움말 문서 링크는 패널에서 해당 언어로 바로 열려요.

## 답변은 어디서 오나요

도움말은 질문과 관련된 도움말 문서와 문서에서 다루지 않는 내용에 관한 앱 코드를 확인해요. 관련된 내용이 없으면 다른 표현을 써서 한 번 더 찾아봐요. 답변에는 참고한 문서 링크가 포함돼요.

내 Machine의 자체 모델을 사용해 별도의 짧은 채팅으로 실행돼요. 메시지 입력란 아래에서 이 도움말 채팅에 사용할 다른 모델이나 사고 수준을 선택할 수 있어요([모델](model.md) 참고). 질문과 관련된 문서만 전달돼요. 메시지, 사람 정보, 설정은 전달되지 않아요.

대부분의 사람에게는 쉬운 표현으로, 기술적인 질문에는 더 자세히 답해요. 설정, 역할, 질문 방식으로 수준을 추측하고, 추측한 수준만 전달해요.

먼저 The Machine에서 이미 할 수 있는 방법을 안내하고, 기본 기능으로 해결할 수 없을 때만 스킬을 제안해요. [나답게 만들기](personalize.md)를 참고하세요.

## 팀에서 볼 수 있는 내용

도움말을 개선하기 위해 내 Machine은 각 질문의 주제를 나타내는 몇 가지 단어를 세요. 예를 들면 "할 일 미루기"와 같은 단어예요. 질문이나 답변, 이름, 주소, 숫자는 보내지 않아요. 도움말 문서에 있는 단어만 사용해요. 하루에 한 번, 집계된 내용이 계정 정보 없이 The Machine 팀에 전송돼요.

전송을 중지하려면 **설정**의 **보안**에서 **The Machine 팀** 아래에 있는 **요청된 도움 내용 공유**를 끄거나 **신중** [보안 수준](security-levels.md)을 선택하세요. [The Machine Network](/network)가 필요해요. 아직 전송되지 않은 내용은 삭제돼요.

## 할 수 없는 일

도움말은 질문에 답해요. 데이터에 접근할 수 없고 아무것도 변경하지 않아요. 대신 어디를 탭하면 되는지 알려줘요.

설명한 내용이 사용법 질문이 아니라 문제처럼 들리면 답변 끝에 **이 버그 신고**가 표시돼요. 누른 뒤 **버그 신고**를 열면 한 일, 예상한 결과, 실제로 발생한 일을 간단히 작성하고 지원 보고서 항목을 선택해 둬요. 내용을 자유롭게 수정할 수 있어요. **보내기**를 누르기 전까지는 아무것도 전송되지 않아요.

**버그 신고**는 같은 패널에서 별도의 탭으로도 제공돼요. [지원받기](get-support.md#report-a-bug)를 참고하세요.
