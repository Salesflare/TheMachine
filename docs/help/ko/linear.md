## 읽어오는 항목

내 Linear 받은 편지함과 나에게 할당된 이슈를 읽어요. 다음 항목을 가져와요.

- 나에게 할당된 이슈: 새 이슈와 상태, 마감일 또는 제목이 변경된 이슈예요. Linear에서 이슈가 완료되거나 취소되면 해당 할 일이 자동으로 닫혀요. **실행 취소**를 누르면 다시 열려요.
- 나를 멘션한 내용, 내가 팔로우하는 이슈의 댓글과 답글이에요.
- 검토 요청과 트리아지에 추가된 이슈예요.
- 마감일 알림이에요.

각 항목은 내용상 내가 처리해야 할 때만 할 일이 돼요. 내가 직접 변경한 내용은 가져오지 않아요. 첫 동기화는 지난 7일간의 항목을 가져와요. Linear에 표시된 이메일 주소를 기준으로 사람을 내 [Graph](graph.md)에 연결해요.

작업에만 사용하려면 **세부 정보**에서 **신호를 가져와요**를 꺼요.

## 할 수 있는 작업

다음 작업은 각각 해당 할 일에서 승인할 때까지 대기해요.

- 할 일과 관련된 이슈에 댓글을 달거나 댓글 스레드에 답글을 달아요. 내가 작성한 것으로 게시돼요.
- 해당 이슈의 상태를 팀에서 사용하는 상태 중 하나로 변경해요.
- 이슈를 팀원이나 나에게 할당해요.
- 내 팀 중 하나에 새 이슈를 만들어요.

이슈를 삭제하거나 보관 처리하지 않으며, 다른 팀으로 옮기지도 않아요.

## 연결하기

1. 대시보드에서 **연결**, **+ 추가**, Linear를 선택해요. 호스팅된 Machine의 설정 페이지(app.themachine.computer/setup)에서는 **더 많은 소스**, Linear를 선택해요. 내 컴퓨터에서는 먼저 계정을 연결해야 해요.
2. **Linear로 로그인**을 누르고 워크스페이스를 선택한 다음 액세스를 허용해요.
3. The Machine으로 돌아오면 로그인 상태를 바로 확인하고 워크스페이스 이름을 표시해요.

다른 워크스페이스를 추가하려면 Linear를 다시 추가해요. 다른 연결과 마찬가지로 **업무** 또는 **개인**을 선택해요.

## API 키를 붙여넣기

**또는 API 키 붙여넣기** 아래에서 **토큰 받기**를 눌러요. Linear에서 **설정**, **보안 및 액세스**를 열어요. 개인 API 키를 만든 다음 복사해 붙여 넣고 **연결**을 눌러요. 내 컴퓨터에서도 `assistant connect linear`에서 API 키를 요청해요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 Linear를 선택한 다음 **세부 정보**, **연결 해제**를 눌러요. 이미 가져온 내용은 그대로 남아요.
- 호스팅된 Machine에서는 설정 페이지에서 Linear 옆의 **삭제**를 눌러도 돼요.

## Linear에서 액세스 권한 취소하기

Linear에서 **설정**, **보안 및 액세스**를 연 다음 승인된 애플리케이션에서 The Machine의 권한을 취소해요. API 키를 붙여 넣었다면 같은 페이지에서 키를 취소해요.
