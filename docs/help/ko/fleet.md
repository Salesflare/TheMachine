Fleet에서는 The Machine Network을 통해 내 Machine이 팀원, 가족 또는 친구의 Machine과 함께 일할 수 있어요. Machine끼리 주고받는 내용은 종단 간 암호화되며, 내 Machine은 내가 정한 규칙에 따라서만 답해요.

## Fleet 종류

- **업무 Fleet**: 팀을 위한 Fleet이에요. 업무를 넘기고, 아는 사람이 있는지 물어보고, 소개를 요청하고, 팀 브리프를 받아 보세요.
- **가족 Fleet**: 최대 6명이 함께할 수 있어요. 모두의 일정이 맞을 때 공유 할 일과 계획을 세우고, 서로의 Machine에 질문할 수 있어요. 무료이며, 포함된 호스팅 Machine에는 가족 요금이 적용돼요. [가족](family.md)을 참고하세요.
- **친구**: The Machine을 사용하는 사람과 한 명씩 연결해요. 무료예요. [친구](friends.md)를 참고하세요.

## Fleet 탭

Fleet에 참여하면 표시돼요. Fleet마다 패널이 있고, 그다음에 친구, Network, 공유, 활동 패널이 있어요. 소유자와 관리자는 **관리**도 볼 수 있고, Graph를 공유하는 업무 Fleet에는 **공유 항목**도 표시돼요.

## 요금, Fleet 나가기, Fleet 시작하기

Fleet 이름 아래의 **요금**에는 시트 수, 내 Machine 비용을 누가 내는지, 소유자에게는 Fleet 카드와 청구서가 표시돼요. **이 Fleet 나가기**를 선택하면 Fleet에서 나가요. 소유자는 먼저 다른 사람에게 소유권을 넘겨야 해요. **다른 Fleet 시작**을 선택하면 새 Fleet을 시작해요.

각 항목을 선택하면 계정의 해당 페이지가 열리고, 요금이 바뀌면 먼저 확인할 금액이 표시돼요. 셀프 호스팅 Machine에서는 새 탭에 계정이 열리며, 여기서 로그인할 수 있어요.

## Fleet에 질문하기

Fleet 탭에서 "Acme에 아는 사람이 있어?"라고 물어보거나, [Graph](graph.md)에서 조직을 선택한 다음 **Fleet에 물어보기**를 선택하세요. 각 팀원의 Machine은 팀원 자신의 공유 규칙에 따라 답하며, 규칙에 따라 먼저 확인이 필요한 경우 팀원에게 먼저 물어봐요.

그 외의 질문은 업무 Fleet 패널에서 **무엇이든 물어보기**를 사용하세요. 각 팀원은 자신의 업무 계정에서 초안 답변을 받으며, 답변을 보내기 전까지는 아무 내용도 공유되지 않아요.

## 업무 Fleet에서 자동으로 답하는 내용

표준 업무 Fleet에서는 내 Machine이 팀원의 질문 중 세 가지에 자동으로 답해요. **아는 사람**, **회의 맥락**("이 참석자는 누구야?") 및 **공유 이메일 담당자**예요. [팀 Graph](team-graph.md)에서 팀과 이미 공유된 정보만 사용하며, 비공개, 개인 또는 민감한 대화는 사용하지 않아요. 각 답변은 Fleet 탭의 **활동**에 표시돼요.

답변을 중지하려면 **공유**에서 **안 함**으로 설정하세요. **먼저 확인 요청**으로 저장된 규칙은 **항상**처럼 작동해요. 팀 Graph 공유가 꺼져 있으면 아는 사람과 회의 맥락에 관한 질문은 먼저 확인을 요청해요.

신중한 업무 Fleet, 친구, 가족 Fleet에서는 계속 먼저 확인을 요청해요. 친근한 소개, 인계, 무료 질문에는 각각 별도의 규칙이 적용돼요.

## 팀에서 배운 점

내 Machine은 팀 Graph에서 이미 공유된 고객 대화를 바탕으로 팀의 업무 방식을 기록해요. 하루에 한 번을 넘지 않아요. 예를 들어 "환불 요청은 지원 받은 편지함에서 환불 템플릿을 사용해 답변해요." 같은 내용이에요. 배운 점은 업무 Fleet 패널의 **팀에서 배운 점**에 Fleet의 모든 구성원이 볼 수 있도록 표시되고, 각각 **활동**에도 기록돼요. 먼저 확인을 요청하지 않아요.

- 팀원 중 누군가가 작성한 대화만 사용해요. 비공개, 개인 또는 민감한 대화는 사용하지 않아요.
- 여러 고객에게 공통으로 적용되는 내용만 기록해요. 업무 절차, 도구, 글쓰기 방식 또는 담당 업무가 이에 해당해요. 한 고객에 관한 내용, 내 제품에 대한 피드백, 이름, 주소, 숫자 또는 인용문은 기록하지 않아요.
- 확실하지 않은 내용은 제외해요.

내 Machine은 이 회사의 업무 할 일을 준비할 때 관련 있는 배운 점을 사용해요. 내 사실, 규칙, 스킬이 먼저 적용되며, 개인 할 일에는 배운 점을 사용하지 않아요. 배운 점을 사용한 할 일에는 "팀에서 배운 점 사용: 환불은 지원 받은 편지함에서 처리해요."처럼 표시돼요. 여기서 **삭제**를 누르면 Fleet 전체에서 해당 내용을 삭제할 수 있어요.

Fleet 구성원 누구나 배운 점을 **삭제**할 수 있어요. 삭제하면 모든 사람에게서 사라지고 다시 생성되지 않아요. 배운 점 공유를 중지하려면 설정의 보안에서 **배운 점 공유 제안**을 끄세요. 신중한 업무 Fleet에는 배운 점이 제공되지 않아요.

## 팀 브리프

Fleet 탭의 **공유**에서 **팀 브리프**를 **매일** 또는 **매주**로 설정하세요. 그러면 내 Machine이 팀원들의 Machine에 건수와 날짜를 요청해요. 내게 필요한 내용은 업무의 할 일에 표시돼요. 예를 들어 팀원의 답변을 기다리는 고객, 2주 이상 소식이 없는 회사, 같은 사람들에게 연락하고 있는 팀원 두 명, 공유 회의 등이 있어요.

- 할 일에는 누구의 답변을 기다리는지, 언제부터 기다렸는지, 무엇을 요청했는지, 진행 중인 프로젝트처럼 무엇이 걸려 있는지가 표시돼요. 구체적으로 알릴 내용이 없으면 할 일이 아니라 브리프의 한 줄로만 표시돼요.
- 회사와 팀원은 각자의 페이지로 연결돼요. **세부 정보**를 누르면 팀원이 작성한 내용과 중요 사항, 팀에서 연락 중인 사람, 최근 대화를 볼 수 있어요. 팀원이 작성한 내용을 읽으려면 해당 내용을 누르세요. [팀 Graph](team-graph.md)에서 공유된 정보만 표시돼요.
- 팀원이 작성한 내용이 팀원의 메일에만 있으면 할 일에 누구에게 물어봐야 하는지 표시돼요.
- **팀에 물어보기**를 누르면 미리 작성된 질문을 팀원에게 보낼 수 있어요. 답변은 할 일에 표시돼요.
- **필요 없음**을 누르면 할 일이 완료 처리되고 브리프에 반영돼요. 새로운 내용이 있을 때만 다시 표시돼요.
- 누군가 답장하거나 맡으면 할 일이 자동으로 완료 처리돼요. 이미 할 일이 있는 회사에 관한 내용은 기존 할 일에 합쳐져요.

## 브리프 요청

팀 브리프를 켠 팀원은 매일 아침 내 Machine에 건수와 날짜를 요청해요. 업무 Fleet에서 내 Machine은 [팀 Graph](team-graph.md)에 이미 공유된 정보만 사용해 자동으로 답해요. 팀 Graph 공유가 꺼져 있으면 아무 내용도 공유하지 않아요. 각 답변은 Fleet 탭의 **활동**에 표시되며, 할 일이나 알림으로는 표시되지 않아요.

공유를 중지하려면 Fleet 탭의 **공유**에서 **팀과 내 핵심 정보 공유**를 끄세요. 그러면 팀원의 브리프에 내가 답하지 않은 것으로 표시돼요.

신중한 Fleet에서는 요청이 Fleet 탭의 **브리프 요청**에 표시돼요. **한 번 공유**, **항상 공유**, **거절** 또는 **안 함**을 선택할 수 있어요. 직접 선택하기 전에는 아무것도 공유되지 않으며, 답하지 않은 요청은 만료돼요.

## 팀 Graph

업무 Fleet에서는 내용을 검토한 후 고객 관련 업무를 팀과 공유할 수 있어요. [팀 Graph](team-graph.md)를 참고하세요.

## 공유 연결

소유자나 관리자는 Fleet 탭의 **공유 연결**에서 Stripe 또는 Intercom을 한 번 연결해 팀과 공유할 수 있어요. 팀원은 내용을 읽을 수 있지만 변경할 수는 없으며, 누가 공유했는지도 볼 수 있어요. 관리자만 연결을 변경하거나 공유를 중지할 수 있어요. [Stripe](stripe.md)와 [Intercom](intercom.md)을 참고하세요.

## 내 Machine이 답하는 내용

공유 패널에서 Fleet별로 설정하세요. [공유 규칙](sharing-rules.md)을 참고하세요. **설정**에 바로 가기가 있어요. **Fleet 규칙**을 선택하세요.

## 회사 계정 로그인

팀원이 회사 계정으로 참여할 수 있도록 설정하세요. 호스팅 업무 Fleet에서는 Google Workspace 또는 Microsoft 365로 로그인한 소유자나 관리자가 계정 페이지에서 **회사 계정 로그인**을 켤 수 있어요.

회사 도메인으로 로그인한 팀원에게는 **참여 요청**이 표시돼요. 소유자나 관리자가 각 요청을 **승인**해야 해요. 개인 Gmail 및 Outlook.com 계정은 회사 계정으로 인정되지 않아요.

Fleet에서 누군가를 삭제하면 모든 곳에서 로그아웃돼요.

Fleet에 참여하거나 Fleet을 시작하거나 내 컴퓨터에서 Machine을 페어링하려면 [요금제 및 결제](plans-and-billing.md)와 [친구와 Network](friends.md)를 참고하세요.

## 소유자 및 관리자용

Fleet 탭의 **관리**에는 관리 중인 각 Fleet의 구성원, 역할, 초대가 표시돼요. 호스팅 Machine에서는 같은 화면에서 초대, 역할 변경, 구성원 삭제, 참여 요청 처리를 할 수 있어요. 요금에 영향을 주는 변경은 먼저 계정을 열어 확인을 요청해요. 셀프 호스팅 Machine에서는 Fleet 구성원을 볼 수 있으며, 계정의 해당 Fleet 설정으로 이동하는 링크가 표시돼요. 여기서 구성원과 초대를 관리할 수 있어요.

Fleet 패널의 Fleet 이름 아래와 관리 화면에서 **Fleet 설정**을 열면 계정에서 해당 Fleet의 설정을 관리할 수 있어요. 공유 연결, 보안, 회사 계정 로그인, 답변할 Machine과 다음 두 항목을 설정할 수 있어요.

- **최근 삭제**: 삭제되었거나 Fleet에서 나간 구성원이 표시돼요. "삭제 완료, 확인됨"은 해당 Machine에서 업무 데이터가 삭제되고 모든 곳에서 로그아웃되었다는 뜻이에요. 완료 전에는 **대기 중**과 그 이유가 표시돼요.
- **활동**: 누가 언제 무엇을 했는지 확인할 수 있어요. 초대, 참여, 삭제, 역할, 호스팅 Machine, 결제, 공유 연결, 승인 내역이 포함돼요. 지원팀이 구성원의 Machine 보고서나 로그를 읽은 기록도 표시돼요. 메시지 내용은 표시되지 않아요. **CSV 다운로드**를 선택하면 내보낼 수 있어요. 12개월 동안 보관돼요.

소유자만 설정할 수 있는 **구성원의 Machine을 시작하기 전에 확인 요청**은 켜면 새 구성원의 Machine을 시작하기 전에 승인을 기다려요. 무료 Fleet에서도 마찬가지예요. 끄면 무료 Fleet에서는 Machine이 바로 시작되고 알림이 와요. 비용이 발생하는 Machine은 금액을 확인할 때까지 항상 기다려요.

**공유 중지**를 선택한 후 모든 Machine에서 공유 연결에 접근할 수 없게 되면 "삭제 완료, 확인됨"으로 표시돼요.
