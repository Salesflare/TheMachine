Fleet을 사용하면 The Machine Network를 통해 The Machine이 팀, 가족 또는 친구의 Machine과 함께 일할 수 있어요. Machine끼리 주고받는 내용은 종단 간 암호화되고, The Machine은 설정한 규칙에 따라서만 답변해요.

## Fleet 종류

- **업무용 Fleet**: 팀을 위한 Fleet이에요. 업무를 넘기고, 아는 사람이 있는지 묻고, 소개를 받거나 팀 브리프를 확인할 수 있어요.
- **가족 Fleet**: 최대 6명이 함께 쓸 수 있어요. 모두 시간이 될 때 공유 할 일과 계획을 세워요. 무료예요. [가족](family.md)을 확인하세요.
- **친구**: The Machine을 사용하는 사람과 한 명씩 연결해요. 무료예요. [친구](friends.md)를 확인하세요.

## Fleet 탭

Fleet에 참여하면 Fleet 탭이 표시돼요. Fleet, 가족, 친구, Network, 공유, 활동마다 패널이 하나씩 있어요.

## 요금, Fleet 나가기, Fleet 시작하기

각 Fleet 이름 아래의 **요금**에서 좌석 수, 내 Machine 요금을 내는 사람, 소유자라면 Fleet 카드와 청구서를 확인할 수 있어요. **이 Fleet 나가기**를 누르면 Fleet에서 나가요. 소유자는 먼저 다른 사람에게 소유권을 넘겨야 해요. **다른 Fleet 시작**을 누르면 새 Fleet을 시작해요.

각 항목을 누르면 계정에서 해당 단계가 열리고, 요금이 바뀌면 먼저 확인할 금액이 표시돼요. 자체 호스팅 Machine에서는 새 탭에 계정이 열리고 로그인해야 해요.

## Fleet에 질문하기

Fleet 탭에서 "Acme에 아는 사람이 있나요?"라고 묻거나, [Graph](graph.md)의 조직에서 **Fleet에 질문**을 선택하세요. 팀원마다 설정한 공유 규칙에 따라 해당 팀원의 Machine이 답변하고, 규칙에서 먼저 확인하도록 했다면 팀원에게 먼저 물어봐요.

## 업무용 Fleet에서 자동으로 답변하는 질문

Standard Work Fleet에서는 The Machine이 팀원의 질문 중 세 가지 종류에 자동으로 답변해요. **아는 사람**, **회의 맥락**("이 참석자는 누구인가요?") 및 **공유 이메일 담당자**예요. [팀 Graph](team-graph.md)에서 팀과 이미 공유한 내용만 사용하며, 비공개, 개인 정보 또는 민감한 대화는 사용하지 않아요. 답변은 Fleet 탭의 **활동**에 표시돼요.

자동 답변을 중지하려면 **공유**에서 **안 함**으로 설정하세요. 규칙을 **먼저 확인 요청**으로 저장해도 **항상**으로 작동해요. 팀 Graph 공유가 꺼져 있으면 아는 사람과 회의 맥락에 대해 먼저 확인을 요청해요.

신중한 Work Fleet, 친구, 가족은 계속 먼저 확인을 요청해요. 따뜻한 소개, 인계, 무료 질문에는 각각 별도의 규칙이 적용돼요.

## 팀에서 배운 점

The Machine은 팀 Graph에서 이미 공유된 고객 대화를 바탕으로 팀의 업무 방식을 기록해요. 하루에 한 번까지만 기록해요. 예를 들면 "환불 요청에는 지원 받은편지함에서 환불 템플릿을 사용해 답변해요." 같은 내용이에요. 기록은 Work Fleet의 **팀에서 배운 점** 패널에 표시되고 Fleet의 모든 구성원이 볼 수 있어요. 각 기록은 **활동**에도 남아요. 누구에게도 먼저 확인을 요청하지 않아요.

- 팀원이 작성한 대화만 사용해요. 비공개, 개인 정보 또는 민감한 대화는 절대 사용하지 않아요.
- 여러 고객에게 공통으로 적용되는 내용만 기록해요. 업무 절차, 도구, 글쓰기 방식, 담당자 등이 해당돼요. 특정 고객에 관한 내용, 제품에 대한 피드백, 이름, 주소, 숫자 또는 인용문은 기록하지 않아요.
- 확실하지 않은 내용은 제외해요.

The Machine은 이 회사의 업무용 할 일을 준비할 때 관련 있는 배운 점을 사용해요. 개인 정보, 규칙, 스킬이 우선이고 개인 할 일에는 배운 점을 사용하지 않아요. 배운 점을 사용한 할 일에는 "팀에서 배운 점 사용: 환불은 지원 받은편지함에서 처리해요."처럼 표시돼요. 여기서 **삭제**를 누르면 Fleet 전체에서 삭제돼요.

Fleet 구성원 누구나 배운 점을 **삭제**할 수 있어요. 삭제한 내용은 모두에게서 사라지고 다시 생성되지 않아요. 배운 점을 제공하지 않으려면 설정의 보안에서 **배운 점 공유 제안**을 꺼주세요. 신중한 Work Fleet에는 배운 점이 제공되지 않아요.

## 팀 브리프

Fleet 탭의 **공유**에서 **팀 브리프**를 **매일** 또는 **매주**로 설정하세요. 그러면 The Machine이 팀원들의 Machine에 건수와 날짜를 요청해요. 확인이 필요한 내용은 업무의 할 일에 표시돼요. 팀원이 답변을 기다리는 고객, 2주 이상 소식이 없는 회사, 같은 사람들에게 연락하는 팀원 둘, 공유 회의 등이 여기에 해당돼요.

- 할 일에는 누구의 답변을 기다리는지, 언제부터 기다렸는지, 어떤 요청을 받았는지, 진행 중인 프로젝트처럼 무엇이 중요한지가 표시돼요. 구체적으로 알릴 내용이 없으면 할 일이 아니라 브리프의 한 줄로만 표시돼요.
- 회사와 팀원은 해당 페이지로 연결돼요. **세부 정보**에는 상대가 작성한 내용(눌러서 읽을 수 있어요), 중요한 사안, 연락 중인 팀원, 최근 대화가 표시돼요. [팀 Graph](team-graph.md)에서 공유한 내용만 표시돼요.
- 상대가 작성한 내용이 팀원의 메일에만 있으면, 할 일에 누구에게 물어봐야 하는지 표시돼요.
- **팀에 물어보기**를 누르면 미리 작성된 질문이 전송돼요. 답변은 할 일에 표시돼요.
- **필요 없음**을 선택하면 할 일이 닫히고 브리프가 그 내용을 반영해요. 새로운 내용이 있을 때만 다시 표시돼요.
- 누군가 답변하거나 맡으면 할 일이 자동으로 닫혀요. 이미 할 일이 있는 회사에 관한 내용은 해당 할 일에 합쳐져요.

## 브리프 요청

팀 브리프를 켠 팀원은 매일 아침 건수와 날짜를 요청해요. Work Fleet에서 The Machine은 [팀 Graph](team-graph.md)에서 이미 공유한 내용만 사용해 자동으로 답변해요. 팀 Graph 공유가 꺼져 있으면 아무것도 보내지 않아요. 각 답변은 Fleet 탭의 **활동**에 표시되며, 할 일이나 알림으로는 표시되지 않아요.

요청을 중지하려면 Fleet 탭의 **공유**에서 **팀과 내 기본 정보 공유**를 꺼주세요. 그러면 팀원의 브리프에 답변하지 않은 사람으로 표시돼요.

신중한 Fleet에서는 Fleet 탭의 **브리프 요청**에서 요청을 확인할 수 있어요. **한 번 공유**, **항상 공유**, **거절** 또는 **안 함**을 선택하세요. 직접 선택하기 전에는 아무것도 공유되지 않으며, 답변하지 않은 요청은 만료돼요.

## 팀 Graph

Work Fleet에서는 내용을 검토한 뒤 고객 관련 업무를 팀과 공유할 수 있어요. [팀 Graph](team-graph.md)를 확인하세요.

## 공유 연결

소유자나 관리자는 Fleet 탭의 **공유 연결**에서 Stripe 또는 Intercom을 한 번 연결해 팀과 공유할 수 있어요. 팀원은 연결을 변경할 수 없고 읽기만 할 수 있으며, 누가 공유했는지 볼 수 있어요. 관리자만 연결을 변경하거나 중지할 수 있어요. [Stripe](stripe.md)와 [Intercom](intercom.md)을 확인하세요.

## The Machine이 답변하는 내용

공유 패널에서 Fleet별로 설정하세요. [공유 규칙](sharing-rules.md)을 확인하세요. **설정**에서 바로가기를 사용할 수 있어요. **Fleet 규칙**을 선택하세요.

## 회사 계정으로 로그인

팀원이 회사 계정으로 참여할 수 있게 설정하세요. 호스팅 Work Fleet에서는 Google Workspace 또는 Microsoft 365로 로그인한 소유자나 관리자가 계정 페이지에서 **회사 계정으로 로그인**을 켤 수 있어요.

해당 회사 도메인으로 로그인한 팀원에게는 **참여 요청**이 표시되고, 소유자나 관리자가 요청마다 **승인**해야 해요. 개인 Gmail 및 Outlook.com 계정은 해당하지 않아요.

Fleet에서 사람을 삭제하면 모든 곳에서 로그아웃돼요.

Fleet에 참여하거나 새 Fleet을 시작하거나 자신의 컴퓨터에서 Machine을 페어링하는 방법은 [요금제 및 결제](plans-and-billing.md)와 [친구 및 Network](friends.md)를 확인하세요.

## 소유자 및 관리자용

Fleet 탭의 **관리**에는 운영 중인 Fleet과 각 Fleet의 구성원, 역할, 초대가 표시돼요. 호스팅 Machine에서는 여기서 초대, 역할 변경, 구성원 삭제, 참여 요청 답변을 할 수 있어요. 요금에 영향을 주는 변경은 먼저 확인할 수 있도록 계정이 열려요. 자체 호스팅 Machine에서는 참여 중인 사람이 표시되고, 계정에서 해당 Fleet의 설정을 열어 구성원과 초대를 관리할 수 있는 링크가 제공돼요.

각 Fleet의 패널에 있는 Fleet 이름 아래와 관리에 표시되는 **Fleet 설정**을 누르면 계정에서 해당 Fleet의 설정이 열려요. 공유 연결, 보안, 회사 계정으로 로그인, 답변하는 Machine을 설정할 수 있고, 다음 두 항목도 확인할 수 있어요.

- **최근 삭제**: 삭제된 사람이나 나간 사람이 표시돼요. **삭제됨, 확인 완료**는 해당 사람의 Machine에서 업무 데이터가 삭제되고 모든 곳에서 로그아웃됐다는 뜻이에요. 아직 완료되지 않았다면 **대기 중**과 그 이유가 표시돼요.
- **활동**: 누가 언제 무엇을 했는지 표시돼요. 초대, 참여, 삭제, 역할 변경, 호스팅 Machine, 결제, 공유 연결, 승인 내역이 포함돼요. 지원팀에서 구성원의 Machine 보고서나 로그를 확인한 시간도 기록돼요. 메시지 내용은 기록되지 않아요. **CSV 다운로드**를 선택해 내보낼 수 있어요. 기록은 12개월간 보관돼요.

소유자가 설정하는 **구성원의 Machine을 시작하기 전에 확인 요청**을 켜면 무료 Fleet에서도 새 구성원의 Machine을 시작하기 전에 승인을 받아야 해요. 끄면 무료 Fleet에서 Machine이 바로 시작되고 알림을 받아요. 비용이 드는 Machine은 금액을 확인할 때까지 항상 대기해요.

**공유 중지**를 누른 후에는 모든 Machine에서 공유 연결에 더 이상 접근할 수 없게 되면 **삭제됨, 확인 완료**로 표시돼요.
