Fleet을 사용하면 The Machine Network를 통해 내 Machine이 팀, 가족 또는 친구의 Machine과 함께 일할 수 있어요. 서로 주고받는 내용은 종단 간 암호화되며, 내 Machine은 설정한 규칙에 따라서만 답해요.

## Fleet 종류

- **업무 Fleet**: 팀과 함께 사용해요. 업무를 넘기고, 아는 사람이 있는지 물어보고, 소개를 받고, 팀 브리프를 확인할 수 있어요.
- **가족 Fleet**: 최대 6명이 함께 사용해요. 모두 시간이 될 때 공유 할 일과 계획을 확인할 수 있어요. 무료이며, 포함된 호스팅 Machine에는 가족 요금이 적용돼요. [가족](family.md)에서 자세히 알아보세요.
- **친구**: The Machine을 사용하는 누구와든 한 명씩 연결할 수 있어요. 무료예요. [친구](friends.md)에서 자세히 알아보세요.

## Fleet 탭

Fleet에 참여하면 Fleet마다 패널이 표시되고, 그 뒤에 친구, Network, 공유, 활동이 나와요. 소유자와 관리자는 **관리**도 볼 수 있고, Graph를 공유하는 업무 Fleet에는 **공유 항목**도 표시돼요.

## 요금, Fleet 나가기 및 Fleet 시작하기

각 Fleet 이름 아래의 **요금**에는 시트 수, 내 Machine 요금을 내는 사람, 소유자에게는 Fleet의 카드와 청구서가 표시돼요. **이 Fleet 나가기**를 선택하면 Fleet에서 나갈 수 있어요. 소유자는 먼저 소유권을 다른 사람에게 넘겨야 해요. **다른 Fleet 시작**을 선택하면 새 Fleet을 만들 수 있어요.

각 항목을 열면 계정에서 해당 작업을 진행할 수 있고, 요금이 변경되면 먼저 확인할 금액이 표시돼요. 직접 호스팅하는 Machine에서는 새 탭으로 계정이 열리며, 로그인해야 해요.

## Fleet에 질문하기

Fleet 탭에서 “Acme에 아는 사람이 있어?”라고 물어보거나, [Graph](graph.md)에서 조직을 선택한 뒤 **Fleet에 물어보기**를 선택하세요. 팀원의 Machine은 각자의 공유 규칙에 따라 답하고, 규칙에서 먼저 확인하도록 설정한 경우에는 해당 팀원에게 먼저 물어봐요.

그 밖의 질문은 업무 Fleet 패널에서 **무엇이든 물어보기**를 사용하세요. 팀원마다 자신의 업무 계정 정보를 바탕으로 답변 초안을 받아요. 팀원이 직접 보내기 전까지는 아무 답변도 전달되지 않아요.

## 업무 Fleet에서 자동으로 답변하기

표준 업무 Fleet에서는 팀원의 다음 세 가지 질문에 내 Machine이 자동으로 답해요. **아는 사람**을 찾는 질문, **회의 맥락**(“이 손님은 누구야?”), **공유 이메일 담당자**에 관한 질문이에요. [팀 Graph](team-graph.md)에서 팀에 이미 공유한 내용만 사용하며, 비공개, 개인 또는 민감한 대화는 사용하지 않아요. 답변은 Fleet 탭의 **활동**에 표시돼요.

특정 답변을 중지하려면 **공유**에서 해당 항목을 **안 함**으로 설정하세요. **먼저 확인 요청**으로 저장한 규칙은 **항상**으로 작동해요. 팀 Graph 공유가 꺼져 있으면 아는 사람과 회의 맥락에 관한 질문은 먼저 확인을 요청해요.

신중한 업무 Fleet, 친구, 가족 Fleet에서는 계속 먼저 확인을 요청해요. 지인 소개, 인계, 무료 질문에는 각각 별도의 규칙이 적용돼요.

## 팀에서 배운 점

내 Machine은 팀이 고객 관련 대화에서 일하는 방식을 기록해요. 해당 대화는 팀 Graph에서 이미 공유된 것이어야 하며, 하루에 한 번까지만 기록해요. 예를 들면 “환불 요청에는 지원 받은 편지함에서 환불 템플릿을 사용해 답변해요.”와 같은 내용이에요. 내용은 업무 Fleet 패널의 **팀에서 배운 점**에 표시되며 Fleet의 모든 구성원이 볼 수 있어요. 각 항목은 **활동**에도 기록돼요. 먼저 확인을 요청하지 않아요.

- 팀원이 직접 작성한 대화만 사용해요. 비공개, 개인 또는 민감한 대화는 절대 사용하지 않아요.
- 여러 고객에게 공통으로 적용되는 내용만 사용해요. 업무 절차, 도구, 글쓰기 방식 또는 담당자 등이 해당해요. 특정 고객에 관한 내용, 내 제품에 대한 피드백, 이름, 주소, 번호 또는 인용문은 포함하지 않아요.
- 확실하지 않은 내용은 제외해요.

내 Machine은 이 회사의 업무 할 일을 준비할 때 관련 있는 배운 점을 활용해요. 내 정보, 규칙, 스킬이 우선하며 개인 할 일에는 배운 점을 사용하지 않아요. 배운 점을 사용한 할 일에는 “팀에서 배운 점 사용: 환불은 지원 받은 편지함에서 처리”와 같이 표시돼요. 해당 항목에서 **삭제**를 누르면 Fleet 전체에서 제거돼요.

Fleet의 누구나 배운 점을 **삭제**할 수 있어요. 삭제된 내용은 모두에게서 사라지고 다시 만들어지지 않아요. 배운 점 공유를 중지하려면 설정의 보안에서 **배운 점 공유 제안**을 끄세요. 신중한 업무 Fleet에는 배운 점이 제공되지 않아요.

## 팀 브리프

Fleet 탭의 **공유**에서 **팀 브리프**를 **매일** 또는 **매주**로 설정하세요. 그러면 내 Machine이 팀원의 Machine에 수와 날짜를 요청해요. 내게 필요한 내용은 업무의 할 일에 표시돼요. 예를 들면 팀원의 답변을 기다리는 고객, 2주 이상 소식이 없는 회사, 같은 사람들에게 연락하는 팀원 두 명 또는 공유 회의가 있어요.

- 할 일에는 누구의 답변을 기다리는지, 언제부터 기다렸는지, 어떤 요청을 받았는지, 진행 중인 프로젝트처럼 무엇이 걸려 있는지가 표시돼요. 구체적으로 알릴 내용이 없으면 할 일이 아니라 브리프의 한 줄로 표시돼요.
- 회사와 팀원은 각자의 페이지로 연결돼요. **세부 정보**에는 팀원이 작성한 내용(눌러서 읽을 수 있어요), 중요한 사항, 연락 중인 팀원과 최근 대화가 표시돼요. [팀 Graph](team-graph.md)에서 공유한 내용만 표시돼요.
- 팀원이 작성한 내용이 팀원의 메일에만 있으면 할 일에 누구에게 물어봐야 하는지 표시돼요.
- **팀에 물어보기**를 누르면 미리 작성된 질문을 보낼 수 있어요. 답변은 해당 할 일에 표시돼요.
- **필요 없음**을 선택하면 할 일이 닫히고 브리프가 이를 반영해요. 새로운 내용이 있을 때만 다시 표시돼요.
- 누군가 답장을 보내거나 맡으면 할 일이 자동으로 닫혀요. 이미 할 일이 있는 회사에 관한 내용은 기존 할 일에 추가돼요.

## 브리프 요청

팀 브리프를 켠 팀원은 매일 아침 내 Machine에 수와 날짜를 요청해요. 업무 Fleet에서 내 Machine은 [팀 Graph](team-graph.md)로 이미 공유된 내용만 사용해 자동으로 답변해요. 팀 Graph 공유가 꺼져 있으면 아무것도 공유하지 않아요. 답변은 Fleet 탭의 **활동**에 표시되며, 할 일이나 알림으로는 표시되지 않아요.

공유를 중지하려면 Fleet 탭의 **공유**에서 **팀과 내 기본 정보 공유**를 끄세요. 그러면 팀원의 브리프에 응답하지 않은 사람으로 표시돼요.

신중한 Fleet에서는 요청이 Fleet 탭의 **브리프 요청**에 표시돼요. **한 번 공유**, **항상 공유**, **거절** 또는 **안 함**을 선택할 수 있어요. 선택하기 전에는 아무것도 공유되지 않으며, 답변하지 않은 요청은 만료돼요.

## 팀 Graph

업무 Fleet에서는 내용을 검토한 뒤 고객 업무를 팀과 공유할 수 있어요. [팀 Graph](team-graph.md)에서 자세히 알아보세요.

## 공유 연결

소유자나 관리자는 Fleet 탭의 **공유 연결**에서 Stripe 또는 Intercom을 한 번 연결한 뒤 팀과 공유할 수 있어요. 팀원은 연결 정보를 읽을 수 있지만 변경할 수는 없으며, 누가 공유했는지 확인할 수 있어요. 관리자만 연결을 변경하거나 중지할 수 있어요. [Stripe](stripe.md) 및 [Intercom](intercom.md)에서 자세히 알아보세요.

## 내 Machine이 답변하는 내용

공유 패널에서 Fleet별로 설정하세요. [공유 규칙](sharing-rules.md)에서 자세히 알아보세요. **설정**에서 바로가기를 사용할 수 있어요. **Fleet 규칙**을 선택하세요.

## 회사 계정으로 로그인

팀원이 회사 계정으로 참여하도록 할 수 있어요. 호스팅 업무 Fleet에서 Google Workspace 또는 Microsoft 365 계정으로 로그인한 소유자나 관리자는 계정 페이지에서 **회사 계정으로 로그인**을 켤 수 있어요.

해당 회사 도메인으로 로그인한 팀원에게는 **참여 요청**이 표시돼요. 소유자나 관리자는 각 요청을 **승인**해야 해요. 개인 Gmail 및 Outlook.com 계정은 회사 계정으로 인정되지 않아요.

Fleet에서 구성원을 삭제하면 모든 곳에서 로그아웃돼요.

Fleet에 참여하거나, Fleet을 시작하거나, 내 컴퓨터에서 Machine을 페어링하려면 [요금제 및 결제](plans-and-billing.md)와 [친구와 Network](friends.md)를 참고하세요.

## 소유자 및 관리자

Fleet 탭의 **관리**에는 관리하는 각 Fleet과 구성원, 역할, 초대가 표시돼요. 호스팅 Machine에서는 여기서 사람을 초대하고 역할을 변경하거나, 구성원을 삭제하고 참여 요청에 답변할 수 있어요. 요금에 영향을 주는 변경 사항은 먼저 계정을 열어 확인을 요청해요. 직접 호스팅하는 Machine에서는 Fleet 구성원이 표시되며, 계정에서 해당 Fleet의 설정을 여는 링크를 통해 구성원과 초대를 관리할 수 있어요.

Fleet 패널의 각 Fleet 이름 아래와 관리 화면에 있는 **Fleet 설정**을 열면 계정에서 해당 Fleet의 설정을 확인할 수 있어요. 공유 연결, 보안, 회사 계정 로그인, 답변에 사용할 Machine, 그리고 다음 두 항목이 있어요.

- **최근 삭제된 구성원**: 삭제되었거나 나간 사람이 표시돼요. “삭제 완료”는 해당 구성원의 Machine에서 업무 데이터가 삭제되고 모든 곳에서 로그아웃되었다는 뜻이에요. 완료 전에는 이유와 함께 **대기 중**으로 표시돼요.
- **활동**: 초대, 참여, 삭제, 역할, 호스팅 Machine, 결제, 공유 연결, 승인 등 누가 언제 무엇을 했는지 표시돼요. 지원팀이 구성원의 Machine 보고서나 로그를 읽은 기록도 표시돼요. 메시지 내용은 포함되지 않아요. **CSV 다운로드**를 선택하면 내보낼 수 있어요. 12개월 동안 보관돼요.

소유자용 **구성원의 Machine을 시작하기 전에 확인 요청**을 켜면 무료 Fleet에서도 새 구성원의 Machine을 시작하기 전에 승인을 기다려요. 끄면 무료 Fleet에서는 Machine이 바로 시작되고 알림을 받아요. 비용이 발생하는 Machine은 항상 금액을 확인할 때까지 기다려요.

**공유 중지**를 선택한 뒤 모든 Machine에서 공유 연결에 접근할 수 없게 되면 “삭제 완료”로 표시돼요.
