## 간단히 보기

- 나만 쓰는 Machine: 호스팅 버전은 EU 클라우드에서 실행되며, 나만 사용할 수 있고 다른 사람과 공유되지 않아요. 또는 내 컴퓨터에서 실행할 수도 있어요.
- 이메일을 읽지 않아요: 메시지는 암호화되어 저장되고, 지원 도구로도 열어 볼 수 없어요.
- 확인 없이는 아무것도 전송되지 않아요: 읽고 초안을 작성하지만, 무엇을 보낼지는 직접 결정해요. [실행](do-it.md)을 확인해 보세요.
- AI 학습에 사용되지 않아요: 자체 AI가 없어요. 제공업체는 내 계정으로 작동하며 해당 업체의 약관을 따라요.
- 끄지 않으면 팀을 위한 배운 점을 공유해요: 가끔 일반적인 팁 몇 가지를 공유하며, 개인 정보는 포함되지 않아요. 전송 전에 확인해요. [배운 점 공유](share-learnings.md)를 확인해 보세요.
- 끄지 않으면 오류 보고서를 보내요: 문제가 발생하면 오류 유형과 코드에서 발생한 위치를 전송해요. 메시지, 이름, 주소는 절대 포함하지 않아요. [오류 보고서](error-reports.md)를 확인해 보세요.
- 호스팅된 Machine의 사용 횟수: 할 일을 열거나 이메일을 보낸 횟수처럼 하루 동안의 사용 횟수를 기록하며, 내용은 기록하지 않아요.
- 데이터를 가져가거나 삭제할 수 있어요: **설정** › **일반**에서 모든 데이터를 내보내거나, 버튼 하나로 Machine과 백업을 삭제할 수 있어요. [구독 취소 또는 삭제](cancel-and-delete.md)를 확인해 보세요.
- 접근 기록을 남겨요: 저희 팀이 내 호스팅 Machine의 보고서나 로그를 읽을 때마다 기록돼요. Fleet 소유자와 관리자는 **활동**에서 확인할 수 있어요. [Fleet](fleet.md)를 확인해 보세요.

## 보안 수준

**표준**은 현재 기본 설정을 유지해요. **신중**을 선택하면 알림에 텍스트가 표시되지 않고, 로그인 정보가 저장되지 않으며, 저장되는 정보가 줄어들어요. 업무 Fleet의 관리자는 Fleet의 보안 수준을 신중으로 설정할 수 있어요. [보안 수준](security-levels.md)을 확인해 보세요.

## 로그인

호스팅된 대시보드에 로그인하려면 패스키를 사용하거나, Google 또는 Microsoft 계정으로 로그인한 뒤 인증 앱 코드를 입력해야 해요.

## 연결

각 연결의 도움말에서 어떤 정보를 읽고 무엇을 전송할 수 있는지 확인할 수 있어요. 연결은 언제든 해제할 수 있어요. [연결](connections.md)을 확인해 보세요.

## 도움말

도움말은 내 Machine에서 실행되므로 내 데이터에 접근할 수 없어요. 질문의 주제만 The Machine 팀에 전송되고, 질문 내용은 전송되지 않아요. [도움말에 질문하기](help-chat.md#what-the-team-sees)를 확인해 보세요.
