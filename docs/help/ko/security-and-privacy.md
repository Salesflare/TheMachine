## 핵심 내용

- 나만 쓰는 Machine: 호스팅형은 EU 클라우드에서 나만 사용할 수 있도록 실행되며, 다른 사람과 공유되지 않아요. 직접 소유한 컴퓨터에서 실행할 수도 있어요.
- 이메일을 읽지 않아요. 메시지는 암호화해 저장하며, 고객 지원 도구로도 열 수 없어요.
- 허락 없이는 아무것도 전송되지 않아요. 내용을 읽고 초안을 작성하지만, 무엇을 보낼지는 직접 결정해요. [실행](do-it.md)을 참고하세요.
- AI 학습에 사용하지 않아요. 자체 AI가 없어요. 이용 중인 제공업체는 내 계정과 해당 업체의 약관에 따라 작동해요.
- 기능을 끄지 않으면 팀에 배운 점을 공유해요. 가끔 일반적인 팁을 몇 가지 공유하며, 개인적인 내용은 포함하지 않고 전송 전에 확인해요. [배운 점 공유](share-learnings.md)를 참고하세요.
- 기능을 끄지 않으면 오류 보고서를 보내요. 문제가 발생하면 오류 유형과 코드에서 오류가 발생한 위치를 전송해요. 메시지, 이름, 주소는 절대 전송하지 않아요. [오류 보고서](error-reports.md)를 참고하세요.
- 호스팅형 Machine의 사용량 집계: 할 일을 열거나 이메일을 보내는 등 어떤 작업을 했는지 매일 집계해요. 내용은 집계하지 않아요. 대시보드가 열리는 속도도 측정해요. 휴대폰이나 컴퓨터, 앱이나 브라우저에서의 로드 시간만 측정해요.
- 데이터를 가져가거나 삭제할 수 있어요. **설정** › **일반**에서 모든 데이터를 내보내거나, 버튼 하나로 Machine과 백업을 삭제할 수 있어요. [취소 또는 삭제](cancel-and-delete.md)를 참고하세요.
- 저희의 접근 기록을 남겨요. 팀에서 호스팅형 Machine의 보고서나 로그를 열람할 때마다 기록돼요. Fleet 소유자와 관리자는 **활동**에서 확인할 수 있어요. [Fleet](fleet.md)을 참고하세요.

## 백업

호스팅형 Machine은 매일 밤 데이터를 백업해요. 백업은 Machine에서 암호화한 뒤 외부로 전송되며, 네덜란드(EU)의 Microsoft Azure에 저장돼요. 일별 백업은 최근 7개, 주별 백업은 최근 4개, 월별 백업은 최근 3개를 보관해요. 약 3개월치예요. Machine을 삭제하면 백업도 삭제돼요.

백업을 열 수 있나요? 네, Machine에 문제가 생겨 복구해야 할 때 열 수 있어요. 백업과 별도로 암호화 키를 보관해요. 백업에 포함된 메시지는 저희가 보관하는 별도의 두 번째 키로 한 번 더 암호화하고 봉인해요. 이 키는 백업에 절대 포함되지 않아요.

백업은 안전망이므로 잃어버릴 수 없는 데이터는 직접 사본을 보관해 주세요. **설정** › **일반** › **내보내기**에서 **전체**를 내보내면 돼요. [다른 컴퓨터로 옮기기](moving.md)를 참고하세요.

직접 소유한 컴퓨터에서는 자동으로 백업되지 않으며, 저희도 사본을 보관하지 않아요. 홈 폴더를 매일 밤 암호화해 백업하면 충분해요. [시작하기](https://github.com/Salesflare/TheMachine/blob/main/docs/getting-started.md#later)를 참고하세요.

## 보안 수준

**표준**은 현재 기본 설정을 유지해요. **신중**은 알림에 텍스트를 표시하지 않고, 로그인 정보를 저장하지 않으며, 보관하는 데이터도 줄여요. 업무 Fleet의 관리자는 Fleet을 신중 모드로 설정할 수 있어요. [보안 수준](security-levels.md)을 참고하세요.

## 로그인

호스팅형 대시보드에 로그인하려면 패스키를 사용하거나 Google 또는 Microsoft 계정으로 로그인한 뒤 인증 앱 코드를 입력해야 해요.

## 연결

각 연결의 도움말에서 어떤 데이터를 읽고 전송할 수 있는지 확인할 수 있어요. 언제든 연결을 해제할 수 있어요. [연결](connections.md)을 참고하세요.

## 도움말

도움말은 내 Machine에서 실행되므로 데이터에 접근할 수 없어요. 각 질문의 주제만 The Machine 팀에 전송되며, 질문 내용은 전송되지 않아요. [도움말에 질문하기](help-chat.md#what-the-team-sees)를 참고하세요.
