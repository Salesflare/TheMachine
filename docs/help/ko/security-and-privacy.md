## 핵심 내용

- 나만 사용하는 Machine이에요. 호스팅된 Machine은 EU 클라우드에서 실행되며, 나만 사용할 수 있고 다른 사람과 공유되지 않아요. 또는 내 컴퓨터에서 직접 실행할 수 있어요.
- 이메일을 읽지 않아요. 메시지는 암호화되어 저장되고, 지원 도구로도 열어 볼 수 없어요.
- 동의 없이는 아무것도 보내지 않아요. 내용을 읽고 초안을 작성하지만, 무엇을 보낼지는 직접 결정해요. [실행](do-it.md)을 참고하세요.
- AI 학습에 사용하지 않아요. 자체 AI는 없어요. 제공업체는 내 계정과 해당 업체의 약관에 따라 작동해요.
- 팀에 배운 점을 공유할 때도 동의가 필요해요. 가끔 일반적인 팁 몇 가지를 보낼지 물어보며, 개인정보는 보내지 않아요. [배운 점 공유](share-learnings.md)를 참고하세요.
- 오류 보고서는 끄지 않는 한 전송돼요. 문제가 발생하면 오류 유형과 코드 내 위치를 보내요. 메시지, 이름, 주소는 보내지 않아요. [오류 보고서](error-reports.md)를 참고하세요.
- 호스팅된 Machine에서는 사용량을 집계해요. 할 일을 열거나 이메일을 보낸 횟수처럼 매일 사용한 기능의 횟수만 집계하며, 내용은 수집하지 않아요.
- 데이터를 가져가거나 삭제할 수 있어요. **설정** › **일반**에서 모든 데이터를 내보내거나, 버튼 하나로 Machine과 백업을 삭제할 수 있어요. [취소 또는 삭제](cancel-and-delete.md)를 참고하세요.
- 팀의 접근 내역을 기록해요. 팀에서 호스팅된 Machine의 보고서나 로그를 열어 볼 때마다 기록돼요. Fleet 소유자와 관리자는 **활동**에서 확인할 수 있어요. [Fleets](fleet.md)를 참고하세요.

## 보안 수준

**표준**은 현재 기본 설정을 유지해요. **신중**은 알림에 텍스트를 표시하지 않고, 로그인 정보를 저장하지 않으며, 보관하는 정보도 줄여요. Work Fleet의 관리자는 Fleet를 신중 모드로 설정할 수 있어요. [보안 수준](security-levels.md)을 참고하세요.

## 로그인

호스팅된 대시보드에 로그인하려면 Google 또는 Microsoft 계정과 인증 앱 코드나 패스키가 필요해요.

## 연결

각 연결 문서에서 어떤 정보를 읽고 무엇을 보낼 수 있는지 확인할 수 있어요. 언제든 연결을 해제할 수 있어요. [연결](connections.md)을 참고하세요.

## 도움말

도움말은 내 Machine에서 실행되므로 데이터에 접근할 수 없어요. 각 질문의 주제만 The Machine 팀에 전송되며, 질문 내용은 전송되지 않아요. [도움말에 질문하기](help-chat.md#what-the-team-sees)를 참고하세요.
