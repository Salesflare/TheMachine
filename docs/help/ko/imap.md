## 읽는 항목

받은 편지함과 보낸 편지함을 읽어요. 연결할 때는 최근 7일간의 메일을 읽고, 그다음부터는 새 메일을 모두 읽어요. 보낸 메일도 포함되므로 글을 쓰는 방식과 약속한 내용을 파악할 수 있어요. 다른 폴더는 읽지 않아요.

The Machine이 보낸 메일의 사본을 보낸 편지함에 저장하는 것 외에는 메일함의 내용을 변경하지 않아요. 메일을 읽음으로 표시하지도 않아요.

## 할 수 있는 작업

**보내기**를 누른 뒤에만 이메일을 보내요. 같은 비밀번호를 사용해 제공업체의 메일 서버(SMTP)를 통해 보내고, 보낸 편지함에 사본을 저장해요. 답장은 기존 대화에 이어지고, 서명은 설정에 저장된 서명을 사용해요. 저장된 서명이 없으면 보낸 메일 끝에 있는 서명을 사용해요.

## 연결하기

1. 대시보드에서 **연결**을 연 다음 **이메일**을 선택하고 **기타 이메일**을 골라요.
2. 이메일 주소와 비밀번호를 입력해요.
3. **연결**을 눌러요.

많은 제공업체에서 메일 앱에는 일반 비밀번호가 아닌 앱 비밀번호를 사용해야 해요. 제공업체 계정 설정에서 앱 비밀번호를 만드세요.

- iCloud: account.apple.com에서 앱 전용 비밀번호를 만들어요.
- Yahoo: 계정 보안에서 앱 비밀번호 생성을 선택해요.
- Fastmail: 설정, 개인정보 보호 및 보안, 앱 비밀번호로 이동해요.
- Telenet: 일반 Telenet 메일 비밀번호를 사용해요.
- 2단계 인증을 사용하는 Zoho Mail: Zoho 계정의 보안 설정에서 애플리케이션 전용 비밀번호를 만들어요.
- Proton Mail: 같은 컴퓨터에서 Proton Mail Bridge를 실행하고 Bridge에 표시된 비밀번호를 사용해요. 같은 컴퓨터에서 사용하는 The Machine에서만 작동해요. The Machine에는 Bridge 인증서의 지문이 표시되며, 해당 인증서만 신뢰해요.

대부분의 제공업체는 서버 설정이 자동으로 입력돼요. 제공업체를 찾을 수 없나요? **서버 설정**을 열고 메일 앱에 필요한 정보를 입력하세요. IMAP 및 SMTP 서버, 포트, 보안 방식(SSL/TLS 또는 STARTTLS)을 제공업체에서 확인할 수 있어요. The Machine은 TLS 없이 연결하지 않아요.

개인 도메인에서 사용하는 경우를 포함해 Gmail 또는 Microsoft 메일을 이용하나요? 대신 **Gmail** 또는 **Outlook**을 선택하세요. 비밀번호 없이 로그인할 수 있어요. 서버 설정에 직접 입력한 서버도 해당 항목으로 이동해요. Microsoft는 더 이상 메일 앱에서 비밀번호를 사용할 수 없어요.

Microsoft 365 주소를 입력하면 해당 내용이 표시되고, 비밀번호 대신 **Microsoft로 로그인**이 나타나요. 이 버튼을 누르면 Outlook 로그인이 열려요. 몇 초 안에 주소를 찾지 못하면 비밀번호 입력란이 그대로 표시돼요.

## 연결이 끊기면

- **메일 서버에서 비밀번호를 거부했어요**: 비밀번호를 변경했거나 앱 비밀번호가 삭제됐어요. 새 비밀번호로 다시 연결하세요.
- **메일 서버에서 발신 비밀번호를 거부했어요**: 메일이 전송되지 않았어요. 다시 연결하세요. 계속 거부되면 서버 설정에서 SMTP 서버를 확인하세요. 그동안에는 메일을 읽기만 해요.
- **메일 서버에 연결할 수 없어요**: 자동으로 다시 시도해요. 계속 실패하면 서버 설정에서 서버 이름을 확인하세요.
- **메일 서버 인증서가** 다른 이름으로 되어 있어요: 공유 호스팅에서는 서버가 자체 이름으로 응답하는 경우가 많아요. 서버 설정에 표시된 이름을 입력하세요. The Machine은 인증서 확인을 건너뛰지 않아요.

## 연결 해제하기

**연결**에서 계정을 열고 **세부 정보**를 선택한 다음 **연결 해제**를 누르세요. 메일을 더 이상 읽지 않지만, 이미 가져온 메일은 그대로 남아요. 제공업체 계정에서도 앱 비밀번호를 삭제하세요.
