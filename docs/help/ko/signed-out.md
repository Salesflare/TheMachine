LinkedIn이나 X 같은 사이트는 Machine 자체 브라우저에서 열려요. 사이트에서 로그아웃되는 경우도 있어요.

## 다시 로그인하기

**연결**과 할 일 상단에 로그아웃 상태가 표시돼요. **다시 로그인**을 누르고 대시보드의 작은 창에서 로그인하세요.

**다음에도 사용할 수 있게 저장**을 선택하면 다음에 로그아웃됐을 때 한 번 눌러 다시 로그인할 수 있어요. 비밀번호는 Machine에 암호화되어 저장되고, AI는 볼 수 없어요.

## 비밀번호와 인증 코드

비밀번호는 직접 입력하세요. 2단계 인증 코드도 직접 입력해야 해요.

저장된 로그인은 **연결**의 **로그인 세션**에서 확인할 수 있어요. **잊기**를 누르면 항목 하나가 삭제돼요.

## 사이트에서 로그인을 거부하거나 로봇 확인을 요구하는 경우

LinkedIn, X, Cloudflare 확인을 사용하는 사이트는 클라우드 브라우저에서 로그인을 거부하는 경우가 많아요. 호스팅된 Machine에서는 이때 **집 인터넷 연결로 로그인**이 표시돼요. 이 버튼을 누르면 설정 페이지가 열려요. 여기서 Tailscale을 사용해 Machine 브라우저가 집 인터넷으로 연결되게 하거나, 직접 마련한 프록시를 사용할 수 있어요. 그런 다음 다시 로그인하세요.

자신의 컴퓨터에서는 브라우저가 이미 집에 연결되어 있으므로 이 설정이 필요하지 않아요.
