LinkedIn이나 X 같은 사이트의 내용은 내 Machine의 브라우저에서 읽어요. 가끔 사이트에서 로그아웃되기도 해요.

## 다시 로그인

**연결**과 할 일 목록 맨 위에 로그아웃 상태가 표시돼요. **여기서 로그인**을 누르면 대시보드의 작은 창에서 로그인할 수 있어요.

**다음에도 사용할 수 있게 저장**을 선택하면, 다음에 로그아웃될 때 한 번 탭해서 다시 로그인할 수 있어요. 비밀번호는 내 Machine에 암호화되어 저장되고, AI는 절대 볼 수 없어요. 같은 사이트에 계정이 여러 개라면 **다른 이름으로 저장**에서 계정 이름(회사, 개인)을 지정할 수 있어요. 할 일에 사용할 계정이 지정되지 않은 경우 대화상자에서 어떤 계정을 사용할지 물어봐요.

## 비밀번호와 코드

비밀번호는 직접 입력해야 해요. 2단계 인증 코드도 직접 입력해야 해요.

저장된 로그인은 **연결**의 **로그인 세션**에서 확인할 수 있어요. **잊기**를 누르면 저장된 로그인을 삭제해요. **가져오기**를 누르면 비밀번호 관리자에서 가져올 수 있어요.

## 사이트에서 로그인을 거부하거나 로봇 확인을 요구하는 경우

LinkedIn, X 및 Cloudflare 확인을 사용하는 사이트는 클라우드의 브라우저에서 로그인을 거부하는 경우가 많아요. 호스팅된 Machine에서는 로그인 화면에 **집 인터넷 연결로 로그인**이 표시돼요. 이 버튼을 누르면 설정 페이지가 열려요. 여기서 Tailscale을 통해 집 인터넷으로 연결하거나 직접 설정한 프록시를 통해 내 Machine의 브라우저가 인터넷에 접속하도록 설정할 수 있어요. 그런 다음 다시 로그인하면 돼요.

내 컴퓨터에서는 이 설정이 필요 없어요. 브라우저가 이미 집 인터넷을 사용하고 있으니까요.
