LinkedIn이나 X 같은 사이트는 내 Machine의 자체 브라우저에서 열려요. 가끔 사이트에서 로그아웃될 수 있어요.

## 다시 로그인하기

**연결** 화면과 할 일 목록 상단에 로그아웃 상태가 표시돼요. **여기서 로그인**을 누르면 대시보드의 작은 창에서 로그인할 수 있어요.

**다음에도 사용할 수 있게 저장**을 선택하면 다음에 로그아웃될 때 한 번만 눌러 다시 로그인할 수 있어요. 비밀번호는 내 Machine에 암호화되어 저장되고, AI는 볼 수 없어요. 한 사이트에 계정이 여러 개라면 **다른 이름으로 저장**으로 계정 이름을 지정할 수 있어요(직장, 개인). 할 일에 사용할 계정이 지정되어 있지 않으면 대화상자에서 선택하라고 안내해요.

## 비밀번호와 코드

비밀번호는 직접 입력하세요. 2단계 인증 코드도 직접 입력해야 해요.

저장된 로그인은 **연결**의 **로그인 세션**에서 확인할 수 있어요. **잊기**를 누르면 저장된 로그인 하나를 삭제해요. **가져오기**를 사용하면 내 Machine 브라우저에서 비밀번호 관리자 자체의 내보내기 페이지를 열거나 내보낸 파일을 사용해 저장된 로그인을 가져올 수 있어요.

## 사이트에서 로그인을 거부하거나 로봇 확인을 요구하는 경우

LinkedIn, X, Cloudflare 확인이 필요한 사이트는 클라우드 브라우저에서 로그인을 거부하는 경우가 많아요. 호스팅된 Machine에서는 로그인 화면에 **집 인터넷 연결로 로그인**이 표시돼요. 이 버튼을 누르면 설정 페이지가 열려요. 여기서 Tailscale을 사용해 내 Machine의 브라우저가 집 인터넷을 통해 접속하도록 설정하거나, 직접 프록시를 사용할 수 있어요. 그런 다음 다시 로그인하세요.

내 컴퓨터에서는 이 설정이 필요 없어요. 브라우저가 이미 집 인터넷에 연결되어 있으니까요.
