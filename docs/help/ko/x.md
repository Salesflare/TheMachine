## 읽을 수 있는 내용

Machine 브라우저에서 로그인한 계정의 X 멘션, 답글, 쪽지를 확인해요. 읽음으로 표시하지 않으며, 암호화된 X Chat은 읽을 수 없어요.

## 보낼 수 있는 내용

답글이나 쪽지를 보낼 수 있어요. 할 일에서 승인한 뒤에만 보내요.

X의 공식 API를 사용하지 않아요. 내용을 읽고 승인한 답글을 가끔 보내는 것은 문제를 일으킬 가능성이 매우 낮지만, 대량으로 보내거나 자동으로 보내면 계정이 차단될 수 있어요.

## 연결하기

호스팅형 Machine을 사용하는 경우:

1. app.themachine.computer/setup에서 설정 페이지를 열고 **추가 소스**로 이동해요.
2. X를 열고 @ 없이 핸들을 입력해요. 안내가 표시되면 Machine 브라우저에서 X에 로그인한 다음 **연결**을 눌러요.

내 컴퓨터에서 사용하는 경우:

1. 대시보드에서 **연결**을 열고 **채팅**을 선택한 다음 X를 골라요.
2. 회사 계정이면 **업무**, 개인 계정이면 **개인**을 선택하고 @ 없이 핸들을 입력한 다음 **연결**을 눌러요.
3. **X에 로그인**을 누르고 Machine 브라우저에서 로그인해요. 로그인하면 자동으로 연결돼요.

또는 터미널에서 `assistant connect x`을 실행해요.

X에서 Machine이 로그아웃되면 [사이트에서 로그아웃됨](signed-out.md)을 참고해요.

## 연결 해제하기

- 대시보드에서 **연결**을 열고 X를 선택한 다음 **세부 정보**에서 **연결 해제**를 눌러요. 읽기가 중지돼요. 이미 가져온 내용은 그대로 남아요.
- 호스팅형 Machine을 사용하는 경우 설정 페이지에서 X 옆의 **삭제**를 눌러도 돼요.

## X에서 로그아웃하기

X에서 설정, 보안 및 계정 액세스, 앱 및 세션, 세션으로 이동한 다음 Machine 브라우저 세션에서 로그아웃해요.
