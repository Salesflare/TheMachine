## 읽는 내용

메일을 모두 읽어요. 연결할 때는 최근 7일간의 메일을 읽고, 이후에는 새로 주고받는 메일을 모두 읽어요. 보낸 메일도 포함되므로 글을 쓰는 방식과 어떤 약속을 했는지 파악해요.

프로모션, 뉴스레터, 업데이트 및 포럼 메일은 먼저 발신자, 제목, 몇 단어만 빠르게 확인해요. 여러 메일을 한 번에 확인해요. 중요한 메일은 전체 내용을 읽고 할 일로 만들 수 있어요. 확인하지 않고 지나치는 메일은 없어요.

## 보낼 수 있는 내용

할 일에서 이메일을 작성할 수 있고, 승인한 뒤에만 보내요. **실행**을 누르면 초안을 준비해요. **검토 후 보내기**를 누르면 수정할 수 있는 상태로 열리고, **지금 보내기**를 누르기 전까지는 발송되지 않아요. **Google로 로그인**하면 Google에 메일 발송 권한도 요청해요. 내 컴퓨터에서 직접 만든 앱을 사용하는 경우, 직접 발송 기능을 추가하기 전까지 로그인은 읽기 전용이에요.

검토 화면의 **보낸 사람**은 Gmail에서 이 메일함이 별칭으로 메일을 보낼 수 있도록 허용한 경우 표시되는 작은 선택 메뉴예요. 별칭은 설정의 **내 것**으로 표시된 항목이에요([내 주소](settings.md#your-addresses)). 별칭으로 받은 메일에 답장하면 해당 별칭으로 발송하고, 새 메일은 메일함 주소로 발송해요. 발송 직전에 Gmail에 다시 확인해요. 주소가 확인되지 않으면 메일을 보내지 않아요.

답장은 원래 메일이 있던 대화에 추가돼요. 원래 메일을 받은 메일함과 다른 메일함에서 답장을 보내는 경우, 보내기 전에 할 일에 안내가 표시돼요. 답장은 그래도 상대방의 기존 대화에 추가돼요.

## 연결하기

호스팅된 The Machine에서:

1. app.themachine.computer/setup에서 설정 페이지를 열어요.
2. **메일 및 캘린더**에서 **Google 연결**을 누르고 로그인해요. Google 화면에는 The Machine을 만든 Salesflare가 표시돼요.
3. Gmail과 Google Calendar가 함께 연결돼요.

Google로 가입하면서 해당 화면에서 Gmail과 Calendar를 허용했다면 자동으로 연결돼요. **보내기**를 누른 경우에만 메일을 보내요.

또는 대시보드에서 **연결**, **이메일**을 열고 Gmail을 선택한 다음 **Google로 로그인**을 눌러요. 완료하면 대시보드로 돌아와요.

내 컴퓨터에서 사용하는 경우, [계정과 페어링한 후](friends.md#a-machine-on-your-own-computer):

1. 대시보드에서 **연결**을 열고 **이메일**을 선택한 다음 Gmail을 골라요.
2. **Google로 로그인**을 누르고 새로 열린 탭에서 로그인해요. Gmail과 Google Calendar가 함께 연결돼요.

페어링하지 않았거나 직접 만든 Google OAuth 클라이언트를 사용하는 경우, 여기에서 **직접 만든 앱 사용**을 열거나 `assistant connect gmail`을 실행해요. **Google 열기**를 누르고 로그인한 다음, Google에서 이동한 주소를 붙여 넣어요. 같은 주소의 Google Calendar도 함께 연결돼요.

Google Workspace 관리자가 Admin console에서 먼저 앱을 허용해야 할 수도 있어요.

## 연결 해제하기

- 호스팅된 The Machine에서: 설정 페이지의 주소 옆에 있는 **연결 해제**를 눌러요. 해당 주소의 Gmail과 Calendar 연결이 해제되고, The Machine에서 로그인 정보를 삭제해요. 다른 Machine의 로그인 정보는 유지돼요. 대시보드의 연결에서 **연결 해제 ↗**를 누르면 해당 페이지로 이동해요. 여기서 **다시 연결**을 누르면 대시보드를 나가지 않고 다시 로그인할 수 있어요.
- 내 컴퓨터에서: **연결**을 열고 Gmail을 선택한 다음 **세부정보**, **연결 해제**를 눌러요. 메일 읽기가 중지돼요. 이미 가져온 내용은 그대로 남아요. 해당 Google 로그인 정보를 사용하는 다른 항목이 없으면 로그인 정보를 삭제해요. 다른 Machine의 로그인 정보는 유지돼요.

## Google에서 앱 삭제하기

Google 계정에서 보안으로 이동한 다음, 타사 앱 및 서비스 연결을 열고 Salesflare(Google로 로그인 또는 호스팅)나 직접 만든 앱을 삭제해요.
