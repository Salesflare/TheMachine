## 추가하기

할 일을 **이메일로** 넘길 때 **할 일 페이지 추가** 또는 **아니요, 괜찮아요**를 누르세요.

1. 미리보기를 확인하세요. 보여 주면 안 되는 부분은 **제외**하고, **되돌리기**를 누르면 다시 표시돼요.
2. 링크가 유효한 기간을 선택하세요. 7일, 14일 또는 30일이에요.
3. **이메일에 추가**를 누르세요. 링크가 초안에 추가되면 이메일을 직접 보내면 돼요.

## 상대방에게 보이는 내용

상대방에게는 할 일과 표시하기로 선택한 내용, 세 가지 답변이 보여요. ‘진행할게요’, ‘완료’, ‘할 수 없어요’ 중 하나를 선택할 수 있어요. 답변은 할 일에 표시돼요.

할 일에서 **할 일 페이지**를 누르면 브라우저에서 상대방에게 보이는 페이지를 열 수 있어요.

페이지는 링크에만 있는 키로 보호돼요. 서버에는 페이지가 어느 단계에 있는지만 표시돼요.

## 공유 중지

할 일에서 **공유 중지**를 누르세요. 페이지는 즉시 삭제되고 링크는 더 이상 작동하지 않아요.
