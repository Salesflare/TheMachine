## 명령 팔레트

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K`, 또는 `/`을 눌러 **검색 및 명령**을 열어요. 이름의 일부를 입력해 보세요. 동작, 페이지, 할 일, 사람, 조직, 프로젝트 또는 메시지를 찾을 수 있어요. 화살표 키와 Enter를 사용하거나 Esc를 눌러 닫으세요. 최근 명령이 먼저 표시되고, **모든 결과 보기**를 누르면 일치하는 메시지를 모두 볼 수 있어요.

휴대전화에서는 상단 바의 검색 아이콘을 눌러요.

## 질문하기

“Kim이 파일럿에 대해 뭐라고 했지?”처럼 질문하면 내 메일과 메시지에서 짧은 답을 찾아 결과 위에 표시해요. 답변에는 참고한 메시지로 연결되는 링크도 있어요. 질문한 언어로 답하고, 현재 보고 있는 영역(전체, 업무 또는 개인)의 내용만 살펴봐요. 이름이나 키워드 몇 개만 입력하면 검색해요.

“Kim이 지난주에 뭐라고 했지?”처럼 사람과 시점을 함께 물으면, 해당 날짜에 그 사람과 주고받은 메시지만 살펴봐요. 시간대는 내 시간대를 기준으로 해요. 그때 메시지가 없으면 없다고 알려주고, 날짜와 함께 가장 최근 메시지를 보여줘요.

“내 개인 메일에 새로 온 게 뭐야?”처럼 내 메일함이나 채팅 계정에 대해 물어보거나, 주소를 입력하거나, “Kim이 WhatsApp으로 뭘 보냈어?”라고 물으면 해당 연결의 메시지만 살펴봐요. 별도로 지정하지 않으면 가장 최근 메시지를 확인해요. 연결 상태도 확인할 수 있어요. 예를 들어 연결에 ‘도움이 필요함’으로 표시되는지, 언제까지 확인했는지 알려줘요. 새로 메시지를 읽지는 않아요.

해당 주제와 관련된 내용이 없으면 현재 보고 있는 영역의 다른 곳도 살펴보고, 어디에서 찾았는지 알려줘요.

연결하지 않은 주소를 물어보면 연결에서 추가하라고 알려줘요. 업무를 선택한 상태에서는 개인 메일함을 볼 수 없고, 반대도 마찬가지예요.

The Machine이 질문과 관련해 이미 보관 중인 내용도 살펴봐요. 약속(열려 있거나 지난 30일 안에 닫힌 약속), 배운 점, 질문한 사람이나 프로젝트 또는 조직의 요약, 회의 메모가 여기에 포함돼요. 답변에 사용한 내용은 각 항목의 종류(예: 약속, 배운 점, 요약 또는 회의 메모)를 표시해 아래에 보여주고, 해당 내용이 있는 곳을 열 수 있어요. 현재 보고 있는 영역에서 질문과 일치하는 내용만 살펴봐요.

같은 이름을 가진 사람이 여럿이면 누구를 말하는지 알려줘요. 그 밖에 읽은 메시지는 메시지 아래에 표시돼요. 검색어가 없을 때 제안되는 질문은 메시지가 있는 항목에 대해서만 나와요. 답변은 메시지를 보내거나 할 일을 추가하지 않으며, 모델이 필요해요(설정, 모델).

## 단축키

컴퓨터에서 사용할 수 있는 전체 키 목록을 보려면 `?`를 눌러 **키보드 단축키**를 열어요.

- 페이지로 이동: `G`를 누른 다음 `T` 할 일, `C` 캘린더, `R` 루틴, `P` 사람, `O` 조직, `J` 프로젝트, `F` Fleet, `L` 배운 점, `N` 연결, `,` 설정을 눌러요. `G`을 누른 다음 `E`을 누르면 메시지 검색 결과가 열려요.
- `N`을 누르면 새 할 일이 추가돼요. `T`를 누르면 Talk가 시작되고, 진행 중일 때 다시 누르면 끝나요. `J`과 `K`(또는 `↓`와 `↑`)을 누르면 목록을 이동해요. Enter를 누르면 항목이 열려요.
- 할 일에서: `E`를 누르면 이름을 바꾸고, `S`를 누르면 미루고, `D`을 누르면 완료로 표시하고, `R`을 누르면 채팅에 내용을 입력해요.
- 캘린더에서: `T`을 누르면 오늘로 이동하고, `J`와 `K`(또는 `→`과 `←`)을 누르면 다음 주나 달 또는 이전 주나 달로 이동해요. `A`, `W`, `M`를 누르면 일정, 주, 월 보기로 전환해요.
- 컴퓨터에서 Mac은 `⌘B`, Windows와 Linux는 `Ctrl B`을 누르면 사이드바를 아이콘만 표시하도록 접거나 다시 펼쳐요.

입력란에 입력 중일 때는 키가 작동하지 않아요.

## 이동하기

- 키보드로 페이지를 열면 첫 번째 항목에 포커스가 놓여요.
- `J` 또는 `↓`를 누르면 다음 할 일로, `K` 또는 `↑`을 누르면 이전 할 일로 이동해요. 접힌 목록의 맨 위 항목도 이동할 수 있어요. Enter 또는 `→`를 누르면 목록이 열리고, `←`을 누르면 다시 접혀요.
- 할 일에서 Enter를 누르면 채팅이 열리고 바로 입력할 수 있어요. Esc를 누르면 입력란에서 나가고, 다시 Esc를 누르면 채팅을 닫고 할 일로 돌아가요. 입력란이 비어 있으면 Esc를 한 번 눌러 닫을 수 있어요.
- Esc를 누르면 대화상자, 명령 팔레트, 단축키 목록도 닫히고 이전에 포커스가 있던 곳으로 돌아가요.
- Tab을 누르면 버튼 사이를 이동해요. 포커스가 있는 항목에는 테두리가 표시돼요.

## 키를 눌러도 전송되지 않아요

키나 명령 팔레트 항목을 눌러도 전송, 승인 또는 게시되지 않아요. “이메일 검토” 같은 항목을 누르면 초안만 열려요. 내용을 읽고 수정한 다음, 초안에 있는 버튼을 눌러 보내면 돼요. 예외는 [하나씩 처리하기](cards.md)예요. 여기서는 Enter를 누르면 전체 내용이 표시된 초안이 전송돼요.
