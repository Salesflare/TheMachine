## 팔레트

Mac에서는 `⌘K`, Windows와 Linux에서는 `Ctrl K` 또는 `/`을 눌러 **검색 및 명령**을 열어요. 이름의 일부를 입력해 보세요. 작업, 페이지, 할 일, 사람, 조직, 프로젝트 또는 메시지를 찾을 수 있어요. 화살표 키와 Enter를 사용하거나 Esc를 눌러 닫으세요. 최근 명령이 먼저 표시되고, **모든 결과 보기**를 누르면 일치하는 메시지를 모두 볼 수 있어요.

휴대폰에서는 상단 바의 검색 아이콘을 눌러요.

## 질문하기

“Kim이 파일럿에 대해 뭐라고 했어?”처럼 질문하면 내 메일과 메시지를 바탕으로 한 짧은 답변이 검색 결과 위에 표시돼요. 답변에는 참고한 메시지로 연결되는 링크가 포함돼요. 질문한 언어로 답하고, 현재 보고 있는 영역(전체, 업무 또는 개인)의 내용만 확인해요. 이름이나 키워드 몇 개만 입력하면 검색만 해요.

“Kim이 지난주에 뭐라고 했어?”처럼 사람과 시간을 함께 물어보면, 해당 날짜에 그 사람이 보냈거나 주고받은 메시지만 확인해요. 시간대는 내 시간대를 기준으로 해요. 그 기간에 메시지가 없으면 없다고 알려 주고, 가장 최근 메시지와 날짜를 보여 줘요.

“내 개인 메일에 새 소식 있어?”처럼 내 메일함이나 채팅 계정 하나를 물어보거나, 주소를 입력하거나, “Kim이 WhatsApp에서 뭘 보냈어?”라고 물어보면 해당 위치의 메시지만 확인해요. 더 구체적으로 요청하지 않으면 가장 최근 메시지를 확인해요. 연결 상태도 알아요. 예를 들어 연결에 ‘도움 필요’로 표시되는지, 마지막으로 확인한 시점과 마지막까지 확인했는지를 알아요. 새로 읽지는 않아요.

“8분 전에 업무 메일함으로 메일이 왔어”처럼 방금 들어온 내용을 물어보면, 어떤 표현을 쓰든 그때쯤부터 해당 위치에 도착한 메시지를 모두 확인해요. 메시지는 검토되기 전이라도 읽는 즉시 찾아요. 이름은 악센트와 하이픈이 없어도 일치해요. “Soren Kjaer”로 검색하면 Søren Kjær를 찾아요.

현재 영역에서 주제와 관련된 내용을 찾지 못하면 현재 보고 있는 영역의 나머지 부분도 확인하고, 어디서 찾았는지 알려 줘요.

연결하지 않은 주소라면 알려 줘요. 연결에서 추가해 주세요. 개인 메일함은 업무를 선택한 상태에서는 볼 수 없고, 반대의 경우도 마찬가지예요.

질문과 관련해 The Machine이 이미 보관 중인 내용도 확인해요. 약속(진행 중이거나 지난 30일 안에 종료된 약속), 배운 점, 질문한 사람이나 프로젝트 또는 조직의 요약, 회의 메모를 확인해요. 답변에 사용한 내용은 종류에 따라 약속, 배운 점, 요약 또는 회의 메모로 표시되고, 해당 내용이 있는 곳을 열 수 있어요. 현재 보고 있는 영역에서 일치하는 내용만 확인해요.

“6월에 Initech에 얼마를 지불했어?” 또는 “갱신 전에는 어땠어?”처럼 과거 상황을 물어보면, 더 이상 유효하지 않은 배운 점도 확인해요. 배운 날짜와 내용이 바뀐 날짜를 함께 보여 줘요. 여러 번 바뀌었다면 그 시기에 알고 있던 내용부터 표시해요. 이는 The Machine이 알아챈 날짜이지, 실제로 사실이 되었거나 더 이상 사실이 아니게 된 날짜라고 단정할 수는 없어요. 삭제한 내용은 다시 나타나지 않아요.

여기서 답을 찾지 못하거나 일부만 찾으면, 현재 보고 있는 영역의 내 메일함을 한 번 검색해요. 오래된 메일도 검색하고, 찾은 내용을 바탕으로 답변하며 각 메일로 연결되는 링크를 제공해요. Gmail과 Outlook만 검색하고 Fleet은 검색하지 않아요. 찾은 오래된 메일은 참고 자료일 뿐, 새 할 일이나 약속으로 만들지 않아요. 검색할 수 없는 메일함이 있으면 알려 줘요.

같은 이름을 가진 사람이 여럿이면 누구를 말하는지 알려 줘요. 다른 동명이인이 지난 3시간 안에 글을 썼다면 두 사람의 내용을 모두 보여 줘요. 확인한 다른 메시지는 메시지 아래에 표시돼요. 검색창이 제안하는 빈 질문은 메시지가 있는 경우에만 표시돼요. 답변은 아무것도 보내거나 할 일을 추가하지 않으며, 모델이 필요해요(설정, 모델).

## 단축키

`?`를 눌러 컴퓨터에서 사용할 수 있는 전체 단축키 목록인 **키보드 단축키**를 열어요.

- 페이지로 이동: `G`를 누른 다음 `T` 할 일, `C` 캘린더, `R` 루틴, `P` 사람, `O` 조직, `J` 프로젝트, `F` Fleet, `L` 배운 점, `N` 연결, `,` 설정을 눌러요. `G`을 누른 다음 `E`을 누르면 메시지 검색 결과가 열려요.
- `N`을 눌러 새 할 일을 추가해요. `T`를 눌러 Talk를 시작하거나, 진행 중일 때 종료해요. `J`과 `K`(또는 `↓`와 `↑`)을 눌러 목록을 이동하고, Enter를 누르면 열려요.
- 할 일에서: `E`로 이름을 바꾸고, `S`로 미루고, `D`으로 완료 처리하고, `R`로 채팅에 내용을 입력해요.
- 캘린더에서: `T`을 누르면 오늘로 이동하고, `J`와 `K`(또는 `→`과 `←`)을 누르면 다음 주나 이전 주 또는 다음 달이나 이전 달로 이동해요. `A`, `W`, `M`를 눌러 안건, 주, 월 보기로 전환해요.
- 컴퓨터에서 Mac은 `⌘B`, Windows와 Linux는 `Ctrl B`을 누르면 사이드바가 아이콘 보기로 접히고, 다시 누르면 펼쳐져요.

입력란에 글을 입력하는 동안에는 단축키가 작동하지 않아요.

## 이동하기

- 키보드로 페이지를 열면 첫 번째 항목에 포커스가 놓여요.
- `J` 또는 `↓`를 누르면 다음 할 일로, `K` 또는 `↑`을 누르면 이전 할 일로 이동해요. 접힌 목록의 맨 앞 항목에도 멈춰요. Enter 또는 `→`를 누르면 목록이 열리고, `←`을 누르면 다시 접혀요.
- 할 일에서 Enter를 누르면 채팅이 열리고 바로 입력할 수 있어요. Esc를 누르면 입력란에서 나가고, Esc를 한 번 더 누르면 채팅이 닫히고 할 일로 돌아가요. 입력란이 비어 있으면 Esc를 한 번 눌러 닫아요.
- Esc를 누르면 대화상자, 팔레트, 단축키 목록도 닫히고, 원래 포커스가 있던 곳으로 돌아가요.
- Tab을 누르면 버튼 사이를 이동해요. 포커스된 항목에는 테두리가 표시돼요.

## 키만 눌러서는 전송되지 않아요

어떤 키나 팔레트 항목도 내용을 보내거나 승인하거나 게시하지 않아요. “이메일 검토” 같은 항목은 초안만 열어요. 내용을 읽고 수정한 다음, 초안에 있는 버튼으로 직접 보낼 수 있어요. 예외는 [전체 확인하기](cards.md)예요. 여기서는 Enter를 누르면 전체 내용이 표시된 초안이 전송돼요.
